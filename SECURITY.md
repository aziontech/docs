# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

### How to Report

Use GitHub private vulnerability reporting: go to the
[Security Advisories](../../security/advisories) page of this repository and
click **"Report a vulnerability"**. Do not open a public issue.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response SLA

| Action | Timeframe |
|--------|-----------|
| Acknowledgment | 2 business days |
| Status update | 5 business days |
| Fix (critical) | Best effort, prioritized |

## Supported Versions

Only the latest release is actively supported with security patches.

## Disclosure Policy

We follow coordinated disclosure. Please do not publicly disclose vulnerabilities until a fix has been released.
