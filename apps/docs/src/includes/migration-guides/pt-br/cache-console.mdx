Para criar a configuração de cache no Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** e selecione a aplicação.

  </DocStep>
  <DocStep title="Vá para a aba Cache Settings" />
  <DocStep title="Selecione + Cache" />
  <DocStep title="Dê um nome à configuração de cache">

  Em **Name**, informe `static-assets`.

  </DocStep>
  <DocStep title="Mantenha Override cache behavior selecionado">

  Em **Cache**, mantenha _Override cache behavior_ selecionado, para que **Max Age** substitua o TTL que a origem envia.

  </DocStep>
  <DocStep title="Defina Max Age">

  Em **Max Age**, informe o TTL em segundos. Por exemplo: `300`.

  </DocStep>
  <DocStep title="(Opcional) Ative Tiered Cache">

  Ative **Tiered Cache** e selecione a **Tiered Cache Region**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A nova configuração aparece na lista **Cache Settings**. Para aplicá-la, crie uma regra da Request Phase na aba **Rules Engine**. Use critérios como `${uri}` _starts with_ `/static/` e o comportamento **Set Cache Policy** definido como `static-assets`.
