Para vincular um firewall com Azion CLI, passe `--firewall-id` para `azion create workload-deployment` ao criar o deployment. Em um projeto que declara o workload no `azion.config.js`, nomeie o firewall em `strategy.attributes.firewall` da entrada [`deployments`](/pt-br/documentacao/devtools/cli/azion-config-js/#deployments-do-workload) dele e execute `azion deploy`. Para o conjunto de regras e a regra, siga [Primeiros passos com WAF](/pt-br/documentacao/plataforma/firewall/waf/primeiros-passos/).
