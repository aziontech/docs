Para criar cada variável com Azion CLI:

```bash
azion create variables --key API_KEY --value <your-value> --secret false
```

A CLI responde com o UUID da nova variável:

```text
Created variable with UUID 00000000-0000-0000-0000-000000000001
```

Defina `--secret true` para uma credencial. Para listar as variáveis, execute `azion list variables`. Para os outros comandos, consulte [variables](/pt-br/documentacao/devtools/cli/recursos/variables/).
