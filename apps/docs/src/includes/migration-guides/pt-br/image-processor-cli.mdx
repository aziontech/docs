Para ativar Image Processor com Azion CLI:

```bash
azion update application --application-id <application-id> --image-processor true
```

```text
Updated Application with ID <application-id>
```

A aplicação tem Image Processor ativado, e suas regras podem trazer o comportamento `optimize_images`. Para criar a regra, siga o painel CLI de [Primeiros passos com Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/primeiros-passos/).
