Para criar o redirecionamento no Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** e selecione a aplicação.

  </DocStep>
  <DocStep title="Vá para a aba Rules Engine" />
  <DocStep title="Selecione + Rule" />
  <DocStep title="Dê um nome à regra">

  Informe um nome como `old-path-redirect` e selecione **Request Phase**.

  </DocStep>
  <DocStep title="Defina os critérios">

  Em **Criteria**, selecione `${uri}` e o operador _matches_. Como argumento, informe `^/old/(.*)$`.

  </DocStep>
  <DocStep title="Adicione o comportamento Capture Match Groups">

  Em **Behaviors**, selecione _Capture Match Groups_. Informe `capture` como nome do array, `${uri}` como **Subject** e `^/old/(.*)$` como **Regex**.

  </DocStep>
  <DocStep title="Adicione o redirecionamento">

  Adicione um segundo comportamento, _Redirect To (301 Moved Permanently)_, com `/new/%{capture[1]}` como argumento.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A regra aparece na lista de regras de requisição.
