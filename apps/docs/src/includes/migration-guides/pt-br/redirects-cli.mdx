Para criar o redirecionamento com Azion CLI, adicione a regra às `rules` da aplicação no `azion.config.js`. Dê a ela os comportamentos `capture_match_groups` e `redirect_to_301` e execute `azion deploy`. Para os campos de uma regra, consulte [azion.config.js](/pt-br/documentacao/devtools/cli/azion-config-js/).
