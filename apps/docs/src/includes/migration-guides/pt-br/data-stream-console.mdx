Para criar um stream no Azion Console:

<DocSteps>
  <DocStep title="Abra Data Stream">

  Acesse [Azion Console](https://console.azion.com/) > **Data Stream**.

  </DocStep>
  <DocStep title="Selecione + Stream" />
  <DocStep title="Selecione a fonte de dados">

  Em **Input**, selecione a **Data Source**: _Activity History_, _Applications_, _Functions_ ou _WAF Events_.

  </DocStep>
  <DocStep title="Selecione o template">

  Em **Render Template**, selecione o **Template**. Para escolher os campos, selecione **Create Custom Template**.

  </DocStep>
  <DocStep title="Selecione o destino">

  Em **Output**, selecione o **Connector**, como _Datadog_ ou _Simple Storage Service (S3)_, e informe suas credenciais.

  </DocStep>
  <DocStep title="Ative Active e selecione Save" />
</DocSteps>

O stream começa a enviar depois de 1 a 2 minutos.
