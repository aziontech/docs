To create the cache setting in Azion Console:

<DocSteps>
  <DocStep title="Open the application">

  Access [Azion Console](https://console.azion.com/) > **Applications**, then select the application.

  </DocStep>
  <DocStep title="Go to the Cache Settings tab" />
  <DocStep title="Select + Cache" />
  <DocStep title="Name the cache setting">

  In **Name**, enter `static-assets`.

  </DocStep>
  <DocStep title="Keep Override cache behavior selected">

  Under **Cache**, keep _Override cache behavior_ selected, so **Max Age** replaces the TTL the origin sends.

  </DocStep>
  <DocStep title="Set Max Age">

  In **Max Age**, enter the TTL in seconds. For example: `300`.

  </DocStep>
  <DocStep title="(Optional) Turn on Tiered Cache">

  Turn on **Tiered Cache**, and select the **Tiered Cache Region**.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The new setting appears in the **Cache Settings** list. To apply it, create a Request Phase rule in the **Rules Engine** tab. Use criteria such as `${uri}` _starts with_ `/static/`, and the behavior **Set Cache Policy** set to `static-assets`.
