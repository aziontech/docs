To turn on Image Processor with the Azion CLI:

```bash
azion update application --application-id <application-id> --image-processor true
```

```text
Updated Application with ID <application-id>
```

The application has Image Processor on, and its rules can carry the `optimize_images` behavior. To create the rule, follow the CLI panel of the [Image Processor quickstart](/en/documentation/platform/applications/image-processor/quickstart/).
