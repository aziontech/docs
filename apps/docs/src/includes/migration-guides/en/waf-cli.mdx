To bind a firewall with the Azion CLI, pass `--firewall-id` to `azion create workload-deployment` when you create the deployment. In a project that declares the workload in `azion.config.js`, name the firewall in `strategy.attributes.firewall` of its [`deployments`](/en/documentation/devtools/cli/azion-config-js/#workload-deployments) entry, then run `azion deploy`. For the rule set and the rule, follow the [WAF quickstart](/en/documentation/platform/firewall/waf/quickstart/).
