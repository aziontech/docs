To turn on Image Processor in Azion Console:

<DocSteps>
  <DocStep title="Open the application">

  Access [Azion Console](https://console.azion.com/) > **Applications**, then select the application.

  </DocStep>
  <DocStep title="Turn on Image Processor">

  In the **Main Settings** tab, under **Modules**, turn on **Image Processor**. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/).

  </DocStep>
  <DocStep title="Select Save" />
  <DocStep title="Add the Optimize Images rule">

  In the **Rules Engine** tab, create a Request Phase rule with `${uri}` _matches_ `\.(jpg|jpeg|gif|bmp|png|ico|webp|avif)` and the _Optimize Images_ behavior.

  </DocStep>
</DocSteps>

Image requests that match the rule are now processed.
