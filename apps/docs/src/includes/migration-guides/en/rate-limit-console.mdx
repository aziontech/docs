To create the rate limit in Azion Console:

<DocSteps>
  <DocStep title="Open the firewall">

  Access [Azion Console](https://console.azion.com/) > **Firewalls**, and select the firewall.

  </DocStep>
  <DocStep title="Go to the Rules Engine tab" />
  <DocStep title="Select + Rule" />
  <DocStep title="Set the criteria">

  Under **Criteria**, select `${request_uri}`, the _starts with_ operator, and `/api/` as the argument.

  </DocStep>
  <DocStep title="Add the Set Rate Limit behavior">

  Under **Behaviors**, select _Set Rate Limit_. Set **Rate Limit Type** to _Req/s_, **Limit By** to _Client IP address_, **Average Rate Limit** to `10`, and **Maximum Burst Size** to `10`.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The rule appears in the list of firewall rules.
