To turn on Load Balancer in Azion Console:

<DocSteps>
  <DocStep title="Open the Connectors page">

  Access [Azion Console](https://console.azion.com/) > **Connectors**.

  </DocStep>
  <DocStep title="Open the connector of the origin" />
  <DocStep title="Turn on Load Balancer">

  In **Modules**, turn on **Load Balancer**.

  </DocStep>
  <DocStep title="Select the balancing method">

  In **Load Balancer Configuration**, set **Method** to _Round Robin_, _Least Connections_, or _IP Hash_.

  </DocStep>
  <DocStep title="Set the first address">

  Under **Address Management**, on the existing address, set **Server Role** and **Weight**.

  </DocStep>
  <DocStep title="Select Add Address" />
  <DocStep title="Enter the next origin">

  In the new **Address**, enter the host of the origin, without a protocol or a port. Then set its **Server Role** and **Weight**.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The Console shows `Connector has been updated`. The connector has Load Balancer on and one address for each origin.
