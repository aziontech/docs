To create the redirect in Azion Console:

<DocSteps>
  <DocStep title="Open the application">

  Access [Azion Console](https://console.azion.com/) > **Applications**, then select the application.

  </DocStep>
  <DocStep title="Go to the Rules Engine tab" />
  <DocStep title="Select + Rule" />
  <DocStep title="Name the rule">

  Enter a name such as `old-path-redirect`, and select **Request Phase**.

  </DocStep>
  <DocStep title="Set the criteria">

  Under **Criteria**, select `${uri}` and the _matches_ operator. As the argument, enter `^/old/(.*)$`.

  </DocStep>
  <DocStep title="Add the Capture Match Groups behavior">

  Under **Behaviors**, select _Capture Match Groups_. Enter `capture` as the array name, `${uri}` as the **Subject**, and `^/old/(.*)$` as the **Regex**.

  </DocStep>
  <DocStep title="Add the redirect">

  Add a second behavior, _Redirect To (301 Moved Permanently)_, with `/new/%{capture[1]}` as the argument.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The rule appears in the list of request rules.
