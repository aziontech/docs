:::caution[atenção]
    Aplicações HTTP são automaticamente protegidas pelo certificado SAN da Azion. No entanto, aplicações HTTPS requerem [configuração de cifras TLS](/pt-br/documentacao/guias/seguranca-de-aplicacoes/tls-e-certificados/cifras/) e um [certificado digital](/pt-br/documentacao/guias/seguranca-de-aplicacoes/tls-e-certificados/certificado-digital/).
:::
