If you've already installed [Azion Orchestrator Agent](/en/documentation/guides/application-development/automation/install-orchestrator-agent/) on your device, the next step is to authorize the edge node on the platform. You can do so in Azion Console. API v4 has no Orchestrator endpoints.

<DocButton href="/en/documentation/guides/application-development/automation/install-orchestrator-agent/" label="Go to install Orchestrator agent" kind="secondary" size="medium" />

## Authorize the edge node

1. Access [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Find the edge node you wish to authorize, which will have the status `Waiting Authorization`.
3. Select the three dots icon and then select **Authorize**.
4. Confirm the authorization. 

After the authorization, an edge node can take up to 10 seconds before services can be orchestrated on it.

## Authorize several edge nodes at once

To authorize several edge nodes in one action in Azion Console:

1. Access [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Select the edge nodes you want to authorize. To select every edge node in the list, select the checkbox in the list header.
3. Select **Actions** and then select **Authorize**.
4. Select **Confirm**.

A confirmation message appears.
