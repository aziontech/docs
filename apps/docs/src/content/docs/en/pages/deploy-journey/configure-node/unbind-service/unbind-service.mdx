You can unbind an edge service from an edge node in Azion Console. API v4 has no Orchestrator endpoints.

---

## Unbind the edge service

1. Access [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Select the edge node from which you want to unbind a service.
3. Go to the **Services** tab.
4. Find the service you wish to unbind and select the trash can icon. 
5. Confirm the unbinding.
