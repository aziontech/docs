During the deployment process on [Orchestrator](/en/documentation/platform/orchestrator/), you can work with variables. A variable can be set on an [edge service](#edge-services-variables) and an [edge node](#edge-node-variables).

You can create edge node and edge services variables in [Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/). API v4 has no Orchestrator endpoints.

:::note
The priority is always the edge node variable. So, if you have a variable configured on an edge service and the same variable configured on an edge node, the one on the node will override the one configured on the edge service.
:::

---

## Edge Services variables 

1. Access [Azion Console](https://console.azion.com/) > **Edge Services**.
2. Select the [edge service](/en/documentation/guides/application-development/automation/create-edge-service/) to which you want to add a variable.
3. In the **Variables** section, add the following variable:

<Code client:visible lang="bash" code="name=azion" />

4. Select **Save**.

Now, you've created a variable related to a specific service. You need to access this variable through a resource.

1. Navigate to the **Resources** tab. 
2. Click on **+ Resource** or select the resource to which you wish to use the variable.
3. Enter the **Path** of the resource.
4. Choose the type **Text**.
5. Add the following content to the content block: 

```bash
I am using {{name}} Orchestrator
```

6. Click the **Save** button.

---

## Edge Node variables

1. Access [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Select the edge node to which you want to add a variable.
3. Go to the **Services** tab.
4. Choose the [service](/en/documentation/guides/application-development/automation/create-edge-service/) to which you want to apply the variable.
5. Add the following content to the variables block: 

```bash 
name=azion2
```

6. Select **Save**.

Now, you've created a variable related to a specific node. You need to access this variable through a resource.

1. Go to **Edge Services**.
2. Select the service related to the resource. 
3. Click on **+ Resource** or select the resource where you wish to use the variable.
4. Enter the **Path** of the resource.
5. Choose the type **Text**.
6. Add the following content to the content block: 

```bash 
I am using {{name}} Orchestrator
```

7. Click the **Save** button.

---

## Access the resource on the edge node

Your variables are ready to be accessed during the execution on the nodes related to the service. It's relevant to stress that when you have a variable with the same name configured on a service and on a node, the value stored on the node will prevail, for example:

Variable configured on the edge service: 

```bash
name=azion
```

Variable configured on the edge node

```bash
name=azion2
```

When the resource is accessed, the value of the variable will be `azion2` instead of `azion`.

To access the resource on the edge node, you need to access the file. You can access it through the filepath you informed during the creation of the resource. 

Resource name: 

```bash
/txt/test
```

To access it: 

```bash 
nano /txt/test
```
