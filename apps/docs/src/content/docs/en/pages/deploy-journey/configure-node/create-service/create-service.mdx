You can create an edge service in Azion Console or with the Azion API.

## Create the edge service

<Tabs client:visible sharedStore="interface">
    <Fragment slot="tab.console">Console</Fragment>
    <Fragment slot="tab.api">API</Fragment>

<Fragment slot="panel.console">

### Console

1. Access [Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/) > **Edge Services**.
2. Click on the **+ Service** button.
3. Give a name for your service.
4. Define the variables, if necessary.
    - The variables must be in the format `Variable = Value`.
5. Set the status as **Active**.
6. Click the **Save** button.
7. Go to the **Resources** tab and [provide resources](/en/documentation/guides/application-development/automation/provision-files/) for your service.
</Fragment>

<Fragment slot="panel.api">

### API

1. Run the following `POST` request in your terminal, replacing `[TOKEN VALUE]` with your [personal token](/en/documentation/guides/platform/account-and-billing/personal-tokens/) and informing the name of the service being created:

```bash
curl --location 'https://api.azionapi.net/edge_services/' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]' \
--header 'Content-Type: application/json' \
--data '{
  "name": "string"
}'
``` 

2. Keep the `id` returned in the response body. The API creates the service with `"active": false`.

3. Run the following `PATCH` request to set the service as active, replacing `[TOKEN VALUE]` with your personal token and `:id` with the ID of the edge service:

```bash
curl --location --request PATCH 'https://api.azionapi.net/edge_services/:id' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]' \
--header 'Content-Type: application/json' \
--data '{
  "active": true
}'
```

Now, the service is active and you can bind it to your edge nodes.

:::note
If an edge service isn't set as active, it isn't available for binding to an edge node.
:::

:::tip
Check the [Azion API documentation](https://api.azion.com/) and the [OpenAPI specification](https://github.com/aziontech/azionapi-openapi/) to know more about all features available via API.
:::
