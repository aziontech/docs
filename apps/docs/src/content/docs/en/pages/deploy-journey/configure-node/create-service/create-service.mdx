You can create an edge service in Azion Console. API v4 has no Orchestrator endpoints.

## Create the edge service

1. Access [Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/) > **Edge Services**.
2. Click on the **+ Service** button.
3. Give a name for your service.

:::note
If an edge service isn't set as active, it isn't available for binding to an edge node.
:::
4. Define the variables, if necessary.
    - The variables must be in the format `Variable = Value`.
5. Set the status as **Active**.
6. Click the **Save** button.
7. Go to the **Resources** tab and [provide resources](/en/documentation/guides/application-development/automation/provision-files/) for your service.
