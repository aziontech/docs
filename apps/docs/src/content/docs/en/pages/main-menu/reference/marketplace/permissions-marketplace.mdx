An Azion Marketplace integration can require read and write privileges on the configuration of your [application](/en/documentation/platform/applications/). When Azion Console asks for them, it shows the message "Azion Marketplace requires the following privileges on the selected Application." with a link to this page. A template can instead require products that you activate on your account.

## Application privileges

An integration that asks to read and write **Main Settings** reads or changes one of the settings below. In Azion Console, Application Accelerator, Functions, and Image Processor are Default Modules in the **Modules** section of the application's **Main Settings** tab.

| Module or setting | Why an integration asks for it |
| --- | --- |
| [Functions](/en/documentation/platform/functions/) | Required to run any integration installed from Marketplace, so you must allow access to it. The integration uses it to change the viewer request or response, customize the function's arguments (**Args**), and choose the criteria that run it in [Rules Engine](/en/documentation/platform/applications/rules-engine/). |
| [Application Accelerator](/en/documentation/platform/applications/application-accelerator/settings/) | Required when the integration uses advanced Rules Engine behaviors, such as `Bypass Cache` or `Forward Cookies`. |
| [Image Processor](/en/documentation/platform/applications/image-processor/settings/) | Optimizes how the application handles images. |
| Load Balancer | Balances traffic for reliability and network congestion control. |

:::note
Some integrations require [Tiered Cache](/en/documentation/platform/applications/cache/tiered-cache/). To activate Tiered Cache for your account, contact the [Azion Sales team](https://www.azion.com/en/contact/).
:::

## Rules Engine

An application runs its criteria and behaviors through [Rules Engine](/en/documentation/platform/applications/rules-engine/). An integration runs on a request when a rule with the **Run Function** behavior calls its function, so Azion Marketplace needs read and write privileges on the rules of your application.

## Firewall privileges

Some integrations run on a [firewall](/en/documentation/platform/firewall/) instead of an application. These integrations need more privileges than an application grants. For more information, refer to [Teams permissions](/en/documentation/fundamentals/teams-permissions/).

## Template requirements

Some templates need Azion products that you activate on your account and enable separately in Azion Console. When those products are active, running the template can generate usage costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

Some templates also work with third-party tools. To use one, you meet the tool's requirements, such as creating an account or completing an initial setup. That tool can also generate usage costs.
