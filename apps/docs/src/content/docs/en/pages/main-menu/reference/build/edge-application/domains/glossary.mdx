Definitions for the terms the **Domains** documentation uses.

| Term | Definition |
| --- | --- |
| Azion domain | The hostname that Azion generates for a domain, in the format `xxxx.map.azionedge.net`. A domain in the Staging Network gets one in the format `xxxx.preview.azionedge.net`. [Domain settings](/en/documentation/platform/domains/reference/#environment) lists both. |
| Azion SAN | The certificate a domain uses when you select **Azion SAN** in **Digital Certificate**, or when `digital_certificate_id` is `null`. [Domain settings](/en/documentation/platform/domains/reference/#domain-fields) lists the field. |
| custom domain | A hostname of a domain you own, listed in the **CNAME** field of a domain so the domain answers it. [Point a domain to a workload](/en/documentation/guides/platform/migration/point-domain-to-azion/) creates the DNS record that sends it to Azion. |
| domain | An entry on your account, created in Domains, that holds a name, the hostnames it serves, the application that answers them, and its certificate. [Domains](/en/documentation/platform/domains/) describes the Platform Resource. |
| mTLS | Mutual Transport Layer Security: a TLS handshake in which the client also presents a certificate, which the domain validates against a Trusted CA certificate. [Domain settings](/en/documentation/platform/domains/reference/#mtls) lists its fields. |
| Trusted CA certificate | The certificate of a certificate authority that you trust, of type `trusted_ca_certificate`. A domain checks the certificates of its clients against it when mTLS is on. [Domain settings](/en/documentation/platform/domains/reference/#mtls) lists the field. |
