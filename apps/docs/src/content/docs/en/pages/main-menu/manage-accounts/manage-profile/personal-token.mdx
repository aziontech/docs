You can create and delete a [personal token](/en/documentation/fundamentals/personal-tokens/) from Azion Console or with the [Azion CLI](/en/documentation/devtools/cli/). A personal token authenticates your requests to the [Azion API](/en/documentation/devtools/api/) and the commands you run in the CLI. To revoke a token, delete it.

## Create a personal token

Each personal token has a name, an optional description, and an expiration. Azion shows the token value only when the token is created, so store it before you continue.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

To create a personal token in Azion Console:

<DocSteps>
  <DocStep title="Open the Personal Tokens page">

  Access [Azion Console](https://console.azion.com/) > **Account** > **Personal Token**. **Account** is the avatar menu.

  </DocStep>
  <DocStep title="Select + Personal Token" />
  <DocStep title="Name the token">

  In the **General** section, enter a **Name** that identifies the token.

  </DocStep>
  <DocStep title="(Optional) Describe the token">

  In **Description**, enter what the token is for.

  </DocStep>
  <DocStep title="Set the expiration">

  In the **Token** section, select a value in **Expires within**. The default is _1 day_. The other values are:

  - _7 days_, _15 days_, _30 days_, or _90 days_
  - _1 year_
  - _Custom Date_, which opens a calendar to select the date

  </DocStep>
  <DocStep title="Select Save" />
  <DocStep title="Copy the token">

  In the **Personal Token has been created** dialog, select **Copy**. The **Personal Token** field masks the value until you show it.

  </DocStep>
  <DocStep title="Select Confirm" />
</DocSteps>

The token appears on the **Personal Tokens** page with its **Expiration Date**. After the dialog closes, the value cannot be retrieved, and a lost token must be replaced with a new one.

</Fragment>

<Fragment slot="panel.cli">

To create a personal token with the Azion CLI, pass a name, an expiration, and an optional description. This command creates a token named `my-token` that expires the next day:

```bash
azion create personal-token --name my-token --expiration 1d --description 'Token for local CLI tests'
```

The command prints the token value:

```text
Created Personal Token: [TOKEN VALUE]
```

The `--expiration` flag takes a number followed by `d` for days or `m` for months, such as `1d` or `9m`. No other `personal-token` command prints the value. To create the token from a JSON file with the `name`, `expires_at`, and `description` keys, refer to [Azion CLI personal-token](/en/documentation/devtools/cli/resources/personal-token/).

</Fragment>

</Tabs>

## Delete a personal token

Deleting a personal token revokes it, and the deletion cannot be undone. Azion Console asks you to confirm the deletion with the token name, and the Azion CLI takes the token UUID.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

To delete a personal token in Azion Console:

<DocSteps>
  <DocStep title="Open the Personal Tokens page">

  Access [Azion Console](https://console.azion.com/) > **Account** > **Personal Token**. **Account** is the avatar menu.

  </DocStep>
  <DocStep title="Select Delete on the token">

  In the row of the token, select **Delete**. The **Delete personal token** dialog opens.

  </DocStep>
  <DocStep title="Enter the token name">

  In the box of the dialog, enter the name of the token, as the confirmation label quotes it.

  </DocStep>
  <DocStep title="Select Delete" />
</DocSteps>

The message **Personal token successfully deleted** appears, and the token no longer shows on the **Personal Tokens** page.

</Fragment>

<Fragment slot="panel.cli">

The Azion CLI deletes a personal token by its UUID. To find the UUID, list your personal tokens:

```bash
azion list personal-token
```

The command prints the UUID, the name, and the expiration of each token, never its value:

```text
ID                                    NAME                               EXPIRES AT
11111111-2222-4333-8444-555555555555  my-token                           2027-01-15 23:59:59 +0000 UTC
22222222-3333-4444-8555-666666666666  ci-deploy                          2026-12-20 23:59:59 +0000 UTC
33333333-4444-4555-8666-777777777777  cli-local                          2027-09-17 23:59:59 +0000 UTC
44444444-5555-4666-8777-888888888888  old-token                          2026-09-11 23:59:59 +0000 UTC
```

A token past its expiration, such as `old-token`, stays in the list until you delete it.

To delete the token, pass its UUID in `--id`. This command deletes the token named `my-token`:

```bash
azion delete personal-token --id 11111111-2222-4333-8444-555555555555
```

The command deletes the token without asking for confirmation, and prints:

```text
Personal token 11111111-2222-4333-8444-555555555555 was successfully deleted
```

</Fragment>

</Tabs>
