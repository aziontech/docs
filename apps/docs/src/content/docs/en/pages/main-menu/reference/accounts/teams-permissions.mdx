On the **Team Permissions** page, you can create and manage teams, control and configure access rights for distinct teams within your organization. You can, for example, create groups dividing them into the tasks that they need to perform at Azion's platform.

:::note
Only users with **Account Owner** status can add teams and edit permissions.
:::

By granting or restricting access to specific features and settings, you can:

- Save time, since the teams access only what they need.
- Enhance security, limiting the access to keep sensitive information safe.
- Have more control, tracking the specific teams actions for security and rules.
- Encourage teamwork with the team accessing tools together.

## Access permissions

In this table, you can find what each permission grants access to:

| Permission | Description |
| --- | --- |
| View Content Delivery Settings   | Grants permission to view the cache settings list. Permission for the products Web Performance, Real-Time Purge, Analytics and Analytics Standard.   |
| Edit Content Delivery Settings   | Grants permission to edit the cache settings list. It also requires the permission **View Content Delivery Settings**.  Permission for the products Web Performance, Real Time Purge, Analytics and Analytics Standard.                           |
| Real-Time Purge                  | Grants permission to add a new purge to Real-Time Purge.                                                                                                         |
| View Analytics                   | Grants permission to view analytics. |
| View Security Settings           | Grants permission to view WAF Rule Sets and Certificate Manager (with the exception of the private key), but does not allow creation, removal, or modifications. |
| Edit Security Settings           | Grants permission to view, create, edit, and remove WAF Rule Sets and Certificate Manager. It also requires the permission **View Security Settings**.                                                                       |
| View Subscriptions               | Grants permission to view the account subscriptions, but does not allow modifications. It also requires the permission **View Bills**.
| Edit Subscriptions               | Grants permission to modify the account subscriptions. It also requires the permissions **View Bills** and **View Subscriptions**.                                                                                                                                                                    |
| View Payment Methods             | Grants permission to view the active payment methods and payment history. It also requires the permission **View Bills**.                                                                                                                                                                     |
| Edit Payment Methods             | Grants permission to create, edit, and remove payment methods. It also requires the permissions **View Bills** and **View Payment Methods**.                                                                                                                                                                     |
| View Bills                       | Grants permission to view the **Billing** tab in **Billing & Subscriptions**. Viewing the Payment Methods and Payment History require the **View Payment Methods** permission.                                                                                                                                                                    |
| Edit Multi-Factor Authentication | Grants permission to edit Multi-Factor Authentication.                                                                                                                                                                    |
| View Applications           | Grants permission to view the configurations, but it does not allow modifications, creation, or removal.                                                                                                                                                                    |
| Edit Applications           | Grants permission to edit, create, and remove applications. It also requires the permission **View Applications**.                                                                                                                                                                   |
| View Workloads                   | Grants permission to view existing workloads, but it does not allow creation, removal, or modifications.                                                                                                                                                                   |
| Edit Workloads                   | Grants permission to create, edit, and remove workloads. It also requires the permission **View Workloads**.                                                                                                                                                                   |
| View Connectors                  | Grants permission to view connectors. |
| Edit Connectors                  | Grants permission to edit connectors. It also requires the permission **View Connectors**. |
| View Custom Pages                | Grants permission to view custom pages. |
| Edit Custom Pages                | Grants permission to edit custom pages. It also requires the permission **View Custom Pages**. |
| View Events                      | Grants permission to view and filter by data source.                                                                                                                                                                      |
| View Users                       | Grants permission to view the users' account on the Users Management page, but it does not allow creation, removal, or modifications.  |
| Edit Users                       | Grants permission to create, edit, and remove users on the account. It also requires the permission **View Users**.                                                                                                                                                                   |
| Wildcard Purge                   | Grants permission to select the purge type **Wildcard** in **Real-Time Purge**. It also requires the permission **Real-Time Purge**.                                                                                                                                                                 |
| View DNS                         | Grants permission to view the zones created on the account. It does not allow creation or removal.                                                                                                                                                                   |
| Edit DNS                         | Grants permission to create, edit, and remove zones. It also requires the permission **View DNS**.                                                                                                                                                                   |
| View Data Stream                 | Grants permission to view the account's streams. It does not allow creation, modification, or removal.                                                                                                                                                                  |
| Edit Data Stream                 | Grants permission to create, edit, and remove streams. It also requires the permission **View Data Stream**.                                                                                                                                                                  |
| View Network Lists               | Grants permission to view Network Lists, but does not allow creation, removal, or modification.                                                                   |
| Edit Network Lists               | Grants permission to view, create, edit, and remove Network Lists. It also requires the permission **View Network Lists**.                                                                                               |
| View Firewall               | Grants permission to view firewall, but does not allow creation, removal, or modification.                                                         |
| Edit Firewall               | Grants permission to view, create, edit, and remove firewall. It also requires the permission **View Firewall**.                                                                            |
| View Functions              | Grants permission to view functions, but it does not allow creation, removal, or modifications.                                                                                                                                                                  |
| Edit Functions              | Grants permission to create, edit, and remove functions. It also requires the permission **View Functions**.                                                                                                                                                                 |
| View Storage Bucket              | Grants permission to view Object Storage buckets using the Azion API. |
| Edit Storage Bucket              | Grants permission to create and edit Object Storage buckets using the Azion API. |
| Delete Storage Bucket            | Grants permission to remove Object Storage buckets using the Azion API. |
| View Storage Object              | Grants permission to view the metadata of objects and download objects from Object Storage buckets using the Azion API. |
| Edit Storage Object              | Grants permission to create and edit objects in Object Storage buckets using the Azion API. |
| Delete Storage Object            | Grants permission to remove objects in Object Storage buckets using the Azion API. |
| View client list                 | Grants permission to view clients list. It does not allow creation, modifications, or removal of clients. The Clients feature is only available for accounts of the Reseller type.                                                                                                                                                               |
| Change clients                   | Grants permission to create, edit or remove Clients. It also requires the permission **View Client list**.                                                                                                                                                                         |
| View SQL Database                    | Grants permission to view the created databases and their data using the Azion API. |
| Edit SQL Database                    | Grants permission to create and edit databases and their data using the Azion API. |
| Create Storage Credentials       | Grants permission to create storage credentials. |
| View Storage Credentials         | Grants permission to view storage credentials. |
| Delete Storage Credentials       | Grants permission to delete storage credentials. |
| View Policies                    | Grants permission to view policies. |
| Edit Policies                    | Grants permission to edit policies. It also requires the permission **View Policies**. |
| Delete Policies                  | Grants permission to delete policies. |
| Create VCS Integrations          | Grants permission to create VCS integrations. |
| View VCS Integrations            | Grants permission to view VCS integrations. |
| Delete VCS Integrations          | Grants permission to delete VCS integrations. |
| View VCS Continuous Deployment   | Grants permission to view VCS continuous deployment. |
| Edit VCS Continuous Deployment   | Grants permission to edit VCS continuous deployment. It also requires the permission **View VCS Continuous Deployment**. |
| Delete VCS Continuous Deployment | Grants permission to delete VCS continuous deployment. |
| Create VCS Continuous Deployment Execution | Grants permission to create VCS continuous deployment executions. |
| Create Orchestrator Nodes        | Grants permission to create Orchestrator nodes. |
| Edit Orchestrator Nodes          | Grants permission to edit Orchestrator nodes. |
| Delete Orchestrator Nodes        | Grants permission to delete Orchestrator nodes. |

| Edit Orchestrator Services       | Grants permission to edit Orchestrator services. |

## Errors

If a user tries to access a page on Azion's platform without the required permissions, a *403 Forbidden* error page will be delivered.
