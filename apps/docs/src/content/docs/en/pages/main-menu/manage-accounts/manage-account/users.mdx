You can add, edit, and delete the users of an account in [Users Management](/en/documentation/fundamentals/users-management/), from Azion Console. What a user who is not an Account owner can do comes from the teams the user belongs to. To create those teams and their permissions, refer to [Manage teams and permissions](/en/documentation/guides/platform/account-and-billing/teams-permissions/).

---

## Prerequisites

- Access to Azion Console as an **Account owner**, or as a user on a team with the **View Users** and **Edit Users** permissions. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- An email address for the new user. Azion Console sends the activation email to it.

---

## Add a user to the account

The user form has four sections: **Profile**, **Contact Information**, **Security Settings**, and **Status**. A field with an asterisk is required. The user can join teams that exist already or that you [create later](/en/documentation/fundamentals/teams-permissions/).

To add a user in Azion Console:

<DocSteps>
  <DocStep title="Open Users Management">

  Access [Azion Console](https://console.azion.com/) and, in the account menu, select **Users Management**.

  </DocStep>
  <DocStep title="Select + User" />
  <DocStep title="Fill in the profile">

  In the **Profile** section, enter the **First Name** and **Last Name**, and choose a **Timezone** and a **Language**.

  </DocStep>
  <DocStep title="Enter the contact information">

  In the **Contact Information** section, enter the **Email** and the **Phone Number**. Include the country and region code in the phone number.

  </DocStep>
  <DocStep title="Choose the teams">

  In the **Security Settings** section, select one or more **Teams**. With no team created yet, select **Default Team**.

  </DocStep>
  <DocStep title="Set the access level">

  (Optional) In the same section, turn on **Account owner** to give the user full access to every feature, account management included.

  </DocStep>
  <DocStep title="Keep the user active">

  In the **Status** section, leave **Active** turned on.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

Azion Console returns to **Users Management**, where the user is listed with the **First Name**, **Last Name**, **Email Address**, **Teams**, **Account Owner**, **MFA**, and **Status** columns.

An Account owner reaches every feature, including account and solution management. A non-owner reaches solution management only as far as the permissions of the user's teams allow.

:::note
Azion sends the new user an email to activate the account. The activation stays valid for 14 days. When the user does not activate the account within that time, Azion removes the user from the platform.
:::

The **Security Settings** section also carries **Enforce Multi-Factor Authentication**. To turn MFA on or off for a user, refer to [Enable multi-factor authentication](/en/documentation/guides/platform/account-and-billing/multi-factor-authentication/).
