Azion allows some accounts to create separate accounts, each managed independently with its own **Account owner**. An account of the *Company* type creates *Group* accounts, and an account of the *Reseller* type creates *Client* accounts.

You need to be an **Account owner** or have the **View client list** and **Change clients** permissions to add clients to your account.

:::note
**Groups Management** shows in the account menu only on *Company* accounts, and **Clients Management** only on *Reseller* accounts.
:::

---

## Group accounts

An account of the *Company* type creates *Group* accounts in **Groups Management**, in the account menu. The **Create Group** form carries the same sections as a client account, described in [Client accounts](/en/documentation/fundamentals/accounts/#client-accounts).

---

## Client accounts

An account of the *Reseller* type creates *Client* accounts in **Clients Management**, in the account menu. When you select the **Add client** button, three sections are displayed: **Main Settings**, **Address Information**, and **Account Owner**.

Fields marked with an asterisk are required.

### Main settings

In this section, you can fill in the client details.

| Field | Description |
| --- | --- |
| **Account name** | Name of the client company; it is the *Client* type account. |
| **Company name** | Corporate name. |
| **Unique identifier** | Unique code that identifies the legal entity of that client. |
| **Billing emails** | Billing email addresses. |
| **Active** | Enables or disables the operation of that client. |

### Address information

In this section, you can inform the client's address information.

| Field | Description |
| --- | --- |
| **Country** | Country where the client is located. |
| **State/Region** | State or region where the client is located. |
| **City** | City where the client is located. |
| **Address** | Address where the client is located. |
| **Apartment, floor, etc.** | Additional information for the address. |
| **Postal code** | Postal code of the client. |

### Account Owner

These fields refer to the Account Owner of the new account.

| Field | Description |
| --- | --- |
| **First name** | Account owner's name for the client. |
| **Last name** | Account owner's last name for the client. |
| **Email Identifier** | Email address of the user who will be the Account owner of that account. The Account owner will use this email as login information. |

After confirming the registration, the Account owner receives an automatic email to activate the account, which will be available for *14 days*. If it is not activated within that period, the Account owner will be automatically removed from Azion's platform.
