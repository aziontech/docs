[Domains](/en/documentation/platform/domains/) bounds the number of CNAMEs one domain lists. This page states the default limit and how to raise it.

---

## Default limits

| Scope | Limit |
| --- | --- |
| CNAMEs per domain | 50 |

You can request a higher limit based on your plan. Contact the [technical support team](/en/documentation/support/) to request it.
