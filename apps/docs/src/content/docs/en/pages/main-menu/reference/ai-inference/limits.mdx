A model call in [AI Inference](/en/documentation/platform/ai-inference/) meets three kinds of boundary. The first is access, which depends on the plan of the account. The second is a condition: Azion may terminate the execution of a model that consumes too much memory or runs too long, and may deprovision one that is created and not executed for more than three days. The third is a stated value that bounds one call, such as a request field or a model's context length. This page carries the access and the conditions, and names the page that states each value.

## Access by plan

Access to AI Inference depends on the plan. The plans are the ones the [Azion pricing page](https://www.azion.com/en/pricing/) lists.

| Plan | AI Inference access |
| --- | --- |
| Hobby | Upon request, subject to approval |
| Pro | Upon request, subject to approval |
| Enterprise | Custom |

An account without access receives `AIError: model not found or not allowed` for every model id. That is the same error a model id that does not exist returns, so the error alone does not tell the two cases apart.

---

## Model termination and deprovisioning

Azion applies the conditions below to every model. The first two bound a model while it runs, and Azion publishes no value for either ceiling. The third states a number of days.

| Condition | Value | What happens past it |
| --- | --- | --- |
| Memory a model consumes | Not published | Azion may terminate a model that consumes more than the maximum defined memory. |
| Time a model runs | Not published | Azion may terminate a model that runs for longer than the maximum allowed time. |
| Time since creation without an execution | 3 days | Azion may deprovision a model that is created and not executed for more than three days. |

## Limits stated on other pages

The values that bound a model call belong to the model, to the request schema, or to the Function that makes the call. Each one is stated on the page that owns it. To size a prompt, read the context length on the page of the model you call.

| Limit | What it bounds | Where it is stated |
| --- | --- | --- |
| Context length | The context a model accepts, in tokens. Each model page states its own value. | [AI models](/en/documentation/platform/ai-inference/models/) |
| Request field bounds | The values `temperature`, `top_p`, `n`, `max_tokens`, `presence_penalty`, and `frequency_penalty` accept. | [Model invocation](/en/documentation/platform/ai-inference/model-invocation/) |
| Function limits | The code size, memory, execution time, and outbound requests of the Function that calls the model. | [Functions limits](/en/documentation/platform/functions/limits/) |

The time a Function waits inside `Azion.AI.run` does not count against the 2-second CPU limit of the Function. For example, a generation of 2048 tokens that takes about 20 seconds completes without the Function being terminated. The 5-minute execution time of a Function is wall-clock time and includes async operations, so the wait counts there.
