[AI Inference](/en/documentation/platform/ai-inference/) runs the models on this page. You select a model by its id, a string the model answers to, rather than by the name it is listed under. Each row of the catalog carries that id next to the capabilities of the model. For the request body the id travels in, refer to [Model invocation](/en/documentation/platform/ai-inference/model-invocation/).

## Model catalog

Each row is one model, and the model name links the model page, which carries a request example. The Category column takes one of four values:

- **LLM**: a large language model, which reads text and returns text.
- **VLM**: a vision language model, which reads text and images and returns text.
- **Embedding**: a model that returns a vector that represents the input text.
- **Reranker**: a model that scores a set of documents against a query.

A dash means the model page states no value for that capability.

## Model ids

A model id is the string that selects the model: the first argument to `Azion.AI.run` inside a [Function](/en/documentation/platform/functions/), and the `model` field of a request body sent to the HTTP endpoint of the [AI Inference Starter Kit](/en/documentation/guides/application-development/frameworks/ai-inference-starter-kit/). A model can answer to two forms of its id: a repository form, such as `Qwen/Qwen2.5-VL-3B-Instruct-AWQ`, and a lowercase form with hyphens, such as `qwen-qwen25-vl-3b-instruct-awq`. Both forms select the same model. The lowercase form does not follow from the repository form by a simple rule, so copy an id from the table character for character rather than deriving it from the model name.

To list the ids your account can call, in both forms, call `Azion.AI.models()` from a Function. It returns a promise that resolves to an array of id strings:

```ts
const modelIds = await Azion.AI.models()
```

The `model` field of a response carries the account's internal id for the model, which can differ from the id the request sent. A request to `Qwen/Qwen3-30B-A3B-Instruct-2507-FP8` returns `qwen-qwen3-30b-a3b-instruct-2507-fp8`, and GPT-OSS 20B returns `gpt-oss-20b`, an id that `Azion.AI.run` refuses as input. Do not reuse the `model` field of a response as an id.
