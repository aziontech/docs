You check an installed Marketplace integration for a newer version, install that version, and move a function instance to it, from Azion Console. To install an integration for the first time, refer to [Install an integration](/en/documentation/guides/application-development/integrations/install-an-integration/).

Integrations change over time: Azion and its partners publish new versions as they add features. Installing a new version does not change the version your instances run. An instance keeps its version until you select the new one in its settings.

---

## Prerequisites

- An Azion account. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- An integration installed from Azion Marketplace.
- For the last section, an application or a firewall with a function instance of that integration.

---

## Check for a newer version

The integration's page in Marketplace shows whether your account runs its latest version. To check it:

<DocSteps>
  <DocStep title="Open Marketplace">

  Access [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Open the integration's page">

  Enter the integration's name in the **Search on Marketplace** field, then select its card.

  </DocStep>
  <DocStep title="Read the version state">

  The **Version** field shows the version Marketplace offers. When your installed version is older, the **Get New Version** button is enabled. When it is current, the page shows `Latest version installed!`.

  </DocStep>
</DocSteps>

You know whether a newer version exists. The **Application** list of the **Install an Integration** drawer can also tag an application with `Update Available`.

---

## Install the new version

The new version installs beside the one your instances run, so nothing changes in traffic until you move an instance. To install it:

<DocSteps>
  <DocStep title="Open the integration's page">

  Access [Azion Console](https://console.azion.com/) > **Marketplace**, then select the integration's card.

  </DocStep>
  <DocStep title="Select Get New Version">

  The Console warns: `Updating will create a new instance of the integration's function.`

  </DocStep>
</DocSteps>

The integration's page shows `Latest version installed!`. Your existing instances still run the previous version.

---

## Move an instance to the new version

Test the new version before production traffic reaches it. Move an instance on a test application first, then move the production instance after the new version passes your validation. To move one instance:

<DocSteps>
  <DocStep title="Open the resource that holds the instance">

  Access [Azion Console](https://console.azion.com/) > **Applications** or **Firewalls**, then select the application or the firewall.

  </DocStep>
  <DocStep title="Open the Functions Instances tab" />
  <DocStep title="Select the instance" />
  <DocStep title="Select the new version">

  In **Function**, select the new version of the integration.

  </DocStep>
  <DocStep title="Check the arguments">

  In **Arguments**, confirm the JSON still holds your values.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The instance runs the new version. The rules that run the instance need no change, because they point to the instance and not to the function version.
