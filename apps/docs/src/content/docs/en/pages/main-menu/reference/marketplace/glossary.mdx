This glossary defines the terms that the [Azion Marketplace](/en/documentation/platform/marketplace/) documentation uses for integrations, templates, licenses, and selling, with their Azion Console labels.

| Term | Definition |
| --- | --- |
| arguments (Args) | The values that an integration's code reads, which you customize while the code itself stays fixed. A function instance holds them as JSON in its **Arguments** field, which Azion Console fills with the integration's defaults, and the code reads each one with `EVENT.ARGS('ARG_NAME')`. Because the arguments live on the instance, two resources can run one integration with different values, as [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/#integrations) describes. |
| Bring Your Own License (BYOL) | The license under which you run an integration with a license or credentials you already hold from the integration's provider, offered on the integration's page as **Bring Your Own License**. You provide valid credentials that authenticate your account and connect Azion with the provider, and Azion charges for the Azion services your use generates. [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/#licenses) compares the licenses, and [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#business-models) gives the seller's side. |
| Buy to Subscribe | The license option on an integration's page that leads to a contact with the Azion Sales Team instead of an install. You obtain the integration through the subscription you agree with Azion Sales, as [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/#licenses) describes. |
| buyer | An Azion Marketplace customer who uses Marketplace to install and deploy the software it lists. Anyone with an Azion account can act as a buyer and can then apply to become a seller, as [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#roles) describes. |
| Free License | The license of an integration that you obtain with the **Install** button alone, shown on its page with "Install this integration using the available free model." You pay only when you use the integration, subject to its terms of use, and sellers call this business model _Free_. [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/#licenses) compares it with the other licenses. |
| function instance | The object that runs an installed integration on an [application](/en/documentation/platform/applications/functions-instances/) or a [firewall](/en/documentation/platform/firewall/functions-instances/) with its own arguments, listed in the resource's **Functions Instances** tab. After a direct install, you create it in the **Create Instance** drawer by selecting the integration in the **Function** list, while the **Install an Integration** drawer creates it on the application you select. A Rules Engine rule with the **Run Function** behavior calls it, as [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/#integrations) describes. |
| integration | A Marketplace listing that is a function: code that you cannot modify, plus arguments that you customize. Depending on the integration, **Install** either adds the function to your account, after which you create a function instance and a rule, or opens the **Install an Integration** drawer, which instantiates it on the application you select. Each integration runs on an application or a firewall, as [Marketplace integrations](/en/documentation/platform/marketplace/integrations/#where-an-integration-runs) lists. |
| ISV | An Independent Software Vendor, a third party that publishes products on Azion Marketplace as a seller. A seller can also be an individual software developer or an open-source community, and [Become a Marketplace seller](/en/documentation/platform/marketplace/isv-signup/#apply-as-an-isv) describes the application. |
| metering record | A usage measure from which the Azion Marketplace Metering Service bills a Pay As You Go product: deployed instances, registered users, requests, compute time, or data transfer. The seller's software reports each buyer's usage every hour, and Azion cannot bill usage whose record fails to transmit or arrive, as [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#pay-as-you-go) describes. |
| Pay As You Go (PAYG) | The pricing model in which Azion Marketplace bills buyers monthly from the metering records of their usage and the price the seller sets, with no commitment. A PAYG product can offer a free trial, after which Azion Marketplace enrolls the buyer in PAYG unless the buyer cancels or opts out. [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#pay-as-you-go) describes the model. |
| private offer | An offer that a seller makes to one buyer, with special pricing and its own end-user license agreement (EULA), instead of the standard price list. A buyer can also start a private offer to negotiate pricing and usage, and the negotiated terms start when the buyer accepts the deal, as [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#pricing-models) describes. |
| Saving Plan | The pricing model in which a buyer agrees with the seller on a quantity of usage, such as requests for a 1-month, 1-year, 2-year, or 3-year period. Azion Marketplace bills it upfront or on the seller's payment schedule, and bills usage above the plan at the seller's Pay As You Go price, as [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#saving-plans) describes. |
| seller | An Azion Marketplace customer who provides ready-to-use software and uses Marketplace as a distribution channel: an ISV, an individual software developer, or an open-source community. Azion reviews the seller and each product before publishing, and [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#eligibility) lists the requirements. |
| template | A Marketplace listing that is a preconfigured project, which you deploy from Azion Console instead of installing. A deployment creates an application, an Azion domain, the configuration the use case needs, a function in some templates, and a GitHub repository with the template's files, as [Marketplace templates](/en/documentation/platform/marketplace/templates/#what-a-deployment-creates) describes. [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/#templates) compares templates with integrations. |
| tiered listing fee (TLF) | The listing fee that Azion Marketplace charges a seller on each transaction of a product, as a percentage tiered by the transaction's dollar value. The tiers run from 13% to 6% for SaaS products, depending on value and subscription year, and from 20% to 13% for Azion Web Platform-based products. A lower fee from a higher value applies month by month, never retroactively, as [Seller requirements and fees](/en/documentation/platform/marketplace/marketplace-seller-guide/#tiered-listing-fees) describes. |
