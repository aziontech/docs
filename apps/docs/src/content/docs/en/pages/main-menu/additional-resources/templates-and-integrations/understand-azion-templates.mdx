A Marketplace template is a preconfigured project that you deploy from Azion Console. Each deployment creates the application, domain, and configuration the project runs on, and a GitHub repository that holds its files. This page lists every template, what it deploys, the guide that walks through it, and the Console link that starts the deployment. For how a template fits into the Marketplace, refer to [How Marketplace works](/en/documentation/platform/marketplace/how-it-works/).

---

## What a deployment creates

Deploying a Marketplace template creates these resources in your account:

- **An application** that holds every setting of the template.
- **An Azion domain** that gives access to the application. You can also [add a custom domain](/en/documentation/guides/platform/migration/configure-a-domain/) to the application.
- **The configuration the use case needs**, set by the template.
- **A function**, in some templates, with its arguments and the dependencies it requires.
- **A GitHub repository** with the template's files, including the function and a GitHub Action. Activate the action to deploy each change continuously and keep a trackable deployment history.

After the deployment, you can change any of these settings in Azion Console. The source of every template is in the [azion-samples repository](https://github.com/aziontech/azion-samples/tree/dev/templates). Some templates based on frameworks can also start from the Azion CLI. For more information, refer to [CLI quickstart](/en/documentation/devtools/cli/quickstart/).

:::caution
Some templates need Azion products that you activate separately in Azion Console. When these products are active, the template can generate usage costs. Check the template's guide and [Pricing](/en/documentation/fundamentals/pricing/) before you deploy.
:::

Some templates integrate with a third-party service. These templates require an account with that service and its initial setup, and the service can charge for usage.
