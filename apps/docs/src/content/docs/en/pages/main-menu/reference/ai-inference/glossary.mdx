Definitions for the terms the **AI Inference** documentation uses.

| Term | Definition |
| --- | --- |
| AI Inference | A Platform Resource that runs open-source AI models on Azion's distributed infrastructure, in response to the calls your Functions send. A [Function](/en/documentation/platform/functions/) calls a model with `Azion.AI.run`, so you provision no infrastructure to run one. [AI Inference](/en/documentation/platform/ai-inference/) describes the request path and the scope. |
| AI Inference Starter Kit | A template in Azion Console that deploys an Application serving an OpenAI-compatible API, with the Function that calls the model. The [AI Inference Starter Kit](/en/documentation/guides/application-development/frameworks/ai-inference-starter-kit/) also creates the Workload and its deployment, and the API answers on the workload domain. |
| Azion Runtime | The JavaScript runtime of [Functions](/en/documentation/platform/functions/), which runs the handler of a Function on Azion's distributed infrastructure. `Azion.AI.run` is one of its Azion APIs, so the Function that calls a model runs on [Azion Runtime](/en/documentation/devtools/runtime/). |
| `Azion.AI.run` | The runtime binding a Function calls to run a model. It takes the model id and a request body, and no credential, and it resolves to the response object, such as a `chat.completion` for a chat model, or to an iterator of chunks when `stream` is `true`. [Model invocation](/en/documentation/platform/ai-inference/model-invocation/) documents every field. |
| Compute Time | The usage meter of AI Inference and LoRA Fine-Tune: the duration of active execution in hours multiplied by the memory allocated in gigabytes, stated in GB-hour. The [pricing page](/en/documentation/fundamentals/pricing/#ai-inference) carries the rate. |
| LoRA Fine-Tune | A Platform Resource that extends [AI Inference](/en/documentation/platform/ai-inference/) with the fine-tuning of supported models through Low-Rank Adaptation, on Azion's infrastructure. The [model pages](/en/documentation/platform/ai-inference/models/) state which models support it, and [LoRA Fine-Tune](/en/documentation/platform/ai-inference/lora-fine-tune/) describes it. |
| model id | The string that selects a model: the first argument of `Azion.AI.run`, or the `model` field of an HTTP request body. Two forms select the same model, a repository path such as `Qwen/Qwen3-Embedding-4B` and a lowercase form such as `qwen-qwen3-embedding-4b`. Each [model page](/en/documentation/platform/ai-inference/models/) states an id to use, and `Azion.AI.models()` returns the ids your account can call. |
| OpenAI-compatible API | The HTTP endpoint that an Application deployed from the [AI Inference Starter Kit](/en/documentation/guides/application-development/frameworks/ai-inference-starter-kit/) serves on its domain. It takes a request body in the OpenAI chat completions format, with the model id in `model`, and passes it to `Azion.AI.run`. [Model invocation](/en/documentation/platform/ai-inference/model-invocation/) documents the body and the response. |
| workload domain | The read-only hostname Azion assigns a [Workload](/en/documentation/platform/workloads/) at creation, in the form `<id>.map.azionedge.net` on production infrastructure. An Application deployed from the AI Inference Starter Kit serves its OpenAI-compatible API on this domain. The [Workloads glossary](/en/documentation/platform/workloads/glossary/) defines it in full. |
