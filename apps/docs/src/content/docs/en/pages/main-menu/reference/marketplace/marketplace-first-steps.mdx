This guide instructs you through installing your first [Marketplace](/en/documentation/platform/marketplace/) integration on an application. By the end you will have:

- The [Hello World](/en/documentation/guides/application-development/integrations/hello-world/) integration installed on one of your applications.
- A browser page that shows the Hello World message.

Two objects take part. The **integration** comes from Marketplace and carries a function and its arguments. The **application** runs it: when you install Hello World, the install drawer instantiates the integration on the application you select. Hello World takes two arguments, `Status` and `Body`, and you set them in the same drawer.

---

## Prerequisites

- An Azion account. To create one, refer to [Create an Azion account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- An [application](/en/documentation/platform/applications/) served by a [workload](/en/documentation/platform/workloads/). The install drawer lists your applications. To create one, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

---

## Install Hello World

Hello World is not one of the **Featured** cards, so find it with the search field. To start the install from Azion Console:

<DocSteps>
  <DocStep title="Open Marketplace">

  In [Azion Console](https://console.azion.com/), open the **Products menu** and select **Marketplace**.

  </DocStep>
  <DocStep title="Search for the integration">

  In the **Search on Marketplace** field, enter `Hello World`. The card reads `Use the Hello World integration to start creating new resources at the edge.`

  </DocStep>
  <DocStep title="Open the integration's page">

  Select the **Hello World** card.

  </DocStep>
  <DocStep title="Select Install" />
</DocSteps>

The **Install an Integration** drawer opens.

To find other integrations, enter a name or a keyword in **Search on Marketplace**, or filter the cards by **Categories**.

---

## Configure and deploy

The drawer installs Hello World on one application, with the arguments you set. To complete the install:

<DocSteps>
  <DocStep title="Select the application">

  In the **Select an Application** section, open the **Application** list and select the application that runs Hello World.

  If the list is empty, select **Create New**, create an application, and then start the install again from the Hello World page.

  </DocStep>
  <DocStep title="Set the arguments">

  In the **General** section, set the two arguments of Hello World:

  - `Status`: the HTTP status code of the response. The default is `200`, a successful request.
  - `Body`: the text the page shows. It takes any string. The default is `Hello World!`.

  </DocStep>
  <DocStep title="Review the permissions">

  The permissions block lists the privileges Marketplace requires on the selected application. For Hello World, it reads and writes the selected application, and it deletes the functions to instantiate the new integration in the selected application. For every privilege, refer to [Marketplace permissions](/en/documentation/platform/marketplace/permissions-marketplace/).

  </DocStep>
  <DocStep title="Select Deploy" />
</DocSteps>

A message confirms that the integration was successfully installed. Hello World runs on the application you selected.

---

## See the result

Open the domain of your application in a browser. The page shows the `Body` text: `Hello World!` with the default arguments.
