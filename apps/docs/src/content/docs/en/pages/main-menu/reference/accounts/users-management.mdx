**Users Management** on Azion Web Platform is where you add, modify, and delete users, which gives you control over who has access to your Azion account and its associated resources.

To add users to the account, you need to have *Account Owner* privileges or have the permissions to **View Users** and **Edit Users**.

With **Users Management**, you can:

- Add new users to your Azion account.
- Allocate them in existing teams.
- Assign roles and permissions to users, distinguishing between Account Owners and non-owners.
- Strengthen account security by enabling Multi-Factor Authentication (MFA) for users.
- Remove users from your account.

---

## Profile

In this section, you are able to fill in the new user's personal information.

| Field | Description |
| --- | --- |
| **First name** | New user first name. |
| **Last name** | New user last name. |
| **Timezone** | The timezone where the new user is located. Choosing the correct timezone guarantees precision when accessing data and metrics on Azion Web Platform. |
| **Language** | English is the only language available on Azion Web Platform. |

---

## Contact information

In this section, you are able to provide the new user's contact information.

| Field | Description |
| --- | --- |
| **Email** | New user email address. The user will apply the provided email address as a login credential. |
| **Phone Number** | New user phone number, including the country and region code. |

---

## Security settings

Here, you are able to set security measures to the new user's account.

| Field | Description |
| --- | --- |
| **Account owner** | When enabled, the new user is set as an Account owner, allowed access to all configurations, including the management of solutions and all accounts. When disabled, the user is set as a non-owner, with restricted access according to the permission settings defined in Teams. |
| **Teams** | Teams have different access permissions. You must select a team to allocate non-owners, unlike account owners, who have permission to access all teams. You can also allocate non-owners to more than one team, which expands the permission possibilities for the same user. |
| **Enforce Multi-Factor Authentication** | Turns on multi-factor authentication (MFA) for the user, who then signs in with a code from an authenticator application. While **Enforce Multi-Factor Authentication** is on in **Account Settings**, this field is read-only. |

:::note
Non-owner access permissions depend on the permissions granted to the team they are allocated to. For more details, refer to [Teams permissions](/en/documentation/fundamentals/teams-permissions/).
:::

## Status

| Field | Description |
| --- | --- |
