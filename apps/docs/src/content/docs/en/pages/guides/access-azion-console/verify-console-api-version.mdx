During the [Transition to API v4](/en/documentation/fundamentals/api-v4-migration/) you might see some pages with different versions for v3 and v4. This guide helps you verify if your account has already been migrated to v4.

1. Access [Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
2. Open the **Products menu**.

If you see options such as **Workloads**, **Connectors** or **Custom Pages** your account has been migrated to v4 and you can use those products.
