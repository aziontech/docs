You can deploy a Videoteca player application to Azion from the Static Cache + Videoteca Player template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

The template caches static and dynamic content by file extension. It also serves the Videoteca player, from Videofront, through an iframe.

The deployment creates a GitHub repository for your project, an [application](/en/documentation/platform/applications/) that serves it, and a domain to reach it. The application carries several cache settings and a preconfigured route that runs the Videoteca Player function. It uses [Application Accelerator](/en/documentation/platform/applications/application-accelerator/), [Functions](/en/documentation/platform/functions/), [Image Processor](/en/documentation/platform/applications/image-processor/), and [Cache](/en/documentation/platform/applications/cache/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A [GitHub account](https://github.com/signup). Azion connects to it and creates the project's repository there.
- The Videoteca Player integration, installed and configured. To install it, refer to [Install the Videoteca Player integration](/en/documentation/guides/media-and-streaming/streaming/videofront-player/).
- A Videoteca account. The configuration form asks for its username and API token.

## Deploy the template

The Static Cache + Videoteca Player template opens as a configuration form in Azion Console, and an asterisk marks each mandatory field. After the application name, the form holds the fields of the Videoteca Player integration.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [Static Cache + Videoteca Player](https://console.azion.com/create/videofront/static-cache-videoteca-player) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Name the application">

  Enter a unique name for the application. The storage bucket and the function that the template creates take the same name. If the name is already in use, the platform returns an error message.

  </DocStep>
  <DocStep title="Enter the origin address">

  In **Origin Address**, enter the domain name or the IP address of the origin.

  </DocStep>
  <DocStep title="(Optional) Set the custom host header">

  In **Custom Host Header**, enter the value of the `host` header that the application sends to the origin. If you leave the field blank, it takes the origin address. For more information, refer to [Host Header](/en/documentation/platform/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="Enter the player path">

  In **Videoteca Player Path**, enter the path that serves the player. For example: `/player`.

  </DocStep>
  <DocStep title="Enter your Videoteca username">

  In **Videoteca Username**, enter the username of your Videoteca account.

  </DocStep>
  <DocStep title="Enter your Videoteca API token">

  In **Videoteca API Token**, enter the API token of your Videoteca account. You find the token at `https://<YOUR-USER>.videotecaead.com.br/Apidoc`, where `<YOUR-USER>` is your Videoteca username.

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

## Update the project

Every push to the GitHub repository that the Static Cache + Videoteca Player template creates deploys automatically.

To update the deployed project, push your changes to that repository. Azion deploys them, and the application serves the new version.

---

## Manage the application

The settings that the Static Cache + Videoteca Player template applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by **Application Name** only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure, including the cache settings and the route that the template configured. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/). To change how long the application keeps the static files in cache, refer to [Create a cache setting](/en/documentation/guides/application-performance/cache-and-purge/tune-cache-settings/).

## Add a custom domain

The Static Cache + Videoteca Player deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. For more information, refer to [Domains](/en/documentation/platform/workloads/domains/) and [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/).
