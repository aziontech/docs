You can deploy an application that caches static files to Azion from the Static Cache template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

The template caches static files, such as JavaScript and CSS, by their file extension. It applies its rules through [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and the rules cover the **GET**, **HEAD**, and **OPTIONS** methods. They respect the cache settings that the origin sends, or apply a default TTL instead.

You point the template at your own origin. The deployment creates an [application](/en/documentation/platform/applications/) for it, and every setting of that application stays editable. The application uses [Application Accelerator](/en/documentation/platform/applications/application-accelerator/) and [Functions](/en/documentation/platform/functions/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- An origin that holds your static files. The configuration form asks for its address.

---

## Deploy the template

The Static Cache template opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [Static Cache](https://console.azion.com/create/azion/static-cache) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Name the application">

  In **Application Name**, enter a unique name for the application on Azion. If the name is already in use, the platform returns an error message.

  </DocStep>
  <DocStep title="Enter the origin address">

  In **Origin Address**, enter the address of the origin that the application fetches content from. For example: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Optional) Add a custom host header">

  In **Custom Host Header**, enter the host information to add to the request that retrieves content from the origin. For example: `${host}`. For more information, refer to [Host Header](/en/documentation/platform/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="List the static file extensions to cache">

  In **Static files extensions to cache**, enter the file extensions that the static rules cover, separated by commas. You can add as many as you need. For example: `aif,aiff,au,avi,bin,cab,carb,cct,cdf,class,doc`.

  </DocStep>
  <DocStep title="Set the maximum cache TTL">

  In **CDN Static Maximum TTL**, enter the maximum time, in seconds, that the application delivers cached content. The field accepts values from `0` to `31536000`, and the default is `1296000`.

  </DocStep>
  <DocStep title="Set the maximum browser TTL">

  In **Browser Static Maximum TTL**, enter the maximum time, in seconds, that content stays cached in the browser. The field accepts values from `0` to `31536000`, and the default is `0`.

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

## Manage the application

The settings that the Static Cache template applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by **Application Name** only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. The **Cache Settings** and **Rules Engine** tabs hold what the template configured. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/). To change how long the application keeps the static files in cache, refer to [Create a cache setting](/en/documentation/guides/application-performance/cache-and-purge/tune-cache-settings/).
