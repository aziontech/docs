You can add [Bot Manager Lite](/en/documentation/platform/firewall/bot-manager/bot-manager-lite/) to a [Firewall](/en/documentation/platform/firewall/) you already run from the Bot Manager Lite Integration Kit template, in Azion Console. The template creates no Firewall, so it asks for the ID of yours. To create the Function Instance and the rule yourself, refer to [Bot Manager quickstart](/en/documentation/platform/firewall/bot-manager/quickstart/).

---

## Prerequisites

- A Firewall in your account, and its ID.
- **Functions** turned on for that Firewall. A Firewall created on the **Create Firewall** page, with the Azion CLI, or with the API starts with **Functions** turned on. To turn it on, refer to [Turn WAF, Network Shield, or Functions on or off](/en/documentation/guides/application-security/firewall-and-waf/firewall-configure-main-settings/#turn-waf-network-shield-or-functions-on-or-off).
- Bot Manager Lite installed from Marketplace. For more information, refer to [Install Bot Manager Lite](/en/documentation/guides/application-development/integrations/bot-manager-lite/).
- Access to Azion Console. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- The Function Instance runs on [Functions](/en/documentation/platform/functions/), which can generate usage costs. For the metrics Bot Manager is billed on, refer to [Pricing](/en/documentation/fundamentals/pricing/#bot-manager).

The template checks the first three requirements before it creates anything. When one of them is not met, the deployment fails and writes a log line that names the reason.

## Deploy the template

To deploy the template in Azion Console:

<DocSteps>
  <DocStep title="Copy the Firewall ID">

  Access [Azion Console](https://console.azion.com/) > **Firewalls**, select the Firewall, and copy the ID from the address. The address ends in `/firewalls/edit/<firewall-id>`.

  </DocStep>
  <DocStep title="Open the template">

  Go to the [Bot Manager Lite Integration Kit](https://console.azion.com/create/azion/bot--manager-integration-kit) template.

  </DocStep>
  <DocStep title="Enter the Firewall ID">

  In **Firewall ID**, enter the ID you copied.

  </DocStep>
  <DocStep title="Select Deploy" />
</DocSteps>

When the deployment finishes, the **Functions Instances** tab of the Firewall lists the new Bot Manager Lite Function Instance, and its **Rules Engine** tab lists the rule that runs it. The Function Instance carries three arguments:

```json
{
  "threshold": 10,
  "action": "allow",
  "internal_logs": 2
}
```

A `threshold` of `10` is lower than the `30` that Bot Manager Lite ships, so the Function Instance applies `action` to more requests than the shipped default does. An `action` of `allow` refuses no request. An `internal_logs` of `2` writes one report log line for every request, whatever its score.

To change the arguments, open the Function Instance and edit its **Arguments** section. For the values each argument takes, refer to [Arguments](/en/documentation/platform/firewall/bot-manager/arguments/).

:::caution
The API checks that the arguments are a JSON object or array, and it checks no key. A misspelled argument such as `thresold` is stored as typed, the API and the Azion CLI raise no error, and `threshold` stays absent from the Function Instance. To see what the Function does without it, refer to [Threshold](/en/documentation/platform/firewall/bot-manager/arguments/#threshold).
:::

## Read what the Function Instance scored

With `internal_logs` set to `2`, the Function Instance writes one report log line for every request it scores, including a request that scored `0`. To read the lines in Azion Console:

<DocSteps>
  <DocStep title="Open Real-Time Events">

  Access [Azion Console](https://console.azion.com/) > **Real-Time Events**, then select the **Functions Console** tab.

  </DocStep>
  <DocStep title="Read the report lines">

  Narrow the period to the requests you want to read. Each report line opens with `[Bot-Protection]` in the **Log Body** column and carries the score of one request.

  </DocStep>
</DocSteps>

An `action` of `allow` refuses nothing while you read the scores. Set `threshold` and `action` from the scores your own traffic produces, rather than from the template values. For the fields a line carries, refer to [Logs](/en/documentation/platform/firewall/bot-manager/logs/). To forward the lines to a destination you own, refer to [Data Stream](/en/documentation/platform/data-stream/).
