You copy the [Edge Pulse](/en/documentation/platform/edge-pulse/) JavaScript tag from Azion Console and add it to the pages you want to measure. To read the measurements the tag collects, refer to [Query Edge Pulse measurements with GraphQL](/en/documentation/guides/platform/observability/query-edge-pulse-measurements-with-graphql/).

Edge Pulse is activated for every Azion account, so there is nothing to create in Azion Console. The only object you change is the HTML of your pages.

---

## Prerequisites

- Access to Azion Console. Refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- Access to edit and publish the HTML of the pages you measure, or to the tag management system that publishes scripts on them.

---

## Copy the tag your pages need

The tag comes in two forms, and the pages decide which one you take. The **Default Tag** runs after the loading event completes, so it does not interrupt that event. The **Pre-loading Tag** runs before the load event fires. Take it when the pages carry Content Security Policy settings that prevent inline JavaScript. The tag is customized for your account, so copy it from your own Console.

To copy the tag:

<DocSteps>
  <DocStep title="Open Edge Pulse">

  Access [Azion Console](https://console.azion.com/) > **Products menu** > **Observe** > **Edge Pulse**.

  </DocStep>
  <DocStep title="Select the tag your pages need">

  Select the **Default Tag**, or the **Pre-loading Tag** when the pages prevent inline JavaScript.

  </DocStep>
  <DocStep title="Select Copy to Clipboard" />
</DocSteps>

The tag is on your clipboard, ready to paste into a page.

---

## Add the tag to the pages you measure

Edge Pulse measures a page only when that page carries the tag. The tag is not inherited from a parent path, from another page of the site, or from a template you did not republish. Both tags go in the same place, before the closing `body` tag.

To add the tag:

<DocSteps>
  <DocStep title="Paste the tag into the page">

  In the HTML of the page, or of the template that renders it, paste the tag immediately before the closing `body` tag.

  </DocStep>
  <DocStep title="Repeat for every page you measure">

  Paste the same tag page by page, or distribute it across the pages with a tag management system.

  </DocStep>
  <DocStep title="Publish the pages" />
  <DocStep title="Check the published page">

  Open a published page, such as `https://www.example.com/`, in a browser and view the page source. The tag you copied sits before the closing `body` tag.

  </DocStep>
</DocSteps>

Each published page carries the tag, and the browsers of its visitors run it. Nothing is collected until a visitor loads a tagged page, so the first measurements follow your traffic rather than the moment you published.

In the [Monitor website and API performance](/en/documentation/use-cases/improve-performance-and-reliability/monitor-website-and-api-performance/) use case, this section takes these values:

| Setting | Value |
| --- | --- |
| **Tag** | the **Default Tag**, or the **Pre-loading Tag** when the pages block inline JavaScript |
| **Pages** | `/` and `/search`. Paste the tag in the template that renders each page, so every page built from that template carries it |

Every visit to `/` and `/search` now produces a measurement.

In the [Monitor website and API performance](/en/documentation/use-cases/improve-performance-and-reliability/monitor-website-and-api-performance/) use case, expect:

- **The pages carry the tag.** The page source of `https://www.example.com/` and of `/search` holds the Edge Pulse tag you copied, before the closing `body` tag.
