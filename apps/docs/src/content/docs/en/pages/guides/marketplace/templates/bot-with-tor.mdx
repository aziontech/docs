You can create a [Firewall](/en/documentation/platform/firewall/) that scores requests with [Bot Manager Lite](/en/documentation/platform/firewall/bot-manager/bot-manager-lite/) and denies Tor exit-node addresses from the Bot Manager Lite and TOR Block Starter Kit template, in Azion Console. To add Bot Manager Lite to a Firewall you already run, refer to [Add Bot Manager Lite to a Firewall](/en/documentation/guides/application-development/integrations/bot-manager-lite-integration-kit/). To create the Function Instance and the rule yourself, refer to [Bot Manager quickstart](/en/documentation/platform/firewall/bot-manager/quickstart/).

---

## Prerequisites

- Bot Manager Lite installed from Marketplace. For more information, refer to [Install Bot Manager Lite](/en/documentation/guides/application-development/integrations/bot-manager-lite/).
- Access to Azion Console. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- Optionally, the IDs of the Workloads whose requests the Firewall inspects. Without them, the template creates the Firewall and no deployment sets it.
- The Function Instance runs on [Functions](/en/documentation/platform/functions/), and the deny rule uses [Network Shield](/en/documentation/platform/firewall/network-shield/). Both can generate usage costs. For the metrics Bot Manager is billed on, refer to [Pricing](/en/documentation/fundamentals/pricing/#bot-manager).

The template checks that Bot Manager Lite is installed before it creates anything. When it is not, the deployment fails and writes a log line that names the reason.

## Deploy the template

To deploy the template in Azion Console:

<DocSteps>
  <DocStep title="(Optional) Copy the Workload IDs">

  Access [Azion Console](https://console.azion.com/) > **Workloads**, select a Workload whose requests the Firewall inspects, and copy its ID from the address. The address ends in `/workloads/edit/<workload-id>`.

  </DocStep>
  <DocStep title="Open the template">

  Go to the [Bot Manager Lite and TOR Block Starter Kit](https://console.azion.com/create/azion/bot--manager-and-tor-block-starter-kit) template.

  </DocStep>
  <DocStep title="Enter the Workload IDs">

  In **Domain ID(s)**, enter the IDs you copied. The field is optional. Left empty, the template creates the Firewall and no deployment sets it. To set it on a Workload afterwards, refer to [Set a Firewall on a Workload](/en/documentation/guides/application-security/firewall-and-waf/firewall-protect-your-domain/).

  </DocStep>
  <DocStep title="Select Deploy" />
</DocSteps>

When the deployment finishes, the account carries a new Firewall with **Functions** and **Network Shield** turned on. Its **Functions Instances** tab lists one Bot Manager Lite Function Instance. Its **Rules Engine** tab lists the rules that run the Function Instance, check that the Workloads you entered are valid, and deny a request whose address is in the `Azion IP Tor Exit Nodes` [Network List](/en/documentation/platform/firewall/network-shield/network-lists/).

The Function Instance carries three arguments:

```json
{
  "threshold": 10,
  "action": "allow",
  "internal_logs": 2
}
```

A `threshold` of `10` is lower than the `30` that Bot Manager Lite ships, so the Function Instance applies `action` to requests the shipped default lets through. An `action` of `allow` refuses no request, so the rule that uses the Network List is what denies a Tor address. An `internal_logs` of `2` writes one report log line for every request, whatever its score. For the values each argument takes, refer to [Arguments](/en/documentation/platform/firewall/bot-manager/arguments/).

## Score Tor exit-node addresses

`Azion IP Tor Exit Nodes` is the Network List with ID `2`, maintained by Azion. Bot Manager Lite rule `14` adds 6 points for each list in `reputation_network_lists` that holds the client address. The template does not set `reputation_network_lists`, so the Function Instance scores a Tor address like any other address.

To add the Tor list to the arguments in Azion Console:

<DocSteps>
  <DocStep title="Open the Function Instance">

  Access [Azion Console](https://console.azion.com/) > **Firewalls**, select the Firewall the template created, then select the **Functions Instances** tab and the Bot Manager Lite Function Instance.

  </DocStep>
  <DocStep title="Add the list to the arguments">

  In the **Arguments** section, add `reputation_network_lists` with the ID `2`:

  ```json
  {
    "threshold": 10,
    "action": "allow",
    "internal_logs": 2,
    "reputation_network_lists": [2]
  }
  ```

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

Once the change propagates, a request from a Tor exit node scores 6 points more than the same request from another address. For the rule table behind that score, refer to [Bot Manager Lite](/en/documentation/platform/firewall/bot-manager/bot-manager-lite/#rules). For how long a change takes to reach requests, refer to [Propagation](/en/documentation/platform/firewall/how-it-works/#propagation).

:::caution
The API checks that the arguments are a JSON object or array, and it checks no key. A misspelled key such as `reputation_network_list` is stored as typed, the API and the Azion CLI raise no error, and the Function never reads it.
:::

## Read what the Function Instance scored

With `internal_logs` set to `2`, the Function Instance writes one report log line for every request it scores, including a request that scored `0`. To read the lines in Azion Console:

<DocSteps>
  <DocStep title="Open Real-Time Events">

  Access [Azion Console](https://console.azion.com/) > **Real-Time Events**, then select the **Functions Console** tab.

  </DocStep>
  <DocStep title="Read the report lines">

  Narrow the period to the requests you want to read. Each report line opens with `[Bot-Protection]` in the **Log Body** column and carries the score of one request.

  </DocStep>
</DocSteps>

The **Functions Console** tab shows what the Function Instance scored. An `action` of `allow` refuses nothing, so set `threshold` and `action` from the scores your own traffic produces, rather than from the template values. For the fields a line carries, refer to [Logs](/en/documentation/platform/firewall/bot-manager/logs/). To forward the lines to a destination you own, refer to [Data Stream](/en/documentation/platform/data-stream/).
