You can deploy an application for your WordPress website to Azion from the WordPress EdgeAccelerator template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

Azion designed the WordPress EdgeAccelerator template to improve the performance and security of a WordPress website. The template helps you migrate the website to run on Azion's distributed infrastructure.

The deployment creates an [application](/en/documentation/platform/applications/) and its domain, which you use to manage the project on Azion. It also defines key configurations that optimize the performance of your WordPress website. The deployment can generate usage-related costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A WordPress website on a hosted origin. The configuration form asks for the origin's address.

---

## Deploy the template

The WordPress EdgeAccelerator template opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [WordPress EdgeAccelerator](https://console.azion.com/create/wordpress/wordpress-edgeaccelerator) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Name the application">

  In **Application Name**, enter a unique name that you can remember. You use the name to identify and manage the application on Azion. If the name is already in use, the platform returns an error message.

  </DocStep>
  <DocStep title="Enter the origin address">

  In **Origin Address**, enter the address of your hosted origin. The application fetches the original content from it. For example: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Optional) Add host information to the origin request">

  Some origins need host information in the header of the request that retrieves their content. In **Custom host header**, enter that value. For example: `${host}`. For more information, refer to [Origins](/en/documentation/platform/connectors/origins/).

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue. The deployment leaves you with:

- An application on Azion that you manage the project with.
- A domain that a browser can open to reach the application.
- Common cache rules, image file cache rules, and static file cache rules.
- Bypass routes for the website.

These configurations optimize the performance of your WordPress website. To change them, refer to [Manage the application](#manage-the-application).

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

## Manage the application

The settings that the WordPress EdgeAccelerator template applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application for your WordPress website">

  To find it in a long list, search by its name. The search filters the list by **Application Name** only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/).

After the deployment, you keep full control over the design, content, and functionality of your website in the WordPress admin panel. For questions about WordPress, refer to the official channels of [WordPress](https://wordpress.com/).

---

## Add a custom domain

The WordPress EdgeAccelerator deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. For more information, refer to [Domains](/en/documentation/platform/workloads/domains/) and [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/).
