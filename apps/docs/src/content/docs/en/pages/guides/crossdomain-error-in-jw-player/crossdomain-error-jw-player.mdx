This page covers the crossdomain error that JW Player reports when it loads a live stream from Azion. For a cross-origin request that a browser blocks with a missing `Access-Control-Allow-Origin` header, refer to [Troubleshoot CORS policy errors](/en/documentation/guides/application-development/getting-started/cors-errors/).

---

## The player shows Cannot load M3U8 crossdomain access denied

A live stream does not start, and JW Player displays this message:

```text
Cannot load M3U8 crossdomain access denied
```

The cause is a missing registration: Azion Console has no record of the CNAME that the player requests.

Apply both remedies, in this order:

- **Register the domain**: add the hostname of the stream, the CNAME, to the workload that delivers it. For the procedure, refer to [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/).
- **Add the CNAME to your DNS**: create a `CNAME` record for the same hostname at your DNS provider. For the procedure, refer to [Point a domain to a workload](/en/documentation/guides/platform/migration/point-domain-to-azion/).

The player loads the M3U8 playlist, and the live stream starts.

If the message persists after both remedies, open a support ticket and include the URL that fails to load. To open one, refer to [How to open a Support Ticket](/en/documentation/support/open-tickets/).
