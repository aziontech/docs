You can deploy a basic stack of application and security settings to Azion from the Azion Starter Kit template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

Use the Azion Starter Kit to take your first steps on Azion Web Platform and to explore the platform and its features. The template includes:

- A new [application](/en/documentation/platform/applications/), with common caching rules for images and for dynamic and static files.
- [Image Processor](/en/documentation/platform/applications/image-processor/) features to manipulate and process images directly on Azion.
- A new [firewall](/en/documentation/platform/firewall/) with rules that execute a function instance for Bot Manager Lite and deny requests from the pre-built Azion IP Tor Exit Nodes network list.

The template uses [Application Accelerator](/en/documentation/platform/applications/application-accelerator/), [Functions](/en/documentation/platform/functions/), [Image Processor](/en/documentation/platform/applications/image-processor/), and [Network Shield](/en/documentation/platform/firewall/network-shield/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- Application Accelerator, Functions, Image Processor, and Network Shield enabled on your account.
- The latest version of the Bot Manager Lite integration, installed. To install it, go to [Azion Marketplace](https://console.azion.com/marketplace) and select **Install**. For more information, refer to [Install Bot Manager Lite](/en/documentation/guides/application-development/integrations/bot-manager-lite/).
- A hosted origin that holds your content. The configuration form asks for its address.

If you do not install the Bot Manager Lite function before you use this template, the deployment fails and prints a log that explains the reason.

## Deploy the template

The Azion Starter Kit opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [Azion Starter Kit](https://console.azion.com/create/azion/azion-starter) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Name the application">

  In **Application Name**, enter a unique name that you can remember. The name identifies the new application, its domain, and the firewall on Azion. If the name is already in use, the platform returns an error message.

  </DocStep>
  <DocStep title="Enter the origin address">

  In **Origin Address**, enter the address of the hosted origin. The application fetches the original content from it. For example: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Optional) Override the Host header">

  Some origins need a different value in the `Host` header of the request that retrieves their content. In **Custom Host Header**, enter that value. To pass the `Host` header of the visitor's request on to the origin, enter the `${host}` variable. For more information, refer to [Origins](/en/documentation/platform/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again. To change the settings that the deployment applies, refer to [Manage the application](#manage-the-application).

## Template rules and settings

The Azion Starter Kit sets up rules on the application and on the firewall that it creates.

### Application rules

The application includes a default rule with this criterion and behavior:

- **Criteria**: if `${uri}` *starts with* `/`.
- **Behavior**: then [Set Connector](/en/documentation/platform/applications/rules-engine/#set-connector) as `Default Origin`.

For image optimization and caching, the template covers the file extensions `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.gif`, and `.png`. For static content, it supports the common static file extensions.

The template respects the cache settings of the origin. When the origin sends none, it uses the Max Age of the cache setting. Its rules change the cache settings of static files by the file extension of the requested content, to improve delivery.

### Firewall rules

The firewall enhances security through the [Azion IP Tor Exit Nodes](/en/documentation/guides/application-security/bots-and-network/block-tor-networks/) network list and Azion [Bot Manager Lite](/en/documentation/guides/application-development/integrations/bot-manager-lite/).

The template creates the Bot Manager Lite function instance with the following JSON Args:

```json
{
  "threshold": 10,
  "action": "allow",
  "internal_logs": 2
}
```

Where:

- `threshold`: the maximum score the request can reach before the function takes an action. The template sets `10`. An instance that sets no threshold runs on the function's default, `30`.
- `action`: the action to be taken by the function whenever the request's score is greater than or equal to the defined threshold. Possible values: `allow`, `custom_html`, `deny`, `drop`, `hold_connection`, `random_delay`, and `redirect`. The template sets `allow`, so requests are scored and logged but not blocked. An instance that sets no action runs on the function's default, `deny`.
- `internal_logs`: every execution of the Bot Manager Lite writes report logs, no matter the score of the request.

For every argument and its default, refer to [Bot Manager arguments](/en/documentation/platform/firewall/bot-manager/arguments/).

Check the Bot Manager Lite logs in [Real-Time Events](/en/documentation/platform/real-time-events/). Analyze them to find out whether the function instance's JSON Args need any changes. You can also use Azion [Data Stream](/en/documentation/platform/data-stream/) as an observability tool. For more information, refer to [Monitor and calibrate Bot Manager](/en/documentation/guides/application-security/bots-and-network/monitor-and-calibrate-bot-manager/#read-the-report-log-in-real-time-events).

## Manage the application

The settings that the Azion Starter Kit applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by **Application Name** only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/).

## Add a custom domain

The Azion Starter Kit deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. To add one, refer to [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/). For more information, refer to [Domains](/en/documentation/platform/workloads/domains/).
