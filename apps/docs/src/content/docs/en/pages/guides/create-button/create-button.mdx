You can start an application, or create one resource at a time, from the **+ Create** button of Azion Console. To bring in a GitHub repository with every step shown, refer to [Import a project from GitHub](/en/documentation/guides/application-development/automation/import-an-existing-project-from-github/).

---

## Prerequisites

- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- For the **Import from GitHub** tab, a GitHub repository of your own.

---

## Pick a starting point

The **+ Create** button opens a modal with four tabs. On some accounts, only the **Resources** tab shows.

| Tab | Shows | Use it to |
| --- | --- | --- |
| **Recommended** | **Select a Template** | Browse a set of suggested options, templates among them. |
| **Templates** | **Select a Template** | Start from a pre-designed project with default settings, built on a widely used framework. For the catalog, refer to [Marketplace templates](/en/documentation/platform/marketplace/templates/). |
| **Resources** | **Select a Resource** | Create one application or one resource. For what to build with each, refer to [Guides](/en/documentation/guides/). |
| **Import from GitHub** | **Import from GitHub** | Build and deploy a new application on Azion from your own GitHub repository. |

---

## Start building

The procedure is the same for every tab; only the item you select changes.

To start building from the **+ Create** button:

<DocSteps>
  <DocStep title="Open the Create modal">

  Access [Azion Console](https://console.azion.com/) and select **+ Create**. The button is in the Console header and in the **Get Started** block of the homepage.

  </DocStep>
  <DocStep title="Select a tab">

  Select **Recommended**, **Templates**, **Resources**, or **Import from GitHub**.

  </DocStep>
  <DocStep title="Select the template, resource, or repository" />
  <DocStep title="Fill in the form">

  Enter the settings that the form of your selection asks for.

  </DocStep>
  <DocStep title="Save the configuration">

  Select **Save** or **Save and Build**.

  </DocStep>
</DocSteps>

Azion Console creates the application or the resource you configured.

## Resources you can create

The **Resources** tab lists these items, in this order. Some accounts do not show **Custom Page**.

| Resource | Creates |
| --- | --- |
| **Workloads** | A workload, which launches an application and secures it with digital certificates. |
| **Application** | An application that delivers your content. |
| **Variables** | Environment variables or secrets that configured functions use. |
| **Edge DNS** | A domain hosted on an authoritative DNS server. |
| **Firewall** | Security settings that protect applications against threats and attacks. |
| **Connectors** | A connector, which centralizes how your applications connect to machines and other applications. |
| **Custom Page** | A custom page, which displays a personalized error page for specific HTTP errors. |
| **Edge Nodes** | Infrastructure you manage with Orchestrator, where you install services and resources. |
| **Data Stream** | A stream that feeds the event logs from Azion to streaming, SIEM, and big data platforms. |
| **Functions** | A function to use with an application or a firewall. |
| **Edge Services** | A service that defines the dependencies between the resources you install with Orchestrator. |
| **Certificate Manager** | A digital certificate entry that secures HTTPS applications. |
| **Network Lists** | An allowlist, a blocklist, or a greylist for the Rules Engine of a firewall. |
