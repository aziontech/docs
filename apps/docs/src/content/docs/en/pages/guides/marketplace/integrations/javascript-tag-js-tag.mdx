The JavaScript tag (JS TAG) is a browser-level script that you add to a web page. It captures data about the browser, builds a unique identifier from that data, and sets the identifier as a session cookie named `_azfp_sc`. The browser sends cookies in every request it makes, so the identifier reaches your application with each one.

The script runs on the page you want to fingerprint, a process also known as JavaScript injection. It captures the following data from the browser:

- Audio and video support.
- Canvas rendering.
- Access to device-level APIs, such as the accelerometer and the gyroscope.
- Manufacturer's data.
- Timezone.
- WebGL rendering.

Before it creates a cookie, the script checks whether `_azfp_sc` already exists. If it does, the script creates no new one.

---

## Prerequisites

- Access to the HTML source of the web page you want to fingerprint.
- To serve your own copy of the script, a project folder that your domain serves.

---

## Embed the script

Azion provides the script as [a file](https://assets.azion.com/global/bot-manager/client-fingerprint/azfp-1.0.0.min.js) that you can load from your HTML source. To load it from Azion, add this element to your HTML source:

```html
<script src="https://assets.azion.com/global/bot-manager/client-fingerprint/azfp-1.0.0.min.js"></script>
```

You can also serve your own copy of the script. To do so:

<DocSteps>
  <DocStep title="Copy the code">

  Copy the code in [the script file](https://assets.azion.com/global/bot-manager/client-fingerprint/azfp-1.0.0.min.js).

  </DocStep>
  <DocStep title="Create a JavaScript file with the code">

  In this example, the file name is `fingerprint-script.js`.

  </DocStep>
  <DocStep title="Add the file to your project folder" />
  <DocStep title="Load the file from your HTML source">

  Add this element to your HTML source:

  ```html
  <script src="https://example.com/fingerprint-script.js"></script>
  ```

  </DocStep>
</DocSteps>

Replace the values in the element as follows:

| Value | Replace with |
| --- | --- |
| `https://example.com/` | Your domain. |
| `fingerprint-script.js` | Your JavaScript file name. |

The script then sets the `_azfp_sc` session cookie in each browser that loads the page.
