You can deploy a minimal Astro website to Azion from the Clean Astro + Sanity application template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

The template creates a minimal [Astro](https://docs.astro.build/en/concepts/why-astro/) website integrated with [Sanity](http://sanity.io/), which manages the website's content. The template uses Astro `3.1.4`.

The deployment creates a GitHub repository for your project, an [application](/en/documentation/platform/applications/) that serves it, and a domain to reach it. The application uses [Application Accelerator](/en/documentation/platform/applications/application-accelerator/), [Functions](/en/documentation/platform/functions/), and [Cache](/en/documentation/platform/applications/cache/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A [GitHub account](https://github.com/signup). Azion connects to it and creates the project's repository there.
- A [Sanity.io](http://sanity.io/) account, with a blog project that the application reads content from. To start the project, use one of two options:
  - **Sanity CLI**: create the project for free by selecting the blog template.
  - **Sanity GUI**: this option can incur costs. For more information, refer to the [Sanity CMS](http://sanity.io/) website.

## Deploy the template

The Clean Astro + Sanity application template opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [Clean Astro + Sanity application](https://console.azion.com/create/sanity/clean-astro-sanity-app) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Connect Azion with your GitHub account">

  A window opens to confirm the installation of the [Azion GitHub App](/en/documentation/guides/application-development/automation/azion-github-app/), which connects your GitHub account with Azion. In that window, define the app's permissions and repository access.

  </DocStep>
  <DocStep title="Select the Git Scope">

  Select the **Git Scope** to work with.

  </DocStep>
  <DocStep title="Name the application">

  In **Application Name**, enter a unique name for the application.

  </DocStep>
  <DocStep title="Enter the Sanity project details">

  Enter the values that point the application at your Sanity content:

  - **Sanity Project ID**: the ID of the project that the application reads content from.
  - **Sanity Studio Dataset**: the dataset that the application reads content from.

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

## Update the project

Every push to the GitHub repository that the Clean Astro + Sanity application template creates deploys automatically.

To update the deployed website, push your changes to that repository. Azion deploys them, and the application serves the new version.

## Manage the application

The settings that the Clean Astro + Sanity application template applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by application name only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/).

## Add a custom domain

The Clean Astro + Sanity application deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. To add one, refer to [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/). For more information, refer to [Domains](/en/documentation/platform/workloads/domains/).
