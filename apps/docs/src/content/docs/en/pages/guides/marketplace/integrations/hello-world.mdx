Hello World answers requests to your application with an HTTP status code and a text body, so the browser displays a message such as `Hello World!`. Use it as a first function to see how an application runs an integration. It is one of the [Marketplace integrations](/en/documentation/platform/marketplace/integrations/) that run on an application.

Hello World installs through the **Install an Integration** drawer. The drawer installs the integration on the application you select, with the status code and the body you enter, in one pass.

---

## Prerequisites

- An Azion account. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- An [application](/en/documentation/platform/applications/) served by a [workload](/en/documentation/platform/workloads/). To create one, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/). Without an application, the drawer shows `No Application has been created. Go to Application to create a new one.` Create the application, then restart the install from **Marketplace**.
- Turning on a product or a module can generate usage costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

## Install the integration

Hello World is not shown among the featured cards, so search for it. To install it on your application from Azion Console:

<DocSteps>
  <DocStep title="Open Marketplace">

  Access [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Find the integration">

  Enter `Hello` in the **Search on Marketplace** field, then select the **Hello World** card.

  </DocStep>
  <DocStep title="Select Install">

  The **Install an Integration** drawer opens.

  </DocStep>
  <DocStep title="Select the application">

  In the **Select an Application** section, open the **Application** list and select the application that runs the integration.

  </DocStep>
  <DocStep title="Set the arguments">

  In the **General** section, keep the defaults of `Status` and `Body`, or enter your own. Each argument is described in the table below.

  </DocStep>
  <DocStep title="Review the permissions">

  The drawer lists the privileges Azion Marketplace requires on the selected application. For Hello World, they are `Read and write the selected application` and `Delete the functions to instantiate the new integration in the selected application`.

  </DocStep>
  <DocStep title="Select Deploy" />
</DocSteps>

A message confirms that the integration was successfully installed. Once the application is ready, a request to it displays the `Body` text in the browser.

### Arguments

| Argument | Default | Description |
|---|---|---|
| `Status` | `200` | The HTTP status code of the response. `200` indicates that the request was successful |
| `Body` | `Hello World!` | Any string. It is the text the browser displays |
