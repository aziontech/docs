You can deploy a function-based application to Azion from the Function Starter Kit template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

The Function Starter Kit holds the configuration of an application that runs a function and has no origin dependencies. The template simplifies the configuration, so the function it deploys is ready to run.

The deployment creates an [application](/en/documentation/platform/applications/), a basic Hello World function, and a domain that you manage on Azion Web Platform. The application uses [Application Accelerator](/en/documentation/platform/applications/application-accelerator/) and [Functions](/en/documentation/platform/functions/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).

## Deploy the template

The Function Starter Kit opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [Function Starter Kit](https://console.azion.com/create/azion/functions-starter) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Name the application">

  Enter a unique name that you can remember. The storage bucket and the function that the template creates take the same name. If the name is already in use, the platform returns an error message.

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application, a link that opens it in a browser, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

## Update the function

The Function Starter Kit installs a Hello World function that is ready to run, and you can change it to fit your project. The function's page carries three tabs:

- **Main Settings** renames the function and changes its basic settings.
- **Code** holds the function code, which you can update.
- **Arguments** defines the arguments the function uses.

To update the function:

<DocSteps>
  <DocStep title="Open the functions list">

  Access [Azion Console](https://console.azion.com/) > **Functions**.

  </DocStep>
  <DocStep title="Select the function that the template created">

  The function carries the same name as the application. The list is alphabetical, and the **search bar** filters it by **Function Name** only.

  </DocStep>
  <DocStep title="Open the tab that holds the setting">

  Open the **Main Settings**, **Code**, or **Arguments** tab.

  </DocStep>
  <DocStep title="Change the setting">

  In that tab, change the setting.

  </DocStep>
  <DocStep title="Select Save">

  Select **Save**.

  </DocStep>
</DocSteps>

The function has the changes you saved. For more information, refer to [Functions](/en/documentation/platform/functions/).

## Manage the application

The settings that the Function Starter Kit applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application on the account, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by **Application Name** only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/).

## Add a custom domain

The Function Starter Kit deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. For more information, refer to [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/) and [Domains](/en/documentation/platform/workloads/domains/).
