You can deploy a web application to Azion from one of the VuePress Templates in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

The VuePress Templates collection holds four templates, all based on the VuePress framework:

- **VuePress Blog with Hope Theme**: a VuePress-based blog with the Hope Theme. It uses version `2.0.0` of VuePress.
- **VuePress Docs with Hope Theme**: a VuePress-based documentation website. It uses version `2.0.0` of VuePress.
- **VuePress Live2D Plus**: a VuePress documentation website. It uses version `2.0.0` of VuePress.
- **VuePress Solid**: a static site built with VuePress. It uses version `2.0.0` of VuePress.

Each template's deployment creates a GitHub repository for your project, an [application](/en/documentation/platform/applications/) that serves it, and a domain to reach it. The templates use [Application Accelerator](/en/documentation/platform/applications/application-accelerator/), [Functions](/en/documentation/platform/functions/), and [Cache](/en/documentation/platform/applications/cache/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A [GitHub account](https://github.com/signup). Azion connects to it and creates the project's repository there.

---

## Deploy a template

Each template in the collection opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy a template:

<DocSteps>
  <DocStep title="Open the template">

  Go to the template you want to deploy in Azion Console:

  - [VuePress Blog with Hope Theme](https://console.azion.com/create/azion-community/vuepress-blog-hope)
  - [VuePress Docs with Hope Theme](https://console.azion.com/create/azion-community/vuepress-docs-hope)
  - [VuePress Live2D Plus](https://console.azion.com/create/azion-community/vuepress-live-2d-plus)
  - [VuePress Solid](https://console.azion.com/create/azion-community/vuepress--solid)

  The configuration form opens.

  </DocStep>
  <DocStep title="Connect Azion with your GitHub account">

  A window opens to confirm the installation of the [Azion GitHub App](/en/documentation/guides/application-development/automation/azion-github-app/), which connects your GitHub account with Azion. In that window, define the app's permissions and repository access.

  </DocStep>
  <DocStep title="Select the Git scope to work with" />
  <DocStep title="Name the application">

  Enter a unique name that you can remember. The storage bucket and the function that the template creates take the same name. If the name is already in use, the platform returns an error message.

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

---

## Update the project

Every push to the GitHub repository that the template creates deploys automatically.

To update the deployed project, push your changes to that repository. Azion deploys them, and the application serves the new version.

---

## Manage the application

The settings that the template applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by application name only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/).

---

## Add a custom domain

The deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. To add one, refer to [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/). For more information, refer to [Domains](/en/documentation/platform/workloads/domains/).
