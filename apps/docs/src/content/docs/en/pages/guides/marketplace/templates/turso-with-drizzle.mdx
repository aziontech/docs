You can deploy an application connected to a Turso database to Azion from the Turso Starter Kit with Drizzle ORM template in Azion Console. To create an application without a template, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

The template holds the configurations that create the application and connect it to the Turso database through Drizzle ORM.

The deployment creates a GitHub repository for your project, an [application](/en/documentation/platform/applications/) that serves it, and a domain to reach it. In your Turso account, the deployment adds a new database with a new table. The application uses [Application Accelerator](/en/documentation/platform/applications/application-accelerator/), [Functions](/en/documentation/platform/functions/), and [Cache](/en/documentation/platform/applications/cache/), and their usage can generate costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/). Turso can also charge you directly for the storage and operations of the database. For details, refer to [Turso's pricing page](https://turso.tech/pricing).

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A [GitHub account](https://github.com/signup). Azion connects to it and creates the project's repository there.
- A [Turso account](https://turso.tech/) with an empty database slot.

## Deploy the template

The Turso Starter Kit with Drizzle ORM opens as a configuration form in Azion Console, and an asterisk marks each mandatory field.

To deploy the template:

<DocSteps>
  <DocStep title="Open the template">

  Go to [Turso Starter Kit with Drizzle ORM](https://console.azion.com/create/drizzle-orm/drizzle-turso-starter) in Azion Console. The configuration form opens.

  </DocStep>
  <DocStep title="Connect Azion with your GitHub account">

  A window opens to confirm the installation of the [Azion GitHub App](/en/documentation/guides/application-development/automation/azion-github-app/), which connects your GitHub account with Azion. In that window, define the app's permissions and repository access.

  </DocStep>
  <DocStep title="Select the Git Scope">

  Select the **Git Scope** to work with.

  </DocStep>
  <DocStep title="Name the application">

  In **Application Name**, enter a unique name for the application. The storage bucket and the function that the template creates take the same name.

  </DocStep>
  <DocStep title="Enter the details of your Turso account">

  Enter the details that the template uses to create the database in your Turso account:

  - **Turso Authorization Token**: the token used to communicate with the Turso API. The token must have writing permission.
  - **Turso Organization**: the name of your organization at Turso.
  - **Turso Group**: the group at Turso where the template launches the new database.

  </DocStep>
  <DocStep title="Start the deployment">

  Select **Deploy**.

  </DocStep>
</DocSteps>

A window shows the deployment logs while it runs. When the deployment completes, the page shows the application's details, a browser link to it, and options to continue.

The link can take a few minutes to start serving the application, while its configuration propagates across Azion's distributed infrastructure. If the page does not load, wait a few minutes and open the link again.

## Update the project

Every push to the GitHub repository that the Turso Starter Kit with Drizzle ORM creates deploys automatically.

To update the deployed project, push your changes to that repository. Azion deploys them, and the application serves the new version.

## Manage the application

The settings that the Turso Starter Kit with Drizzle ORM applies may not fit your application. You can change any of them at any time from Azion Console.

To open the application's settings:

<DocSteps>
  <DocStep title="Open the applications list">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The list shows every application you created, in alphabetical order.

  </DocStep>
  <DocStep title="Select the application that the template created">

  To find it in a long list, search by its name. The search filters the list by application name only.

  </DocStep>
</DocSteps>

The application opens on a page that holds every setting you can configure. For more information, refer to [Main Settings](/en/documentation/platform/applications/main-settings/), [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/), and [Device Groups](/en/documentation/platform/applications/device-groups/).

## Add a custom domain

The Turso Starter Kit with Drizzle ORM deployment assigns the application a [workload](/en/documentation/platform/workloads/) domain in the format `xxxxxxxxxx.map.azionedge.net`, which a browser can open. To serve the application from a domain you own, add a custom domain. For more information, refer to [Domains](/en/documentation/platform/workloads/domains/) and [Add a custom domain to a workload](/en/documentation/guides/platform/migration/configure-a-domain/).
