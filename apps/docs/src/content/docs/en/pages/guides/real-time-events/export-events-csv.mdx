You can download the result of a [Real-Time Events](/en/documentation/platform/real-time-events/) search as a CSV file from Azion Console. The download belongs to the newer Real-Time Events view, reached from **Switch to new view** and marked with a **PREVIEW** badge. This page follows that view, not the one Real-Time Events opens on.

The two views take different words for the same things. The newer view labels the index selector **Dataset**, and its filter field takes Azion Query Language. The view Real-Time Events opens on labels the selector **Data Sources**, and its **Filter by** field takes a different syntax.

---

## Prerequisites

- An Azion account. To create one, refer to [How to create an account on Azion](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A product already writing event records, so the dataset you pick holds records to download.

Real-Time Events bounds the period a search can ask for and the rows it returns, and a download inherits the bounds of the search behind it. For each one, refer to [Limits](/en/documentation/platform/real-time-events/limits/).

---

## Download a search result as a CSV file

A search is one dataset, one time range, and one filter over them. Narrow those three first: the download carries the result of the search, not the dataset.

To download the result from Azion Console:

<DocSteps>
  <DocStep title="Open Real-Time Events">

  Access [Azion Console](https://console.azion.com) > **Products menu** > **Observe** > **Real-Time Events**.

  </DocStep>
  <DocStep title="Select Switch to new view" />
  <DocStep title="Select the dataset">

  In **Dataset**, select the records to read. For example, _HTTP Requests_.

  </DocStep>
  <DocStep title="Set the period">

  Set the from-to time range to a period that holds the records.

  </DocStep>
  <DocStep title="Narrow the result">

  Enter a condition in the filter field, which takes Azion Query Language. The field reads `Filter using Azion Query Language syntax...` until you enter one.

  </DocStep>
  <DocStep title="Select Refresh" />
  <DocStep title="Download the result">

  Beside the page-size selector, select the download control. The control carries an icon and no text.

  </DocStep>
</DocSteps>

The result downloads as a CSV file.

Real-Time Events states how many events the search returned, so you can tell whether the result is the set you want before you download it. The **Fields** panel lists what each record carries, and `Search documents...` narrows the rows the table already holds.

Field names in this view are camelCase, identical to the names the GraphQL API uses, such as `remoteAddress` and `httpUserAgent`. For what each one carries, refer to [Real-Time Events GraphQL API fields](/en/documentation/devtools/graphql/gql-real-time-events-fields/).
