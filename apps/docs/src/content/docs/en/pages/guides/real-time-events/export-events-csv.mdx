You can download the result of a [Real-Time Events](/en/documentation/platform/real-time-events/) search as a CSV file from Azion Console.

---

## Prerequisites

- An Azion account. To create one, refer to [How to create an account on Azion](/en/documentation/fundamentals/creating-account/).
- Access to Azion Console. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- A product already writing event records, so the data source you select holds records to download.

Real-Time Events bounds the period a search can ask for and the rows it returns. A download inherits the bounds of the search behind it. For each one, refer to [Limits](/en/documentation/platform/real-time-events/limits/).

---

## Download a search result as a CSV file

A search is one data source, one period, and one filter over them. The download carries the result of that search, not the whole data source. To download fewer records, filter the search first, as [Query HTTP request events](/en/documentation/guides/platform/observability/query-workload-events/) describes.

To download the result from Azion Console:

<DocSteps>
  <DocStep title="Open Real-Time Events">

  Access [Azion Console](https://console.azion.com/) > **Real-Time Events**.

  </DocStep>
  <DocStep title="Select the data source">

  Select the tab of the records to download, such as **HTTP Requests**.

  </DocStep>
  <DocStep title="Open the period">

  Select the period field, which shows _Last 5 minutes_.

  </DocStep>
  <DocStep title="Select the period">

  Select **Quick**, and then select a period that holds the records, such as _Last 24 hours_.

  </DocStep>
  <DocStep title="Run the search">

  Select **Update**.

  </DocStep>
  <DocStep title="Download the result">

  In the table header, select the download icon, whose tooltip reads **Export to CSV**.

  </DocStep>
</DocSteps>

The browser downloads the CSV file at once. From the **HTTP Requests** tab, the file is `http-requests-logs.csv`.

The file has the two columns of the table, **Time** and **Log Body**. It holds one row per record the search found, including the rows on other pages of the table. The count of records found tells you how many rows the file holds before you download it.

**Log Body** lists each field by its camelCase name, identical to the GraphQL API, such as `remoteAddress` and `httpUserAgent`. For what each one carries, refer to [Real-Time Events GraphQL API fields](/en/documentation/devtools/graphql/gql-real-time-events-fields/).
