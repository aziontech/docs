You can read the classification counts of your bot traffic from the `botManagerMetrics` dataset, in the GraphiQL Playground or with the GraphQL API. For the URLs and the addresses bot traffic reached, refer to [Query the top URLs bots reach with GraphQL](/en/documentation/guides/platform/observability/query-bot-manager-breakdown-data-with-graphql/).

---

## Prerequisites

- [Bot Manager](/en/documentation/platform/firewall/bot-manager/) running on your account. On an account with no Bot Manager data, the query answers `200` with an empty list.
- For the Playground, a signed-in Azion Console session in the same browser. Without it, the endpoint answers `401` with `Authentication credentials were not provided.` For more information, refer to [GraphiQL Playground](/en/documentation/devtools/graphql/graphql-playground/).
- For a GraphQL client, a personal token, sent in an `Authorization: Token [TOKEN VALUE]` header. For more information, refer to [Personal Tokens](/en/documentation/fundamentals/personal-tokens/).

---

## Query the classification counts

The dataset counts the requests Bot Manager analyzed, and it carries no score. A score belongs to one request and is on its report line, which [Logs](/en/documentation/platform/firewall/bot-manager/logs/) documents. The query below filters the dataset by a time range, sums `requests` per group, and returns one object per combination of the grouped fields.

To query the classification counts:

<DocSteps>
  <DocStep title="Open the Playground">

  Go to `https://api.azion.com/v4/metrics/graphql`. From a GraphQL client, send the query to the same URL with your token.

  </DocStep>
  <DocStep title="Enter the query">

  Set `begin` and `end` to the period you want to read. The dataset is retained for 2 years:

  ```graphql
  query {
    botManagerMetrics(
      filter: {
        tsRange: {
          begin: "2024-09-23T15:00:00"
          end: "2024-09-23T17:00:00"
        }
      }
      aggregate: {
        sum: requests
      }
      orderBy: [ts_ASC]
      groupBy: [ts, action, botCategory, botMode, classified]
      limit: 10000
    ) {
      action
      botCategory
      botMode
      classified
      sum
    }
  }
  ```

  </DocStep>
  <DocStep title="Run the query and read the response">

  The response carries one object per combination of the grouped fields, with the summed requests in `sum`:


You now have the requests Bot Manager analyzed in the period, counted by how it classified each one and by the action it applied. `classified` and `botCategory` are independent of each other, so one category can hold requests of several classifications.

The query selects five fields, and the dataset carries more, including the host, the HTTP method, the geographic origin, and the result of a CAPTCHA challenge. For every field, refer to [botManagerMetrics](/en/documentation/devtools/graphql/gql-real-time-metrics-fields/#bot-manager-metrics).

## Rank the classifications by volume

Ordering by the aggregate instead of by the timestamp turns the same dataset into a ranking of the combinations that carry the most traffic.

To rank the classifications:

<DocSteps>
  <DocStep title="Order by the sum">

  Set `orderBy` to `[sum_DESC]`, so the largest groups come first.

  </DocStep>
  <DocStep title="Drop ts from groupBy">

  Each combination then collapses into one object across the whole range:

  ```graphql
  query {
    botManagerMetrics(
      filter: {
        tsRange: {
          begin: "2024-10-01T00:00:00"
          end: "2024-10-03T23:59:59"
        }
      }
      aggregate: {
        sum: requests
      }
      orderBy: [sum_DESC]
      groupBy: [classified, botCategory, action]
      limit: 10000
    ) {
      classified
      botCategory
      action
      sum
    }
  }
  ```

  </DocStep>
  <DocStep title="Run the query" />
</DocSteps>

The objects at the top of the response are the largest groups, which is where a change of threshold or of action moves the most traffic. To act on these counts, refer to [Monitor and calibrate Bot Manager](/en/documentation/guides/application-security/bots-and-network/monitor-and-calibrate-bot-manager/).
