Every product, resource, and account setting you use at Azion is configured from one web interface. Its header carries the menus and buttons that open each area, and its homepage carries shortcuts to the first tasks. That interface is [Azion Console](https://console.azion.com/).

In it, you set up your [Azion account](/en/documentation/fundamentals/creating-account/), [build and deploy applications](/en/documentation/platform/applications/), [manage the main settings of an application](/en/documentation/guides/application-development/getting-started/configure-main-settings/), and configure every Azion product. The [Guides](/en/documentation/guides/) cover the tasks of each one. The sections below cover the homepage, the products menu, the Create modal, the help and feedback buttons, and the account menu, in that order. To sign up or sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).

---

## Homepage

The homepage opens after you sign in. Its cards work as shortcuts: each one opens a product or starts a task.

| Block | What it holds |
| --- | --- |
| **Get Started** | The **+ Create** button, which starts an application from the [Azion template](/en/documentation/platform/marketplace/) that fits your project, or creates another resource. |
| **Manage Applications** | A link to the [Applications](/en/documentation/platform/applications/) page, where you add applications and manage their main settings and features. |
| **View Analytics** | A link to [Real-Time Metrics](/en/documentation/platform/real-time-metrics/), with data on the performance, availability, and security of your applications. |
| **Invite Your Team** | An optional shortcut to bring other people into the account to work with you. Their access follows [Teams Permissions](/en/documentation/fundamentals/teams-permissions/). |
| Help links | Links to the [Azion documentation](/en/documentation/guides/), the [Azion API library](https://api.azion.com/), and the [support team](/en/documentation/support/open-tickets/). |

## Products menu

The products menu lists every Azion product and resource you can open. Three entries come first:

| Entry | Opens |
| --- | --- |
| **Home** | The homepage. |
| **Marketplace** | [Azion Marketplace](/en/documentation/platform/marketplace/), the digital catalog of Azion. |
| **Workloads** | [Workloads](/en/documentation/platform/workloads/), the service that generates and manages domains. |

The other products sit in sections, each named for a stage of the work:

| Section | Products |
| --- | --- |
| **Build** | **Applications**, **Variables** |
| **Secure** | **Edge DNS**, **Firewall** |
| **Deploy** | **Edge Nodes** |
| **Observe** | **Data Stream**, **Edge Pulse**, **Real-Time Metrics**, **Real-Time Events** |
| **Tools** | **Real-Time Purge** |
| **Edge Libraries** | **Certificate Manager**, **Edge Services**, **Functions**, **Network Lists**, **WAF Rules** |

Selecting an entry opens that product with its settings.

## Create modal

The **+ Create** button sits in the Console header and in the **Get Started** block of the homepage. It opens a modal with four tabs: **Recommended**, **Templates**, **Resources**, and **Import from GitHub**. On some accounts, only the **Resources** tab shows.

The **Resources** tab creates one resource at a time, such as a workload, an application, a firewall, a function, or a digital certificate. The other tabs start a whole application from a template or from a GitHub repository. For what each tab offers, refer to [Use the + Create button](/en/documentation/guides/platform/account-and-billing/create-button/).

## Help and feedback

The **Help** button shows documentation related to the screen you are on, along with other useful links. The **Feedback** button sends your opinion of Azion Console to Azion.

:::note
The **Help Center** does not carry documentation for every Console screen.
:::

## Account menu

The account menu opens from the Console header. It shows your account information, and its entries depend on the type of account.

| Group | Entries |
| --- | --- |
| Account | **Account Settings**, **Environments**, **Deployments Settings**, **Variables**, **Users Management**, **Billing**, **Credentials**, **Activity History**, **Teams Permissions**, **SSO Management** |
| Company accounts only | **Groups Management** |
| Reseller accounts only | **Clients Management** |
| Personal, labeled with your profile name | **Your Settings**, **Personal Token** |
| Theme | _Light_, _Dark_, _System_ |
| Session | **Logout** |

**SSO Management** shows only on accounts where the feature is turned on. For the setup, refer to [SSO](/en/documentation/guides/platform/account-and-billing/sso/). The **Switch account** control opens the **Switch Account** dialog, where you change the account you work in.
