Every product, resource, and account setting you use at Azion is configured from one web interface. Its header carries the menus and buttons that open each area, and its homepage carries shortcuts to the first tasks. That interface is [Azion Console](https://console.azion.com/).

In it, you set up your [Azion account](/en/documentation/fundamentals/creating-account/), [build and deploy applications](/en/documentation/platform/applications/), [manage the main settings of an application](/en/documentation/guides/application-development/getting-started/configure-main-settings/), and configure every Azion product. The [Guides](/en/documentation/guides/) cover the tasks of each one. This page covers the homepage, the Console menu, Creation Center, the help and Copilot buttons, and the account menu. To sign up or sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).

---

## Homepage

The homepage opens after you sign in. Its cards work as shortcuts: each one opens a product or starts a task.

| Block | What it holds |
| --- | --- |
| **Get Started** | The **+ Create** button, which starts an application from the [Azion template](/en/documentation/platform/marketplace/) that fits your project, or creates another resource. |
| **Manage Applications** | A link to the [Applications](/en/documentation/platform/applications/) page, where you add applications and manage their main settings and features. |
| **View Analytics** | A link to [Real-Time Metrics](/en/documentation/platform/real-time-metrics/), with data on the performance, availability, and security of your applications. |
| **Invite Your Team** | An optional shortcut to bring other people into the account to work with you. Their access follows [Teams Permissions](/en/documentation/fundamentals/teams-permissions/). |
| Help links | Links to the [Azion documentation](/en/documentation/guides/), the [Azion API library](https://api.azion.com/), and the [support team](/en/documentation/support/open-tickets/). |

## Console menu

The **Menu** button in the Console header opens the Console menu, which lists every Azion product and resource you can open. Two entries come first:

| Entry | Opens |
| --- | --- |
| **Home** | The homepage. |
| **Marketplace** | [Azion Marketplace](/en/documentation/platform/marketplace/), the digital catalog of Azion. |

The other entries sit in sections, each named for a stage of the work:

| Section | Entries |
| --- | --- |
| **Build** | **Workloads**, **Applications** |
| **Secure** | **Connectors**, **Edge DNS**, **Firewalls** |
| **Store** | **Object Storage**, **SQL Database** |
| **Deploy** | **Edge Nodes** |
| **Observe** | **Data Stream**, **Edge Pulse**, **Real-Time Metrics**, **Real-Time Events** |
| **Tools** | **Real-Time Purge** |
| **Edge Libraries** | **Certificate Manager**, **Custom Pages**, **Edge Services**, **Functions**, **Network Lists**, **WAF Rules** |

Selecting an entry opens that product with its settings. The menu can differ with the type of account. Some accounts show **Domains** in place of **Workloads**. Others nest **Applications**, **Firewalls**, and **Custom Pages** under **Workloads**, and leave out entries such as **Marketplace** and **Edge Nodes**. The procedures in this documentation name only the entry, such as **Firewalls**, so look for the entry by its name.

## Creation Center

The **+ Create** button sits in the Console header and in the **Get Started** block of the homepage. It opens **Creation Center**, a page with two sections:

- **Import from GitHub** starts an application from a repository of a GitHub account you connect.
- **Start from Template** lists the **Recommended** templates and the **Azion Templates** available to your account, with a search and filters by technology and use case.

For what each option offers, refer to [Use the + Create button](/en/documentation/guides/platform/account-and-billing/create-button/).

---

## Help and Copilot

The **Help** button shows documentation related to the screen you are on, along with other useful links. The **Copilot** button opens Azion Copilot in a side panel. Azion Copilot is an AI assistant with knowledge of every Azion product.

:::note
The **Help Center** does not carry documentation for every Console screen.
:::

## Account menu

The account menu opens from the Console header. It shows your account information, and its entries depend on the type of account.

| Group | Entries |
| --- | --- |
| Account | **Account Settings**, **Environments**, **Deployments Settings**, **Variables**, **Users Management**, **Billing**, **Credentials**, **Activity History**, **Teams Permissions**, **SSO Management** |
| Company accounts only | **Groups Management** |
| Reseller accounts only | **Clients Management** |
| Personal, labeled with your profile name | **Your Settings**, **Personal Token** |
| Theme | _Light_, _Dark_, _System_ |
| Session | **Logout** |

**SSO Management** shows only on accounts where the feature is turned on. For the setup, refer to [SSO](/en/documentation/guides/platform/account-and-billing/sso/). The **Switch account** control opens the **Switch Account** dialog, where you change the account you work in.
