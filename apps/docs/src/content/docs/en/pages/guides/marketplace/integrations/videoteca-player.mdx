Videoteca Player hosts the player of [Videofront's Videoteca](https://videofront.com.br/videoteca) and embeds it with an iframe. To choose the video the page displays, pass its ID in the `video-id` query string argument. It is one of the [Marketplace integrations](/en/documentation/platform/marketplace/integrations/) that run on an application.

Four objects must exist before a request loads the player: the installed function, an application with the **Functions** module turned on, a function instance that holds your Videoteca credentials, and a Rules Engine rule with the **Run Function** behavior. Each section below creates one of them.

---

## Prerequisites

- An Azion account. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- An [application](/en/documentation/platform/applications/) served by a [workload](/en/documentation/platform/workloads/). To create one, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).
- An account on the [Videoteca website](https://videofront.com.br/videoteca), with its **Username** and **API Token**. The function instance requires both.
- Turning on a product or a module can generate usage costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/).

## Install the integration

The install adds the Videoteca Player function to your account. To install it from Azion Console:

<DocSteps>
  <DocStep title="Open Marketplace">

  Access [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Find the integration">

  Enter `Videoteca Player` in the **Search on Marketplace** field, then select the integration's card.

  </DocStep>
  <DocStep title="Select Install" />
</DocSteps>

The card shows `Successfully installed!` and `Latest version installed!`. The function is then listed in the **Function** list of the **Create Instance** drawer.

---

## Turn on the Functions module

An application runs an installed function only when its **Functions** module is on. To turn on the module:

<DocSteps>
  <DocStep title="Open your application">

  Access [Azion Console](https://console.azion.com/) > **Applications** > **your application**.

  </DocStep>
  <DocStep title="Open the Modules section">

  In the **Main Settings** tab, go to the **Modules** section.

  </DocStep>
  <DocStep title="Turn on the Functions switch" />
  <DocStep title="Select Save" />
</DocSteps>

Azion Console confirms that the application was updated.

## Create the function instance

A function instance holds the arguments the Videoteca Player function reads for one application. To create the instance in your application:

<DocSteps>
  <DocStep title="Open the Functions Instances tab">

  In **Applications**, select your application, then select the **Functions Instances** tab.

  </DocStep>
  <DocStep title="Select + Function">

  An application with no instance yet offers the same action as **Function Instance**. The **Create Instance** drawer opens.

  </DocStep>
  <DocStep title="Name the instance">

  In **Name**, enter a unique name that identifies the instance. For example: `videoteca-player`.

  </DocStep>
  <DocStep title="Select the function">

  In **Function**, select _Videoteca Player_. The **Arguments** editor fills with the default arguments of the integration.

  </DocStep>
  <DocStep title="Edit the arguments">

  In **Arguments**, enter your Videoteca username and API token. Each key is described in the table below.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The instance appears in the **Functions Instances** tab with the name you entered.

### Arguments

The arguments are one JSON object. Replace each placeholder with your own value:

```json
{
"videoteca_user": "<your_username>", // Replace with your Videoteca username
"videoteca_token": "<your_token>", // Replace with your Videoteca API token
"custom_html": "<your_html>" // Replace with your custom html
}
```

| Key | Required | Description |
|---|---|---|
| `videoteca_user` | Yes | The name of the account the function retrieves the videos from |
| `videoteca_token` | Yes | The token that accesses the Videoteca API |
| `custom_html` | No | Custom HTML for the page the function delivers. It must include the `<!-- videoteca_iframe -->` tag, which the function replaces with the iframe of the video |

To get your API token, open `https://<YOUR-USER>.videotecaead.com.br/Apidoc`, with `<YOUR-USER>` replaced by your Videoteca username.

## Create the rule

The instance runs only when a Rules Engine rule calls it. The rule below matches every request. To create the rule:

<DocSteps>
  <DocStep title="Open the Rules Engine tab">

  In **Applications**, select your application, then select the **Rules Engine** tab.

  </DocStep>
  <DocStep title="Select + Rule" />
  <DocStep title="Name the rule">

  In **Name**, enter a name for the rule. For example: `Run Videoteca Player on every request`.

  </DocStep>
  <DocStep title="Select the phase">

  In the **Phase** section, select _Request Phase_.

  </DocStep>
  <DocStep title="Set the criterion">

  In the **Criteria** section, keep the `${uri}` variable and the _starts with_ operator, then enter `/` as the argument.

  </DocStep>
  <DocStep title="Add the Run Function behavior">

  In the **Behaviors** section, select _Run Function_, then select the instance you created by its name.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The rule appears in the **Rules Engine** tab, under the request phase, and runs the Videoteca Player instance on every request. To narrow the requests that load the player, change the criterion.

For every criterion and behavior a rule accepts, refer to [Rules Engine](/en/documentation/platform/applications/rules-engine/).
