## Azion platform access

Claude Desktop reaches Azion through the MCP servers, which look things up and change your configuration through the Azion API.

### MCP servers

Azion runs five MCP servers, one per area of the Azion Platform. Each one is an HTTP endpoint that takes your personal token in the `Authorization: Token [TOKEN VALUE]` header. The quick start connects the docs server, and you connect the others the same way, with the URLs in this table.

Connect only the servers the work needs. The docs server only reads. The other four also create, change, and delete, and each of their write tools previews a change without making it when the agent sets `dry_run`:

## Tips

<DocCallout kind="tip">Claude Desktop writes its MCP logs to `mcp*.log` files. `mcp.log` records connection failures, and `mcp-server-azion-docs.log` holds the output of the `mcp-remote` bridge. The logs are in `~/Library/Logs/Claude` on macOS, `%APPDATA%\Claude\logs` on Windows, and `~/.config/Claude/logs` on Linux.</DocCallout>

<DocCallout kind="tip">Ask for a `dry_run` preview before a write. The build, secure, observe, and storage servers change your account through the Azion API.</DocCallout>
