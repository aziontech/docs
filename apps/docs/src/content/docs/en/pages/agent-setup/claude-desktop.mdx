## Azion platform access

Claude Desktop reaches Azion through the MCP servers: they look things up and create configuration through the API.

### MCP servers

Five servers, one per area of the platform. Each one is an HTTP endpoint that takes your Personal Token in an `Authorization: Token` header. The quick start connects the docs server. Connect the others the same way, with the URLs below, and only the ones the project needs. The docs server only reads. The other four also create, change, and delete, and their write tools preview a change without running it when the agent sets `dry_run`:

## Tips

<DocCallout kind="tip">Claude Desktop logs every MCP connection. `mcp.log` records connection failures, and `mcp-server-azion-docs.log` holds the output of the `mcp-remote` bridge. The logs are in `~/Library/Logs/Claude` on macOS and in `%APPDATA%\Claude\logs` on Windows.</DocCallout>

<DocCallout kind="tip">Ask for a `dry_run` preview before a write. The build, secure, observe, and storage servers change your account through the API.</DocCallout>
