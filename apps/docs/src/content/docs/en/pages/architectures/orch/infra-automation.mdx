[Azion Orchestrator](/en/documentation/platform/orchestrator/) allows you to automate and manage your infrastructure efficiently. By leveraging [Azion CLI](/en/documentation/devtools/cli/), you can perform tasks such as deployment, monitoring, and updates of applications. This documentation provides an in-depth look at the architecture and steps for implementing infrastructure automation using Azion Orchestrator, helping you achieve optimal performance and streamlined operations.

---

## Architecture

:::note
This flow assumes a service has been created for installing Azion CLI on the node. For further information, check the [Implementation](#implementation) section.
:::

![Orchestrator architecture diagram](/assets/docs/images/uploads/infrastructure-arch.png?v=2)


### Dataflow

1. The user opens **Edge Nodes** in **Azion Console** to manage the nodes.
2. The user binds a service, created in **Edge Services**, to the nodes.
3. The nodes are managed and configured through the service binding.
4. **Orchestrator** orchestrates the services on the nodes.

---

## Components

- [Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/): interface for managing and monitoring applications and services.
- [Azion Orchestrator](/en/documentation/platform/orchestrator/): automates deployment and management of applications across nodes.
- [Nodes](/en/documentation/platform/orchestrator/edge-node/): the devices that run the Orchestrator Agent, such as servers, routers, and network switches, and that Orchestrator manages.
- [Services](/en/documentation/platform/orchestrator/edge-services/): the services you create and customize so that Orchestrator runs them on nodes.

---

## Implementation

1. [Install Orchestrator Agent](/en/documentation/guides/application-development/automation/install-orchestrator-agent/) in your device to turn it into a node.
2. Authorize the node so it can be orchestrated.
    - On Console, you can see and [authorize nodes](/en/documentation/guides/application-development/automation/authorize-an-edge-node/).
    - Use [Azion API](https://api.azion.com/#e6a19e66-71e9-4b10-b50c-c0e0684bf458) to authorize a node.
3. Create services that will [run scripts](/en/documentation/guides/application-development/automation/run-scripts/) on the nodes.
4. Bind services to nodes.
    - On Console, [bind services](/en/documentation/guides/application-development/automation/bind-service-node/) to your nodes.
    - Use [Azion API](https://api.azion.com/#230b2947-a706-4143-ae96-3115b8ecd333) to bind a service to a node.
5. [Watch logs](/en/documentation/guides/application-development/automation/watch-logs/) from your nodes and services.
