The Azion Terraform Provider v2.0 configures the Azion Platform with two kinds of block. A resource creates, updates, and deletes an object on Azion, and a data source queries information about objects that already exist. A singular name such as `azion_workload` is often both a resource and the data source that reads one object, and its plural, `azion_workloads`, is the data source that lists them.

Each section below covers one product: its resources, its data sources, and a configuration block that uses them. Every name links its Terraform Registry page.

---

## Workloads

These resources and data sources manage workloads and their deployments. For more information, refer to [Workloads resources](/en/documentation/devtools/terraform/workloads/).

| Resource | Description |
| --- | --- |
| [`azion_workload`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/workload) | Creates and manages a workload. |
| [`azion_workload_deployment`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/workload_deployment) | Creates and manages a workload deployment, which binds an application, and optionally a firewall and a custom page, to a workload. |

| Data source | Description |
| --- | --- |
| [`azion_workloads`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workloads) | Lists workloads. |
| [`azion_workload`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload) | Reads one workload. |
| [`azion_workload_deployments`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload_deployments) | Lists workload deployments. |
| [`azion_workload_deployment`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload_deployment) | Reads one deployment. |

This block creates an application, a workload, and a deployment that binds the application to the workload, then queries the existing workloads:

```hcl
# Create the application that the deployment binds
resource "azion_application_main_setting" "app" {
  application = {
    name   = "my-application"
    active = true
  }
}

# Create a workload
resource "azion_workload" "example" {
  workload = {
    name   = "my-workload"
    active = true
  }
}

# Deploy the application on the workload
resource "azion_workload_deployment" "example" {
  workload_id = azion_workload.example.workload.id

  deployment = {
    name    = "my-deployment"
    active  = true
    current = true

    strategy = {
      type = "default"
      attributes = {
        application = azion_application_main_setting.app.application.application_id
      }
    }
  }
}

# Query existing workloads
data "azion_workloads" "all" {}
```

| [`azion_connector`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/connector) | Reads one connector. |

This block creates an `http` connector to an HTTPS origin, then queries the existing connectors:

```hcl
# Create a connector
resource "azion_connector" "example" {
  connector = {
    name   = "my-connector"
    type   = "http"
    active = true

    http_attributes = {
      addresses = [
        {
          endpoint = {
            address    = "origin.example.com"
            https_port = 443
          }
        }
      ]
      connection_options = {
        host             = "origin.example.com"
        transport_policy = "force_https"
      }
    }
  }
}

# Query existing connectors
data "azion_connectors" "all" {}
```

This block creates an application with the cache module on, and a cache setting that honors the cache policy of the origin:

```hcl
# Create an application
resource "azion_application_main_setting" "app" {
  application = {
    name   = "my-application"
    active = true
    modules = {
      cache = {
        enabled = true
      }
    }
  }
}

# Configure cache
resource "azion_application_cache_setting" "cache" {
  application_id = azion_application_main_setting.app.application.application_id

  cache_setting = {
    name = "cache-default"
    browser_cache = {
      behavior = "honor"
    }
    modules = {
      cache = {
        behavior = "honor"
      }
    }
  }
}
```

This block creates a zone and an `A` record in it, then queries the existing zones:

```hcl
# Create a DNS zone
resource "azion_intelligent_dns_zone" "zone" {
  zone = {
    name   = "example-zone"
    domain = "example.com"
    active = true
  }
}

# Create a DNS record
resource "azion_intelligent_dns_record" "www" {
  zone_id = azion_intelligent_dns_zone.zone.id

  record = {
    name   = "www"
    type   = "A"
    rdata  = ["192.0.2.1"]
    policy = "simple"
    ttl    = 3600
  }
}

# Query existing DNS zones
data "azion_intelligent_dns_zones" "all" {}
```

This block creates a firewall with the WAF module on, a WAF, and a firewall rule that applies the WAF in blocking mode to every request. It also creates a network list of two IP ranges:

```hcl
# Create a firewall with the WAF module on
resource "azion_firewall_main_setting" "firewall" {
  data = {
    name   = "my-firewall"
    active = true
    modules = {
      waf = {
        enabled = true
      }
    }
  }
}

# Create a WAF
resource "azion_waf" "waf" {
  result = {
    name   = "my-waf"
    active = true
  }
}

# Apply the WAF to every request that reaches the firewall
resource "azion_firewall_rule_engine" "waf" {
  firewall_id = azion_firewall_main_setting.firewall.data.id

  results = {
    name   = "Enable WAF"
    active = true
    behaviors = [
      {
        behavior = {
          type = "set_waf"
          attributes = {
            waf_id = azion_waf.waf.result.id
            mode   = "blocking"
          }
        }
      }
    ]
    criteria = [
      {
        entries = [
          {
            criterion = {
              variable    = "$${request_uri}"
              operator    = "starts_with"
              conditional = "if"
              argument    = "/"
            }
          }
        ]
      }
    ]
  }
}

# Create a network list
resource "azion_network_list" "allowlist" {
  results = {
    name = "allowlist-ips"
    type = "ip_cidr"
    items = [
      "192.0.2.0/24",
      "10.0.0.0/8",
    ]
  }
}
```

The `$${request_uri}` argument escapes the `$`, so Terraform passes the literal `${request_uri}` variable to the firewall instead of interpolating it.

## Complete example

This configuration pins the provider to version 2.10.0 and creates an application with a cache setting, a connector and a rule that sends requests to it, a firewall that applies a WAF, and a workload with a deployment that binds the application and the firewall to it. It outputs the IDs of the application, the workload, and the connector, and reads your personal token from the `api_token` variable that the [Azion Terraform Provider quickstart](/en/documentation/devtools/terraform/getting-started/) declares.

```hcl
terraform {
  required_providers {
    azion = {
      source  = "aziontech/azion"
      version = "2.10.0"
    }
  }
}

provider "azion" {
  api_token = var.api_token
}

# Application
resource "azion_application_main_setting" "app" {
  application = {
    name   = "my-application"
    active = true
    modules = {
      cache = {
        enabled = true
      }
    }
  }
}

# Cache setting
resource "azion_application_cache_setting" "cache" {
  application_id = azion_application_main_setting.app.application.application_id

  cache_setting = {
    name = "cache-default"
    browser_cache = {
      behavior = "honor"
    }
    modules = {
      cache = {
        behavior = "honor"
      }
    }
  }
}

# Connector
resource "azion_connector" "origin" {
  connector = {
    name   = "my-origin"
    type   = "http"
    active = true

    http_attributes = {
      addresses = [
        {
          endpoint = {
            address    = "origin.example.com"
            https_port = 443
          }
        }
      ]
      connection_options = {
        host             = "origin.example.com"
        transport_policy = "force_https"
      }
    }
  }
}

# Rule that sends every request to the connector
resource "azion_application_rule_engine" "origin" {
  application_id = azion_application_main_setting.app.application.application_id

  results = {
    name   = "Send requests to the origin"
    phase  = "request"
    active = true
    behaviors = [
      {
        behavior = {
          type = "set_connector"
          attributes = {
            value = azion_connector.origin.connector.id
          }
        }
      }
    ]
    criteria = [
      {
        entries = [
          {
            criterion = {
              variable    = "$${uri}"
              operator    = "starts_with"
              conditional = "if"
              argument    = "/"
            }
          }
        ]
      }
    ]
  }
}

# Firewall with the WAF module on
resource "azion_firewall_main_setting" "firewall" {
  data = {
    name   = "my-firewall"
    active = true
    modules = {
      waf = {
        enabled = true
      }
    }
  }
}

# WAF
resource "azion_waf" "waf" {
  result = {
    name   = "my-waf"
    active = true
  }
}

# Firewall rule that applies the WAF
resource "azion_firewall_rule_engine" "waf" {
  firewall_id = azion_firewall_main_setting.firewall.data.id

  results = {
    name   = "Enable WAF"
    active = true
    behaviors = [
      {
        behavior = {
          type = "set_waf"
          attributes = {
            waf_id = azion_waf.waf.result.id
            mode   = "blocking"
          }
        }
      }
    ]
    criteria = [
      {
        entries = [
          {
            criterion = {
              variable    = "$${request_uri}"
              operator    = "starts_with"
              conditional = "if"
              argument    = "/"
            }
          }
        ]
      }
    ]
  }
```
