The Azion CLI `profiles` command shows the profiles configured on your machine and switches the active one. A profile holds the personal token of one account, so several profiles let you work with several accounts or environments from the same machine. To create or delete a profile, use the commands on [Azion CLI profile](/en/documentation/devtools/cli/resources/profile/). The options every command accepts, such as `--debug` and `--timeout`, are on [Global options](/en/documentation/devtools/cli/globals/).

---

## Usage

`azion profiles` opens a selector with every profile you configured:

```bash
azion profiles [flags]
```

The command takes no flags of its own. `-h` or `--help` prints the help of the command.

The selector is interactive: move the cursor with the arrow keys and press Enter to choose a profile. The command needs a terminal to read your choice. Without one, as in a script, it prints the list and exits with `Error: EOF`. No command lists the profiles without a selector.

The selector always opens with the cursor on `default`, whichever profile is active. To see the active profile, run [`azion whoami`](/en/documentation/devtools/cli/whoami/), which prints it as `Active Profile`.

---

## Examples

This command opens the selector on a machine with two profiles, `default` and `my-profile`:

```bash
azion profiles
```

The command lists the profiles, with the cursor on `default`:

```text
? Choose a profile:  [Use arrows to move, type to filter]
> default
  my-profile
```

After you move the cursor to `my-profile` and press Enter, the command replaces the list with your choice and prints nothing else:

```text
? Choose a profile: my-profile
```

`my-profile` is then the active profile, and `~/.azion/profiles.json` names it:

```text
Name = 'my-profile'
```
