The Azion CLI `rollback` command makes a static site serve the files of an earlier deploy again. Those files stay in the [Object Storage](/en/documentation/platform/object-storage/) bucket of the project, and the command works through the storage [connector](/en/documentation/platform/connectors/) that delivers them. The options every command accepts, such as `--format`, `--out`, and `-y`, are on [Global options](/en/documentation/devtools/cli/globals/).

---

## Usage

`azion rollback` acts on the storage connector whose ID you pass:

```bash
azion rollback [flags]
```

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--config-dir` | — | string | `"azion"` | Relative path to the folder that holds your `azion.json` and `args.json` files. |
| `--connector-id` | — | int | — | ID of the storage connector that delivers the static files of the site. `azion deploy` writes this ID to the `connectors` entry of `azion/azion.json`. |
