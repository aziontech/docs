Azion CLI resource commands create, list, describe, update, and delete platform resources, take the form `azion <verb> <noun> [flags]`, and accept the options on [Global options](/en/documentation/devtools/cli/globals/).

## Behavior shared by resource commands

The Azion CLI resource commands work the same way in these cases:

- A command asks for any value it needs that you did not pass, such as a name or an ID, and fails when no terminal answers the question.
- Every resource delete command except `azion delete profile` deletes without asking for confirmation, with or without `-y`.
- `--file` reads the resource attributes from a JSON file, and an update through `--file` keeps the values of the fields the file leaves out, except on `connector`, which refuses a partial file.
- `--active` on `dns-zone` and `--enabled` on `dnssec`, which help lists without a type, take their value after `=`, as in `--active=false`, since the space form changes nothing.
- With the [global options](/en/documentation/devtools/cli/globals/) `--format json` and `--out <path>`, a describe command prints the full object or writes the same JSON to a file, and `--out` needs no `--format`.
