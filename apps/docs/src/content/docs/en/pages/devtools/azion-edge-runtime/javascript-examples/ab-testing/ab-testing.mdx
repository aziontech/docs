Serve one of two responses from a function on Azion's global network, choosing the group at random and recording it in a cookie. Use this pattern to run randomized experiments, such as comparing two page variants, without sending traffic to an origin to decide which version to show.

```js
function handleRequest(request) {
  const NAME = "ab-group"
  const cookie = request.headers.get("cookie")

  if (cookie && cookie.includes(`${NAME}=test`)) {
    return new Response("Test group")
  }
  if (cookie && cookie.includes(`${NAME}=control`)) {
    return new Response("Control group")
  }

  const group = Math.random() < 0.5 ? "test" : "control"
  const response = new Response(group === "test" ? "Test group" : "Control group")
  response.headers.append("Set-Cookie", `${NAME}=${group}; path=/`)

  return response
}

addEventListener("fetch", event => {
  event.respondWith(handleRequest(event.request))
})
```

## How it works

The `fetch` handler reads the incoming `Cookie` header with `request.headers.get("cookie")`. When the header contains `ab-group=test`, the function returns the test response, and when it contains `ab-group=control`, it returns the control response. When neither is present, `Math.random()` picks the test or control group at roughly 50/50, and `response.headers.append("Set-Cookie", ...)` writes the chosen group into the `ab-group` cookie. The browser sends that cookie on the next request, so the visitor stays in the same group. `event.respondWith()` then returns that `Response` to the client.
