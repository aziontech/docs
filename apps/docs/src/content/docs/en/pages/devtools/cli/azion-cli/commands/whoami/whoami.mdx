The Azion CLI `whoami` command prints the client ID, the email, and the active profile that the CLI stores for your Azion account. Use it to check which account the CLI is set up for when you work with more than one Azion account on the same machine. The options every command accepts, such as `--config` and `--debug`, are on [Global options](/en/documentation/devtools/cli/globals/).

---

## Usage

`azion whoami` reads the account details from the local CLI configuration and prints them:

```bash
azion whoami [flags]
```

The command takes no flags of its own. `-h` or `--help` prints the help text of the command.

When the CLI holds no logged-in account, for example after `azion reset`, the command stops with `Error: You must be logged in to use the 'whoami' command`. Run `azion login` first to authenticate the CLI.

The profile configuration stores the client ID and the email. `azion logout` empties only the stored [personal token](/en/documentation/fundamentals/personal-tokens/), so after a logout `azion whoami` still prints the same client ID and email.

---

## Examples

This command shows the account the CLI is logged in with:

```bash
azion whoami
```

The command prints the client ID, the email, and the active profile, one per line:

```text
 Client ID: 1234u
 Email: you@example.com
 Active Profile: default
```
