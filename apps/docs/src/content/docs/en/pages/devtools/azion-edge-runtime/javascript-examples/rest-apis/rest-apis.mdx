Make outbound HTTP requests from a function using the `fetch` API, covering the GET, DELETE, POST, PUT, and PATCH methods with JSON data. Use these snippets when your function needs to call a REST API, whether to read data, submit a form, or update a resource, while running close to the user on Azion's global network.

## Examples

### Get

This function reads the list of items from the API and returns it to the client as JSON:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const response = await fetch(API_URL, {
      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
    });

    if (!response.ok) {
      return new Response(`Upstream error: ${response.status}`, { status: 502 });
    }

    const items = await response.json();
    return new Response(JSON.stringify(items), {
      headers: { "Content-Type": "application/json" },
    });
  },
};
```

### Delete

This function deletes the item `42` and returns the status the API answers with:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const id = "42";
    const response = await fetch(`${API_URL}/${id}`, {
      method: "DELETE",
      headers: {
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
    });

    return new Response(null, { status: response.status });
  },
};
```

### Post

This function creates an item from a JSON body and returns the response of the API:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const item = { name: "Notebook", price: 25 };
    const response = await fetch(API_URL, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
      body: JSON.stringify(item),
    });

    return new Response(await response.text(), {
      status: response.status,
      headers: { "Content-Type": "application/json" },
    });
  },
};
```

### Put

This function replaces the item `42` with a new JSON body:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const id = "42";
    const item = { name: "Notebook", price: 30 };
    const response = await fetch(`${API_URL}/${id}`, {
      method: "PUT",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
      body: JSON.stringify(item),
    });

    return new Response(await response.text(), {
      status: response.status,
      headers: { "Content-Type": "application/json" },
    });
  },
};
```

### Patch

This function changes only the `price` field of the item `42`:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const id = "42";
    const changes = { price: 28 };
    const response = await fetch(`${API_URL}/${id}`, {
      method: "PATCH",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
      body: JSON.stringify(changes),
    });

    return new Response(await response.text(), {
      status: response.status,
      headers: { "Content-Type": "application/json" },
    });
  },
};
```

## How it works

Each example is a complete function in the ES Modules pattern. The `fetch` handler calls `fetch()` with the URL of the API and an options object: `method` selects the HTTP verb, `headers` carries the `Content-Type` and the authorization token, and `body` carries the JSON string that `JSON.stringify()` produces. The token comes from the `API_TOKEN` [environment variable](/en/documentation/devtools/runtime/api-reference/environment-variables/) through `Azion.env.get()`, so it stays out of the code. `await fetch()` resolves to a `Response`. The GET example reads it with `response.json()`, and the other examples return the status and body of the API to the client. Replace `https://api.example.com/items` and the sample values with the ones of your API.
