The Azion CLI `logout` command logs you out of your Azion account and removes the [personal token](/en/documentation/fundamentals/personal-tokens/) that `azion login` saved locally. Use it to end your session, or before you log in with a different account on the same machine. The options every command accepts, such as `--config` and `--debug`, are on [Global options](/en/documentation/devtools/cli/globals/).

---

## Usage

`azion logout` removes the personal token of the active profile:

```bash
azion logout [flags]
```

The command takes no flags of its own. `-h` or `--help` prints the help of the command.

After you log out, a command that needs authentication works again only after you run `azion login`.

---

## Examples

This command logs out of the active profile:

```bash
azion logout
```

The command confirms the logout:

```text
successfully logged out
```

The command empties the stored personal token. The profile keeps its client ID and email.
