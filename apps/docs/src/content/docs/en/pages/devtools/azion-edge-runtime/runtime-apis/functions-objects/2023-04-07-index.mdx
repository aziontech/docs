Azion Runtime gives every function a set of global names that the code uses without an import: JavaScript built-ins, Web APIs, the Azion APIs, and some Node.js globals. The lists on this page are the names the deployed runtime exposes, grouped by the type `typeof` returns for each. `self` and `globalThis` are the same object.

:::note
Under `azion dev`, `caches`, `upgradeWebSocket`, `WebSocket`, and `CustomEvent` are not defined, and `globalThis.dispatchEvent` is not a function. `queueMicrotask` is defined locally but not deployed. `EdgeRuntime` holds `"edge-runtime"`, and `Date.now()` advances during a request.
:::

## Objects

These globals are objects, so `typeof` returns `object` for each of them:

- globalThis
- JSON
- Math
- Intl
- Reflect
- console
- crypto
- self
- Atomics
- WebAssembly
- performance
- caches: the `CacheStorage` instance of the [Cache API](/en/documentation/devtools/runtime/api-reference/cache/).
- process: the Node.js `process` object. Its `process.env` holds the environment variables of the account. For more information, refer to [node:process](/en/documentation/devtools/runtime/node/process/).
- Azion: the namespace of the Azion APIs, which reach [environment variables](/en/documentation/devtools/runtime/api-reference/environment-variables/), [network lists](/en/documentation/devtools/runtime/api-reference/network-list/), [Object Storage](/en/documentation/devtools/runtime/api-reference/storage/), [SQL Database](/en/documentation/devtools/runtime/api-reference/sql-database/), [KV Store](/en/documentation/devtools/runtime/api-reference/kv-store/), and [AI Inference](/en/documentation/devtools/runtime/api-reference/ai/).

## Time inside a request

In a deployed function, `Date.now()` returns the same value for the whole request. It does not advance across a loop, a timer, or a `fetch()` call, and its milliseconds read `0`. To measure elapsed time inside a request, use `performance.now()`: it advances during the request and starts at `0`.
