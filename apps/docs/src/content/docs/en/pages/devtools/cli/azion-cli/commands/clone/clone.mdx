The Azion CLI `clone` command copies a resource under a new name. Its one subcommand, `application`, creates an [Application](/en/documentation/platform/applications/) with the configuration of an existing one, its [Rules Engine](/en/documentation/platform/applications/rules-engine/) rules included. The options every command accepts, such as `--format`, `--out`, and `-y`, are on [Global options](/en/documentation/devtools/cli/globals/).

---

## Usage

`azion clone` takes the type of the resource to copy as its subcommand:

```bash
azion clone <subcommand> [flags]
```

The command takes no flags of its own. `-h` or `--help` prints the help of the command. The only subcommand is `application`.

---

## Application

`azion clone application` creates an application from the configuration of the application whose ID you pass:

```bash
azion clone application [flags]
```

| Flag | Short | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `--application-id` | — | int | — | ID of the application to copy. |
| `--name` | — | string | — | **Required**. Name of the new application. Without it, the command asks for the name. |

The command prints the name of the new application, not its ID. To find the ID, run `azion list application`. Your account needs permission to clone applications.

---

## Examples

Each example shows the command and the output it prints.

### Clone an application

This command copies the application with ID `1791039175` into a new application named `my-site-clone`:

```bash
azion clone application --application-id 1791039175 --name my-site-clone
```

The command confirms the copy:

```text
Application my-site-clone cloned successfully
```

### Find the ID of the clone

This command lists the applications whose name contains `my-site`:

```bash
azion list application | grep -E 'ID|my-site'
```

The clone appears with an ID of its own, next to the application it was copied from:

```text
ID          NAME             ACTIVE
1791039175  my-site          true
1791049178  my-site-clone    true
```

### Check the rules of the clone

This command lists the rules of the clone in the request phase:

```bash
azion list rules-engine --application-id 1791049178 --phase request
```

The clone holds the rules of the application it was copied from:

```text
ID      NAME
742326  Deliver Static Assets and Set Cache Policy
742324  Redirect to index.html
742325  Redirect to index.html for Subpaths
```
