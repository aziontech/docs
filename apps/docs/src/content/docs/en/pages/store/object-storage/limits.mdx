[Object Storage](/en/documentation/platform/object-storage/) bounds the name of a bucket, the key of an object, and the number of records that one list request returns. It also bounds the number of buckets and access keys that one account holds. This page states where Object Storage stops, each bound, and what the platform does past it. To request a higher limit for the account, contact the [technical support](/en/documentation/support/) team.

---

## Scope

- **Delivery to your users**: the [Terms of Service](/en/documentation/agreements/tos/) say that objects should reach your users through an Application, and they subject direct access, outside an Application, to rate limits. An Application serves objects through a rule that sets a Connector of type `storage` or runs a Function, as the [Object Storage overview](/en/documentation/platform/object-storage/#request-path) shows. The Azion API and the S3 endpoint refuse requests without credentials with `401`, but a presigned S3 URL delivers an object to whoever holds it.
- **Bucket listing**: a request for `/` that reaches a Connector with no prefix returns an XML list of the object keys in the bucket, with no credentials. `?prefix=` filters that list. A rule in [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/) that matches `${uri}` equal to `/` and redirects it, for example to `/index.html`, answers with the redirect instead.
- **Writes through an Application**: the access level of a bucket decides what a Connector and a Function can do with its objects. On a `read_write` bucket, a `DELETE` request that reaches the Connector deletes the object, while `PUT` gets `403` and `POST` gets `501`. Keep `read_only` on a bucket that a Connector serves. A bucket that a Function writes to needs `read_write`, so point no Connector at it.
- **Writes outside an Application**: the access level does not restrict the Azion API or the S3 protocol. A personal token, or a credential with the `writeFiles` capability, writes to a bucket at every level, `restricted` included.
- **Buckets through S3**: the S3 endpoint manages objects, not buckets, and it refuses `CreateBucket` and `DeleteBucket` with `403` `AccessDenied`. Create and delete buckets in Azion Console, the Azion API, the Azion CLI, or the Terraform Provider. [S3 compatibility](/en/documentation/platform/object-storage/s3-compatibility/#supported-operations) lists the operations Azion supports.
- **Versions**: a write to a key replaces the object that the Azion API returns, and you cannot turn versioning on. An Application returns the new object once it holds no cached copy of the old one. Through the S3 protocol, `ListObjectVersions` still lists an earlier version or a deleted object, and `GetObject` reads it by its version ID. That copy stays for a period you cannot set, so keep your own copy of a version you may need back.
- **Queries**: the Azion API and the S3 endpoint read an object by its key or list the keys under a prefix. Neither has an operation that searches the content or the metadata of objects. Store relational data in [SQL Database](/en/documentation/platform/sql-database/) and key-value pairs in [KV Store](/en/documentation/platform/kv-store/).
- **Durability**: Azion makes commercially reasonable efforts to keep your objects available and durable, and the [Terms of Service](/en/documentation/agreements/tos/) give no guarantee against data loss. Keep your own copy of the data you cannot lose.

## Default limits

Object Storage applies each bound below by default. Past a bound, the Azion API answers HTTP `400` with the error code and title in its row, unless the row says otherwise.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Bucket name length (`name`) | 6 to 63 characters | `10048` `Min Length` below 6 characters, and `10046` `Max Length` past 63. |
| Bucket name characters | Lowercase letters, numbers, and the hyphen (`-`) | `17002` `Invalid Bucket Name` for an uppercase letter or an underscore (`_`). |
| First and last characters of a bucket name | A lowercase letter or a number | `17002` `Invalid Bucket Name` for a hyphen. |
| Bucket name prefixes and suffixes | Never begins with `azion`, `xn--`, `sthree-`, or `amzn-s3-demo-`, or ends with `-s3alias` or `--ol-s3` | `17001` `Bucket Name Not Available`. |
| Bucket name uniqueness | One name across every Azion account | `17000` `Bucket Already Exists`. |
| Object key length (`object_key`) | 1 to 1,024 characters | `503` `10100` `Service Unavailable` past 1,024 characters. Shorten the key. |
| Single upload through Azion Console | 300 MB | Azion Console refuses the file: "Files larger than 300 MB cannot be uploaded." |
| Buckets per list response (`page_size`) | 100 buckets | `10097` `Invalid Page Size` past 100. Read the rest of the list with `page`. |
| Objects per list response (`max_object_count`) | 1,000 keys | The response carries a `continuation_token`. Send it back to read the next page. |
| Bucket deletion | Blocked while the bucket holds objects, and for 24 hours after the last object is removed | `17006` `Cannot Delete Non Empty Bucket`. |
| Deletion of a referenced bucket | Blocked while a Connector references the bucket | `409` `17016` `Cannot Delete Referenced Bucket`, whose `detail` names the Connector and its ID. |
| Region | `us-east-005` | The region cannot be selected: the Azion API ignores a `region` field. |

Two more bounds apply to each account: 100 buckets and 100,000 S3 credential access keys.
