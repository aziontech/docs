Definitions for the terms the **Connectors** documentation uses.

| Term | Definition |
| --- | --- |
| address | The IPv4 address, IPv6 address, or hostname of a server that a Connector of type `http` reaches, written without protocol or port. A Connector holds one address, or up to 15 with Load Balancer on, and each address carries its own `http_port` and `https_port`. [Connector settings](/en/documentation/platform/connectors/settings/#addresses) lists every address field. |
| Azion Origin Shield list | The [network list](/en/documentation/platform/firewall/network-shield/network-lists/) named `Azion Origin Shield`, which holds the IPv4 and IPv6 prefixes that Azion's infrastructure uses to connect to origins. With Origin IP ACL, your origin's firewall allows only these prefixes, and you keep that allowlist updated as the list changes. To apply it at your origin, refer to [Allow Azion's IP ranges at your origin](/en/documentation/support/retrieve-azion-ip-ranges/). |
| balancing method | The method Load Balancer uses to pick the address of a Connector for each request. **Method** in Azion Console and `method` in the API take _Round Robin_ (`round_robin`, the default), _Least Connections_ (`least_conn`), or _IP Hash_ (`ip_hash`). [Balancing methods](/en/documentation/platform/connectors/load-balancer/balancing-methods/#balancing-method) describes how each method chooses. |
| Connector | The entity you create in [Connectors](/en/documentation/platform/connectors/), the Platform Resource that routes requests from your Applications to the [origins](https://www.azion.com/en/learning/cdn/what-is-an-origin-server/) that hold your content. A Connector is the upstream of a [reverse proxy](https://www.azion.com/en/learning/performance/what-is-a-reverse-proxy/): where your content is, and how each request reaches it. An Application rule with the _Set Connector_ behavior sets one Connector by its ID, so several Applications can share it. |
| Connector type | The kind of origin a Connector reaches: `http` for servers you run, `storage` for an [Object Storage](/en/documentation/platform/object-storage/) bucket, or `live_ingest` for [Live Ingest](/en/documentation/platform/connectors/live-ingest/). **Connector Type** in Azion Console offers it as the cards _HTTP_, _Object Storage_, and _Live Ingest_, and `type` in the API carries it. [Connector settings](/en/documentation/platform/connectors/settings/#general) lists the fields each type takes. |
| HMAC | A Feature of Origin Shield that [signs each request to the origin](/en/documentation/platform/connectors/origin-shield/origin-ip-acl-and-hmac/#hmac-authentication) with a hash-based message authentication code, so a private S3-compatible bucket accepts it. It uses `aws4_hmac_sha256` and one set of credentials from your object storage provider for every address: **Region**, **Service**, **Access Key**, and **Secret Key** in Azion Console. Turning it off removes the stored credentials, and [Sign origin requests with HMAC](/en/documentation/guides/application-development/getting-started/sign-origin-requests-with-hmac/) sets it up. |
| Host header | The HTTP header the origin reads to select which of its sites, called virtual hosts, serves a request. **Host** in Azion Console and `host` in the API default to `${host}`, the host the client requested, and the Connector sends any other value as written. [Host header](/en/documentation/platform/connectors/how-it-works/#host-header) explains the mechanism, and [Set the Host header and path prefix for an origin](/en/documentation/guides/application-development/getting-started/set-the-host-header-and-path-prefix/) shows when to send the origin's own name. |
| Live Ingest | A Platform Resource nested in Connectors that takes in the live stream your encoder pushes over Real-Time Messaging Protocol (RTMP). A Connector of type `live_ingest` sets the region that receives the stream, and an Application delivers the stream to viewers through that Connector. [Live Ingest](/en/documentation/platform/connectors/live-ingest/) describes it, and [Ingestion and delivery](/en/documentation/platform/connectors/live-ingest/ingestion-and-delivery/) explains how it works. |
| Load Balancer | A Platform Resource nested in Connectors that balances requests across the addresses of a Connector of type `http`, a practice called [load balancing](https://www.azion.com/en/learning/performance/what-is-load-balancing/). You turn it on, for up to 15 addresses, with the **Load Balancer** switch in Azion Console or `attributes.modules.load_balancer.enabled` in the API. [Load Balancer](/en/documentation/platform/connectors/load-balancer/) describes it, and the [Load Balancer quickstart](/en/documentation/platform/connectors/load-balancer/quickstart/) balances a first Connector. |
| Origin IP ACL | A Feature of Origin Shield that gives your account the Azion Origin Shield list, so your origin's firewall can accept connections from Azion's addresses alone. **Origin IP ACL** in Azion Console and `attributes.modules.origin_shield.config.origin_ip_acl.enabled` in the API turn it on, and it is off by default. [Origin IP ACL and HMAC](/en/documentation/platform/connectors/origin-shield/origin-ip-acl-and-hmac/#origin-ip-acl) explains the mechanism. |
| Origin Shield | A Platform Resource nested in Connectors that lets your origin accept only the requests a Connector sends from Azion, by their source address (Origin IP ACL), their signature (HMAC), or both. You turn [Origin Shield](/en/documentation/platform/connectors/origin-shield/) on in a Connector of type `http`, with the **Origin Shield** switch in Azion Console or `attributes.modules.origin_shield.enabled` in the API. The cache layer that some providers call an origin shield is [Tiered Cache](/en/documentation/platform/applications/cache/tiered-cache/), a Feature of Cache. |
| path prefix | The path a Connector of type `http` adds in front of each requested path: **Path** in Azion Console, `path_prefix` in the API. It starts with `/` and is empty by default, and with `/anything`, a request for `/get` reaches the origin as `/anything/get`. [Path prefix](/en/documentation/platform/connectors/how-it-works/#path-prefix) explains its effect, and [Connector settings](/en/documentation/platform/connectors/settings/#connection-options) lists its bounds. |
| server role | The role of an address of a Connector with Load Balancer on: _Primary_ (`primary`, the default when the address's `modules.load_balancer` leaves `server_role` out) or _Backup_ (`backup`). A backup address receives requests only when every primary address fails, and the _IP Hash_ method refuses backup addresses with `28005`. **Server Role** in Azion Console and `server_role` in the API set it, as [Server role](/en/documentation/platform/connectors/load-balancer/balancing-methods/#server-role) describes. |
| Set Connector | The behavior of an Application rule that sets the Connector for the requests the rule matches: _Set Connector_ in Azion Console, `set_connector` in the API. The rule sets the Connector by its ID in `attributes.value`, and when several matching rules carry the behavior, only the last one runs. [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/) documents the behavior. |
| SNI Check | A Feature of the Azion Platform that answers an HTTPS request to a Workload with `421 Misdirected Request` when the Workload's certificate does not cover the request's host and enforcement is on. It reads the Server Name Indication (SNI) and the `Host` header of the request before any Application or Connector runs. Enforcement has no setting in Azion Console or the API, so Azion Support turns it on, and [SNI Check](/en/documentation/platform/connectors/sni-check/) describes each check. |
| weight | The share of requests an address receives against the other addresses of its Connector with Load Balancer on, a whole number from 1 to 100. **Weight** in Azion Console and `weight` in the API default to `1`, and a higher weight allocates more traffic to the address. [Weight](/en/documentation/platform/connectors/load-balancer/balancing-methods/#weight) describes how it changes the choice. |
