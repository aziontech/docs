A [Firewall](/en/documentation/platform/firewall/) holds [rules](/en/documentation/platform/firewall/rules-engine/) and [Function Instances](/en/documentation/platform/firewall/functions-instances/). Each nested Platform Resource adds entities of its own: [Web Application Firewall (WAF)](/en/documentation/platform/firewall/waf/) adds [rule sets](/en/documentation/platform/firewall/waf/rules-set/) and [exceptions](/en/documentation/platform/firewall/waf/custom-allowed-rules/), and [Network Shield](/en/documentation/platform/firewall/network-shield/) adds [Network Lists](/en/documentation/platform/firewall/network-shield/network-lists/). [Bot Manager](/en/documentation/platform/firewall/bot-manager/) runs as a Function Instance. This page states where a Firewall's scope ends, the bound Azion applies to each of those entities, and the answer a call receives past it.

The two kinds of value are different things. A default limit is checked on every call, and the call fails past it. An included amount is a billing quantity, and passing it changes what the account is charged rather than what the call returns. For the amounts each plan includes, such as Firewall requests and rules per Firewall, refer to [Azion pricing](https://www.azion.com/en/pricing/).

## Scope

- **Nested resources to turn on**: a Firewall accepts rules only while at least one of WAF, Network Shield, or Functions is on. With all three off, the API refuses every rule with `25047`, even a _Deny (403 Forbidden)_ rule on _Host_. A Firewall created with only a name starts with Network Shield and Functions on and WAF off, as [How Firewall works](/en/documentation/platform/firewall/how-it-works/#nested-resources-and-switches-on-a-firewall) shows.
- **Criteria that need a nested resource**: the _Network_ criterion needs Network Shield, and the header criteria and _Request Method_ need WAF. The API refuses a rule that uses one of them while its resource is off, with `25047`. For the resource each criterion and behavior needs, refer to [Rules Engine for Firewall](/en/documentation/platform/firewall/rules-engine/#criteria).
- **WAF inspection**: in tests, WAF inspected no request on an Application with no [Connector](/en/documentation/platform/connectors/). On an Application that sent its other paths to a Connector, WAF also inspected and blocked a request that a Function answered. A WAF test against an Application with no Connector shows no block, as [Scoring and modes](/en/documentation/platform/firewall/waf/scoring-and-modes/) explains.
- **DDoS Protection**: [DDoS Protection](/en/documentation/platform/workloads/ddos-protection/ddos-mitigation/) mitigates denial-of-service attacks on every Workload, ahead of the Firewall, with no configuration. A Firewall shows it as the **DDoS Protection Unmetered** switch, which carries the tag **Automatically enabled in all accounts** and cannot be turned off. For a defense against one specific attack, add rules to the Firewall.
- **Shared Firewalls**: the deployments of several Workloads can set the same Firewall, and a change to its rules then reaches all of them. Each rule belongs to the one Firewall it was created on. To give one Workload a different policy, clone the Firewall with **Clone** in the **Firewalls** list or with `POST /v4/workspace/firewalls/<firewall-id>/clone`: the copy carries the rules, in the same order, and the Function Instances with their arguments. For when to share a Firewall, refer to [Best practices for Firewall](/en/documentation/platform/firewall/best-practices/#share-one-firewall-among-workloads-with-the-same-security-policy).
- **Deletion**: the API refuses to delete a Firewall while a Workload's deployment still sets it, with `24003`, and the message lists those Workloads. Change their deployments first, as [Troubleshoot Firewall](/en/documentation/platform/firewall/troubleshooting/#a-firewall-is-refused-with-cannot-delete-firewall) shows.
- **Third-party bot protection**: [Radware Bot Manager](/en/documentation/guides/application-development/integrations/radware-bot-manager/) and [DataDome Bot Protection](/en/documentation/guides/application-development/integrations/datadome-bot-protection/) install from Azion Marketplace as Functions that a Firewall runs. Each one needs a key from its vendor, which its Function Instance takes as an argument, as its guide shows.
- **Observability**: no response header names the Firewall or the rule that decided. To find which rules a request ran, turn on the Firewall's **Debug Rules** setting, which is off when you create a Firewall, as [How Firewall works](/en/documentation/platform/firewall/how-it-works/#observability) shows.

## Rules and Function Instances

A Firewall holds its rules in Rules Engine, and a rule's _Run Function_ behavior runs a Function Instance, which pairs a Function with its arguments. The bounds in this section apply to the rules and Function Instances of every Firewall, whichever of WAF, Network Shield, and Functions it has on.

### Default limits

Each row names what is bounded, the bound, and what a call past it receives.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Rule `name` | 1 to 100 characters | `400` `10046 Max Length`, `Ensure this field has no more than 100 characters.` |
| Rule `description` | Up to 1,000 characters | `400` `10046 Max Length`. Azion Console shows `Description should not exceed 1000 characters`. |
| Criteria groups per rule | 1 to 5 | `400` `10065 List Field Max Length` past 5, and `10049 Min Length List Field` for none. Azion Console disables **Add Criteria** at 5 groups. |
| Criteria per group | 1 to 10 | `400` `10065 List Field Max Length` past 10. Azion Console disables **And** and **Or** at 10 criteria in a group. |
| Behaviors per rule | 1 to 10 | `400` `10065 List Field Max Length` past 10, and `10049 Min Length List Field` for none. |
| **Average Rate Limit** on a _Set Rate Limit_ behavior | At least 1 | `400` `10050 Min Value`. Azion Console refuses a lower value. |
| **Maximum Burst Size** on a _Set Rate Limit_ behavior | At least 1, with the _Req/s_ type only | `400` `10050 Min Value` below 1, `25035 Required Rate Limit Parameter` when it is missing with _Req/s_, and `25034 Invalid Rate Limit Parameter` when it is sent with _Req/min_. Azion Console refuses a lower value, and it does not send the field with the _Req/min_ type. |
| Function Instance `name` | Up to 100 characters | `400` `10046 Max Length`, `Ensure this field has no more than 100 characters.` |
| Arguments payload, the JSON object or array a Function Instance carries | 100,000 bytes | `400` `23000 JSON Args Size Too Big`, `Value size (in bytes) is too big. Maximum size allowed is 100000 bytes.` |
| Azion API requests | 200 per minute, on the `global-default` scope | A response carries `x-ratelimit-limit`, `x-ratelimit-remaining`, `x-ratelimit-reset`, and `x-ratelimit-scope`, which report the allowance left in the window and the time it resets. |

One further bound applies: a **Debug Rules** log carries 1.5 kB.

A Firewall carries no list of domains. A Workload's deployment sets the Firewall that inspects the Workload's requests, so the number of domains is not a bound of the Firewall. The bound of 200 domains belongs to API v3. There, a Firewall lists the domains it protects in its `domains` array, and it takes up to 200 of them.

The arguments payload bound is decimal: 100 KB means 100,000 bytes, not 100 KiB, so a payload of 102,400 bytes is refused. An object with one key, sent as compact JSON, is refused at 100,000 bytes and accepted at 99,999 bytes.

Azion can raise the arguments payload bound, and the other default limits of a Function on a Firewall, on request, based on your plan. To request an increase, contact the [technical support](/en/documentation/support/) team.

The API checks the arguments for size and type only: a value that is not a JSON object or array is refused with `23001`. Every key an instance sends is stored and returned as sent, whatever its name. For example, a misspelled argument passes the call, and the Function never reads it.

The number of Function Instances a Firewall carries is not bounded. The count a Firewall reaches is an operational choice rather than a value the platform checks.

A Function that runs on a Firewall shares the memory, environment variable, sub-request, and CPU time limits of every Function. Those limits and the size of the Function code belong to the Function rather than to the Firewall. For the values, refer to [Functions limits](/en/documentation/platform/functions/limits/).

The rate limit is the value that the response headers advertise. A response from the Azion API carries `x-ratelimit-limit: 200`, `x-ratelimit-scope: global-default`, and an `x-ratelimit-reset` timestamp about 60 seconds after the call. `x-ratelimit-remaining` stays a few calls below the limit, and it does not count down during a burst of calls within a minute. The answer to a call past 200 calls in one minute was not observed.

A call that the API accepts is not in effect at once. A new rule, or a Workload whose deployment newly sets a Firewall, can take several minutes to reach traffic, and no duration is guaranteed. While a change propagates, successive requests can get the previous answer and the new one in turn, so repeat the request until it answers as expected. For how a change reaches traffic, refer to [How Firewall works](/en/documentation/platform/firewall/how-it-works/).

Firewall meters every request that passes through a Firewall, including the requests that a Network Shield rule evaluates. For the rate, refer to [Pricing](/en/documentation/fundamentals/pricing/#firewall).

## WAF

WAF bounds the name a rule set takes, the conditions an exception carries, the size of the request body it inspects, and what one list request returns.

### Default limits

WAF applies each bound in this table on every service plan. The API answers a rejected call with a numeric `code`, a `title`, a `detail`, and a `source` pointer naming the field that failed. The Past the limit column carries the status, the code and title, and the text that arrives with them.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Rule set `name` | Up to 250 characters | `400` `10046 Max Length`, `Ensure this field has no more than 250 characters.` |
| Exception `name` | Up to 255 characters | `400` `10046 Max Length`, `Ensure this field has no more than 255 characters.` |
| Exception condition `name` and `value` | 1 to 255 characters | An empty value returns `400` `10018 Blank Field`, `This field may not be blank.` A longer one returns `400` `10046 Max Length`, `Ensure this field has no more than 255 characters.` |
| Conditions per exception | At least 1, with one `specific_*` condition at most | An empty array returns `400` `10049 Min Length List Field`, `Ensure this field has at least 1 elements.` A second `specific_*` condition returns `400` `26004 Only One 'specific' Match Condition Is Allowed Per WAF Exception.` |
| Records per list response (`page_size`) | 100 maximum, default 10 | `400` `10097 Invalid Page Size`, `Page size must be between 0 and 100.` |
| Azion API requests | 200 per minute, on the `global-default` scope | A response carries `x-ratelimit-limit`, `x-ratelimit-remaining`, `x-ratelimit-reset`, and `x-ratelimit-scope`, which report the allowance left in the window and the time it resets. |
| `thresholds` entries on a rule set | Up to 8, one per threat family | Nine entries, or a repeated `threat`, return `500` `10067 Internal Server Error`, `A server error occurred.` |
| `operator` on an exception | `contains` or `regex`, default `contains` | `400` `10039 Invalid Choice` |
| `mode` on a `set_waf` behavior | `logging` or `blocking`, and required | An unlisted value, such as `learning`, returns `400` `10039 Invalid Choice`. A missing `mode` returns `400` `10059 Required Field`, `This field is required.` |
| Request body WAF inspects | 131,072 bytes, which is 128 KiB | In `blocking` mode, `400` and Azion's default error page, not a `413`. In `logging` mode, the request passes and is recorded. |
| WAF Tuning query window | 3 days | Azion Console offers no longer range. |

WAF parses a `POST` body when its `Content-Type` is `application/x-www-form-urlencoded`, `multipart/form-data`, `application/json`, or `application/csp-report`. In tests, an `application/vnd.api+json` body was not parsed, as [Scoring and modes](/en/documentation/platform/firewall/waf/scoring-and-modes/) describes. The body bound counts the body alone, without the request line and headers.

With `Content-Type: application/x-www-form-urlencoded` and a body that carries no attack pattern, a body of 131,072 bytes returns `200`, and a body of 131,073 bytes returns `400`. The event recorded for the refused request names rule `2` in the `BODY` zone, as `wafMatch` `0:2:BODY:-`, with `wafAttackFamily` `$OTHERS`. Rule `2` tests the size rather than adding to a score, so the bound holds at every sensitivity: a 170 KB body is refused at the default `medium` too. The event's `requestLength` also counts the request line and headers, so it reads higher than the body size: `131148` for a body of 131,073 bytes. The same body sent as `application/json` or `text/plain` is refused at both sizes, because rules `15` and `11` match the request before the size check. To test this boundary, send `application/x-www-form-urlencoded` or `multipart/form-data`.

The `500` that nine entries or a repeated `threat` return is a validation failure rather than a fault in the service. Send each of the eight threat families at most once in `thresholds`.

For the fields these bounds apply to, refer to [Rule sets](/en/documentation/platform/firewall/waf/rules-set/) and [Exceptions](/en/documentation/platform/firewall/waf/custom-allowed-rules/).

A create request past the number of rule sets or exceptions a plan includes is accepted. The count an account reaches is a cost to watch, not a rejection to handle. For the rates of WAF's billing metrics, refer to [Pricing](/en/documentation/fundamentals/pricing/#web-application-firewall).

## Network Shield

Network Shield lets a rule use a Network List through the _Network_ criterion, which matches the client address of a request against the list. The Azion API bounds the size of a Network List, its items, and its name, the records per list response, and the rate of calls.

Network Shield has no billing metric of its own, as [Pricing](/en/documentation/fundamentals/pricing/#network-shield) shows. A rule that uses the _Network_ criterion is a Firewall rule, so it counts toward the rules per Firewall that each plan includes. Firewall also meters the requests it evaluates.

### Default limits

The Azion API applies each bound in this table by default. A call past a Network List bound is refused with a `400` status and an `errors` array. Each entry carries a `code`, a `title`, a `detail`, and a `source` pointer naming the field that failed.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Items per Network List | Up to 20,000 items | `400` `10065 List Field Max Length`, `Ensure this field has no more than 20000 elements.` |
| Items per Network List, minimum | At least 1 item | `400` `10049 Min Length List Field`, `Ensure this field has at least 1 elements.` |
| Characters per item, annotations included | Up to 250 characters | `400` `10046 Max Length`, `Ensure this field has no more than 250 characters.` |
| Characters per list `name` | Up to 250 characters | `400` `10046 Max Length`, `Ensure this field has no more than 250 characters.` |
| Records per list response (`page_size`) | 100 maximum, default 10 | `400` `10097 Invalid Page Size`, `Page size must be between 0 and 100.` |
| Azion API requests | 200 per minute, on the `global-default` scope | A response carries `x-ratelimit-limit`, `x-ratelimit-remaining`, `x-ratelimit-reset`, and `x-ratelimit-scope`, which report the allowance left in the window and the time it resets. |

The item ceiling is exact, and it applies to the items of an IP/CIDR list and of an ASN list alike. A create call with 20,000 items returns `201`, and the same call with 20,001 items returns this body:

```json
{
  "errors": [
    {
      "code": "10065",
      "title": "List Field Max Length",
      "detail": "Ensure this field has no more than 20000 elements.",
      "status": "400",
      "source": { "pointer": "/data/items" }
    }
  ]
}
```

An item's 250 characters include its annotations: the `--LT` expiration date and the `#` comment that an `ip_cidr` item can carry. For example, an `ip_cidr` item of exactly 250 characters, an address followed by a space and a `#` comment, is stored verbatim. For the item formats and annotations of each list type, refer to [Network Lists](/en/documentation/platform/firewall/network-shield/network-lists/).

When a call sets no `page_size`, the list endpoint returns 10 records per page. A `page_size` of `0` is refused with the same `10097` message, although the message names 0 as allowed.

The 20,000-item ceiling is a default limit, and Azion can raise it on request, based on the plan. To request an increase, contact the [technical support](/en/documentation/support/) team.

A change to a list's items is not in effect at once. It reaches traffic up to a few minutes after the call (observed: 41 s to 156 s), and until it settles, requests receive the previous answer and the new one in turn.

## Bot Manager

Bot Manager runs on a Firewall as a Function Instance, which a rule's _Run Function_ behavior runs. The Function Instance bounds of every Firewall apply to it. Two more bounds apply to the surfaces around it: the report log and the GraphQL datasets.

### Default limits

A call past the Function Instance `name` or the arguments payload bound returns `400` with the code and message in the Past the limit column. The two surface bounds cap what the log field and a query return, and no call fails on them.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Function Instance `name` | Up to 100 characters | `400` `10046 Max Length`, `Ensure this field has no more than 100 characters.` |
| Arguments payload | 100,000 bytes | `400` `23000 JSON Args Size Too Big`, `Value size (in bytes) is too big. Maximum size allowed is 100000 bytes.` |
| Report log field `request_headers` | 10,000 characters | Each header name and value deducts from the amount, and the field takes no further header once the amount is reached. |
| GraphQL `limit` against the Bot Manager datasets | `10000` at most | One query returns no more than 10,000 results. |

The arguments payload bound is decimal, so a payload of 102,400 bytes, which is 100 KiB, is refused. For the arguments the payload holds and the default each one carries, refer to [Arguments](/en/documentation/platform/firewall/bot-manager/arguments/). For the report log, refer to [Logs](/en/documentation/platform/firewall/bot-manager/logs/). For the query, refer to [Query Bot Manager data with GraphQL](/en/documentation/guides/platform/observability/query-bot-manager-data-with-graphql/).

[Bot Manager Lite](/en/documentation/platform/firewall/bot-manager/bot-manager-lite/) is the self-serve edition. The full edition is in Preview: it is not enabled on an account by default, and Azion enables it on request. To request it, refer to [Support guidelines](/en/documentation/support/). For the rates of its requests and profiles, refer to [Pricing](/en/documentation/fundamentals/pricing/#bot-manager).
