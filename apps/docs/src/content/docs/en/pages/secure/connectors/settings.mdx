A [Connector](/en/documentation/platform/connectors/) routes requests from your [Applications](/en/documentation/platform/applications/) to the origin that holds your content, and holds where that content is and how to reach it. Its type, `http`, `storage`, or `live_ingest`, sets which settings the Connector carries. Azion Console and the Azion API write the same settings, so each table on this page names the Console label beside the API field. API fields are written as paths inside the request body, such as `attributes.connection_options.host`.

---

## Connector object

This JSON body is a complete Connector of type `http` with one address, every connection option at its default except `transport_policy` and `host`, and [Load Balancer](/en/documentation/platform/connectors/load-balancer/) and [Origin Shield](/en/documentation/platform/connectors/origin-shield/) off:

```json
{
  "name": "my-connector",
  "active": true,
  "type": "http",
  "attributes": {
    "addresses": [
      {
        "address": "origin.example.com",
        "http_port": 80,
        "https_port": 443,
        "active": true
      }
    ],
    "connection_options": {
      "dns_resolution": "both",
      "transport_policy": "force_https",
      "http_version_policy": "http1_1",
      "host": "origin.example.com",
      "path_prefix": "",
      "following_redirect": false,
      "real_ip_header": "X-Real-IP",
      "real_port_header": "X-Real-PORT"
    },
    "modules": {
      "load_balancer": { "enabled": false },
      "origin_shield": { "enabled": false }
    }
  }
}
```

The API path is `/v4/workspace/connectors`, and one Connector is `/v4/workspace/connectors/{connector_id}`. A `POST` that creates a Connector answers `202` with `"state": "pending"` and the full Connector, defaults included.

A `PATCH` merges the keys you send into the stored Connector, except `addresses`, which it replaces. A `PUT` replaces it: a `PUT` without `connection_options` resets every connection option to its default. For every operation, refer to the [Azion API](https://api.azion.com/).

The Azion CLI takes the same JSON body from a file: `azion create connector --type http --file my-connector.json` prints `Created Connector with ID <connector-id>`. In Terraform, the `azion_connector` resource manages a Connector, as [Connectors resources](/en/documentation/devtools/terraform/connectors/) shows. In `azion.config.js`, `attributes.modules.loadBalancer` and `attributes.modules.originShield` declare Load Balancer and Origin Shield, as [Connector modules](/en/documentation/devtools/cli/azion-config-js/#connector-modules) lists.

A change to a Connector takes effect without a new deployment. It reaches Azion's distributed infrastructure in several minutes, and data centers apply it at different times. An Application rule with the _Set Connector_ behavior sets the Connector that receives the Application's requests. To write that rule, refer to [Rules Engine for Applications](/en/documentation/platform/applications/rules-engine/).

## General

The general fields name the Connector and set its type. The API requires `name`, `type`, and `attributes` on every Connector.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| **Name** | `name` | string | none | Required. 1 to 255 characters. A name that another Connector already uses is refused with `28002`. |
| **Connector Type**, with the cards _HTTP_, _Object Storage_, and _Live Ingest_ | `type` | enum | none | Required. `http`, `storage`, or `live_ingest`. Sets which fields `attributes` takes. Fixed at creation: a `PATCH` that changes it is refused with `28003`. |
| **Active**, in the **Status** section | `active` | boolean | `true` | `true` or `false`. A Connector that an Application rule sets cannot change to `false`, and the request is refused with `28008`. |

A Connector of type `http` takes the fields in Addresses, Connection options, Load Balancer, and Origin Shield. A Connector of type `storage` takes the fields in Storage, and a Connector of type `live_ingest` takes the field in Live Ingest.

## Addresses

The addresses of a Connector of type `http` are the origin servers it connects to. Each item of `attributes.addresses` holds one address with its ports, its state, and its role in load balancing. The Console section **Address Management** writes them.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| **Address** | `attributes.addresses[].address` | string | none | Required. An IPv4 address, an IPv6 address, or a hostname, up to 255 characters, with no protocol and no port. |
| **HTTP Port** | `attributes.addresses[].http_port` | integer | `80` | 1 to 65535. The port for HTTP connections to this address. |
| **HTTPS Port** | `attributes.addresses[].https_port` | integer | `443` | 1 to 65535. The port for HTTPS connections to this address. |
| **Active** | `attributes.addresses[].active` | boolean | `true` | `false` takes the address out of rotation. |
| **Server Role**, with _Primary_ and _Backup_ | `attributes.addresses[].modules.load_balancer.server_role` | enum | `primary` | `primary` or `backup`. The role of the address in load balancing. |
| **Weight** | `attributes.addresses[].modules.load_balancer.weight` | integer | `1` | 1 to 100. Higher weights allocate more traffic to this address. |

A Connector holds one address unless Load Balancer is on. Two addresses with Load Balancer off are refused with `28004`, on create and when you turn Load Balancer off. With Load Balancer on, a Connector holds up to 15 addresses, and a 16th is refused with `28011`. For every bound in one place, refer to [Connectors limits](/en/documentation/platform/connectors/limits/).

An address with a protocol or a port, such as `https://origin.example.com` or `origin.example.com:443`, is refused with `28001`. The Console shows `Address must be a valid IPv4, IPv6, or hostname, without protocol or port.` Set the ports in **HTTP Port** and **HTTPS Port**, and a path in `path_prefix`.

An address reads back `"modules": null` until you send its Load Balancer fields. An address sent with only `weight` reads back `server_role` as `primary`, and one sent with only `server_role` reads back `weight` as `1`. A `backup` address is refused under the _IP Hash_ method with `28005`. The Console shows `Backup role is not available when the load balancing method is IP Hash.` and `Backup role is not supported with IP Hash. Change this address to Primary or select another method.` A weight outside the range shows `Weight must be between 1 and 100` in the Console.

An address with no `modules` does not count as `primary` beside a `backup` address. Such a list is refused with `28006`, so send `server_role` as `primary` on the address that must stay primary.

A `PATCH` that sends `attributes.addresses` replaces the stored list with the list you send. An address sent without its ports or `modules` returns to the defaults: `http_port` `80`, `https_port` `443`, and `"modules": null`. To change one address, send every address with all its fields.

## Connection options

The connection options of a Connector of type `http` set how it talks to its addresses. They cover the `Host` header, the path, the protocol, the IP version, and the headers that carry the client's address. They sit in `attributes.connection_options`.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| **Host** | `attributes.connection_options.host` | string | `${host}` | 1 to 255 characters. The `Host` header and the Server Name Indication (SNI) value sent to the origin. `${host}` sends the host the client requested, and a literal value is sent as is. An empty value is refused with `10018`, and a value with a protocol, such as `https://origin.example.com`, with `28010`. |
| **Path** | `attributes.connection_options.path_prefix` | string | `""`, no prefix | Up to 255 characters, starting with `/`. Prepended to the request path. A value without the leading slash is refused with `28009`. |
| **Transport Protocol Policy**, with _Preserve_, _Force HTTPS_, and _Force HTTP_ | `attributes.connection_options.transport_policy` | enum | `preserve` | `preserve` keeps the scheme the client used. `force_https` connects to the origin over HTTPS only, and `force_http` over HTTP only. |
| **DNS Resolution Policy**, with _IPv4 and IPv6_, _Force IPv4_, and _Force IPv6_ | `attributes.connection_options.dns_resolution` | enum | `both` | `both` connects over IPv4 or IPv6. `force_ipv4` connects over IPv4 only, and `force_ipv6` over IPv6 only. |
| none | `attributes.connection_options.http_version_policy` | enum | `http1_1` | The HTTP version to the origin. `http1_1`, HTTP/1.1, is the only value. |
| **Following Redirect** | `attributes.connection_options.following_redirect` | boolean | `false` | Whether the Connector follows the HTTP redirects the origin returns. |
| **Real IP Header** | `attributes.connection_options.real_ip_header` | string | `X-Real-IP` | The name of the header that carries the client IP address to the origin. An empty value is refused with `10018`, and one over 100 characters with `10046`. |
| **Real Port Header** | `attributes.connection_options.real_port_header` | string | `X-Real-PORT` | The name of the header that carries the client port to the origin. An empty value is refused with `10018`, and one over 100 characters with `10046`. |

The `host` value decides which name the origin sees. For example, with the default `${host}`, a client that requests `www.example.com` makes the Connector send `Host: www.example.com`. With `"host": "origin.example.com"`, the Connector sends `Host: origin.example.com` for every request. An origin that routes requests by name may not answer to the client's host, so send the origin's own name as a literal value.

The Console validates **Host** with `Host must be a valid hostname, IP address, or variable.`

Over HTTPS, the Connector also sends the `host` value as the SNI value, the server name of its Transport Layer Security (TLS) handshake. With the default `${host}`, the server name and the `Host` header both carry the hostname the client requested. With a literal value such as `origin.example.com`, both carry that value. The `host` field sets both: a Connector has no separate field for the server name.

The `path_prefix` value goes in front of the path the client requested. With `/anything`, a request for `/get` reaches the origin as `/anything/get`. For **Path**, the Console reads "Use '/' for the root path." and validates the field with `Path must start with a forward slash (/)`.

By default, the origin receives the client IP address in `X-Real-IP` and the client port in `X-Real-PORT`. Renaming `real_ip_header` changes the header name: with `X-Client-Real-IP`, the origin receives `X-Client-Real-IP` and no `X-Real-IP`. Some origins drop `X-Real-IP` themselves. To add the client IP to a header with a rule instead, refer to [Send the client IP to the origin in a header](/en/documentation/support/original-ip-header/).

## Load Balancer

Load Balancer balances requests across the addresses of a Connector of type `http`. In the Console, the **Load Balancer** switch in the **Modules** section turns it on, and the **Method**, **Max Retries**, **Connection Timeout**, and **Read/Write Timeout** fields appear. In the API, the fields sit in `attributes.modules.load_balancer`.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| **Load Balancer** | `attributes.modules.load_balancer.enabled` | boolean | `false` | `true` enables Load Balancer on the Connector and allows up to 15 addresses. |
| **Method**, with _Round Robin_, _Least Connections_, and _IP Hash_ | `attributes.modules.load_balancer.config.method` | enum | `round_robin` | `round_robin`, `least_conn`, or `ip_hash`. `ip_hash` refuses `backup` addresses. |
| **Max Retries** | `attributes.modules.load_balancer.config.max_retries` | integer | `0` in the API, `3` in the Console | 0 to 20. The number of retry attempts on a connection failure. |
| **Connection Timeout** | `attributes.modules.load_balancer.config.connection_timeout` | integer, seconds | `60` seconds in the API, `30` seconds in the Console | 1 to 300 seconds. The maximum time to wait for the connection to the origin. |
| **Read/Write Timeout** | `attributes.modules.load_balancer.config.read_write_timeout` | integer, seconds | `120` seconds in the API, `60` seconds in the Console | 1 to 600 seconds. The maximum time to wait for data to be read or written on the open connection to the origin. |

With `enabled` set to `true`, a request without `config`, or with `null`, is refused with `28014`, and so is a `PATCH` with an empty `config`. A key you leave out takes the API default, and on a `POST` an empty `config` takes every default. For example, `"config": {"method": "round_robin"}` reads back with `max_retries` `0`, `connection_timeout` `60`, and `read_write_timeout` `120`. When you turn on **Load Balancer** in the Console, the form fills in _Round Robin_, `3`, `30`, and `60` instead.

The retries and the two timeouts exist only with Load Balancer on. A Connector without Load Balancer has no configurable timeout. For the timeouts that apply then, refer to [How Connectors works](/en/documentation/platform/connectors/how-it-works/). For how each method chooses an address, refer to [Balancing methods](/en/documentation/platform/connectors/load-balancer/balancing-methods/).

## Origin Shield

Origin Shield protects the origin of a Connector of type `http` in two ways. Origin IP ACL lets your origin accept only Azion's published addresses, and HMAC signs each request the Connector sends to the origin. In the API, the fields sit in `attributes.modules.origin_shield`.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| **Origin Shield** | `attributes.modules.origin_shield.enabled` | boolean | `false` | `true` enables Origin Shield on the Connector. |
| **Origin IP ACL** | `attributes.modules.origin_shield.config.origin_ip_acl.enabled` | boolean | `false` | `true` turns on Origin IP ACL. |
| **HMAC** | `attributes.modules.origin_shield.config.hmac.enabled` | boolean | `false` | `true` signs each request to the origin with the HMAC credentials. |
| **Type**, read-only | `attributes.modules.origin_shield.config.hmac.config.type` | enum | `aws4_hmac_sha256` | The signing scheme. |
| **Region** | `attributes.modules.origin_shield.config.hmac.config.attributes.region` | string | none | Required. 1 to 255 characters. A region that the object storage provider supports. |
| **Service** | `attributes.modules.origin_shield.config.hmac.config.attributes.service` | string | `s3` | 1 to 255 characters. Required in the Console. |
| **Access Key** | `attributes.modules.origin_shield.config.hmac.config.attributes.access_key` | string | none | Required. 1 to 255 characters. |
| **Secret Key** | `attributes.modules.origin_shield.config.hmac.config.attributes.secret_key` | string | none | Required. 1 to 255 characters. The Console renders it as a password field. |

With `enabled` set to `true`, `config` must carry at least one key, such as `origin_ip_acl`. With `hmac.enabled` set to `true`, `hmac.config` must be present. Otherwise the API refuses the request with `28014`. Turning HMAC off removes the stored credentials, so you enter them again when you turn it back on.

The API returns the HMAC `access_key` and `secret_key` in plain text, exactly as you sent them. Three responses carry both values:

- The response to the `POST` that creates the Connector.
- The response to a `GET` of the Connector by ID.
- The list that `GET /v4/workspace/connectors` returns.

The HMAC credentials belong to an account at the object storage provider that holds the private content. For example, a Connector that reads a private bucket through the S3 endpoint `s3.us-east-005.azionstorage.net` sends `region` `us-east-005`, `service` `s3`, and a credential scoped to that bucket. With HMAC off, that endpoint answers `401`. For how Origin IP ACL and HMAC protect the origin, refer to [Origin IP ACL and HMAC](/en/documentation/platform/connectors/origin-shield/origin-ip-acl-and-hmac/).

## Storage

A Connector of type `storage` reads from an [Object Storage bucket](/en/documentation/platform/object-storage/buckets-and-objects/) in your account. It carries two attributes and no addresses or connection options. A `modules` key sent with this type is accepted and not stored, so Origin Shield does not apply.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| Bucket selector, _Select a Bucket_, with the **Create Object Storage** button | `attributes.bucket` | string | none | Required. Up to 255 characters. The name of an existing bucket whose workloads access is read only or read write. Any other bucket is refused with `28007`. |
| **Prefix** | `attributes.prefix` | string | `null` when omitted | Optional in the API, required in the Console. 1 to 255 characters, such as `images/`. Filters the objects within the bucket. An empty string is refused with `10018`. |

The bucket selector lists the buckets of your account, and **Create Object Storage** creates a bucket without leaving the form. In the API, leave `prefix` out to store `null`, and never send it empty. For example, this body creates a Connector of type `storage` for the objects under `images/`:

```json
{
  "name": "my-connector",
  "type": "storage",
  "attributes": { "bucket": "my-bucket", "prefix": "images/" }
}
```

The leading and trailing slashes of `prefix` are optional, because the Connector joins `prefix` and the request path with a single slash. `images`, `images/`, `/images`, and `/images/` are equivalent: with any of them, a request for `/logo.png` receives the object `images/logo.png`. With `images/icons`, the same request receives the object `images/icons/logo.png`. The API stores the value as you sent it and does not normalize it.

The request path carries only the part of the object key after the prefix. A request whose path repeats the prefix, such as `/images/logo.png` with the prefix `images`, receives `404` with a `NoSuchKey` XML body.

## Live Ingest

A Connector of type `live_ingest` belongs to [Live Ingest](/en/documentation/platform/connectors/live-ingest/). It carries one attribute, `region`, and no addresses or connection options.

| Console | API field | Type | Default | Description |
| --- | --- | --- | --- | --- |
| **Region** | `attributes.region` | enum | none | Required. `us-east-1`, `us-east-2`, `br-east-1`, `br-east-2`, or `br-east-3`. |

A request without `region` is refused with `10059`, and a value the API does not accept with `10039`. A `bucket`, `addresses`, or `modules` key sent with this type is accepted and not stored, so Load Balancer and Origin Shield do not apply. For example, this body creates a Connector of type `live_ingest` in `us-east-1`:

```json
{
  "name": "my-connector",
  "type": "live_ingest",
  "attributes": { "region": "us-east-1" }
}
```

For how Live Ingest works, refer to [Ingestion and delivery](/en/documentation/platform/connectors/live-ingest/ingestion-and-delivery/).

## Errors

The API refuses each request in this table with HTTP `400` and creates or changes nothing. The code and the message are in the response's `errors` array, with a `source.pointer` to the field.

| Code | Message | Cause | What to do |
| --- | --- | --- | --- |
| `28001` | `Invalid address format. Must be a valid IPv4, IPv6, or CNAME.` | An address carries a protocol or a port, such as `https://origin.example.com` or `origin.example.com:443`. | Send the hostname or IP address alone, and set the ports in `http_port` and `https_port`. |
| `28002` | `A connector with this name already exists for this Workspace.` | Another Connector already uses the `name`. | Send a name that no other Connector uses. |
| `28003` | `Connector type cannot be changed after creation.` | A `PATCH` sends a `type` other than the stored one. | Create a Connector of the type you need, and set it in your rules instead. |
| `28004` | `To use more than one address, you must enable the Load Balancer module.` | The Connector has two or more addresses and Load Balancer is off, on create or when you turn Load Balancer off. | Enable Load Balancer on the Connector, or keep one address. |
| `28011` | `When the Load Balancer module is enabled, you can use up to 15 addresses.` | The Connector has 16 or more addresses. | Keep 15 addresses or fewer. |
| `28012` | `At least one active address is required.` | A `POST` or a `PATCH` sends the only address with `active` `false`. | Send the address with `active` `true`. |
| `28006` | `At least one address with server_role set to 'primary' and marked as active is required.` | The addresses include a `backup` one, and no address is an active `primary`. An address with no `modules`, or a `primary` one with `active` `false`, does not count. | Send `server_role` as `primary` on at least one address with `active` `true`. |
| `28005` | `Backup addresses are not allowed when using 'ip_hash' as load balance method.` | An address has `server_role` `backup` and the method is `ip_hash`, on create or on a `PATCH` that changes the method. | Set the address to `primary`, or choose `round_robin` or `least_conn`. |
| `28014` | `Module configuration must be provided when 'enabled' is true.` | Load Balancer has `enabled` `true` with no `config` or `null`, or a `PATCH` sends an empty `config`. Origin Shield has `enabled` `true` with no `config`, `null`, or an empty one. HMAC is on without `hmac.config`. | Send `config` with at least one key, such as `method` for Load Balancer, or `hmac.config` with the credentials. |
| `28009` | `Invalid path format. Must be a valid path.` | `path_prefix` does not start with `/`. | Start the value with `/`, such as `/anything`. |
| `28010` | `Invalid host format. Must be a valid host.` | `host` is not a valid host, such as a value with a protocol. | Send a hostname, an IP address, or `${host}`. |
| `28007` | `This bucket does not exist or its workloads access is restricted. To use it in a connector, set its workloads access to read only or read write.` | `bucket` names a bucket that does not exist in the account, or one whose workloads access is restricted. | Send the name of an existing bucket, and set its workloads access to read only or read write. |
| `28000` | `Cannot delete an Connector referenced by another resource. References: EdgeApplicationRuleEngine - id: <rule-id>` | A `DELETE` targets a Connector that an Application rule still sets. The message names the rule. | Set another Connector in the rule, or delete the rule, then repeat the `DELETE`. |
| `28008` | `Cannot deactivate an Connector referenced by another resource. References: EdgeApplicationRuleEngine - id: <rule-id>` | A `PATCH` sends `active` `false` for a Connector that an Application rule still sets. The message names the rule. | Set another Connector in the rule, or delete the rule, then repeat the `PATCH`. |
| `10018` | `This field may not be blank.` | `name`, `host`, `prefix`, `real_ip_header`, `real_port_header`, or the HMAC `region` is an empty string. | Send a value, or leave `prefix` out. |
| `10059` | `This field is required.` | A required field is missing, such as `name`, `type`, the addresses of a Connector of type `http`, `bucket`, `region`, or an HMAC credential. | Send the field that `source.pointer` names. |
| `10039` | `"http2" is not a valid choice.` | An enum field holds a value outside its list. The message quotes the value, such as `"http2"` for `http_version_policy`. | Send a value from the field's list. |
| `10050` | `Ensure this value is greater than or equal to 1.` | A number is below its minimum. The message names it: `1` for the ports, `weight`, `connection_timeout`, and `read_write_timeout`, and `0` for `max_retries`. | Send a value inside the field's range. |
| `10068` | `Ensure this value is less than or equal to 100.` | A number is above its maximum. The message names it: `65535` for the ports, `100` for `weight`, `20` for `max_retries`, `300` for `connection_timeout`, and `600` for `read_write_timeout`. | Send a value inside the field's range. |
| `10046` | `Ensure this field has no more than 255 characters.` | A string is longer than its maximum. The message names it: `100` for `real_ip_header` and `real_port_header`, and `255` for every other string field. | Shorten the value to the maximum or fewer characters. |

The Azion CLI prints the same message inside its own error. For `28000`, that is:

```text
Error: Failed to delete the Connector: ["Cannot delete an Connector referenced by another resource. References: EdgeApplicationRuleEngine - id: <rule-id>"]. Check your settings and try again. If the error persists, contact Azion support
```

The `errors` entry of `28012` carries the `title` `Active Address Required`, the entry of `28006` carries `Active Primary Address Required`, the entry of `28014` carries `Missing Module Configuration`, the entry of `28008` carries `Cannot Deactivate Referenced Connector`, and the entry of `28007` carries `Bucket Not Accessible By Workloads`.
