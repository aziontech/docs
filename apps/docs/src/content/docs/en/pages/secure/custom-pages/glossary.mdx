Definitions for the terms the **Custom Pages** documentation uses.

| Term | Definition |
| --- | --- |
| custom page | One entry of a custom page set: the page Azion serves in place of a response with a 4xx or 5xx status code from a [Connector](/en/documentation/platform/connectors/), selected by the status code of the page. With a `page_connector` page, Azion fetches the document at `uri` from the page's Connector, caches it for `ttl`, and answers with `custom_status_code` when one is set, so the client is served in place and not redirected. [Custom page settings](/en/documentation/platform/custom-pages/settings/) documents every field. |
| custom page set | The named list that groups custom pages, at least one per set, served in the API at `/v4/workspace/custom_pages`. Azion Console calls it a custom page, on the **Create Custom Page** page. A [Workload](/en/documentation/platform/workloads/) uses a custom page set only once that Workload's [deployment](/en/documentation/platform/workloads/settings/#deployment) sets that custom page set, as the [Custom Pages quickstart](/en/documentation/platform/custom-pages/quickstart/) shows. |
| Custom Pages | A Platform Resource that replaces the error response returned by a Connector with a page of your own, one page per error status code, through the custom page set that a Workload's deployment sets. It replaces the [Error Responses](/en/documentation/platform/custom-pages/error-responses/) of an [Application](/en/documentation/platform/applications/) on API v3. [Custom Pages](/en/documentation/platform/custom-pages/) describes it. |
