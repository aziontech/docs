[Certificate Manager](/en/documentation/platform/certificate-manager/) is a Platform Resource that stores the certificates a [Workload](/en/documentation/platform/workloads/) uses for Transport Layer Security (TLS): server certificates, Trusted CA certificates for mutual TLS (mTLS), and the certificate revocation lists (CRLs) a Workload lists. It also requests the Let's Encrypt certificates that Azion manages for you. Certificate Manager has no included amount per plan.

---

## Scope

- **Azion SAN certificate**: a Workload needs nothing from Certificate Manager for its workload domain and its `azion.app` hostname, because the Azion SAN certificate covers both. A domain of your own needs a server certificate from Certificate Manager. For the certificate types, refer to [Certificates](/en/documentation/platform/certificate-manager/certificates/#certificate-types).
- **Names on a Let's Encrypt certificate**: a certificate requested from the Workload form covers the Workload's domains, because the form fills `common_name` and `alternative_names` from them. An API request names its hostnames in those two fields itself. A Workload refuses a wildcard domain, so the Workload form cannot request a wildcard name. For a wildcard name, refer to [Wildcard certificates](/en/documentation/platform/certificate-manager/issuance-and-renewal/#wildcard-certificates).
- **Let's Encrypt service**: Azion's support for Let's Encrypt certificates depends on the availability and the limits of the Let's Encrypt service. One wildcard certificate in place of one certificate per subdomain lowers the chance of reaching those limits. For the limits, refer to the [Let's Encrypt rate limits](https://letsencrypt.org/docs/rate-limits/).

---

## Default limits

The Azion API checks each bound in this table on every call, and a call past a bound fails.

| Scope | Limit |
| --- | --- |
| Certificate, server or Trusted CA, in `certificate` | Up to 1,000,000 characters |
| Private key, in `private_key` | Up to 64,000 characters |
| CRL, in `crl` | Up to 30,720,000 characters |
| CRLs per Workload, in `mtls.config.crl` | Up to 100 |

One further bound applies: a Let's Encrypt certificate covers up to 50 of the Workload's domains. For the number of domains a Workload lists, refer to [Workloads limits](/en/documentation/platform/workloads/limits/).
