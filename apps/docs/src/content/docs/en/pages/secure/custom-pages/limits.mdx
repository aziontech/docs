[Custom Pages](/en/documentation/platform/custom-pages/) is a Platform Resource that replaces the error response returned by a [Connector](/en/documentation/platform/connectors/) with a page of your own, one page per error status code. A custom page set is the named list that groups those pages. This page states where Custom Pages acts and the bounds Azion applies to a set and to each page in it.

---

## Scope

- **Status codes**: a page replaces only one of the 22 codes in [Status codes](/en/documentation/platform/custom-pages/settings/#status-codes), 16 client errors (4xx) and six server errors (5xx).
- **Workloads**: a [Workload](/en/documentation/platform/workloads/) uses a custom page set only once that Workload's deployment sets that custom page set. A Workload holds at most one deployment, so one set covers every hostname of the Workload. For the deployment fields, refer to [Workload settings](/en/documentation/platform/workloads/settings/#deployment).
- **Timing**: an assigned set serves only after the change to the deployment propagates, over several minutes, and Azion does not guarantee when. Repeat the request until the page answers, as [Propagation](/en/documentation/platform/workloads/how-it-works/#propagation) explains.
- **API v3**: Custom Pages is the API v4 model for error pages. An Application that still runs on API v3 sets its error pages in [Error Responses](/en/documentation/platform/custom-pages/error-responses/), whose fields map to Custom Pages fields in [Interfaces](/en/documentation/platform/custom-pages/settings/#interfaces).

---

## Default limits

A custom page set holds at least one page. The API and Azion Console refuse an empty set, each with the message in the Past the limit column.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Pages per custom page set | At least 1 | The API returns `Ensure this field has at least 1 elements.` Azion CLI prints that message inside `Error: Failed to create Custom Page: [...]`. Azion Console shows `You must have at least one custom page code`. |

Four further bounds apply: a set `name` takes 1 to 255 characters, a page `ttl` takes 0 to 31,536,000 seconds, a page `uri` takes 1 to 250 characters, and a page `custom_status_code` takes 100 to 599. For the fields these bounds apply to, refer to [Custom page settings](/en/documentation/platform/custom-pages/settings/).
