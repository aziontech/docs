## Escreva cada página duas vezes

A documentação publica toda página em inglês dos EUA e em português do Brasil. O inglês dos EUA é a fonte da verdade. Escreva a página em português do Brasil sobre a página em inglês dos EUA pronta, não em paralelo com ela. A estrutura da página em português do Brasil segue a página em inglês dos EUA, e uma mudança na página em inglês dos EUA cria trabalho correspondente na página em português do Brasil.

Para escrever ou atualizar uma página em português do Brasil, abra primeiro a página em inglês dos EUA. Se a página em inglês dos EUA não existe, escreva-a primeiro: uma página em português do Brasil escrita primeiro não tem fonte, e a página em inglês dos EUA que vier depois vira uma tradução de uma tradução.

## Vincule as versões pelo namespace

O site vincula as duas versões de uma página pelo campo `namespace`, não pelo caminho do arquivo. O seletor de idioma depende desse vínculo. Os dois arquivos carregam o mesmo valor, caractere por caractere:

```
en:     title:     Create an Object Storage bucket
        permalink: /documentation/guides/application-development/data/create-and-modify-bucket/
        namespace: documentation_products_object_storage_bucket

pt-br:  title:     Criar um bucket do Object Storage
        permalink: /documentacao/guias/desenvolvimento-de-aplicacoes/dados/criar-e-modificar-um-bucket/
        namespace: documentation_products_object_storage_bucket
```

Cada campo do frontmatter segue uma de três regras na página em português do Brasil:

| Campo | Página em português do Brasil |
| --- | --- |
| `title` | traduzido |
| `description` | traduzida |
| `permalink` | traduzido |
| `namespace` | idêntico ao da página em inglês dos EUA |
| `meta_tags` | por convenção, em inglês dos EUA |

Um namespace diferente entre as versões quebra o seletor de idioma, e o build passa mesmo assim. Nada avisa; confira o valor caractere por caractere antes de publicar. As regras de cada campo estão em [Frontmatter](/pt-br/documentacao/guia-de-estilo/convencoes/frontmatter/).

## Localize diretórios e permalinks

Localize os nomes de diretórios e de arquivos; não copie a árvore em inglês dos EUA. `guides/` vira `guias/`, e `create-bucket.mdx` vira `criar-bucket.mdx`. Os permalinks seguem a mesma regra: `/documentation/products/...` vira `/documentacao/produtos/...`.

Os permalinks ficam em ASCII nos dois idiomas. Remova os acentos em vez de codificá-los: `configuracao`, não `configuração`.

## Use o prefixo de idioma correto nos links

Links internos são absolutos, começam com um prefixo de idioma e terminam com barra. O mesmo link muda só o prefixo entre as duas versões:

```
Página em inglês dos EUA:      [Applications](/en/documentation/platform/applications/)
Página em português do Brasil: [Applications](/pt-br/documentacao/plataforma/applications/)
```

Uma página em português do Brasil aponta para uma página em inglês dos EUA só quando a tradução não existe. Nunca envie o leitor para o inglês dos EUA quando a página em português do Brasil existe.

## Escreva o inglês dos EUA para sobreviver à tradução

A página em inglês dos EUA define a tarefa de quem traduz. Uma frase curta traduz um para um. Uma frase de 45 palavras com três orações subordinadas força quem traduz a reestruturá-la, e a reestruturação é onde o sentido se perde.

As regras estruturais de [Estrutura de frases](/pt-br/documentacao/guia-de-estilo/escrita/estrutura-de-frases/) valem para o português do Brasil sem mudança. Limite de tamanho de frase, uma instrução por passo, tempos verbais simples, voz ativa e agrupamentos curtos de substantivos: tudo se transfere. As regras de vocabulário não se transferem; o vocabulário do português do Brasil está em [Terminologia da documentação](/pt-br/documentacao/guia-de-estilo/escrita/terminologia/).

## Aplique as regras de tradução

Seis regras cobrem a maior parte do trabalho em uma página em português do Brasil:

- Não traduza termos técnicos genéricos: `data center`, `serverless`, `template`, `compliance`, `on-premise`, `authoritative DNS`. As strings `edge` e `edge computing` permanecem sem tradução onde já aparecem, mas textos novos não as introduzem.
- Não traduza nomes de recursos da plataforma nem outros nomes da Azion: **Applications**, **Functions**, **Firewall**, **Azion Platform**, **Azion Marketplace**. A instância também mantém o nome: `uma Function`, `as suas Applications`. Nunca troque um nome por uma descrição dele em português: `firewall de aplicação web` para Web Application Firewall, `gerenciamento de bots` para Bot Manager, `armazenamento de objetos` para Object Storage e `funções` para Functions escondem o nome que o leitor procura.
- Aplique as substituições: `aplicação`, não `aplicativo`, só para o software do próprio cliente, porque a instância criada na Azion é uma `Application`; `rede distribuída`, não `borda`, ao traduzir texto existente; `performance`, não `desempenho`. Texto novo em português do Brasil que nomeia onde a plataforma roda escreve `infraestrutura distribuída`.
- Escreva a frase que um leitor brasileiro usa, não a frase em inglês palavra por palavra: `experimentaram` vira `experienciaram` ou `vivenciaram`, `nenhum servidor sozinho carrega toda ela` vira `nenhum servidor fica sobrecarregado`, e `nunca consulta uma API` vira `sem a necessidade de consultar uma API`.
- Escreva títulos com maiúscula só na primeira palavra e nos nomes próprios.
- Localize os rótulos dos asides: `:::note[nota]`, `:::tip[dica]`, `:::caution[Atenção]`, `:::danger[perigo]`. A caixa segue o uso do repositório: `nota`, `dica` e `perigo` em minúscula, `Atenção` com maiúscula. Um rótulo em inglês dos EUA em uma página em português do Brasil é um defeito visível.

A lista completa de termos que ficam em inglês dos EUA está em [Terminologia da documentação](/pt-br/documentacao/guia-de-estilo/escrita/terminologia/).

## Use as formas fixas em português do Brasil

Três elementos recorrentes se traduzem sempre da mesma forma. Não improvise uma forma nova para eles.

Três nomes de seção têm forma fixa em português do Brasil:

- `## Prerequisites` vira `## Pré-requisitos`.
- `## Next steps` vira `## Próximos passos`.
- `## Related resources` vira `## Recursos relacionados`.

As frases padrão de link têm forma fixa, e o verbo é `consulte`:

- `Para mais informações, consulte [Título](/pt-br/.../).`
- `Para <fazer algo>, consulte [Título](/pt-br/.../).`

Os rótulos da interface do Console ficam como a interface mostra. Não traduza nomes de botões e campos que o Console exibe em inglês dos EUA: **Save**, **Workloads Access**, **+ Bucket**.

## Revise toda tradução

Nunca publique uma tradução automática sem revisão. Uma tradução errada é mais difícil de achar e corrigir do que uma tradução ausente, porque a página parece completa. Use tradução automática só como primeiro rascunho, e revise o rascunho antes de publicar.
