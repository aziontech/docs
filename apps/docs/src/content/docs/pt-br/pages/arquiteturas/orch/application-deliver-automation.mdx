O [Azion Orchestrator](/pt-br/documentacao/plataforma/orchestrator/) permite releases frequentes e confiáveis de aplicações através de orquestração. Esta documentação aborda a arquitetura e os passos para a entrega automatizada de aplicações usando o Azion Orchestrator, garantindo performance ótima e operações simplificadas.

---

## Arquitetura da entrega e operações de aplicações

:::note[nota]
Este fluxo pressupõe que um serviço foi criado para salvar uma página HTML contendo uma lista de produtos. Para mais informações, verifique a seção [Implementação](#implementacao).
:::

![Diagrama de arquitetura do Orchestrator](/assets/docs/images/uploads/infrastructure-arch.png?v=2)

### Fluxo de dados da entrega e operações de aplicações

1. O usuário abre **Edge Nodes** no **Azion Console** para gerenciar os nodes.
2. O usuário associa aos nodes um serviço criado em **Edge Services**.
3. Os nodes são gerenciados e configurados pela associação do serviço.
4. O **Orchestrator** orquestra os serviços nos nodes.
5. Os nodes agora contêm uma página HTML com uma lista de produtos.

## Componentes

- [Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/): interface para gerenciar e monitorar aplicações e serviços.
- [Azion Orchestrator](/pt-br/documentacao/plataforma/orchestrator/): automatiza o deploy e gerenciamento de aplicações em nodes.
- [Nodes](/pt-br/documentacao/plataforma/orchestrator/edge-node/): os dispositivos que executam o Orchestrator Agent, como servidores, roteadores e switches de rede, e que o Orchestrator gerencia.
- [Serviços](/pt-br/documentacao/plataforma/orchestrator/edge-services/): os serviços que você cria e customiza para que o Orchestrator os execute nos nodes.

## Implementação

1. [Instale o Orchestrator Agent](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/instalar-orchestrator-agent/) em seu dispositivo para transformá-lo em um node.
2. Autorize o node para que possa ser orquestrado.
    - No Console, você pode ver e [autorizar nodes](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/autorizar-edge-node/).
    - Use a [API da Azion](https://api.azion.com/#e6a19e66-71e9-4b10-b50c-c0e0684bf458) para autorizar um node.
3. [Crie serviços](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/criar-edge-service/) que irão salvar uma página HTML nos nodes.
4. Atribua serviços a nodes.
    - No Console, [vincule serviços](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/vincular-servico/) a seus nodes.
    - Use a [API da Azion](https://api.azion.com/#230b2947-a706-4143-ae96-3115b8ecd333) para atribuir um serviço a um node.
5. [Acompanhe logs](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/verificar-logs/) de seus nodes e serviços.
