Você pode implantar um stack básico de configurações de aplicação e de segurança na Azion a partir do template Azion Starter Kit no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

Use o Azion Starter Kit para dar os primeiros passos na Azion Web Platform e para explorar a plataforma e seus recursos. O template inclui:

- Uma nova [aplicação](/pt-br/documentacao/plataforma/applications/), com regras comuns de cache para imagens e para arquivos dinâmicos e estáticos.
- Recursos do [Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/) para manipular e processar imagens diretamente na Azion.
- Um novo [firewall](/pt-br/documentacao/plataforma/firewall/) com regras que executam uma instância de função para o Bot Manager Lite e negam requisições da network list pré-construída Azion IP Tor Exit Nodes.

O template usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/), [Functions](/pt-br/documentacao/plataforma/functions/), [Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/) e [Network Shield](/pt-br/documentacao/plataforma/firewall/network-shield/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Application Accelerator, Functions, Image Processor e Network Shield habilitados na sua conta.
- A versão mais recente da integração Bot Manager Lite, instalada. Para instalá-la, acesse o [Marketplace da Azion](https://console.azion.com/marketplace) e selecione **Install**. Para mais informações, consulte [Instale o Bot Manager Lite](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/bot-manager-lite/).
- Uma origem hospedada que guarda o seu conteúdo. O formulário de configuração pede o endereço dela.

Se você não instalar a função Bot Manager Lite antes de usar este template, a implantação falha e mostra um log que explica o motivo.

## Implante o template

O Azion Starter Kit abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Azion Starter Kit](https://console.azion.com/create/azion/azion-starter) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Em **Application Name**, insira um nome único e fácil de lembrar. O nome identifica a nova aplicação, o domínio dela e o firewall na Azion. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira o endereço da origem">

  Em **Origin Address**, insira o endereço da origem hospedada. A aplicação busca o conteúdo original nela. Por exemplo: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Opcional) Substitua o cabeçalho Host">

  Algumas origens precisam de outro valor no cabeçalho `Host` da requisição que busca o conteúdo delas. Em **Custom Host Header**, insira esse valor. Para repassar à origem o cabeçalho `Host` da requisição do visitante, insira a variável `${host}`. Para mais informações, consulte [Origins](/pt-br/documentacao/plataforma/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação. Nesse intervalo, a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente. Para alterar as configurações que a implantação aplica, consulte [Gerencie a aplicação](#gerencie-a-aplicacao).

## Regras e configurações do template

O Azion Starter Kit configura regras na aplicação e no firewall que ele cria.

### Regras da aplicação

A aplicação inclui uma regra padrão com este critério e este behavior:

- **Criteria**: se `${uri}` *starts with* `/`.
- **Behavior**: então [Set Connector](/pt-br/documentacao/plataforma/applications/rules-engine/#set-connector) como `Default Origin`.

Para a otimização e o cache de imagens, o template cobre as extensões de arquivo `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.gif` e `.png`. Para conteúdo estático, ele suporta as extensões comuns de arquivos estáticos.

O template respeita as configurações de cache da origem. Quando a origem não envia nenhuma, ele usa o Max Age do cache setting. As regras dele alteram as configurações de cache de arquivos estáticos pela extensão do arquivo requisitado, para melhorar a entrega.

### Regras do firewall

O firewall aprimora a segurança por meio da network list [IP Tor Exit Nodes da Azion](/pt-br/documentacao/guias/seguranca-de-aplicacoes/bots-e-rede/bloquear-redes-tor/) e do [Bot Manager Lite da Azion](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/bot-manager-lite/).

O template cria a instância da função do Bot Manager Lite com os seguintes argumentos JSON:

```json
{
  "threshold": 10,
  "action": "allow",
  "internal_logs": 2
}
```

Onde:

- `threshold`: a pontuação máxima que a requisição pode atingir antes que a função execute uma ação. O template define `10`. Uma instância que não define `threshold` usa o padrão da função, `30`.
- `action`: a ação a ser tomada pela função sempre que a pontuação da requisição for maior ou igual ao limite definido. Valores possíveis: `allow`, `custom_html`, `deny`, `drop`, `hold_connection`, `random_delay` e `redirect`. O template define `allow`, então as requisições recebem pontuação e são registradas nos logs, mas não são bloqueadas. Uma instância que não define `action` usa o padrão da função, `deny`.
- `internal_logs`: toda execução do Bot Manager Lite grava logs de relatório, independentemente da pontuação da requisição.

Para ver todos os argumentos e seus padrões, consulte [Argumentos do Bot Manager](/pt-br/documentacao/plataforma/firewall/bot-manager/argumentos/).

Consulte os logs do Bot Manager Lite no [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/). Analise esses logs para descobrir se os argumentos JSON da instância da função precisam de alguma alteração. Você também pode usar o [Data Stream da Azion](/pt-br/documentacao/plataforma/data-stream/) como uma ferramenta de observabilidade. Para mais informações, consulte [Monitore e calibre o Bot Manager](/pt-br/documentacao/guias/seguranca-de-aplicacoes/bots-e-rede/monitorar-e-calibrar-bot-manager/#leia-o-log-de-report-no-real-time-events).

## Gerencie a aplicação

As configurações que o Azion Starter Kit aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/).

## Adicione um domínio personalizado

A implantação do Azion Starter Kit atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para adicionar um, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/). Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
