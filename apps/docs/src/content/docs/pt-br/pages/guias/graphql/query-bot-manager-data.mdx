Você pode ler as contagens de classificação do seu tráfego de bots no dataset `botManagerMetrics`, no GraphiQL Playground ou com a GraphQL API. Para as URLs e os endereços que o tráfego de bots alcançou, consulte [Consulte as URLs mais atingidas por bots com GraphQL](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-bot-manager-breakdown-com-graphql/).

---

## Pré-requisitos

- [Bot Manager](/pt-br/documentacao/plataforma/firewall/bot-manager/) em execução na sua conta. Em uma conta sem dados do Bot Manager, a consulta responde `200` com uma lista vazia.
- Para o Playground, uma sessão autenticada no Azion Console no mesmo navegador. Sem ela, o endpoint responde `401` com `Authentication credentials were not provided.` Para mais informações, consulte [GraphiQL Playground](/pt-br/documentacao/devtools/graphql/playground-graphql/).
- Para um cliente GraphQL, um personal token, enviado em um header `Authorization: Token [TOKEN VALUE]`. Para mais informações, consulte [Tokens pessoais](/pt-br/documentacao/fundamentos/personal-tokens/).

## Consulte as contagens de classificação

O dataset conta as requisições que o Bot Manager analisou e não carrega nenhum score. Um score pertence a uma requisição e está na linha de report dela, que [Logs](/pt-br/documentacao/plataforma/firewall/bot-manager/logs/) documenta. A consulta a seguir filtra o dataset por um intervalo de tempo, soma `requests` por grupo e devolve um objeto por combinação dos campos agrupados.

Para consultar as contagens de classificação:

<DocSteps>
  <DocStep title="Abra o Playground">

  Acesse `https://api.azion.com/v4/metrics/graphql`. A partir de um cliente GraphQL, envie a consulta para a mesma URL com o seu token.

  </DocStep>
  <DocStep title="Informe a consulta">

  Defina `begin` e `end` para o período que você quer ler. O dataset é retido por 2 anos:

  ```graphql
  query {
    botManagerMetrics(
      filter: {
        tsRange: {
          begin: "2024-09-23T15:00:00"
          end: "2024-09-23T17:00:00"
        }
      }
      aggregate: {
        sum: requests
      }
      orderBy: [ts_ASC]
      groupBy: [ts, action, botCategory, botMode, classified]
      limit: 10000
    ) {
      action
      botCategory
      botMode
      classified
      sum
    }
  }
  ```

  </DocStep>
  <DocStep title="Execute a consulta e leia a resposta">

  A resposta carrega um objeto por combinação dos campos agrupados, com as requisições somadas em `sum`:

Você agora tem as requisições que o Bot Manager analisou no período, contadas por como ele classificou cada uma e pela action que aplicou. `classified` e `botCategory` são independentes um do outro, então uma categoria pode ter requisições de várias classificações.

A consulta seleciona cinco campos, e o dataset carrega mais, incluindo o host, o método HTTP, a origem geográfica e o resultado de um desafio de CAPTCHA. Para cada campo, consulte [botManagerMetrics](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-metrics/#metricas-de-bot-manager).

## Ordene as classificações por volume

Ordenar pelo agregado em vez de pelo timestamp transforma o mesmo dataset em um ranking das combinações que carregam mais tráfego.

Para ordenar as classificações:

<DocSteps>
  <DocStep title="Ordene pela soma">

  Defina `orderBy` como `[sum_DESC]`, para que os maiores grupos venham primeiro.

  </DocStep>
  <DocStep title="Retire ts de groupBy">

  Cada combinação então se reduz a um objeto ao longo de todo o intervalo:

  ```graphql
  query {
    botManagerMetrics(
      filter: {
        tsRange: {
          begin: "2024-10-01T00:00:00"
          end: "2024-10-03T23:59:59"
        }
      }
      aggregate: {
        sum: requests
      }
      orderBy: [sum_DESC]
      groupBy: [classified, botCategory, action]
      limit: 10000
    ) {
      classified
      botCategory
      action
      sum
    }
  }
  ```

  </DocStep>
  <DocStep title="Execute a consulta" />
</DocSteps>

Os objetos no topo da resposta são os maiores grupos, que é onde uma mudança de threshold ou de action move mais tráfego. Para agir sobre essas contagens, consulte [Monitore e calibre o Bot Manager](/pt-br/documentacao/guias/seguranca-de-aplicacoes/bots-e-rede/monitorar-e-calibrar-bot-manager/).
