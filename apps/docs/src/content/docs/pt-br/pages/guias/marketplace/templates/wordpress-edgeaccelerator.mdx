Você pode implantar uma aplicação para o seu site WordPress na Azion a partir do template WordPress EdgeAccelerator no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

A Azion desenvolveu o template WordPress EdgeAccelerator para melhorar a performance e a segurança de um site WordPress. O template ajuda você a migrar o site para ser executado na infraestrutura distribuída da Azion.

A implantação cria uma [aplicação](/pt-br/documentacao/plataforma/applications/) e o domínio dela, com os quais você gerencia o projeto na Azion. Ela também define configurações principais que otimizam a performance do seu site WordPress. A implantação pode gerar custos relacionados ao uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Um site WordPress em uma origem hospedada. O formulário de configuração pede o endereço da origem.

---

## Implante o template

O template WordPress EdgeAccelerator abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [WordPress EdgeAccelerator](https://console.azion.com/create/wordpress/wordpress-edgeaccelerator) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Em **Application Name**, insira um nome único e fácil de lembrar. Você usa o nome para identificar e gerenciar a aplicação na Azion. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira o endereço da origem">

  Em **Origin Address**, insira o endereço da sua origem hospedada. A aplicação busca o conteúdo original nela. Por exemplo: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Opcional) Adicione informações de host à requisição para a origem">

  Algumas origens precisam de informações de *host* no cabeçalho da requisição que busca o conteúdo delas. Em **Custom host header**, insira esse valor. Por exemplo: `${host}`. Para mais informações, consulte [Origins](/pt-br/documentacao/plataforma/connectors/origins/).

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar. Ao final da implantação, você tem:

- Uma aplicação na Azion com a qual você gerencia o projeto.
- Um domínio que um navegador consegue abrir para acessar a aplicação.
- Regras comuns de cache, regras de cache de arquivos de imagem e regras de cache de arquivos estáticos.
- Rotas de bypass para o site.

Essas configurações otimizam a performance do seu site WordPress. Para alterá-las, consulte [Gerencie a aplicação](#gerencie-a-aplicacao).

O link pode levar alguns minutos para começar a entregar a aplicação, enquanto a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Gerencie a aplicação

As configurações que o template WordPress EdgeAccelerator aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação do seu site WordPress">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/).

Depois da implantação, você mantém controle total sobre o design, o conteúdo e a funcionalidade do seu site no painel de administração do WordPress. Para perguntas sobre o WordPress, consulte os canais oficiais do [WordPress](https://wordpress.com/).

## Adicione um domínio personalizado

A implantação do template WordPress EdgeAccelerator atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/) e [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).
