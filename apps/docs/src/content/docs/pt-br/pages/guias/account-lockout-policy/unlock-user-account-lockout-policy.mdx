Um *Account Owner* pode liberar um usuário que a [Account Lockout Policy](/pt-br/documentacao/fundamentos/account-lockout-policy/) bloqueou, pela API da Azion. Reserve o desbloqueio manual para casos excepcionais ou urgentes. Para ler os registros de bloqueio sem alterá-los, consulte [Verificar os logs da Account Lockout Policy](/pt-br/documentacao/guias/seguranca-de-aplicacoes/acesso-e-compliance/account-lockout-policy-logs/). Um usuário bloqueado que não é Account Owner encontra as opções em [Solucionar problemas de acesso ao Azion Console](/pt-br/documentacao/suporte/acesso-a-conta/).

---

## Pré-requisitos

- Privilégios de *Account Owner*. Uma requisição de qualquer outro usuário retorna *Erro 403*, assim como uma requisição em uma conta que não tem a política ativada.
- Um personal token para o header `Authorization`. Para criar um, consulte [Gerencie personal tokens](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).

---

## Encontre o usuário bloqueado

Confirme os dados do usuário nos registros de bloqueio antes de liberar alguém. O parâmetro de query `locked=true` limita a lista aos usuários bloqueados.

Envie uma requisição `GET` para o endpoint `identity/users`:

```bash
curl --request GET \
  --url https://api.azion.com/v4/identity/users?locked=true \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]'
```

A resposta é semelhante a esta:

```json
{
  "count": 2,
  "results": [
    {
      "id": 1,
      ...
      "lockout": {
        "locked_at": "20240101T10:20:01",
        "unlock_at": "20240102T10:20:01",
      }
    }
  ]
}
```

As chaves a ler na resposta:

| Chave | Descrição |
| ----------- | ----------- |
| `count` | Número de contas de usuário bloqueadas. Exemplo: `2` |
| `id` | Identificador único de um usuário |
| `lockout` | Período em que a conta do usuário fica bloqueada. `locked_at` é o timestamp do início do bloqueio, e `unlock_at` é o timestamp do fim |

Guarde o `id` do usuário que você quer liberar.

---

## Remova o bloqueio

O caminho da requisição leva o `id` do usuário da seção anterior no lugar de `{id}`.

Envie uma requisição `DELETE` para o endpoint `identity/users/{id}/lockout`:

```bash
curl --request DELETE \
  --url https://api.azion.com/v4/identity/users/{id}/lockout \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]' \
  --header 'Content-Type: application/json'
```

A resposta é semelhante a esta:

```json
{
  "status": "executed"
}
```

O bloqueio deixa de existir, e o usuário pode fazer login de novo.

Para todos os endpoints que a API expõe, consulte a [referência da API da Azion](https://api.azion.com/).
