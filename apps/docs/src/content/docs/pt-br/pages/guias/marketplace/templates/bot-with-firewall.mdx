Você pode adicionar [Bot Manager Lite](/pt-br/documentacao/plataforma/firewall/bot-manager/bot-manager-lite/) a um [Firewall](/pt-br/documentacao/plataforma/firewall/) que você já executa a partir do template Bot Manager Lite Integration Kit, no Azion Console. O template não cria nenhum Firewall, então ele pede o ID do seu. Para criar a Function Instance e a regra você mesmo, consulte [Primeiros passos com Bot Manager](/pt-br/documentacao/plataforma/firewall/bot-manager/primeiros-passos/).

---

## Pré-requisitos

- Um Firewall na sua conta e o ID dele.
- **Functions** ativado nesse Firewall. Um Firewall criado na página **Create Firewall**, com o Azion CLI ou com a API começa com **Functions** ativado. Para ativá-lo, consulte [Ative ou desative WAF, Network Shield ou Functions](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/firewall-definir-main-settings/#ative-ou-desative-waf-network-shield-ou-functions).
- Bot Manager Lite instalado pelo Marketplace. Para mais informações, consulte [Instale o Bot Manager Lite](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/bot-manager-lite/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- A Function Instance é executada em [Functions](/pt-br/documentacao/plataforma/functions/), o que pode gerar custos de uso. Para as métricas pelas quais o Bot Manager é cobrado, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#bot-manager).

O template verifica os três primeiros requisitos antes de criar qualquer coisa. Quando um deles não é atendido, a implantação falha e escreve uma linha de log que informa o motivo.

---

## Implante o template

Para implantar o template no Azion Console:

<DocSteps>
  <DocStep title="Copie o ID do Firewall">

  Acesse [Azion Console](https://console.azion.com/) > **Firewalls**, selecione o Firewall e copie o ID do endereço. O endereço termina em `/firewalls/edit/<firewall-id>`.

  </DocStep>
  <DocStep title="Abra o template">

  Acesse o template [Bot Manager Lite Integration Kit](https://console.azion.com/create/azion/bot--manager-integration-kit).

  </DocStep>
  <DocStep title="Informe o ID do Firewall">

  Em **Firewall ID**, informe o ID que você copiou.

  </DocStep>
  <DocStep title="Selecione Deploy" />
</DocSteps>

Quando a implantação termina, a aba **Functions Instances** do Firewall lista a nova Function Instance do Bot Manager Lite, e a aba **Rules Engine** lista a regra que a executa. A Function Instance carrega três argumentos:

```json
{
  "threshold": 10,
  "action": "allow",
  "internal_logs": 2
}
```

Um `threshold` de `10` é menor que o `30` com que o Bot Manager Lite é entregue, então a Function Instance aplica `action` a mais requisições do que o padrão entregue aplica. Uma `action` de `allow` não recusa nenhuma requisição. Um `internal_logs` de `2` escreve uma linha de log de report para cada requisição, qualquer que seja a pontuação.

Para alterar os argumentos, abra a Function Instance e edite a seção **Arguments** dela. Para os valores que cada argumento aceita, consulte [Argumentos](/pt-br/documentacao/plataforma/firewall/bot-manager/argumentos/).

:::caution[Atenção]
A API verifica se os argumentos são um objeto ou um array JSON, e não verifica nenhuma chave. Um argumento digitado errado, como `thresold`, é armazenado como foi digitado, a API e o Azion CLI não retornam nenhum erro, e `threshold` continua ausente da Function Instance. Para ver o que a Function faz sem ele, consulte [Threshold](/pt-br/documentacao/plataforma/firewall/bot-manager/argumentos/#threshold).
:::

## Leia o que a Function Instance pontuou

Com `internal_logs` definido como `2`, a Function Instance escreve uma linha de log de report para cada requisição que pontua, incluindo uma requisição que pontuou `0`. Para ler as linhas no Azion Console:

<DocSteps>
  <DocStep title="Abra o Real-Time Events">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events** e selecione a aba **Functions Console**.

  </DocStep>
  <DocStep title="Leia as linhas de report">

  Restrinja o período às requisições que você quer ler. Cada linha de report abre com `[Bot-Protection]` na coluna **Log Body** e carrega a pontuação de uma requisição.

  </DocStep>
</DocSteps>

Uma `action` de `allow` não recusa nada enquanto você lê as pontuações. Defina `threshold` e `action` pelas pontuações que o seu próprio tráfego produz, e não pelos valores do template. Para os campos que uma linha carrega, consulte [Logs](/pt-br/documentacao/plataforma/firewall/bot-manager/logs/). Para encaminhar as linhas para um destino seu, consulte [Data Stream](/pt-br/documentacao/plataforma/data-stream/).
