Você pode alterar a ordem em que um [Firewall](/pt-br/documentacao/plataforma/firewall/) executa as suas regras pelo Azion Console ou pela Azion CLI. Uma regra nova ocupa a última posição. Para saber como a posição de uma regra decide quais regras são executadas, consulte [Ordem das regras](/pt-br/documentacao/plataforma/firewall/como-funciona/#ordem-das-regras). Para reordenar as regras pela API, consulte [Reordene as regras de Application e Firewall](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/reordene-as-regras-de-application-e-firewall/).

Os exemplos movem a regra `siem - deny listed addresses` para cima da regra que aplica um rule set do WAF, no Firewall `<firewall-id>`. Substitua-os pelas suas regras e pelo seu Firewall.

## Mova uma regra para cima de outra

A regra que você move é executada antes de todas as regras abaixo dela, então uma requisição que ela nega nunca chega a elas.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

### Console

Para mover a regra pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a aba Rules Engine do Firewall">

  Acesse [Azion Console](https://console.azion.com/) > **Firewalls**, selecione o Firewall e vá para a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Mova a regra para cima">

  Na lista do **Rules Engine**, mova `siem - deny listed addresses` para cima da regra que aplica um rule set do WAF.

  </DocStep>
  <DocStep title="Selecione Review Changes">

  O diálogo **Review Changes** mostra a nova ordem.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

Azion Console mostra a mensagem **Reorder saved**, e a lista do **Rules Engine** mostra `siem - deny listed addresses` acima da regra que aplica um rule set do WAF.

</Fragment>

<Fragment slot="panel.cli">

### CLI

A Azion CLI define a ordem inteira de uma vez, a partir dos IDs de todas as regras do Firewall. Para ler os IDs, liste as regras do Firewall:

```bash
azion list firewall-rule --firewall-id <firewall-id>
```

O comando exibe uma linha por regra, na ordem em que as regras são executadas. Um nome com mais de 30 caracteres aparece cortado:

```text
ID              NAME                          ACTIVE  DESCRIPTION
<waf-rule-id>   <waf-rule-name>               true
<deny-rule-id>  siem - deny listed addresses  true
```

Envie todos os IDs de regra do Firewall na nova ordem, com a regra de negação primeiro:

```bash
azion update firewall-rule-order --firewall-id <firewall-id> --rule-ids "<deny-rule-id>,<waf-rule-id>"
```

O comando confirma a nova ordem:

```text
Ordered Rules Engine of Firewall with ID <firewall-id>
```

Uma lista que omite uma regra do Firewall falha com este erro:

```text
Error: Failed to order the rules in Rules Engine of the Firewall: ["When ordering you should provide the order for all rules."]. Check your settings and try again. If the error persists, contact Azion support.
```

Para confirmar a ordem, liste as regras do Firewall de novo:

```bash
azion list firewall-rule --firewall-id <firewall-id>
```

O comando exibe `siem - deny listed addresses` acima da regra que aplica um rule set do WAF:

```text
ID              NAME                          ACTIVE  DESCRIPTION
<deny-rule-id>  siem - deny listed addresses  true
<waf-rule-id>   <waf-rule-name>               true
```

Para todas as flags do comando, consulte [Azion CLI firewall-rule](/pt-br/documentacao/devtools/cli/recursos/firewall-rule/#ordenar-regras).

</Fragment>
</Tabs>

O Firewall executa `siem - deny listed addresses` antes da regra que aplica um rule set do WAF, então um endereço listado é recusado antes que WAF o inspecione. Como qualquer alteração salva, a nova ordem se propaga pela infraestrutura distribuída da Azion antes que as requisições a reflitam. Para mais informações, consulte [Propagação](/pt-br/documentacao/plataforma/firewall/como-funciona/#propagacao).

O caso de uso [Bloquear atacantes automaticamente a partir de detecções do SIEM](/pt-br/documentacao/casos-de-uso/proteger-aplicacoes-e-redes/bloquear-atacantes-automaticamente-a-partir-de-deteccoes-do-siem/) usa os valores deste exemplo.

No caso de uso [Inspecionar uploads de arquivos em busca de conteúdo malicioso](/pt-br/documentacao/casos-de-uso/proteger-aplicacoes-e-redes/inspecionar-uploads-de-arquivos-em-busca-de-conteudo-malicioso/), esta seção usa estes valores:

| Configuração | Valor |
| --- | --- |
| Posição | Abaixo de `upload - deny flagged senders` |
