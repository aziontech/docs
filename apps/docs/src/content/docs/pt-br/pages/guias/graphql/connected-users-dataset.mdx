Você pode contar as sessões únicas conectadas às suas transmissões do Live Ingest com o dataset `connectedUsersMetrics` da GraphQL API, por host ou no total entre todos os hosts. O dataset guarda dados agregados que o Live Ingest fornece, e o endpoint de métricas, `https://api.azion.com/v4/metrics/graphql`, os serve. Use os resultados para analisar a atividade da sua audiência ou para levá-los a outra plataforma de análise.

---

## Pré-requisitos

- Uma assinatura do Live Ingest na sua conta. Para saber o que o Live Ingest faz, consulte [Connectors](/pt-br/documentacao/plataforma/connectors/#live-ingest).
- Um [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) da sua conta.
- Uma forma de enviar uma query GraphQL, como o GraphiQL ou o `curl`. Para mais informações, consulte [Primeiros passos com a GraphQL API](/pt-br/documentacao/devtools/graphql/primeiros-passos/).

## Consulte as sessões únicas por host

Agrupe as linhas por `ts` e `host` para ler as sessões únicas de cada host em cada timestamp. Para consultar as sessões por host:

<DocSteps>
  <DocStep title="Escreva a query">

  Esta query lê as sessões de todos os hosts em uma janela de um dia, da mais recente para a mais antiga. Substitua os valores de `begin` e `end` pela sua janela:

  ```graphql
  query ConnectedUsers {
    connectedUsersMetrics(
      limit: 10000,
      filter: {
        tsRange:{
          begin: "2024-04-10T00:00:00",
          end: "2024-04-11T00:00:00"
        }
      },
      groupBy: [ts,host]
      orderBy: [ts_DESC]
    ) {
      ts,
      host,
      uniqueSessions
    }
  }
  ```

  A query usa estes argumentos:

  | Argumento | O que define |
  | --- | --- |
  | `limit` | O número máximo de linhas retornadas, de `0` a `10000`. Sem ele, a API retorna no máximo `10` linhas. |
  | `filter` | Os critérios que as linhas devem atender. Um filtro de tempo é obrigatório. `tsRange` recebe um timestamp `begin` e um `end` no formato `"YYYY-MM-DDTHH:mm:ss"`. |
  | `groupBy` | Os campos que agrupam as linhas: `ts`, `host` ou ambos. `[ts,host]` retorna uma linha por timestamp e host. |
  | `orderBy` | A ordem das linhas. `[ts_DESC]` retorna primeiro o timestamp mais recente, e `[ts_ASC]`, o mais antigo. |

  O dataset `connectedUsersMetrics` não aceita o argumento `resample`.

  </DocStep>
  <DocStep title="Envie a query">

  Envie a query em uma requisição `POST` para `https://api.azion.com/v4/metrics/graphql`, com o header `Authorization: Token [TOKEN VALUE]`.

  </DocStep>
  <DocStep title="Leia a resposta">

  A resposta traz um objeto por timestamp e host em `data.connectedUsersMetrics`, com os campos que a query seleciona:

  | Campo | Tipo | Descrição |
  | --- | --- | --- |
  | `ts` | `CustomDateTime` | O timestamp do ponto de dados. |
  | `host` | `String` | O host da requisição: o nome do host da linha de requisição, o nome do host do header de requisição `Host` ou o nome do servidor que corresponde à requisição. |
  | `uniqueSessions` | `Int` | As sessões únicas contadas para o host. |

  </DocStep>
</DocSteps>

A API responde com HTTP `200` e retorna as linhas em `data.connectedUsersMetrics`.

No caso de uso [Transmitir eventos ao vivo para grandes audiências](/pt-br/documentacao/casos-de-uso/entregar-midia-e-streaming/transmitir-eventos-ao-vivo-para-grandes-audiencias/), espere:

- **A audiência é contada.** Consulte o dataset `connectedUsersMetrics` para `live.example.com`, como esta seção mostra. A API responde `200`, e `data.connectedUsersMetrics` traz linhas para o tempo em que o player esteve conectado.

## Consulte o total entre hosts

O campo `uniqueSessionsTotal` conta as sessões únicas entre todos os hosts, por isso a query agrupa as linhas apenas por `ts` e deixa `host` de fora. Para consultar o total de sessões:

<DocSteps>
  <DocStep title="Escreva a query">

  Esta query lê o total de sessões em uma janela de um dia, da mais recente para a mais antiga. Substitua os valores de `begin` e `end` pela sua janela:

  ```graphql
  query ConnectedUsers {
    connectedUsersMetrics(
      limit: 10000,
      filter: {
        tsRange:{
          begin: "2024-04-10T00:00:00",
          end: "2024-04-11T00:00:00"
        }
      },
      groupBy: [ts]
      orderBy: [ts_DESC]
    ) {
      ts,
      uniqueSessionsTotal
    }
  }
  ```

  `limit` aceita até `10000` linhas, `filter` exige um filtro de tempo como `tsRange`, e `orderBy` aceita `[ts_DESC]` ou `[ts_ASC]`. `groupBy: [ts]` retorna uma linha por timestamp.

  </DocStep>
  <DocStep title="Envie a query">

  Envie a query em uma requisição `POST` para `https://api.azion.com/v4/metrics/graphql`, com o header `Authorization: Token [TOKEN VALUE]`.

  </DocStep>
  <DocStep title="Leia a resposta">

  A resposta traz um objeto por timestamp em `data.connectedUsersMetrics`, com os campos que a query seleciona:

  | Campo | Tipo | Descrição |
  | --- | --- | --- |
  | `ts` | `CustomDateTime` | O timestamp do ponto de dados. |
  | `uniqueSessionsTotal` | `Int` | As sessões únicas contadas entre todos os hosts. |

  </DocStep>
</DocSteps>

A API responde com HTTP `200` e retorna as linhas em `data.connectedUsersMetrics`.
