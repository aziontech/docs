Você pode implantar um site orientado a conteúdo na Azion a partir de um dos templates da coleção ButterCMS Templates no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

A coleção ButterCMS Templates facilita o gerenciamento colaborativo do conteúdo da sua aplicação. Cada template é um projeto inicial integrado ao [ButterCMS](https://buttercms.com/), um sistema de gerenciamento de conteúdo headless para criar e gerenciar sites orientados a conteúdo por meio de APIs. A coleção reúne cinco templates:

- **ButterCMS + Gatsby Starter Project**: um projeto inicial Gatsby totalmente funcional, integrado ao ButterCMS. Usa a versão `5.7.0` do Gatsby.
- **ButterCMS + Angular Starter Project**: um projeto inicial Angular totalmente funcional, integrado ao ButterCMS. Usa a versão `15.1.2` do Angular.
- **ButterCMS + Nuxt Starter Project**: um projeto inicial Nuxt totalmente funcional, integrado ao ButterCMS. Usa a versão `3.2.3` do Nuxt.
- **ButterCMS + React Starter Project**: um projeto inicial React totalmente funcional, integrado ao ButterCMS. Usa a versão `18.2.0` do React.
- **ButterCMS + Vue.js Starter Project**: um projeto inicial Vue.js totalmente funcional, integrado ao ButterCMS. Usa a versão `3.2.45` do Vue.js.

A implantação de cada template cria um repositório no GitHub para o seu projeto, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que o entrega e um domínio para acessá-lo. Os templates usam [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/), [Functions](/pt-br/documentacao/plataforma/functions/) e [Cache](/pt-br/documentacao/plataforma/applications/cache/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.
- Uma conta no [ButterCMS](https://buttercms.com/). O formulário de configuração pede a chave de API dessa conta.

## Implante um template

Cada template da coleção abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar um template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse o template que você quer implantar no Azion Console:

  - [ButterCMS + Gatsby Starter Project](https://console.azion.com/create/buttercms/gatsby-starter)
  - [ButterCMS + Angular Starter Project](https://console.azion.com/create/buttercms/angular-starter)
  - [ButterCMS + Nuxt Starter Project](https://console.azion.com/create/buttercms/nuxt-starter)
  - [ButterCMS + React Starter Project](https://console.azion.com/create/buttercms/react-starter)
  - [ButterCMS + Vue.js Starter Project](https://console.azion.com/create/buttercms/vue-starter)

  O formulário de configuração abre.

  </DocStep>
  <DocStep title="Conecte a Azion à sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub à Azion. Nessa janela, defina as permissões do app e o acesso aos repositórios.

  </DocStep>
  <DocStep title="Selecione o Git Scope">

  Selecione o **Git Scope** com o qual trabalhar.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Em **Application Name**, insira um nome único para a aplicação.

  </DocStep>
  <DocStep title="Insira a chave de API do ButterCMS">

  Em **ButterCMS API Key**, insira a chave de acesso da API do ButterCMS. A aplicação precisa dela para ler o seu conteúdo.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação. Nesse intervalo, a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Atualize o projeto

Cada push para o repositório do GitHub que o template cria é implantado automaticamente.

Para atualizar o projeto implantado, faça push das suas alterações para esse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

---

## Gerencie a aplicação

As configurações que o template aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo nome da aplicação.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/).

## Adicione um domínio personalizado

A implantação atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para adicionar um, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/). Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
