Você copia a tag JavaScript do [Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/) no Azion Console e a adiciona às páginas que quer medir. Para ler as medições que a tag coleta, consulte [Consulte as medições do Edge Pulse com GraphQL](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-medicoes-do-edge-pulse-com-graphql/).

Edge Pulse é ativado em toda conta Azion, então não há nada a criar no Azion Console. O único objeto que você altera é o HTML das suas páginas.

---

## Pré-requisitos

- Acesso ao Azion Console. Consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Acesso para editar e publicar o HTML das páginas que você mede, ou ao sistema de gerenciamento de tags que publica scripts nelas.

---

## Copie a tag que suas páginas precisam

A tag vem em duas formas, e as páginas decidem qual você usa. A **Default Tag** roda depois que o evento de carregamento termina, então não interrompe esse evento. A **Pre-loading Tag** roda antes que o evento de carregamento dispare. Use-a quando as páginas carregarem configurações de Content Security Policy que impedem JavaScript inline. A tag é customizada para a sua conta, então copie-a do seu próprio Console.

Para copiar a tag:

<DocSteps>
  <DocStep title="Abra Edge Pulse">

  Acesse [Azion Console](https://console.azion.com/) > **Products menu** > **Observe** > **Edge Pulse**.

  </DocStep>
  <DocStep title="Selecione a tag que suas páginas precisam">

  Selecione a **Default Tag**, ou a **Pre-loading Tag** quando as páginas impedirem JavaScript inline.

  </DocStep>
  <DocStep title="Selecione Copy to Clipboard" />
</DocSteps>

A tag está na sua área de transferência, pronta para colar em uma página.

---

## Adicione a tag às páginas que você mede

Edge Pulse mede uma página só quando essa página carrega a tag. A tag não é herdada de um caminho pai, de outra página do site nem de um template que você não republicou. As duas tags ficam no mesmo lugar, antes da tag `body` de fechamento.

Para adicionar a tag:

<DocSteps>
  <DocStep title="Cole a tag na página">

  No HTML da página, ou do template que a renderiza, cole a tag imediatamente antes da tag `body` de fechamento.

  </DocStep>
  <DocStep title="Repita em cada página que você mede">

  Cole a mesma tag página por página ou distribua a tag pelas páginas com um sistema de gerenciamento de tags.

  </DocStep>
  <DocStep title="Publique as páginas" />
  <DocStep title="Confira a página publicada">

  Abra uma página publicada, como `https://www.example.com/`, em um browser e veja o código-fonte da página. A tag que você copiou fica antes da tag `body` de fechamento.

  </DocStep>
</DocSteps>

Cada página publicada carrega a tag, e os browsers dos seus visitantes a executam. Nada é coletado até que um visitante carregue uma página com a tag, portanto as primeiras medições seguem o seu tráfego, não o momento em que você publicou.
