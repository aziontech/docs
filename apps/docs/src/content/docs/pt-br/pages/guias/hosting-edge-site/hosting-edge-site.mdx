Você pode servir uma página de status ou de erro com a função Hello World em uma aplicação, pelo Azion Console. A função responde na infraestrutura distribuída da Azion, então a requisição nunca chega à sua origem. Para instalar Hello World pelo Azion Marketplace com um código de status e um body, consulte [Instale a integração Hello World](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/hello-world/).

Uma página de status informa a situação de um serviço, para que você o monitore e avise os seus usuários. O exemplo desta página responde às requisições para `www.myapplication.com/api_service` com um aviso de que o serviço está temporariamente indisponível. Pelo [Data Stream](/pt-br/documentacao/plataforma/data-stream/), você também pode enviar os registros de acesso da página a um SIEM (Security Information and Event Management), Big Data ou log servers e analisar os dados lá.

---

## Pré-requisitos

- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [aplicação](/pt-br/documentacao/plataforma/applications/) que recebe as requisições da página de status.
- Application Accelerator e [Functions](/pt-br/documentacao/plataforma/functions/) ativados na aplicação. O behavior _Run Function_ exige os dois. Para mais informações, consulte [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/#run-function).

## Crie a instância da função

Uma aplicação executa uma função por meio de uma instância, e a instância passa os seus Args à função. A Azion fornece a função Hello World, e os Args dela definem o código de status HTTP e a mensagem da resposta. A instância do exemplo usa estes Args:

```json
{
    "param":{
        "http_status": 503,
        "body": "We are working hard to serve you better!"
    }
}
```

Para criar a instância no Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** e selecione a aplicação que serve a página de status.

  </DocStep>
  <DocStep title="Vá para a aba Functions Instances" />
  <DocStep title="Selecione + Function Instance" />
  <DocStep title="Dê um nome à instância">

  Digite um nome que a identifique. Por exemplo: `MyHelloWorld`.

  </DocStep>
  <DocStep title="Selecione a função">

  No campo **Function**, selecione _Hello World_. O campo **Code** mostra o código da função apenas para consulta.

  </DocStep>
  <DocStep title="Digite os Args">

  Na aba **Args**, digite o JSON com o seu código de status e a sua mensagem.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância `MyHelloWorld` está na aplicação. Ela só roda depois que uma regra do Rules Engine a seleciona.

---

## Adicione a regra que executa a instância

Uma regra do Rules Engine define os critérios que uma requisição precisa atender e os behaviors que rodam quando ela atende. Você pode adicionar o behavior à Default Rule ou criar uma nova regra. Aqui, uma nova regra executa `MyHelloWorld` quando a URI começa com `/api_service`.

Para criar a regra no Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** e selecione a aplicação que serve a página de status.

  </DocStep>
  <DocStep title="Selecione a aba Rules Engine" />
  <DocStep title="Selecione + Rule" />
  <DocStep title="Dê um nome à regra">

  Digite um nome para a regra.

  </DocStep>
  <DocStep title="Defina o critério">

  Na seção **Criteria**, selecione `${uri}` como variável e `starts_with` como operador, e digite `/api_service` como argumento.

  </DocStep>
  <DocStep title="Adicione o behavior">

  Na seção **Behaviors**, selecione _Run Function_ e depois selecione `MyHelloWorld`.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

Uma requisição para `www.myapplication.com/api_service` retorna o código de status `503` com o body `We are working hard to serve you better!`.
