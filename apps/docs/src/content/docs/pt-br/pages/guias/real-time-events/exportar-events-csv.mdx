Você pode baixar o resultado de uma busca do [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) como um arquivo CSV pelo Azion Console. O download pertence à visualização mais recente de Real-Time Events, acessada por **Switch to new view** e marcada com um selo **PREVIEW**. Esta página segue essa visualização, não a visualização em que Real-Time Events abre.

As duas visualizações usam palavras diferentes para as mesmas coisas. A visualização mais recente chama o seletor de índice de **Dataset**, e o campo de filtro dela recebe Azion Query Language. A visualização em que Real-Time Events abre chama esse seletor de **Data Sources**, e o campo **Filter by** dela recebe outra sintaxe.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Um produto que já escreve registros de evento, para que o dataset escolhido tenha registros para baixar.

Real-Time Events limita o período que uma busca pode pedir e as linhas que ela retorna, e um download herda os limites da busca por trás dele. Para cada um deles, consulte [Limites](/pt-br/documentacao/plataforma/real-time-events/limites/).

---

## Baixe o resultado de uma busca como um arquivo CSV

Uma busca é um dataset, um período e um filtro sobre eles. Reduza esses três primeiro: o download carrega o resultado da busca, não o dataset.

Para baixar o resultado pelo Azion Console:

<DocSteps>
  <DocStep title="Abra Real-Time Events">

  Acesse [Azion Console](https://console.azion.com) > **Products menu** > **Observe** > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione Switch to new view" />
  <DocStep title="Selecione o dataset">

  Em **Dataset**, selecione os registros que você quer ler. Por exemplo, _HTTP Requests_.

  </DocStep>
  <DocStep title="Defina o período">

  Defina o intervalo de tempo de início e fim para um período que contenha os registros.

  </DocStep>
  <DocStep title="Reduza o resultado">

  Informe uma condição no campo de filtro, que recebe Azion Query Language. O campo exibe `Filter using Azion Query Language syntax...` até você informar uma.

  </DocStep>
  <DocStep title="Selecione Refresh" />
  <DocStep title="Baixe o resultado">

  Ao lado do seletor de tamanho de página, selecione o controle de download. O controle carrega um ícone e nenhum texto.

  </DocStep>
</DocSteps>

O resultado é baixado como um arquivo CSV.

Real-Time Events informa quantos eventos a busca retornou, portanto você consegue saber se o resultado é o conjunto que você quer antes de baixá-lo. O painel **Fields** lista o que cada registro carrega, e `Search documents...` reduz as linhas que a tabela já contém.

Os nomes de campo nessa visualização são em camelCase, idênticos aos nomes que a API GraphQL usa, como `remoteAddress` e `httpUserAgent`. Para o que cada um carrega, consulte [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/).
