Você pode baixar o resultado de uma busca do [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) como arquivo CSV pelo Azion Console.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Um produto que já escreve registros de evento, para que a fonte de dados selecionada tenha registros para baixar.

Real-Time Events limita o período que uma busca pode pedir e as linhas que ela retorna. Um download herda os limites da busca por trás dele. Para cada um deles, consulte [Limites](/pt-br/documentacao/plataforma/real-time-events/limites/).

---

## Baixe o resultado de uma busca como um arquivo CSV

Uma busca é uma fonte de dados, um período e um filtro sobre eles. O download carrega o resultado dessa busca, não a fonte de dados inteira. Para baixar menos registros, filtre a busca primeiro, como descreve [Consultar eventos de requisição HTTP](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-workload-events/).

Para baixar o resultado pelo Azion Console:

<DocSteps>
  <DocStep title="Abra Real-Time Events">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione a fonte de dados">

  Selecione a aba dos registros que você quer baixar, como **HTTP Requests**.

  </DocStep>
  <DocStep title="Abra o período">

  Selecione o campo de período, que mostra _Last 5 minutes_.

  </DocStep>
  <DocStep title="Selecione o período">

  Selecione **Quick** e depois um período que contenha os registros, como _Last 24 hours_.

  </DocStep>
  <DocStep title="Execute a busca">

  Selecione **Update**.

  </DocStep>
  <DocStep title="Baixe o resultado">

  No cabeçalho da tabela, selecione o ícone de download, cuja dica mostra **Export to CSV**.

  </DocStep>
</DocSteps>

O navegador baixa o arquivo CSV na mesma hora. Na aba **HTTP Requests**, o arquivo é `http-requests-logs.csv`.

O arquivo tem as duas colunas da tabela, **Time** e **Log Body**. Ele carrega uma linha por registro que a busca encontrou, incluindo as linhas das outras páginas da tabela. A contagem de registros encontrados informa quantas linhas o arquivo terá antes de você baixá-lo.

**Log Body** lista cada campo pelo nome em camelCase, idêntico ao da API GraphQL, como `remoteAddress` e `httpUserAgent`. Para o que cada um carrega, consulte [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/).
