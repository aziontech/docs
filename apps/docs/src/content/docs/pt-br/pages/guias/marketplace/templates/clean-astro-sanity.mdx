Você pode implantar um site Astro mínimo na Azion a partir do template Clean Astro + Sanity application no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

O template cria um site [Astro](https://docs.astro.build/en/concepts/why-astro/) mínimo integrado ao [Sanity.io](http://sanity.io/), que gerencia o conteúdo do site. O template usa Astro `3.1.4`.

A implantação cria um repositório no GitHub para o seu projeto, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que o entrega e um domínio para acessá-lo. A aplicação usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/), [Functions](/pt-br/documentacao/plataforma/functions/) e [Cache](/pt-br/documentacao/plataforma/applications/cache/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.
- Uma conta do [Sanity.io](http://sanity.io/), com um projeto de blog do qual a aplicação lê o conteúdo. Para iniciar o projeto, use uma de duas opções:
  - **Sanity CLI**: crie o projeto gratuitamente selecionando o template de blog.
  - **Interface gráfica** (Sanity GUI): o uso dessa opção pode gerar custos. Para mais informações, consulte a página do [Sanity CMS](http://sanity.io/).

## Implante o template

O template Clean Astro + Sanity application abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Clean Astro + Sanity application](https://console.azion.com/create/sanity/clean-astro-sanity-app) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Conecte a Azion à sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub à Azion. Nessa janela, defina as permissões do app e o acesso aos repositórios.

  </DocStep>
  <DocStep title="Selecione o Git scope com o qual trabalhar" />
  <DocStep title="Nomeie a aplicação">

  Em **Application Name**, insira um nome único para a aplicação.

  </DocStep>
  <DocStep title="Insira os dados do projeto do Sanity">

  Insira os valores que apontam a aplicação para o seu conteúdo no Sanity:

  - **Sanity Studio Project ID**: o ID do projeto do qual a aplicação lê o conteúdo.
  - **Sanity Studio Dataset**: o dataset do qual a aplicação lê o conteúdo.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação, enquanto a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Atualize o projeto

Cada push para o repositório do GitHub que o template Clean Astro + Sanity application cria é implantado automaticamente.

Para atualizar o site implantado, faça push das suas alterações para esse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

---

## Gerencie a aplicação

As configurações que o template Clean Astro + Sanity application aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo nome da aplicação.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/).

## Adicione um domínio personalizado

A implantação do template Clean Astro + Sanity application atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para adicionar um, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/). Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
