O Massive Redirect redireciona um grande conjunto de URLs a partir de uma lista de regras, e mantém todos os redirecionamentos em um só lugar. Use-o em uma migração de domínio, uma migração de CMS ou de plataforma de e-commerce, ou uma atualização de site, seja qual for o número de páginas. Ele é uma das [integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/) que são executadas em uma aplicação.

Quatro objetos precisam existir antes de uma requisição ser redirecionada: a função instalada, uma aplicação com o módulo **Functions** ligado, uma instância de função que guarda os redirecionamentos e uma regra do Rules Engine com o behavior **Run Function**. Cada seção abaixo cria um deles.

---

## Pré-requisitos

- Uma conta Azion. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [aplicação](/pt-br/documentacao/plataforma/applications/) servida por um [workload](/pt-br/documentacao/plataforma/workloads/). Para criar uma, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
- Ligar um produto ou um módulo pode gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Instale a integração

A instalação adiciona a função Massive Redirect à sua conta. Para instalá-la pelo Azion Console:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Encontre a integração">

  Informe `Massive Redirect` no campo **Search on Marketplace** e selecione o card da integração. Navegar pelos cards e pelas categorias alcança a mesma página.

  </DocStep>
  <DocStep title="Selecione Install" />
</DocSteps>

O card mostra `Successfully installed!` e `Latest version installed!`. A função passa então a aparecer como _Massive Redirect [Global]_ na lista **Function** do drawer **Create Instance**.

---

## Ligue o módulo Functions

Uma aplicação executa uma função instalada apenas quando o módulo **Functions** dela está ligado. Para ligar o módulo:

<DocSteps>
  <DocStep title="Abra sua aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação**.

  </DocStep>
  <DocStep title="Abra a seção Modules">

  Na aba **Main Settings**, vá para a seção **Modules**.

  </DocStep>
  <DocStep title="Ligue o switch Functions" />
  <DocStep title="Selecione Save" />
</DocSteps>

O Azion Console confirma que a aplicação foi atualizada.

## Crie a instância de função

Uma instância de função guarda os redirecionamentos que a função Massive Redirect aplica a uma aplicação. Para criar a instância na sua aplicação:

<DocSteps>
  <DocStep title="Abra a aba Functions Instances">

  Em **Applications**, selecione sua aplicação e depois selecione a aba **Functions Instances**.

  </DocStep>
  <DocStep title="Selecione + Function">

  Uma aplicação que ainda não tem instância oferece a mesma ação como **Function Instance**. O drawer **Create Instance** abre.

  </DocStep>
  <DocStep title="Nomeie a instância">

  Em **Name**, informe um nome único que identifique a instância. Por exemplo: `massive-redirect-migration`.

  </DocStep>
  <DocStep title="Selecione a função">

  Em **Function**, selecione _Massive Redirect [Global]_. O editor **Arguments** é preenchido com os argumentos padrão da integração.

  </DocStep>
  <DocStep title="Edite os argumentos">

  Em **Arguments**, substitua os redirecionamentos padrão pelos seus. Cada chave está descrita na tabela abaixo.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância aparece na aba **Functions Instances** com o nome que você informou.

### Argumentos

Os argumentos são um array JSON. Cada objeto do array é um redirecionamento, então uma instância guarda vários redirecionamentos ao mesmo tempo. O arquivo JSON tem um limite de 300 kb. O editor carrega argumentos como estes:

```json
[
  {
    "from": "https://www.azion.com.br",
    "found": "https://www.azion.com"
  }, {
    "from_regex": "http://www\\.(azion)\\.com$",
    "moved": "https://www.%s.com"
  },{
    "from_regex":"http://www\\.azion\\.com/t/other/([\\w_]+)/([\\w_]+)/([\\w_]+)/$",
    "moved":"https://www.azion.com.br/doc/%3$/%1$/%2$/"
  }
]
```

Cada redirecionamento recebe uma chave de origem e uma chave de destino:

| Chave | Descrição |
|---|---|
| `from` | A URL anterior, aquela que redireciona para uma nova URL |
| `from_regex` | Um padrão que corresponde a vários endereços, para passar vários redirecionamentos em uma linha |
| `moved` | A nova URL, o destino de um redirecionamento permanente |
| `found` | A nova URL, o destino de um redirecionamento temporário |

Um redirecionamento sem uma chave `moved` ou `found` retorna um erro com o código `JA001`.

## Crie a regra

A instância é executada apenas quando uma regra do Rules Engine a chama. A regra abaixo corresponde às requisições a um domínio. Para criar a regra:

<DocSteps>
  <DocStep title="Abra a aba Rules Engine">

  Em **Applications**, selecione sua aplicação e depois selecione a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Em **Name**, informe um nome para a regra. Por exemplo: `Run Massive Redirect on xpto.com`. **Description** é opcional.

  </DocStep>
  <DocStep title="Selecione a fase">

  Na seção **Phase**, selecione _Request Phase_.

  </DocStep>
  <DocStep title="Defina o critério">

  Na seção **Criteria**, defina a variável como `${domain}` e o operador como _is equal_, e depois informe seu domínio como argumento. Por exemplo: `xpto.com`.

  </DocStep>
  <DocStep title="Adicione o behavior Run Function">

  Na seção **Behaviors**, selecione _Run Function_ e depois selecione a instância que você criou pelo nome dela.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A regra aparece na aba **Rules Engine**, na fase de requisição, e executa a instância do Massive Redirect nas requisições ao seu domínio.

Para cada critério e behavior que uma regra aceita, consulte [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/).
