Você pode importar um repositório do GitHub no Azion Console para fazer o build e o deploy dele como uma [aplicação](/pt-br/documentacao/plataforma/applications/). Após a importação, cada push no repositório faz o deploy dele de novo. Para fazer o deploy de um projeto pelo terminal, consulte [Azion CLI deploy](/pt-br/documentacao/devtools/cli/deploy/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Uma conta do GitHub.
- Um repositório construído com um framework que a lista **Preset** traz: Next.js, Angular, Astro, Hexo, React ou Vue. Para detalhes de cada framework, consulte [Compatibilidade com web frameworks](/pt-br/documentacao/devtools/runtime/frameworks/compatibilidade-frameworks/).
- O código do projeto na raiz do repositório, não em um subdiretório.

Para começar de um projeto que funciona, faça fork de um dos [exemplos de código da Azion](https://github.com/aziontech/azion-samples/tree/dev/templates) e importe o seu fork.

## Importe o repositório

O formulário de importação conecta o Azion Console à sua conta do GitHub, lê um repositório e faz o deploy dele com o preset de framework que você seleciona.

Para importar o repositório no Azion Console:

<DocSteps>
  <DocStep title="Abra o diálogo de criação">

  Acesse [Azion Console](https://console.azion.com/) > **Create**. O diálogo **New** abre.

  </DocStep>
  <DocStep title="Abra a aba Import from GitHub">

  No diálogo **New**, selecione a aba **Import from GitHub**. Em uma conta sem deployments, o botão **Import** da página **Home** abre a mesma aba.

  </DocStep>
  <DocStep title="Selecione o card de importação">

  Na aba **Import from GitHub**, selecione o card. A página **Import from GitHub** abre.

  </DocStep>
  <DocStep title="Conecte sua conta do GitHub">

  Na seção **GitHub Connection**, selecione **Connect with GitHub**. Uma janela do GitHub abre e pede que você instale o [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/). Defina as permissões e o acesso aos repositórios e confirme a instalação.

  O botão **Connect with GitHub** aparece somente enquanto nenhuma conta do GitHub está conectada.

  </DocStep>
  <DocStep title="Selecione o escopo">

  Em **Git Scope**, selecione a conta do GitHub da qual importar. Para conectar outra conta, selecione **Add GitHub Account**.

  </DocStep>
  <DocStep title="Selecione o repositório">

  Em **Repository**, selecione o repositório. A lista fica indisponível até você selecionar um escopo.

  </DocStep>
  <DocStep title="Dê um nome à aplicação">

  Na seção **General**, mantenha ou altere o **Application Name**. O Console preenche o campo com o nome do repositório.

  O nome deve ser único na sua conta; um nome já em uso retorna um erro. O bucket de armazenamento e a function do projeto recebem o mesmo nome.

  </DocStep>
  <DocStep title="Selecione o preset">

  Em **Preset**, selecione o framework do repositório: _Next.js_, _Angular_, _Astro_, _Hexo_, _React_ ou _Vue_. O preset define as configurações iniciais para esse framework.

  </DocStep>
  <DocStep title="Defina o diretório raiz">

  Em **Root Directory**, mantenha `/`, o padrão. O valor deve começar com `/` e não pode conter `..` nem espaços.

  </DocStep>
  <DocStep title="Informe o comando de instalação">

  Em **Install Command**, informe o comando que instala o projeto. Por exemplo: `npm install`.

  </DocStep>
  <DocStep title="(Opcional) Adicione variáveis do projeto">

  Na seção **Variables**, selecione **Variable** e informe uma **Key** e um **Value**. Por exemplo: chave `API_URL`, valor `www.apiurl.com/abc`.

  A chave aceita letras maiúsculas, números e underscores. Após o deploy, você pode editar uma variável, ou transformá-la em um segredo, na página **Variables** do menu **Account**.

  </DocStep>
  <DocStep title="Selecione Deploy">

  O botão **Deploy** fica indisponível até que cada campo obrigatório tenha um valor válido.

  </DocStep>
</DocSteps>

A página de deploy abre com o título `Deploy: <Application Name>` e mostra **Project is being created** enquanto o build roda.

## Verifique o deployment

A página de deploy de um repositório importado mostra a saída do build no painel **Deploy Log** e traz o link da aplicação quando o deploy termina.

Para verificar o deployment no Azion Console:

<DocSteps>
  <DocStep title="Acompanhe o build">

  Na página de deploy, leia a saída do build no painel **Deploy Log**. Quando o deploy termina, a notificação **Successfully created!** aparece.

  </DocStep>
  <DocStep title="Abra o domínio da aplicação">

  No card da aplicação, selecione o link do domínio. O domínio tem o formato `xxxxxxxxxx.map.azionedge.net`.

  </DocStep>
  <DocStep title="(Opcional) Abra as configurações da aplicação">

  Selecione **Manage**. As configurações da aplicação abrem no Console. Depois, você acessa as mesmas configurações pela página **Applications**.

  </DocStep>
</DocSteps>

A aplicação responde no seu domínio Azion. O primeiro deploy pode levar vários minutos para responder de todas as localidades. Se o domínio ainda não responder, aguarde alguns minutos e tente de novo.

Se o deploy falhar, a página mostra **Creation failed**. O painel **Deploy Log** traz os detalhes da falha.

O repositório continua conectado após a importação: cada push nele faz o deploy da aplicação de novo. Para servir a aplicação no seu próprio domínio em vez do domínio Azion, adicione um domínio personalizado.
