Você pode ler as URLs que o tráfego de bots mais alcançou no dataset `botManagerBreakdownMetrics`, no GraphiQL Playground ou com a GraphQL API. Para as contagens de classificação, consulte [Consulte dados do Bot Manager com GraphQL](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-bot-manager-com-graphql/).

---

## Pré-requisitos

- [Bot Manager](/pt-br/documentacao/plataforma/firewall/bot-manager/) em execução na sua conta. Em uma conta sem dados do Bot Manager, a consulta responde `200` com uma lista vazia.
- Para o Playground, uma sessão autenticada no Azion Console no mesmo navegador. Sem ela, o endpoint responde `401` com `Authentication credentials were not provided.` Para mais informações, consulte [GraphiQL Playground](/pt-br/documentacao/devtools/graphql/playground-graphql/).
- Para um cliente GraphQL, um personal token, enviado em um header `Authorization: Token [TOKEN VALUE]`. Para mais informações, consulte [Tokens pessoais](/pt-br/documentacao/fundamentos/personal-tokens/).

---

## Consulte as URLs que os bots mais alcançaram

O dataset conta as requisições que o Bot Manager classificou como bots, pelo host, pela URL e pelo endereço IP de cada requisição. A consulta a seguir o filtra por um intervalo de tempo, soma `botRequests` por URL e devolve as cinco URLs com o maior total.

Para consultar as URLs que os bots mais alcançaram:

<DocSteps>
  <DocStep title="Abra o Playground">

  Acesse `https://api.azion.com/v4/metrics/graphql`. A partir de um cliente GraphQL, envie a consulta para a mesma URL com o seu token.

  </DocStep>
  <DocStep title="Informe a consulta">

  Defina `begin` e `end` para o período que você quer ler. O dataset é retido por 60 dias:

  ```graphql
  query {
    botManagerBreakdownMetrics (
      filter: {
        tsRange: {
          begin: "2024-10-01T00:00:00"
          end: "2024-10-03T00:00:00"
        }
      }
      aggregate: {
        sum: botRequests
      }
      groupBy: [requestUrl]
      orderBy: [sum_DESC]
      limit: 5
    ) {
      requestUrl
      sum
    }
  }
  ```

  </DocStep>
  <DocStep title="Execute a consulta e leia a resposta">

  A resposta carrega um objeto por URL, com as requisições somadas em `sum`:

  ```json
  {
    "data": {
      "botManagerBreakdownMetrics": [
        {
          "requestUrl": "example-host1.com/api/v1/resource",
          "sum": 333543
        },
        {
          "requestUrl": "example-host2.net/api/v2/data",
          "sum": 107281
        },
        {
          "requestUrl": "example-host3.org/api/v3/info",
          "sum": 103363
        },
        {
          "requestUrl": "example-host4.io/api/v4/details",
          "sum": 89668
        },
        {
          "requestUrl": "example-host5.co/api/v5/summary",
          "sum": 64060
        }
      ]
    }
  }
  ```

  </DocStep>
</DocSteps>

Você agora tem as URLs que o tráfego de bots mais alcançou no período, ordenadas pelo número de requisições classificadas como bots. Para cada campo do dataset, consulte [botManagerBreakdownMetrics](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-metrics/#metricas-de-detalhamento-de-bot-manager).

## Mude o agrupamento ou a soma

A consulta anterior combina um campo do dataset com uma soma. O argumento `groupBy` aceita `host`, `remoteAddr`, `requestUrl` e `ts`, e `sum` aceita `botRequests` e `badBotRequests`. O campo `uniqRequestUrl` pode ser selecionado, mas não agrupado nem somado: como soma, ele é recusado com `Value 'uniqRequestUrl' does not exist in 'BotManagerBreakdownMetricsAggregatedFields' enum.`

Para ler o mesmo período de outra forma:

<DocSteps>
  <DocStep title="Mude o agrupamento">

  Defina `groupBy` como `[host]` ou como `[remoteAddr]` e selecione o mesmo campo no lugar de `requestUrl`. A consulta então totaliza as requisições por host ou por endereço IP de origem.

  </DocStep>
  <DocStep title="Mude a soma">

  Defina `aggregate` como `sum: badBotRequests` para contar apenas as requisições classificadas como bad bots, que são um subconjunto das requisições que `botRequests` conta.

  </DocStep>
  <DocStep title="Execute a consulta" />
</DocSteps>

A resposta carrega um objeto por host, endereço IP de origem ou URL, com a soma escolhida em `sum`.
