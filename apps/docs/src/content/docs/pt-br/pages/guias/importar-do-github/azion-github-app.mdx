Você pode conectar o Azion GitHub App pelo Azion Console, revisar, suspender, desinstalar ou revogar o app nas configurações do GitHub, ou remover a conexão pelo Azion Console. O app vincula sua conta do GitHub à sua conta Azion. A Azion pode então importar seus repositórios e fazer o deploy de cada push que você fizer neles. Para importar um repositório e fazer o deploy dele, consulte [Importe um projeto do GitHub](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/importar-um-projeto-existente-do-github/). GitHub é uma marca registrada da GitHub, Inc.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Uma conta do GitHub, pessoal ou de organização. Para instalar o app em uma organização, você deve ser o proprietário da organização ou ter permissão de administrador em um repositório.

---

## O que o app pode acessar

O Azion GitHub App pede estas permissões quando você o instala. Decida a conta e os repositórios antes de conectar:

| Área | Acesso |
| --- | --- |
| Conta | Instala em uma conta pessoal ou em uma organização. Você seleciona a conta na janela do GitHub que abre durante a autorização. Em uma organização, somente os proprietários gerenciam as configurações do app instalado. |
| Identidade e código | Verifica sua identidade no GitHub. Lê o código, os metadados e os recursos que sua conta pode acessar. |
| Repositórios | Lê todos os repositórios da conta, ou somente os repositórios que você seleciona. Você define isso durante a instalação e pode editar no GitHub a qualquer momento. |
| Deploy contínuo | Faz o deploy de cada push em um repositório conectado no seu ambiente Azion, para que o projeto fique atualizado. |

## Conecte o GitHub

O Azion Console conecta o GitHub em **Account Settings**, que você abre no menu da conta, sob o seu avatar. Para conectar o Azion GitHub App no Azion Console:

<DocSteps>
  <DocStep title="Abra Account Settings">

  Acesse [Azion Console](https://console.azion.com/) > **Account Settings**.

  </DocStep>
  <DocStep title="Selecione Connect with GitHub">

  Na seção **GitHub Integration**, selecione **Connect with GitHub**. O GitHub abre em uma nova janela.

  </DocStep>
  <DocStep title="Selecione a conta do GitHub">

  Na janela do GitHub, selecione a conta pessoal ou a organização a conectar.

  </DocStep>
  <DocStep title="Escolha o acesso aos repositórios">

  Dê ao app acesso a todos os repositórios ou selecione os repositórios que ele pode ler.

  </DocStep>
  <DocStep title="Confirme a instalação" />
</DocSteps>

O Azion Console mostra **GitHub integration connected successfully**. A seção **GitHub Integration** lista a conta em **Connected Account**, marcada como **Integration active**.

Você também pode conectar o GitHub em dois outros momentos, com a mesma janela do GitHub:

- Quando você se cadastra na Azion com sua conta do GitHub.
- Quando você faz o deploy de um dos [Azion Templates](/pt-br/documentacao/plataforma/marketplace/templates/) ou importa um projeto do GitHub. A seção **GitHub Connection** do formulário mostra **Connect with GitHub** até que uma conta esteja conectada.

Nesses formulários, o campo **Git Scope** seleciona a conta do GitHub conectada da qual a Azion lê o projeto. Para conectar outra conta, abra a lista **Git Scope** e selecione **Add GitHub Account**.

## Revise o app no GitHub

Após a instalação, o Azion GitHub App aparece entre as aplicações instaladas nas configurações do GitHub. No GitHub, **Settings** fica no menu da conta, sob o seu avatar, e **Applications** fica na seção **Integrations** desse menu. Para abrir a página de configuração do app:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Faça login no [GitHub](https://github.com/login) e vá para **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Configure o app">

  Na aba **Installed GitHub Apps**, encontre o Azion GitHub App e selecione **Configure**.

  </DocStep>
</DocSteps>

A página de configuração mostra a descrição do app e as **Permissions** dele. Nela, você pode editar as configurações de **Repository access**. A seção **Danger zone** traz as opções para suspender e desinstalar o app.

A página **Applications** tem três abas:

- **Installed GitHub Apps**: os GitHub Apps instalados na sua conta.
- **Authorized GitHub Apps**: os GitHub Apps que têm acesso à sua conta.
- **Authorized OAuth Apps**: os OAuth Apps que têm acesso à sua conta.

Para mais informações, consulte [GitHub Apps](https://docs.github.com/en/apps).

## Suspenda o app

Uma suspensão impede o Azion GitHub App de ler os recursos da sua conta e mantém a instalação, para que você possa restaurá-la. Para suspender o app no GitHub:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Faça login no [GitHub](https://github.com/login) e vá para **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Configure o app">

  Na aba **Installed GitHub Apps**, encontre o Azion GitHub App e selecione **Configure**.

  </DocStep>
  <DocStep title="Selecione Suspend">

  Na seção **Danger zone**, selecione **Suspend**.

  </DocStep>
  <DocStep title="Confirme a suspensão" />
</DocSteps>

O app não tem mais acesso aos recursos da sua conta. A seção **Danger zone** mostra **Unsuspend**, que restaura o acesso.

---

## Desinstale o app

A desinstalação remove o Azion GitHub App da sua conta do GitHub e revoga o acesso dele a todos os recursos da conta. Para desinstalar o app no GitHub:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Faça login no [GitHub](https://github.com/login) e vá para **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Configure o app">

  Na aba **Installed GitHub Apps**, encontre o Azion GitHub App e selecione **Configure**.

  </DocStep>
  <DocStep title="Selecione Uninstall">

  Na seção **Danger zone**, selecione **Uninstall**.

  </DocStep>
  <DocStep title="Confirme a desinstalação" />
</DocSteps>

O app é removido da sua conta do GitHub. Para instalá-lo de novo, consulte [Conecte o GitHub](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/#conecte-o-github).

---

## Revogue a autorização do app

Uma revogação impede o Azion GitHub App de chamar a API do GitHub para a sua conta. Você não pode desfazer uma revogação. Para revogar a autorização no GitHub:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Faça login no [GitHub](https://github.com/login) e vá para **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Selecione Revoke">

  Na aba **Authorized GitHub Apps**, encontre o Azion GitHub App e selecione **Revoke**.

  </DocStep>
  <DocStep title="Confirme a revogação" />
</DocSteps>

O Azion GitHub App não pode mais acessar a API do GitHub para a sua conta.

---

## Desconecte da Azion

Você remove uma conta do GitHub conectada em **Account Settings**. Para remover a conexão no Azion Console:

<DocSteps>
  <DocStep title="Abra Account Settings">

  Acesse [Azion Console](https://console.azion.com/) > **Account Settings**.

  </DocStep>
  <DocStep title="Selecione Remove">

  Na seção **GitHub Integration**, encontre a conta em **Connected Account** e selecione **Remove**.

  </DocStep>
</DocSteps>

O Azion Console mostra **GitHub integration removed successfully**, e a conta não aparece mais em **Connected Account**.
