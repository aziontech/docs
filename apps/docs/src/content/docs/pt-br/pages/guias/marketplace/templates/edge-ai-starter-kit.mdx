Você pode implantar o template **AI Inference Starter Kit** e gerenciar o que ele cria pelo Azion Console. O template cria um Workload com o deployment dele, uma Application e uma Function com a Function Instance dela, e a Function serve um endpoint compatível com OpenAI no workload domain do Workload.

O guia [Primeiros passos com AI Inference](/pt-br/documentacao/plataforma/ai-inference/primeiros-passos/) cobre a mesma implantação e acrescenta uma primeira requisição ao modelo.

## Pré-requisitos

O template usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/), [Functions](/pt-br/documentacao/plataforma/functions/) e [AI Inference](/pt-br/documentacao/plataforma/ai-inference/), que podem gerar custos de uso. Para conhecer os valores, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Implante o template

Para criar essas entidades a partir de um único template:

<DocSteps>
  <DocStep title="Acesse Azion Console">

  Acesse [Azion Console](https://console.azion.com/) e selecione **+ Create**.

  </DocStep>
  <DocStep title="Selecione o template AI Inference Starter Kit">

  Em **Start from Template**, selecione **AI Inference Starter Kit**.

  </DocStep>
  <DocStep title="Insira um nome para a aplicação">

  Em **Application Name**, insira um nome feito de letras, números e sublinhados, como o padrão `ai_inference_starter_kit`. Um hífen é recusado com "The use of accents and/or special characters is not allowed."

  </DocStep>
  <DocStep title="Selecione Deploy">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando ela termina, a página mostra o domínio em **Visit site**, a opção **Add custom domain**, os **Deployment logs** e **Resources created**, que lista o Workload e a Application.

:::note[nota]
A implantação leva vários minutos para se propagar aos data centers da Azion. Até se propagar, o domínio responde com o `404` de placeholder da Azion. Aguarde alguns minutos e selecione **Visit site** novamente.
:::

A Application responde no workload domain do Workload, na forma `xxxxxxxxxx.map.azionedge.net`, e a Function serve um endpoint compatível com OpenAI em qualquer path desse domínio. Para conhecer o caminho que uma requisição percorre do domínio até o modelo, consulte a arquitetura de [Adicionar funcionalidades de IA a aplicações existentes](/pt-br/documentacao/casos-de-uso/construir-e-executar-workloads-de-ai/adicionar-funcionalidades-de-ia-a-aplicacoes-existentes/).

## Atualize a função

A função que o template instala contém a chamada ao modelo, e a página dela tem três abas:

- **Main Settings** renomeia a função e altera as configurações básicas dela.
- **Code** contém o código da função.
- **Arguments** define os argumentos que a função usa.

Para alterar a função:

<DocSteps>
  <DocStep title="Acesse Functions">

  Acesse [Azion Console](https://console.azion.com/) > **Functions**.

  </DocStep>
  <DocStep title="Selecione a função">

  Selecione a Function que tem o nome que você inseriu durante a implantação, seguido do sufixo "(Build at …)". A lista está em ordem alfabética, e a **barra de busca** a filtra apenas por **Function Name**.

  </DocStep>
  <DocStep title="Abra a aba que contém a configuração">

  Abra a aba que contém a configuração que você quer alterar.

  </DocStep>
  <DocStep title="Selecione Save">

  Selecione **Save**.

  </DocStep>
</DocSteps>

A função tem as alterações que você salvou. Para conhecer todas as configurações que uma função tem, consulte [Functions](/pt-br/documentacao/plataforma/functions/).

A aba **Code** contém o código que o template instala. A cada requisição, a Function:

- Aceita só uma requisição `POST` cujo header `Content-Type` seja exatamente `application/json`. Qualquer outra requisição recebe `400` com `{"error":"Request must be a POST request with JSON body"}`.
- Lê o id do modelo do campo `model` do corpo da requisição. Um corpo sem esse campo recebe `400` com `{"error":"Missing 'model' field in request body"}`.
- Passa o corpo inteiro para `Azion.AI.run` e retorna a resposta do modelo. Com `stream` definido como `true`, ela transmite a resposta como server-sent events, uma linha `data:` por parte, terminando com `data: [DONE]`.

O código não contém nenhum id de modelo. Para chamar outro modelo, altere o campo `model` da requisição para o id dele, listado em [Modelos de AI](/pt-br/documentacao/plataforma/ai-inference/modelos/). Para conhecer todos os campos que o corpo aceita, consulte [Invocação de modelos](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/).

A resposta do modelo mantém o formato de chat completion, e o texto gerado fica em `choices[0].message.content`. O campo `model` dela traz o id interno da conta para o modelo, que pode ser diferente do id que a requisição enviou: `Qwen/Qwen3-30B-A3B-Instruct-2507-FP8` retorna `qwen-qwen3-30b-a3b-instruct-2507-fp8`. Para enviar uma primeira requisição e ler uma resposta completa, consulte [Primeiros passos com AI Inference](/pt-br/documentacao/plataforma/ai-inference/primeiros-passos/).

Antes de alterar o código, leia [Boas práticas do AI Inference](/pt-br/documentacao/plataforma/ai-inference/boas-praticas/) para conhecer os padrões de requisição que Azion recomenda, e [Limites do AI Inference](/pt-br/documentacao/plataforma/ai-inference/limites/) para conhecer as condições em que Azion encerra um modelo.

## Gerencie a aplicação

A página da aplicação contém todas as configurações que a implantação criou, e você pode alterar qualquer uma delas. Para abri-la:

<DocSteps>
  <DocStep title="Acesse Applications">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**.

  </DocStep>
  <DocStep title="Selecione a aplicação">

  Selecione a aplicação que tem o nome que você inseriu durante a implantação. A lista está em ordem alfabética, e a **barra de busca** a filtra apenas por **Application Name**.

  </DocStep>
</DocSteps>

A página da aplicação abre nas configurações que você pode ajustar. Para saber o que cada configuração faz, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
