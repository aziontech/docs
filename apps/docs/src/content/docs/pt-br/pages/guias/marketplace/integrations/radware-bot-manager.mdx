A integração **Radware Bot Manager** usa uma engine proprietária, chamada **Intent-based Deep Behavior Analysis** (IDBA), que coleta mais de 250 parâmetros, além de uma análise granular de intenção por modelagem comportamental para compreender a intenção do visitante. Assim, o Radware Bot Manager é uma integração completa para defender os seus ativos online contra ataques de bots, como account takeover, spam em formulários, fraude publicitária e muitas outras ameaças OWASP.

---

## Obtenha a integração pelo Azion Marketplace

Para obter a integração, siga estes passos:

1. Acesse o [Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/) > **Marketplace**.
2. Na página inicial do Marketplace, selecione o card da integração.
3. Quando a página da integração abrir, selecione **Install**.

Uma mensagem de sucesso aparece. A sua integração está instalada.

:::tip[dica]
Você pode procurar qualquer integração navegando pelos cards, usando os filtros ou digitando uma palavra-chave na barra de busca.
:::

## Configure a integração

A integração obtida no Marketplace é acrescentada à sua lista de **Functions**. Esta integração é executada sob o **Firewall** da Azion; portanto, você deve configurá-la antes de usá-la.

### Crie um firewall

Para instanciar a integração **Radware Bot Manager**, siga estes passos:

1. Acesse **Firewalls** no Azion Console.
2. Selecione o botão **+ Firewall**.
3. Dê um nome ao seu firewall.
4. Habilite o switch **Functions** para habilitar functions nas suas aplicações.
5. Selecione **Save**.

Pronto. Agora você instanciou o firewall para a sua função.

### Configure a função do firewall

Para instanciar a integração **Radware Bot Manager**, ainda na página do Firewall:

1. Selecione a aba **Functions Instances**.
2. Selecione o botão **+ Function Instance**.
3. Dê um nome à sua instância.
4. No menu suspenso, selecione a função **Radware Bot Manager**.
    - Esta ação carrega a aba **Arguments**.
5. Na aba **Arguments**, acrescente os parâmetros.

:::note[nota]
O nome listado no menu suspenso é diferente do nome que está no Marketplace.
:::

A aba **Arguments** carrega um arquivo JSON parecido com este:

```json
{
    "api_key": "Your-API-Key",
    "env_id": "Your-Env-ID"
}
```

6. Selecione **Save**.

Pronto. Agora a sua instância do Radware Bot Manager está salva.

### Configure o Rules Engine do firewall

Para concluir, você configura um **Rules Engine** para definir o *behavior* e os *criteria* que executam a função.

Ainda na página do **Firewall**:

1. Selecione a aba **Rules Engine**.
2. Selecione o botão **+ Rule**.
3. Dê um nome à regra.
4. Selecione um *criteria* para executar e capturar os domínios em que você quer executar a integração.
  - Exemplo: if `Host` *matches* `yourdomain.com`.
5. Abaixo, selecione um *behavior* para os *criteria*. Neste caso, será **Run Function**.
    - Selecione a função adequada de acordo com o nome que você deu a ela na etapa de instanciação.
6. Selecione **Save**.

No Console, você deve agora configurar o seu domínio para que ele seja protegido pelo seu firewall.

7. Acesse **Workloads** no Azion Console.
8. Selecione o domínio que você quer proteger com a sua função Radware Bot Manager.
9. Na seção **Settings**, abra o seletor `Firewall` e escolha o firewall que você acabou de criar.
10. Selecione **Save**.

Pronto. Agora a integração **Radware Bot Manager** é executada para toda requisição feita ao domínio que você indicou.
