Neste tutorial, você vai criar uma galeria de imagens cujas imagens ficam num bucket do [Object Storage](/pt-br/documentacao/plataforma/object-storage/). Você vai enviar duas imagens a um bucket, escrever uma Function que lista o bucket e serve cada imagem e publicar a Function por meio de uma Application e de um Workload.

Cada recurso que o tutorial cria se liga a um criado antes dele:

1. O bucket guarda as imagens. O **Workloads Access** dele é somente leitura, então as Functions o leem e não o alteram.
2. A [Function](/pt-br/documentacao/plataforma/functions/) lê o bucket com o módulo `azion:storage` e monta a página da galeria.
3. A [Application](/pt-br/documentacao/plataforma/applications/) tem Functions ativado, uma function instance que vincula a Function e uma regra de requisição que a executa em todos os caminhos.
4. O [Workload](/pt-br/documentacao/plataforma/workloads/) guarda o domínio que recebe as requisições, e o deployment dele define a Application que as responde.

Os recursos são os mesmos no Azion Console, na Azion CLI e na API. Selecione a interface que você usa, e cada etapa mostra os passos dela.

## 1. Crie as imagens

Crie um diretório para o tutorial e entre nele. Depois, escreva duas imagens SVG, um quadrado laranja e um círculo azul:

```bash
echo '<svg xmlns="http://www.w3.org/2000/svg" width="160" height="160"><rect width="160" height="160" fill="orange"/></svg>' > orange.svg
echo '<svg xmlns="http://www.w3.org/2000/svg" width="160" height="160"><circle cx="80" cy="80" r="70" fill="steelblue"/></svg>' > blue.svg
```

O diretório guarda `orange.svg` e `blue.svg`.

## 2. Crie o bucket e envie as imagens

Escolha um nome para o bucket. O nome de um bucket é único entre todas as contas Azion e tem de 6 a 63 caracteres: letras minúsculas, números e hífens, começando e terminando com uma letra ou um número. Onde um passo mostrar `<your-bucket-name>`, use o seu nome.

### API

Guarde o seu personal token e o nome do seu bucket em variáveis do shell. Substitua `<your-personal-token>` pelo seu token:

```bash
export AZION_API_TOKEN="<your-personal-token>"
BUCKET=<your-bucket-name>
```

Crie o bucket com acesso somente leitura para os Workloads:

```bash
curl --silent https://api.azion.com/v4/workspace/storage/buckets \
  --header "Authorization: Token $AZION_API_TOKEN" \
  --header 'Content-Type: application/json' \
  --data "{\"name\": \"$BUCKET\", \"workloads_access\": \"read_only\"}"
```

```json
{"state":"executed","data":{"name":"gallery-api-xcjstk","workloads_access":"read_only",...}}
```

Envie cada imagem como corpo de uma requisição `POST` para a chave do objeto. O `Storage-Content-Type` define o tipo do objeto:

```bash
for image in orange.svg blue.svg; do
  curl --silent https://api.azion.com/v4/workspace/storage/buckets/$BUCKET/objects/$image \
    --header "Authorization: Token $AZION_API_TOKEN" \
    --header 'Content-Type: application/octet-stream' \
    --header 'Storage-Content-Type: image/svg+xml' \
    --data-binary @$image
  echo
done
```

```text
{"state":"executed","data":{"object_key":"orange.svg"}}
{"state":"executed","data":{"object_key":"blue.svg"}}
```

O bucket guarda as duas imagens.

## 3. Escreva a Function

Crie um arquivo `index.js` com este código. Na terceira linha, substitua `<your-bucket-name>` pelo nome do seu bucket:

```javascript title="index.js"
import Storage from 'azion:storage'

const BUCKET = '<your-bucket-name>'

export default {
  async fetch(request) {
    const storage = new Storage(BUCKET)
    const { pathname } = new URL(request.url)
    if (pathname === '/') {
      const { entries } = await storage.list()
      const figures = entries
        .filter((entry) => entry.key.endsWith('.svg'))
        .map((entry) => `<figure><img src="/images${entry.key}" alt="${entry.key.slice(1)}" width="160"><figcaption>${entry.key.slice(1)}</figcaption></figure>`)
        .join('')
      return new Response(`<!doctype html><html lang="en"><head><meta charset="utf-8"><title>Gallery</title></head><body><h1>Gallery</h1>${figures}</body></html>`, {
        headers: { 'content-type': 'text/html; charset=utf-8' }
      })
    }
    if (pathname.startsWith('/images/')) {
      try {
        const object = await storage.get(pathname.slice('/images/'.length))
        return new Response(object.content, { headers: { 'content-type': 'image/svg+xml' } })
      } catch (error) {
        return new Response('Not found', { status: 404 })
      }
    }
    return new Response('Not found', { status: 404 })
  }
}
```

A Function responde a duas rotas, ambas lidas do bucket:

- `GET /` lista o bucket com `storage.list()`. Cada entrada traz a chave de um objeto com uma barra inicial, como `/orange.svg`, e a Function escreve um `<figure>` por SVG.
- `GET /images/<key>` lê um objeto com `storage.get(key)` e devolve o conteúdo dele. Uma chave sem objeto responde `404`.

Para todos os métodos do módulo, consulte [Object Storage API](/pt-br/documentacao/devtools/runtime/api-reference/storage/).

## 5. Crie a Application

A Application precisa de três partes: a própria Application com Functions ativado, uma function instance que vincula a Function e uma regra que executa a instance.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

### Console

Para criar a Application:

1. Acesse [Azion Console](https://console.azion.com/) > **Applications**.
2. Selecione **+ Application**.
3. Em **Name**, digite `gallery`.
4. Em **Modules**, ative **Functions**.
5. Selecione **Create**.

O Console abre a Application nova na aba **Main Settings**.

Para vincular a Function:

1. Selecione a aba **Functions Instances**.
2. Selecione **+ Function**.
3. Em **Name**, digite `gallery`.
4. Em **Function**, selecione `gallery`.
5. Selecione **Save**.

Para executar a Function em toda requisição:

1. Selecione a aba **Rules Engine**.
2. Selecione **+ Rule**.
3. Em **Name**, digite `Run gallery`.
4. Mantenha **Request Phase** selecionado.
5. Em **Criteria**, mantenha `${uri}` e **starts with**, e digite `/` como argumento.
6. Em **Behaviors**, troque **Deliver** por **Run Function**.
7. No campo de function instance que **Run Function** adiciona, selecione a instance `gallery`.
8. Selecione **Save**.

A regra aparece na fase de requisição da aba **Rules Engine**.

</Fragment>

<Fragment slot="panel.cli">

### CLI

Crie a Application com Functions ativado:

```bash
azion create application --name gallery --function true --active true
```

```text
Created Application with ID 1794609946
```

Guarde o ID. Substitua `1794609946` pelo seu ID:

```bash
APPLICATION_ID=1794609946
```

Vincule a Function à Application:

```bash
azion create function-instance --application-id $APPLICATION_ID --function-id $FUNCTION_ID --name gallery
```

```text
Created Function Instance with ID 64713
```

Guarde o ID. Substitua `64713` pelo seu ID:

```bash
INSTANCE_ID=64713
```

Escreva num arquivo `rule.json` a regra que executa a instance em todos os caminhos:

```bash
cat > rule.json <<EOF
{
  "name": "Run gallery",
  "criteria": [[{ "variable": "\${uri}", "conditional": "if", "operator": "starts_with", "argument": "/" }]],
  "behaviors": [{ "type": "run_function", "attributes": { "value": $INSTANCE_ID } }]
}
EOF
```

Crie a regra na fase de requisição:

```bash
azion create rules-engine --application-id $APPLICATION_ID --phase request --file rule.json
```

```text
Created Rules Engine with ID 1547629
```

</Fragment>

## 7. Abra a galeria

Um Workload novo pode levar cerca de dez minutos para se propagar pela rede da Azion. Até lá, o domínio responde `404` com uma página de erro em HTML, e pode alternar entre `404` e a resposta da Function por alguns minutos.

Se você usou o Console, defina antes `DOMAIN` com o seu domínio, com `DOMAIN=<your-domain>`. Envie uma requisição à página da galeria:

```bash
curl "https://$DOMAIN/"
```

Repita a requisição a cada minuto até a página voltar três vezes seguidas. Ela lista uma figura por imagem:

```html
<!doctype html><html lang="en"><head><meta charset="utf-8"><title>Gallery</title></head><body><h1>Gallery</h1><figure><img src="/images/blue.svg" alt="blue.svg" width="160"><figcaption>blue.svg</figcaption></figure><figure><img src="/images/orange.svg" alt="orange.svg" width="160"><figcaption>orange.svg</figcaption></figure></body></html>
```

Envie uma requisição a uma imagem e imprima o status e o tipo:

```bash
curl --silent --output /dev/null --write-out '%{http_code} %{content_type}\n' "https://$DOMAIN/images/orange.svg"
```

```text
200 image/svg+xml
```

Abra `https://<your-domain>/` num navegador para ver as duas imagens, cada uma com o nome do arquivo.

## 8. (Opcional) Exclua os recursos

A galeria continua no ar no seu domínio depois do tutorial. Se você quiser remover os recursos, exclua-os na ordem inversa da criação. Excluir o Workload também exclui o deployment dele, e excluir a Application também exclui a instance e a regra dela.

Um bucket só é excluído quando está vazio e nenhum objeto foi removido dele nas últimas 24 horas. Para remover também o bucket, exclua primeiro os objetos e o bucket um dia depois.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

### Console

Para excluir o Workload:

1. Acesse [Azion Console](https://console.azion.com/) > **Workloads**.
2. Na linha `gallery`, abra o menu de ações e selecione **Delete**.
3. Na caixa de diálogo **Delete Workload**, digite `gallery`.
4. Selecione **Delete**.

Repita os passos em **Applications** para a Application `gallery` e depois em **Functions** para a Function `gallery`.

Para excluir as imagens:

1. Acesse [Azion Console](https://console.azion.com/) > **Object Storage**.
2. Na lista de buckets, selecione o nome do seu bucket.
3. Na linha `blue.svg`, abra o menu de ações e selecione **Delete**.
4. Na caixa de diálogo **Delete File**, digite `blue.svg`.
5. Selecione **Delete**.

Repita os passos para `orange.svg`. O bucket fica vazio.

Um dia depois, exclua o bucket:

1. Acesse [Azion Console](https://console.azion.com/) > **Object Storage**.
2. Na lista de buckets, abra o menu de ações do seu bucket e selecione **Delete**.
3. Na caixa de diálogo **Delete bucket**, digite o nome do seu bucket.
4. Confirme a exclusão.

Antes de passarem as 24 horas, o Console responde com este erro:

```text

```
