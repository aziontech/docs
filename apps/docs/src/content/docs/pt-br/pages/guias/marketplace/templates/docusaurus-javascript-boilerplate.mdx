Você pode implantar um projeto estático básico em Docusaurus, escrito em JavaScript, na Azion a partir do template Docusaurus JavaScript Boilerplate no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

Docusaurus é um gerador de sites estáticos. Ele cria uma single-page application (SPA) com navegação rápida do lado do cliente e usa React para tornar o site interativo. Use-o para documentação, sites, páginas de produtos, blogs e páginas de destino. O template usa `Docusaurus 3`.

A implantação cria um repositório no GitHub para o seu projeto, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que o entrega e um domínio para acessá-lo. O template usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/) e [Functions](/pt-br/documentacao/plataforma/functions/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.

## Implante o template

O Docusaurus JavaScript Boilerplate abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Docusaurus JavaScript Boilerplate](https://console.azion.com/create/docusaurus/docusaurus-boilerplate-javascript) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Conecte a Azion à sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub à Azion. Nessa janela, defina as permissões do app e o acesso aos repositórios.

  </DocStep>
  <DocStep title="Selecione o Git Scope">

  Selecione o **Git Scope** com o qual trabalhar.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Insira um nome único e fácil de lembrar. O bucket de armazenamento que o template cria recebe o mesmo nome. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação. Nesse intervalo, a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Atualize o projeto

Cada push para a branch principal do repositório do GitHub que o Docusaurus JavaScript Boilerplate cria é implantado automaticamente.

Para atualizar o projeto implantado, faça push das suas alterações para a branch principal desse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

---

## Gerencie a aplicação

As configurações que o Docusaurus JavaScript Boilerplate aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo nome da aplicação.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/).

## Adicione um domínio personalizado

A implantação do Docusaurus JavaScript Boilerplate atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para adicionar um, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/). Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
