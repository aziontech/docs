Cada produto, recurso e configuração de conta que você usa na Azion é configurado em uma única interface web. O cabeçalho dela traz os menus e botões que abrem cada área, e a página inicial traz atalhos para as primeiras tarefas. Essa interface é o [Azion Console](https://console.azion.com/).

Nele, você configura sua [conta Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/), [cria e implanta aplicações](/pt-br/documentacao/plataforma/applications/), [gerencia as configurações principais de uma aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/definir-configuracoes-principais/) e configura cada produto da Azion. Os [Guias](/pt-br/documentacao/guias/) cobrem as tarefas de cada um. As seções abaixo cobrem a página inicial, o menu de produtos, o modal Create, os botões de ajuda e feedback e o menu da conta, nessa ordem. Para se cadastrar ou entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Página inicial

A página inicial abre depois que você entra. Os cards dela funcionam como atalhos: cada um abre um produto ou inicia uma tarefa.

| Bloco | O que contém |
| --- | --- |
| **Get Started** | O botão **+ Create**, que inicia uma aplicação a partir do [template da Azion](/pt-br/documentacao/plataforma/marketplace/) que se encaixa no seu projeto ou cria outro recurso. |
| **Manage Applications** | Um link para a página de [Applications](/pt-br/documentacao/plataforma/applications/), onde você adiciona aplicações e gerencia as configurações principais e os recursos delas. |
| **View Analytics** | Um link para o [Real-Time Metrics](/pt-br/documentacao/plataforma/real-time-metrics/), com dados de performance, disponibilidade e segurança das suas aplicações. |
| **Invite Your Team** | Um atalho opcional para trazer outras pessoas para trabalhar com você na conta. O acesso delas segue as [Teams Permissions](/pt-br/documentacao/fundamentos/teams-permissions/). |
| Links de ajuda | Links para a [documentação da Azion](/pt-br/documentacao/guias/), a [biblioteca da Azion API](https://api.azion.com/) e o [time de suporte](/pt-br/documentacao/suporte/abrir-tickets/). |

## Menu de produtos

O menu de produtos lista cada produto e recurso da Azion que você pode abrir. Três entradas vêm primeiro:

| Entrada | Abre |
| --- | --- |
| **Home** | A página inicial. |
| **Marketplace** | O [Azion Marketplace](/pt-br/documentacao/plataforma/marketplace/), o catálogo digital da Azion. |
| **Workloads** | O [Workloads](/pt-br/documentacao/plataforma/workloads/), o serviço que gera e gerencia domínios. |

Os demais produtos ficam em seções, cada uma nomeada por uma etapa do trabalho:

| Seção | Produtos |
| --- | --- |
| **Build** | **Applications**, **Variables** |
| **Secure** | **Edge DNS**, **Firewall** |
| **Deploy** | **Edge Nodes** |
| **Observe** | **Data Stream**, **Edge Pulse**, **Real-Time Metrics**, **Real-Time Events** |
| **Tools** | **Real-Time Purge** |
| **Edge Libraries** | **Certificate Manager**, **Edge Services**, **Functions**, **Network Lists**, **WAF Rules** |

Selecionar uma entrada abre aquele produto com as configurações dele.

## Modal Create

O botão **+ Create** fica no cabeçalho do Console e no bloco **Get Started** da página inicial. Ele abre um modal com quatro abas: **Recommended**, **Templates**, **Resources** e **Import from GitHub**. Em algumas contas, só a aba **Resources** aparece.

A aba **Resources** cria um recurso por vez, como um workload, uma aplicação, um firewall, uma função ou um certificado digital. As outras abas iniciam uma aplicação inteira a partir de um template ou de um repositório do GitHub. Para saber o que cada aba oferece, consulte [Use o botão + Create](/pt-br/documentacao/guias/plataforma/conta-e-billing/botao-create/).

## Ajuda e feedback

O botão **Help** mostra a documentação relacionada à tela em que você está, junto com outros links úteis. O botão **Feedback** envia à Azion a sua opinião sobre o Azion Console.

:::note[nota]
O **Help Center** não traz documentação para todas as telas do Console.
:::

## Menu da conta

O menu da conta abre a partir do cabeçalho do Console. Ele mostra as informações da sua conta, e as entradas dele dependem do tipo de conta.

| Grupo | Entradas |
| --- | --- |
| Conta | **Account Settings**, **Environments**, **Deployments Settings**, **Variables**, **Users Management**, **Billing**, **Credentials**, **Activity History**, **Teams Permissions**, **SSO Management** |
| Só em contas de empresa | **Groups Management** |
| Só em contas de revenda | **Clients Management** |
| Pessoal, com o nome do seu perfil como rótulo | **Your Settings**, **Personal Token** |
| Tema | _Light_, _Dark_, _System_ |
| Sessão | **Logout** |

O **SSO Management** aparece só em contas com o recurso ativado. Para a configuração, consulte [SSO](/pt-br/documentacao/guias/plataforma/conta-e-billing/sso/). O controle **Switch account** abre o diálogo **Switch Account**, onde você troca a conta em que trabalha.
