Você pode implantar, a partir do template Bot Manager Lite Starter Kit, um sandbox em que o [Bot Manager Lite](/pt-br/documentacao/plataforma/firewall/bot-manager/bot-manager-lite/) pontua as requisições que você mesmo envia, no Azion Console. O template cria todas as entidades que usa, incluindo o [Firewall](/pt-br/documentacao/plataforma/firewall/). Para adicionar o Bot Manager Lite a um Firewall que você já executa, consulte [Adicione Bot Manager Lite a um Firewall](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/bot-manager-lite-integration-kit/).

---

## Pré-requisitos

- Bot Manager Lite instalado pelo Marketplace. Para mais informações, consulte [Instale o Bot Manager Lite](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/bot-manager-lite/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- A Function Instance é executada em [Functions](/pt-br/documentacao/plataforma/functions/), o que pode gerar custos de uso. Para as métricas pelas quais o Bot Manager é cobrado, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#bot-manager).

O template verifica se o Bot Manager Lite está instalado antes de criar qualquer coisa. Quando não está, a implantação falha e grava uma linha de log que nomeia o motivo.

---

## Implante o template

Para implantar o template no Azion Console:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse o template [Bot Manager Lite Starter Kit](https://console.azion.com/create/azion/bot--manager-starter-kit).

  </DocStep>
  <DocStep title="Nomeie a Application">

  Em **Applications Name**, insira um nome. O template dá o mesmo nome ao Firewall que cria.

  </DocStep>
  <DocStep title="Nomeie a Function de exemplo">

  Em **Sample Function Name**, insira um nome para a Function que serve a página de teste.

  </DocStep>
  <DocStep title="Selecione Deploy" />
</DocSteps>

A implantação mostra o seu log enquanto é executada. Quando ela termina, a conta carrega quatro entidades novas:

- Uma [Application](/pt-br/documentacao/plataforma/applications/) com **Functions** ativado, que executa a Function de exemplo.
- Uma Function que serve a página de teste e os seus botões de requisição.
- Um Firewall cuja aba **Functions Instances** lista uma Function Instance do Bot Manager Lite, e cuja aba **Rules Engine** lista a regra que a executa.
- Um [Workload](/pt-br/documentacao/plataforma/workloads/) que responde em um domínio no formato `<id>.map.azionedge.net`.

A Function Instance carrega uma `action` de `deny`, então uma requisição cujo score atinge o threshold ou o ultrapassa recebe uma resposta `403` com a página de erro padrão da Azion. Ela também grava uma linha de report para toda requisição que pontua. Para ler ou alterar os argumentos dela, abra a Function Instance na aba **Functions Instances** do Firewall. Para cada argumento que uma Function Instance aceita, consulte [Argumentos](/pt-br/documentacao/plataforma/firewall/bot-manager/argumentos/).

A Application serve a Function de exemplo, e não uma origem sua, então o sandbox é uma demonstração e não um site em operação. Para alcançá-lo em um domínio seu, adicione esse domínio ao Workload que o template criou.

O domínio serve a página de teste só depois que a implantação se propaga pela infraestrutura distribuída da Azion, o que leva vários minutos. Para mais informações, consulte [Propagação](/pt-br/documentacao/plataforma/firewall/como-funciona/#propagacao).

## Envie uma requisição boa e uma ruim

Para pontuar uma requisição que você mesmo envia:

<DocSteps>
  <DocStep title="Abra a página de teste">

  No navegador, acesse o domínio do Workload que o template criou.

  </DocStep>
  <DocStep title="Envie uma requisição boa">

  Selecione **Send Request** na requisição boa. A página renderiza uma mensagem de sucesso.

  </DocStep>
  <DocStep title="Envie uma requisição ruim">

  Selecione **Send Request** na requisição ruim. A página renderiza a resposta `403` que a action `deny` devolve.

  </DocStep>
</DocSteps>

Cada requisição que a página envia produz uma linha de report, qualquer que seja o score.

Para enviar uma requisição recusada a um endereço que você escolhe, em vez da página de erro padrão, defina `action` como `redirect` e informe o destino em `redirect_to`. Para mais informações, consulte [Argumentos](/pt-br/documentacao/plataforma/firewall/bot-manager/argumentos/#action).

---

## Leia o que a Function Instance pontuou

Para ler as linhas de report no Azion Console:

<DocSteps>
  <DocStep title="Abra o Real-Time Events">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events** e selecione a aba **Functions Console**.

  </DocStep>
  <DocStep title="Leia as linhas de report">

  Restrinja o período às requisições que a página de teste enviou. Cada linha de report começa com `[Bot-Protection]` na coluna **Log Body** e carrega o score de uma requisição.

  </DocStep>
</DocSteps>

Os scores vêm de requisições que o sandbox formou, não do seu próprio tráfego. Antes que uma Function Instance recuse qualquer coisa na frente de uma Application sua, defina `threshold` e `action` a partir dos scores que o seu próprio tráfego produz. Para os campos que uma linha carrega, consulte [Logs](/pt-br/documentacao/plataforma/firewall/bot-manager/logs/). Para encaminhar as linhas a um destino seu, consulte [Data Stream](/pt-br/documentacao/plataforma/data-stream/).
