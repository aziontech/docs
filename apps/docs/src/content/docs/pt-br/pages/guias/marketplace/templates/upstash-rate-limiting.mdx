Você pode implantar rate limiting na Azion a partir do template Upstash Rate Limit no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/). A [integração Upstash Rate Limiting](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/upstash-rate-limiting-integration/) é uma listagem diferente do Azion Marketplace, que é executada em um firewall.

O template Upstash Rate Limit implementa rate limiting em um ambiente serverless, sem uma configuração manual extensa. Ele inclui configurações para limiting requests e para o window limit. O template funciona com [Functions](/pt-br/documentacao/plataforma/functions/), e você ajusta a configuração inicial dele pelos argumentos da função.

A implantação cria um repositório no GitHub para o seu projeto, uma função, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que executa a função e um domínio para acessá-la. O repositório contém um fluxo de *continuous deployment*, ou implantação contínua, para que você configure e personalize ainda mais a configuração de acordo com as suas necessidades. A aplicação usa Functions, e o uso dele pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.
- Uma [conta no Upstash](https://console.upstash.com/).
- Um banco de dados global, criado no [console do Upstash](https://console.upstash.com/) para obter a melhor latência disponível.

:::caution[Atenção]
O Upstash processa e cobra separadamente, na plataforma do Upstash, o custo do uso do Upstash. Para mais informações, consulte a [documentação do Upstash](https://docs.upstash.com/redis/features/globaldatabase#pricing).
:::

## Implante o template

O template Upstash Rate Limit abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Upstash Rate Limit](https://console.azion.com/create/upstash/upstash-ratelimit) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Conecte a Azion à sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub à Azion. Nessa janela, defina as permissões do app e o acesso aos repositórios.

  </DocStep>
  <DocStep title="Selecione o Git scope com o qual trabalhar" />
  <DocStep title="Nomeie a aplicação">

  Insira um nome único e fácil de lembrar. O bucket de armazenamento e a função que o template cria recebem o mesmo nome. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira os dados do Upstash e do rate limit">

  Copie os valores do Upstash da página do seu banco de dados no console do Upstash e defina os limites:

  - **Upstash Redis Rest URL** *: a URL que acessa o seu banco de dados Upstash via REST. Copie o `UPSTASH_REDIS_REST_URL`.
  - **Upstash Redis Rest Token** *: o token que autoriza o acesso ao seu banco de dados Upstash via REST. Copie o `UPSTASH_REDIS_REST_TOKEN`.
  - **Request Limit**: o número máximo de requisições. Exemplo: `6`.
  - **Window Limit**: a janela de tempo para novas requisições. Exemplo: `10 s`. Unidades aceitas: `"ms" | "s" | "m" | "h" | "d"`.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra informações sobre a aplicação, um link para abri-la no navegador e opções para continuar. Ao final da implantação, você tem:

- Um repositório na sua conta do GitHub, baseado em um [template público](https://github.com/aziontech/).
- Uma GitHub Action nesse repositório que habilita o deploy contínuo.
- Uma função que fornece os argumentos do rate limiting.
- Uma aplicação na Azion e o domínio dela.

O link pode levar alguns minutos para começar a entregar a aplicação, enquanto a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Comportamento do rate limiting

A função que o template Upstash Rate Limit cria integra as bibliotecas `upstash/redis` e `upstash/ratelimit` e se conecta ao seu banco de dados global no Upstash. Na rota `/login`, ela verifica se cada cliente está dentro dos valores de **Window** e **Limit** configurados. A chave dos limites são os metadados `["remote_addr"]`.

Um cliente que excede o **Request Limit** configurado dentro do **Window Limit** definido recebe da função uma resposta `HTTP 429 Too Many Requests`. A função não bloqueia o cliente permanentemente: a limitação é temporária e está vinculada ao **Window Limit** que você definiu.

Quando a janela de tempo é reiniciada, o contador de requisições é zerado, e o cliente pode enviar requisições novamente até o limite configurado. Por exemplo, defina um limite de `6` requisições por `10 s`. Um cliente que envia mais de 6 requisições em qualquer janela de 10 segundos recebe respostas `429` até que essa janela expire. Depois que a janela é reiniciada, a função atende as requisições normalmente.

Para ajustar o comportamento do rate limiting ao seu caso de uso, altere os valores de **Window Limit** e **Request Limit** nos argumentos da função. Você pode alterá-los a qualquer momento no [Azion Console](https://console.azion.com/).

## Atualize o projeto

Cada push para o repositório do GitHub que o template Upstash Rate Limit cria é implantado automaticamente.

Para atualizar o projeto implantado, faça push das suas alterações para esse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

## Gerencie a aplicação

As configurações que o template Upstash Rate Limit aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console. Depois da implantação, você também mantém controle total sobre a sua conta Upstash e o seu banco de dados.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome que você deu a ela durante a implantação. A busca filtra a lista apenas por **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/). Para tirar dúvidas sobre o Upstash, consulte a [documentação do Upstash](https://docs.upstash.com/).

## Adicione um domínio personalizado

A implantação do Upstash Rate Limit atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/) e [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
