Você pode implantar uma aplicação com políticas de cache padrão na Azion a partir do template Dynamic and Static File Optimization no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

O template reúne políticas e configurações de cache padrão para conteúdo estático, conteúdo dinâmico e imagens. Elas melhoram a entrega e a performance com base na extensão de arquivo do conteúdo requisitado. O template também ativa o processamento e a otimização de imagens, para que você entregue o seu conteúdo com a Azion como CDN.

A implantação cria uma [aplicação](/pt-br/documentacao/plataforma/applications/) que carrega todas as regras e configurações de cache do template. A aplicação usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/) e [Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

Depois da implantação, você pode entregar a aplicação em um domínio seu. Para mais informações, consulte [Adicione um domínio personalizado](#adicione-um-dominio-personalizado).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma origem hospedada que guarda o seu conteúdo. O formulário de configuração pede o endereço dela.

## Implante o template

O template Dynamic and Static File Optimization abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Dynamic and Static File Optimization](https://console.azion.com/create/azion/dynamic-and-static-file-optimization) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Em **Application Name**, insira um nome único e fácil de lembrar. O nome identifica a aplicação na Azion. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira o endereço da origem">

  Em **Origin Address**, insira o endereço da origem hospedada. A aplicação busca o conteúdo original nela. Por exemplo: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Opcional) Substitua o cabeçalho Host">

  Algumas origens precisam de outro valor no cabeçalho `Host` da requisição que busca o conteúdo delas. Em **Custom Host Header**, insira esse valor. Para usar o valor de host da URI da requisição, insira a variável `${host}`. Para mais informações, consulte [Origins](/pt-br/documentacao/plataforma/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página de implantação confirma que a plataforma criou a aplicação. A página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação. Nesse intervalo, a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Regras e configurações do template

A aplicação que o template Dynamic and Static File Optimization implanta tem uma regra com este critério e este behavior:

- **Criteria**: se `${uri}` *starts with* `/`.
- **Behavior**: então [Set Connector](/pt-br/documentacao/plataforma/applications/rules-engine/#set-connector) como `Default Origin`.

Para a otimização e o cache de imagens, o template cobre as extensões de arquivo `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.gif` e `.png`. Para conteúdo estático, ele suporta as extensões comuns de arquivos estáticos.

O template respeita as configurações de cache que a origem envia ou, quando a origem não envia nenhuma, usa o Max Age do cache setting. As regras dele alteram as configurações de cache de arquivos estáticos pela extensão do arquivo requisitado, para melhorar a entrega.

## Gerencie a aplicação

As configurações que o template Dynamic and Static File Optimization aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/). Para alterar as políticas de cache, consulte [Configure políticas de cache para uma aplicação](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/cache-settings/).

## Adicione um domínio personalizado

A implantação do template Dynamic and Static File Optimization atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/) e [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).
