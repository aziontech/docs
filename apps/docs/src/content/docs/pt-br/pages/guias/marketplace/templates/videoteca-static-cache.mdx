Você pode implantar uma aplicação com o player da Videoteca na Azion a partir do template Static Cache + Videoteca Player no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

O template coloca conteúdo estático e dinâmico em cache por extensão de arquivo. Ele também entrega o player da Videoteca, da Videofront, por um iframe.

A implantação cria um repositório no GitHub para o seu projeto, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que o entrega e um domínio para acessá-lo. A aplicação carrega vários cache settings e uma rota preconfigurada que executa a função do Videoteca Player. Ela usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/), [Functions](/pt-br/documentacao/plataforma/functions/), [Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/) e [Cache](/pt-br/documentacao/plataforma/applications/cache/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.
- A integração Videoteca Player, instalada e configurada. Para instalá-la, consulte [Instale a integração Videoteca Player](/pt-br/documentacao/guias/midia-e-streaming/streaming/videofront-player/).
- Uma conta Videoteca. O formulário de configuração pede o username e o token de API dela.

## Implante o template

O template Static Cache + Videoteca Player abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório. Depois do nome da aplicação, o formulário traz os campos da integração Videoteca Player.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Static Cache + Videoteca Player](https://console.azion.com/create/videofront/static-cache-videoteca-player) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Insira um nome único para a aplicação. O bucket de armazenamento e a função que o template cria recebem o mesmo nome. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira o endereço da origem">

  Em **Origin Address**, insira o nome de domínio ou o endereço IP da origem.

  </DocStep>
  <DocStep title="(Opcional) Defina o custom host header">

  Em **Custom Host Header**, insira o valor do header `host` que a aplicação envia à origem. Se você deixar o campo em branco, ele recebe o endereço da origem. Para mais informações, consulte [Host Header](/pt-br/documentacao/plataforma/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="Insira o path do player">

  Em **Videoteca Player Path**, insira o path que entrega o player. Por exemplo: `/player`.

  </DocStep>
  <DocStep title="Insira o seu username da Videoteca">

  Em **Videoteca Username**, insira o username da sua conta Videoteca.

  </DocStep>
  <DocStep title="Insira o seu token de API da Videoteca">

  Em **Videoteca API Token**, insira o token de API da sua conta Videoteca. O token fica em `https://<SEU-USUARIO>.videotecaead.com.br/Apidoc`, onde `<SEU-USUARIO>` é o seu username da Videoteca.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação, enquanto a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Atualize o projeto

Cada push para o repositório do GitHub que o template Static Cache + Videoteca Player cria é implantado automaticamente.

Para atualizar o projeto implantado, faça push das suas alterações para esse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

---

## Gerencie a aplicação

As configurações que o template Static Cache + Videoteca Player aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. A página inclui os cache settings e a rota que o template configurou. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/). Para alterar por quanto tempo a aplicação mantém os arquivos estáticos em cache, consulte [Crie um cache setting](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/ajustar-cache-settings/).

## Adicione um domínio personalizado

A implantação do template Static Cache + Videoteca Player atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Domains](/pt-br/documentacao/plataforma/workloads/domains/) e [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).
