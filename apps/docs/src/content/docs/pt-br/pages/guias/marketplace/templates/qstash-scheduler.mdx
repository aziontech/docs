Você pode implantar um agendador de tarefas na Azion a partir do template QStash Function Scheduler no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

O template configura e gerencia uma função personalizada. A função recebe um agendamento que você configura e o despacha pelo QStash, um agendador de tarefas e fila de mensagens para runtimes serverless.

A implantação cria a função, um repositório no GitHub para o seu projeto, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que executa a função e um domínio para acessá-la. A aplicação usa [Functions](/pt-br/documentacao/plataforma/functions/), e o uso dele pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.
- Uma [conta no Upstash](https://console.upstash.com/).
- A **Current Signing Key**, a **Next Signing Key** e o **QStash Token** da sua conta Upstash. Copie esses valores na aba **QStash** do [console do Upstash](https://console.upstash.com/qstash).

:::caution[Atenção]
O Upstash processa e cobra separadamente, na plataforma Upstash, o custo do uso do QStash. Para mais informações, consulte a [documentação do QStash](https://upstash.com/docs/qstash/overall/getstarted).
:::

## Implante o template

O QStash Function Scheduler abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [QStash Function Scheduler](https://console.azion.com/create/upstash/qstash-edgefunction-scheduler) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Conecte a Azion à sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub à Azion. Nessa janela, defina as permissões do app e o acesso aos repositórios.

  </DocStep>
  <DocStep title="Selecione o Git scope com o qual trabalhar" />
  <DocStep title="Nomeie a aplicação">

  Insira um nome único e fácil de lembrar. O bucket de armazenamento e a função que o template cria recebem o mesmo nome. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira as signing keys do QStash">

  As duas chaves são obrigatórias. Copie cada uma delas da aba **QStash** do seu console do Upstash:

  - **QStash Current Signing Key**: a string que assina todas as mensagens enviadas ao destino. Copie o valor de `QSTASH_CURRENT_SIGNING_KEY`.
  - **QStash Next Signing Key**: a string que assina as mensagens depois que você faz a rotação das suas signing keys. Copie o valor de `QSTASH_NEXT_SIGNING_KEY`.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra a aplicação, um link para abri-la no navegador e opções para continuar. Ao final da implantação, você tem:

- Uma função construída com os argumentos que você inseriu no formulário.
- Um repositório no GitHub que contém uma automação para deploy contínuo.
- Uma aplicação, criada e instanciada na Azion, e o domínio dela.

O link pode levar alguns minutos para começar a entregar a aplicação, enquanto a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Agende tarefas

Depois que a implantação do QStash Function Scheduler termina e se propaga, agende tarefas para a função pelo terminal ou pelo console do Upstash. Agende cada tarefa em um formato que uma requisição HTTP consegue carregar, como JSON, XML ou binário. Os exemplos desta seção usam JSON.

### Agende uma tarefa pelo terminal

Para agendar uma tarefa pelo seu ambiente de desenvolvimento:

<DocSteps>
  <DocStep title="Obtenha o domínio da sua aplicação" />
  <DocStep title="Copie o seu token do QStash">

  Na aba **QStash** do [console do Upstash](https://console.upstash.com/qstash), copie o `QSTASH_TOKEN`.

  </DocStep>
  <DocStep title="Abra um terminal no seu ambiente de desenvolvimento" />
  <DocStep title="Envie uma requisição HTTP POST que agenda as suas mensagens">

  Execute o exemplo que corresponde ao intervalo de que você precisa.

  </DocStep>
</DocSteps>

#### Uma vez

Para publicar a mensagem uma vez:

```bash
curl --request POST "https://qstash.upstash.io/v1/publish/{add your domain here}" \
     -H "Authorization: Bearer {add your QStash token here}" \
     -H "Content-Type: application/json" \
     -d "{ \"hello\": \"world\"}"
```

#### A cada minuto

Para publicar a mensagem a cada minuto:

```bash
curl --request POST "https://qstash.upstash.io/v1/publish/{add your domain here}" \
     -H "Authorization: Bearer {add your QStash token here}" \
     -H "Content-Type: application/json" \
     -H "Upstash-Cron: * * * * *" \
     -d "{ \"hello\": \"world\"}"
```

#### A cada 10 minutos

Para publicar a mensagem a cada 10 minutos:

```bash
curl --request POST "https://qstash.upstash.io/v1/publish/{add your domain here}" \
     -H "Authorization: Bearer {add your QStash token here}" \
     -H "Content-Type: application/json" \
     -H "Upstash-Cron: */10 * * * *" \
     -d "{ \"hello\": \"world\"}"
```

#### A cada hora

Para publicar a mensagem a cada hora:

```bash
curl --request POST "https://qstash.upstash.io/v1/publish/{add your domain here}" \
     -H "Authorization: Bearer {add your QStash token here}" \
     -H "Content-Type: application/json" \
     -H "Upstash-Cron: 0 * * * *" \
     -d "{ \"hello\": \"world\"}"
```

Os comandos usam estas flags:

| Flag | Descrição |
|---|---|
| `--request POST` | Define o método da requisição. O método HTTP POST publica, ou agenda, uma mensagem HTTP. |
| `-H "Authorization"` | Carrega o token que autentica a requisição. Insira aqui o seu token do QStash. |
| `-H "Content-Type"` | Define o tipo de conteúdo do corpo da requisição, JSON nestes exemplos. |
| `-H "Upstash-Cron"` | Agenda um job no estilo cron no Upstash, que executa a tarefa em um intervalo fixo. |
| `-d` | Carrega os dados do corpo da requisição, incluindo o payload JSON. As barras invertidas (`\`) antes das aspas duplas (`"`) mantêm as aspas como parte dos dados dentro do payload JSON. |

A tarefa está agendada e é executada de acordo com o agendamento que você definiu. Para revisar e monitorar as suas tarefas agendadas, abra a aba **QStash** do [console do Upstash](https://console.upstash.com/qstash).

### Agende uma tarefa pelo console do Upstash

Para agendar uma tarefa pelo console do Upstash:

<DocSteps>
  <DocStep title="Copie o domínio da sua aplicação na Azion" />
  <DocStep title="Abra a aba QStash">

  No [console do Upstash](https://console.upstash.com/qstash), abra a aba **QStash**.

  </DocStep>
  <DocStep title="Preencha o formulário">

  Defina o campo de tipo como _Scheduled_ e escolha o delay. Para enviar uma única mensagem imediata, selecione _Once_.

  </DocStep>
  <DocStep title="Selecione Schedule" />
</DocSteps>

A tarefa está agendada e aparece na seção **Scheduled Jobs**, onde você pode revisá-la e monitorá-la.

Para publicar a mensagem com uma requisição de API REST em vez do formulário, consulte a [documentação do QStash](https://upstash.com/docs/qstash/api-reference/messages/publish-a-message).

## Atualize o projeto

Cada push para o repositório do GitHub que o QStash Function Scheduler cria é implantado automaticamente.

Para atualizar o projeto implantado, faça push das suas alterações para esse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

## Gerencie a aplicação

As configurações que o QStash Function Scheduler aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo [Azion Console](https://console.azion.com/). Depois da implantação, você também mantém controle total sobre a sua conta Upstash e a sua configuração do QStash.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações da conta, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas por **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/). Para tirar dúvidas sobre Upstash ou QStash, consulte a [documentação do Upstash](https://docs.upstash.com/).

## Adicione um domínio personalizado

A implantação do QStash Function Scheduler atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/) e [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
