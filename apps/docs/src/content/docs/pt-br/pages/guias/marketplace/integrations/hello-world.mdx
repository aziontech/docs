O Hello World responde às requisições à sua aplicação com um código de status HTTP e um corpo de texto, então o navegador exibe uma mensagem como `Hello World!`. Use-o como uma primeira função para ver como uma aplicação executa uma integração. Ele é uma das [integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/) que são executadas em uma aplicação.

O Hello World é instalado pelo drawer **Install an Integration**. O drawer instala a integração na aplicação que você seleciona, com o código de status e o corpo que você informa, em uma única passagem.

---

## Pré-requisitos

- Uma conta Azion. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [aplicação](/pt-br/documentacao/plataforma/applications/) servida por um [workload](/pt-br/documentacao/plataforma/workloads/). Para criar uma, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/). Sem uma aplicação, o drawer mostra `No Application has been created. Go to Application to create a new one.` Crie a aplicação e depois reinicie a instalação pelo **Marketplace**.
- Ligar um produto ou um módulo pode gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Instale a integração

O Hello World não aparece entre os cards em destaque, então busque por ele. Para instalá-lo na sua aplicação pelo Azion Console:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Encontre a integração">

  Informe `Hello` no campo **Search on Marketplace** e selecione o card **Hello World**.

  </DocStep>
  <DocStep title="Selecione Install">

  O drawer **Install an Integration** abre.

  </DocStep>
  <DocStep title="Selecione a aplicação">

  Na seção **Select an Application**, abra a lista **Application** e selecione a aplicação que executa a integração.

  </DocStep>
  <DocStep title="Defina os argumentos">

  Na seção **General**, mantenha os padrões de `Status` e `Body` ou informe os seus. Cada argumento está descrito na tabela abaixo.

  </DocStep>
  <DocStep title="Revise as permissões">

  O drawer lista os privilégios que o Azion Marketplace exige na aplicação selecionada. Para o Hello World, eles são `Read and write the selected application` e `Delete the functions to instantiate the new integration in the selected application`.

  </DocStep>
  <DocStep title="Selecione Deploy" />
</DocSteps>

Uma mensagem confirma que a integração foi instalada com sucesso. Quando a aplicação estiver pronta, uma requisição a ela exibe o texto de `Body` no navegador.

### Argumentos

| Argumento | Padrão | Descrição |
|---|---|---|
| `Status` | `200` | O código de status HTTP da resposta. `200` indica que a requisição foi bem-sucedida |
| `Body` | `Hello World!` | Qualquer string. É o texto que o navegador exibe |
