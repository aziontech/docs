Você pode implantar mensagens de saudação baseadas na localização na Azion a partir do template Upstash GeoLocation no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

Upstash GeoLocation é uma automação que entrega mensagens personalizadas, que você configura no seu banco de dados global no Upstash. Cada usuário recebe a mensagem que corresponde à localização geográfica dele, por meio de uma interface estática em HTML que o template gera depois da implantação.

A implantação cria um repositório no GitHub para o seu projeto, uma função, uma [aplicação](/pt-br/documentacao/plataforma/applications/) que entrega o projeto e um domínio para acessá-lo. A aplicação usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/) e [Functions](/pt-br/documentacao/plataforma/functions/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [conta no GitHub](https://github.com/signup). A Azion se conecta a essa conta e cria nela o repositório do projeto.
- Uma [conta no Upstash](https://console.upstash.com/).
- Um banco de dados global, criado no [console do Upstash](https://console.upstash.com/) para obter a melhor latência disponível.

:::caution[Atenção]
O Upstash processa e cobra separadamente, na plataforma do Upstash, o custo do uso do Upstash. Para mais informações, consulte [Preços do banco de dados global do Upstash](https://docs.upstash.com/redis/features/globaldatabase#pricing).
:::

## Implante o template

O template Upstash GeoLocation abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Upstash GeoLocation](https://console.azion.com/create/upstash/upstash-geolocation) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Conecte a Azion à sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub à Azion. Nessa janela, defina as permissões do app e o acesso aos repositórios.

  </DocStep>
  <DocStep title="Selecione o Git Scope">

  Selecione o **Git Scope** com o qual trabalhar.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Insira um nome único e fácil de lembrar. O bucket de armazenamento e a função que o template cria recebem o mesmo nome. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira a URL REST do Upstash">

  Em **Upstash Redis Rest URL**, insira o `UPSTASH_REDIS_REST_URL` da página do seu banco de dados no console do Upstash. A URL acessa o seu banco de dados Upstash via REST.

  </DocStep>
  <DocStep title="Insira o token REST do Upstash">

  Em **Upstash Redis Rest Token**, insira o `UPSTASH_REDIS_REST_TOKEN` da página do seu banco de dados no console do Upstash. O token autoriza o acesso ao seu banco de dados Upstash via REST.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra informações sobre a aplicação, um link para abri-la no navegador e opções para continuar. Ao final da implantação, você tem:

- Um repositório na sua conta do GitHub, baseado em um [template público](https://github.com/aziontech/azion-samples/tree/dev/templates/javascript/upstash-geolocation).
- Uma GitHub Action nesse repositório que habilita a implantação contínua.
- Uma função que fornece os argumentos para o template, incluindo os argumentos para a geolocalização.
- Uma interface estática que exibe as mensagens.
- Uma aplicação na Azion e o domínio dela.

O link pode levar alguns minutos para começar a entregar a aplicação. Nesse intervalo, a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Personalize as saudações

A função que o template Upstash GeoLocation cria integra a biblioteca `upstash/redis`. Ela se conecta ao seu banco de dados global no Upstash e recupera a mensagem da localização do usuário, que ela lê dos metadados `["geoip_country_code"]`.

O template também adiciona saudações baseadas na localização ao seu banco de dados, e a função as recupera pela integração com o Upstash. As saudações ficam como nesta sessão da Upstash CLI:

```bash
Welcome to Upstash CLI

set BR "Olá, tudo bem!"
OK
set GB "Ey up?"
OK
set US "Yo, what's up?"
OK
set IN "Namaste"
OK
```

Para adequar as saudações às suas necessidades, altere-as no seu banco de dados do Upstash.

## Atualize o projeto

Cada push para o repositório do GitHub que o template Upstash GeoLocation cria é implantado automaticamente.

Para atualizar o projeto implantado, faça push das suas alterações para esse repositório. A Azion implanta as alterações, e a aplicação entrega a nova versão.

## Gerencie a aplicação

As configurações que o template Upstash GeoLocation aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console. Depois da implantação, você também mantém controle total sobre a sua conta Upstash e o seu banco de dados.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas por **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/). Para tirar dúvidas sobre o Upstash, consulte a [documentação do Upstash](https://docs.upstash.com/).

## Adicione um domínio personalizado

A implantação do Upstash GeoLocation atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/) e [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
