Você pode implantar uma aplicação que coloca arquivos estáticos em cache na Azion a partir do template Static Cache no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

O template coloca arquivos estáticos em cache, como JavaScript e CSS, pela extensão do arquivo. Ele aplica as suas regras pelo [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/), e as regras cobrem os métodos **GET**, **HEAD** e **OPTIONS**. Elas respeitam as configurações de cache que a origem envia ou, quando a origem não envia nenhuma, aplicam o Max Age do cache setting.

Você aponta o template para a sua própria origem. A implantação cria uma [aplicação](/pt-br/documentacao/plataforma/applications/) para ela, e cada configuração dessa aplicação continua editável. A aplicação usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/) e [Functions](/pt-br/documentacao/plataforma/functions/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma origem que guarda os seus arquivos estáticos. O formulário de configuração pede o endereço dela.

## Implante o template

O template Static Cache abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Static Cache](https://console.azion.com/create/azion/static-cache) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Em **Application Name**, insira um nome único para a aplicação na Azion. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira o endereço da origem">

  Em **Origin Address**, insira o endereço da origem de onde a aplicação busca o conteúdo. Por exemplo: `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Opcional) Adicione um custom host header">

  Em **Custom Host Header**, insira a informação de host a acrescentar à requisição que busca conteúdo na origem. Por exemplo: `${host}`. Para mais informações, consulte [Host Header](/pt-br/documentacao/plataforma/connectors/origins/#host-header).

  </DocStep>
  <DocStep title="Liste as extensões de arquivos estáticos a colocar em cache">

  Em **Static files extensions to cache**, insira as extensões de arquivo que as regras estáticas cobrem, separadas por vírgulas. Você pode adicionar quantas precisar. Por exemplo: `aif,aiff,au,avi,bin,cab,carb,cct,cdf,class,doc`.

  </DocStep>
  <DocStep title="Defina o TTL máximo de cache">

  Em **CDN Static Maximum TTL**, insira o tempo máximo, em segundos, em que a aplicação entrega o conteúdo em cache. O campo aceita valores de `0` a `31536000`, e o padrão é `1296000`.

  </DocStep>
  <DocStep title="Defina o TTL máximo de browser">

  Em **Browser Static Maximum TTL**, insira o tempo máximo, em segundos, em que o conteúdo permanece em cache no browser. O campo aceita valores de `0` a `31536000`, e o padrão é `0`.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra os detalhes da aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação, enquanto a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Gerencie a aplicação

As configurações que o template Static Cache aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações que você criou, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas pelo **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. As abas **Cache Settings** e **Rules Engine** guardam o que o template configurou. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/). Para alterar por quanto tempo a aplicação mantém os arquivos estáticos em cache, consulte [Crie um cache setting](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/ajustar-cache-settings/).
