Você pode enviar queries da [GraphQL API](/pt-br/documentacao/devtools/graphql/visao-geral/) pelo Postman e ler a resposta ao lado da requisição. O Postman envia a query como uma requisição `POST` com o seu personal token no header `Authorization`. Para executar uma query pelo navegador ou com `curl`, consulte [Primeiros passos com a GraphQL API](/pt-br/documentacao/devtools/graphql/primeiros-passos/).

---

## Pré-requisitos

- Um personal token. Para criar um, consulte [Como criar um personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).
- O Postman instalado na sua máquina.
- Um [workload](/pt-br/documentacao/plataforma/workloads/) que recebeu requisições durante a janela de tempo consultada. A query de exemplo lê os dados de requisições dele.

---

## Envie uma query

A query de exemplo lê `workloadMetrics`, um dataset agregado do endpoint de métricas. Ela soma os bytes enviados aos clientes por bucket de tempo ao longo de sete dias, do mais antigo para o mais recente, e retorna no máximo 10 linhas.

Para enviar a query pelo Postman:

<DocSteps>
  <DocStep title="Crie uma requisição">

  No Postman, selecione **+** para abrir uma requisição.

  </DocStep>
  <DocStep title="Defina o método como POST">

  Selecione **GET** para abrir a lista de métodos e, depois, selecione _POST_.

  </DocStep>
  <DocStep title="Informe o endpoint">

  No campo **Enter URL or paste text**, digite o endpoint de métricas:

  ```text
  https://api.azion.com/v4/metrics/graphql
  ```

  Para dados brutos, como `workloadEvents`, digite `https://api.azion.com/v4/events/graphql` em vez disso. O endpoint de cada dataset está em [Queries](/pt-br/documentacao/devtools/graphql/queries/).

  </DocStep>
  <DocStep title="Adicione o header de autorização">

  Na aba **Headers**, selecione **Bulk Edit** e digite a linha abaixo. Substitua `[TOKEN VALUE]` pelo seu personal token:

  ```text
  Authorization: Token [TOKEN VALUE]
  ```

  Mantenha o prefixo `Token`. Com `Bearer`, a API retorna `401` com `Authentication credentials were not provided.`

  </DocStep>
  <DocStep title="Selecione GraphQL como tipo de corpo">

  Na aba **Body**, selecione _GraphQL_.

  </DocStep>
  <DocStep title="Digite a query">

  Na caixa de query, digite a query. Defina `tsRange` como uma janela em que o seu workload recebeu requisições:

  ```graphql
  query HttpQuery {
    workloadMetrics(
      limit: 10,
      filter: {
        tsRange: {begin:"2026-09-26T14:00:00", end:"2026-10-03T14:00:00"}
      }
      aggregate: {sum: bytesSent}
      groupBy: [ts]
      orderBy: [ts_ASC]
    )
    {
      ts
      sum
    }
  }
  ```

  O nome de dataset `httpMetrics` está obsoleto; use `workloadMetrics`, que retorna as mesmas linhas.

  </DocStep>
  <DocStep title="Envie a requisição">

  Selecione **Send**.

  </DocStep>
</DocSteps>

O Postman mostra a resposta da API, `200` com as linhas em JSON. A query retorna até 10 linhas. A resposta está cortada depois da terceira:

```json
{
  "data": {
    "workloadMetrics": [
      {
        "ts": "2026-09-26T16:00:00Z",
        "sum": 104492
      },
      {
        "ts": "2026-09-27T18:00:00Z",
        "sum": 1100
      },
      {
        "ts": "2026-09-27T22:00:00Z",
        "sum": 14088
      },
      …
    ]
  }
}
```

---

## Leia a resposta

A chave `data` contém um array com o nome do dataset, com um objeto por linha e apenas os campos que a query selecionou:

| Campo | Valor |
| --- | --- |
| `ts` | O início do bucket de tempo, em UTC, indicado pelo sufixo `Z`. Em uma janela de sete dias, cada bucket tem uma hora. |
| `sum` | A saída de `aggregate: {sum: bytesSent}`: os bytes enviados aos clientes durante o bucket. |

Um bucket sem requisições não retorna linha, então as linhas pulam as horas sem tráfego. O tamanho do bucket acompanha a duração da janela, como descreve [Como a GraphQL API funciona](/pt-br/documentacao/devtools/graphql/visao-geral/).

Uma query recusada retorna um objeto JSON com uma única chave `detail`, que contém a mensagem. Para cada mensagem e a sua causa, consulte [Respostas de erro](/pt-br/documentacao/devtools/graphql/mensagens-erro/).

Para mais queries que você executa da mesma forma, consulte [aziontech/azion-queries](https://github.com/aziontech/azion-queries), o repositório da Azion com exemplos de queries da GraphQL API.
