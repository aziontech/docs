Videoteca Player hospeda o player da [Videoteca do Videofront](https://videofront.com.br/videoteca) e o incorpora com um iframe. Para escolher o vídeo que a página exibe, passe o ID dele no argumento de query string `video-id`. É uma das [integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/) que rodam em uma aplicação.

Quatro objetos precisam existir antes de uma requisição carregar o player: a função instalada, uma aplicação com o módulo **Functions** ligado, uma instância de função que guarda as suas credenciais da Videoteca e uma regra do Rules Engine com o behavior **Run Function**. Cada seção abaixo cria um deles.

---

## Pré-requisitos

- Uma conta Azion. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [aplicação](/pt-br/documentacao/plataforma/applications/) servida por um [workload](/pt-br/documentacao/plataforma/workloads/). Para criar uma, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
- Uma conta no [site da Videoteca](https://videofront.com.br/videoteca), com o seu **Username** e o seu **API Token**. A instância de função exige os dois.
- Ligar um produto ou um módulo pode gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Instale a integração

A instalação adiciona a função Videoteca Player à sua conta. Para instalá-la pelo Azion Console:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Encontre a integração">

  Informe `Videoteca Player` no campo **Search on Marketplace** e selecione o card da integração.

  </DocStep>
  <DocStep title="Selecione Install" />
</DocSteps>

O card mostra `Successfully installed!` e `Latest version installed!`. A função passa a aparecer na lista **Function** do drawer **Create Instance**.

---

## Ligue o módulo Functions

Uma aplicação executa uma função instalada apenas quando o seu módulo **Functions** está ligado. Para ligar o módulo:

<DocSteps>
  <DocStep title="Abra a sua aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação**.

  </DocStep>
  <DocStep title="Abra a seção Modules">

  Na aba **Main Settings**, vá até a seção **Modules**.

  </DocStep>
  <DocStep title="Ligue o switch Functions" />
  <DocStep title="Selecione Save" />
</DocSteps>

O Azion Console confirma que a aplicação foi atualizada.

## Crie a instância de função

Uma instância de função guarda os argumentos que a função Videoteca Player lê para uma aplicação. Para criar a instância na sua aplicação:

<DocSteps>
  <DocStep title="Abra a aba Functions Instances">

  Em **Applications**, selecione a sua aplicação e selecione a aba **Functions Instances**.

  </DocStep>
  <DocStep title="Selecione + Function">

  Uma aplicação ainda sem instância oferece a mesma ação como **Function Instance**. O drawer **Create Instance** abre.

  </DocStep>
  <DocStep title="Nomeie a instância">

  Em **Name**, informe um nome único que identifique a instância. Por exemplo: `videoteca-player`.

  </DocStep>
  <DocStep title="Selecione a função">

  Em **Function**, selecione _Videoteca Player_. O editor **Arguments** é preenchido com os argumentos padrão da integração.

  </DocStep>
  <DocStep title="Edite os argumentos">

  Em **Arguments**, informe o seu username e o seu API token da Videoteca. Cada chave é descrita na tabela abaixo.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância aparece na aba **Functions Instances** com o nome que você informou.

### Argumentos

Os argumentos são um único objeto JSON. Substitua cada placeholder pelo seu próprio valor:

```json
{
"videoteca_user": "<your_username>", // Replace with your Videoteca username
"videoteca_token": "<your_token>", // Replace with your Videoteca API token
"custom_html": "<your_html>" // Replace with your custom html
}
```

| Chave | Obrigatória | Descrição |
|---|---|---|
| `videoteca_user` | Sim | O nome da conta de onde a função recupera os vídeos |
| `videoteca_token` | Sim | O token que acessa a API da Videoteca |
| `custom_html` | Não | HTML personalizado para a página que a função entrega. Ele precisa incluir a tag `<!-- videoteca_iframe -->`, que a função substitui pelo iframe do vídeo |

Para obter o seu API token, abra `https://<YOUR-USER>.videotecaead.com.br/Apidoc`, com `<YOUR-USER>` substituído pelo seu username da Videoteca.

## Crie a regra

A instância roda apenas quando uma regra do Rules Engine a chama. A regra abaixo corresponde a todas as requisições. Para criar a regra:

<DocSteps>
  <DocStep title="Abra a aba Rules Engine">

  Em **Applications**, selecione a sua aplicação e selecione a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Em **Name**, informe um nome para a regra. Por exemplo: `Run Videoteca Player on every request`.

  </DocStep>
  <DocStep title="Selecione a fase">

  Na seção **Phase**, selecione _Request Phase_.

  </DocStep>
  <DocStep title="Defina o critério">

  Na seção **Criteria**, mantenha a variável `${uri}` e o operador _starts with_ e informe `/` como argumento.

  </DocStep>
  <DocStep title="Adicione o behavior Run Function">

  Na seção **Behaviors**, selecione _Run Function_ e selecione a instância que você criou pelo nome.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A regra aparece na aba **Rules Engine**, na fase de requisição, e executa a instância do Videoteca Player em todas as requisições. Para restringir as requisições que carregam o player, altere o critério.

Para cada critério e behavior que uma regra aceita, consulte [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/).
