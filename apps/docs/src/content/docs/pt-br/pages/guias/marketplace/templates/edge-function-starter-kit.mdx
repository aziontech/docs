Você pode implantar uma aplicação baseada em uma função na Azion a partir do template Function Starter Kit no Azion Console. Para criar uma aplicação sem um template, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

O Function Starter Kit contém a configuração de uma aplicação que executa uma função e não tem dependências de origem. O template simplifica a configuração, para que a função que ele implanta fique pronta para ser executada.

A implantação cria uma [aplicação](/pt-br/documentacao/plataforma/applications/), uma função básica de Hello World e um domínio que você gerencia na Azion Web Platform. A aplicação usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/) e [Functions](/pt-br/documentacao/plataforma/functions/), e o uso deles pode gerar custos. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Implante o template

O Function Starter Kit abre como um formulário de configuração no Azion Console, e um asterisco marca cada campo obrigatório.

Para implantar o template:

<DocSteps>
  <DocStep title="Abra o template">

  Acesse [Function Starter Kit](https://console.azion.com/create/azion/functions-starter) no Azion Console. O formulário de configuração abre.

  </DocStep>
  <DocStep title="Nomeie a aplicação">

  Insira um nome único e fácil de lembrar. O bucket de armazenamento e a função que o template cria recebem o mesmo nome. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs da implantação enquanto ela é executada. Quando a implantação termina, a página mostra a aplicação, um link para abri-la no navegador e opções para continuar.

O link pode levar alguns minutos para começar a entregar a aplicação. Nesse intervalo, a configuração dela se propaga pela infraestrutura distribuída da Azion. Se a página não carregar, aguarde alguns minutos e abra o link novamente.

## Atualize a função

O Function Starter Kit instala uma função de Hello World pronta para ser executada, e você pode alterá-la para atender ao seu projeto. A página da função tem três abas:

- **Main Settings** renomeia a função e altera as configurações básicas dela.
- **Code** contém o código da função, que você pode atualizar.
- **Arguments** define os argumentos que a função usa.

Para atualizar a função:

<DocSteps>
  <DocStep title="Abra a lista de funções">

  Acesse [Azion Console](https://console.azion.com/) > **Functions**.

  </DocStep>
  <DocStep title="Selecione a função que o template criou">

  A função tem o mesmo nome da aplicação. A lista está em ordem alfabética, e a **barra de busca** a filtra apenas por **Function Name**.

  </DocStep>
  <DocStep title="Abra a aba que contém a configuração">

  Abra a aba **Main Settings**, **Code** ou **Arguments**.

  </DocStep>
  <DocStep title="Altere a configuração">

  Nessa aba, altere a configuração.

  </DocStep>
  <DocStep title="Selecione Save">

  Selecione **Save**.

  </DocStep>
</DocSteps>

A função tem as alterações que você salvou. Para mais informações, consulte [Functions](/pt-br/documentacao/plataforma/functions/).

## Gerencie a aplicação

As configurações que o Function Starter Kit aplica podem não servir para a sua aplicação. Você pode alterar qualquer uma delas a qualquer momento pelo Azion Console.

Para abrir as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A lista mostra todas as aplicações da conta, em ordem alfabética.

  </DocStep>
  <DocStep title="Selecione a aplicação que o template criou">

  Para encontrá-la em uma lista longa, busque pelo nome dela. A busca filtra a lista apenas por **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página que reúne todas as configurações que você pode definir. Para mais informações, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/), [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/).

## Adicione um domínio personalizado

A implantação do Function Starter Kit atribui à aplicação um domínio de [workload](/pt-br/documentacao/plataforma/workloads/) no formato `xxxxxxxxxx.map.azionedge.net`, que um navegador consegue abrir. Para entregar a aplicação em um domínio seu, adicione um domínio personalizado. Para mais informações, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/) e [Domains](/pt-br/documentacao/plataforma/workloads/domains/).
