O template **Function Starter Kit** contém as configurações para criar uma aplicação baseada em uma **function**, sem dependências de origem. Este template simplifica o processo de configuração, para que você implante uma function pronta para ser executada.

A implantação desse template cria uma application, uma function básica de **"Hello World"** e um domínio para facilitar seu acesso e gerenciamento através da Azion Web Platform.

---

## Pré-requisitos

- O template usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/#application-accelerator) e [Functions](/pt-br/documentacao/plataforma/functions/). Isso pode gerar custos relacionados ao uso. Consulte a [página de preços](/pt-br/documentacao/fundamentos/precos/) para mais informações.

Você obtém e configura o template pelo Azion Console. Para fazer o deploy, selecione o botão abaixo.

## Configure o template

No formulário de configuração, você deve fornecer as informações para personalizar sua aplicação. Preencha os campos apresentados. 

Os campos identificados com um asterisco são obrigatórios.

<DocSteps>
  <DocStep title="Defina um nome para sua aplicação">

  - O bucket para armazenamento e a function usarão o mesmo nome.
  - Use um nome único e fácil de lembrar. Se o nome já tiver sido usado, a plataforma retornará uma mensagem de erro.

  </DocStep>
  <DocStep title="Selecione Deploy">

  Selecione **Deploy** para iniciar o processo de implantação.

  </DocStep>
</DocSteps>

Durante a implantação, você poderá acompanhar o processo através de uma janela que mostra os logs. Quando estiver completo, a página mostra informações sobre a aplicação e algumas opções para continuar sua jornada.

:::note[nota]
O link abre a aplicação no navegador. Propagar e configurar a aplicação pela rede distribuída da Azion leva alguns minutos, portanto a URL pode não responder imediatamente.
:::

## Gerencie o template

Considerando que essa configuração inicial pode não ser ótima para sua application específica, todas as configurações podem ser personalizadas a qualquer momento que você precise, usando a plataforma da Azion.

### Atualize a function

Este template inclui uma function simples de `Hello World` pronta para ser executada. Siga esses passos para atualiza-la de acordo com suas necessidades:

<DocSteps>
  <DocStep title="Acesse Azion Console">

  [Acesse Azion Console](https://console.azion.com).

  </DocStep>
  <DocStep title="Selecione Functions">

  No canto superior esquerdo, selecione **Products menu**, o ícone de três linhas horizontais, > **Functions**.

  </DocStep>
  <DocStep title="Selecione sua function">

  Encontre a function relacionada ao seu template e selecione-a. Ela terá o mesmo nome da sua application.

  - A lista está organizada alfabeticamente. Você também pode usar a **barra de busca** localizada no canto superior esquerdo da lista; atualmente, ela filtra apenas pelo campo **Function Name**.

  </DocStep>
  <DocStep title="Configure sua function">

  Na página da function, use as abas para configurar sua função.

  - Na aba **Main Settings**, você pode renomear a função e alterar algumas configurações básicas.
  - Na aba **Code**, você pode atualizar o código da função.
  - Na aba **Arguments**, você pode definir os argumentos usados pela função.

  </DocStep>
  <DocStep title="Selecione Save">

  Selecione **Save**.

  </DocStep>
</DocSteps>

:::tip[dica]
Leia a documentação sobre [gerenciamento de functions](/pt-br/documentacao/plataforma/functions/) para mais detalhes.
:::

### Gerencie a application

Para gerenciar e editar as configurações da sua application, siga esses passos:

<DocSteps>
  <DocStep title="Acesse Azion Console">

  [Acesse Azion Console](https://console.azion.com).

  </DocStep>
  <DocStep title="Selecione Applications">

  No canto superior esquerdo, selecione **Products menu**, o ícone de três linhas horizontais, > **Applications**.

  - Você será redirecionado para a página **Applications**. Ela lista todas as applications que você criou.

  </DocStep>
  <DocStep title="Selecione sua aplicação">

  Encontre a application relacionada ao seu template e selecione-a.

  - A lista está organizada alfabeticamente. Você também pode usar a **barra de busca** localizada no canto superior esquerdo da lista; atualmente, ela filtra apenas pelo campo **Application Name**.

  </DocStep>
</DocSteps>

Depois de selecionar a application que você trabalhará, você será direcionado para uma página contendo todas as configurações que você pode ajustar.

:::tip[dica]
Leia a documentação sobre [gerenciamento de application](/pt-br/documentacao/plataforma/applications/primeiros-passos/) para mais detalhes.
:::

### Adicione um domínio personalizado

A application criada durante a implantação tem um Azion Workload Domain atribuído para torná-la acessível através do navegador. O domínio tem o seguinte formato: `xxxxxxxxxx.map.azionedge.net/`. No entanto, você pode adicionar um domínio personalizado para que os usuários acessem sua application através dele.

Para mais informações, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).
