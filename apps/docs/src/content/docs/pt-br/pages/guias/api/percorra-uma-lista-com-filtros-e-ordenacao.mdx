Você pode restringir, ordenar e percorrer uma listagem da [API da Azion](/pt-br/documentacao/devtools/api/) v4 com parâmetros de query, e ler todas as páginas em um script. Para o que cada parâmetro faz e os limites dele, consulte [Paginação e parâmetros de query](/pt-br/documentacao/devtools/api/#paginacao-e-parametros-de-query).

Os exemplos listam cinco [Network Lists](/pt-br/documentacao/plataforma/firewall/network-shield/network-lists/) cujos nomes começam com `warehouse-`, e os resultados da sua conta são outros.

---

## Pré-requisitos

- Um personal token. Para criar um, consulte [Gerencie personal tokens](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).
- `curl`, para chamar a API, e `jq`, para ler as respostas JSON.
- Bash, para executar o script da última seção.

---

## Filtre e ordene uma página

O parâmetro `search` restringe a lista aos resultados que correspondem a um termo. O parâmetro `fields` pede os campos que você cita, e um recurso pode retornar alguns a mais. O parâmetro `ordering` ordena os resultados por um campo.

Em Network Lists, o `search` encontra parte de um nome, com qualquer combinação de maiúsculas e minúsculas: `search=LIS` encontra `warehouse-lisbon`. Ele também encontra o tipo da lista, então `search=ip_cidr` retorna todas as listas desse tipo. Os endereços dentro de uma lista ficam fora da busca: `search=192.0.2.3` não retorna resultados, embora uma das listas contenha esse endereço.

Envie uma requisição `GET` pelas Network Lists que correspondem a `warehouse`, com IDs e nomes, ordenadas por nome. Substitua o token pelo seu:

```bash
export AZION_API_TOKEN="[TOKEN VALUE]"
curl --silent "https://api.azion.com/v4/workspace/network_lists?search=warehouse&fields=id,name&ordering=name" \
  --header "Authorization: Token $AZION_API_TOKEN"
```

```json
{
  "count": 5,
  "total_pages": 1,
  "page": 1,
  "page_size": 10,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": 72648,
      "name": "warehouse-austin",
      "is_versioned": false,
      "version": null
    },
    {
      "id": 72650,
      "name": "warehouse-berlin",
      "is_versioned": false,
      "version": null
    },
    {
      "id": 72647,
      "name": "warehouse-lisbon",
      "is_versioned": false,
      "version": null
    },
    {
      "id": 72644,
      "name": "warehouse-sao-paulo",
      "is_versioned": false,

```

O `count` é 5, e os resultados vêm em ordem de nome. Em uma Network List, `fields=id,name` também retorna `is_versioned` e `version`. Para ordenar em ordem decrescente, coloque um `-` antes do campo, como em `ordering=-name`.

## Leia a lista uma página por vez

O `page_size` define quantos resultados uma página guarda, e o `page` seleciona a página. A resposta traz o `total_pages`, e o `next` guarda a URL completa da página seguinte, com os mesmos parâmetros de query.

Para ler a lista de dois em dois resultados:

1. Solicite a primeira página. Substitua o token pelo seu:

   ```bash
   export AZION_API_TOKEN="[TOKEN VALUE]"
   curl --silent "https://api.azion.com/v4/workspace/network_lists?search=warehouse&fields=id,name&ordering=name&page_size=2" \
     --header "Authorization: Token $AZION_API_TOKEN"
   ```

   ```json
   {
     "count": 5,
     "total_pages": 3,
     "page": 1,
     "page_size": 2,
     "next": "https://api.azion.com/v4/workspace/network_lists?fields=id%2Cname&ordering=name&page=2&page_size=2&search=warehouse",
     "previous": null,
     "results": [
       {
         "id": 72648,
         "name": "warehouse-austin",
         "is_versioned": false,
         "version": null
       },
       {
         "id": 72650,
         "name": "warehouse-berlin",
         "is_versioned": false,
         "version": null
       }
     ]
   }
   ```

2. Solicite a última página, que o `total_pages` informa como `3`:

   ```bash
   curl --silent "https://api.azion.com/v4/workspace/network_lists?search=warehouse&fields=id,name&ordering=name&page_size=2&page=3" \
     --header "Authorization: Token $AZION_API_TOKEN"
   ```

   ```json
   {
     "count": 5,
     "total_pages": 3,
     "page": 3,
     "page_size": 2,
     "next": null,
     "previous": "https://api.azion.com/v4/workspace/network_lists?fields=id%2Cname&ordering=name&page=2&page_size=2&search=warehouse",
     "results": [
       {
         "id": 72649,
         "name": "warehouse-tokyo",
         "is_versioned": false,
         "version": null
       }
     ]
   }
   ```

Na última página, o `next` é `null`.

Dois limites valem para esses parâmetros. Um `page` além do `total_pages` retorna `404` com o código `10004`. Um `page_size` acima de 100 retorna `400` com o código `10097` e o `detail` `Page size must be between 0 and 100.` Para os dois limites, consulte [Limites](/pt-br/documentacao/devtools/api/#limites).

## Leia todas as páginas em um script

Um script que segue o `next` até ele ser `null` lê todas as páginas da lista, com uma requisição por página. Cada requisição conta para o rate limit, então um `page_size` maior, até 100, lê a lista com menos requisições.

Crie um arquivo `list-all.sh`. Ele imprime o ID e o nome de cada resultado, um por linha:

```bash title="list-all.sh"
#!/usr/bin/env bash
set -euo pipefail

url="https://api.azion.com/v4/workspace/network_lists?search=warehouse&fields=id,name&ordering=name&page_size=2"

while [ "$url" != "null" ]; do
  page=$(curl --silent --show-error --fail "$url" --header "Authorization: Token $AZION_API_TOKEN")
  echo "$page" | jq -r '.results[] | "\(.id)\t\(.name)"'
  url=$(echo "$page" | jq -r '.next')
done
```

Para executar o script:

1. Torne o script executável:

   ```bash
   chmod +x list-all.sh
   ```

   O comando não imprime nada, e o arquivo passa a ser executável.

2. Guarde o seu token. Substitua o token pelo seu:

   ```bash
   export AZION_API_TOKEN="[TOKEN VALUE]"
   ```

   O comando não imprime nada, e o token fica disponível para os próximos comandos que você executar neste shell.

3. Execute o script:

   ```bash
   ./list-all.sh
   ```

   ```text
   72648	warehouse-austin
   72650	warehouse-berlin
   72647	warehouse-lisbon
   72644	warehouse-sao-paulo
   72649	warehouse-tokyo
   ```

O script lê as três páginas e imprime as cinco Network Lists em ordem de nome.

Quando uma requisição falha, o `--fail` faz o `curl` sair com um erro, e o `set -e` interrompe o script. O `--show-error` imprime o status da requisição que falhou. Com um token que a API não aceita, o script para na primeira requisição e imprime um erro como `curl: (56) The requested URL returned error: 401`.
