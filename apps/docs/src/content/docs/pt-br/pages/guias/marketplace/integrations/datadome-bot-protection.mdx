Você pode instalar a integração DataDome Bot Protection pelo Azion Marketplace e executá-la em um [Firewall](/pt-br/documentacao/plataforma/firewall/), pelo Azion Console. A integração detecta e bloqueia ameaças automatizadas como credential stuffing, DDoS de camada 7 e scraping. Para as outras integrações que são executadas em um Firewall, consulte [Integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/).

---

## Pré-requisitos

- Uma conta Azion. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma Application servida por um [Workload](/pt-br/documentacao/plataforma/workloads/). A última seção define o seu Firewall no deployment desse Workload.
- Uma assinatura ativa do DataDome, com uma chave de API server-side do DataDome. Para os planos e os seus preços, consulte [datadome.co](https://datadome.co).
- Ativar um recurso da plataforma pode gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Instale a integração

A Function é instalada uma vez por conta. Para instalá-la:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Encontre a integração">

  Encontre o card **DataDome Bot Protection** e selecione-o. Os filtros **Category**, **Type** e **Vendor** estreitam os cards.

  </DocStep>
  <DocStep title="Selecione Install" />
</DocSteps>

O card mostra `Successfully installed!` e `Latest version installed!`, e a Function aparece na lista **Function** do drawer **Create Instance**.

## Crie o Firewall

O Firewall guarda a Function Instance e a regra que a executa. Para criar um:

<DocSteps>
  <DocStep title="Abra a página Firewalls">

  Acesse [Azion Console](https://console.azion.com/) > **Firewalls** e selecione **Firewall**.

  </DocStep>
  <DocStep title="Nomeie o Firewall">

  Na seção **General**, insira um **Name**. Por exemplo: `datadome-firewall`.

  </DocStep>
  <DocStep title="Confirme que Functions está ativado">

  Na seção **Modules**, o switch **Functions** é o que permite a um Firewall executar uma Function instalada. Um Firewall criado nesta página começa com **Functions** ativado.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Firewall mostra uma aba **Functions Instances** enquanto **Functions** permanecer ativado. Para usar um Firewall existente, ative **Functions** nele. Para mais informações, consulte [Ative ou desative WAF, Network Shield ou Functions](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/firewall-definir-main-settings/#ative-ou-desative-waf-network-shield-ou-functions).

## Crie a Function Instance

A [Function Instance](/pt-br/documentacao/plataforma/firewall/functions-instances/) guarda a sua chave de API server-side do DataDome. Para criá-la:

<DocSteps>
  <DocStep title="Abra a aba Functions Instances">

  Em **Firewalls**, selecione o seu Firewall e depois selecione a aba **Functions Instances**.

  </DocStep>
  <DocStep title="Selecione Function">

  Em um Firewall que ainda não carrega nenhuma Function Instance, a mesma ação aparece como **Function Instance**. O drawer **Create Instance** abre.

  </DocStep>
  <DocStep title="Nomeie a Function Instance">

  Em **Name**, insira um nome. Por exemplo: `datadome`.

  </DocStep>
  <DocStep title="Selecione a Function instalada">

  Em **Function**, selecione a Function DataDome Bot Protection. A lista guarda apenas as Functions que são executadas em um Firewall.

  </DocStep>
  <DocStep title="Insira a sua chave">

  Em **Arguments**, o editor JSON abre com os argumentos default da integração. Defina `api_key` como a sua chave de API server-side do DataDome.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A Function Instance aparece na aba **Functions Instances**.

## Crie a regra

A Function Instance não analisa nada até que uma regra a execute. Uma regra do [Rules Engine para Firewall](/pt-br/documentacao/plataforma/firewall/rules-engine/) seleciona as requisições que alcançam a Function Instance, por um comportamento _Run Function_. Para criar a regra:

<DocSteps>
  <DocStep title="Abra a aba Rules Engine">

  Em **Firewalls**, selecione o seu Firewall e depois selecione a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Selecione Rule">

  O drawer **Create Rule** abre.

  </DocStep>
  <DocStep title="Nomeie a regra">

  Em **Name**, insira um nome. Por exemplo: `Run DataDome`.

  </DocStep>
  <DocStep title="Defina o critério">

  Na seção **Criteria**, selecione os domínios a proteger. Por exemplo: _Host_ _matches_ `yourdomain.com`.

  </DocStep>
  <DocStep title="Adicione o comportamento Run Function">

  Na seção **Behaviors**, selecione _Run Function_. No segundo controle, com o placeholder `Select a Function`, selecione a Function Instance do DataDome Bot Protection que você criou.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Firewall executa a Function Instance em toda requisição aos domínios do critério.

## Defina o Firewall no Workload

O deployment do Workload define o Firewall. Para definir o seu Firewall no Azion Console:

<DocSteps>
  <DocStep title="Abra a página Workloads">

  Acesse [Azion Console](https://console.azion.com/) > **Workloads**.

  </DocStep>
  <DocStep title="Abra o Workload">

  Selecione o Workload que serve a sua Application. O formulário de edição dele abre.

  </DocStep>
  <DocStep title="Selecione o seu Firewall">

  Na seção **Deployment Settings**, selecione o seu Firewall no campo **Firewall**. **Application** e **Custom Page** mantêm os valores que o Workload serve hoje.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

Depois de salvar, o deployment do Workload define o seu Firewall, e o DataDome Bot Protection é executado em cada requisição aos domínios do critério. A Function do DataDome envia os metadados de cada requisição para a API do DataDome e depois permite, bloqueia ou desafia a requisição a partir da resposta e das configurações do seu dashboard do DataDome. Um Workload recém-definido pode levar vários minutos para aplicar as regras do seu Firewall. Para mais informações, consulte [Propagação](/pt-br/documentacao/plataforma/firewall/como-funciona/#propagacao).
