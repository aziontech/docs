Você pode ler o uso das suas [aplicações](/pt-br/documentacao/plataforma/applications/) no [dataset `workloadConsumptionMetrics`](/pt-br/documentacao/devtools/graphql/campos-gql-consumption/) da GraphQL API, no [GraphiQL Playground](/pt-br/documentacao/devtools/graphql/playground-graphql/). O dataset retorna as requisições que suas aplicações processaram, os bytes que elas transferiram e as requisições inspecionadas pelo Web Application Firewall (WAF). Image Processor e Tiered Cache reportam o uso deles sob IDs de produto próprios. Para esses produtos, consulte [Consulte dados de uso do Image Processor](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-image-processor-com-graphql/) e [Consulte dados de uso do Tiered Cache](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-tiered-cache-com-graphql/).

O dataset contém dados agregados, e a Azion os mantém por até 24 meses. Você pode mover os resultados para uma plataforma de terceiros para analisá-los com mais profundidade.

---

## Pré-requisitos

- Uma conta da Azion, com a sessão iniciada no navegador que abre o GraphiQL Playground. Sem uma sessão, o playground responde com um erro. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- O início e o fim do período que você quer consultar.

## Consulte as requisições e os dados transferidos

A métrica `requests` conta as requisições que suas aplicações receberam e processaram. A métrica `data_transferred_total` soma os bytes que elas transferiram. Uma consulta lê as duas métricas, com estes argumentos de `workloadConsumptionMetrics`:

| Argumento | Valor | Efeito |
| --- | --- | --- |
| `filter` › `tsRange` | `begin` e `end`, no formato `YYYY-MM-DDTHH:mm:ss`, como `2024-04-11T00:00:00` | Define o período que o uso cobre |
| `filter` › `productId` | `1441740010` | Seleciona Applications |
| `filter` › `metricNameIn` | `["requests", "data_transferred_total"]` | Seleciona as duas métricas |
| `filter` › `isEdgeFirewallActive` | `true` | Opcional. Mantém apenas o uso com Firewall ativo. Os outros filtros desse tipo são `isLoadBalancerActive`, `isImageProcessorActive` e `isApplicationAcceleratorActive` |
| `aggregate` › `sum` | `accounted` | Soma o uso contabilizado para os eventos que correspondem aos filtros e aos grupos |
| `groupBy` | `[clientId, workloadId, productId, metricName]` | Retorna um total por workload e métrica |
| `limit` | Até `10000` | Limita o número de resultados |

A consulta pede `clientId`, `workloadId`, `productId` e `metricName`, e a soma sob o alias `total`.

Para executar a consulta:

<DocSteps>
  <DocStep title="Abra o GraphiQL Playground">

  No navegador em que você entrou na sua conta da Azion, acesse `https://api.azion.com/v4/consumption/graphql`.

  </DocStep>
  <DocStep title="Escreva a consulta">

  Insira uma consulta `workloadConsumptionMetrics` com os argumentos e os campos que esta seção lista.

  </DocStep>
  <DocStep title="Envie a consulta" />
</DocSteps>

A resposta contém uma entrada por workload e métrica, com estes campos:

| Campo | Conteúdo |
| --- | --- |
| `clientId` | Seu identificador de cliente na Azion, como `8437r` |
| `workloadId` | O workload ao qual o uso pertence, como `4829301746` |
| `productId` | `1441740010`, o ID de produto de Applications |
| `metricName` | `requests` ou `data_transferred_total` |
| `total` | Para `data_transferred_total`, os bytes transferidos, como uma soma. Para `requests`, o número de requisições processadas, como uma soma |

Agora você tem, para cada workload, as requisições que suas aplicações processaram e os bytes que elas transferiram no período.

## Consulte as requisições inspecionadas pelo WAF

A métrica `waf_requests` conta as requisições inspecionadas pelo Web Application Firewall (WAF). Ela é reportada sob o ID de produto de Applications. Uma consulta lê essa métrica com estes argumentos de `workloadConsumptionMetrics`:

| Argumento | Valor | Efeito |
| --- | --- | --- |
| `filter` › `tsRange` | `begin` e `end`, no formato `YYYY-MM-DDTHH:mm:ss`, como `2024-04-11T00:00:00` | Define o período que o uso cobre |
| `filter` › `productId` | `1441740010` | Seleciona Applications |
| `filter` › `metricName` | `"waf_requests"` | Seleciona a métrica do WAF |
| `filter` › `isEdgeFirewallActive` | `true` | Opcional. Mantém apenas o uso com Firewall ativo. Os outros filtros desse tipo são `isLoadBalancerActive`, `isImageProcessorActive` e `isApplicationAcceleratorActive` |
| `aggregate` › `sum` | `accounted` | Soma o uso contabilizado para os eventos que correspondem aos filtros e aos grupos |
| `groupBy` | `[clientId, workloadId, productId, metricName]` | Retorna um total por workload |
| `limit` | Até `10000` | Limita o número de resultados |

A consulta pede `clientId`, `workloadId`, `productId` e `metricName`, e a soma sob o alias `total`.

Para executar a consulta:

<DocSteps>
  <DocStep title="Abra o GraphiQL Playground">

  No navegador em que você entrou na sua conta da Azion, acesse `https://api.azion.com/v4/consumption/graphql`.

  </DocStep>
  <DocStep title="Escreva a consulta">

  Insira uma consulta `workloadConsumptionMetrics` com os argumentos e os campos que esta seção lista.

  </DocStep>
  <DocStep title="Envie a consulta" />
</DocSteps>

A resposta contém uma entrada por workload, com estes campos:

| Campo | Conteúdo |
| --- | --- |
| `clientId` | Seu identificador de cliente na Azion, como `8437r` |
| `workloadId` | O workload ao qual o uso pertence, como `4829301746` |
| `productId` | `1441740010`, o ID de produto de Applications |
| `metricName` | `waf_requests` |
| `total` | O número de requisições inspecionadas pelo WAF, como uma soma |

Agora você tem, para cada workload, o número de requisições inspecionadas pelo WAF no período.
