Uma instância de função é executada apenas quando uma regra do [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/) a seleciona com o comportamento **Run Function**. Você adiciona essa regra pelo Azion Console ou pela Azion API. Para uma primeira execução guiada que cria a função, a instância e a regra em uma só passagem, consulte [Primeiros passos com Functions](/pt-br/documentacao/plataforma/functions/primeiros-passos/).

---

## Pré-requisitos

- Uma função na conta. Para escrever uma, consulte [Escreva e teste uma função](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/functions-e-runtime/primeiros-passos/).
- Uma instância de função na aplicação. Para criar uma, consulte [Instancie uma função em uma aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/instanciar-functions/).
- O módulo **Application Accelerator** ativado na aplicação. O comportamento **Run Function** depende dele. Consulte [Application Accelerator](/pt-br/documentacao/plataforma/applications/#application-accelerator).
- A permissão **Edit Applications** na conta. A regra altera uma aplicação. Consulte [Teams Permissions](/pt-br/documentacao/fundamentos/teams-permissions/).
- Um [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/), para o caminho pela API.

:::tip[dica]
Uma função pré-configurada do [Azion Marketplace](/pt-br/documentacao/plataforma/marketplace/) substitui uma função que você escreve. A função **Azion - Hello World** está vinculada à sua conta e pronta para ser instanciada.
:::

## Adicione a regra que executa a função

A regra define a fase de execução, os critérios que a acionam e a instância que ela executa. A regra então executa essa instância em toda requisição que corresponde aos critérios. Azion Console e Azion API criam a mesma regra.

No caso de uso [Executar aplicações SaaS multi-tenant](/pt-br/documentacao/casos-de-uso/construir-e-executar-aplicacoes/executar-aplicacoes-saas-multi-tenant/), esta seção usa estes valores:

| Configuração | Valor |
| --- | --- |
| **Name** | `tenants - run tenant-app` |
| **Phase** | _Request Phase_ |
| **Criterion** | `${uri}` _starts with_ `/`, para que todos os caminhos de todos os hostnames de tenant executem a função |
| **Behavior** | _Run Function_ com a instância `tenant-app` |

Toda requisição ao workload executa `tenant-app`. Uma regra nova leva alguns minutos para chegar a todos os data centers.

No caso de uso [Criar e executar assistentes de IA para suporte ao cliente](/pt-br/documentacao/casos-de-uso/construir-e-executar-workloads-de-ai/criar-e-executar-assistentes-de-ia-para-suporte-ao-cliente/), esta seção usa estes valores:

| Configuração | Valor |
| --- | --- |
| Regra | `support - ask`, na Request Phase |
| Critério | `${uri}` _is equal_ `/api/ask` |
| Behavior | **Run Function**, selecionando a instância `support-assistant` |

Um `POST` para `/api/ask` com uma pergunta responde com a resposta do modelo, que cita trechos como `[n]`, e com o documento de onde veio cada trecho citado. Uma regra nova leva alguns minutos para se propagar.

No caso de uso [Adicionar funcionalidades de IA a aplicações existentes](/pt-br/documentacao/casos-de-uso/construir-e-executar-workloads-de-ai/adicionar-funcionalidades-de-ia-a-aplicacoes-existentes/), esta seção usa estes valores:

| Configuração | Valor |
| --- | --- |
| Regra | `ai - summarize`, na Request Phase |
| Critério | `${uri}` _is equal_ `/api/summarize` |
| Behavior | **Run Function**, selecionando a instância `ai-summarize` |

Um `POST` para `/api/summarize` no seu domínio executa a function, e todos os outros caminhos mantêm as regras que tinham. Uma regra nova leva alguns minutos para se propagar.

No caso de uso [Governar o acesso a múltiplos modelos de IA](/pt-br/documentacao/casos-de-uso/construir-e-executar-workloads-de-ai/governar-o-acesso-a-multiplos-modelos-de-ia/), esta seção usa estes valores:

| Configuração | Valor |
| --- | --- |
| Regra | `gateway - all paths`, na Request Phase |
| Critério | `${uri}` _starts with_ `/` |
| Behavior | **Run Function**, selecionando a instância `ai-gateway` |

O gateway responde em `/v1/chat/completions` e `/admin/teams`, e todos os outros caminhos respondem `404`.

### Adicione a regra pelo Azion Console

Para adicionar a regra pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação**.

  </DocStep>
  <DocStep title="Na aba Rules Engine, selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Digite um nome para a regra. Por exemplo: `Run hello-world`.

  </DocStep>
  <DocStep title="Selecione Request Phase" />
  <DocStep title="Na seção Criteria, selecione a variável de URI">

  Selecione a variável `${uri}`.

  </DocStep>
  <DocStep title="Selecione is equal como operador de comparação" />
  <DocStep title="Digite a URI que executa a função">

  Digite a URI como argumento. Por exemplo: `/hello-world`.

  </DocStep>
  <DocStep title="Na seção Behaviors, selecione Run Function" />
  <DocStep title="Selecione a instância de função" />
  <DocStep title="Selecione Save" />
</DocSteps>

A regra aparece na aba **Rules Engine** da aplicação. Novas regras podem levar alguns minutos para propagar.

:::note[nota]
Se **Run Function** não estiver na lista de **Behaviors**, a aplicação também precisa do módulo **Application Accelerator**. Consulte [Run Function não aparece na lista de comportamentos](/pt-br/documentacao/plataforma/functions/solucao-de-problemas/#run-function-nao-aparece-na-lista-de-comportamentos) para a correção.
:::

### Adicione a regra pela Azion API

Envie uma requisição `POST` para o endpoint de request rules da aplicação. Substitua `[TOKEN VALUE]` pelo seu [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/), `<application_id>` pelo [ID da sua aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/definir-configuracoes-principais/) e `<edge_function_instance_id>` pelo ID da instância de função:

```bash
curl --request POST \
  --url https://api.azion.com/v4/workspace/applications/<application_id>/request_rules \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]' \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "Run Hello World",
  "active": true,
  "criteria": [
    [
      {
        "conditional": "if",
        "variable": "${uri}",
        "operator": "is_equal",
        "argument": "/hello-world"
      }
    ]
  ],
  "behaviors": [
    {
      "type": "run_function",
      "attributes": { "value": <edge_function_instance_id> }
    }
  ],
  "description": "Run function on /hello-world"
}'
```

A resposta retorna a regra que a aplicação agora carrega:

```json
{
  "state": "pending",
  "data": {
    "id": <rule_id>,
    "name": "Run Hello World",
    "active": true,
    "criteria": [
      [
        {
          "conditional": "if",
          "variable": "${uri}",
          "operator": "is_equal",
          "argument": "/hello-world"
        }
      ]
    ],
    "behaviors": [
      {
        "type": "run_function",
        "attributes": {
          "value": <edge_function_instance_id>
        }
      }
    ],
    "description": "Run function on /hello-world",
    "order": 0,
    "last_editor": "your-email@example.com",
    "last_modified": "2026-01-01T12:00:00.000000Z"
  }
}
```

O valor `"state": "pending"` significa que a regra leva alguns minutos para propagar. Para todos os campos do endpoint de rules, consulte [Crie uma regra de aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/trabalhar-com-rules-engine/).

## Verifique a resposta

Sua aplicação responde em um domínio no formato `xxxxxxxxx.map.azionedge.net`. Para definir o domínio da sua aplicação, consulte [Adicione um domínio a um workload](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).

Aguarde a propagação da regra e requisite a URI definida nos critérios:

```bash
curl https://<your-azion-domain>/hello-world
```

O corpo da resposta é a string que a função retorna. A função `hello-world` de [Primeiros passos com Functions](/pt-br/documentacao/plataforma/functions/primeiros-passos/) responde:

```
Hello World!
```

Uma resposta que não vem da função significa que a regra não correspondeu à requisição ou que a alteração ainda não propagou.
