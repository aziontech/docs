A JavaScript tag (JS TAG) é um script de nível de navegador que você adiciona a uma página web. Ela captura dados sobre o navegador, gera um identificador único a partir desses dados e define o identificador como um cookie de sessão chamado `_azfp_sc`. O navegador envia os cookies em toda requisição que faz, então o identificador chega à sua aplicação em cada uma delas.

O script é executado na página que você quer identificar, um processo também conhecido como injeção de JavaScript. Ele captura os seguintes dados do navegador:

- Suporte a áudio e vídeo.
- Renderização de Canvas.
- Acesso a APIs de nível de dispositivo, como o acelerômetro e o giroscópio.
- Dados do fabricante.
- Fuso horário.
- Renderização WebGL.

Antes de criar um cookie, o script verifica se `_azfp_sc` já existe. Se existir, o script não cria um novo.

---

## Pré-requisitos

- Acesso ao código-fonte HTML da página web que você quer identificar.
- Para servir sua própria cópia do script, uma pasta de projeto que seu domínio serve.

---

## Incorpore o script

A Azion fornece o script como [um arquivo](https://assets.azion.com/global/bot-manager/client-fingerprint/azfp-1.0.0.min.js) que você pode carregar a partir do seu código-fonte HTML. Para carregá-lo da Azion, adicione este elemento ao seu código-fonte HTML:

```html
<script src="https://assets.azion.com/global/bot-manager/client-fingerprint/azfp-1.0.0.min.js"></script>
```

Você também pode servir sua própria cópia do script. Para isso:

<DocSteps>
  <DocStep title="Copie o código">

  Copie o código do [arquivo do script](https://assets.azion.com/global/bot-manager/client-fingerprint/azfp-1.0.0.min.js).

  </DocStep>
  <DocStep title="Crie um arquivo JavaScript com o código">

  Neste exemplo, o nome do arquivo é `fingerprint-script.js`.

  </DocStep>
  <DocStep title="Adicione o arquivo à pasta do seu projeto" />
  <DocStep title="Carregue o arquivo a partir do seu código-fonte HTML">

  Adicione este elemento ao seu código-fonte HTML:

  ```html
  <script src="https://example.com/fingerprint-script.js"></script>
  ```

  </DocStep>
</DocSteps>

Substitua os valores do elemento da seguinte forma:

| Valor | Substitua por |
| --- | --- |
| `https://example.com/` | Seu domínio. |
| `fingerprint-script.js` | O nome do seu arquivo JavaScript. |

O script então define o cookie de sessão `_azfp_sc` em cada navegador que carrega a página.
