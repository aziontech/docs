Você pode iniciar uma aplicação, ou criar um recurso por vez, pelo botão **+ Create** do Azion Console. Para trazer um repositório do GitHub com cada etapa detalhada, consulte [Importe um projeto do GitHub](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/importar-um-projeto-existente-do-github/).

---

## Pré-requisitos

- Acesso ao Azion Console. Para entrar, consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Para a aba **Import from GitHub**, um repositório próprio no GitHub.

---

## Escolha um ponto de partida

O botão **+ Create** abre um modal com quatro abas. Em algumas contas, só a aba **Resources** aparece.

| Aba | Mostra | Use para |
| --- | --- | --- |
| **Recommended** | **Select a Template** | Navegar por um conjunto de opções sugeridas, incluindo templates. |
| **Templates** | **Select a Template** | Começar de um projeto pré-desenhado com configurações padrão, feito em um framework de uso comum. Para o catálogo, consulte [Templates do Marketplace](/pt-br/documentacao/plataforma/marketplace/templates/). |
| **Resources** | **Select a Resource** | Criar uma aplicação ou um recurso. Para saber o que construir com cada um, consulte [Guias](/pt-br/documentacao/guias/). |
| **Import from GitHub** | **Import from GitHub** | Criar e implantar uma nova aplicação na Azion a partir do seu próprio repositório do GitHub. |

---

## Comece a construir

O procedimento é o mesmo em todas as abas; só muda o item que você seleciona.

Para começar a construir pelo botão **+ Create**:

<DocSteps>
  <DocStep title="Abra o modal Create">

  Acesse [Azion Console](https://console.azion.com/) e selecione **+ Create**. O botão fica no cabeçalho do Console e no bloco **Get Started** da página inicial.

  </DocStep>
  <DocStep title="Selecione uma aba">

  Selecione **Recommended**, **Templates**, **Resources** ou **Import from GitHub**.

  </DocStep>
  <DocStep title="Selecione o template, o recurso ou o repositório" />
  <DocStep title="Preencha o formulário">

  Informe as configurações que o formulário da sua seleção pede.

  </DocStep>
  <DocStep title="Salve a configuração">

  Selecione **Save** ou **Save and Build**.

  </DocStep>
</DocSteps>

O Azion Console cria a aplicação ou o recurso que você configurou.

## Recursos que você pode criar

A aba **Resources** lista estes itens, nesta ordem. Algumas contas não mostram **Custom Page**.

| Recurso | Cria |
| --- | --- |
| **Workloads** | Um workload, que publica uma aplicação e a protege com certificados digitais. |
| **Application** | Uma aplicação que entrega o seu conteúdo. |
| **Variables** | Variáveis de ambiente ou secrets que as functions configuradas usam. |
| **Edge DNS** | Um domínio hospedado em um servidor DNS autoritativo. |
| **Firewall** | Configurações de segurança que protegem aplicações contra ameaças e ataques. |
| **Connectors** | Um connector, que centraliza como suas aplicações se conectam a máquinas e a outras aplicações. |
| **Custom Page** | Uma página personalizada, que exibe uma página de erro própria para erros HTTP específicos. |
| **Edge Nodes** | Uma infraestrutura que você gerencia com Orchestrator, onde instala serviços e recursos. |
| **Data Stream** | Um stream que envia os logs de eventos da Azion para plataformas de streaming, SIEM e big data. |
| **Functions** | Uma função para usar com uma aplicação ou um firewall. |
| **Edge Services** | Um serviço que define as dependências entre os recursos que você instala com Orchestrator. |
| **Certificate Manager** | Uma entrada de certificado digital que protege aplicações HTTPS. |
| **Network Lists** | Uma allowlist, uma blocklist ou uma greylist para o Rules Engine de um firewall. |
