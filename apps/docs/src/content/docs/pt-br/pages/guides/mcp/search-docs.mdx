Você pode buscar na documentação da Azion, nos exemplos de código da Azion e nas referências da [Azion CLI](/pt-br/documentacao/devtools/cli/) e do [Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/) pedindo a um agente de código conectado ao servidor de docs dos [Azion MCP Servers](/pt-br/documentacao/devtools/mcp/). O servidor de docs tem uma ferramenta de busca por fonte, e cada ferramenta retorna os documentos mais próximos da sua pergunta. Para as entradas de cada ferramenta, consulte [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/).

---

## Pré-requisitos

- Um agente de código conectado ao servidor de docs, `https://docs-mcp.azion.com/mcp`. Para conectar um, consulte [Primeiros passos com o MCP server](/pt-br/documentacao/devtools/mcp/primeiros-passos/).

---

## Busque com o seu agente

Cada ferramenta de busca lê uma fonte. A tabela associa quatro delas a uma pergunta que cada uma responde e ao tipo de documento que ela retorna. Para a ferramenta que busca na referência da Azion API, consulte [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/#ferramentas-do-servidor-de-docs).

| Pergunta | Ferramenta | Documentos que ela retorna |
| --- | --- | --- |
| "Como configuro proteção DDoS?" | `search_azion_docs_and_site` | Páginas da documentação e do site da Azion |
| "Me mostre exemplos de deploy Next.js" | `search_azion_code_samples` | Exemplos de código e bibliotecas de código |
| "Quais comandos CLI gerenciam functions?" | `search_azion_cli_commands` | Referências dos comandos da Azion CLI |
| "Como crio recursos Terraform?" | `search_azion_terraform` | Documentação do Azion Terraform Provider |

Para buscar com o seu agente:

<DocSteps>
  <DocStep title="Faça uma pergunta ao seu agente">

  Nomeie o produto e a tarefa na pergunta, como fazem as perguntas da tabela.

  </DocStep>
  <DocStep title="Leia os documentos que a ferramenta retorna">

  A ferramenta retorna um item de texto que contém um objeto JSON com um array `results` de documentos. Cada documento traz `title`, `content` e `source`, que indica a página ou o arquivo de onde o documento vem, além de `similarity`, `search_type` e `relevance_score` da correspondência.

  </DocStep>
  <DocStep title="(Opcional) Defina o número de documentos">

  Uma ferramenta de busca retorna cinco documentos por padrão. Para receber outro número, peça ao agente que defina `docsAmount`.

  </DocStep>
</DocSteps>

O seu agente tem os documentos mais próximos da pergunta, e o `source` de cada um aponta para a página ou o arquivo completo. Se os documentos não correspondem à pergunta, consulte [Uma busca retorna documentos que não correspondem à query](/pt-br/documentacao/devtools/mcp/solucao-de-problemas/#uma-busca-retorna-documentos-que-nao-correspondem-a-query).

## Obtenha resultados relevantes

Quatro práticas ajudam as ferramentas de busca a retornar os documentos de que você precisa:

- **Seja específico**: forneça contexto sobre o tipo de projeto e os seus requisitos.
- **Refine a pergunta**: comece com uma pergunta simples e adicione detalhes aos poucos.
- **Combine ferramentas**: use várias ferramentas MCP juntas para concluir uma tarefa.
- **Salve o que funciona**: guarde as configurações que funcionam e use-as de novo.
