Você pode adicionar um registro wildcard a uma zona no [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/) pelo Azion Console, pela Azion CLI ou pela Azion API. O registro abaixo responde `192.0.2.31` para todo nome de `example.com` que não tem registro próprio. Para responder a um host específico, consulte [Adicione, edite ou exclua um registro](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/adicionar-registros/).

- Uma zona para o seu domínio no Edge DNS. Para criar uma, consulte [Crie, edite ou exclua uma zona](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/edge-dns-definir-main-settings/).
- A permissão **Edit Edge DNS**. Consulte [Permissões de equipes](/pt-br/documentacao/fundamentos/teams-permissions/).
- O `dig` na sua máquina, para conferir a resposta. Para instalá-lo, consulte [Consulte uma zona com o dig](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/executar-o-comando-dig/).

## Adicione um registro wildcard

Um registro com o nome `*` responde a todo nome da zona que não tem registro próprio, não importa quantos rótulos ele tenha. Para responder apenas aos nomes abaixo de um rótulo, como `apps`, dê ao registro o nome `*.apps`. Substitua `example.com` pelo seu domínio onde esta página o mostrar.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para adicionar o registro wildcard pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a página do Edge DNS">

  Acesse [Azion Console](https://console.azion.com/) > **Edge DNS**.

  </DocStep>
  <DocStep title="Abra a zona">

  Na página **Zones**, selecione a linha da zona.

  </DocStep>
  <DocStep title="Abra a aba Records e selecione + Record">

  Na aba **Records**, selecione **+ Record**. O drawer **Create Record** é aberto.

  </DocStep>
  <DocStep title="Informe o nome wildcard">

  Em **Name**, informe `*`. O Console mostra o seu domínio depois do campo e o adiciona para você, então nunca digite o domínio.

  </DocStep>
  <DocStep title="Mantenha o tipo de registro A">

  Mantenha **Record Type** em *A - IPv4 Address*.

  </DocStep>
  <DocStep title="Mantenha o TTL">

  Mantenha **TTL (seconds)** em `3600`.

  </DocStep>
  <DocStep title="Informe o valor">

  Em **Value**, informe `192.0.2.31`.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Console mostra `Edge DNS Record has been created`, e o registro `*` aparece na tabela **Records**.

</Fragment>

<Fragment slot="panel.cli">

Para adicionar o registro wildcard pela Azion CLI, substitua `<zone-id>` pelo ID da sua zona. Coloque o asterisco entre aspas para que o seu shell o repasse sem alteração:

```bash
azion create dns-record --zone-id <zone-id> --name "*" --type A --rdata 192.0.2.31 --ttl 3600
```

O comando mostra o ID do registro:

```text
Created DNS record with ID 100778
```

A zona contém o registro wildcard. Nunca inclua o domínio em `--name`: o Edge DNS o adiciona.

</Fragment>

<Fragment slot="panel.api">

Para adicionar o registro wildcard pela Azion API, envie uma requisição `POST` ao endpoint de registros da zona. Substitua `<zone-id>` pelo `id` da sua zona e `[TOKEN VALUE]` pelo seu personal token:

```bash
curl -X POST https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records \
  -H "Authorization: Token [TOKEN VALUE]" \
  -H "Content-Type: application/json" \
  -d '{"name":"*","type":"A","rdata":["192.0.2.31"],"ttl":3600}'
```

Um `201` retorna o registro:

```json
{
  "state": "executed",
  "data": {
    "id": 100253,
    "description": "",
    "name": "*",
    "ttl": 3600,
    "type": "A",
    "rdata": ["192.0.2.31"],
    "policy": "simple",
    "weight": 255
  }
}
```

A zona contém o registro wildcard. Nunca inclua o domínio em `name`: o Edge DNS o adiciona.

</Fragment>

</Tabs>

Um nome com registro próprio mantém a própria resposta: se a zona contém um registro A para `www`, uma consulta por `www.example.com` retorna esse registro, não `192.0.2.31`. Para saber a quais nomes um wildcard corresponde e a quais não, consulte [Tipos de registro](/pt-br/documentacao/plataforma/edge-dns/tipos-de-registro/#wildcards).

## Confira a resposta

Consulte o nameserver da Azion diretamente, sem o cache do seu resolver, por um nome que não tem registro próprio.

:::caution[Atenção]
Salve o registro wildcard antes de consultar qualquer nome que ele cobre. O Edge DNS responde `NXDOMAIN` por até uma hora, o mínimo do SOA, a um nome que você consultou antes de o registro existir.
:::

Para consultar `ns1.aziondns.net` por um nome sem registro, como `ghost`, execute:

```bash
dig +short @ns1.aziondns.net ghost.example.com A
```

O nameserver retorna o valor do registro wildcard:

```text
192.0.2.31
```

O wildcard responde por `ghost.example.com`. Se o comando não mostrar nada, consulte [Um registro novo retorna NXDOMAIN](/pt-br/documentacao/plataforma/edge-dns/solucao-de-problemas/#um-registro-novo-retorna-nxdomain).
