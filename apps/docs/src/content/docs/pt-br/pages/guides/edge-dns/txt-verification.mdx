Você pode verificar um domínio com um registro TXT no [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/) pelo Azion Console, pela Azion CLI ou pela Azion API. Um serviço que pede que você comprove o controle de um domínio fornece um valor e depois o lê de volta no DNS do domínio. Para validar um certificado que a Azion solicita para um workload, consulte [Emissão e renovação](/pt-br/documentacao/plataforma/workloads/certificate-manager/emissao-e-renovacao/#validacao-de-dominio) em vez deste guia.

## Pré-requisitos

- Uma zona no Edge DNS para o domínio. Para criar uma, consulte [Crie, edite ou exclua uma zona](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/edge-dns-definir-main-settings/).
- O valor que o serviço pede que você publique, e o nome do registro, se o serviço informar um.
- O domínio delegado aos nameservers da Azion, para que o serviço consiga ler o registro. Consulte [Migre nameservers para a Azion](/pt-br/documentacao/guias/plataforma/migracao/migrar-ns-para-a-azion/).

## Adicione o registro TXT

Adicione o registro em `@`, o domínio raiz, a menos que o serviço indique outro registro. Os nomes de registro são relativos à zona: para `<name>.example.com`, informe apenas `<name>`. O exemplo abaixo adiciona o valor `verification-token-abc123` em `@`; substitua-o pelo valor que o serviço forneceu.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para adicionar o registro pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a página Edge DNS">

  Acesse [Azion Console](https://console.azion.com/) > **Edge DNS**.

  </DocStep>
  <DocStep title="Abra os registros da zona">

  Na página **Zones**, selecione a linha da zona e, em seguida, a aba **Records**.

  </DocStep>
  <DocStep title="Selecione + Record">

  O drawer **Create Record** é aberto.

  </DocStep>
  <DocStep title="Informe o nome do registro">

  Em **Name**, informe `@`, ou o nome que o serviço pede sem o seu domínio. O Console adiciona o domínio para você.

  </DocStep>
  <DocStep title="Selecione o tipo de registro TXT">

  Em **Record Type**, selecione *TXT - Text*.

  </DocStep>
  <DocStep title="Mantenha o TTL">

  Mantenha **TTL (seconds)** em `3600`.

  </DocStep>
  <DocStep title="Informe o valor">

  Em **Value**, informe o valor que o serviço forneceu, em uma linha.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Console mostra `Edge DNS Record has been created`, e o registro TXT aparece na tabela **Records**.

</Fragment>

<Fragment slot="panel.cli">

Para adicionar o registro pela Azion CLI, salve o registro como `txt.json`:

```json
{"name":"@","type":"TXT","rdata":["verification-token-abc123"],"ttl":3600}
```

Em seguida, crie o registro a partir do arquivo. Substitua `<zone-id>` pelo ID da sua zona:

```bash
azion create dns-record --zone-id <zone-id> --file txt.json
```

O comando imprime o ID do registro:

```text
Created DNS record with ID 100790
```

A zona contém o registro TXT. O arquivo mantém o valor intacto: `--rdata` lê o argumento como uma lista separada por vírgulas, então passe um valor por `--rdata` apenas quando ele não contiver vírgula nem aspas duplas.

</Fragment>

<Fragment slot="panel.api">

Para adicionar o registro pela Azion API, envie uma requisição `POST` ao endpoint de registros da zona. Substitua `<zone-id>` pelo `id` da sua zona e `[TOKEN VALUE]` pelo seu personal token:

```bash
curl -X POST https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records \
  -H "Authorization: Token [TOKEN VALUE]" \
  -H "Content-Type: application/json" \
  -d '{"name":"@","type":"TXT","rdata":["verification-token-abc123"],"ttl":3600}'
```

Uma resposta `201` retorna o registro:

```json
{
  "state": "executed",
  "data": {
    "id": 100791,
    "description": "",
    "name": "@",
    "ttl": 3600,
    "type": "TXT",
    "rdata": ["verification-token-abc123"],
    "policy": "simple",
    "weight": 255
  }
}
```

A zona contém o registro TXT. Nunca inclua o domínio em `name`: o Edge DNS o adiciona.

</Fragment>

</Tabs>

Um valor TXT tem até 1.000 caracteres. Se o nome já tiver um registro TXT, um segundo é recusado com `19004` `Record Already Exists`. Nesse caso, adicione o valor como outra linha do registro existente, como em [Adicione, edite ou exclua um registro](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/adicionar-registros/). Para todas as regras do TXT, consulte [Tipos de registro](/pt-br/documentacao/plataforma/edge-dns/tipos-de-registro/#txt).

## Confira o registro nos nameservers da Azion

Antes que o serviço verifique o domínio, consulte o nameserver da Azion diretamente, sem o cache do seu resolver. Esta verificação não depende da interface escolhida.

:::caution[Atenção]
Consulte um nome apenas depois de salvar o registro dele. Um nome consultado antes de o registro existir recebe `NXDOMAIN` por até uma hora, o mínimo do SOA, mesmo depois que você adiciona o registro.
:::

Para consultar o registro TXT em `@` no `ns1.aziondns.net`, substitua `example.com` pelo seu domínio:

```bash
dig +short @ns1.aziondns.net example.com TXT
```

O nameserver retorna cada valor do registro entre aspas duplas:

```text
"verification-token-abc123"
```

Se o comando não imprimir nada, aguarde alguns minutos e execute-o novamente. Uma alteração em um registro existente pode levar alguns minutos para chegar a todos os nameservers. Se o nome foi consultado antes de o registro existir, o nameserver pode retornar uma resposta vazia ou `NXDOMAIN` por até uma hora. Para esse caso, consulte [Um registro novo retorna NXDOMAIN](/pt-br/documentacao/plataforma/edge-dns/solucao-de-problemas/#um-registro-novo-retorna-nxdomain).

Quando o `ns1.aziondns.net` retornar o seu valor, peça ao serviço que verifique o domínio. Até que o registrador do domínio o delegue aos nameservers da Azion, um resolver público não encontra delegação para a Azion, e o serviço não consegue ler o registro.
