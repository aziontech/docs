Um stream é a entidade do [Data Stream](/pt-br/documentacao/plataforma/data-stream/) que coleta os eventos de uma fonte de dados. Ele renderiza cada evento como uma linha de log com um template e envia as linhas para um endpoint. Azion Console e Azion API gravam o mesmo objeto, por isso cada tabela desta página mostra o rótulo do Azion Console ao lado do campo da API. Os campos da API são escritos como caminhos dentro do corpo da requisição, como `inputs[0].attributes.data_source`.

---

## Objeto do stream

Este é um stream completo, escrito como um corpo JSON:

```json
{
  "name": "activity-to-bucket",
  "active": true,
  "inputs": [
    { "type": "raw_logs", "attributes": { "data_source": "activity_history" } }
  ],
  "transform": [
    { "type": "sampling", "attributes": { "rate": 100 } },
    { "type": "render_template", "attributes": { "template": 251 } }
  ],
  "outputs": [
    {
      "type": "s3",
      "attributes": {
        "host_url": "https://s3.us-east-005.azionstorage.net",
        "bucket_name": "<your-bucket>",
        "region": "us-east-005",
        "access_key": "[ACCESS KEY]",
        "secret_key": "[SECRET KEY]",
        "object_key_prefix": "activity",
        "content_type": "plain/text"
      }
    }
  ]
}
```

O stream envia todos os eventos do Activity History, formatados pelo template *Activity History Collector*, para um bucket pelo protocolo S3.

Os três arrays carregam as partes do stream:

- `inputs` contém uma fonte de dados.
- `transform` contém um item `render_template`. Em um stream de Applications, Functions ou WAF Events, ele também contém exatamente um entre `sampling` e `filter_workloads`. Um stream de Activity History salvo sem item `sampling` é aceito e não envia nenhum evento.
- `outputs` contém um endpoint. Quando `outputs` lista dois endpoints do mesmo tipo, a API responde `201` e mantém o último. Com um endpoint S3 e um endpoint Standard HTTP/HTTPS POST, ela responde `500`. Um `outputs` vazio é recusado com `10049`.

Cada item de `transform` tem um `type` e `attributes`, então `transform[sampling].attributes.rate` indica a chave `attributes.rate` do item cujo `type` é `sampling`.

O caminho da API é `/v4/workspace/stream/streams`, e um stream específico é `/v4/workspace/stream/streams/<stream-id>`. Toda requisição leva o header `Authorization: Token [TOKEN VALUE]`, com um personal token da conta. Para o token e a primeira requisição, consulte [Azion API](/pt-br/documentacao/devtools/api/).

Um `POST` responde `201` com `"state": "executed"` e o objeto armazenado, que acrescenta os campos somente leitura `id`, `last_editor`, `created`, `last_modified` e `product_version`. Um `PATCH` altera apenas as chaves que você envia: `{"active": true}` ativa um stream e o retorna com a fonte de dados, os transforms e o endpoint inalterados. Um `PUT` exige as mesmas chaves obrigatórias de uma criação. Para cada operação, consulte a [referência da Azion API](https://api.azion.com/v4).

Em contas que usam a API v4, Azion CLI gerencia streams e templates com os [comandos `data-stream`](/pt-br/documentacao/devtools/cli/recursos/data-stream/). [Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/) cria, atualiza no lugar e exclui um stream com o recurso `azion_data_stream`.

Salvar um stream como ativo é a única etapa de ativação de que ele precisa. Um stream que você cria ou ativa pode levar vários minutos para começar a coletar eventos, e ele não envia os eventos de antes disso. Um stream que você desativa pode continuar enviando por alguns minutos.

Uma conta com 3.000 Workloads ou mais gerencia seus streams apenas pela API, porque Azion Console bloqueia os formulários de criação e edição a partir desse número.

## General

No Azion Console, a seção **General** dá nome ao stream. A API exige `name`, `inputs`, `transform` e `outputs` em toda criação.

| Console | Campo da API | Tipo | Obrigatório | Padrão | Valores |
| --- | --- | --- | --- | --- | --- |
| **Name** | `name` | string | Sim | nenhum | De 1 a 100 caracteres. Um nome mais longo é recusado com `10046`. |

---

## Input

No Azion Console, a seção **Input** escolhe a fonte de dados da qual o stream coleta. Cada fonte de dados tem suas próprias variáveis, listadas em [Fontes de dados e variáveis](/pt-br/documentacao/plataforma/data-stream/fontes-de-dados-e-variaveis/).

| Console | Campo da API | Tipo | Obrigatório | Padrão | Valores |
| --- | --- | --- | --- | --- | --- |
| **Data Source** | `inputs[0].attributes.data_source` | enum | Sim | nenhum na API, *Applications* no Azion Console | `activity_history`, `workloads`, `functions_console` ou `waf`. Qualquer outro valor é recusado com `10039`. |
| nenhum | `inputs[0].type` | enum | Sim | nenhum | `raw_logs`, o único valor. |

Azion Console nomeia cada fonte de dados de forma diferente do seu slug na API:

| Opção no Azion Console | Slug na API | Variáveis |
| --- | --- | --- |
| *Activity History* | `activity_history` | [Activity History](/pt-br/documentacao/plataforma/data-stream/fontes-de-dados-e-variaveis/#activity-history) |
| *Applications* | `workloads` | [Applications](/pt-br/documentacao/plataforma/data-stream/fontes-de-dados-e-variaveis/#applications) |
| *Functions* | `functions_console` | [Functions](/pt-br/documentacao/plataforma/data-stream/fontes-de-dados-e-variaveis/#functions) |
| *WAF Events* | `waf` | [WAF Events](/pt-br/documentacao/plataforma/data-stream/fontes-de-dados-e-variaveis/#waf-events) |

*Activity History* carrega o [Activity History](/pt-br/documentacao/fundamentos/activity-history/) da conta. *Functions* requer [Functions](/pt-br/documentacao/plataforma/functions/) na conta, e *WAF Events* requer [Firewall](/pt-br/documentacao/plataforma/firewall/) com WAF.

## Transform

No Azion Console, a seção **Transform** define de quais [Workloads](/pt-br/documentacao/plataforma/workloads/) o stream coleta e qual parcela dos eventos deles ele envia.

No Console, o botão de opção **Option** escolhe o escopo. Cada escolha envia um item diferente:

| **Option** | O que o stream coleta | Item da API |
| --- | --- | --- |
| *All Current and Future Workloads*, o padrão | Todos os Workloads da conta, inclusive os criados depois. Mostra **Sampling**. | `sampling` |
| *Filter Workloads* | Apenas os Workloads que você move para **Chosen Workload**. | `filter_workloads` |

Um stream de Applications, Functions ou WAF Events carrega um item `sampling` ou um item `filter_workloads`. A API recusa um `transform` sem nenhum dos dois (`32002`) ou com os dois (`32007`). A API não define padrão para estes campos, então os padrões desta tabela são os do Azion Console:

| Console | Campo da API | Padrão no Azion Console | Valores |
| --- | --- | --- | --- |
| **Workloads** | `transform[filter_workloads].attributes.workloads` | Nenhum | Os Workloads em **Chosen Workload**: um array de 1 a 600 IDs de Workload, cada um de um Workload da conta. Um ID de outra conta é recusado com `32003`. |
| **Sampling** | `transform[sampling]` | Ligado | Ligado envia um objeto `sampling`. Desligado não envia nenhum e redefine **Sampling Rate (%)** para `100`. |
| **Sampling Rate (%)** | `transform[sampling].attributes.rate` | `100` | Inteiro de 1 a 100, obrigatório em um item `sampling`: a porcentagem de eventos que o stream envia. `0` é recusado com `10050`, e `101` com `10068`. |

Os eventos do Activity History pertencem à conta, e não a um Workload. Um stream de Activity History aceita um item `sampling` ou nenhum item de escopo, e a API recusa um item `filter_workloads` nele (`10088`). No Azion Console, *Filter Workloads* não aparece para Activity History. Sem um item `sampling`, o stream é aceito e não envia nenhum evento.

Azion Console pode nomear o mesmo controle a partir de domínios em vez de Workloads. **Option** passa a oferecer *All Current and Future Domains* e *Filter Domains*, e a lista de seleção mostra **Available Domain** e **Chosen Domain**. O campo da API é `filter_workloads` nos dois casos, e os itens que ele aceita são os IDs que os objetos da conta carregam.

Salvar um stream ativo com um item `sampling` em Applications, Functions ou WAF Events desativa todos os outros streams da conta, exceto os streams de Activity History. A API não retorna erro. Uma taxa de `100` conta como sampling. Para manter vários streams de Applications, Functions ou WAF Events ativos ao mesmo tempo, dê a cada um deles um item `filter_workloads` em vez de sampling.

Antes de salvar um stream com sampling em Applications, Functions ou WAF Events, Azion Console mostra `After activating and saving these settings, all other Data Streams will be disabled.` e acrescenta `When multiple Data Streams have different sampling rates, the system uses the lowest percentage.`

## Render Template

No Azion Console, a seção **Render Template** escolhe o template que transforma cada evento em uma linha de log. Azion Console agrupa as opções de **Template** em *Azion's Templates* e *Custom Templates*. O campo somente leitura **Data Set** mostra as variáveis do template selecionado.

| Console | Campo da API | Tipo | Obrigatório | Padrão | Valores |
| --- | --- | --- | --- | --- | --- |
| **Template** | `transform[render_template].attributes.template` | inteiro, ID do template | Sim | nenhum na API, o primeiro template por nome no Azion Console | O ID de um template predefinido ou de um template personalizado da conta. Sem o item, a requisição é recusada com `32008`, e um ID que não existe, com `32004`. |

A Azion oferece cinco templates predefinidos:

| Template predefinido | `template` |
| --- | --- |
| *Activity History Collector* | `251` |
| *Applications Event Collector* | `2` |
| *Applications + WAF Event Collector* | `184` |
| *Functions Event Collector* | `86` |
| *WAF Event Collector* | `4` |

No Console, **Create Custom Template** abre um drawer que cria um template personalizado na conta, listado em *Custom Templates*. Para as variáveis de cada template predefinido e o formato de um template personalizado, consulte [Templates e payload](/pt-br/documentacao/plataforma/data-stream/templates-e-payload/#templates-predefinidos).

## Status

No Azion Console, a seção **Status** liga ou desliga o stream. A lista de streams mostra cada um como *Active* ou *Inactive*.

| Console | Campo da API | Tipo | Obrigatório | Padrão | Valores |
| --- | --- | --- | --- | --- | --- |
| **Active** | `active` | boolean | Não | `true`, e ligado no Azion Console | `false` para o stream e mantém as configurações dele. `true` o inicia de novo. |

Um stream que você cria ou ativa pode levar vários minutos para começar a coletar eventos, e ele não envia os eventos de antes disso. Um stream que você desativa pode continuar enviando por alguns minutos. Ativar um stream que tem um item `sampling` em Applications, Functions ou WAF Events desativa todos os outros streams da conta, exceto os streams de Activity History.

## Permissões

As permissões da conta decidem quem pode alterar um stream. **View Data Stream** mostra os streams da conta, mas não permite criá-los, editá-los nem excluí-los. Azion Console deixa um usuário alterar um stream com **Edit Data Stream** ou como owner da conta. Para saber como as permissões são concedidas, consulte [Permissões de equipes](/pt-br/documentacao/fundamentos/teams-permissions/).

Apenas com **View Data Stream**, Azion Console desativa **+ Stream** e todos os campos do formulário, e a página de edição não mostra **Save**.

Azion Console mascara seis campos de chave, com um ícone que revela o valor:

- S3: **Access Key**, **Secret Key** e **Object Key Prefix**.
- AWS Kinesis Data Firehose: **Access Key** e **Secret Key**.
- Azure Monitor: **Shared Key**.

Sem a permissão de edição, um ícone de cadeado substitui o ícone de revelar.

## Erros

A API recusa cada requisição desta seção com HTTP `400`, exceto `10002`, com `401`, e não cria nada. O array `errors` carrega o código, o título e um `source.pointer` para o campo. O número em um pointer é a posição do item no seu array.

| Código | Título | Pointer | Causa | O que fazer |
| --- | --- | --- | --- | --- |
| `10002` | `Not Authenticated` | `source.headers` `Authorization` | A requisição não tem token: `Authentication credentials were not provided.` | Envie `Authorization: Token [TOKEN VALUE]`. |
| `10046` | `Max Length` | `/data/name` | `name` tem mais de 100 caracteres. | Reduza o nome para 100 caracteres ou menos. |
| `10039` | `Invalid Choice` | `/data/inputs/0/attributes/data_source` | `data_source` não é um slug conhecido, como `"nope"`. | Envie `activity_history`, `workloads`, `functions_console` ou `waf`. |
| `32002` | `Workloads Must Be Provided` | `/data/transforms` | Um stream de Applications, Functions ou WAF Events não tem item `sampling` nem item `filter_workloads` em `transform`: `If sampling is disabled, workloads must be provided.` | Adicione um item `sampling`, ou um item `filter_workloads` com IDs de Workload. |
| `32007` | `Sampling And Workloads Are Exclusive` | `/data/transform` | `transform` tem um item `sampling` e um item `filter_workloads`: `If sampling is enabled, workloads must not be provided.` | Mantenha apenas um deles: sampling para todos os Workloads, ou o filtro de workloads. |
| `32003` | `Workloads Not Belong Account` | `/data/transform/0/attributes/workloads` | Um ID de Workload não pertence à conta. `meta.invalid_workloads` lista os IDs, como `[1]`. | Envie IDs de Workloads da conta. |
| `10050` | `Min Value` | `/data/transform/0/attributes/rate` | `rate` é `0`. | Envie uma taxa de 1 a 100. |
| `10068` | `Max Value` | `/data/transform/0/attributes/rate` | `rate` é maior que `100`. | Envie uma taxa de 1 a 100. |
| `32008` | `Template Must Be Provided` | `/data/transform` | `transform` não tem item `render_template`. | Adicione um item `render_template` com um ID de template. |
| `32004` | `Template Does Not Exist` | `/data/transform/1/attributes/template` | `template` não é o ID de um template predefinido nem de um template personalizado da conta. | Envie um ID da lista de templates. |
| `10050` | `Min Value` | `/data/outputs/0/max_size` | Um endpoint `standard` tem `max_size` menor que `1000000`. | Envie `1000000` ou mais, ou omita `max_size`. |
| `10059` | `Required Field` | `/data/outputs/0/headers` | Um endpoint `standard` não tem `headers`. | Envie `headers`, ou `{}` para nenhum. |
| `10059` | `Required Field` | `/data/outputs/0/kafka_topic` | Um endpoint `kafka` não tem `kafka_topic`. | Envie `kafka_topic`. |
| `32006` e `10032` | `Invalid URL Scheme` e `Invalid Url` | `/data/outputs/0/url` | Um endpoint `standard` tem uma `url` que não é uma URL `http` ou `https`, como `not-a-url`. | Envie uma URL completa que comece com `http://` ou `https://`. |

Três comportamentos não retornam erro. Um stream de Activity History salvo sem item `sampling` é aceito e não envia nenhum evento. Quando `outputs` lista dois endpoints do mesmo tipo, a API responde `201` e mantém o último. Salvar um stream ativo com um item `sampling` em Applications, Functions ou WAF Events desativa todos os outros streams da conta, exceto os streams de Activity History.
