A tag JavaScript do Edge Pulse é o script que coleta medições nos browsers dos visitantes das suas páginas. [Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/) fornece a tag no Azion Console em duas formas, a **Default Tag** e a **Pre-loading Tag**.

A tag que o Azion Console fornece é customizada para a sua conta, então esta página descreve as duas formas em vez de reproduzir qualquer uma delas. Copie a tag do seu próprio Console e não reaproveite uma tag vinda de outro lugar.

A tag é totalmente assíncrona. Ela respeita o protocolo em uso, HTTP ou HTTPS. Ela não interfere no processo de carregamento nem na estrutura interna do conteúdo entregue.

---

## Tags

As duas tags do Edge Pulse ficam no mesmo lugar, no HTML da página e antes da tag `body` de fechamento. Elas diferem em quando o browser as executa.

| Tag | Quando ela executa | Quando escolher |
| --- | --- | --- |
| **Default Tag** | Depois que o evento de carregamento termina. A tag espera esse evento, depois baixa e executa o RUM Client. | A página permite JavaScript inline. Esperar o evento de carregamento mantém esse evento ininterrupto e deixa a experiência do visitante inalterada. |
| **Pre-loading Tag** | Antes que o evento de load dispare. | A página carrega configurações de Content Security Policy que impedem o uso de JavaScript inline. |

## Posicionamento da tag

Edge Pulse mede uma página apenas quando essa página carrega a tag. A tag está na página **Edge Pulse** no [Azion Console](https://console.azion.com), atrás do botão **Copy to Clipboard**. Uma tag cobre uma página, e Edge Pulse não coleta nada de uma página que não carrega a tag.

A tag é publicada manualmente ou por meio de um sistema de gerenciamento de tags. Quando o browser a executa depende de qual das duas tags você adicionou. Para copiar a tag e adicioná-la a uma página, consulte [Primeiros passos com Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/primeiros-passos/).

## O que a tag não aceita

A tag não tem configuração. Não existe taxa de amostragem para reduzir, nem campo para excluir do que ela envia, nem forma de deixar o seu próprio tráfego fora das medições. Escolher entre a **Default Tag** e a **Pre-loading Tag**, e escolher quais páginas carregam uma tag, são as duas decisões disponíveis.

A tag também mede apenas o carregamento em que ela roda. Ela não fica observando trocas de rota posteriores, então uma single-page application reporta uma medição por carregamento completo. Para entender por que isso decorre do momento em que a tag roda, consulte [Como o Edge Pulse funciona](/pt-br/documentacao/plataforma/edge-pulse/como-funciona/).

## Configurações do browser

Edge Pulse lê a configuração `navigator.doNotTrack` do browser do visitante. O valor decide se o identificador do visitante sobrevive de uma visita para a seguinte.

| Valor | Comportamento do Edge Pulse |
| --- | --- |
| `navigator.doNotTrack` definido como `1` | Se o rastreamento nunca foi permitido, e Edge Pulse portanto nunca usou o local storage, um identificador é gerado para cada visita que o visitante faz ao site. Se o valor é `1` mas o visitante foi rastreado antes, o identificador anterior é excluído e um novo é gerado. |
| `navigator.doNotTrack` definido como qualquer outro valor | Edge Pulse rastreia, e o mesmo identificador é usado para cada visita de um visitante. |

## Identificador de visitante

Edge Pulse identifica um visitante com um valor gerado pelo algoritmo UUID4, a variante aleatória do esquema de identificador único universal. Edge Pulse guarda esse valor no local storage do browser, o armazenamento que um browser mantém para um site e não limpa quando a página fecha. A configuração `navigator.doNotTrack` decide quanto tempo o valor vive.

Para acompanhar o identificador ao longo de uma medição, consulte [Como o Edge Pulse funciona](/pt-br/documentacao/plataforma/edge-pulse/como-funciona/).

## Dados coletados

Edge Pulse coleta informações como o resolvedor usado para a resolução DNS, o data center testado e a rede anônima do visitante. Essas são instâncias das cinco categorias em que os dados coletados se dividem:

- Navegação
- Performance
- Experiência de usuário
- Informacionais
- Rede
