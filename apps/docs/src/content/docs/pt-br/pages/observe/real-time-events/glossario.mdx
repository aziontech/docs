Definições dos termos que a documentação de [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) usa.

| Termo | Definição |
| --- | --- |
| Activity History | Uma das oito fontes de dados do Real-Time Events. Guarda um registro por ação executada em uma conta Azion, conforme [Activity History](/pt-br/documentacao/fundamentos/activity-history/) a registra, e mantém esse registro por 2 anos. Para as variáveis que o registro carrega, consulte [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/#activity-history). |
| Data Scan | Uma das duas métricas pelas quais Real-Time Events é cobrado, cobrada por GB. Mede o volume de dados que uma consulta lê, portanto uma busca sobre um período amplo escaneia mais que uma busca estreita. Para a tarifa e o volume que cada plano inclui, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#real-time-events). |
| dataset | O conjunto de registros que a API GraphQL do Real-Time Events consulta, e a palavra que a visualização em Preview do Azion Console usa para uma fonte de dados. Um dataset nomeia seus campos em camelCase, portanto a variável `Remote Address` na visualização clássica do Azion Console é o campo `remoteAddress` em uma consulta, e o [Data Stream](/pt-br/documentacao/plataforma/data-stream/) nomeia as próprias variáveis, como `$remote_addr`. [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/) lista cada dataset e seus campos. |
| fonte de dados | Os registros de um tipo de evento, como as requisições que suas Applications e Firewalls recebem ou as ações na sua conta. Em uma consulta, ela é o índice de onde os registros são lidos, portanto toda busca seleciona uma. [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/) documenta as oito fontes de dados e as variáveis que cada uma carrega. |
| GraphiQL Playground | O cliente de navegador que a API GraphQL do Real-Time Events serve em `https://api.azion.com/v4/events/graphql`, onde você compõe e executa uma consulta contra um dataset. Para obter um token e enviar uma primeira consulta, consulte [Primeiros passos da API GraphQL](/pt-br/documentacao/devtools/graphql/primeiros-passos/). |
| intervalo de tempo | O período que uma busca cobre, aplicado sobre a fonte de dados: a fonte de dados decide quais registros são lidos e o intervalo de tempo decide até onde a busca alcança no passado. Um intervalo de tempo que vai além da [retenção](/pt-br/documentacao/plataforma/real-time-events/limites/) não retorna nenhum registro para a parte fora dela. [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/#intervalo-de-tempo) lista os períodos que o Console oferece. |
| registro de evento | Uma entrada que uma fonte de dados guarda: o conjunto de variáveis que um recurso da plataforma escreveu para um único evento, como uma requisição, uma consulta DNS ou uma ação na conta. [Como Real-Time Events funciona](/pt-br/documentacao/plataforma/real-time-events/como-funciona/) acompanha um registro do recurso da plataforma que o escreve até a consulta que o lê. Para abrir um registro e ler suas variáveis, consulte [Ler um registro de evento](/pt-br/documentacao/guias/plataforma/observabilidade/entender-logs/). |
| retenção | Por quanto tempo Real-Time Events mantém um registro de evento consultável. Os registros são mantidos por 7 dias, equivalentes a 168 horas, e os registros de Activity History por 2 anos. [Limites](/pt-br/documentacao/plataforma/real-time-events/limites/) carrega os dois valores e os limites que uma consulta carrega. |
| Storage | Uma das duas métricas pelas quais Real-Time Events é cobrado, cobrada por GB. Mede o volume de registros de eventos mantidos. Para a tarifa e o volume que cada plano inclui, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#real-time-events). |
| variável | O nome que estas páginas dão a um campo de um registro de evento, conforme o filtro da visualização clássica do Azion Console o lista, como _Remote Address_. Cada fonte de dados carrega o próprio conjunto, portanto as variáveis de um registro de HTTP Requests diferem das de um registro de Edge DNS. [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/) lista as variáveis das oito, e [Filtrar eventos](/pt-br/documentacao/guias/plataforma/observabilidade/adicionar-filtros-events/) mostra como uma busca se restringe a uma. |
