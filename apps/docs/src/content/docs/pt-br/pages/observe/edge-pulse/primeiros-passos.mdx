Este guia conduz você pela coleta das suas primeiras medições com [Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/).

- Abra Edge Pulse no Azion Console.
- Copie a tag JavaScript do Edge Pulse que Azion Console fornece.
- Adicione a tag a cada página que você quer monitorar e publique essas páginas.
- Descubra onde são lidas as medições que seus visitantes produzem.

Não há nada a criar no Azion Console. Edge Pulse é um produto padrão, ativado em toda conta Azion, e a tag que Azion Console fornece já existe. O único objeto que você altera é o seu próprio HTML. Uma página carrega uma tag, e uma página sem a tag é uma página que Edge Pulse não mede. Essa é toda a composição, e é por isso que este guia termina no seu sistema de publicação, não no Azion Console.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- As páginas que você quer monitorar, com acesso para editar e publicar o HTML delas.

---

## Abra Edge Pulse no Azion Console

A tag é servida pela própria página do produto, e nenhuma etapa de ativação vem antes dela.

Acesse [Azion Console](https://console.azion.com/) > **Products menu** > **Observe** > **Edge Pulse**.

A página **Edge Pulse** abre, carregando a tag JavaScript do Edge Pulse atrás de um botão **Copy to Clipboard**.

---

## Copie a tag

A tag que o Azion Console fornece é customizada para a sua conta, então copie a do seu próprio Console e não a de outro lugar. Ela vem em duas formas, e escolher entre elas é uma propriedade das suas páginas, não uma preferência. Use a **Default Tag**. Use a **Pre-loading Tag** em vez dela quando a página carregar configurações de Content Security Policy que impedem o uso de JavaScript inline. Para o que separa as duas, consulte [Tag JavaScript do Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/tag-javascript/).

Para copiar a tag no Azion Console:

<DocSteps>
  <DocStep title="Selecione a tag que suas páginas precisam" />
  <DocStep title="Selecione Copy to Clipboard" />
</DocSteps>

A tag está na sua área de transferência, pronta para colar em uma página.

---

## Adicione a tag a cada página que você quer monitorar

Edge Pulse mede uma página porque essa página carrega a tag. A tag não é herdada de um caminho pai, de um template que você não republicou nem de outra página do mesmo site. Uma página que você deixa sem a tag não produz medição nenhuma.

Para adicionar a tag às suas páginas:

<DocSteps>
  <DocStep title="Cole a tag na página">

  No HTML da página, cole a tag imediatamente antes da tag `body` de fechamento.

  </DocStep>
  <DocStep title="Repita em cada página que você quer monitorar">

  Cole a mesma tag página por página ou distribua a tag pelas páginas com um sistema de gerenciamento de tags.

  </DocStep>
  <DocStep title="Publique as páginas" />
</DocSteps>

Cada página que você publicou carrega a tag JavaScript do Edge Pulse, e os browsers dos visitantes dessas páginas a executam.

---

## Descubra onde as medições são lidas

Uma medição vem de uma visita real. Nada é coletado até que um visitante carregue uma das páginas que você publicou, portanto os primeiros resultados seguem o seu tráfego, não o momento em que você publicou. Em uma página com pouco tráfego, considere isso antes de concluir que a tag está errada.

Não existe tela no Azion Console que mostre as medições. Elas são lidas com a API GraphQL que [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) serve, e uma consulta é a única forma de chegar até elas. O dataset a consultar é o `pulseEvents`. Para saber como se autenticar nesse endpoint e enviar uma primeira consulta, consulte [Primeiros Passos API GraphQL](/pt-br/documentacao/devtools/graphql/primeiros-passos/). Para os campos que o `pulseEvents` carrega, consulte [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/).

Suas páginas estão com a tag, e toda visita a uma delas produz uma medição que Edge Pulse coleta. Para saber o que um browser com a tag faz em uma visita, com que frequência ele repete o teste e o que identifica um visitante, consulte [Como o Edge Pulse funciona](/pt-br/documentacao/plataforma/edge-pulse/como-funciona/).
