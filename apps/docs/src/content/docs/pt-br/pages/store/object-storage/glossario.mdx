Definições dos termos que a documentação do [Object Storage](/pt-br/documentacao/plataforma/object-storage/) usa.

| Termo | Definição |
| --- | --- |
| access key | A metade pública de uma [credencial S3](/pt-br/documentacao/plataforma/object-storage/compatibilidade-s3/), enviada com toda requisição assinada para o protocolo S3. Identifica a credencial e pode ser lida novamente depois da criação, ao contrário do secret key. |
| `azion:storage` | O módulo do [Azion Runtime](/pt-br/documentacao/devtools/runtime/api-reference/storage/) que uma Function importa para chamar `get`, `put`, `list` e `delete` nos objetos de um bucket durante uma requisição. Uma Function só grava em um bucket cujo workloads access é `read_write`. |
| bucket | O contêiner em que o Object Storage guarda objetos. Buckets não são aninhados, um nome é único entre todas as contas Azion e o nome não pode ser alterado depois da criação. [Buckets e objetos](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/) documenta cada campo e as regras que um nome segue. |
| capability | Uma das seis permissões que uma [credencial S3](/pt-br/documentacao/plataforma/object-storage/compatibilidade-s3/) pode ter: `listFiles`, `readFiles`, `writeFiles`, `deleteFiles`, `listAllBucketNames` e `listBuckets`. A API da Azion rejeita qualquer outro valor. `writeFiles` permite à credencial gravar e excluir objetos, e `deleteFiles` sozinha não permite nenhuma operação. |
| chave do objeto | A string que identifica um objeto dentro de um bucket, entre 1 e 1.024 caracteres. Uma chave pode conter a barra, que as interfaces leem como um [prefixo](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/). Azion Console renomeia ou move um objeto copiando-o para a chave nova e excluindo a antiga. |
| Connector | A entidade que você cria em [Connectors](/pt-br/documentacao/plataforma/connectors/), o recurso da plataforma que encaminha requisições das suas Applications às origens que guardam o seu conteúdo. Um Connector do tipo `storage` encaminha requisições a um bucket, restrito a um prefixo quando ele tem um, e a Application as responde com os objetos desse bucket. |
| credencial S3 | A entidade que guarda o par de access key e secret key que autentica uma requisição ao [endpoint S3](/pt-br/documentacao/plataforma/object-storage/compatibilidade-s3/), limitado pelas suas capabilities. A lista de buckets da credencial limita os objetos que ela alcança, e uma credencial sem lista alcança os objetos de todos os buckets da conta. Uma credencial não muda depois de criada e deixa de funcionar quando expira ou é excluída. |
| Object Storage | Um recurso da plataforma que [armazena arquivos como objetos em buckets](/pt-br/documentacao/plataforma/object-storage/) na infraestrutura da Azion e pode servi-los às suas [Applications](/pt-br/documentacao/plataforma/applications/). As interfaces dele são Azion Console, a API da Azion, a Azion CLI, o Azion Runtime, a [biblioteca `@aziontech/storage`](/pt-br/documentacao/devtools/azion-lib/storage/) e o protocolo S3, e o [Terraform Provider](/pt-br/documentacao/devtools/terraform/) gerencia os buckets dele. |
| objeto | Um arquivo armazenado em um bucket, junto com a chave sob a qual é guardado e o content type com que é servido. Um objeto é substituído por inteiro: um upload para uma chave em uso sobrescreve o conteúdo que a API da Azion devolve, e uma Application devolve o conteúdo novo quando não guarda mais uma cópia em cache. Pelo protocolo S3, a versão anterior continua legível pelo ID dela por um prazo que você não define, como indicam os [Limites do Object Storage](/pt-br/documentacao/plataforma/object-storage/limites/#escopo). |
| período de carência | As 24 horas em que um objeto excluído é retido antes de ser removido em definitivo. A API da Azion deixa de listar e de servir o objeto imediatamente, e o bucket não pode ser excluído até o período terminar. [Buckets e objetos](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/) documenta as operações de exclusão a que ele se aplica. |
| prefixo | Um segmento inicial que um grupo de [chaves de objeto](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/) compartilha, como `assets/` na chave `assets/logo.svg`. Azion Console mostra um prefixo como uma pasta, assim como a API da Azion quando uma requisição de listagem define `all_levels` como `false`, mas um prefixo só existe enquanto houver uma chave que começa com ele. Um [Connector](/pt-br/documentacao/plataforma/connectors/) do tipo `storage` com o prefixo `assets` encaminha uma requisição para `/logo.svg` ao objeto `assets/logo.svg`. |
| secret key | A metade privada de uma [credencial S3](/pt-br/documentacao/plataforma/object-storage/compatibilidade-s3/), usada para assinar uma requisição ao protocolo S3. É retornada apenas pela requisição que cria a credencial e não pode ser lida nem alterada depois. Um secret key perdido é substituído pela criação de outra credencial. |
| `Storage-Content-Type` | Um cabeçalho que a API da Azion aceita em um upload e sobre o qual não age. O content type armazenado com um objeto vem de `Content-Type` ou, quando um upload pela API da Azion não envia esse cabeçalho, da extensão da chave. [Buckets e objetos](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/) documenta o comportamento. |
| workloads access | O campo do bucket que decide o que um Connector e uma Function das suas Applications fazem com os objetos nele, definido como `read_only`, `read_write` ou `restricted`. Não restringe a API da Azion nem o protocolo S3, que são governados pelo token ou pela credencial que a requisição carrega. [Buckets e objetos](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/) documenta cada valor. |
