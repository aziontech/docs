[Object Storage](/pt-br/documentacao/plataforma/object-storage/) limita o nome de um bucket, a chave de um objeto e o número de registros que uma requisição de listagem retorna. Ele também limita o número de buckets e de access keys que uma conta guarda. Esta página indica o escopo do Object Storage, cada limite e o que a plataforma faz acima dele. Para solicitar um limite maior para a conta, entre em contato com o time de [suporte técnico](/pt-br/documentacao/suporte/).

---

## Escopo

- **Entrega aos seus usuários**: os [Termos de Serviço](/pt-br/documentacao/contratos/tds/) dizem que os objetos devem chegar aos seus usuários por uma Application. Eles também sujeitam o acesso direto, fora de uma Application, a rate limits. Uma Application os serve por uma regra que define um Connector do tipo `storage` ou executa uma Function. A [visão geral do Object Storage](/pt-br/documentacao/plataforma/object-storage/#caminho-da-requisicao) mostra esse caminho. A API da Azion e o endpoint S3 recusam requisições sem credenciais com `401`, mas uma URL pré-assinada entrega o objeto a quem a tiver.
- **Listagem do bucket**: uma requisição para `/` que chega a um Connector sem prefixo devolve uma lista XML das chaves dos objetos do bucket, sem credenciais. `?prefix=` filtra essa lista. Uma regra no [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) que compara `${uri}` com `/` e o redireciona, por exemplo para `/index.html`, responde com o redirecionamento no lugar.
- **Gravações por uma Application**: o nível de acesso de um bucket decide o que um Connector e uma Function fazem com os objetos dele. Em um bucket `read_write`, uma requisição `DELETE` que chega ao Connector exclui o objeto, enquanto `PUT` recebe `403` e `POST` recebe `501`. Mantenha `read_only` em um bucket que um Connector serve. Um bucket em que uma Function grava precisa de `read_write`, então não aponte nenhum Connector para ele.
- **Gravações fora de uma Application**: o nível de acesso não restringe a API da Azion nem o protocolo S3. Um personal token, ou uma credencial com a capability `writeFiles`, grava em um bucket em qualquer nível, `restricted` incluído.
- **Buckets pelo S3**: o endpoint S3 gerencia objetos, não buckets, e recusa `CreateBucket` e `DeleteBucket` com `403` `AccessDenied`. Crie e exclua buckets pelo Azion Console, pela API da Azion, pela Azion CLI ou pelo Terraform Provider. [Compatibilidade com S3](/pt-br/documentacao/plataforma/object-storage/compatibilidade-s3/#operacoes-suportadas) lista as operações que a Azion suporta.
- **Versões**: uma gravação em uma chave substitui o objeto que a API da Azion devolve, e não é possível ativar o versionamento. Uma Application devolve o objeto novo quando não guarda mais uma cópia em cache do antigo. Pelo protocolo S3, `ListObjectVersions` ainda lista uma versão anterior ou um objeto excluído, e `GetObject` o lê pelo ID da versão. Essa cópia fica por um prazo que você não define, então mantenha a sua própria cópia de uma versão de que possa precisar de volta.
- **Consultas**: a API da Azion e o endpoint S3 leem um objeto pela chave dele ou listam as chaves sob um prefixo. Nenhum dos dois tem uma operação que pesquise o conteúdo ou os metadados dos objetos. Guarde dados relacionais no [SQL Database](/pt-br/documentacao/plataforma/sql-database/) e pares de chave e valor no [KV Store](/pt-br/documentacao/plataforma/kv-store/).
- **Durabilidade**: a Azion faz esforços comercialmente razoáveis para manter os seus objetos disponíveis e duráveis, e os [Termos de Serviço](/pt-br/documentacao/contratos/tds/) não garantem contra perda de dados. Mantenha a sua própria cópia dos dados que você não pode perder.

## Limites padrão

Object Storage aplica cada limite abaixo por padrão. Acima de um limite, a API da Azion responde HTTP `400` com o código de erro e o título da linha. Quando a linha indica outro resultado, vale o que a linha diz.

| Escopo | Limite | Acima do limite |
| --- | --- | --- |
| Tamanho do nome do bucket (`name`) | 6 a 63 caracteres | `10048` `Min Length` abaixo de 6 caracteres e `10046` `Max Length` acima de 63. |
| Caracteres do nome do bucket | Letras minúsculas, números e o hífen (`-`) | `17002` `Invalid Bucket Name` para uma letra maiúscula ou um underscore (`_`). |
| Primeiro e último caracteres do nome do bucket | Uma letra minúscula ou um número | `17002` `Invalid Bucket Name` para um hífen. |
| Prefixos e sufixos do nome do bucket | Nunca começa com `azion`, `xn--`, `sthree-` ou `amzn-s3-demo-`, nem termina com `-s3alias` ou `--ol-s3` | `17001` `Bucket Name Not Available`. |
| Unicidade do nome do bucket | Um único nome em todas as contas Azion | `17000` `Bucket Already Exists`. |
| Tamanho da chave do objeto (`object_key`) | 1 a 1.024 caracteres | `503` `10100` `Service Unavailable` acima de 1.024 caracteres. Encurte a chave. |
| Upload único pelo Azion Console | 300 MB | Azion Console recusa o arquivo: "Files larger than 300 MB cannot be uploaded." |
| Buckets por resposta de listagem (`page_size`) | 100 buckets | `10097` `Invalid Page Size` acima de 100. Leia o restante da lista com `page`. |
| Objetos por resposta de listagem (`max_object_count`) | 1.000 chaves | A resposta carrega um `continuation_token`. Envie-o de volta para ler a próxima página. |
| Exclusão de bucket | Bloqueada enquanto o bucket guarda objetos e por 24 horas após a remoção do último objeto | `17006` `Cannot Delete Non Empty Bucket`. |
| Exclusão de um bucket referenciado | Bloqueada enquanto um Connector referencia o bucket | `409` `17016` `Cannot Delete Referenced Bucket`, cujo `detail` indica o Connector e o ID dele. |
| Região | `us-east-005` | A região não pode ser selecionada: a API da Azion ignora um campo `region`. |

Dois outros limites se aplicam a cada conta: 100 buckets e 100.000 access keys de credencial S3.
