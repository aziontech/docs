Com o data source plugin da Azion, você cria um painel de dashboard do Grafana que exibe os dados da Azion de que você precisa. Esta página cobre o painel em si: o data source, a consulta, os cinco campos que moldam o resultado e o tipo de visualização.

Conectar Grafana à sua conta é uma tarefa separada. Para mais informações, consulte [Instale o plugin da Azion para Grafana](/pt-br/documentacao/guias/plataforma/observabilidade/integrar-grafana/).

---

## Pré-requisitos

- Uma instância do Grafana rodando na sua máquina. Para instalar uma, consulte o [repositório do plugin da Azion para Grafana](https://github.com/aziontech/grafana-plugin).
- O plugin da Azion instalado nessa instância e autorizado. Para mais informações, consulte [Instale o plugin da Azion para Grafana](/pt-br/documentacao/guias/plataforma/observabilidade/integrar-grafana/).
- Uma consulta que retorna os dados do [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) que você quer exibir no painel.

---

## Crie o painel

Um painel guarda uma consulta e um tipo de visualização. Os cinco campos abaixo mapeiam os campos que a consulta retorna para a visualização.

Para adicionar um painel que lê dados da Azion, no Grafana:

<DocSteps>
  <DocStep title="Abra a lista de dashboards">

  Selecione **Dashboards**. A página de dashboards abre.

  </DocStep>
  <DocStep title="Crie um dashboard">

  Ao lado da barra de busca, _search_, selecione **New** > **New Dashboard**.

  </DocStep>
  <DocStep title="Selecione Add visualization" />
  <DocStep title="Selecione o data source">

  Na lista suspensa **Data source**, selecione _Azion_.

  </DocStep>
  <DocStep title="Insira a consulta">

  Na caixa de código, insira a consulta que o painel executa. Para exemplos de consultas, consulte [API GraphQL](/pt-br/documentacao/devtools/graphql/visao-geral/).

  </DocStep>
  <DocStep title="Preencha os campos do painel">

  Cinco campos completam a configuração. Quais deles você preenche depende do tipo de visualização e do que o painel exibe:

  - **Data path**: informe o valor `Events`.
  - **Time path**: informe um timestamp. O campo é delimitado por pontos.
  - **Time format**: informe um formato de hora/data [no formato moment.js](https://momentjs.com/docs/#/parsing/string/).
  - **Group by**: use esse campo quando quiser os dados agrupados em formato agregado.
  - **Alias by**: use esse campo para mudar o valor e o nome que um campo carrega na legenda.

  </DocStep>
  <DocStep title="Selecione o tipo de visualização">

  Na lista **Visualization**, selecione o tipo que o painel usa. Para ler registros de eventos brutos em grande volume, ou uma consulta top X, Azion recomenda o tipo _Table_. Você pode combiná-lo com outros tipos de gráficos.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

Grafana salva o painel e o dashboard exibe os dados que a consulta retorna.
