Você pode ler um registro de evento do [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) pelo Azion Console. O que o registro responde depende das variáveis que você lê. Cada fonte de dados carrega seu próprio conjunto de variáveis pré-organizadas. Elas informam sobre o acesso, o comportamento e a performance das suas aplicações e dos produtos relacionados.

Para cada variável que uma fonte de dados carrega, com a descrição dela e um exemplo, consulte [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/).

Duas buscas levam a esse registro. Execute uma [busca geral](#executar-uma-busca-geral) para retornar todos os registros que uma fonte de dados escreveu no período. Execute uma [busca filtrada](#executar-uma-busca-filtrada) para retornar apenas os registros que correspondem aos valores que você nomeia.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Um produto que já escreveu registros na fonte de dados que você quer buscar.

---

## Executar uma busca geral

Uma busca geral retorna todos os registros de uma fonte de dados no período, com todas as variáveis deles. Execute uma quando você quer o máximo de informação possível, ou quando ainda não sabe o que investigar. Ela é executada com o campo de consulta vazio.

Para executar uma busca geral no Azion Console:

<DocSteps>
  <DocStep title="Abra Real-Time Events">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione a fonte de dados">

  Selecione a aba da fonte de dados, como **Functions**.

  </DocStep>
  <DocStep title="Abra o período">

  Selecione o campo de período, que mostra _Last 5 minutes_.

  </DocStep>
  <DocStep title="Selecione o período">

  Selecione **Quick** e depois _Last 1 hour_.

  </DocStep>
  <DocStep title="Execute a busca">

  Selecione **Update**.

  </DocStep>
</DocSteps>

A tabela de resultados carrega todos os registros que essa fonte de dados escreveu no período. Cada linha mostra **Time** e **Log Body**. A tabela mostra uma contagem, como "3 records found". Um período sem registros mostra "No logs have been found for this period."

Considere uma Application que não exibe o que você configurou em uma [Function](/pt-br/documentacao/plataforma/functions/). Selecione a aba **Functions** para ver se a Function correta foi executada e quanto tempo ela levou. Depois selecione a aba **Functions Console** para ler as linhas que a Function escreveu no console.

## Executar uma busca filtrada

Uma busca filtrada retorna apenas os registros cujo campo carrega o valor que você nomeia. Execute uma quando você já sabe o que vai analisar.

Para executar uma busca filtrada no Azion Console:

<DocSteps>
  <DocStep title="Abra Real-Time Events">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione a fonte de dados">

  Selecione a aba **HTTP Requests**.

  </DocStep>
  <DocStep title="Abra o filtro">

  Selecione o ícone de filtro.

  </DocStep>
  <DocStep title="Selecione o campo">

  No diálogo **Filter**, selecione _Status_.

  </DocStep>
  <DocStep title="Selecione o operador">

  Em **Operator**, selecione _Equals_.

  </DocStep>
  <DocStep title="Informe o valor">

  No campo de valor, digite `400`.

  </DocStep>
  <DocStep title="Aplique o filtro">

  Selecione **Apply**.

  </DocStep>
</DocSteps>

A busca é executada na mesma hora, sobre o período que o campo de período mostra. O campo de consulta mostra `status = 400`, e a tabela de resultados carrega apenas os registros que correspondem.

Considere a suspeita de que usuários maliciosos estão tentando alcançar sua aplicação. Na aba **HTTP Requests**, filtre por um campo que identifica o cliente. _Host_, _Remote Address_ e _Request Uri_ reduzem o resultado, cada um, a uma propriedade diferente da requisição.

Para o campo de consulta, o período e mais exemplos de filtros, consulte [Filtrar eventos](/pt-br/documentacao/guias/plataforma/observabilidade/adicionar-filtros-events/).

## Buscar por request ID

Um request ID alcança o registro de uma requisição e de nenhuma outra. O campo `requestId` guarda um identificador único para cada requisição, como `5f222ae5938482c32a822dbf15e19f0f`.

Um valor de um cabeçalho de resposta HTTP, como `X-Request-Id`, pode carregar um sufixo numérico depois de um hífen. Por exemplo: `5f222ae5938482c32a822dbf15e19f0f-1234`. A camada de rede adiciona esse sufixo, e o registro de evento não o guarda.

Busque no Real-Time Events, ou na [API GraphQL](/pt-br/documentacao/devtools/graphql/visao-geral/), apenas com o identificador base. Uma busca que inclui o sufixo pode não retornar resultado nenhum, ou retornar um erro `400`.

Onde o cabeçalho retorna `5f222ae5938482c32a822dbf15e19f0f-1234`, busque por `5f222ae5938482c32a822dbf15e19f0f`.

---

## Abrir um registro

Uma linha da tabela de resultados mostra o registro em duas colunas, **Time** e **Log Body**. **Log Body** lista os campos dele pelos nomes da API, como `remoteAddress`, `requestUri` e `status`. Abrir o registro dispõe cada campo em uma linha própria.

Para abrir um registro no Azion Console, selecione a linha dele na tabela de resultados.

A visualização **More Details** abre, com o host do registro no título. As colunas **Field** e **Value** listam todos os campos do registro pelo nome da API, como `host` e `upstreamStatus`. Um seletor **Table** e **Cards** define o layout da visualização.

Para o significado de cada um desses campos, consulte [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/).
