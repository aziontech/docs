Definições dos termos que a documentação de **Custom Pages** usa.

| Termo | Definição |
| --- | --- |
| conjunto de custom pages | A lista nomeada que agrupa custom pages, pelo menos uma por conjunto, servida na API em `/v4/workspace/custom_pages`. Azion Console a chama de custom page, na página **Create Custom Page**. Um [Workload](/pt-br/documentacao/plataforma/workloads/) usa um conjunto de custom pages somente depois que o [deployment](/pt-br/documentacao/plataforma/workloads/configuracoes/#deployment) desse Workload define esse conjunto, como mostra [Primeiros passos com Custom Pages](/pt-br/documentacao/plataforma/custom-pages/primeiros-passos/). |
| custom page | Uma entrada de um conjunto de custom pages: a página que a Azion entrega no lugar de uma resposta com status code 4xx ou 5xx de um [Connector](/pt-br/documentacao/plataforma/connectors/), selecionada pelo status code da página. Com uma página `page_connector`, a Azion busca o documento em `uri` no Connector da página, guarda-o em cache por `ttl` e responde com `custom_status_code`, quando definido, então o cliente é atendido no mesmo endereço, e não redirecionado. [Configurações de custom page](/pt-br/documentacao/plataforma/custom-pages/configuracoes/) documenta todos os campos. |
| Custom Pages | Um recurso da plataforma que substitui por uma página sua a resposta de erro retornada por um Connector, uma página por status code de erro, por meio do conjunto de custom pages que o deployment de um Workload define. Ele substitui as [Error Responses](/pt-br/documentacao/plataforma/custom-pages/error-responses/) de uma [Application](/pt-br/documentacao/plataforma/applications/) na API v3. [Custom Pages](/pt-br/documentacao/plataforma/custom-pages/) o descreve. |
