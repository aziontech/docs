[Custom Pages](/pt-br/documentacao/plataforma/custom-pages/) é um recurso da plataforma que substitui por uma página sua a resposta de erro retornada por um [Connector](/pt-br/documentacao/plataforma/connectors/), uma página por status code de erro. Um conjunto de custom pages é a lista nomeada que agrupa essas páginas. Esta página informa onde Custom Pages age e os limites que a Azion aplica a um conjunto e a cada página dele.

---

## Escopo

- **Status codes**: uma página substitui apenas um dos 22 códigos de [Status codes](/pt-br/documentacao/plataforma/custom-pages/configuracoes/#status-codes), 16 erros de cliente (4xx) e seis erros de servidor (5xx).
- **Workloads**: um [Workload](/pt-br/documentacao/plataforma/workloads/) usa um conjunto de custom pages somente depois que o deployment desse Workload define esse conjunto. Um Workload guarda no máximo um deployment, então um conjunto cobre todos os hostnames do Workload. Para os campos do deployment, consulte [Configurações de Workload](/pt-br/documentacao/plataforma/workloads/configuracoes/#deployment).
- **Tempo**: um conjunto atribuído só é servido depois que a mudança no deployment se propaga, ao longo de vários minutos, e a Azion não garante quando. Repita a requisição até a página responder, como explica [Propagação](/pt-br/documentacao/plataforma/workloads/como-funciona/#propagacao).
- **API v3**: Custom Pages é o modelo da API v4 para páginas de erro. Uma Application que ainda roda na API v3 define as páginas de erro dela em [Error Responses](/pt-br/documentacao/plataforma/custom-pages/error-responses/), cujos campos correspondem aos campos de Custom Pages em [Interfaces](/pt-br/documentacao/plataforma/custom-pages/configuracoes/#interfaces).

---

## Limites padrão

Um conjunto de custom pages contém pelo menos uma página. A API e Azion Console recusam um conjunto vazio, cada um com a mensagem da coluna Ao ultrapassar o limite.

| Escopo | Limite | Ao ultrapassar o limite |
| --- | --- | --- |
| Páginas por conjunto de custom pages | No mínimo 1 | A API retorna `Ensure this field has at least 1 elements.` Azion CLI imprime essa mensagem dentro de `Error: Failed to create Custom Page: [...]`. Azion Console mostra `You must have at least one custom page code`. |

Mais quatro limites se aplicam: o `name` de um conjunto aceita de 1 a 255 caracteres, o `ttl` de uma página aceita de 0 a 31.536.000 segundos, o `uri` de uma página aceita de 1 a 250 caracteres e o `custom_status_code` de uma página aceita de 100 a 599. Para os campos a que esses limites se aplicam, consulte [Configurações de custom page](/pt-br/documentacao/plataforma/custom-pages/configuracoes/).
