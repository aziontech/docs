Este glossário define os termos que [Connectors](/pt-br/documentacao/plataforma/connectors/) usa com um significado próprio, junto com os termos de [Load Balancer](/pt-br/documentacao/plataforma/connectors/#load-balancer), [Origin Shield](/pt-br/documentacao/plataforma/connectors/#origin-shield) e [Live Ingest](/pt-br/documentacao/plataforma/connectors/#live-ingest), que atuam sobre um connector.

| Termo | Definição |
| --- | --- |
| connector | O objeto que guarda onde e como uma aplicação alcança uma [origem](https://www.azion.com/pt-br/learning/), o servidor que guarda o seu conteúdo, também chamado de backend. Várias aplicações podem reutilizar um connector, e cada uma envia requisições a ele por meio de uma regra com o behavior `Set Connector`. A API serve os connectors em `/v4/workspace/connectors`, [Connectors](/pt-br/documentacao/plataforma/connectors/) descreve o recurso e [Primeiros passos com Connectors](/pt-br/documentacao/plataforma/connectors/primeiros-passos/) cria um. |
| endereço | O endereço IPv4, o endereço IPv6 ou o hostname de um servidor ao qual um connector do tipo `http` se conecta, escrito sem protocolo e sem porta. Um connector contém um endereço, ou até 15 com Load Balancer ativado, e cada endereço tem seus próprios `http_port` e `https_port`. Um endereço também é chamado de endpoint, e [Configurações de connector](/pt-br/documentacao/plataforma/connectors/configuracoes/#enderecos) lista todos os campos de endereço. |
| função do servidor | A função de um endereço quando Load Balancer está ativado, **Server Role** no Azion Console e `server_role` na API: _Primary_ (`primary`, o padrão) ou _Backup_ (`backup`). Um endereço de backup fica em espera e recebe requisições somente quando todos os endereços primários falham. O método _IP Hash_ recusa endereços de backup com `28005`, e [Métodos de balanceamento](/pt-br/documentacao/plataforma/connectors/load-balancer/metodos-de-balanceamento/) descreve como a função muda a escolha. |
| header de IP real | O header que leva o endereço IP do cliente até a origem, `X-Real-IP` por padrão, nomeado em **Real IP Header** no Azion Console ou em `real_ip_header` na API. Renomeá-lo altera o header que a origem recebe, e **Real Port Header**, `real_port_header`, leva a porta do cliente em `X-Real-PORT`. Para adicionar o IP do cliente com uma regra em vez disso, consulte [Envie o IP do cliente para a origem em um header](/pt-br/documentacao/suporte/ip-original-header/). |
| header `Host` | O header `Host` que um connector do tipo `http` envia à origem, que a origem lê para selecionar o [host virtual](https://www.azion.com/pt-br/learning/) que serve o conteúdo. **Host** no Azion Console e `host` na API têm `${host}` como padrão, que envia o host que o cliente requisitou, e um valor literal é enviado como está. [Defina o Host header e o path prefix de uma origem](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/defina-o-host-header-e-o-path-prefix/) mostra quando enviar o nome da própria origem. |
| HMAC | A [autenticação de mensagens baseada em hash](https://www.azion.com/pt-br/learning/) que Origin Shield adiciona a toda requisição à origem, para que um bucket privado compatível com S3 possa atendê-la. Ela usa `aws4_hmac_sha256` e um conjunto de credenciais do seu provedor de object storage, **Region**, **Service**, **Access Key** e **Secret Key**, para todos os endereços. [Assine requisições de origem com HMAC](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/assine-requisicoes-de-origem-com-hmac/) a configura, e desativá-la remove as credenciais armazenadas. |
| lista Azion Origin Shield | A [network list](/pt-br/documentacao/plataforma/firewall/network-shield/network-lists/) chamada `Azion Origin Shield`, que guarda os prefixos IPv4 e IPv6 da infraestrutura de rede da Azion. O firewall da sua origem a usa como uma allowlist que aceita tráfego de entrada somente desses endereços, e você automatiza as atualizações dessa allowlist conforme a lista muda. Para o passo a passo, consulte [Libere os IPs da Azion na sua origem](/pt-br/documentacao/suporte/obter-ranges-ip-azion/). |
| Live Ingest | A ingestão de transmissões de vídeo ao vivo por meio de um connector do tipo `live_ingest`, na região de ingestão que você seleciona. Ela é cobrada em Data Ingestion, medida por GB. [Live Ingest](/pt-br/documentacao/plataforma/connectors/#live-ingest) a descreve, e [Ingestão e entrega](/pt-br/documentacao/plataforma/connectors/live-ingest/ingestao-e-entrega/) explica como ela funciona. |
| Load Balancer | [Balanceamento de carga](https://www.azion.com/pt-br/learning/) entre os endereços de um connector do tipo `http`, também chamado de pool. Ativar Load Balancer no connector, com o switch **Load Balancer** ou `attributes.modules.load_balancer.enabled`, aumenta o limite de endereços de 1 para 15. [Load Balancer](/pt-br/documentacao/plataforma/connectors/#load-balancer) o descreve, e [Primeiros passos com Load Balancer](/pt-br/documentacao/plataforma/connectors/load-balancer/primeiros-passos/) balanceia um primeiro connector. |
| método de balanceamento | A regra que Load Balancer segue para escolher um endereço para cada requisição, também chamada de steering policy. **Method** no Azion Console e `method` na API aceitam _Round Robin_ (`round_robin`, o padrão), _Least Connections_ (`least_conn`) ou _IP Hash_ (`ip_hash`). Cada data center balanceia por conta própria, então a divisão nunca é exata, e [Métodos de balanceamento](/pt-br/documentacao/plataforma/connectors/load-balancer/metodos-de-balanceamento/) descreve como cada método escolhe. |
| Origin IP ACL | O switch dentro do Origin Shield, **Origin IP ACL** no Azion Console e `attributes.modules.origin_shield.config.origin_ip_acl.enabled` na API, desativado por padrão. Ele permite que sua origem aceite somente os endereços publicados da Azion, a lista Azion Origin Shield, ao liberá-los no firewall da origem. [Origin IP ACL e HMAC](/pt-br/documentacao/plataforma/connectors/origin-shield/origin-ip-acl-e-hmac/) explica o mecanismo. |
| Origin Shield | A proteção da origem de um connector do tipo `http` por dois controles: Origin IP ACL, uma allowlist dos endereços da Azion, e a assinatura de requisições com HMAC. Você ativa [Origin Shield](/pt-br/documentacao/plataforma/connectors/#origin-shield) no connector com o switch **Origin Shield** ou `attributes.modules.origin_shield.enabled`, e ele é cobrado em Shielded Connectors. Uma camada de cache entre o cache da Azion e a origem, às vezes também chamada de origin shield, é [Tiered Cache](/pt-br/documentacao/plataforma/applications/cache/tiered-cache/). |
| peso | Um número de 1 a 100 que define a parcela de requisições que um endereço recebe quando Load Balancer está ativado, `1` por padrão. Pesos maiores destinam mais tráfego a um endereço, e você define o peso em **Weight** no Azion Console ou em `weight` na API. [Métodos de balanceamento](/pt-br/documentacao/plataforma/connectors/load-balancer/metodos-de-balanceamento/) descreve como o peso muda a escolha. |
| política de protocolo de transporte | A opção que define o protocolo que um connector do tipo `http` usa para alcançar seus endereços: **Transport Protocol Policy** no Azion Console, `transport_policy` na API. _Preserve_ (`preserve`, o padrão) mantém o esquema que o cliente usou, _Force HTTPS_ (`force_https`) se conecta somente por HTTPS e _Force HTTP_ (`force_http`) somente por HTTP. [Configurações de connector](/pt-br/documentacao/plataforma/connectors/configuracoes/#opcoes-de-conexao) a documenta com as outras opções de conexão. |
| política de resolução DNS | A opção que define qual versão de IP um connector do tipo `http` usa para alcançar seus endereços: **DNS Resolution Policy** no Azion Console, `dns_resolution` na API. `both`, o padrão e _IPv4 and IPv6_ no Azion Console, se conecta por qualquer uma das versões, e `force_ipv4`, _Force IPv4_, se conecta somente por IPv4. [Configurações de connector](/pt-br/documentacao/plataforma/connectors/configuracoes/#opcoes-de-conexao) a documenta com as outras opções de conexão. |
| prefixo de caminho | O caminho que um connector do tipo `http` coloca na frente do caminho requisitado: **Path** no Azion Console, `path_prefix` na API. Ele começa com `/` e é vazio por padrão, e com `/anything`, uma requisição para `/get` chega à origem como `/anything/get`. [Configurações de connector](/pt-br/documentacao/plataforma/connectors/configuracoes/#opcoes-de-conexao) lista os limites e os erros dele. |
| região de ingestão | A região em que um connector do tipo `live_ingest` faz a ingestão de uma transmissão de vídeo ao vivo: **Region** no Azion Console, `attributes.region` na API. Ela é obrigatória e aceita `us-east-1`, `us-east-2`, `br-east-1`, `br-east-2` ou `br-east-3`, então escolha a que minimiza a latência da sua transmissão. [Configurações de connector](/pt-br/documentacao/plataforma/connectors/configuracoes/#live-ingest) lista os erros que uma região ausente ou desconhecida retorna. |
| Set Connector | O behavior, _Set Connector_ no Azion Console e `set_connector` na API, que envia a um connector as requisições que correspondem a uma regra de aplicação. A regra indica o connector pelo ID dele em `attributes.value` e, quando várias regras correspondentes carregam o behavior, somente a última é executada. Até que uma regra indique um connector, uma aplicação não tem origem, e [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) documenta o behavior. |
| Single Origin | O nome que os planos dão a um connector com um endereço, que Hobby, Pro e Enterprise incluem. Ele também é o Origin Type de uma origem v3 com um endereço, documentado em [Origins](/pt-br/documentacao/plataforma/connectors/origins/). Um connector com mais de um endereço usa Load Balancer, como mostra [Limites de Connectors](/pt-br/documentacao/plataforma/connectors/limites/#connectors). |
| tipo de connector | O `type` de um connector: `http` para servidores de origem, `storage` para um bucket do Object Storage ou `live_ingest` para ingestão de vídeo ao vivo. Azion Console o oferece como os cards **Connector Type** _HTTP_, _Object Storage_ e _Live Ingest_, e o tipo define quais campos `attributes` aceita. [Configurações de connector](/pt-br/documentacao/plataforma/connectors/configuracoes/#geral) lista os campos de cada tipo. |
