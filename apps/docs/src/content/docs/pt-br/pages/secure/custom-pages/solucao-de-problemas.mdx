Esta página cobre dois sintomas de [Custom Pages](/pt-br/documentacao/plataforma/custom-pages/): um conjunto de custom pages recusado e uma página de erro que não chega ao cliente. Custom Pages é um recurso da plataforma que substitui por uma página sua a resposta de erro retornada por um Connector, e as páginas ficam em um conjunto de custom pages. Para saber onde Custom Pages age sobre uma requisição, consulte [Caminho da requisição](/pt-br/documentacao/plataforma/custom-pages/#caminho-da-requisicao). Uma recusa citada é a mensagem da API, a menos que a entrada nomeie outra fonte.

---

## Um conjunto de custom pages é recusado com Ensure this field has at least 1 elements

Criar um conjunto de custom pages falha com `Ensure this field has at least 1 elements.`, ou Azion Console se recusa a salvá-lo com `You must have at least one custom page code`. Azion CLI imprime a mensagem da API dentro de `Error: Failed to create Custom Page: [...]`.

Um conjunto de custom pages contém pelo menos uma página, e a requisição enviou `"pages": []`, como mostram os erros de [Configurações de custom page](/pt-br/documentacao/plataforma/custom-pages/configuracoes/#erros). No Azion Console, a tabela **Page Codes** não tinha nenhuma linha.

- **Adicione uma página a `pages`**: uma página substitui um status code de erro por um conteúdo de um Connector, como mostra o corpo em [Corpo da requisição](/pt-br/documentacao/plataforma/custom-pages/configuracoes/#corpo-da-requisicao).
- **Adicione um código de página no Azion Console**: a tabela **Page Codes** precisa de uma linha antes que você salve o conjunto.

Azion CLI então imprime `Created Custom Page with ID <custom-page-id>`.

---

## Uma página de erro não aparece

A resposta de erro do Connector chega ao cliente sem alteração, mesmo com uma página para o status code dela no conjunto de custom pages.

Um Workload usa um conjunto de custom pages somente depois que o deployment desse Workload define esse conjunto. Uma página também age apenas sobre o status code que lista, e uma mudança no deployment leva vários minutos para se propagar.

- **Defina o conjunto de custom pages no deployment**: no Azion Console, selecione-o no campo **Custom Page** de **Deployment Settings**, ou passe `--custom-page` para `azion create workload-deployment` ao criar o deployment. A Azion CLI não tem comando que atualiza um deployment. Para os passos, consulte [Personalize uma página de erro](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/personalizar-pagina-resposta-erro/#atribua-o-conjunto-no-deployment-do-workload).
- **Verifique o status code que o Connector retorna**: compare-o com o `code` de cada página do conjunto, como `"404"`.
- **Espere a mudança se propagar**: a Azion não garante uma duração, então repita a requisição até a página responder. Para mais informações, consulte [Propagação](/pt-br/documentacao/plataforma/workloads/como-funciona/#propagacao).

O cliente então recebe o conteúdo da página no lugar da resposta, com o `custom_status_code` da página quando definido, e sem header `Location`.
