Um [Connector](/pt-br/documentacao/plataforma/connectors/) encaminha requisições das suas [Applications](/pt-br/documentacao/plataforma/applications/) à origem que guarda o seu conteúdo, e guarda onde esse conteúdo está e como alcançá-lo. O tipo dele, `http`, `storage` ou `live_ingest`, define quais configurações o Connector carrega. Azion Console e Azion API escrevem as mesmas configurações, então cada tabela desta página nomeia o rótulo do Console ao lado do campo da API. Os campos da API aparecem como caminhos dentro do corpo da requisição, como `attributes.connection_options.host`.

---

## Objeto Connector

O corpo JSON a seguir é um Connector completo do tipo `http` com um endereço. Todas as opções de conexão estão no padrão, exceto `transport_policy` e `host`, e [Load Balancer](/pt-br/documentacao/plataforma/connectors/load-balancer/) e [Origin Shield](/pt-br/documentacao/plataforma/connectors/origin-shield/) estão desativados:

```json
{
  "name": "my-connector",
  "active": true,
  "type": "http",
  "attributes": {
    "addresses": [
      {
        "address": "origin.example.com",
        "http_port": 80,
        "https_port": 443,
        "active": true
      }
    ],
    "connection_options": {
      "dns_resolution": "both",
      "transport_policy": "force_https",
      "http_version_policy": "http1_1",
      "host": "origin.example.com",
      "path_prefix": "",
      "following_redirect": false,
      "real_ip_header": "X-Real-IP",
      "real_port_header": "X-Real-PORT"
    },
    "modules": {
      "load_balancer": { "enabled": false },
      "origin_shield": { "enabled": false }
    }
  }
}
```

O caminho da API é `/v4/workspace/connectors`, e o de um Connector é `/v4/workspace/connectors/{connector_id}`. Um `POST` que cria um Connector responde `202` com `"state": "pending"` e o Connector completo, padrões incluídos.

Um `PATCH` mescla as chaves que você envia no Connector armazenado, exceto `addresses`, que ele substitui. Um `PUT` substitui o Connector: um `PUT` sem `connection_options` redefine cada opção de conexão para o seu padrão. Para cada operação, consulte [Azion API](https://api.azion.com/).

Azion CLI recebe o mesmo corpo JSON de um arquivo: `azion create connector --type http --file my-connector.json` imprime `Created Connector with ID <connector-id>`. No Terraform, o recurso `azion_connector` gerencia um Connector, como mostra [Recursos de Connectors](/pt-br/documentacao/devtools/terraform/connectors/). No `azion.config.js`, `attributes.modules.loadBalancer` e `attributes.modules.originShield` declaram Load Balancer e Origin Shield, como lista [Modules do connector](/pt-br/documentacao/devtools/cli/azion-config-js/#modules-do-connector).

Uma alteração em um Connector entra em vigor sem um novo deployment. Ela chega à infraestrutura distribuída da Azion em vários minutos, e os data centers a aplicam em momentos diferentes. Uma regra de uma Application com o behavior _Set Connector_ define o Connector que recebe as requisições da Application. Para escrever essa regra, consulte [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/).

## Geral

Os campos gerais nomeiam o Connector e definem o seu tipo. A API exige `name`, `type` e `attributes` em todo Connector.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| **Name** | `name` | string | nenhum | Obrigatório. 1 a 255 caracteres. Um nome que outro Connector já usa é recusado com `28002`. |
| **Connector Type**, com os cards _HTTP_, _Object Storage_ e _Live Ingest_ | `type` | enum | nenhum | Obrigatório. `http`, `storage` ou `live_ingest`. Define quais campos `attributes` aceita. Fixo na criação: um `PATCH` que o altera é recusado com `28003`. |
| **Active**, na seção **Status** | `active` | boolean | `true` | `true` ou `false`. Um Connector que uma regra de uma Application define não pode mudar para `false`, e a requisição é recusada com `28008`. |

Um Connector do tipo `http` aceita os campos de Endereços, Opções de conexão, Load Balancer e Origin Shield. Um Connector do tipo `storage` aceita os campos de Storage, e um Connector do tipo `live_ingest` aceita o campo de Live Ingest.

## Endereços

Os endereços de um Connector do tipo `http` são os servidores de origem aos quais ele se conecta. Cada item de `attributes.addresses` contém um endereço com suas portas, seu estado e sua função no balanceamento de carga. A seção **Address Management** do Console os escreve.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| **Address** | `attributes.addresses[].address` | string | nenhum | Obrigatório. Um endereço IPv4, um endereço IPv6 ou um hostname, de até 255 caracteres, sem protocolo e sem porta. |
| **HTTP Port** | `attributes.addresses[].http_port` | integer | `80` | 1 a 65535. A porta das conexões HTTP com este endereço. |
| **HTTPS Port** | `attributes.addresses[].https_port` | integer | `443` | 1 a 65535. A porta das conexões HTTPS com este endereço. |
| **Active** | `attributes.addresses[].active` | boolean | `true` | `false` tira o endereço da rotação. |
| **Server Role**, com _Primary_ e _Backup_ | `attributes.addresses[].modules.load_balancer.server_role` | enum | `primary` | `primary` ou `backup`. A função do endereço no balanceamento de carga. |
| **Weight** | `attributes.addresses[].modules.load_balancer.weight` | integer | `1` | 1 a 100. Pesos maiores destinam mais tráfego a este endereço. |

Um Connector contém um endereço, a menos que Load Balancer esteja ativado. Dois endereços com Load Balancer desativado são recusados com `28004`, na criação e quando você desativa Load Balancer. Com Load Balancer ativado, um Connector contém até 15 endereços, e um 16º é recusado com `28011`. Para todos os limites em um só lugar, consulte [Limites de Connectors](/pt-br/documentacao/plataforma/connectors/limites/).

Um endereço com protocolo ou porta, como `https://origin.example.com` ou `origin.example.com:443`, é recusado com `28001`. Azion Console mostra `Address must be a valid IPv4, IPv6, or hostname, without protocol or port.` Defina as portas em **HTTP Port** e **HTTPS Port**, e um caminho em `path_prefix`.

Um endereço retorna `"modules": null` na leitura até que você envie os campos de Load Balancer dele. Um endereço enviado apenas com `weight` retorna `server_role` como `primary`, e um enviado apenas com `server_role` retorna `weight` como `1`. Um endereço `backup` é recusado no método _IP Hash_ com `28005`. Azion Console mostra `Backup role is not available when the load balancing method is IP Hash.` e `Backup role is not supported with IP Hash. Change this address to Primary or select another method.` Um peso fora do intervalo mostra `Weight must be between 1 and 100` no Console.

Um endereço sem `modules` não conta como `primary` ao lado de um endereço `backup`. Uma lista assim é recusada com `28006`, então envie `server_role` como `primary` no endereço que deve continuar primário.

Um `PATCH` que envia `attributes.addresses` substitui a lista armazenada pela lista que você envia. Um endereço enviado sem as portas ou sem `modules` volta aos padrões: `http_port` `80`, `https_port` `443` e `"modules": null`. Para alterar um endereço, envie todos os endereços com todos os campos deles.

## Opções de conexão

As opções de conexão de um Connector do tipo `http` definem como ele se comunica com seus endereços. Elas cobrem o header `Host`, o caminho, o protocolo, a versão de IP e os headers que levam o endereço do cliente. Elas ficam em `attributes.connection_options`.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| **Host** | `attributes.connection_options.host` | string | `${host}` | 1 a 255 caracteres. O header `Host` e o valor de Server Name Indication (SNI) enviados à origem. `${host}` envia o host que o cliente requisitou, e um valor literal é enviado como está. Um valor vazio é recusado com `10018`, e um valor com protocolo, como `https://origin.example.com`, com `28010`. |
| **Path** | `attributes.connection_options.path_prefix` | string | `""`, sem prefixo | Até 255 caracteres, começando com `/`. Adicionado antes do caminho da requisição. Um valor sem a barra inicial é recusado com `28009`. |
| **Transport Protocol Policy**, com _Preserve_, _Force HTTPS_ e _Force HTTP_ | `attributes.connection_options.transport_policy` | enum | `preserve` | `preserve` mantém o esquema que o cliente usou. `force_https` se conecta à origem apenas por HTTPS, e `force_http` apenas por HTTP. |
| **DNS Resolution Policy**, com _IPv4 and IPv6_, _Force IPv4_ e _Force IPv6_ | `attributes.connection_options.dns_resolution` | enum | `both` | `both` se conecta por IPv4 ou IPv6. `force_ipv4` se conecta apenas por IPv4, e `force_ipv6` apenas por IPv6. |
| nenhum | `attributes.connection_options.http_version_policy` | enum | `http1_1` | A versão de HTTP até a origem. `http1_1`, HTTP/1.1, é o único valor. |
| **Following Redirect** | `attributes.connection_options.following_redirect` | boolean | `false` | Se o Connector segue os redirecionamentos HTTP que a origem retorna. |
| **Real IP Header** | `attributes.connection_options.real_ip_header` | string | `X-Real-IP` | O nome do header que leva o endereço IP do cliente até a origem. Um valor vazio é recusado com `10018`, e um valor com mais de 100 caracteres com `10046`. |
| **Real Port Header** | `attributes.connection_options.real_port_header` | string | `X-Real-PORT` | O nome do header que leva a porta do cliente até a origem. Um valor vazio é recusado com `10018`, e um valor com mais de 100 caracteres com `10046`. |

O valor de `host` decide qual nome a origem vê. Por exemplo, com o padrão `${host}`, um cliente que requisita `www.example.com` faz o Connector enviar `Host: www.example.com`. Com `"host": "origin.example.com"`, o Connector envia `Host: origin.example.com` em toda requisição. Uma origem que roteia requisições por nome pode não responder ao host do cliente, então envie o nome da própria origem como valor literal.

Azion Console valida **Host** com `Host must be a valid hostname, IP address, or variable.`

Por HTTPS, o Connector também envia o valor de `host` como valor de SNI, o nome do servidor do seu handshake de Transport Layer Security (TLS). Com o padrão `${host}`, o nome do servidor e o header `Host` levam o hostname que o cliente requisitou. Com um valor literal como `origin.example.com`, os dois levam esse valor. O campo `host` define os dois: um Connector não tem um campo separado para o nome do servidor.

O valor de `path_prefix` vai na frente do caminho que o cliente requisitou. Com `/anything`, uma requisição para `/get` chega à origem como `/anything/get`. Para **Path**, Azion Console diz "Use '/' for the root path." e valida o campo com `Path must start with a forward slash (/)`.

Por padrão, a origem recebe o endereço IP do cliente em `X-Real-IP` e a porta do cliente em `X-Real-PORT`. Renomear `real_ip_header` altera o nome do header: com `X-Client-Real-IP`, a origem recebe `X-Client-Real-IP` e nenhum `X-Real-IP`. Algumas origens descartam `X-Real-IP` por conta própria. Para adicionar o IP do cliente a um header com uma regra, consulte [Envie o IP do cliente para a origem em um header](/pt-br/documentacao/suporte/ip-original-header/).

## Load Balancer

Load Balancer distribui requisições entre os endereços de um Connector do tipo `http`. No Console, o switch **Load Balancer** da seção **Modules** o ativa, e os campos **Method**, **Max Retries**, **Connection Timeout** e **Read/Write Timeout** aparecem. Na API, os campos ficam em `attributes.modules.load_balancer`.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| **Load Balancer** | `attributes.modules.load_balancer.enabled` | boolean | `false` | `true` ativa Load Balancer no Connector e permite até 15 endereços. |
| **Method**, com _Round Robin_, _Least Connections_ e _IP Hash_ | `attributes.modules.load_balancer.config.method` | enum | `round_robin` | `round_robin`, `least_conn` ou `ip_hash`. `ip_hash` recusa endereços `backup`. |
| **Max Retries** | `attributes.modules.load_balancer.config.max_retries` | integer | `0` na API, `3` no formulário do Console para um novo Connector | 0 a 20. O número de novas tentativas em uma falha de conexão. |
| **Connection Timeout** | `attributes.modules.load_balancer.config.connection_timeout` | integer, segundos | `60` segundos na API, `30` segundos no formulário do Console para um novo Connector | 1 a 300 segundos. O tempo máximo de espera pela conexão com a origem. |
| **Read/Write Timeout** | `attributes.modules.load_balancer.config.read_write_timeout` | integer, segundos | `120` segundos na API, `60` segundos no formulário do Console para um novo Connector | 1 a 600 segundos. O tempo máximo de espera para que dados sejam lidos ou escritos na conexão aberta com a origem. |

Com `enabled` definido como `true`, uma requisição sem `config`, ou com `null`, é recusada com `28014`, assim como um `PATCH` com um `config` vazio. Uma chave que você deixa de fora recebe o padrão da API, e em um `POST` um `config` vazio recebe todos os padrões. Por exemplo, `"config": {"method": "round_robin"}` retorna na leitura com `max_retries` `0`, `connection_timeout` `60` e `read_write_timeout` `120`. No Azion Console, o formulário de um novo Connector preenche _Round Robin_, `3`, `30` e `60` em vez disso quando você ativa **Load Balancer**.

As novas tentativas e os dois timeouts existem apenas com Load Balancer ativado. Um Connector sem Load Balancer não tem timeout configurável. Para os timeouts que se aplicam nesse caso, consulte [Como Connectors funciona](/pt-br/documentacao/plataforma/connectors/como-funciona/). Para saber como cada método escolhe um endereço, consulte [Métodos de balanceamento](/pt-br/documentacao/plataforma/connectors/load-balancer/metodos-de-balanceamento/).

## Origin Shield

Origin Shield permite que a sua origem aceite somente as requisições que um Connector do tipo `http` envia, com duas Features. Origin IP ACL (access control list) dá à sua conta a lista `Azion Origin Shield` para o firewall da sua origem liberar, e hash-based message authentication code (HMAC) assina cada requisição que o Connector envia à origem. Na API, os campos ficam em `attributes.modules.origin_shield`.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| **Origin Shield** | `attributes.modules.origin_shield.enabled` | boolean | `false` | `true` ativa Origin Shield no Connector. |
| **Origin IP ACL** | `attributes.modules.origin_shield.config.origin_ip_acl.enabled` | boolean | `false` | `true` ativa Origin IP ACL. |
| **HMAC** | `attributes.modules.origin_shield.config.hmac.enabled` | boolean | `false` | `true` assina cada requisição à origem com as credenciais HMAC. |
| **Type**, somente leitura | `attributes.modules.origin_shield.config.hmac.config.type` | enum | `aws4_hmac_sha256` | O esquema de assinatura. |
| **Region** | `attributes.modules.origin_shield.config.hmac.config.attributes.region` | string | nenhum | Obrigatório. 1 a 255 caracteres. Uma região que o provedor de object storage suporta. |
| **Service** | `attributes.modules.origin_shield.config.hmac.config.attributes.service` | string | `s3` | 1 a 255 caracteres. Obrigatório no Console. |
| **Access Key** | `attributes.modules.origin_shield.config.hmac.config.attributes.access_key` | string | nenhum | Obrigatório. 1 a 255 caracteres. |
| **Secret Key** | `attributes.modules.origin_shield.config.hmac.config.attributes.secret_key` | string | nenhum | Obrigatório. 1 a 255 caracteres. Azion Console o exibe como um campo de senha. |

Com `enabled` definido como `true`, `config` deve conter pelo menos uma chave, como `origin_ip_acl`. Com `hmac.enabled` definido como `true`, `hmac.config` deve estar presente. Caso contrário, a API recusa a requisição com `28014`. Desativar HMAC remove as credenciais armazenadas, então você as informa de novo quando o ativa outra vez.

A API retorna a `access_key` e a `secret_key` do HMAC em texto simples, exatamente como você as enviou. Três respostas trazem os dois valores:

- A resposta do `POST` que cria o Connector.
- A resposta de um `GET` do Connector por ID.
- A listagem que `GET /v4/workspace/connectors` retorna.

As credenciais HMAC pertencem a uma conta no provedor de object storage que guarda o conteúdo privado. Por exemplo, um Connector que lê um bucket privado pelo endpoint S3 `s3.us-east-005.azionstorage.net` envia `region` `us-east-005`, `service` `s3` e uma credencial com escopo nesse bucket. Com HMAC desativado, esse endpoint responde `401`. Para saber como Origin IP ACL e HMAC protegem a origem, consulte [Origin IP ACL e HMAC](/pt-br/documentacao/plataforma/connectors/origin-shield/origin-ip-acl-e-hmac/).

## Storage

Um Connector do tipo `storage` lê de um [bucket de Object Storage](/pt-br/documentacao/plataforma/object-storage/buckets-e-objetos/) da sua conta. Ele carrega dois atributos e nenhum endereço ou opção de conexão. Uma chave `modules` enviada com este tipo é aceita e não é armazenada, então Origin Shield não se aplica.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| Seletor de bucket, _Select a Bucket_, com o botão **Create Object Storage** | `attributes.bucket` | string | nenhum | Obrigatório. Até 255 caracteres. O nome de um bucket existente cujo acesso de workloads é somente leitura ou leitura e escrita. Qualquer outro bucket é recusado com `28007`. |
| **Prefix** | `attributes.prefix` | string | `null` quando omitido | Opcional na API, obrigatório no Console. 1 a 255 caracteres, como `images/`. Filtra os objetos dentro do bucket. Uma string vazia é recusada com `10018`. |

O seletor de bucket lista os buckets da sua conta, e **Create Object Storage** cria um bucket sem sair do formulário. Na API, deixe `prefix` de fora para armazenar `null`, e nunca o envie vazio. Por exemplo, este corpo cria um Connector do tipo `storage` para os objetos em `images/`:

```json
{
  "name": "my-connector",
  "type": "storage",
  "attributes": { "bucket": "my-bucket", "prefix": "images/" }
}
```

A barra inicial e a barra final de `prefix` são opcionais, porque o Connector junta `prefix` e o caminho da requisição com uma única barra. `images`, `images/`, `/images` e `/images/` são equivalentes: com qualquer um deles, uma requisição para `/logo.png` recebe o objeto `images/logo.png`. Com `images/icons`, a mesma requisição recebe o objeto `images/icons/logo.png`. A API armazena o valor como você o enviou e não o normaliza.

O caminho da requisição leva apenas a parte da chave do objeto que vem depois do prefixo. Uma requisição cujo caminho repete o prefixo, como `/images/logo.png` com o prefixo `images`, recebe `404` com um corpo XML `NoSuchKey`.

## Live Ingest

Um Connector do tipo `live_ingest` pertence a [Live Ingest](/pt-br/documentacao/plataforma/connectors/live-ingest/). Ele carrega um atributo, `region`, e nenhum endereço ou opção de conexão.

| Console | Campo da API | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| **Region** | `attributes.region` | enum | nenhum | Obrigatório. `us-east-1`, `us-east-2`, `br-east-1`, `br-east-2` ou `br-east-3`. |

Uma requisição sem `region` é recusada com `10059`, e um valor que a API não aceita com `10039`. Uma chave `bucket`, `addresses` ou `modules` enviada com este tipo é aceita e não é armazenada, então Load Balancer e Origin Shield não se aplicam. Por exemplo, este corpo cria um Connector do tipo `live_ingest` em `us-east-1`:

```json
{
  "name": "my-connector",
  "type": "live_ingest",
  "attributes": { "region": "us-east-1" }
}
```

Para saber como Live Ingest funciona, consulte [Ingestão e entrega](/pt-br/documentacao/plataforma/connectors/live-ingest/ingestao-e-entrega/).

## Erros

A API recusa cada requisição desta tabela com HTTP `400` e não cria nem altera nada. O código, o título e a mensagem ficam no array `errors` da resposta, com um `source.pointer` para o campo.

| Código | Título | Mensagem | Causa | O que fazer |
| --- | --- | --- | --- | --- |
| `28001` | `Invalid Address Format For Connector` | `Invalid address format. Must be a valid IPv4, IPv6, or CNAME.` | Um endereço carrega um protocolo ou uma porta, como `https://origin.example.com` ou `origin.example.com:443`. | Envie apenas o hostname ou o endereço IP, e defina as portas em `http_port` e `https_port`. |
| `28002` | `Connector Already Exists` | `A connector with this name already exists for this Workspace.` | Outro Connector já usa o `name`. | Envie um nome que nenhum outro Connector usa. |
| `28003` | `Connector Type Cannot Be Changed` | `Connector type cannot be changed after creation.` | Um `PATCH` envia um `type` diferente do armazenado. | Crie um Connector do tipo de que você precisa e defina-o nas suas regras. |
| `28004` | `Enable Load Balancer Module For Multiple Addresses` | `To use more than one address, you must enable the Load Balancer module.` | O Connector tem dois ou mais endereços e Load Balancer está desativado, na criação ou quando você desativa Load Balancer. | Ative Load Balancer no Connector, ou mantenha um endereço. |
| `28011` | `Maximum Addresses With Load Balancer Module Enabled` | `When the Load Balancer module is enabled, you can use up to 15 addresses.` | O Connector tem 16 ou mais endereços. | Mantenha 15 endereços ou menos. |
| `28012` | `Active Address Required` | `At least one active address is required.` | Nenhum endereço tem `active` `true`, em um `POST` ou em um `PATCH`. | Envie pelo menos um endereço com `active` `true`. |
| `28006` | `Active Primary Address Required` | `At least one address with server_role set to 'primary' and marked as active is required.` | Os endereços incluem um `backup`, e nenhum endereço é um `primary` ativo. Um endereço sem `modules`, ou um `primary` com `active` `false`, não conta. | Envie `server_role` como `primary` em pelo menos um endereço com `active` `true`. |
| `28005` | `Backup Addresses Not Enabled For IP Hash` | `Backup addresses are not allowed when using 'ip_hash' as load balance method.` | Um endereço tem `server_role` `backup` e o método é `ip_hash`, na criação ou em um `PATCH` que altera o método. | Defina o endereço como `primary`, ou escolha `round_robin` ou `least_conn`. |
| `28014` | `Missing Module Configuration` | `Module configuration must be provided when 'enabled' is true.` | Load Balancer tem `enabled` `true` sem `config` ou com `null`, ou um `PATCH` envia um `config` vazio. Origin Shield tem `enabled` `true` sem `config`, com `null` ou com um `config` vazio. HMAC está ativado sem `hmac.config`. | Envie `config` com pelo menos uma chave, como `method` para Load Balancer, ou `hmac.config` com as credenciais. |
| `28009` | `Invalid Path Format For Connector` | `Invalid path format. Must be a valid path.` | `path_prefix` não começa com `/`. | Comece o valor com `/`, como `/anything`. |
| `28010` | `Invalid Host Format For Connector` | `Invalid host format. Must be a valid host.` | `host` não é um host válido, como um valor com protocolo. | Envie um hostname, um endereço IP ou `${host}`. |
| `28007` | `Bucket Not Accessible By Workloads` | `This bucket does not exist or its workloads access is restricted. To use it in a connector, set its workloads access to read only or read write.` | `bucket` nomeia um bucket que não existe na conta, ou um bucket cujo acesso de workloads é restrito. | Envie o nome de um bucket existente e defina o acesso de workloads dele como somente leitura ou leitura e escrita. |
| `28000` | `Cannot Delete Referenced Connector` | `Cannot delete an Connector referenced by another resource. References: EdgeApplicationRuleEngine - id: <rule-id>` | Um `DELETE` tem como alvo um Connector que uma regra de uma Application ainda define. A mensagem informa a regra. | Defina outro Connector na regra, ou exclua a regra, e então repita o `DELETE`. |
| `28008` | `Cannot Deactivate Referenced Connector` | `Cannot deactivate an Connector referenced by another resource. References: EdgeApplicationRuleEngine - id: <rule-id>` | Um `PATCH` envia `active` `false` para um Connector que uma regra de uma Application ainda define. A mensagem informa a regra. | Defina outro Connector na regra, ou exclua a regra, e então repita o `PATCH`. |
| `10018` | `Blank Field` | `This field may not be blank.` | `name`, `host`, `prefix`, `real_ip_header`, `real_port_header` ou a `region` do HMAC é uma string vazia. | Envie um valor, ou deixe `prefix` de fora. |
| `10059` | `Required Field` | `This field is required.` | Um campo obrigatório está ausente, como `name`, `type`, os endereços de um Connector do tipo `http`, `bucket`, `region` ou uma credencial HMAC. | Envie o campo que `source.pointer` indica. |
| `10039` | `Invalid Choice` | `"http2" is not a valid choice.` | Um campo enum contém um valor fora da sua lista. A mensagem cita o valor, como `"http2"` para `http_version_policy`. | Envie um valor da lista do campo. |
| `10050` | `Min Value` | `Ensure this value is greater than or equal to 1.` | Um número é menor que o seu mínimo. A mensagem o informa: `1` para as portas, `weight`, `connection_timeout` e `read_write_timeout`, e `0` para `max_retries`. | Envie um valor dentro do intervalo do campo. |
| `10068` | `Max Value` | `Ensure this value is less than or equal to 100.` | Um número é maior que o seu máximo. | `10046` | `Max Length` | `Ensure this field has no more than 255 characters.` | Uma string é maior que o seu máximo. A mensagem o informa: `100` para `real_ip_header` e `real_port_header`, e `255` para todos os outros campos de string. | Encurte o valor para o máximo de caracteres ou menos. |
