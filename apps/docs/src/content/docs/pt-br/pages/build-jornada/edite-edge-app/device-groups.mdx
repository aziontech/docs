Você pode criar um [device group](/pt-br/documentacao/plataforma/applications/device-groups/) para uma [aplicação](/pt-br/documentacao/plataforma/applications/) no Azion Console e, em seguida, confirmá-lo com uma regra que marca as respostas para esse grupo. Um device group associa um nome a uma expressão regular, e a aplicação compara a expressão com o header `User-Agent` de cada requisição.

Para manter uma cópia em cache separada de cada objeto para cada device group, defina a variação em um cache setting em vez disso. Para mais informações, consulte [Configurações do Application Accelerator](/pt-br/documentacao/plataforma/applications/application-accelerator/configuracoes/#cache-variation).

---

## Pré-requisitos

- Uma aplicação servida por um [workload](/pt-br/documentacao/plataforma/workloads/). Para criar os dois, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
- Application Accelerator ativado na aplicação. A regra desta página lê a variável `${device_group}`, que exige esse Produto. Para ativá-lo, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/#produtos).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Crie o device group

O device group desta seção se chama `Mobile`. A expressão dele corresponde a qualquer header `User-Agent` que contenha `Mobile`, `iPhone` ou `Android`, porque uma correspondência em parte do header é suficiente. Cada aplicação mantém os próprios device groups, na aba **Device Groups** dela.

Para criar o device group no Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** e selecione a aplicação.

  </DocStep>
  <DocStep title="Selecione a aba Device Groups" />
  <DocStep title="Inicie um novo device group" />
  <DocStep title="Nomeie o device group">

  Em **Name**, insira `Mobile`. O nome aceita apenas letras e números, sem espaços. Para qualquer outro caractere, o Console mostra `Name must be alphanumeric`.

  </DocStep>
  <DocStep title="Insira a expressão regular">

  Na seção **Match to User-Agent**, insira `(Mobile|iPhone|Android)` como a **Regular Expression**.

  </DocStep>
  <DocStep title="Salve o device group" />
</DocSteps>

Azion Console mostra `Device Group successfully created`, e o grupo aparece na aba **Device Groups**. Para cada campo de um device group e as mensagens que o formulário mostra, consulte [Device Groups](/pt-br/documentacao/plataforma/applications/device-groups/#campos-do-device-group).

## Use o device group como critério de uma regra

Uma regra que lê `${device_group}` aplica os behaviors dela apenas às requisições de um device group. A regra desta seção roda na Response Phase. Ela adiciona o header `Device-Is: Mobile device` a cada resposta enviada ao grupo `Mobile`, para que uma resposta mostre se o grupo correspondeu à requisição dela. A regra é uma verificação: depois que o grupo é confirmado, você altera o behavior dela ou a desativa.

Para criar a regra no Azion Console:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** e selecione a aplicação.

  </DocStep>
  <DocStep title="Selecione a aba Rules Engine" />
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Em **General**, insira `Device Group: Mobile` como o **Name**.

  </DocStep>
  <DocStep title="Selecione a fase de resposta">

  Em **Phase**, selecione _Response Phase_. A fase de uma regra não pode mudar depois que você cria a regra.

  </DocStep>
  <DocStep title="Defina o critério">

  Em **Criteria**, selecione a variável `${device_group}` e o operador `is_equal`, e insira `Mobile` como o argumento.

  </DocStep>
  <DocStep title="Adicione o behavior de header de resposta">

  Em **Behaviors**, selecione o behavior que adiciona um header à resposta. Na API, o tipo dele é `add_response_header`.

  </DocStep>
  <DocStep title="Insira o header">

  Insira `Device-Is: Mobile device` como o argumento. O Console recusa um argumento que não está no formato `header-name: value`.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A regra aparece na aba **Rules Engine**, sob o título **Response**. Para todas as variáveis, operadores e behaviors que uma regra aceita, consulte [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/).

## Confirme o device group

A regra que lê `${device_group}` marca cada resposta para o grupo `Mobile`, então uma requisição confirma se o grupo corresponde a um dispositivo. [Envie a requisição para a aplicação](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/) a partir de um dispositivo que corresponda à expressão. Um navegador em um dispositivo móvel funciona, assim como qualquer cliente que defina o header `User-Agent` com um valor correspondente, como `iPhone Android`.

A resposta carrega o header que a regra adiciona, `device-is: Mobile device`. Uma requisição cujo header `User-Agent` não corresponde à expressão não recebe esse header.

Uma regra nova pode levar alguns minutos para entrar em vigor e, até lá, nenhuma resposta carrega o header. Envie a requisição de novo antes de alterar a regra ou a expressão.

Quando o header aparece, o device group está confirmado. Substitua o behavior da regra por aquele a que o grupo se destina, ou desative **Active** na seção **Status** da regra para que ela pare de rodar. Para mais informações, consulte [Crie uma regra de aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/trabalhar-com-rules-engine/).
