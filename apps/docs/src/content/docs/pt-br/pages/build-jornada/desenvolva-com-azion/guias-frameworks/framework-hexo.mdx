Você pode colocar um site Hexo na Azion de três formas: fazer o deploy do template do Hexo pelo Azion Console, importar o seu próprio repositório do GitHub ou executar a [Azion CLI](/pt-br/documentacao/devtools/cli/). Cada rota deixa o site no ar em um domínio da Azion.

A Azion serve um site Hexo como uma aplicação estática. O build do Hexo gera o site em `./public`, e o deploy copia essa pasta para um bucket de storage por trás de uma [aplicação](/pt-br/documentacao/plataforma/applications/). Para ver em quais outros frameworks a Azion faz o build, consulte [Compatibilidade com web frameworks](/pt-br/documentacao/devtools/runtime/frameworks/compatibilidade-frameworks/).

---

- Uma conta do GitHub. O formulário do template a conecta durante o deploy quando pede uma.

## Templates do Hexo

A rota do Console faz o deploy de um template, um projeto Hexo pronto para o build. Ela parte deste template:

| Template | Uso |
| --- | --- |
| [Hexo Boilerplate](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/hexo-boilerplate/) | Aplicação de página única |

O Hexo Boilerplate tem um guia próprio, com link na tabela. Para o catálogo de templates, consulte [Azion Marketplace](/pt-br/documentacao/plataforma/marketplace/). Na rota da CLI, o seletor de templates do `azion init` para o preset do Hexo lista o Hexo Boilerplate como única opção.

## Fazer o deploy do site

Toda rota faz o build do projeto Hexo e cria os recursos da Azion que o servem. Siga o painel da sua rota:

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para fazer o deploy do template do Hexo pelo Azion Console:

<DocSteps>
  <DocStep title="Abra os templates">

  Acesse [Azion Console](https://console.azion.com/) > **Create** > **Templates**.

  </DocStep>
  <DocStep title="Encontre o template do Hexo">

  Em **Search by name, framework, or keyword**, digite `Hexo`.

  </DocStep>
  <DocStep title="Selecione Hexo Boilerplate" />
  <DocStep title="Conecte sua conta do GitHub">

  Se o formulário mostrar **GitHub Connection**, selecione **Connect with GitHub** e instale o [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/).

  </DocStep>
  <DocStep title="Selecione um Git Scope">

  Em **Git Scope**, selecione o escopo do template.

  </DocStep>
  <DocStep title="Preencha as configurações que o template pede" />
  <DocStep title="Selecione Deploy" />
</DocSteps>

Enquanto o projeto passa pelo build, a página de deploy mostra o **Deploy Log**. Um deploy bem-sucedido mostra **Successfully created!**, a URL do domínio e um botão **Manage** que abre a aplicação.

</Fragment>

<Fragment slot="panel.github">

Para fazer o deploy de um projeto Hexo a partir do seu repositório do GitHub:

<DocSteps>
  <DocStep title="Abra Import from GitHub">

  Acesse [Azion Console](https://console.azion.com/) > **Create** > **Import from GitHub**.

  </DocStep>
  <DocStep title="Selecione o card de importação">

  Selecione o card na aba **Import from GitHub**. A página **Import from GitHub** abre.

  </DocStep>
  <DocStep title="Conecte sua conta do GitHub">

  Se nenhuma conta do GitHub estiver conectada, em **GitHub Connection**, selecione **Connect with GitHub**.

  </DocStep>
  <DocStep title="Selecione o repositório">

  Selecione um **Git Scope** e, em seguida, o **Repository** com o projeto Hexo.

  </DocStep>
  <DocStep title="Dê um nome à aplicação">

  Em **General**, digite um **Application Name**. O nome do repositório preenche o campo primeiro, e o bucket de storage e a [function](/pt-br/documentacao/plataforma/functions/) recebem o mesmo nome.

  </DocStep>
  <DocStep title="Selecione o preset do Hexo">

  Defina **Preset** como _Hexo_.

  </DocStep>
  <DocStep title="Defina o diretório raiz">

  Em **Root Directory**, mantenha `/` se o projeto Hexo estiver na raiz do repositório.

  </DocStep>
  <DocStep title="Digite o comando de instalação">

  Em **Install Command**, digite `npm install`.

  </DocStep>
  <DocStep title="Selecione Deploy" />
</DocSteps>

A página de deploy abre. O título dela é `Deploy:` seguido do nome da aplicação, e ela mostra o **Deploy Log** enquanto o projeto passa pelo build. Um deploy bem-sucedido mostra **Successfully created!** e a URL do domínio.

Para a seção **Variables** e os outros campos do formulário, consulte [Importe um projeto do GitHub](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/importar-um-projeto-existente-do-github/).

</Fragment>

<Fragment slot="panel.cli">

Para criar o projeto, execute `azion init` com um nome de projeto. No seletor de presets, selecione _Hexo_; no seletor de templates, selecione _Hexo Boilerplate_:

```bash
azion init --name my-site --auto -y
```

Com `-y`, o comando instala as dependências. Com `--auto`, ele não pergunta se deve iniciar um servidor de desenvolvimento local nem se deve fazer o deploy. Para as perguntas que ele faz sem essas opções, consulte [Azion CLI init](/pt-br/documentacao/devtools/cli/init/). O comando exibe:

O projeto fica na pasta `my-site`. O `azion.config.cjs` dele define o preset `hexo` e envia `./public` para um bucket de storage com acesso somente de leitura para os workloads. Para as configurações desse arquivo, consulte [azion.config.js](/pt-br/documentacao/devtools/cli/azion-config-js/).

Para fazer o build do site, vá para a pasta do projeto e execute `azion build`:

```bash
cd my-site
azion build
```

Para fazer o deploy do site, execute `azion deploy` na pasta do projeto:

```bash
azion deploy
```

O deploy envia o projeto e abre a página do Azion Console que o acompanha. Se o navegador não abrir, use a URL dessa página que aparece na saída. Ao final, o comando exibe a URL do domínio do site. Para a saída completa e as flags de deploy, consulte [Azion CLI deploy](/pt-br/documentacao/devtools/cli/deploy/).

Para visualizar o site localmente antes de um deploy, consulte [Azion CLI dev](/pt-br/documentacao/devtools/cli/dev-comando/). Para um projeto Hexo que você já tem, execute `azion link` na pasta dele e selecione o preset do Hexo, como descrito em [Azion CLI link](/pt-br/documentacao/devtools/cli/link-comando/).

## Verificar o site

Cada rota fornece a URL do domínio da Azion do site, no formato `https://xxxxxxxxxx.map.azionedge.net`. No Azion Console, a página de deploy mostra a URL; na rota da CLI, `azion deploy` a exibe ao final. Abra essa URL em um navegador para carregar o site Hexo.

O primeiro deploy pode levar vários minutos para responder em todas as localidades; os deploys seguintes levam cerca de dois minutos. Uma localidade que ainda não tem o site responde com uma página `404` que diz `There's nothing here yet`. Se você receber essa página, aguarde e carregue a URL novamente.
