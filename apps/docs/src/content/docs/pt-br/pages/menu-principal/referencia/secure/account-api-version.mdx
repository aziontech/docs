Você descobre se sua conta usa a API v3 ou a API v4 pelo menu do Azion Console. A API v4 chega às contas em ondas, então uma conta pode continuar na API v3 enquanto outras já usam a API v4.

## Pré-requisitos

- Acesso ao [Azion Console](https://console.azion.com/).

---

## Verifique o menu do Console

O menu do Azion Console lista os Platform Resources que a sua conta tem. Para verificar:

1. Acesse o [Azion Console](https://console.azion.com/).
2. Abra o menu do Console.
3. Procure por **Workloads**, **Connectors** ou **Custom Pages**.

Se o menu listar qualquer um deles, sua conta usa a API v4. Se o menu não listar Workloads, sua conta ainda usa a API v3.

![Menu do Azion Console com as opções da API v4 Workloads, Connectors e Custom Pages](/assets/docs/images/api-v4-verify-account-version.gif)

---

## Escolha sua versão na documentação

A documentação filtra as páginas por versão da API. Para ver apenas as páginas que se aplicam à sua conta:

1. Abra o seletor de versão no topo da barra lateral da documentação.
2. Selecione **API v3** ou **API v4**, a versão que você encontrou no menu do Console.

O menu da barra lateral passa a listar apenas as páginas dessa versão. O cabeçalho de cada página mostra as versões da API a que ela se aplica.
