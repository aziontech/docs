A funcionalidade de **Users Management** na Azion Web Platform fornece ferramentas para gerenciar os usuários em sua conta. Essa funcionalidade permite adicionar, modificar e excluir usuários, concedendo a você controle sobre quem tem acesso à sua conta da Azion e aos recursos associados.

Para adicionar usuários à conta, você precisa ter privilégios de **Account owner** ou permissões para **View Users** e **Edit Users**.

No **Users Management**, você pode:

- Adicionar novos usuários a sua conta da Azion.
- Alocá-los em equipes já existentes.
- Atribuir funções e permissões aos usuários, distinguindo entre *Account owners* e *non-owners*.
- Reforçar a segurança da conta ativando Multi-Factor Authentication (MFA) para os usuários.
- Remover usuários de sua conta.

## Profile

Nesta seção, você preencherá as informações pessoais do novo usuário.

| Campo | Descrição |
| --- | --- |
| **First name** | Primeiro nome do novo usuário. |
| **Last name** | Sobrenome do novo usuário. |
| **Timezone** | O fuso horário onde o novo usuário está localizado. Escolher o fuso horário correto garante precisão ao acessar dados e métricas na Azion Web Platform. |
| **Language** | O inglês é o único idioma disponível na Azion Web Platform. |

---

## Contact information

Nesta seção, você precisará fornecer as informações de contato do novo usuário.

| Campo | Descrição |
| --- | --- |
| **Email** | Endereço de e-mail do novo usuário. O usuário aplicará o endereço de e-mail fornecido como credencial de login. |
| **Phone Number** | Número de telefone do novo usuário, com o código do país e da região. |

---

## Security settings

Você pode configurar medidas de segurança para a conta do novo usuário.

| Campo | Descrição |
| --- | --- |
| **Account owner** | Quando ativado, o novo usuário é definido como Account Owner, com acesso a todas as configurações, incluindo a gestão de soluções e todas as contas. Quando desativado, o usuário é definido como não proprietário, com acesso restrito de acordo com as configurações de permissão definidas nas equipes. |
| **Teams** | As equipes têm diferentes permissões de acesso. Você deve selecionar uma equipe para alocar não proprietários, ao contrário dos Account Owners, que têm permissão para acessar todas as equipes. Você também pode alocar não proprietários a mais de uma equipe, o que amplia as possibilidades de permissão para o mesmo usuário. |
| **Enforce Multi-Factor Authentication** | Ativa a autenticação multifator (MFA) para o usuário, que passa a fazer login com um código de um aplicativo autenticador. Enquanto **Enforce Multi-Factor Authentication** está ativado em **Account Settings**, este campo fica somente leitura. |

:::note[nota]
As permissões de acesso de não proprietários dependem das permissões concedidas à equipe em que estão alocados. Para mais detalhes, consulte [Permissões de equipes](/pt-br/documentacao/fundamentos/teams-permissions/).
:::

## Status

| Campo | Descrição |
| --- | --- |
| **Active** | Mantém o usuário ativo. A coluna **Status** de **Users Management** mostra essa informação. |
