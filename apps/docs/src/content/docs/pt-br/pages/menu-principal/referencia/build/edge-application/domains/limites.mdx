O [Domains](/pt-br/documentacao/plataforma/domains/) limita o número de CNAMEs que um domínio lista. Esta página traz o limite padrão e como aumentá-lo.

---

## Limites padrão

| Escopo | Limite |
| --- | --- |
| CNAMEs por domínio | 50 |

Você pode solicitar um limite maior com base no seu plano. Contate o [time de suporte técnico](/pt-br/documentacao/suporte/) para fazer a solicitação.
