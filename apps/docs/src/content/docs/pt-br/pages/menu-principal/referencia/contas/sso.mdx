O logon único (SSO) permite que você conceda aos membros de sua equipe uma conta para todos os sistemas que sua empresa usa. O SSO não vem habilitado na conta por padrão, e a Azion o habilita mediante solicitação. Para solicitá-lo, consulte [Diretrizes de suporte](/pt-br/documentacao/suporte/). Com o SSO habilitado e configurado para sua empresa, seus usuários poderão fazer o login na plataforma da Azion usando suas credenciais de SSO.

Somente usuários com privilégio de *Account Owner* podem configurar o *login* dos membros do time entre duas opções de autenticação de conta: **Azion SSO** ou um **Identity Provider (IdP)** externo. Para a configuração no Azion Console, consulte [Configure um identity provider para SSO](/pt-br/documentacao/guias/plataforma/conta-e-billing/sso/).

Usando o SSO, você pode:

- Reduzir problemas relacionados a senhas.
- Aumentar a segurança, minimizando potenciais vulnerabilidades.
- Diminuir pedidos de suporte, já que o usuário gerencia menos senhas.
- Possibilitar navegação contínua entre aplicações.

## Autenticação com certificado X.509

O SSO da Azion suporta autenticação baseada em certificados X.509 como um método de autenticação adicional. Quando configurado, os usuários podem se autenticar usando certificados digitais X.509 emitidos pela Autoridade Certificadora da sua organização.

O fluxo de autenticação funciona de forma idêntica para todos os tipos de certificados X.509. Os usuários não precisam realizar nenhuma configuração especial ou ação diferente para usar a autenticação com certificado X.509: o processo se integra à sua configuração de SSO existente.

Para configurar um certificado X.509 na Azion, consulte [Como configurar um certificado X.509](/pt-br/documentacao/plataforma/workloads/certificate-manager/certificados/#certificado-de-servidor) na documentação do Certificate Manager.

## Termos de SSO

| Termo | Definição |
| --- | --- |
| Identity Provider (IdP) | Uma entidade confiável que permite habilitar o logon único para acessar outros sites ou serviços, como os da Azion. Seus usuários podem continuar usando suas identidades de usuários corporativos sem precisar lembrar de uma senha específica ou digitar credenciais cada vez que for acessar a plataforma da Azion. Um exemplo de IdP é o Microsoft Entra. |
| Service Provider | A Azion, neste contexto, é o provedor de serviços configurado como uma aplicação em um provedor de identidade para habilitar o logon único. |
| Security Assertion Markup Language (SAML) | Um protocolo de padrão aberto para troca de dados de autenticação e autorização entre as partes, em particular, entre um Provedor de Identidade e um Provedor de Serviços. SAML é uma linguagem de marcação baseada em XML para declarações de segurança (declarações que os provedores de serviços usam para tomar decisões de controle de acesso). A Azion suporta o protocolo SAML, versão 2.0. |
| OpenID Connect (OIDC) | Um protocolo de identidade de padrão aberto que usa o OAuth 2.0 para autenticação e autorização e, em seguida, constrói identidades que identificam os usuários exclusivamente. |
| System for Cross-domain Identity Management (SCIM) | Um padrão aberto que simplifica a gestão de identidades de usuários entre sistemas, permitindo a criação, atualização e exclusão automáticas de contas entre provedores de identidade e provedores de serviço. A Azion oferece suporte ao SCIM para uma gestão de identidades segura e eficiente. |
