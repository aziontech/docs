Você instala uma integração pelo Azion Marketplace e a executa em uma aplicação ou em um firewall pelo Azion Console. Esta página é o procedimento que todas as integrações compartilham. Cada integração também tem um guia próprio, com os argumentos que ela recebe. Para essa lista e para saber onde cada integração roda, consulte [Integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/).

As integrações são instaladas de uma de duas formas. Algumas abrem um drawer de instalação que configura a integração em uma aplicação que você seleciona. Outras adicionam a function da integração à sua conta imediatamente. Depois, você ativa o módulo **Functions** de uma aplicação ou de um firewall, cria uma function instance ali e cria uma regra do Rules Engine que executa a instância.

---

## Pré-requisitos

- Uma conta Azion. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [aplicação](/pt-br/documentacao/plataforma/applications/) servida por um [workload](/pt-br/documentacao/plataforma/workloads/). Para criar uma, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
- Para uma integração que roda em um [firewall](/pt-br/documentacao/plataforma/firewall/), um firewall e a [Azion CLI](/pt-br/documentacao/devtools/cli/) instalada e autorizada. A CLI vincula o firewall ao workload.
- Ativar um produto ou um módulo pode gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Instale a integração

Você instala uma integração uma vez por conta. Para instalá-la pelo Azion Console:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Encontre a integração">

  Insira o nome da integração no campo **Search on Marketplace** e selecione o card dela. Navegar pelos cards e pelas **Categories** leva à mesma página.

  </DocStep>
  <DocStep title="Selecione Install" />
</DocSteps>

O que acontece em seguida depende da integração.

Se o drawer **Install an Integration** abrir, a integração inclui um template de instalação. Para preencher o drawer:

<DocSteps>
  <DocStep title="Selecione a aplicação">

  Na seção **Select an Application**, selecione uma **Application**. Para criar uma, selecione **Create New**.

  </DocStep>
  <DocStep title="Preencha os campos da integração">

  O drawer exibe um formulário com os argumentos próprios da integração. O guia da integração descreve cada um.

  </DocStep>
  <DocStep title="Revise as permissões">

  O drawer lista os privilégios que o Azion Marketplace exige na aplicação selecionada. Para saber o que cada um permite, consulte [Permissões do Marketplace](/pt-br/documentacao/plataforma/marketplace/permissoes-marketplace/).

  </DocStep>
  <DocStep title="Selecione Deploy" />
</DocSteps>

O Azion Console confirma que a integração foi instalada, e a integração roda na aplicação selecionada. As seções abaixo não se aplicam a ela.

Se nenhum drawer abrir, a instalação termina imediatamente. O card exibe `Successfully installed!` e `Latest version installed!`, e a function aparece na lista **Function** do drawer **Create Instance**. Continue com [Execute-a em uma aplicação](#execute-a-em-uma-aplicacao) ou [Execute-a em um firewall](#execute-a-em-um-firewall), conforme o guia da integração indica.

## Execute-a em uma aplicação

Uma integração que roda em uma aplicação precisa de três alterações nessa aplicação. Faça-as na ordem abaixo.

### Ative o módulo Functions

Uma aplicação executa uma function instalada somente enquanto o módulo **Functions** dela está ativado. Para ativar o módulo:

<DocSteps>
  <DocStep title="Abra sua aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação**.

  </DocStep>
  <DocStep title="Abra a seção Modules">

  Na aba **Main Settings**, vá para a seção **Modules**.

  </DocStep>
  <DocStep title="Ative a chave Functions" />
  <DocStep title="Selecione Save" />
</DocSteps>

A aplicação exibe uma aba **Functions Instances**, onde você instancia a function.

### Crie a function instance

Uma function instance contém os argumentos que a integração lê em uma aplicação. Para criar a instância:

<DocSteps>
  <DocStep title="Abra a aba Functions Instances">

  Em **Applications**, selecione sua aplicação e selecione a aba **Functions Instances**.

  </DocStep>
  <DocStep title="Selecione + Function">

  Uma aplicação ainda sem instância oferece a mesma ação como **Function Instance**. O drawer **Create Instance** abre.

  </DocStep>
  <DocStep title="Dê um nome à instância">

  Em **Name**, insira um nome único que identifique a instância.

  </DocStep>
  <DocStep title="Selecione a function instalada">

  Em **Function**, selecione a integração. O editor **Arguments** é preenchido com os argumentos padrão da integração em JSON.

  </DocStep>
  <DocStep title="Edite os argumentos">

  Em **Arguments**, substitua os valores padrão pelos seus. O guia da integração descreve cada chave.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância aparece na aba **Functions Instances** com o nome que você inseriu.

### Crie a regra

A instância só roda quando uma regra do [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/) a chama com o behavior **Run Function**. A regra abaixo corresponde a todas as requisições. Para criá-la:

<DocSteps>
  <DocStep title="Abra a aba Rules Engine">

  Em **Applications**, selecione sua aplicação e selecione a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Selecione + Rule" />
  <DocStep title="Dê um nome à regra">

  Em **Name**, insira um nome. Por exemplo: `Run my integration`.

  </DocStep>
  <DocStep title="Selecione a fase">

  Na seção **Phase**, selecione _Request Phase_.

  </DocStep>
  <DocStep title="Defina o critério">

  Na seção **Criteria**, mantenha a variável `${uri}` e o operador _starts with_ e insira `/` como argumento.

  </DocStep>
  <DocStep title="Adicione o behavior Run Function">

  Na seção **Behaviors**, selecione _Run Function_ e selecione a instância pelo nome que você deu a ela.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A regra aparece na aba **Rules Engine**, na fase de requisição, e executa a instância em todas as requisições. Algumas integrações precisam de mais behaviors na mesma regra, como _Bypass Cache_ ou _Forward Cookies_. Esses behaviors e os critérios extras exigem o módulo **Application Accelerator**, e o guia da integração os lista.

## Execute-a em um firewall

Uma integração que roda em um firewall precisa de três alterações no firewall e, depois, de um vínculo entre o firewall e seu workload.

### Ative o módulo Functions

Um firewall exibe a aba **Functions Instances** somente enquanto o módulo **Functions** dele está ativado. Para ativar o módulo:

<DocSteps>
  <DocStep title="Abra seu firewall">

  Acesse [Azion Console](https://console.azion.com/) > **Firewalls** > **seu firewall**.

  </DocStep>
  <DocStep title="Abra a seção Modules">

  Na aba **Main Settings**, vá para a seção **Modules**.

  </DocStep>
  <DocStep title="Ative a chave Functions" />
  <DocStep title="Selecione Save" />
</DocSteps>

O firewall exibe a aba **Functions Instances**. Para todas as configurações deste formulário, consulte [Defina as configurações principais de um firewall](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/firewall-definir-main-settings/).

### Crie a function instance

Uma function instance de firewall contém os argumentos que a integração lê nesse firewall. Para criar a instância:

<DocSteps>
  <DocStep title="Abra a aba Functions Instances">

  Em **Firewalls**, selecione seu firewall e selecione a aba **Functions Instances**.

  </DocStep>
  <DocStep title="Selecione + Function">

  Um firewall ainda sem instância oferece a mesma ação como **Function Instance**. O drawer **Create Instance** abre.

  </DocStep>
  <DocStep title="Dê um nome à instância">

  Em **Name**, insira um nome único que identifique a instância.

  </DocStep>
  <DocStep title="Selecione a function instalada">

  Em **Function**, selecione a integração. A lista contém somente as functions que rodam em um firewall.

  </DocStep>
  <DocStep title="Edite os argumentos">

  Em **Arguments**, substitua os valores padrão no editor JSON pelos seus. O guia da integração descreve cada chave.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância aparece na aba **Functions Instances**.

### Crie a regra

Uma regra do [Rules Engine for Firewall](/pt-br/documentacao/plataforma/firewall/rules-engine/) seleciona as requisições que chegam à instância, por meio do behavior **Run Function**. Para criar a regra:

<DocSteps>
  <DocStep title="Abra a aba Rules Engine">

  Em **Firewalls**, selecione seu firewall e selecione a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Selecione + Rule" />
  <DocStep title="Dê um nome à regra">

  Em **Name**, insira um nome. Por exemplo: `Run my integration`.

  </DocStep>
  <DocStep title="Defina o critério">

  Na seção **Criteria**, selecione as requisições que executam a integração. Por exemplo: if `Hostname` _is equal_ `xxxxxxxxxxxx.map.azionedge.net`.

  </DocStep>
  <DocStep title="Adicione o behavior Run Function">

  Na seção **Behaviors**, selecione **Run Function** e selecione a instância pelo nome que você deu a ela.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O firewall executa a instância em todas as requisições que correspondem ao critério.

### Vincule o firewall ao workload

Um firewall inspeciona as requisições de um workload somente quando o deployment do workload o indica. Para criar um deployment que indique a aplicação e o firewall:

```bash
azion create workload-deployment --workload-id <workload-id> --name <deployment-name> \
  --application-id <application-id> --firewall-id <firewall-id> --strategy-type default \
  --active true --current true
```

O comando exibe o ID do novo deployment:

```text
Created Workload Deployment with ID <deployment-id>
```

As requisições ao domínio do workload chegam ao firewall, e a regra executa a instância nas requisições que correspondem ao critério dela.

## Integrações de terceiros

Algumas integrações chamam uma ferramenta de outro fornecedor. Antes de instalar uma delas, você pode precisar de uma conta com esse fornecedor ou de uma configuração inicial do lado dele. Algumas dessas integrações também podem gerar custos de uso com o fornecedor.

A coluna **Third-party account** de [Integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/) informa quais integrações precisam de uma conta com o fornecedor. O guia próprio da integração descreve a configuração.

---

## Encontre e atualize integrações instaladas

Cada integração instalada aparece na lista **Function** do drawer **Create Instance**. A lista **Functions** também pode exibir uma integração instalada, marcada por um ícone de carrinho na coluna **Vendor**.

A Azion e os parceiros dela publicam novas versões de integrações. Atualizar cria uma nova instância da function da integração. Para atualizar uma integração e mover suas instâncias para a nova versão, consulte [Atualize uma integração](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/atualizar-uma-integracao/).
