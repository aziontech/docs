[AI Inference](/pt-br/documentacao/plataforma/ai-inference/) executa os modelos desta página. Você seleciona um modelo pelo id, uma string à qual o modelo responde, e não pelo nome sob o qual ele aparece listado. Cada linha do catálogo carrega esse id ao lado das capacidades do modelo. Para conhecer o corpo da requisição em que o id viaja, consulte [Invocação de modelos](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/).

## Catálogo de modelos

Cada linha é um modelo, e o nome do modelo leva à página do modelo, que traz um exemplo de requisição. A coluna Categoria assume um de quatro valores:

- **LLM**: um large language model, que lê texto e retorna texto.
- **VLM**: um vision language model, que lê texto e imagens e retorna texto.
- **Embedding**: um modelo que retorna um vetor que representa o texto de entrada.
- **Reranker**: um modelo que pontua um conjunto de documentos em relação a uma consulta.

Um traço significa que a página do modelo não declara valor para aquela capacidade.

## Ids de modelo

Um id de modelo é a string que seleciona o modelo: o primeiro argumento de `Azion.AI.run` dentro de uma [Function](/pt-br/documentacao/plataforma/functions/) e o campo `model` do corpo de uma requisição enviada ao endpoint HTTP do [AI Inference Starter Kit](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/ai-inference-starter-kit/). Um modelo pode responder a duas formas do id: uma forma de repositório, como `Qwen/Qwen2.5-VL-3B-Instruct-AWQ`, e uma forma em minúsculas com hífens, como `qwen-qwen25-vl-3b-instruct-awq`. As duas formas selecionam o mesmo modelo. A forma em minúsculas não decorre da forma de repositório por uma regra simples, então copie um id da tabela caractere por caractere, em vez de derivá-lo do nome do modelo.

Para listar os ids que a sua conta pode chamar, nas duas formas, chame `Azion.AI.models()` a partir de uma Function. Ele retorna uma promise que resolve para um array de strings de id:

```ts
const modelIds = await Azion.AI.models()
```

O campo `model` de uma resposta traz o id interno da conta para o modelo, que pode ser diferente do id que a requisição enviou. Uma requisição para `Qwen/Qwen3-30B-A3B-Instruct-2507-FP8` retorna `qwen-qwen3-30b-a3b-instruct-2507-fp8`, e GPT-OSS 20B retorna `gpt-oss-20b`, um id que `Azion.AI.run` recusa como entrada. Não passe o campo `model` de uma resposta como id.
