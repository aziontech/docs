Na página **Team Permissions**, você pode criar e gerenciar equipes, controlar e configurar direitos de acesso para equipes distintas em sua empresa. Você pode, por exemplo, criar grupos dividindo-os de acordo com as tarefas que eles precisam executar na plataforma da Azion.

:::note[nota]
Somente usuários com status de **Account Owner** podem adicionar equipes e editar permissões.
:::

Ao conceder ou restringir o acesso a recursos e configurações específicos, você pode:

- Economizar tempo, pois as equipes acessam apenas o que precisam.
- Aumentar a segurança, limitando o acesso para manter as informações confidenciais seguras.
- Ter mais controle, acompanhando as ações específicas das equipes para questões de segurança e regras.
- Incentivar o trabalho em equipe com o time acessando as ferramentas em conjunto.

## Permissões de acesso

Nesta tabela, você encontra o que cada permissão concede acesso:

| Permissão | Descrição |
| --- | --- |
| View Content Delivery Settings | Concede permissão para visualizar cache settings list. Permissão para os produtos Web Performance, Real Time Purge, Analytics e Analytics Standard. |
| Edit Content Delivery Settings | Concede permissão para editar a cache settings list. Requer a permissão **View Content Delivery Settings**. Permissão para os produtos Web Performance, Real Time Purge, Analytics e Analytics Standard.|
| Real-Time Purge | Concede permissão para adicionar um novo purge ao Real-Time Purge. |
| View Analytics | Concede permissão para visualizar analytics. |
| View Security Settings | Concede permissão para visualizar o WAF Rule Sets e Certificate Manager (com exceção da private key), mas não permite criação, remoção ou modificações. |
| Edit Security Settings | Concede permissão para visualizar, criar, editar e remover WAF Rule Sets e Certificate Manager. Também requer a permissão **View Security Settings**. |
| View Subscriptions | Concede permissão para visualizar as assinaturas da conta, mas não permite modificações. Também requer a permissão **View Bills**. |
| Edit Subscriptions | Concede permissão para modificar as assinaturas da conta. Também requer as permissões **View Bills** e **View Subscriptions**. |
| View Payment Methods | Concede permissão para visualizar as formas de pagamento ativas e o histórico de pagamentos. Também requer a permissão **View Bills**. |
| Edit Payment Methods | Concede permissão para criar, editar e remover métodos de pagamento. Também requer as permissões **View Bills** e **View Payment Methods**. |
| View Bills | Concede permissão para visualizar a aba **Billing** em **Billing & Subscriptions**. A visualização de **Payment Methods** e **Payment History** requer a permissão **View Payment Methods**. |
| Edit Multi-Factor Authentication | Concede permissão para editar Multi-Factor Authentication. |
| View Applications | Concede permissão para visualizar as configurações, mas não permite modificações, criação ou remoção. |
| Edit Applications | Concede permissão para editar, criar e remover applications. Também requer a permissão **View Applications**. |
| View Workloads | Concede permissão para visualizar workloads existentes, mas não permite criação, remoção ou modificações. |
| Edit Workloads | Concede permissão para criar, editar e remover workloads. Também requer a permissão **View Workloads**. |
| View Connectors | Concede permissão para visualizar connectors. |
| Edit Connectors | Concede permissão para editar connectors. Também requer a permissão **View Connectors**. |
| View Custom Pages | Concede permissão para visualizar custom pages. |
| Edit Custom Pages | Concede permissão para editar custom pages. Também requer a permissão **View Custom Pages**. |
| View Events | Concede permissão para visualizar e filtrar por data source. |
| View Users | Concede permissão para visualizar a conta dos usuários na página **Users Management**, mas não permite criação, remoção ou modificações. |
| Edit Users | Concede permissão para criar, editar e remover usuários da conta. Também requer a permissão **View Users**. |
| Wildcard Purge | Concede permissão para selecionar o purge tipo de **Wildcard** no **Real-Time Purge**. Também requer a permissão **Real-Time Purge**. |
| View DNS | Concede permissão para visualizar as zonas criadas na conta. Não permite criação ou remoção. |
| Edit DNS | Concede permissão para criar, editar e remover zonas. Também requer a permissão **View DNS**. |
| View Data Stream | Concede permissão para visualizar os streams da conta. Não permite criação, modificação ou remoção. |
| Edit Data Stream | Concede permissão para criar, editar e remover streams. Também requer a permissão **View Data Stream**. |
| View Network Lists | Concede permissão para visualizar Network Lists, mas não permite criação, remoção ou modificação. |
| Edit Network Lists | Concede permissão para visualizar, criar, editar e remover Network Lists. Também requer a permissão **View Network Lists**. |
| View Firewall | Concede permissão para visualizar firewalls, mas não permite criação, remoção ou modificação. |
| Edit Firewall | Concede permissão para visualizar, criar, editar e remover firewalls. Também requer a permissão **View Firewall**. |
| View Functions | Concede permissão para visualizar functions existentes, mas não permite criação, remoção ou modificações. |
| Edit Functions | Concede permissão para criar, editar e remover functions. Também requer a permissão **View Functions**. |
| View Storage Bucket | Concede permissão para visualizar Object storage buckets usando a API da Azion. |
| Edit Storage Bucket  | Concede permissão para criar e editar Object storage buckets usando a API da Azion. |
| Delete Storage Bucket | Concede permissão para remover Object storage buckets usando a API da Azion. |
| View Storage Object | Concede permissão para visualizar os metadados de objetos e fazer o download de objetos de Object storage buckets usando a API da Azion. |
| Edit Storage Object | Concede permissão para criar e editar objetos em Object storage buckets usando a API da Azion. |
| Delete Storage Object | Concede permissão para remover objetos usando de Object storage buckets usando a API da Azion. |
| View client list | Concede permissão para visualizar a lista de clientes. Não permite a criação, modificação ou remoção de clientes. O recurso Clients está disponível apenas para contas do tipo Reseller. |
| Change clients | Concede permissão para criar, editar ou remover clientes. Também requer a permissão **View Client list**. |
| View SQL Database | Concede permissão para visualizar os bancos de dados criados e seu conteúdo usando a API da Azion. |
| Edit SQL Database | Concede permissão para criar e editar bancos de dados e seu conteúdo usando a API da Azion. |
| Create Storage Credentials | Concede permissão para criar credenciais de storage. |
| View Storage Credentials | Concede permissão para visualizar credenciais de storage. |
| Delete Storage Credentials | Concede permissão para remover credenciais de storage. |
| View Policies | Concede permissão para visualizar políticas. |
| Edit Policies | Concede permissão para editar políticas. Também requer a permissão **View Policies**. |
| Delete Policies | Concede permissão para remover políticas. |
| Create VCS Integrations | Concede permissão para criar integrações de VCS. |
| View VCS Integrations | Concede permissão para visualizar integrações de VCS. |
| Delete VCS Integrations | Concede permissão para remover integrações de VCS. |
| View VCS Continuous Deployment | Concede permissão para visualizar o continuous deployment de VCS. |
| Edit VCS Continuous Deployment | Concede permissão para editar o continuous deployment de VCS. Também requer a permissão **View VCS Continuous Deployment**. |
| Delete VCS Continuous Deployment | Concede permissão para remover o continuous deployment de VCS. |
| Create VCS Continuous Deployment Execution | Concede permissão para criar execuções de continuous deployment de VCS. |
| Create Orchestrator Nodes | Concede permissão para criar nodes do Orchestrator. |
| Edit Orchestrator Nodes | Concede permissão para editar nodes do Orchestrator. |
| Delete Orchestrator Nodes | Concede permissão para remover nodes do Orchestrator. |
| Create Orchestrator Services | Concede permissão para criar serviços do Orchestrator. |
| Edit Orchestrator Services | Concede permissão para editar serviços do Orchestrator. |
| Delete Orchestrator Services | Concede permissão para remover serviços do Orchestrator. |
| View Marketplace Publisher | Concede permissão para visualizar o publisher do Marketplace. |
| Edit Marketplace Publisher | Concede permissão para editar o publisher do Marketplace. Também requer a permissão **View Marketplace Publisher**. |
| SCIM Integration | Concede permissão para usar a integração SCIM. |

## Erros

Se um usuário tentar acessar uma página na plataforma da Azion sem as permissões necessárias, encontrará uma página de erro *403 Forbidden*.
