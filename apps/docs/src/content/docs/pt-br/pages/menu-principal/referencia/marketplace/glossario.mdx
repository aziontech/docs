Este glossário define os termos que a documentação do [Azion Marketplace](/pt-br/documentacao/plataforma/marketplace/) usa para integrações, templates, licenças e vendas, com os rótulos correspondentes no Azion Console.

| Termo | Definição |
| --- | --- |
| argumentos (Args) | Os valores que o código de uma integração lê, que você personaliza enquanto o próprio código permanece fixo. Uma instância de função os guarda em JSON no campo **Arguments**, que o Azion Console preenche com os valores padrão da integração, e o código lê cada um com `EVENT.ARGS('ARG_NAME')`. Como os argumentos ficam na instância, dois recursos podem executar uma integração com valores diferentes, como descreve [Como o Marketplace funciona](/pt-br/documentacao/plataforma/marketplace/como-funciona/#integracoes). |
| Bring Your Own License (BYOL) | A licença com a qual você executa uma integração usando uma licença ou credenciais que você já tem do provedor da integração, oferecida na página da integração como **Bring Your Own License**. Você fornece credenciais válidas que autenticam a sua conta e conectam a Azion ao provedor, e a Azion cobra pelos serviços da Azion que o seu uso gera. [Como o Marketplace funciona](/pt-br/documentacao/plataforma/marketplace/como-funciona/#licencas) compara as licenças, e [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/) apresenta o lado do vendedor. |
| Buy to Subscribe | A opção de licença na página de uma integração que leva a um contato com o Azion Sales Team em vez de uma instalação. Você obtém a integração pela assinatura que combina com Azion Sales, como descreve [Como o Marketplace funciona](/pt-br/documentacao/plataforma/marketplace/como-funciona/#licencas). |
| comprador | Um cliente do Azion Marketplace que usa o Marketplace para instalar e implantar o software que ele lista. Qualquer pessoa com uma conta Azion pode atuar como compradora e depois se candidatar a vendedora, como descreve [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/). |
| Free License | A licença de uma integração que você obtém apenas com o botão **Install**, exibida na página dela com "Install this integration using the available free model." Você paga somente quando usa a integração, sujeito aos termos de uso dela, e os vendedores chamam esse modelo de negócio de _Free_. [Como o Marketplace funciona](/pt-br/documentacao/plataforma/marketplace/como-funciona/#licencas) a compara com as outras licenças. |
| instância de função | O objeto que executa uma integração instalada em uma [aplicação](/pt-br/documentacao/plataforma/applications/functions-instances/) ou em um [firewall](/pt-br/documentacao/plataforma/firewall/functions-instances/) com os próprios argumentos, listado na aba **Functions Instances** do recurso. Depois de uma instalação direta, você a cria no drawer **Create Instance** selecionando a integração na lista **Function**, enquanto o drawer **Install an Integration** a cria na aplicação que você seleciona. Uma regra do Rules Engine com o comportamento **Run Function** a chama, como descreve [Como o Marketplace funciona](/pt-br/documentacao/plataforma/marketplace/como-funciona/#integracoes). |
| integração | Uma listagem do Marketplace que é uma função: código que você não pode modificar, mais argumentos que você personaliza. Dependendo da integração, **Install** adiciona a função à sua conta, depois do que você cria uma instância de função e uma regra, ou abre o drawer **Install an Integration**, que a instancia na aplicação que você seleciona. Cada integração é executada em uma aplicação ou em um firewall, como lista [Integrações do Marketplace](/pt-br/documentacao/plataforma/marketplace/integracoes/). |
| ISV | Um Independent Software Vendor, fornecedor independente de software, um terceiro que publica produtos no Azion Marketplace como vendedor. Um vendedor também pode ser um desenvolvedor de software individual ou uma comunidade open source, e [Torne-se um vendedor no Marketplace](/pt-br/documentacao/plataforma/marketplace/isv-signup/) descreve a candidatura. |
| oferta privada | Uma oferta que um vendedor faz a um comprador, com preço especial e o próprio contrato de licença de usuário final (EULA), em vez da tabela de preços padrão. Um comprador também pode iniciar uma oferta privada para negociar preço e uso, e os termos negociados começam quando o comprador aceita o acordo, como descreve [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/). |
| Pay As You Go (PAYG) | O modelo de preço em que o Azion Marketplace cobra os compradores mensalmente a partir dos registros de medição do uso deles e do preço que o vendedor define, sem compromisso. Um produto PAYG pode oferecer um teste gratuito, depois do qual o Azion Marketplace inscreve o comprador em PAYG, a menos que o comprador cancele ou desista. [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/) descreve o modelo. |
| registro de medição | Uma medida de uso a partir da qual o Azion Marketplace Metering Service cobra um produto Pay As You Go: instâncias implantadas, usuários registrados, requisições, tempo de computação ou transferência de dados. O software do vendedor informa o uso de cada comprador a cada hora, e a Azion não pode cobrar um uso cujo registro não é transmitido ou não chega, como descreve [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/). |
| Saving Plan | O modelo de preço em que um comprador combina com o vendedor uma quantidade de uso, como requisições, por um período de 1 mês, 1 ano, 2 anos ou 3 anos. O Azion Marketplace o cobra antecipadamente ou no cronograma de pagamento do vendedor, e cobra o uso acima do plano pelo preço Pay As You Go do vendedor, como descreve [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/). |
| template | Uma listagem do Marketplace que é um projeto pré-configurado, que você implanta a partir do Azion Console em vez de instalar. Uma implantação cria uma aplicação, um domínio da Azion, a configuração de que o caso de uso precisa, uma função em alguns templates e um repositório no GitHub com os arquivos do template, como descreve [Templates do Marketplace](/pt-br/documentacao/plataforma/marketplace/templates/). [Como o Marketplace funciona](/pt-br/documentacao/plataforma/marketplace/como-funciona/#templates) compara templates com integrações. |
| tiered listing fee (TLF) | A taxa de listagem que o Azion Marketplace cobra de um vendedor em cada transação de um produto, como um percentual escalonado pelo valor em dólares da transação. As faixas vão de 13% a 6% para produtos SaaS, dependendo do valor e do ano da assinatura, e de 20% a 13% para produtos baseados na Azion Web Platform. Uma taxa menor obtida por um valor maior se aplica mês a mês, nunca retroativamente, como descreve [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/). |
| vendedor | Um cliente do Azion Marketplace que fornece software pronto para uso e usa o Marketplace como canal de distribuição: um ISV, um desenvolvedor de software individual ou uma comunidade open source. A Azion analisa o vendedor e cada produto antes da publicação, e [Requisitos e taxas para vendedores](/pt-br/documentacao/plataforma/marketplace/marketplace-seller-guide/) lista os requisitos. |
