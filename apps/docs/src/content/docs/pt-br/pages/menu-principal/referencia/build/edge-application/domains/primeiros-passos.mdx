Este guia conduz você pela criação do seu primeiro domínio no [Domains](/pt-br/documentacao/plataforma/domains/). Ao final, você terá um domínio que atende os hostnames que você listar e passa as requisições deles para a sua aplicação.

Um **domínio** é uma entrada na sua conta: um nome, os hostnames que ele atende, a aplicação que os responde e o certificado que ele usa. A Azion gera um Azion domain para ele no formato `xxxx.map.azionedge.net`. O nome identifica a entrada e não é um hostname.

---

## Pré-requisitos

- Uma aplicação. Para criar uma, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
- Um hostname de um domínio seu e acesso aos registros DNS dele no seu provedor de DNS ou no [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/).
- Para usar a API, um personal token para o header `Authorization`, no formato `Token [TOKEN VALUE]`, e o `curl`. Para criar um token, consulte [Personal tokens](/pt-br/documentacao/fundamentos/personal-tokens/).
- Para usar o Azion Console, acesso a ele. Para mais informações, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Crie o domínio

<Fragment slot="panel.console">

Para criar o domínio no Azion Console:

<DocSteps>
  <DocStep title="Abra Domains">

  Acesse [Azion Console](https://console.azion.com/) > **Domains**.

  </DocStep>
  <DocStep title="Inicie um domínio">

  Selecione **+ Domain** ou selecione um domínio existente para editá-lo.

  </DocStep>
  <DocStep title="Nomeie o domínio">

  Informe um nome. O nome identifica a entrada na conta e não é um hostname.

  </DocStep>
  <DocStep title="Escolha o ambiente">

  Em **Environment Type**, selecione **Global Edge Network** para produção ou **Staging Network** para um ambiente de teste.

  </DocStep>
  <DocStep title="Selecione a aplicação e o firewall">

  Em **Applications**, selecione sua aplicação. Em **Firewall**, selecione seu firewall.

  </DocStep>
  <DocStep title="Liste os hostnames">

  Em **CNAME**, liste os hostnames que você atende, um por linha.

  </DocStep>
  <DocStep title="Decida sobre o endereço da Azion">

  Deixe **CNAME access only** desligado para manter o endereço `xxxxxxxxxx.map.azionedge.net` acessível, ou ligue-o para atender somente os hostnames listados.

  </DocStep>
  <DocStep title="Selecione o certificado">

  Em **Digital Certificate**, selecione **Azion SAN** ou um certificado próprio.

  </DocStep>
  <DocStep title="Salve o domínio">

  Selecione **Save**.

  </DocStep>
</DocSteps>

</Fragment>

<Fragment slot="panel.api">

Para criar o domínio pela API v3, envie um `POST` para `/domains`. A requisição carrega o header `Accept: application/json; version=3`, e `<application-id>` é o ID da aplicação que o domínio atende:

```bash
curl --request POST \
  --url https://api.azionapi.net/domains \
  --header 'Accept: application/json; version=3' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]' \
  --data '{
  "name": "my-domain",
  "cnames": ["www.example.com"],
  "cname_access_only": false,
  "digital_certificate_id": null,
  "edge_application_id": <application-id>
}'
```

Substitua `my-domain` pelo nome da entrada e `www.example.com` por um hostname seu. Para o que cada chave carrega, consulte [Configurações do domínio](/pt-br/documentacao/plataforma/domains/referencia/#campos-do-dominio).

A resposta devolve o domínio como a Azion o armazenou, com o endereço Azion dele em `domain_name`:

```json
{
  "results": {
    "id": 1234567,
    "name": "my-domain",
    "cnames": ["www.example.com"],
    "cname_access_only": false,
    "digital_certificate_id": null,
    "edge_application_id": 1234567890,
    "is_active": true,
    "domain_name": "xxxxxxxxxx.map.azionedge.net"
  }
}
```

## Aponte seu hostname para o domínio

Um hostname listado não recebe tráfego até que o DNS o envie para lá. Crie um registro DNS para o hostname que aponte para o endereço em que o domínio responde. Para o registro em cada tipo de provedor de DNS e como verificar se ele resolve, consulte [Aponte um domínio para um workload](/pt-br/documentacao/guias/plataforma/migracao/apontar-dominio-para-a-azion/).
