Definições dos termos que a documentação do **Domains** usa.

| Termo | Definição |
| --- | --- |
| Azion domain | O hostname que a Azion gera para um domínio, no formato `xxxx.map.azionedge.net`. Um domínio na Staging Network recebe um no formato `xxxx.preview.azionedge.net`. [Configurações do domínio](/pt-br/documentacao/plataforma/domains/referencia/#ambiente) lista os dois. |
| Azion SAN | O certificado que um domínio usa quando você seleciona **Azion SAN** em **Digital Certificate** ou quando `digital_certificate_id` é `null`. [Configurações do domínio](/pt-br/documentacao/plataforma/domains/referencia/#campos-do-dominio) lista o campo. |
| certificado de CA confiável | O certificado de uma autoridade certificadora em que você confia, do tipo `trusted_ca_certificate`. Um domínio verifica os certificados dos clientes em relação a ele quando o mTLS está ativo. [Configurações do domínio](/pt-br/documentacao/plataforma/domains/referencia/#mtls) lista o campo. |
| domínio | Uma entrada na sua conta, criada no Domains, que guarda um nome, os hostnames que ela atende, a aplicação que os responde e o certificado dela. [Domains](/pt-br/documentacao/plataforma/domains/) descreve o Platform Resource. |
| domínio personalizado | Um hostname de um domínio seu, listado no campo **CNAME** de um domínio para que o domínio responda a ele. [Aponte um domínio para um workload](/pt-br/documentacao/guias/plataforma/migracao/apontar-dominio-para-a-azion/) cria o registro DNS que o envia para a Azion. |
| mTLS | Mutual Transport Layer Security: um handshake TLS em que o cliente também apresenta um certificado, que o domínio valida em relação a um certificado de CA confiável. [Configurações do domínio](/pt-br/documentacao/plataforma/domains/referencia/#mtls) lista os campos dele. |
