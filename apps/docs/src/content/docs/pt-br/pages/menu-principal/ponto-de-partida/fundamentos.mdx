A Azion é uma [plataforma web global](https://www.azion.com/pt-br/produtos/nossa-rede/), com mais de 100 data centers ao redor do mundo. Nela, computação, segurança e dados são entregues a partir do ponto mais próximo de cada usuário, o que permite construir, proteger e escalar aplicações sem gerenciar infraestrutura. Desenvolvedores independentes, startups e grandes empresas a utilizam para workloads que vão de sites simples a sistemas de missão crítica.

## Topologia dos Recursos de Plataforma

Tudo o que serve tráfego na Azion é um conjunto de recursos de plataforma ligados entre si. Cada produto que você ativa, como WAF ou Cache, fica dentro do recurso em que ele atua. O diagrama mostra como eles se conectam: o que o workload vincula, o que cada recurso guarda, de onde a aplicação busca o conteúdo e o que uma função pode chamar.

<PlatformTopology client:visible lang="pt-br" />

1. Um [workload](/pt-br/documentacao/plataforma/workloads/) recebe o tráfego dos seus domínios. Ele guarda os [domínios](/pt-br/documentacao/plataforma/workloads/domains/) e o certificado do [Certificate Manager](/pt-br/documentacao/plataforma/workloads/#certificate-manager), e vincula, lado a lado, um firewall, uma aplicação e um conjunto de custom pages.
2. Um [firewall](/pt-br/documentacao/plataforma/firewall/) inspeciona cada requisição antes da aplicação. Você aplica a ele um rule set de [WAF](/pt-br/documentacao/plataforma/firewall/waf/), [Bot Manager](/pt-br/documentacao/plataforma/firewall/bot-manager/), listas do [Network Shield](/pt-br/documentacao/plataforma/firewall/network-shield/) e funções. [DDoS Protection](/pt-br/documentacao/plataforma/workloads/#ddos-protection) está sempre ativa, com ou sem firewall.
3. Uma [aplicação](/pt-br/documentacao/plataforma/applications/) serve o conteúdo. [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/) decide o que fazer com cada requisição, como redirecioná-la ou alterar os cabeçalhos dela. [Cache](/pt-br/documentacao/plataforma/applications/cache/) guarda uma cópia de uma resposta e responde às requisições repetidas a partir dela, sem ir à origem. [Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/) redimensiona e otimiza imagens antes de elas serem entregues. [Functions](/pt-br/documentacao/plataforma/functions/) executa o seu próprio código no caminho da requisição.
4. Um conjunto de [custom pages](/pt-br/documentacao/plataforma/workloads/#custom-pages) substitui as respostas de erro padrão por páginas que você controla.
5. Quando o cache não consegue responder, a aplicação busca o conteúdo por um [connector](/pt-br/documentacao/plataforma/connectors/): um connector HTTP alcança o seu servidor de origem, e um [connector de storage](/pt-br/documentacao/plataforma/connectors/configuracoes/#storage) lê um bucket do Object Storage. [Load Balancer](/pt-br/documentacao/plataforma/connectors/load-balancer/) e [Origin Shield](/pt-br/documentacao/plataforma/connectors/origin-shield/) são habilitados no connector.
6. Suas funções podem ler e gravar dados no [SQL Database](/pt-br/documentacao/plataforma/sql-database/), no [KV Store](/pt-br/documentacao/plataforma/kv-store/) e no [Object Storage](/pt-br/documentacao/plataforma/object-storage/), e chamar modelos de AI pelo [AI Inference](/pt-br/documentacao/plataforma/ai-inference/).

Se a sua aplicação já roda em outro provedor, consulte [Migrar para a Azion](/pt-br/documentacao/fundamentos/migrar-para-a-azion/) para trazê-la.

## Interfaces

Você cria e gerencia cada recurso pelas interfaces da plataforma. [Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/conhecendo-o-azion-console/) é a interface web, [Azion CLI](/pt-br/documentacao/devtools/cli/) executa as mesmas operações a partir do terminal, a [Azion API](https://api.azion.com/) as expõe por HTTPS para integrações e o [Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/) as declara como código. O catálogo da Azion agrupa o que você habilita nesses recursos em quatro categorias: Build, Store, Secure e Observe. Para o caminho da requisição e a tabela do que cada recurso guarda, consulte [Como a Azion funciona](/pt-br/documentacao/fundamentos/como-funciona/).

## Sua conta

Tudo o que você constrói na Azion vive dentro de uma [conta](/pt-br/documentacao/fundamentos/account-settings/). A conta guarda os recursos, as pessoas que trabalham neles, o perfil de faturamento e os controles de segurança que se aplicam a cada login. Cada pessoa entra como um usuário da conta. O proprietário da conta cria as equipes e define suas permissões, e cada usuário pertence a uma ou mais equipes que decidem quais recursos ele pode ver ou alterar. Uma conta do tipo *Reseller* também guarda [contas de clientes](/pt-br/documentacao/fundamentos/contas/), cada uma com o próprio proprietário. O uso é medido por conta e vira uma fatura na página de [Faturamento](/pt-br/documentacao/fundamentos/billing-and-subscriptions/).

Se você ainda não tem uma conta, crie uma no Azion Console. Para o passo a passo, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/). Para o modelo completo, consulte [Contas, equipes e usuários](/pt-br/documentacao/fundamentos/contas-equipes-e-usuarios/).
