Definições dos termos que a documentação de **AI Inference** usa.

| Termo | Definição |
| --- | --- |
| AI Inference | Um recurso da plataforma que executa modelos de AI open source na infraestrutura distribuída da Azion, em resposta às chamadas que as suas Functions enviam. Uma [Function](/pt-br/documentacao/plataforma/functions/) chama um modelo com `Azion.AI.run`, então você não provisiona infraestrutura para executar um. [AI Inference](/pt-br/documentacao/plataforma/ai-inference/) descreve o caminho da requisição e o escopo. |
| AI Inference Starter Kit | Um template do Azion Console que implanta uma Application que serve uma API compatível com OpenAI, com a Function que chama o modelo. O [AI Inference Starter Kit](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/ai-inference-starter-kit/) também cria o Workload e o deployment dele, e a API responde no workload domain. |
| Azion Runtime | O runtime JavaScript de [Functions](/pt-br/documentacao/plataforma/functions/), que executa o handler de uma Function na infraestrutura distribuída da Azion. `Azion.AI.run` é uma das APIs da Azion desse runtime, então a Function que chama um modelo executa no [Azion Runtime](/pt-br/documentacao/devtools/runtime/). |
| `Azion.AI.run` | O binding de runtime que uma Function chama para executar um modelo. Ele recebe o id do modelo e um corpo de requisição, e nenhuma credencial, e resolve no objeto de resposta, como um `chat.completion` para um modelo de chat, ou num iterador de partes quando `stream` é `true`. [Invocação de modelos](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/) documenta cada campo. |
| Compute Time | O medidor de uso de AI Inference e de LoRA Fine-Tune: a duração da execução ativa em horas multiplicada pela memória alocada em gigabytes, expressa em GB-hora. A [página de preços](/pt-br/documentacao/fundamentos/precos/#ai-inference) informa a tarifa. |
| id do modelo | A string que seleciona um modelo: o primeiro argumento de `Azion.AI.run`, ou o campo `model` do corpo de uma requisição HTTP. Duas formas selecionam o mesmo modelo, um caminho de repositório como `Qwen/Qwen3-Embedding-4B` e uma forma em minúsculas como `qwen-qwen3-embedding-4b`. Cada [página de modelo](/pt-br/documentacao/plataforma/ai-inference/modelos/) indica um id a usar, e `Azion.AI.models()` retorna os ids que a sua conta pode chamar. |
| LoRA Fine-Tune | Um recurso da plataforma que estende [AI Inference](/pt-br/documentacao/plataforma/ai-inference/) com o fine-tuning de modelos suportados por meio de Low-Rank Adaptation, na infraestrutura da Azion. As [páginas de modelo](/pt-br/documentacao/plataforma/ai-inference/modelos/) indicam quais modelos o suportam, e [LoRA Fine-Tune](/pt-br/documentacao/plataforma/ai-inference/lora-fine-tune/) o descreve. |
| OpenAI-compatible API | O endpoint HTTP que uma Application implantada a partir do [AI Inference Starter Kit](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/ai-inference-starter-kit/) serve no domínio dela. Ele recebe um corpo de requisição no formato de chat completions da OpenAI, com o id do modelo em `model`, e o repassa para `Azion.AI.run`. [Invocação de modelos](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/) documenta o corpo e a resposta. |
| workload domain | O hostname somente leitura que a Azion atribui a um [Workload](/pt-br/documentacao/plataforma/workloads/) na criação, no formato `<id>.map.azionedge.net` na infraestrutura de produção. Uma Application implantada a partir do AI Inference Starter Kit serve a API compatível com OpenAI nesse domínio. O [glossário de Workloads](/pt-br/documentacao/plataforma/workloads/glossario/) o define por completo. |
