Você pode criar e excluir um [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) pelo Azion Console ou com a [Azion CLI](/pt-br/documentacao/devtools/cli/). Um personal token autentica as suas requisições à [Azion API](/pt-br/documentacao/devtools/api/) e os comandos que você executa na CLI. Para revogar um token, exclua-o.

## Crie um personal token

Cada personal token tem um nome, uma descrição opcional e uma expiração. A Azion exibe o valor do token somente quando o token é criado, então guarde-o antes de continuar.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para criar um personal token no Azion Console:

<DocSteps>
  <DocStep title="Abra a página Personal Tokens">

  Acesse [Azion Console](https://console.azion.com/) > **Account** > **Personal Token**. **Account** é o menu do avatar.

  </DocStep>
  <DocStep title="Selecione + Personal Token" />
  <DocStep title="Dê um nome ao token">

  Na seção **General**, insira um **Name** que identifique o token.

  </DocStep>
  <DocStep title="(Opcional) Descreva o token">

  Em **Description**, insira a finalidade do token.

  </DocStep>
  <DocStep title="Defina a expiração">

  Na seção **Token**, selecione um valor em **Expires within**. O padrão é _1 day_. Os outros valores são:

  - _7 days_, _15 days_, _30 days_ ou _90 days_
  - _1 year_
  - _Custom Date_, que abre um calendário para selecionar a data

  </DocStep>
  <DocStep title="Selecione Save" />
  <DocStep title="Copie o token">

  Na caixa de diálogo **Personal Token has been created**, selecione **Copy**. O campo **Personal Token** mascara o valor até que você o exiba.

  </DocStep>
  <DocStep title="Selecione Confirm" />
</DocSteps>

O token aparece na página **Personal Tokens** com a sua **Expiration Date**. Depois que a caixa de diálogo fecha, o valor não pode ser recuperado, e um token perdido precisa ser substituído por um novo.

</Fragment>

<Fragment slot="panel.cli">

Para criar um personal token com a Azion CLI, informe um nome, uma expiração e uma descrição opcional. Este comando cria um token chamado `my-token` que expira no dia seguinte:

```bash
azion create personal-token --name my-token --expiration 1d --description 'Token for local CLI tests'
```

O comando imprime o valor do token:

```text
Created Personal Token: [TOKEN VALUE]
```

A flag `--expiration` recebe um número seguido de `d` para dias ou de `m` para meses, como `1d` ou `9m`. Nenhum outro comando `personal-token` imprime o valor. Para criar o token a partir de um arquivo JSON com as chaves `name`, `expires_at` e `description`, consulte [Azion CLI personal-token](/pt-br/documentacao/devtools/cli/recursos/personal-token/).

</Fragment>

</Tabs>

## Exclua um personal token

Excluir um personal token o revoga, e a exclusão não pode ser desfeita. O Azion Console pede que você confirme a exclusão com o nome do token, e a Azion CLI recebe o UUID do token.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para excluir um personal token no Azion Console:

<DocSteps>
  <DocStep title="Abra a página Personal Tokens">

  Acesse [Azion Console](https://console.azion.com/) > **Account** > **Personal Token**. **Account** é o menu do avatar.

  </DocStep>
  <DocStep title="Selecione Delete no token">

  Na linha do token, selecione **Delete**. A caixa de diálogo **Delete personal token** abre.

  </DocStep>
  <DocStep title="Insira o nome do token">

  No campo da caixa de diálogo, insira o nome do token, como o rótulo de confirmação o cita.

  </DocStep>
  <DocStep title="Selecione Delete" />
</DocSteps>

A mensagem **Personal token successfully deleted** aparece, e o token não aparece mais na página **Personal Tokens**.

</Fragment>

<Fragment slot="panel.cli">

A Azion CLI exclui um personal token pelo UUID dele. Para encontrar o UUID, liste os seus personal tokens:

```bash
azion list personal-token
```

O comando imprime o UUID, o nome e a expiração de cada token, nunca o valor dele:

```text
ID                                    NAME                               EXPIRES AT
11111111-2222-4333-8444-555555555555  my-token                           2027-01-15 23:59:59 +0000 UTC
22222222-3333-4444-8555-666666666666  ci-deploy                          2026-12-20 23:59:59 +0000 UTC
33333333-4444-4555-8666-777777777777  cli-local                          2027-09-17 23:59:59 +0000 UTC
44444444-5555-4666-8777-888888888888  old-token                          2026-09-11 23:59:59 +0000 UTC
```

Um token que passou da expiração, como `old-token`, permanece na lista até que você o exclua.

Para excluir o token, informe o UUID dele em `--id`. Este comando exclui o token chamado `my-token`:

```bash
azion delete personal-token --id 11111111-2222-4333-8444-555555555555
```

O comando exclui o token sem pedir confirmação e imprime:

```text
Personal token 11111111-2222-4333-8444-555555555555 was successfully deleted
```

</Fragment>
