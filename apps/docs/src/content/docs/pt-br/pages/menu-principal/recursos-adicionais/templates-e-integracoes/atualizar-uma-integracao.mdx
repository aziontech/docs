Você verifica se uma integração instalada do Marketplace tem uma versão mais recente, instala essa versão e move uma function instance para ela, pelo Azion Console. Para instalar uma integração pela primeira vez, consulte [Instale uma integração](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/instalar-uma-integracao/).

As integrações mudam com o tempo: a Azion e os parceiros dela publicam novas versões conforme adicionam recursos. Instalar uma nova versão não muda a versão que suas instâncias executam. Uma instância mantém a versão dela até que você selecione a nova nas configurações dela.

---

## Pré-requisitos

- Uma conta Azion. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma integração instalada pelo Azion Marketplace.
- Para a última seção, uma aplicação ou um firewall com uma function instance dessa integração.

---

## Verifique se há uma versão mais recente

A página da integração no Marketplace mostra se sua conta executa a versão mais recente dela. Para verificar:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace**.

  </DocStep>
  <DocStep title="Abra a página da integração">

  Insira o nome da integração no campo **Search on Marketplace** e selecione o card dela.

  </DocStep>
  <DocStep title="Leia o estado da versão">

  O campo **Version** mostra a versão que o Marketplace oferece. Quando a versão instalada é mais antiga, o botão **Get New Version** fica ativado. Quando ela está atualizada, a página exibe `Latest version installed!`.

  </DocStep>
</DocSteps>

Você sabe se existe uma versão mais recente. A lista **Application** do drawer **Install an Integration** também pode marcar uma aplicação com `Update Available`.

---

## Instale a nova versão

A nova versão é instalada ao lado da que suas instâncias executam, então nada muda no tráfego até que você mova uma instância. Para instalá-la:

<DocSteps>
  <DocStep title="Abra a página da integração">

  Acesse [Azion Console](https://console.azion.com/) > **Marketplace** e selecione o card da integração.

  </DocStep>
  <DocStep title="Selecione Get New Version">

  O Console avisa: `Updating will create a new instance of the integration's function.`

  </DocStep>
</DocSteps>

A página da integração exibe `Latest version installed!`. Suas instâncias existentes ainda executam a versão anterior.

---

## Mova uma instância para a nova versão

Teste a nova versão antes que o tráfego de produção chegue a ela. Mova primeiro uma instância em uma aplicação de teste e depois mova a instância de produção, quando a nova versão passar na sua validação. Para mover uma instância:

<DocSteps>
  <DocStep title="Abra o recurso que contém a instância">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** ou **Firewalls** e selecione a aplicação ou o firewall.

  </DocStep>
  <DocStep title="Abra a aba Functions Instances" />
  <DocStep title="Selecione a instância" />
  <DocStep title="Selecione a nova versão">

  Em **Function**, selecione a nova versão da integração.

  </DocStep>
  <DocStep title="Confira os argumentos">

  Em **Arguments**, confirme que o JSON ainda contém seus valores.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância executa a nova versão. As regras que executam a instância não precisam de alteração, porque apontam para a instância e não para a versão da function.
