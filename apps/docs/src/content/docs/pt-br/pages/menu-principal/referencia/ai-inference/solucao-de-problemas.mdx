Esta página cobre os sintomas de uma chamada de modelo ao [AI Inference](/pt-br/documentacao/plataforma/ai-inference/), feita por uma Function com `Azion.AI.run` ou enviada ao endpoint do AI Inference Starter Kit. Um erro citado do binding é a `message` do erro que `Azion.AI.run` lança. Um erro citado do endpoint é o campo `error` da resposta JSON dele.

---

## Uma chamada de modelo falha com model not found or not allowed

`Azion.AI.run` lança este erro, e o modelo não executa:

```text
AIError: model not found or not allowed
```

O id do modelo não existe, ou a conta não tem acesso ao AI Inference. A mensagem não diz qual dos dois. Um valor de `model` copiado de uma resposta anterior também pode falhar, porque a resposta traz o id interno da conta, que o binding pode recusar como entrada.

- **Copie o id da página do modelo**: cada página em [Modelos de AI](/pt-br/documentacao/plataforma/ai-inference/modelos/#ids-de-modelo) informa um id que responde.
- **Liste os ids que a conta pode chamar**: `Azion.AI.models()` os retorna, como mostra [Listar modelos](/pt-br/documentacao/devtools/runtime/api-reference/ai/#listar-modelos).
- **Confira o acesso do plano**: nos planos Hobby e Pro, AI Inference está disponível sob solicitação, conforme [Acesso por plano](/pt-br/documentacao/plataforma/ai-inference/limites/#acesso-por-plano).

Com um id dessa lista, a chamada retorna a resposta do modelo.

## Uma chamada de modelo falha com um erro de validação

`Azion.AI.run` lança um erro que nomeia um tipo e um campo, e o modelo não executa:

```text
AIError: validation error: Required {
    path: "/query",
}
```

O corpo da requisição não corresponde ao schema do modelo. `Required` marca um campo ausente, `WrongType` um valor do tipo errado, `Minimum` ou `Maximum` um valor além de um limite, `Enum` um valor fora de um conjunto fixo e `OneOf` uma mensagem que não corresponde a nenhum objeto de mensagem.

- **Corrija o campo que path nomeia**: [Campos da requisição](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#campos-da-requisicao) lista cada campo com o tipo e os limites dele.
- **Use query e documents no reranker**: o reranker BAAI recusa o par `text_1` e `text_2` com `Required`, conforme [Requisições de reranking](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#requisicoes-de-reranking).
- **Escolha uma largura da lista para dimensions**: o Qwen3 Embedding 4B recusa um valor fora da lista dele com `Enum`, conforme [Requisições de embedding](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#requisicoes-de-embedding).

Quando o corpo corresponde ao schema, a chamada retorna a resposta do modelo.

## Uma chamada de modelo falha com Request failed with status 400

`Azion.AI.run` lança um erro que traz um status e nenhum motivo:

```text
Error: Request failed with status 400
```

O servidor do modelo recusou uma requisição que passou na validação. As causas observadas são: uma requisição com `tools` sem `tool_choice` no Qwen2.5 VL AWQ 3B, no Qwen2.5 VL AWQ 7B ou no Nanonets-OCR-s; um prompt maior que o contexto que o modelo serve; `stream_options` sem `stream`; um `tool_choice` desconhecido; um `seed` que não é inteiro; e `temperature` e `top_p` em `0` com as duas penalidades em `-2`.

- **Nomeie a ferramenta nos modelos Qwen2.5 VL**: uma ferramenta nomeada em `tool_choice` retorna `tool_calls`, como mostra [Chamada de ferramentas](/pt-br/documentacao/plataforma/ai-inference/qwen-2-5-vl-3b/#chamada-de-ferramentas). O Nanonets-OCR-s não aceita ferramentas.
- **Encurte o prompt**: [Modelos de AI](/pt-br/documentacao/plataforma/ai-inference/modelos/) informa o comprimento de contexto de cada modelo.
- **Confira os valores na lista**: [Erros](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#erros) lista cada requisição que o servidor do modelo recusa.

Depois da mudança, a chamada retorna a resposta do modelo.

## Uma requisição com imagem falha com Request failed with status 500

Uma requisição com uma parte `image_url` lança este erro:

```text
Error: Request failed with status 500
```

A URL em `image_url.url` não serve uma imagem, então o modelo não tem o que ler.

- **Use uma URL que sirva uma imagem**: uma URL `https` que retorne a imagem, ou uma URL `data:` que carregue a imagem em base64, conforme [Objetos de mensagem](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#objetos-de-mensagem).

Com uma URL que serve uma imagem, o modelo responde em texto.

## O GPT-OSS 20B não retorna conteúdo

Uma resposta do GPT-OSS 20B traz `content` como `null` e `finish_reason` como `length`.

O modelo raciocina antes de responder, e o raciocínio conta no `max_tokens`. Com um `max_tokens` pequeno, o raciocínio usa todo o orçamento, e não sobra texto de resposta. O próprio raciocínio fica em `reasoning_content`.

- **Aumente o max_tokens**: deixe espaço para o raciocínio e para a resposta, como mostra [Chat completion](/pt-br/documentacao/plataforma/ai-inference/gpt-oss-20b/#chat-completion).

Com espaço para os dois, `content` traz a resposta e `finish_reason` é `stop`.

## Um embedding tem 2560 valores em vez de 4096

Uma requisição ao Qwen3 Embedding 4B com `dimensions` definido como `4096` retorna um vetor de 2560 valores, que não corresponde a uma coluna vetorial declarada para 4096 valores.

O modelo aceita `4096`, mas o maior vetor dele tem 2560 valores. Uma requisição sem `dimensions` também retorna 2560 valores.

- **Peça uma largura que o modelo retorna**: `256`, `512`, `1024` ou `2048` retornam essa largura, conforme [Embedding](/pt-br/documentacao/plataforma/ai-inference/qwen3-embedding-4b/#embedding).
- **Dimensione a coluna para 2560 valores**: quando a requisição pede `4096` ou nenhuma largura, declare a coluna vetorial com 2560 valores.

O vetor e a coluna passam a ter a mesma largura.

## Um campo da requisição não tem efeito

Um campo no corpo da requisição não muda nada na resposta, e nenhum erro é retornado.

O binding aceita um campo que o modelo não conhece e o ignora, então um nome de campo escrito errado passa sem aviso. Um campo `model` no corpo também é ignorado: o primeiro argumento de `Azion.AI.run` decide o modelo.

- **Escreva o campo como a referência o lista**: [Campos da requisição](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#campos-da-requisicao) traz cada nome.
- **Passe o id do modelo como primeiro argumento**: altere o primeiro argumento de `Azion.AI.run` para chamar outro modelo.

Com o campo escrito como listado, a resposta o reflete.

## Azion.AI é undefined quando a Function roda localmente

Sob `azion dev`, uma chamada a `Azion.AI.run` lança este erro:

```text
TypeError: Cannot read properties of undefined (reading 'run')
```

`Azion.AI` só existe em uma Function implantada. Sob `azion dev`, ele é `undefined`, conforme a [API de AI Inference](/pt-br/documentacao/devtools/runtime/api-reference/ai/).

- **Teste as chamadas de modelo em uma Function implantada**: implante a Function e envie a requisição ao domínio dela.

Em uma Function implantada, a chamada retorna a resposta do modelo.

## O endpoint responde Request must be a POST request with JSON body

O endpoint do AI Inference Starter Kit responde `400` com este corpo:

```json
{"error":"Request must be a POST request with JSON body"}
```

A Function que o template instala aceita só uma requisição `POST` cujo header `Content-Type` seja exatamente `application/json`. Um navegador que abre o domínio envia um `GET`, e um cliente que acrescenta `; charset=utf-8` ao header também é recusado.

- **Envie uma requisição POST**: os [primeiros passos](/pt-br/documentacao/plataforma/ai-inference/primeiros-passos/#envie-uma-requisicao-ao-modelo) mostram uma com `curl`.
- **Envie o header sem parâmetro**: defina `Content-Type` como `application/json`.

O endpoint então retorna a resposta do modelo.

---

## O endpoint responde Missing model field ou Invalid JSON

O endpoint do AI Inference Starter Kit responde `400` com um destes corpos:

```json
{"error":"Missing 'model' field in request body"}
{"error":"Invalid JSON in request body"}
```

A Function que o template instala lê o id do modelo do campo `model` do corpo. Um corpo sem `model`, ou um corpo que não é um JSON válido, para antes da chamada de modelo.

- **Acrescente o campo model**: defina `model` como um id de [Modelos de AI](/pt-br/documentacao/plataforma/ai-inference/modelos/).
- **Envie um JSON válido**: confira as aspas do corpo que o seu cliente envia.

O endpoint então retorna a resposta do modelo.

---

## O endpoint responde AI internal error

O endpoint do AI Inference Starter Kit responde `500` com este corpo:

```json
{"error":"AI internal error"}
```

O binding lançou um erro diferente de `model not found or not allowed` e de um erro de validação, como uma recusa do servidor do modelo. O corpo não traz esse erro, mas a Function que o template instala o escreve no console.

- **Leia a linha de console da requisição**: a fonte de dados [Functions Console](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/#functions-console) do Real-Time Events traz as linhas que uma Function escreve, incluindo o nome e a mensagem do erro.
- **Associe a mensagem à causa dela**: as entradas acima cobrem cada mensagem observada.

A linha de console nomeia a recusa, e a correção para essa mensagem se aplica.

---

## O endpoint responde 404 logo depois da implantação

Logo depois que você implanta o AI Inference Starter Kit, o domínio em **Visit site** responde `404` com a página de placeholder da Azion.

A implantação ainda não se propagou aos data centers da Azion. A propagação leva vários minutos.

- **Repita a requisição depois de alguns minutos**: como descreve [Abra o workload domain](/pt-br/documentacao/plataforma/ai-inference/primeiros-passos/#abra-o-workload-domain).

Quando a implantação se propaga, o domínio responde com a resposta da Function.

---

## Application Name é recusado quando você implanta o template

Quando você implanta o AI Inference Starter Kit, o campo **Application Name** mostra esta mensagem:

```text
The use of accents and/or special characters is not allowed.
```

O campo aceita só letras, números e sublinhados, então um hífen é recusado.

- **Use sublinhados**: insira um nome como `ai_inference_starter_kit`, o padrão.

O botão **Deploy** então implanta o template.
