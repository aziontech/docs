Este guia orienta você na instalação da sua primeira integração do [Marketplace](/pt-br/documentacao/plataforma/marketplace/) em uma aplicação. Ao final, você terá:

- A integração [Hello World](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/hello-world/) instalada em uma das suas aplicações.
- Uma página no navegador que exibe a mensagem do Hello World.

Dois objetos participam. A **integração** vem do Marketplace e carrega uma function e os argumentos dela. A **aplicação** a executa: quando você instala o Hello World, o drawer de instalação instancia a integração na aplicação que você seleciona. O Hello World recebe dois argumentos, `Status` e `Body`, e você os define no mesmo drawer.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Crie uma conta Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma [aplicação](/pt-br/documentacao/plataforma/applications/) servida por um [workload](/pt-br/documentacao/plataforma/workloads/). O drawer de instalação lista suas aplicações. Para criar uma, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

## Instale o Hello World

O Hello World não está entre os cards **Featured**, então encontre-o com o campo de busca. Para iniciar a instalação pelo Azion Console:

<DocSteps>
  <DocStep title="Abra o Marketplace">

  No [Azion Console](https://console.azion.com/), abra o **Products menu** e selecione **Marketplace**.

  </DocStep>
  <DocStep title="Busque a integração">

  No campo **Search on Marketplace**, insira `Hello World`. O card exibe `Use the Hello World integration to start creating new resources at the edge.`

  </DocStep>
  <DocStep title="Abra a página da integração">

  Selecione o card **Hello World**.

  </DocStep>
  <DocStep title="Selecione Install" />
</DocSteps>

O drawer **Install an Integration** abre.

Para encontrar outras integrações, insira um nome ou uma palavra-chave em **Search on Marketplace**, ou filtre os cards por **Categories**.

---

## Configure e implante

O drawer instala o Hello World em uma aplicação, com os argumentos que você define. Para concluir a instalação:

<DocSteps>
  <DocStep title="Selecione a aplicação">

  Na seção **Select an Application**, abra a lista **Application** e selecione a aplicação que executa o Hello World.

  Se a lista estiver vazia, selecione **Create New**, crie uma aplicação e inicie a instalação de novo pela página do Hello World.

  </DocStep>
  <DocStep title="Defina os argumentos">

  Na seção **General**, defina os dois argumentos do Hello World:

  - `Status`: o código de status HTTP da resposta. O padrão é `200`, uma requisição bem-sucedida.
  - `Body`: o texto que a página exibe. Aceita qualquer string. O padrão é `Hello World!`.

  </DocStep>
  <DocStep title="Revise as permissões">

  O bloco de permissões lista os privilégios que o Marketplace exige na aplicação selecionada. Para o Hello World, ele lê e grava a aplicação selecionada e exclui as functions para instanciar a nova integração na aplicação selecionada. Para todos os privilégios, consulte [Permissões do Marketplace](/pt-br/documentacao/plataforma/marketplace/permissoes-marketplace/).

  </DocStep>
  <DocStep title="Selecione Deploy" />
</DocSteps>

Uma mensagem confirma que a integração foi instalada com sucesso. O Hello World roda na aplicação que você selecionou.

---

## Veja o resultado

Abra o domínio da sua aplicação em um navegador. A página exibe o texto de `Body`: `Hello World!` com os argumentos padrão.
