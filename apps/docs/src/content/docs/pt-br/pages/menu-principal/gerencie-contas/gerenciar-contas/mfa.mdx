Você pode ativar a [autenticação multifator (MFA)](/pt-br/documentacao/fundamentos/multi-factor-authentication/) para um usuário ou para todos os usuários de uma conta pelo Azion Console. Com a MFA ativa, o usuário faz login com a senha e um código de seis dígitos de um aplicativo autenticador. Para recuperar o acesso depois de perder o dispositivo que roda o autenticador, consulte [Solucionar problemas de acesso ao Azion Console](/pt-br/documentacao/suporte/acesso-a-conta/).

---

## Pré-requisitos

- Acesso ao Azion Console como **Account owner**. Para fazer login, consulte [Acesse o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Um aplicativo autenticador em um celular para cada usuário que ativa a MFA, como Google Authenticator ou Microsoft Authenticator. Instale-o pela loja de aplicativos do sistema operacional do celular.

---

## Ative a MFA para um usuário

Um Account owner ativa a MFA para qualquer usuário da conta, inclusive o próprio, em **Users Management**.

Para ativar a MFA para um usuário no Azion Console:

<DocSteps>
  <DocStep title="Abra o Users Management">

  Acesse [Azion Console](https://console.azion.com/) e, no menu da conta, selecione **Users Management**.

  </DocStep>
  <DocStep title="Selecione o usuário" />
  <DocStep title="Ative a MFA">

  Na seção **Security Settings**, ative **Enforce Multi-Factor Authentication**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

No próximo login do usuário, o Azion Console abre a página de configuração da MFA.

---

## Exija a MFA de todos os usuários da conta

A configuração da conta torna a MFA obrigatória para todos os usuários vinculados à conta. Enquanto ela está ativa, um Account owner não consegue desativar a MFA de um único usuário.

Para exigir a MFA de todos os usuários no Azion Console:

<DocSteps>
  <DocStep title="Abra o Account Settings">

  Acesse [Azion Console](https://console.azion.com/) e, no menu da conta, selecione **Account Settings**.

  </DocStep>
  <DocStep title="Ative a exigência">

  Na seção **Login Settings**, ative **Enforce Multi-Factor Authentication**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

Todo usuário vinculado à conta precisa configurar a MFA no próximo login. Para encerrar a exigência, desative **Enforce Multi-Factor Authentication** na mesma seção e selecione **Save**.

---

## Conecte o aplicativo autenticador

A página de configuração da MFA mostra um QR code no primeiro login depois que a MFA é ativada. O aplicativo autenticador lê o código e passa a gerar códigos de seis dígitos para o seu usuário da Azion.

Para conectar o aplicativo autenticador:

1. No aplicativo autenticador, selecione **+**.
2. Selecione o tipo de conta a adicionar. A câmera do celular é aberta.
3. Escaneie o QR code da página de configuração da MFA.
4. Na página de configuração da MFA, digite o código de seis dígitos e selecione **Verify code**.

O Azion Console conclui o login. A partir daí, cada login pede um código do mesmo celular.

---

## Faça login com a MFA

Para fazer login no Azion Console com a MFA ativa:

1. Na página de login do Azion Console, digite seu email e sua senha e selecione **Sign In**.
2. Abra o aplicativo autenticador no celular.
3. No Azion Console, digite o código de seis dígitos e selecione **Verify**.

O Azion Console abre depois que o código é verificado.

---

## Desative a MFA de um usuário

Um usuário que perde o celular com o autenticador não consegue fazer login até que um Account owner desative a MFA dele. O Account owner só consegue fazer isso quando **Enforce Multi-Factor Authentication** está desativado em **Account Settings**.

Para desativar a MFA de um usuário no Azion Console:

<DocSteps>
  <DocStep title="Abra o Users Management">

  Acesse [Azion Console](https://console.azion.com/) e, no menu da conta, selecione **Users Management**.

  </DocStep>
  <DocStep title="Selecione o usuário" />
  <DocStep title="Desative a MFA">

  Na seção **Security Settings**, desative **Enforce Multi-Factor Authentication**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O usuário faz login apenas com email e senha. Quando o usuário bloqueado é o único Account owner da conta, o Suporte da Azion redefine a MFA. Para entrar em contato, consulte [Abra um ticket de suporte](/pt-br/documentacao/suporte/abrir-tickets/).
