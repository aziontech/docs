## Acesso à plataforma Azion

O Claude Desktop alcança a Azion pelos servidores MCP: eles consultam informações e criam configuração pela API.

### Servidores MCP

Cinco servidores, um por área da plataforma. Cada um é um endpoint HTTP que recebe seu Personal Token em um cabeçalho `Authorization: Token`. O início rápido conecta o servidor de docs. Conecte os outros da mesma forma, com as URLs abaixo, e apenas os que o projeto precisa. O servidor de docs apenas lê. Os outros quatro também criam, alteram e excluem, e as ferramentas de escrita deles mostram uma alteração sem executá-la quando o agente define `dry_run`:

## Dicas

<DocCallout kind="tip">O Claude Desktop registra cada conexão MCP. O `mcp.log` registra as falhas de conexão, e o `mcp-server-azion-docs.log` guarda a saída da ponte `mcp-remote`. Os logs ficam em `~/Library/Logs/Claude` no macOS e em `%APPDATA%\Claude\logs` no Windows.</DocCallout>

<DocCallout kind="tip">Peça uma prévia com `dry_run` antes de uma escrita. Os servidores de build, secure, observe e storage alteram sua conta pela API.</DocCallout>
