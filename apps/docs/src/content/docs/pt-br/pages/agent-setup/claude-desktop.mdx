## Acesso à plataforma Azion

O Claude Desktop alcança a Azion pelos MCP servers, que consultam informações e alteram a sua configuração pela Azion API.

### MCP servers

A Azion mantém cinco MCP servers, um por área da Azion Platform. Cada um é um endpoint HTTP que recebe o seu personal token no header `Authorization: Token [TOKEN VALUE]`. O início rápido conecta o servidor de docs, e você conecta os outros da mesma forma, com as URLs desta tabela.

Conecte apenas os servidores de que o trabalho precisa. O servidor de docs apenas lê. Os outros quatro também criam, alteram e excluem, e cada ferramenta de escrita deles mostra uma prévia da alteração sem fazê-la quando o agente define `dry_run`:

## Dicas

<DocCallout kind="tip">O Claude Desktop grava os logs de MCP em arquivos `mcp*.log`. O `mcp.log` registra as falhas de conexão, e o `mcp-server-azion-docs.log` guarda a saída da ponte `mcp-remote`. Os logs ficam em `~/Library/Logs/Claude` no macOS, em `%APPDATA%\Claude\logs` no Windows e em `~/.config/Claude/logs` no Linux.</DocCallout>

<DocCallout kind="tip">Peça uma prévia com `dry_run` antes de uma escrita. Os servidores de build, secure, observe e storage alteram a sua conta pela Azion API.</DocCallout>
