Cada MCP server da Azion é um endpoint HTTP. Para conectar um cliente que esta página não lista, aponte-o para `https://docs-mcp.azion.com/mcp` ou para outro dos cinco servidores e envie o seu [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) no header `Authorization: Token [TOKEN VALUE]`. Um cliente que inicia apenas servidores locais chega ao endpoint por meio do [`mcp-remote`](/pt-br/documentacao/devtools/mcp/glossario/). Para mais informações, consulte [Primeiros passos com o MCP server](/pt-br/documentacao/devtools/mcp/primeiros-passos/).

## Tipos de agentes e conceitos

Estes cards definem os fluxos de trabalho e os termos que a tabela de comparação usa, e os compromissos entre eles.

### Fluxo de trabalho

<DocCardGroup cols={2}>
	<DocCard title="Terminal" icon="pi pi-desktop" label="Um agente que você executa como um comando em um shell. Use-o para automação, scripts e pipelines de CI." />
	<DocCard title="IDE" icon="pi pi-code" label="Um editor construído em torno do seu agente, com diffs visuais e edições em vários arquivos." />
	<DocCard title="Extensão" icon="pi pi-th-large" label="Um agente instalado dentro de um editor que você já usa, então as configurações do seu editor continuam como estão." />
	<DocCard title="Desktop" icon="pi pi-window-maximize" label="Um app de chat instalado no seu computador, fora do editor e do terminal. Ele se conecta aos MCP servers como qualquer outro cliente." />
	<DocCard title="Nuvem" icon="pi pi-cloud" label="Um agente que roda nos servidores do seu fornecedor, sem nada para instalar. Use-o para tarefas longas que rodam enquanto você faz outro trabalho. Copilot, o assistente do Azion Console, é hospedado da mesma forma." />
</DocCardGroup>

### Conceitos-chave

<DocCardGroup cols={2}>
	<DocCard title="MCP" icon="pi pi-server" label="O Model Context Protocol, um padrão aberto que define como um agente lista as ferramentas de um servidor e as chama. A Azion opera cinco MCP servers, um por área da Azion Platform." />
	<DocCard title="Contexto do agente" icon="pi pi-file" label="O arquivo de convenções do projeto que um agente lê no início de cada sessão, como AGENTS.md, CLAUDE.md ou GEMINI.md. Um agente lê o llms.txt, o índice da documentação, apenas quando o busca." />
	<DocCard title="Modelo" icon="pi pi-sliders-h" label="Fixo significa que o agente roda apenas os modelos do seu fabricante. Multiprovedor significa que você escolhe entre modelos de vários provedores, e alguns desses agentes também aceitam a sua própria chave de API." />
	<DocCard title="Preço" icon="pi pi-wallet" label="Pago significa que o agente exige um plano pago ou uma chave de API paga. Plano gratuito significa que existe um plano gratuito, com planos pagos para mais uso. Seu provedor significa que o agente é gratuito, e você paga o provedor de modelos que conectar." />
	<DocCard title="Contexto" icon="pi pi-database" label="Sessão significa que o agente não guarda nada depois que a conversa termina. Memória de projeto significa que ele lê um arquivo de convenções no início de cada sessão. Codebase indexado significa que ele também mantém um índice pesquisável do repositório." />
</DocCardGroup>

### Compromissos comuns

<DocCardGroup cols={2}>
	<DocCard title="Nuvem vs. local" icon="pi pi-cloud-upload" label="Um agente na nuvem trabalha em uma cópia do seu repositório nos servidores do seu fornecedor, então uma tarefa longa não precisa do seu computador. Um agente local trabalha nos arquivos do seu computador e para quando o seu computador para." />
	<DocCard title="Proprietário vs. código aberto" icon="pi pi-github" label="Um agente de código aberto publica o código do seu cliente sob uma licença de código aberto, então você pode ler, auditar e alterá-lo. O código de um agente proprietário é fechado, então só o seu fornecedor pode alterá-lo." />
	<DocCard title="Fixo vs. multiprovedor" icon="pi pi-key" label="Um agente fixo roda os modelos de um fabricante, cobrados por esse fabricante. Um agente multiprovedor permite escolher o modelo de cada tarefa e, com a sua própria chave de API, você paga a esse provedor pelo que usar." />
	<DocCard title="Sessão vs. codebase indexado" icon="pi pi-search" label="Um agente com um índice pode pesquisar código que a conversa nunca abriu. Um agente sem índice conhece apenas os arquivos que abre e o texto que você fornece." />
</DocCardGroup>
