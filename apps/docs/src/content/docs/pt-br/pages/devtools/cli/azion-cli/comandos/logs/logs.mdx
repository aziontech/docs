Os comandos `logs` da Azion CLI imprimem logs recentes no terminal. `azion logs cells` mostra os logs de console das suas [functions](/pt-br/documentacao/plataforma/functions/), e `azion logs http` mostra os logs de eventos HTTP das suas [aplicações](/pt-br/documentacao/plataforma/applications/). As opções que todo comando aceita, como `--debug`, `--timeout` e `-c`, estão em [Opções globais da Azion CLI](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion logs` recebe o tipo de log como subcomando, `cells` ou `http`:

```bash
azion logs [flags]
```

O comando não tem flags próprias. `-h` ou `--help` imprime a ajuda do comando, e `azion logs <subcommand> --help` imprime a ajuda de um subcomando.

---

## azion logs cells

`azion logs cells` mostra os logs de console que as suas functions escrevem. `cells` é o nome que a CLI dá aos logs de console de functions. O comando retorna os logs dos últimos 5 minutos:

```bash
azion logs cells [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--function-id` | — | string | — | ID da function cujos logs você quer ver. Sem ela, o comando mostra os logs de todas as functions. |
| `--limit` | — | string | `"100"` | Número de entradas de log que o comando mostra por vez. |
| `--pretty` | — | — | — | Imprime os logs em um layout formatado. |
| `--tail` | — | — | — | Mantém o comando em execução e imprime os logs à medida que chegam, como `tail -f`. Entre um log e outro, imprime `Waiting for the next event...`. |

Para encontrar o ID de uma function, consulte [Azion CLI function](/pt-br/documentacao/devtools/cli/recursos/function/).

---

## azion logs http

`azion logs http` mostra os logs de eventos HTTP das suas aplicações, uma entrada por requisição, da mais antiga para a mais recente. O comando retorna os logs dos últimos 5 minutos:

```bash
azion logs http [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--limit` | — | string | `"100"` | Número de entradas de log que o comando mostra por vez. |
| `--pretty` | — | — | — | Imprime cada campo de uma entrada em sua própria linha. |
| `--tail` | — | — | — | Mantém o comando em execução e imprime os logs à medida que chegam, como `tail -f`. Entre um log e outro, imprime `Waiting for the next event...`. |

Cada entrada traz, para uma requisição, o timestamp, o host, a URI da requisição, o status, o user agent, o nome da região, os bytes enviados, o tempo da requisição e o método da requisição.

---

## Exemplos

Estes exemplos leem os logs de eventos HTTP de uma aplicação que serve um site estático.

### Mostrar logs de eventos HTTP

Este comando mostra cinco logs de eventos HTTP:

```bash
azion logs http --limit 5
```

### Mostrar logs de eventos HTTP campo a campo

Este comando mostra dois logs de eventos HTTP no layout legível:

```bash
azion logs http --limit 2 --pretty
```

O comando imprime cada campo em sua própria linha, com uma linha em branco entre as requisições:


