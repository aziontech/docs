O comando `logout` da Azion CLI faz logout da sua conta da Azion e remove o [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) que `azion login` salvou localmente. Use-o para encerrar a sua sessão ou antes de fazer login com outra conta na mesma máquina. As opções que todo comando aceita, como `--config` e `--debug`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion logout` remove o personal token do perfil ativo:

```bash
azion logout [flags]
```

O comando não tem flags próprias. `-h` ou `--help` imprime a ajuda do comando.

Depois do logout, um comando que exige autenticação só volta a funcionar depois que você executa `azion login`.

---

## Exemplos

Este comando faz logout do perfil ativo:

```bash
azion logout
```

O comando confirma o logout:

```text
successfully logged out
```

O comando esvazia o personal token armazenado. O perfil mantém o seu client ID e o seu email.
