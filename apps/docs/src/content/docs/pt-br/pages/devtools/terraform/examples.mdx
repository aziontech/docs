O Azion Terraform Provider v2.0 configura a Azion Platform com dois tipos de bloco. Um recurso cria, atualiza e exclui um objeto na Azion, e um data source consulta informações sobre objetos que já existem. Um nome no singular, como `azion_workload`, costuma ser ao mesmo tempo um recurso e o data source que lê um objeto, e o seu plural, `azion_workloads`, é o data source que lista esses objetos.

Cada seção abaixo cobre um produto: os seus recursos, os seus data sources e um bloco de configuração que os usa. Cada nome leva à sua página no Terraform Registry.

## Workloads

Estes recursos e data sources gerenciam workloads e os seus deployments. Para mais informações, consulte [Recursos de Workloads](/pt-br/documentacao/devtools/terraform/workloads/).

| Recurso | Descrição |
| --- | --- |
| [`azion_workload`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/workload) | Cria e gerencia um workload. |
| [`azion_workload_deployment`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/workload_deployment) | Cria e gerencia um deployment de workload, que vincula ao workload uma aplicação e, opcionalmente, um firewall e uma custom page. |

| Data source | Descrição |
| --- | --- |
| [`azion_workloads`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workloads) | Lista workloads. |
| [`azion_workload`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload) | Lê um workload. |
| [`azion_workload_deployments`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload_deployments) | Lista deployments de workload. |
| [`azion_workload_deployment`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload_deployment) | Lê um deployment. |

Este bloco cria uma aplicação, um workload e um deployment que vincula a aplicação ao workload e, em seguida, consulta os workloads existentes:

```hcl
# Create the application that the deployment binds
resource "azion_application_main_setting" "app" {
  application = {
    name   = "my-application"
    active = true
  }
}

# Create a workload
resource "azion_workload" "example" {
  workload = {
    name   = "my-workload"
    active = true
  }
}

# Deploy the application on the workload
resource "azion_workload_deployment" "example" {
  workload_id = azion_workload.example.workload.id

  deployment = {
    name    = "my-deployment"
    active  = true
    current = true

    strategy = {
      type = "default"
      attributes = {
        application = azion_application_main_setting.app.application.application_id
      }
    }
  }
}

# Query existing workloads
data "azion_workloads" "all" {}
```

## Connectors

Estes recursos e data sources gerenciam connectors, que ligam uma aplicação a uma origem externa. Para mais informações, consulte [Recursos de Connectors](/pt-br/documentacao/devtools/terraform/connectors/).

| Recurso | Descrição |
| --- | --- |
| [`azion_connector`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/connector) | Cria e gerencia um connector. |

| Data source | Descrição |
| --- | --- |
| [`azion_connectors`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/connectors) | Lista connectors. |
| [`azion_connector`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/connector) | Lê um connector. |

Este bloco cria um connector do tipo `http` para uma origem HTTPS e, em seguida, consulta os connectors existentes:

```hcl
# Create a connector
resource "azion_connector" "example" {
  connector = {
    name   = "my-connector"
    type   = "http"
    active = true

    http_attributes = {
      addresses = [
        {
          endpoint = {
            address    = "origin.example.com"
            https_port = 443
          }
        }
      ]
      connection_options = {
        host             = "origin.example.com"
        transport_policy = "force_https"
      }
    }
  }
}

# Query existing connectors
data "azion_connectors" "all" {}
```

Este bloco cria uma aplicação com o módulo de cache ativado e uma configuração de cache que respeita a política de cache da origem:

```hcl
# Create an application
resource "azion_application_main_setting" "app" {
  application = {
    name   = "my-application"
    active = true
    modules = {
      cache = {
        enabled = true
      }
    }
  }
}

# Configure cache
resource "azion_application_cache_setting" "cache" {
  application_id = azion_application_main_setting.app.application.application_id

  cache_setting = {
    name = "cache-default"
    browser_cache = {
      behavior = "honor"
    }
    modules = {
      cache = {
        behavior = "honor"
      }
    }
  }
}
```

Este bloco cria um firewall com o módulo WAF ativado, um WAF rule set e uma regra de firewall que aplica o rule set em modo de bloqueio a todas as requisições. Ele também cria uma network list com dois intervalos de IP:

```hcl
# Create a firewall with the WAF module on
resource "azion_firewall_main_setting" "firewall" {
  data = {
    name   = "my-firewall"
    active = true
    modules = {
      waf = {
        enabled = true
      }
    }
  }
}

# Create a WAF rule set
resource "azion_waf" "waf" {
  result = {
    name   = "my-waf"
    active = true
  }
}

# Apply the WAF to every request that reaches the firewall
resource "azion_firewall_rule_engine" "waf" {
  firewall_id = azion_firewall_main_setting.firewall.data.id

  results = {
    name   = "Enable WAF"
    active = true
    behaviors = [
      {
        behavior = {
          type = "set_waf"
          attributes = {
            waf_id = azion_waf.waf.result.id
            mode   = "blocking"
          }
        }
      }
    ]
    criteria = [
      {
        entries = [
          {
            criterion = {
              variable    = "$${request_uri}"
              operator    = "starts_with"
              conditional = "if"
              argument    = "/"
            }
          }
        ]
      }
    ]
  }
}

# Create a network list
resource "azion_network_list" "allowlist" {
  results = {
    name = "allowlist-ips"
    type = "ip_cidr"
    items = [
      "192.0.2.0/24",
      "198.51.100.0/24",
    ]
  }
}
```

O argumento `$${request_uri}` escapa o `$`, então o Terraform passa ao firewall a variável literal `${request_uri}` em vez de interpolá-la.

## Exemplo completo

Esta configuração fixa o provider na versão 2.10.0 e cria uma aplicação com uma configuração de cache, um connector e uma regra que envia as requisições para ele, um firewall que aplica um WAF rule set e um workload com um deployment que vincula a aplicação e o firewall a ele. Ela retorna como outputs os IDs da aplicação, do workload e do connector, e lê o seu personal token da variável `api_token` que [Primeiros passos com o Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/getting-started/) declara.

```hcl
terraform {
  required_providers {
    azion = {
      source  = "aziontech/azion"
      version = "2.10.0"
    }
  }
}

provider "azion" {
  api_token = var.api_token
}

# Application
resource "azion_application_main_setting" "app" {
  application = {
    name   = "my-application"
    active = true
    modules = {
      cache = {
        enabled = true
      }
    }
  }
}

# Cache setting
resource "azion_application_cache_setting" "cache" {
  application_id = azion_application_main_setting.app.application.application_id

  cache_setting = {
    name = "cache-default"
    browser_cache = {
      behavior = "honor"
    }
    modules = {
      cache = {
        behavior = "honor"
      }
    }
  }
}

# Connector
resource "azion_connector" "origin" {

resource "azion_application_rule_engine" "origin" {

  results = {
    name   = "Send requests to the origin"
    phase  = "request"
    active = true
    behaviors = [
      {
        behavior = {
          type = "set_connector"
          attributes = {
            value = azion_connector.origin.connector.id

    criteria = [
      {
        entries = [
          {
            criterion = {
              variable    = "$${uri}"
              operator    = "starts_with"
              conditional = "if"
              argument    = "/"

      }
    ]
  }
```
