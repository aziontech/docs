O Azion Terraform Provider v2.0 configura a Azion Platform com dois tipos de bloco. Um recurso cria, atualiza e exclui um objeto na Azion, e um data source consulta informações sobre objetos que já existem. Um nome no singular, como `azion_workload`, costuma ser ao mesmo tempo um recurso e o data source que lê um objeto, e o seu plural, `azion_workloads`, é o data source que lista esses objetos.

Cada seção abaixo cobre um produto: os seus recursos, os seus data sources e um bloco de configuração que os usa. Cada nome leva à sua página no Terraform Registry.

---

## Workloads

Estes recursos e data sources gerenciam workloads e os seus deployments. Para mais informações, consulte [Recursos de Workloads](/pt-br/documentacao/devtools/terraform/workloads/).

| Recurso | Descrição |
| --- | --- |
| [`azion_workload`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/workload) | Cria e gerencia um workload. |
| [`azion_workload_deployment`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/workload_deployment) | Cria e gerencia um deployment de workload. |

| Data source | Descrição |
| --- | --- |
| [`azion_workloads`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workloads) | Lista workloads. |
| [`azion_workload`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload) | Lê um workload. |
| [`azion_workload_deployments`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload_deployments) | Lista deployments de workload. |
| [`azion_workload_deployment`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/workload_deployment) | Lê um deployment. |

Este bloco cria um workload e um deployment dele e, em seguida, consulta os workloads existentes:

```hcl
# Create a workload
resource "azion_workload" "example" {
  name = "my-workload"
  
  application_id = azion_application_main_setting.app.id
  
  active = true
}

# Create a deployment
resource "azion_workload_deployment" "example" {
  workload_id = azion_workload.example.id
  
  active = true
}

# Query existing workloads
data "azion_workloads" "all" {}
```

## Connectors

Estes recursos e data sources gerenciam connectors, que ligam uma aplicação a uma origem externa. Para mais informações, consulte [Recursos de Connectors](/pt-br/documentacao/devtools/terraform/connectors/).

| Recurso | Descrição |
| --- | --- |
| [`azion_connector`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/connector) | Cria e gerencia um connector. |

| Data source | Descrição |
| --- | --- |
| [`azion_connectors`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/connectors) | Lista connectors. |
| [`azion_connector`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/connector) | Lê um connector. |

Este bloco cria um connector para uma origem HTTPS e, em seguida, consulta os connectors existentes:

```hcl
# Create a connector
resource "azion_connector" "example" {
  name = "my-connector"
  
  origin = {
    address = "origin.example.com"
    protocol = "https"
  }
}

# Query existing connectors
data "azion_connectors" "all" {}
```

| Data source | Descrição |

| [`azion_application_main_settings`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/application_main_settings) | Consulta as configurações principais de aplicações. |

Este bloco cria uma aplicação e uma configuração de cache que respeita a política de cache da origem:

```hcl
# Create an Application
resource "azion_application_main_setting" "app" {
  name = "my-application"
  
  active = true
}

# Configure cache
resource "azion_application_cache_setting" "cache" {
  application_id = azion_application_main_setting.app.id
  name = "cache-default"
  
  browser_cache_settings = "honor"
  cdn_cache_settings = "honor"
}
```

## Edge DNS

Estes recursos e data sources gerenciam zonas, registros e DNSSEC do [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/). Os nomes mantêm a forma `intelligent_dns` que o provider usa. Para mais informações, consulte [Recursos de Edge DNS](/pt-br/documentacao/devtools/terraform/dns/).

| Recurso | Descrição |
| --- | --- |
| [`azion_intelligent_dns_zone`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/intelligent_dns_zone) | Cria e gerencia uma zona DNS. |
| [`azion_intelligent_dns_record`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/intelligent_dns_record) | Cria e gerencia um registro DNS. |
| [`azion_intelligent_dns_dnssec`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/intelligent_dns_dnssec) | Gerencia as configurações de DNSSEC de uma zona. |

| Data source | Descrição |
| --- | --- |
| [`azion_intelligent_dns_zones`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/intelligent_dns_zones) | Lista zonas DNS. |
| [`azion_intelligent_dns_zone`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/intelligent_dns_zone) | Lê uma zona DNS. |
| [`azion_intelligent_dns_records`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/intelligent_dns_records) | Lista registros DNS. |
| [`azion_intelligent_dns_dnssec`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/data-sources/intelligent_dns_dnssec) | Lê as configurações de DNSSEC de uma zona. |

Este bloco cria uma zona e um registro `A` nela e, em seguida, consulta as zonas existentes:

```hcl
# Create a DNS zone
resource "azion_intelligent_dns_zone" "zone" {
  name = "example.com"
  domain = "example.com"
  
  active = true
}

# Create a DNS record
resource "azion_intelligent_dns_record" "www" {
  zone_id = azion_intelligent_dns_zone.zone.id
  name = "www"
  type = "A"
  ttl = 3600
  
  value = "192.0.2.1"
}

# Query existing DNS zones
data "azion_intelligent_dns_zones" "all" {}
```

```hcl
# Create a Firewall
resource "azion_firewall_main_setting" "firewall" {

  active = true
  mode = "waf"
}

resource "azion_network_list" "allowlist" {
  name = "allowlist-ips"
  list_type = "ip_cidr"
  
  items = [
    "192.0.2.0/24",
    "10.0.0.0/8"
  ]
}
```

## Exemplo completo

Esta configuração fixa o provider na versão 2.0.0 e cria uma aplicação com uma configuração de cache, um connector, um workload com um deployment e um firewall. Ela retorna como outputs os IDs da aplicação, do workload e do connector, e lê o seu personal token da variável `api_token` que [Primeiros passos com o Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/getting-started/) declara.

```hcl
terraform {
  required_providers {
    azion = {
      source  = "aziontech/azion"
      version = "2.0.0"
    }
  }
}

provider "azion" {
  api_token = var.api_token
}

# Application
resource "azion_application_main_setting" "app" {
  name = "my-application"
  active = true
}

# Cache Setting
resource "azion_application_cache_setting" "cache" {
  application_id = azion_application_main_setting.app.id
  name = "cache-default"
  browser_cache_settings = "honor"
  cdn_cache_settings = "honor"
}

# Connector
resource "azion_connector" "origin" {
  name = "my-origin"
  origin = {
    address = "origin.example.com"
    protocol = "https"
  }
}

# Workload
resource "azion_workload" "main" {
  name = "my-workload"
  application_id = azion_application_main_setting.app.id
  active = true
}

# Workload Deployment
resource "azion_workload_deployment" "main" {
  workload_id = azion_workload.main.id
  active = true
}

# Firewall
resource "azion_firewall_main_setting" "firewall" {
  name = "my-firewall"
  active = true
  mode = "waf"
}

# Outputs
output "application_id" {
  value = azion_application_main_setting.app.id
}

output "workload_id" {
  value = azion_workload.main.id
}

output "connector_id" {
  value = azion_connector.origin.id
}
```
