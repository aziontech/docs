`Azion.AI.run` é o binding que uma [Function](/pt-br/documentacao/plataforma/functions/) chama para invocar um modelo no [AI Inference](/pt-br/documentacao/plataforma/ai-inference/). Ele é um global do [Azion Runtime](/pt-br/documentacao/devtools/runtime/), então uma Function o alcança sem linha de import e sem credencial. O binding carrega o id do modelo e o corpo da requisição. Os campos que esse corpo aceita, e o objeto que o modelo retorna, são os mesmos do endpoint HTTP e estão documentados em [Invocação de modelos](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/).

:::note[nota]
Com `azion dev`, `Azion.AI` é `undefined`, e uma chamada a `Azion.AI.run` lança `TypeError: Cannot read properties of undefined (reading 'run')`. Teste as chamadas de modelo em uma Function publicada.
:::

---

## Parâmetros

`Azion.AI.run` recebe dois parâmetros, e a chamada é assíncrona: a Function aguarda a chamada e lê a resposta do modelo no valor resolvido.

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| Id do modelo | string | O id do modelo a ser invocado, na forma que a página do modelo indica. |
| Corpo da requisição | object | Os campos da requisição para a operação. Um campo `model` dentro dele é ignorado, assim como um campo que o modelo não conhece. |

A forma do id varia entre os modelos, então copie o id da própria página do modelo em [Modelos de AI](/pt-br/documentacao/plataforma/ai-inference/modelos/) em vez de derivá-lo do nome do modelo.

## Chame um modelo

Uma chamada a um modelo de chat dentro de uma Function:

```ts
const modelResponse = await Azion.AI.run("Qwen/Qwen3-30B-A3B-Instruct-2507-FP8", {
  "stream": false,
  "messages": [
    { "role": "system", "content": "You are a helpful assistant." },
    { "role": "user", "content": "Name three European capitals." }
  ]
})
return modelResponse
```

---

## Valor de retorno

O valor resolvido é o objeto que o modelo retorna. Um modelo de chat retorna um objeto `chat.completion`, um modelo de embedding retorna uma `list` de embeddings e um modelo de reranking retorna os resultados ranqueados. Com `stream` definido como `true` no corpo, a chamada resolve num iterador assíncrono de objetos `chat.completion.chunk`, que a Function lê com `for await`. O campo `model` de uma resposta é o id interno do modelo na conta, que pode ser diferente do id que a chamada passou. O texto gerado por um modelo de chat fica em `modelResponse?.choices?.[0]?.message?.content`, que é o conteúdo da primeira entrada de `choices`. Todos os campos das três formas estão listados em [Invocação de modelos](/pt-br/documentacao/plataforma/ai-inference/invocacao-de-modelos/#campos-da-resposta).

---

## Listar modelos

`Azion.AI.models()` retorna os ids dos modelos que a sua conta pode chamar, como um array de strings. Ele não recebe argumento, e a chamada é assíncrona:

```ts
const modelIds = await Azion.AI.models()
```

A lista pode trazer duas formas do id de um mesmo modelo, um caminho de repositório e uma forma em minúsculas, e qualquer uma delas seleciona esse modelo em `Azion.AI.run`.
