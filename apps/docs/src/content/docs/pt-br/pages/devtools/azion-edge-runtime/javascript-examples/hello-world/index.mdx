Retorne uma string fixa diretamente de uma função, sem contatar um servidor de origem. Esta é a forma mais simples do padrão que toda função segue. Isso a torna uma verificação útil de que a função está publicada e atendendo ao tráfego antes de você adicionar lógica a ela.

```js
async function handleRequest(request) {
  return new Response("Hello World")
}

export default {
  async fetch(request, env, ctx) {
    return handleRequest(request)
  },
}
```

## Como funciona

O export default é um objeto com um método `fetch`, o handler que o Azion Runtime chama a cada requisição. Quando uma requisição chega, `handleRequest` constrói um novo `Response` com o texto a ser retornado, e o handler retorna essa resposta ao cliente. Como o código é executado na infraestrutura distribuída da Azion, a resposta é entregue próxima ao usuário, sem nenhuma requisição a uma origem.

O mesmo padrão retorna qualquer tipo de conteúdo. Altere o valor passado para `Response` para obter outro corpo de resposta e defina um header `content-type` quando o corpo for HTML ou JSON.
