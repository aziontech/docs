O Azion Terraform Provider gerencia o [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/) com três recursos e o lê com quatro data sources. Uma zona contém os registros de um domínio, e o DNSSEC adiciona uma camada de segurança a uma zona. Os identificadores mantêm a forma `intelligent_dns` que o provider usa e têm os mesmos nomes no provider v1.x e na v2.0. Para mais informações, consulte [Migre do provider v1.x para a v2.0](/pt-br/documentacao/devtools/terraform/migration-v3-to-v4/).

---

## Recursos de Edge DNS

| Recurso | Descrição |
| --- | --- |
| [`azion_intelligent_dns_zone`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/intelligent_dns_zone) | Cria e gerencia uma zona DNS. |
| [`azion_intelligent_dns_record`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/intelligent_dns_record) | Cria e gerencia um registro DNS. |
| [`azion_intelligent_dns_dnssec`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/intelligent_dns_dnssec) | Gerencia as configurações de DNSSEC de uma zona. |

Cada recurso recebe as suas configurações em um bloco aninhado: `zone`, `record` ou `dnssec`. Os recursos de registro e de DNSSEC também recebem `zone_id` fora do bloco e o leem do atributo `id` do recurso de zona.

| Recurso | Argumento | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- | --- |
| `azion_intelligent_dns_zone` | `zone.name` | String | Sim | O nome que identifica a zona nas listas. Ele não é o domínio. |
| `azion_intelligent_dns_zone` | `zone.domain` | String | Sim | O domínio que a zona atende, como `example.com`. |
| `azion_intelligent_dns_zone` | `zone.active` | Booleano | Sim | Define se a zona responde às consultas do seu domínio. |
| `azion_intelligent_dns_record` | `zone_id` | String | Sim | O ID da zona que contém o registro. |
| `azion_intelligent_dns_record` | `record.name` | String | Sim | O nome do registro, relativo à zona, como `www`. |
| `azion_intelligent_dns_record` | `record.type` | String | Sim | O tipo do registro, como `A`, `AAAA` ou `CNAME`. |
| `azion_intelligent_dns_record` | `record.rdata` | Lista de strings | Sim | Uma ou mais respostas do registro. |
| `azion_intelligent_dns_record` | `record.policy` | String | Sim | `simple` responde com todos os valores do registro. `weighted` permite que vários registros compartilhem um nome e um tipo. |
| `azion_intelligent_dns_record` | `record.ttl` | Número | Sim | O tempo de vida do registro, em segundos. |
| `azion_intelligent_dns_record` | `record.weight` | Número | Não | O peso do registro. Ele só se aplica quando `policy` é `weighted`. |
| `azion_intelligent_dns_record` | `record.description` | String | Não | A descrição do registro, em qualquer `policy`. |
| `azion_intelligent_dns_dnssec` | `zone_id` | String | Sim | O ID da zona. |
| `azion_intelligent_dns_dnssec` | `dnssec.is_enabled` | Booleano | Sim | Define se o DNSSEC está ativo na zona. |

Um registro `simple` aceita `description` a partir do provider 2.10.0. As versões 2.0.0 a 2.9.0 enviam `description` apenas para registros `weighted`, então um registro `simple` com descrição falha no `terraform apply`. O provider armazena uma `description` vazia como não definida.

Para todos os tipos de registro, consulte [Tipos de registro](/pt-br/documentacao/plataforma/edge-dns/tipos-de-registro/). Para os limites de cada campo, consulte [Zonas e registros](/pt-br/documentacao/plataforma/edge-dns/zonas-e-registros/). A página de cada recurso no Terraform Registry lista todos os argumentos.

## Exemplo

Esta configuração fixa a versão 2.10.0 do provider e cria uma zona com um registro `A` e um registro `CNAME`. Ela ativa o DNSSEC na zona e exibe o ID da zona em um output. O registro `A` tem uma `description`, que um registro `simple` aceita a partir do provider 2.10.0. A configuração lê o seu personal token da variável `api_token` que [Primeiros passos com o Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/getting-started/) declara.

```hcl
terraform {
  required_providers {
    azion = {
      source  = "aziontech/azion"
      version = "2.10.0"
    }
  }
}

provider "azion" {
  api_token = var.api_token
}

# Create DNS zone
resource "azion_intelligent_dns_zone" "my_zone" {
  zone = {
    name   = "example-zone"
    domain = "example.com"
    active = true
  }
}

# Create A record
resource "azion_intelligent_dns_record" "www" {
  zone_id = azion_intelligent_dns_zone.my_zone.id
  record = {
    name        = "www"
    type        = "A"
    rdata       = ["192.0.2.1"]
    policy      = "simple"
    ttl         = 3600
    description = "Web server"
  }
}

# Create CNAME record
resource "azion_intelligent_dns_record" "alias" {
  zone_id = azion_intelligent_dns_zone.my_zone.id
  record = {
    name   = "alias"
    type   = "CNAME"
    rdata  = ["www.example.com"]
    policy = "simple"
    ttl    = 3600
  }
}

# Enable DNSSEC
resource "azion_intelligent_dns_dnssec" "my_dnssec" {
  zone_id = azion_intelligent_dns_zone.my_zone.id
  dnssec = {
    is_enabled = true
  }
}

output "zone_id" {
  value = azion_intelligent_dns_zone.my_zone.id
}
```
