O dataset `accountingDetail` da GraphQL API retorna o uso contabilizado pela Azion para a sua conta, por região, para cada período, produto e métrica. O endpoint de accounting, `https://api.azion.com/v4/accounting/graphql`, atende esse dataset em uma requisição `POST` com o header `Authorization: Token [TOKEN VALUE]`. Os argumentos que uma query aceita estão em [Datasets e argumentos de query](/pt-br/documentacao/devtools/graphql/recursos/).

---

## accountingDetail

Uma query em `accountingDetail` retorna apenas os campos que ela seleciona, entre os da tabela abaixo:

| Campo | Tipo | Descrição | Exemplo |
| --- | --- | --- | --- |
| `billId` | Int | Identificador único da fatura. | — |
| `clientId` | String | Identificador único do cliente na Azion. | `1234u` |
| `periodFrom` | Date | Data de início dos dados contabilizados, no formato ano-mês-dia. | `2026-09-01` |
| `periodTo` | Date | Data de término dos dados contabilizados, no formato ano-mês-dia. | `2026-09-30` |
| `invoiceNumber` | String | Identificador único da nota fiscal gerada para a fatura do cliente. | — |
| `productSlug` | String | Identificador do produto contabilizado. Os valores incluem `application`, `content_delivery`, `application_acceleration`, `edge_firewall`, `waf`, `live_ingest`, `load_balancer`, `image_optimization`, `ddos_protection_20gbps`, `ddos_protection_50gbps`, `ddos_protection_unlimited`, `ddos_protection_data_transferred`, `support_enterprise`, `support_mission_critical`, `realtime_events`, `data_streaming`, `edge_functions`, `intelligent_dns`, `layer_two_cache`, `plan_business`, `plan_enterprise`, `plan_missioncritical`, `edge_storage`, `bot_manager`, `connector`, `workload`, `cache`, `support_developer`, `support` e `support_fee`. | `application` |
| `metricSlug` | String | Identificador da métrica contabilizada. Para mais informações, consulte [Termos de Serviço](/pt-br/documentacao/contratos/tds/#21-metricas-de-cobranca). | `data_transferred`, `load_balancer_data_transferred` |
| `regionName` | String | Região à qual a métrica foi contabilizada: `United States`, `Canada`, `Europe`, `Brazil`, `Latam`, `All Other Regions` ou `No Region`. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/). | `All Other Regions` |
| `accounted` | Float | Uso total do produto contabilizado por região no detalhe da fatura do cliente. | `0.007995243` |

Quando uma query define o argumento `aggregate`, o dataset também retorna os campos de saída `count`, `sum`, `max`, `min` e `avg`. Para mais informações, consulte [Queries](/pt-br/documentacao/devtools/graphql/queries/).

## Exemplo de query

Uma query em `accountingDetail` não precisa de filtro. Esta query retorna as linhas contabilizadas mais recentes, ordenadas por `periodFrom`, da mais recente para a mais antiga:

```graphql
query {
  accountingDetail(limit: 5, orderBy: [periodFrom_DESC]) {
    clientId
    periodFrom
    periodTo
    productSlug
    metricSlug
    regionName
    accounted
  }
}
```
