O comando `purge` da Azion CLI remove objetos em cache antes que o TTL deles termine, para que a próxima requisição busque a versão atual na origem. Ele envia um [Real-Time Purge](/pt-br/documentacao/plataforma/applications/cache/real-time-purge/) de um de três tipos: uma lista de URLs, uma lista de cache keys ou uma expressão wildcard. Por padrão, o purge limpa a camada de Cache, ou a camada de [Tiered Cache](/pt-br/documentacao/plataforma/applications/cache/tiered-cache/) com `--layer tiered_cache`. As opções que todo comando aceita, como `--format`, `--out` e `-y`, estão em [Opções globais da Azion CLI](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion purge` recebe o tipo de purge de uma de três flags, `--urls`, `--cachekey` ou `--wildcard`:

```bash
azion purge [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--cachekey` | — | string | — | Lista de cache keys separadas por vírgula para o purge. É o único tipo de purge que a camada `tiered_cache` aceita. |
| `--layer` | — | string | `"cache"` | Camada em que o purge roda: `cache` ou `tiered_cache`. |
| `--urls` | — | string | — | Lista de URLs separadas por vírgula para o purge, com ou sem o esquema. |
| `--wildcard` | — | string | — | Uma expressão wildcard, uma URL ou uma cache key com um asterisco (`*`), que corresponde aos objetos do purge. |

Uma URL sem esquema cobre as cópias HTTP e HTTPS do objeto. Um purge por wildcard recebe uma expressão por requisição, então uma segunda expressão falha com `Only one item is allowed for the Wildcard option`. Os purges por URL e por wildcard rodam somente na camada `cache`: com `--layer tiered_cache`, eles falham com `Invalid purge layer for purge type "url".`, ou com o mesmo erro indicando `"wildcard"`. Para o formato de cada argumento, consulte [Real-Time Purge](/pt-br/documentacao/plataforma/applications/cache/real-time-purge/).

## Exemplos

Cada exemplo mostra o comando e a saída que ele imprime.

### Fazer o purge de uma lista de URLs

Este comando faz o purge de duas páginas de um site na camada de Cache:

```bash
azion purge --urls 'mz0kbijeiw0.map.azionedge.net/index.html,mz0kbijeiw0.map.azionedge.net/about.html'
```

O comando confirma o purge:

```text
Purge carried out successfully
```

O mesmo comando aceita cada URL com o seu esquema, como `https://mz0kbijeiw0.map.azionedge.net/index.html`.

### Fazer o purge com uma expressão wildcard

Este comando faz o purge de todos os objetos sob o caminho raiz de um site:

```bash
azion purge --wildcard 'mz0kbijeiw0.map.azionedge.net/*'
```

O comando confirma o purge:

```text
Purge carried out successfully
```

### Fazer o purge de uma lista de cache keys

Este comando faz o purge das cache keys de duas páginas na camada de Cache:

```bash
azion purge --cachekey 'mz0kbijeiw0.map.azionedge.net/index.html,mz0kbijeiw0.map.azionedge.net/about.html'
```

O comando confirma o purge:

```text
Purge carried out successfully
```

### Fazer o purge de uma cache key no Tiered Cache

Este comando faz o purge de uma cache key na camada de Tiered Cache:

```bash
azion purge --cachekey 'mz0kbijeiw0.map.azionedge.net/index.html' --layer tiered_cache
```

O comando confirma o purge:

```text
Purge carried out successfully
```

### Escolher o tipo de purge em uma pergunta

Em um terminal, o comando pergunta o tipo de purge quando você não passa nenhuma flag de tipo de purge:

```bash
azion purge
```

O comando lista os três tipos de purge:

```text
? Choose a purge type:  [Use arrows to move, type to filter]
> URL
  Wildcard
  Cache Key
```

Depois que você escolhe _URL_, o comando pergunta `Enter the URLs you wish to purge, separated by commas`. Sem um terminal, como em um script, o comando falha com `Error: EOF`, então passe `--urls`, `--cachekey` ou `--wildcard`.
