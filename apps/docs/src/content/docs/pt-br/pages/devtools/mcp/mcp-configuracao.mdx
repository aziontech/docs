Este guia orienta você na sua primeira pergunta aos MCP servers da Azion pelo Claude Code. Ele conecta o servidor de docs, que apenas lê, e depois mostra como adicionar os quatro servidores que alteram a sua conta.

- Crie um personal token no Azion Console.
- Registre o servidor de docs no Claude Code com um comando.
- Verifique as ferramentas e os recursos que o servidor expõe com o MCP Inspector.
- Faça ao Claude Code uma pergunta que o servidor responde a partir da documentação da Azion.

Três peças se conectam, nesta ordem:

1. O **personal token** identifica a sua conta Azion.
2. A **entrada do servidor** `azion-docs` no Claude Code aponta para `https://docs-mcp.azion.com/mcp` e envia o token no header `Authorization` de cada requisição.
3. O **servidor de docs** verifica o token e entrega ao Claude Code as ferramentas e os recursos dele.

Para mais informações sobre os servidores, consulte [MCP server](/pt-br/documentacao/devtools/mcp/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- O Claude Code, instalado na sua máquina.
- Node.js e npm. O MCP Inspector é executado com `npx`.

---

## 1. Crie um personal token

Os servidores aceitam um personal token da Azion como credencial. Para criar o token no Azion Console:

<DocSteps>
  <DocStep title="Abra a página de personal tokens">

  Acesse [Azion Console](https://console.azion.com/) > **Account** > **Personal Token**. **Account** é o menu do avatar.

  </DocStep>
  <DocStep title="Selecione + Personal Token" />
  <DocStep title="Dê um nome ao token">

  Na seção **General**, insira um **Name**. Por exemplo: `mcp-server`. Os servidores agem com as permissões desse token, então limite o escopo dele ao que o agente precisa.

  </DocStep>
  <DocStep title="Defina a expiração">

  Na seção **Token**, selecione um valor em **Expires within**. O padrão é _1 day_.

  </DocStep>
  <DocStep title="Selecione Save" />
  <DocStep title="Copie o token">

  Na caixa de diálogo **Personal Token has been created**, selecione **Copy**. A caixa de diálogo mostra o token apenas uma vez, então guarde-o antes de continuar.

  </DocStep>
  <DocStep title="Selecione Confirm" />
</DocSteps>

O token aparece na lista **Personal Tokens**, e o valor dele está na sua área de transferência. Para mais informações, consulte [Como criar um personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).

Mantenha o token seguro:

- Nunca faça commit de um token. Adicione ao `.gitignore` todo arquivo de configuração que contenha um.
- Guarde o token em uma variável de ambiente quando o seu cliente oferecer suporte a isso.
- Faça a rotação dos seus tokens regularmente.

## 2. Conecte o Claude Code

O comando `claude mcp add` registra um servidor. A flag `-t http` seleciona o transporte HTTP, `-s user` guarda o servidor para todos os projetos, e `-H` define o header que carrega o seu token. Execute o comando e substitua `[TOKEN VALUE]` pelo seu token:

```bash
claude mcp add "azion-docs" "https://docs-mcp.azion.com/mcp" -t http -s user -H "Authorization: Token [TOKEN VALUE]"
```

O Claude Code guarda o servidor na sua configuração de usuário, que não é um arquivo do seu projeto. O personal token vai no esquema `Token`. Um valor `Bearer` é lido como um access token OAuth, então um personal token enviado como `Bearer` falha com `401`.

O Claude Code tem o servidor de docs registrado como `azion-docs`. Para adicionar outro servidor, execute o mesmo comando com o nome e a URL dele:

| Servidor | Nome | URL |
| --- | --- | --- |
| build | `azion-build` | `https://build-mcp.azion.com/mcp` |
| secure | `azion-secure` | `https://secure-mcp.azion.com/mcp` |
| observe | `azion-observe` | `https://observe-mcp.azion.com/mcp` |
| storage | `azion-storage` | `https://storage-mcp.azion.com/mcp` |

Esses quatro servidores criam, alteram e excluem recursos na sua conta. Adicione apenas os de que o agente precisa. Para o que cada um cobre, consulte [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/). Para mais informações sobre o Claude Code com a Azion, consulte [Claude Code + Azion](/pt-br/documentacao/agent-setup/claude-code/).

## 3. Verifique a conexão

O MCP Inspector se conecta a um MCP server e lista o que o servidor expõe. Inicie o Inspector:

```bash
npx @modelcontextprotocol/inspector
```

Para instalar o Inspector em vez de executá-lo com `npx`, execute `npm install -g @modelcontextprotocol/inspector`.

Para conectar o Inspector ao servidor de docs:

<DocSteps>
  <DocStep title="Selecione o transporte">

  Defina **Transport type** como _streamable-http_.

  </DocStep>
  <DocStep title="Insira o endereço do servidor">

  Em **URL**, insira `https://docs-mcp.azion.com/mcp`.

  </DocStep>
  <DocStep title="Insira o header">

  Em **Authentication**, insira `Authorization: Token [TOKEN VALUE]`, com o seu token no lugar de `[TOKEN VALUE]`.

  </DocStep>
  <DocStep title="Selecione Connect" />
  <DocStep title="Abra a aba Tools" />
  <DocStep title="Abra a aba Resources" />
</DocSteps>

A aba **Tools** lista sete ferramentas, e a aba **Resources** lista sete recursos. Para a lista completa, consulte [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/#ferramentas-do-servidor-de-docs).

Uma requisição sem token falha com `401`, e uma requisição com um token inválido falha com `403`. Para diagnosticar uma conexão que falhou, consulte [Solucionar problemas do MCP server](/pt-br/documentacao/devtools/mcp/solucao-de-problemas/).

## 4. Faça sua primeira pergunta

A ferramenta `search_azion_docs_and_site` pesquisa na documentação e no site da Azion. Em uma sessão do Claude Code, faça uma pergunta que precise dela:

```text
Search the Azion documentation: how to configure cache
```

A ferramenta retorna as páginas da documentação que melhor correspondem à pergunta, cada uma com o título, o conteúdo e a URL de origem. O Claude Code monta a resposta a partir dessas páginas.

As outras ferramentas do servidor de docs retornam exemplos de código, comandos da Azion CLI, operações da Azion API, recursos do Terraform e guias para fazer o deploy de um site estático. Com os servidores de build e observe também conectados, o agente pode criar regras e escrever queries GraphQL para a sua conta. Experimente um destes prompts em seguida:

- `I have a static website with HTML, CSS, and JavaScript files. Help me deploy it to Azion.`
- `Generate a query to analyze cache hit rates for my images.`
- `Create Rules Engine rules to add security headers including HSTS, X-Frame-Options, and CSP for my application. Preview them with dry_run first.`
- `My deployment is failing with error 503. How can I debug this?`

O Claude Code responde a perguntas sobre a Azion a partir do servidor de docs.

## Conecte outro cliente

Cada cliente da tabela abaixo tem a própria página de configuração. Cada página conecta o servidor de docs, e os outros servidores se conectam da mesma forma com as URLs deles:

| Cliente | Onde o servidor é configurado | Página de configuração |
| --- | --- | --- |
| Cursor | `.cursor/mcp.json` | [Cursor + Azion](/pt-br/documentacao/agent-setup/cursor/) |
| GitHub Copilot | `.vscode/mcp.json` | [GitHub Copilot + Azion](/pt-br/documentacao/agent-setup/github-copilot/) |
| Windsurf | `.codeium/windsurf/mcp_config.json` | [Windsurf + Azion](/pt-br/documentacao/agent-setup/windsurf/) |
| Codex | `~/.codex/config.toml` | [Codex + Azion](/pt-br/documentacao/agent-setup/codex/) |
| Gemini CLI | `~/.gemini/settings.json` | [Gemini CLI + Azion](/pt-br/documentacao/agent-setup/gemini-cli/) |
| OpenCode | `opencode.json` | [OpenCode + Azion](/pt-br/documentacao/agent-setup/opencode/) |

Claude Desktop, Warp e Kiro não têm página de configuração. As configurações deles vêm a seguir.

### Claude Desktop

O Claude Desktop inicia a conexão pelo `mcp-remote`, uma ponte entre um cliente local e um MCP server remoto. O comando `npx` baixa o `mcp-remote` no primeiro uso, e a ponte precisa do Node.js 18 ou posterior.

Nas configurações do Claude Desktop, abra a configuração MCP e adicione o servidor de docs. Substitua `[TOKEN VALUE]` pelo seu token:

```json
{
  "mcpServers": {
    "azion-docs": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote@latest",
        "https://docs-mcp.azion.com/mcp",
        "--header",
        "Authorization: Token [TOKEN VALUE]"
      ]
    }
  }
}
```

### Warp

O Warp também se conecta pelo `mcp-remote`, com o mesmo requisito de Node.js. Nas configurações MCP do Warp, adicione o servidor de docs. Esta configuração não tem uma chave `mcpServers` em volta do servidor. Substitua `[TOKEN VALUE]` pelo seu token:

```json
{
  "azion-docs": {
    "command": "npx",
    "args": [
      "-y",
      "mcp-remote@latest",
      "https://docs-mcp.azion.com/mcp",
      "--header",
      "Authorization: Token [TOKEN VALUE]"
    ]
  }
}
```

### Kiro

O Kiro envia o token em um header. Crie o arquivo `.kiro/settings/mcp.json` com o servidor de docs. Substitua `[TOKEN VALUE]` pelo seu token:

```json
{
  "mcpServers": {
    "azion-docs": {
      "url": "https://docs-mcp.azion.com/mcp",
      "headers": {
        "Authorization": "Token [TOKEN VALUE]"
      }
    }
  }
}
```
