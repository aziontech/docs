O Azion Runtime oferece a toda function um conjunto de nomes globais que o código usa sem um import: built-ins do JavaScript, Web APIs, as APIs da Azion e alguns globais do Node.js. As listas desta página são os nomes que o runtime expõe após o deploy, agrupados pelo tipo que `typeof` retorna para cada um. `self` e `globalThis` são o mesmo objeto.

:::note[nota]
Com `azion dev`, `caches`, `upgradeWebSocket`, `WebSocket` e `CustomEvent` não estão definidos, e `globalThis.dispatchEvent` não é uma função. `queueMicrotask` está definido localmente, mas não após o deploy. `EdgeRuntime` contém `"edge-runtime"`, e `Date.now()` avança durante uma requisição.
:::

## Objetos

Estes globais são objetos, então `typeof` retorna `object` para cada um deles:

- globalThis
- JSON
- Math
- Intl
- Reflect
- console
- crypto
- self
- Atomics
- WebAssembly
- performance
- caches: a instância de `CacheStorage` da [Cache API](/pt-br/documentacao/devtools/runtime/api-reference/cache/).
- process: o objeto `process` do Node.js. O `process.env` dele contém as variáveis de ambiente da conta. Para mais informações, consulte [node:process](/pt-br/documentacao/devtools/runtime/node/process/).
- Azion: o namespace das APIs da Azion, que acessam [variáveis de ambiente](/pt-br/documentacao/devtools/runtime/api-reference/environment-variables/), [network lists](/pt-br/documentacao/devtools/runtime/api-reference/network-list/), [Object Storage](/pt-br/documentacao/devtools/runtime/api-reference/storage/), [SQL Database](/pt-br/documentacao/devtools/runtime/api-reference/sql-database/), [KV Store](/pt-br/documentacao/devtools/runtime/api-reference/kv-store/) e [AI Inference](/pt-br/documentacao/devtools/runtime/api-reference/ai/).

## Tempo dentro de uma requisição

Em uma function com deploy feito, `Date.now()` retorna o mesmo valor durante toda a requisição. Ele não avança ao longo de um loop, de um timer ou de uma chamada `fetch()`, e seus milissegundos são `0`. Para medir o tempo decorrido dentro de uma requisição, use `performance.now()`: ele avança durante a requisição e começa em `0`.
