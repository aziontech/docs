O comando `login` da Azion CLI faz login na sua conta da Azion e salva um [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) na sua máquina. A CLI usa esse token para autorizar os comandos que você executa depois do login. As opções que todo comando aceita, como `--help`, `--token` e `-c`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion login` faz as suas perguntas no terminal e faz o login com o método que você escolhe:

```bash
azion login [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--password` | — | string | — | A sua senha. |
| `--username` | — | string | — | O seu endereço de email. |

O comando faz estas perguntas, nesta ordem:

1. `Would you like to create a new profile for this login? (Y/n)`. Com sim, ele pede o nome do [perfil](/pt-br/documentacao/devtools/cli/recursos/profile/) em `Enter a name for the new profile:`.
2. `Choose a login method:`, com as opções _Log in via browser_ e _Log in via terminal_.
3. Com _Log in via terminal_, `Enter your email address:`.

Informar `--username` não pula a pergunta do perfil nem a pergunta do método de login. Execute o comando em um terminal interativo: sem um, ele para na pergunta do nome do perfil com `Failed to get profile name`.

Para autorizar a CLI sem essas perguntas, como em um job de CI, informe um personal token com a opção global `-t`. A CLI salva o token no arquivo `settings.toml` do perfil e o usa em todos os comandos seguintes.

---

## Exemplos

Cada exemplo mostra as perguntas que o comando imprime, até o ponto em que ele espera a sua resposta.

### Escolher um método de login

Este comando inicia o login:

```bash
azion login
```

O comando pergunta se deve criar um perfil e depois mostra os métodos de login. Nesta saída, a resposta à pergunta do perfil é `n`:

```text
🤔 Would you like to create a new profile for this login? (Y/n) n
? Choose a login method:  [Use arrows to move, type to filter]
> Log in via browser
  Log in via terminal
```

Com _Log in via terminal_ selecionado, o comando pede o endereço de email da sua conta:

```text
? Choose a login method: Log in via terminal
? Enter your email address:
```

### Informar o endereço de email

Este comando informa o endereço de email da conta com `--username`:

```bash
azion login --username you@example.com
```

O comando ainda faz a pergunta do perfil e mostra os métodos de login:

```text
🤔 Would you like to create a new profile for this login? (Y/n) n
? Choose a login method:  [Use arrows to move, type to filter]
> Log in via browser
  Log in via terminal
```
