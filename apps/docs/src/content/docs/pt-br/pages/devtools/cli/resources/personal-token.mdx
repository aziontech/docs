Os comandos `personal-token` da Azion CLI criam, listam, descrevem e excluem os seus [personal tokens](/pt-br/documentacao/fundamentos/personal-tokens/), as credenciais que autenticam as suas chamadas à Azion API e os seus comandos da CLI. Cada token tem um UUID, que a flag `--id` recebe. As opções que todo comando aceita, como `--format`, `--out` e `-y`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Criar

`azion create personal-token` cria um personal token com o nome, a expiração e a descrição que você passa:

```bash
azion create personal-token [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--description` | — | string | — | Descrição do personal token. |
| `--expiration` | — | string | — | **Obrigatório**, a menos que `--file` seja definido. Tempo até o token expirar: um número seguido de `d` para dias ou de `m` para meses, como `1d` ou `9m`. Sem ele, o comando pergunta a expiração. |
| `--file` | — | string | — | Caminho de um arquivo JSON com os atributos do personal token. Use `-` para ler o JSON da entrada padrão. |
| `--name` | — | string | — | Nome do personal token. |

Em `--expiration`, `m` significa meses, e não minutos: `9m` cria um token que expira nove meses depois. Um valor sem número, como `tomorrow`, é recusado com `Error: expected integer`.

Este comando cria um token chamado `my-token` que expira no dia seguinte:

```bash
azion create personal-token --name my-token --expiration 1d --description 'Token for local CLI tests'
```

O comando imprime o valor do token. Nenhum outro comando `personal-token` o imprime, então guarde o valor ao criar o token:

```text
Created Personal Token: [TOKEN VALUE]
```

## Listar

`azion list personal-token` lista os seus personal tokens. A lista exibe o UUID, o nome e a expiração de cada token, nunca o valor dele:

```bash
azion list personal-token [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--details` | — | — | — | Adiciona as colunas `CREATED AT` e `DESCRIPTION` às colunas `ID`, `NAME` e `EXPIRES AT`. |

Este comando lista os personal tokens do usuário:

```bash
azion list personal-token
```

O comando imprime uma linha por token. Um token que passou da expiração continua na lista até você excluí-lo, como `old-token` abaixo:

## Descrever

`azion describe personal-token` imprime os atributos de um personal token, sem o valor dele:

```bash
azion describe personal-token [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--id` | — | string | — | UUID do personal token a descrever. |

Este comando descreve o token com UUID `11111111-2222-4333-8444-555555555555`:

```bash
azion describe personal-token --id 11111111-2222-4333-8444-555555555555
```

O comando imprime o UUID, o nome, as datas e a descrição do token:

```text
Uuid:          11111111-2222-4333-8444-555555555555
Name:          my-token
Created:       "2026-10-03T14:50:26.219101Z"
Expires At:    "2026-10-04T11:50:24Z"
Description:   "Token for local CLI tests"
```

Com `--format json`, o comando imprime os mesmos atributos nas chaves `created`, `description`, `expires_at`, `name` e `uuid`.

Um UUID que não corresponde a nenhum token do usuário falha com este erro:

```text
Error: Failed to get your personal token: The given ID or API's endpoint doesn't exist or isn't available. Check that the identifying information is correct. Check your settings and try again. If the error persists, contact Azion support.
```

## Excluir

`azion delete personal-token` exclui um personal token:

```bash
azion delete personal-token [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--id` | — | string | — | **Obrigatório**. UUID do personal token a excluir. Sem ele, o comando pergunta o UUID. |

Este comando exclui o token com UUID `11111111-2222-4333-8444-555555555555`:

```bash
azion delete personal-token --id 11111111-2222-4333-8444-555555555555
```

O comando confirma a exclusão:

```text
Personal token 11111111-2222-4333-8444-555555555555 was successfully deleted
```

Um UUID que não corresponde a nenhum token, como o UUID de um token que você já excluiu, falha com este erro:

```text
Error: Failed to delete the Personal Token: The given ID or API's endpoint doesn't exist or isn't available. Check that the identifying information is correct. Check your settings and try again. If the error persists, contact Azion support
```

## Usar um arquivo JSON

`azion create personal-token` lê os atributos do token de um arquivo JSON com `--file`. O comando lê `name`, `expires_at` e `description`, e `expires_at` aceita os mesmos valores que `--expiration`.

Este arquivo cria um token chamado `my-file-token` que expira nove meses depois de ser criado:

```json
{
  "name": "my-file-token",
  "expires_at": "9m",
  "description": "Token created from a JSON file"
}
```

Passe o arquivo para o comando de criação:

```bash
azion create personal-token --file token-create.json
```

O comando imprime o valor do token:

```text
Created Personal Token: [TOKEN VALUE]
```
