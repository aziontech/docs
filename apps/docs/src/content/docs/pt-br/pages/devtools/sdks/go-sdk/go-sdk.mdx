Um kit de desenvolvimento de software (SDK) para uma API é uma biblioteca que expõe a API como as funções e os tipos de uma linguagem de programação. O seu programa preenche objetos tipados e chama métodos. A biblioteca monta cada requisição HTTP, envia a requisição e devolve a resposta, então você não compõe requisições manualmente.

**Go SDK** é a biblioteca da Azion para Go, publicada no [repositório azionapi-go-sdk](https://github.com/aziontech/azionapi-go-sdk/) no GitHub. Cada serviço da Azion API tem o seu próprio pacote no módulo, como `idns` para [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/). O seu programa cria um cliente para esse pacote com o seu personal token. Use o Go SDK para criar zonas DNS, gerenciar aplicações, functions e domínios ou fazer o purge de conteúdo cacheado a partir de um programa Go.

A [Azion CLI](/pt-br/documentacao/devtools/cli/) e o [Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/) também chamam a [Azion API](/pt-br/documentacao/devtools/api/) por meio do Go SDK. O seu próprio código pode chamar a mesma API diretamente por HTTPS, em vez de usar o SDK.

## Instalar o SDK

O Go SDK é instalado em um módulo Go. Antes de adicioná-lo, a sua máquina e o seu projeto precisam do seguinte:

- Go 1.17 ou posterior.
- Um projeto Go com um arquivo `main.go`.
- Um módulo Go, inicializado com `go mod init <name>`.

Na pasta raiz do projeto, adicione o módulo com `go get`:

```bash
go get github.com/aziontech/azionapi-go-sdk
```

Quando o `main.go` já importa um pacote do SDK, o `go mod tidy` adiciona o módulo ao arquivo `go.mod` do projeto no lugar do `go get`:

```bash
go mod tidy
```

## Programa de exemplo

O programa a seguir cria uma zona do Edge DNS por meio do pacote `idns` do Go SDK. O exemplo chama a Azion API v3: ele define o host da API v3 como servidor e pede a versão 3 no header `Accept`. Copie o programa inteiro para o arquivo `main.go` do seu projeto:

```go
package main

import (
    "bufio"
    "context"
    "fmt"
    "io"
    "net/http"
    "os"
    "strings"

    sdk "github.com/aziontech/azionapi-go-sdk/idns"
)

const (
    intelligentDnsURL = "https://api.azionapi.net/"
)

type Client struct {
    apiClient sdk.APIClient
}

func main() {
    var personalToken string

    fmt.Println("Hey, there! Welcome to iDNS example")

    fmt.Println("Please, provide your Personal Token: ")
    fmt.Scanf("%s", &personalToken)

    err := IDNSHandler(personalToken)
    if err != nil {
        fmt.Println(err)
    }

}

// IDNSHandler
//
//   - I/O operations - asks and reads domain name e zone
//   - Instantiates a new client
//   - Calls NewIdns
func IDNSHandler(personalToken string) error {
    var domainName, dnsZone string
    active := true

    reader := bufio.NewReader(os.Stdin)

    fmt.Println("Plase, provide the Domain Name: ")
    domainName, err := reader.ReadString('\n')
    if err != nil {
        return err
    }
    domainName = strings.Replace(domainName, "\n", "", -1)

    fmt.Println("Enter a dns zone: ")
    dnsZone, err = reader.ReadString('\n')
    if err != nil {
        return err
    }
    dnsZone = strings.Replace(dnsZone, "\n", "", -1)

    var f *http.Client

   client := NewClient(f, intelligentDnsURL, personalToken)
    err = client.NewIdns(&domainName, &dnsZone, &active)
    if err != nil {
        fmt.Println(err)
        return err
    }
    return nil
}

// NewIdns
//   - Instantiate a sdk.Zone object
//   - Instantiate the request and exec it
//   - Prints success or error
func (c *Client) NewIdns(domainName, domain *string, active *bool) error {
    ctx := context.Background()
    idns := new(sdk.Zone)
    idns.Name = domainName
    idns.Domain = domain
    idns.IsActive = active

    fmt.Println("Creating iDNS zone....")

    req := c.apiClient.ZonesApi.PostZone(ctx).Zone(*idns)
    _, httpResp, err := req.Execute()
    if err != nil {
        fmt.Println(httpResp)
        return err
    }
    bytes, err := io.ReadAll(httpResp.Body)
    if err != nil {
        return err
    }

    fmt.Println(string(bytes))
    return nil
}

// NewClient
//   - Instantiates a new skd-api client
//   - Set headers
func NewClient(f *http.Client, url string, token string) *Client {

    conf := sdk.NewConfiguration()

    conf.HTTPClient = f
    conf.AddDefaultHeader("Authorization", "token "+token)
    conf.AddDefaultHeader("Accept", "application/json;version=3")
    conf.Servers = sdk.ServerConfigurations{
        {URL: url},
    }

    return &Client{
        apiClient: *sdk.NewAPIClient(conf),
    }
}
```

O programa tem quatro partes:

- **Importação**: a linha `sdk "github.com/aziontech/azionapi-go-sdk/idns"` carrega o pacote do Edge DNS com o nome `sdk`.
- **Cliente**: `NewClient` cria uma configuração com `sdk.NewConfiguration()` e adiciona dois headers padrão. O `Authorization` leva o seu personal token com o esquema `token` e o `Accept` seleciona a versão da API. Em seguida, a configuração aponta o cliente para uma URL de servidor.
- **Requisição**: `NewIdns` preenche um `sdk.Zone` com `Name`, `Domain` e `IsActive` e depois o envia com `ZonesApi.PostZone(ctx).Zone(*idns)` e `Execute()`.
- **Resposta**: `Execute()` retorna a resposta HTTP junto com o erro. Em caso de sucesso, o programa lê o `Body` da resposta com `io.ReadAll` e o imprime. Em caso de falha, ele imprime a resposta e o erro.

Se você já trabalhou com `net/http`, o cliente e a resposta funcionam da mesma forma. A configuração recebe um `*http.Client`, e o programa lê o corpo da resposta como em qualquer chamada HTTP.

Na pasta raiz do projeto, execute o programa:

```bash
go run main.go
```

O programa pede o seu personal token e, em seguida, o nome do domínio e a zona DNS, um por linha. Ele cria a zona como ativa e imprime o corpo da resposta da API.

## Versão da API e autenticação

Duas configurações do cliente decidem qual API o Go SDK alcança e como cada requisição comprova quem a envia:

- **Versão da API**: o exemplo desta página chama a Azion API v3, por meio da URL do servidor e do header `Accept` que o `NewClient` define. A Azion API v4 serve os seus recursos em `https://api.azion.com/v4`, e alguns recursos mudam entre as versões: a API v4 substitui o recurso Domains da v3 por workloads. Para os recursos e endpoints que mudam, consulte [Migração para API v4](/pt-br/documentacao/fundamentos/api-v4-migration/).
- **Autenticação**: cada requisição do cliente leva um [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) no header `Authorization`. O exemplo escreve o esquema em minúsculas, como `token`, e a Azion API v4 também aceita essa forma. Para criar um token, consulte [Gerencie personal tokens](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).
