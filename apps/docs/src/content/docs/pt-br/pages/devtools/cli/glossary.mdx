Este glossário define os termos que a [Azion CLI](/pt-br/documentacao/devtools/cli/) usa nos seus comandos, nos arquivos de um projeto e em toda a sua documentação.

| Termo | Definição |
| --- | --- |
| Azion Bundler | O adaptador de frameworks open source, publicado em [aziontech/bundler](https://github.com/aziontech/bundler), que permite que a saída de um framework web seja executada na Azion Platform. `azion build` e `azion deploy` o executam por meio do `npx` com o preset do projeto, e [Azion CLI](/pt-br/documentacao/devtools/cli/) descreve onde ele se encaixa. |
| Azion GitHub App | O GitHub App que conecta a sua conta do GitHub à sua conta Azion, para que você importe um repositório e faça o build, o deploy e a gestão dele como uma aplicação. [Gerencie o Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/) descreve como gerenciar a conexão. |
| `azion.config.js` | O arquivo de infraestrutura como código de um projeto, criado a partir das configurações padrão do preset dele e usado como a fonte da verdade da sua configuração. `azion link` o grava como `azion.config.cjs` e `azion sync --iac` como `azion.config.mjs`, e `azion deploy` lê o arquivo `.mjs` quando os dois existem, como [azion.config.js](/pt-br/documentacao/devtools/cli/azion-config-js/) descreve. |
| `azion.json` | O arquivo na pasta `azion` de um projeto em que `azion deploy` grava o ID de cada recurso que cria. O próximo deploy lê esses IDs e atualiza os mesmos recursos em vez de criar novos, como [Azion CLI deploy](/pt-br/documentacao/devtools/cli/deploy/) descreve. |
| deployment do workload | O objeto que indica a aplicação, o firewall e o conjunto de custom pages que atendem o tráfego de um workload. Um workload guarda um deployment, e [Azion CLI workload-deployment](/pt-br/documentacao/devtools/cli/recursos/workload-deployment/) cria, lista e descreve esse deployment. |
| exclusão em cascata | A flag `--cascade` de `azion delete application`, que exclui os recursos listados em `azion/azion.json` do diretório atual. Qualquer flag `--cascade`, inclusive `--cascade=false`, exclui esses recursos, então omita a flag para excluir somente a aplicação, como [Azion CLI application](/pt-br/documentacao/devtools/cli/recursos/application/#excluir) descreve. |
| Git Scope | O campo obrigatório **Git Scope** no Azion Console que escolhe a conta do GitHub cujos repositórios você importa, com **Add GitHub Account** no fim da sua lista suspensa. O campo **Repository** fica desativado até você escolher um escopo, como [Importe um projeto do GitHub](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/importar-um-projeto-existente-do-github/) descreve. |
| noun | A palavra do recurso em `azion <verb> <noun>`, como `application` em `azion create application`. [Comandos de recursos](/pt-br/documentacao/devtools/cli/recursos/) lista todos os nouns e os verbos que cada um recebe. |
| perfil | Uma configuração da CLI em `~/.azion` que guarda um personal token e os dados da conta que a CLI armazena com ele, para que você alterne entre contas ou ambientes com `azion profiles`. [Azion CLI profile](/pt-br/documentacao/devtools/cli/recursos/profile/) cria e exclui perfis. |
| personal token | A credencial que autentica os seus comandos da CLI e as suas chamadas à Azion API, e que cada perfil guarda. [Azion CLI personal-token](/pt-br/documentacao/devtools/cli/recursos/personal-token/) cria, lista, descreve e exclui personal tokens. |
| preset | Um conjunto de configurações padrão de build e deploy para um framework ou uma linguagem, como `astro`, `html` ou `javascript`, que você pode substituir em `azion.config.js`. [Azion CLI presets](/pt-br/documentacao/devtools/cli/recursos/presets/) lista todos os presets que a CLI oferece. |
| template | Um projeto inicial que `azion init` oferece depois que você escolhe um preset, como *Hello World* para o preset *Javascript*. [Azion CLI init](/pt-br/documentacao/devtools/cli/init/) configura um projeto a partir de um preset e de um template. |
