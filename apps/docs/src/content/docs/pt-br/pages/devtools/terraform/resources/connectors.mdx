Um connector define como as suas aplicações se comunicam com as origens que guardam o seu conteúdo. Na API v4, os connectors substituem as origens da API v3. O Azion Terraform Provider gerencia [Connectors](/pt-br/documentacao/plataforma/connectors/) com um recurso e os lê com dois data sources. No provider v1.x, um recurso de origem que pertencia a uma aplicação fazia esse trabalho. Para mover uma configuração v1.x para connectors, consulte [Migre do provider v1.x para a v2.0](/pt-br/documentacao/devtools/terraform/migration-v3-to-v4/).

---

## Recursos de connector

| Recurso | Descrição |
| --- | --- |
| [`azion_connector`](https://registry.terraform.io/providers/aziontech/azion/latest/docs/resources/connector) | Cria e gerencia um connector. |

`azion_connector` recebe as suas configurações em um único atributo aninhado, `connector`. Ele exige `name`, uma string que contém o nome único do connector, e `type`, que é `http` ou `storage`:

- Um connector `http` exige `http_attributes.addresses`, uma lista de endereços de origem. Cada item recebe um `endpoint` com o `address` da origem e os opcionais `http_port`, `https_port` e `active`. `http_attributes` também recebe os opcionais `connection_options` e os módulos `load_balancer` e `origin_shield`.
- Um connector `storage` exige `storage_attributes.bucket`, o nome do bucket que guarda o conteúdo, e recebe um `prefix` opcional.

Depois do apply, `connector.id` contém o ID numérico do connector. A página do recurso no Terraform Registry lista todos os argumentos.

## Exemplo

Esta configuração fixa o provider na versão 2.10.0, cria um connector HTTP para a origem `origin.example.com` nas portas 80 e 443, lê os connectors existentes e exibe o ID do connector em um output. Ela lê o seu personal token da variável `api_token` que [Primeiros passos com o Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/getting-started/) declara.

```hcl
terraform {
  required_providers {
    azion = {
      source  = "aziontech/azion"
      version = "2.10.0"
    }
  }
}

provider "azion" {
  api_token = var.api_token
}

# Create an HTTP connector
resource "azion_connector" "my_origin" {
  connector = {
    name   = "my-origin"
    type   = "http"
    active = true

    http_attributes = {
      addresses = [
        {
          endpoint = {
            address    = "origin.example.com"
            http_port  = 80
            https_port = 443
          }
        }
      ]
    }
  }
}

# Query existing connectors
data "azion_connectors" "all" {}

output "connector_id" {
  value = azion_connector.my_origin.connector.id
}
```
