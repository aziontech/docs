Faça requisições HTTP de saída a partir de uma função usando a API `fetch`, cobrindo os métodos GET, DELETE, POST, PUT e PATCH com dados JSON. Use estes trechos de código quando sua função precisar chamar uma API REST, seja para ler dados, enviar um formulário ou atualizar um recurso, executando próximo ao usuário na rede global da Azion.

## Exemplos

### Get

Esta função lê a lista de itens da API e a retorna ao cliente como JSON:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const response = await fetch(API_URL, {
      method: "GET",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
    });

    if (!response.ok) {
      return new Response(`Upstream error: ${response.status}`, { status: 502 });
    }

    const items = await response.json();
    return new Response(JSON.stringify(items), {
      headers: { "Content-Type": "application/json" },
    });
  },
};
```

### Delete

Esta função exclui o item `42` e retorna o status com que a API responde:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const id = "42";
    const response = await fetch(`${API_URL}/${id}`, {
      method: "DELETE",
      headers: {
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
    });

    return new Response(null, { status: response.status });
  },
};
```

### Post

Esta função cria um item a partir de um corpo JSON e retorna a resposta da API:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const item = { name: "Notebook", price: 25 };
    const response = await fetch(API_URL, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
      body: JSON.stringify(item),
    });

    return new Response(response.body, {
      status: response.status,
      headers: { "Content-Type": response.headers.get("Content-Type") ?? "application/json" },
    });
  },
};
```

### Put

Esta função substitui o item `42` por um novo corpo JSON:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const id = "42";
    const item = { name: "Notebook", price: 30 };
    const response = await fetch(`${API_URL}/${id}`, {
      method: "PUT",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
      body: JSON.stringify(item),
    });

    return new Response(response.body, {
      status: response.status,
      headers: { "Content-Type": response.headers.get("Content-Type") ?? "application/json" },
    });
  },
};
```

### Patch

Esta função altera só o campo `price` do item `42`:

```js
const API_URL = "https://api.example.com/items";

export default {
  async fetch(request, env, ctx) {
    const id = "42";
    const changes = { price: 28 };
    const response = await fetch(`${API_URL}/${id}`, {
      method: "PATCH",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${Azion.env.get("API_TOKEN")}`,
      },
      body: JSON.stringify(changes),
    });

    return new Response(response.body, {
      status: response.status,
      headers: { "Content-Type": response.headers.get("Content-Type") ?? "application/json" },
    });
  },
};
```

## Como funciona

Cada exemplo é uma função completa no padrão ES Modules. O handler `fetch` chama `fetch()` com a URL da API e um objeto de opções: `method` seleciona o verbo HTTP, `headers` leva o `Content-Type` e o token de autorização, e `body` leva a string JSON que `JSON.stringify()` produz. O token vem da [variável de ambiente](/pt-br/documentacao/devtools/runtime/api-reference/environment-variables/) `API_TOKEN` por meio de `Azion.env.get()`, então ele fica fora do código. `await fetch()` resolve em um `Response`. O exemplo de GET o lê com `response.json()`, e os outros exemplos retornam ao cliente o status e o corpo da resposta da API. Substitua `https://api.example.com/items` e os valores de exemplo pelos da sua API.
