O comando `presets` da Azion CLI lista os presets com os quais você faz o build e o deploy de um projeto. Um preset dá a um projeto as configurações de build padrão de um framework ou de uma linguagem, e você escolhe um ao configurar um projeto com [Azion CLI init](/pt-br/documentacao/devtools/cli/init/) ou [Azion CLI link](/pt-br/documentacao/devtools/cli/link-comando/). As opções que todo comando aceita, como `--format`, `--out` e `-y`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Listar

`azion list presets` imprime o nome de cada preset que a CLI oferece:

```bash
azion list presets [flags]
```

O comando não recebe flags próprias. Uma flag de listagem como `--details` é recusada com `Error: unknown flag: --details`.

Este comando lista os presets:

```bash
azion list presets
```

O comando imprime uma linha de status e um aviso de descontinuação do Node.js, e depois uma linha por preset:


A lista é impressa apenas como texto. Com `--format json`, o comando imprime a linha de status e o aviso, e nenhum preset.

O comando também cria uma pasta `.edge` no diretório atual. Quando esse diretório tem um arquivo `.env`, o comando o copia para `.edge/.env`.

`azion link --preset` recebe um nome desta lista: `azion link --preset html` configura um site HTML que serve a pasta `./www`. Um nome que a lista não traz, como `static`, falha com `Error: exit status 1`. `azion build --preset` altera o preset de um projeto durante o build.

O seletor de presets de `azion init` é uma lista separada. Ele traz entradas que este comando não imprime, como _AI Studio_ e _Hono_, e não tem a entrada _Html_. Para configurar um site HTML, execute `azion link --preset html`.
