Este glossário define os termos que a [Azion Lib](/pt-br/documentacao/devtools/azion-lib/) usa nos seus pacotes e em toda a sua documentação.

| Termo | Definição |
| --- | --- |
| cliente | O objeto que uma função `createClient` retorna, que guarda o seu token e as suas opções e expõe as chamadas de um ou mais módulos. O [createClient](/pt-br/documentacao/devtools/azion-lib/client/#createclient) do pacote `azion` retorna um cliente com uma propriedade por módulo, seis no total, e cada módulo também cria o próprio cliente. Uma função chamada sem cliente lê o token de `AZION_TOKEN`, como [Clientes de módulo e funções independentes](/pt-br/documentacao/devtools/azion-lib/client/#clientes-de-modulo-e-funcoes-independentes) descreve. |
| envelope de resposta | O objeto que uma função de módulo retorna em vez de lançar um erro: `data` contém o resultado em caso de sucesso, e `error` contém `{ message, operation }` em caso de falha. Cada página de módulo documenta a própria forma do envelope, como [Storage](/pt-br/documentacao/devtools/azion-lib/storage/#envelope-de-resposta), em que uma exclusão bem-sucedida não retorna `data`. O [AI client](/pt-br/documentacao/devtools/azion-lib/ai-client/#envelope-de-resposta) preenche `error` com um `Error` do JavaScript, e os helpers de Applications que atuam sobre a própria aplicação lançam um erro em vez disso. |
| módulo | Uma biblioteca da Azion Lib, como Storage, SQL ou JWT, importada do próprio caminho. O caminho é um subcaminho do pacote `azion`, como `azion/purge`, ou um pacote com escopo, como `@aziontech/storage`. A documentação também chama um módulo de biblioteca, e [Client](/pt-br/documentacao/devtools/azion-lib/client/#modulos) lista os seis módulos que o cliente acessa. |
| pacote com escopo | Um pacote publicado no escopo npm `@aziontech` que traz um único módulo, como `@aziontech/storage`. Sete módulos têm um pacote assim: storage, sql, jwt, utils, config, types e unenv-preset. Os outros sete existem apenas no pacote `azion`, que recebe apenas correções de bugs, e a manutenção dele termina em dezembro de 2026. |
| preset | Configurações do bundler que um build aplica, em um de dois sentidos. O preset de build é o campo `preset` de `build` em uma configuração da Azion: um nome como `javascript` ou um objeto `AzionBuildPreset`, como [Config](/pt-br/documentacao/devtools/azion-lib/config/) descreve. O preset unenv é o export padrão de `@aziontech/unenv-preset`, `{ inject, alias, external, polyfill }`, como [Preset unenv](/pt-br/documentacao/devtools/azion-lib/unenv/) descreve. |
