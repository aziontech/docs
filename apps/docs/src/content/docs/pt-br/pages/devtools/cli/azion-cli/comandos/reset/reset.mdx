O comando `reset` da Azion CLI restaura os padrões das configurações que a CLI armazena e exclui o seu personal token quando consegue. Use-o quando a configuração local estiver inconsistente ou para recomeçar a partir de uma configuração limpa. O comando afeta somente a CLI e não altera os seus projetos. As opções que todo comando aceita, como `--config` e `-y`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion reset` esvazia as configurações armazenadas na configuração da CLI:

```bash
azion reset [flags]
```

O comando não tem flags próprias. Com a opção global `-c`, ele redefine a configuração na pasta que contém o caminho `.toml` que você passa.

:::caution[Atenção]
`azion reset` não pede confirmação. Ele esvazia o token, o client ID e o email armazenados, então um comando que precisa da sua conta, como `azion whoami`, falha até você fazer login de novo com [Azion CLI login](/pt-br/documentacao/devtools/cli/login/).
:::

---

## Exemplos

Cada exemplo mostra o comando e a saída que ele imprime.

### Redefinir as configurações da CLI

Este comando restaura os padrões das configurações da CLI:

```bash
azion reset
```

O comando imprime uma linha quando a redefinição termina:

```text
Sucessfully reset to default settings
```

Depois da redefinição, todos os valores do arquivo `settings.toml` da CLI ficam vazios ou zerados:

```text
Token = ''
UUID = ''
LastCheck = 0001-01-01T00:00:00Z
LastVulcanVersion = ''
AuthorizeMetricsCollection = 0
ClientId = ''
Email = ''
ContinuationToken = ''
S3AccessKey = ''
S3SecretKey = ''
S3Bucket = ''
```

### Verificar a configuração depois de uma redefinição

Este comando mostra qual conta a CLI usa:

```bash
azion whoami
```

A redefinição volta `AuthorizeMetricsCollection` para `0`, então o comando primeiro pergunta se você concorda em compartilhar dados de uso anônimos. Em seguida, ele falha, porque nenhuma conta está armazenada:

```text
🤔 To better understand user needs and enhance our application, we gather anonymous data. Do you agree to participate? (Y/n) Error: You must be logged in to use the 'whoami' command
```
