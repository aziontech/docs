O comando `clone` da Azion CLI copia um recurso com um novo nome. O seu único subcomando, `application`, cria uma [Application](/pt-br/documentacao/plataforma/applications/) com a configuração de uma existente, incluindo as regras do [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/). As opções que todo comando aceita, como `--format`, `--out` e `-y`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion clone` recebe como subcomando o tipo do recurso a copiar:

```bash
azion clone <subcommand> [flags]
```

O comando não tem flags próprias. `-h` ou `--help` imprime a ajuda do comando. O único subcomando é `application`.

---

## Application

`azion clone application` cria uma aplicação a partir da configuração da aplicação cujo ID você passa:

```bash
azion clone application [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--application-id` | — | int | — | ID da aplicação a copiar. |
| `--name` | — | string | — | **Obrigatório**. Nome da nova aplicação. Sem ela, o comando pergunta o nome. |

O comando imprime o nome da nova aplicação, não o ID dela. Para encontrar o ID, execute `azion list application`. A sua conta precisa de permissão para clonar aplicações.

---

## Exemplos

Cada exemplo mostra o comando e a saída que ele imprime.

### Clonar uma aplicação

Este comando copia a aplicação com ID `1791039175` para uma nova aplicação chamada `my-site-clone`:

```bash
azion clone application --application-id 1791039175 --name my-site-clone
```

O comando confirma a cópia:

```text
Application my-site-clone cloned successfully
```

### Encontrar o ID do clone

Este comando lista as aplicações cujo nome contém `my-site`:

```bash
azion list application | grep -E 'ID|my-site'
```

O clone aparece com um ID próprio, ao lado da aplicação da qual foi copiado:

```text
ID          NAME             ACTIVE
1791039175  my-site          true
1791049178  my-site-clone    true
```

### Verificar as regras do clone

Este comando lista as regras do clone na fase de requisição:

```bash
azion list rules-engine --application-id 1791049178 --phase request
```

O clone contém as regras da aplicação da qual foi copiado:

```text
ID      NAME
742326  Deliver Static Assets and Set Cache Policy
742324  Redirect to index.html
742325  Redirect to index.html for Subpaths
```
