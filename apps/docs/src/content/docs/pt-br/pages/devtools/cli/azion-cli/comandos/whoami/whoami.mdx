O comando `whoami` da Azion CLI imprime o client ID, o email e o perfil ativo que a CLI armazena para a sua conta da Azion. Use-o para saber para qual conta a CLI está configurada quando você trabalha com mais de uma conta da Azion na mesma máquina. As opções que todo comando aceita, como `--config` e `--debug`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion whoami` lê os dados da conta na configuração local da CLI e os imprime:

```bash
azion whoami [flags]
```

O comando não tem flags próprias. `-h` ou `--help` imprime o texto de ajuda do comando.

Quando a CLI não tem nenhuma conta logada, por exemplo depois de `azion reset`, o comando para com `Error: You must be logged in to use the 'whoami' command`. Execute `azion login` antes para autenticar a CLI.

A configuração do perfil armazena o client ID e o email. `azion logout` esvazia somente o [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) armazenado, então, depois de um logout, `azion whoami` ainda imprime o mesmo client ID e o mesmo email.

---

## Exemplos

Este comando mostra a conta com que a CLI está logada:

```bash
azion whoami
```

O comando imprime o client ID, o email e o perfil ativo, um por linha:

```text
 Client ID: 1234u
 Email: you@example.com
 Active Profile: default
```
