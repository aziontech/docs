O dataset `workloadConsumptionMetrics` da GraphQL API contém o uso que a Azion contabilizou para cada workload, produto e métrica, com um registro por hora. Envie as queries desse dataset para `https://api.azion.com/v4/consumption/graphql`, com a janela a ler no filtro `tsRange`. A Azion mantém os dados de consumo por até 24 meses, e uma conta do tipo group ou reseller pode consultar o consumo de todas as contas de cliente vinculadas a ela.

---

## workloadConsumptionMetrics

O dataset `workloadConsumptionMetrics` retorna os campos abaixo. Os argumentos que ele aceita, como `filter`, `groupBy` e `limit`, estão em [Datasets e argumentos de query](/pt-br/documentacao/devtools/graphql/recursos/).

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `accounted` | `Decimal` | Quantidade total de uso do produto contabilizada para o cliente. Uma linha lida sem `aggregate` retorna o valor como string, como `"3578"`. Com `sum: accounted`, a soma retorna como número, como `442444116.0`. |
| `clientId` | `String` | Identificador único do cliente na Azion. Exemplo: `1234u`. |
| `countryCode` | `String` | Código do país onde a Azion processou o uso, não do país a partir do qual o usuário acessou o serviço. Exemplo: `BR`. |
| `metricName` | `String` | Nome da métrica medida. Exemplo: `data_transferred_total`. |
| `modulesBitwise` | `Int` | Um inteiro retornado em todo registro de uso. Exemplo: `8`. |
| `productId` | `Int` | Identificador único do produto ao qual o uso pertence. Exemplo: `1441740010`. |
| `region` | `String` | Região onde a Azion processou o uso, não a região a partir da qual o usuário acessou o serviço. Exemplo: `United States`. |
| `ts` | `CustomDateTime` | Timestamp do registro de uso, em UTC. O dataset contém um registro por hora, então o valor cai na hora cheia. Exemplo: `2026-10-03T03:00:00Z`. |
| `workloadId` | `Int` | Identificador do workload associado ao uso. Exemplo: `1788127218`. |

O dataset também retorna as saídas de agregação `count`, `sum`, `max`, `min`, `avg` e `rate`, cada uma selecionada pelo argumento `aggregate`. Apenas `workloadConsumptionMetrics` e `imagesProcessedMetrics` retornam `rate`.

## Exemplo de query

Esta query lê todos os campos dos três registros de uso mais recentes em uma janela de sete dias de `workloadConsumptionMetrics`:

```graphql
query {
  workloadConsumptionMetrics(limit: 3, filter: { tsRange: {begin: "2026-09-26T14:00:00", end: "2026-10-03T14:00:00"} }, orderBy: [ts_DESC]) {
    ts
    clientId
    workloadId
    countryCode
    region
    productId
    metricName
    modulesBitwise
    accounted
  }
}
```

## IDs de produto e nomes de métrica

Um registro de `workloadConsumptionMetrics` identifica o produto em `productId` e a métrica em `metricName`. Filtre pelos dois para ler o uso de um produto e de uma métrica:

| Produto | ID do produto | Nome da métrica | O que a métrica conta |
| --- | --- | --- | --- |
| [Data Stream](/pt-br/documentacao/plataforma/data-stream/) | `1498670028` | `data_streamed` | Volume total de dados transmitidos pelo Data Stream. |
| Data Stream | `1498670028` | `requests` | Número total de requisições processadas pelo Data Stream. |
| [Applications](/pt-br/documentacao/plataforma/applications/) | `1441740010` | `data_transferred_total` | Quantidade total de dados transferidos pelo Applications. |
| Applications | `1441740010` | `requests` | Número total de requisições recebidas pelo Applications. |
| Applications | `1441740010` | `waf_requests` | Número total de requisições inspecionadas pelo WAF. |
| [Functions](/pt-br/documentacao/plataforma/functions/) | `1531930033` | `compute_time` | Tempo total de execução de Functions, em milissegundos. |
| Functions | `1531930033` | `invocations` | Número total de vezes que uma function foi executada. |
| [Image Processor](/pt-br/documentacao/plataforma/applications/image-processor/configuracoes/) | `1441110021` | `images_processed` | Número total de imagens processadas pelo Image Processor. |
| [Tiered Cache](/pt-br/documentacao/plataforma/applications/cache/tiered-cache/) | `1564082375` | `data_transferred_total` | Quantidade total de dados transferidos pelo Tiered Cache. |
| Tiered Cache | `1564082375` | `requests` | Número total de requisições de cache processadas pelo Tiered Cache. |

Cada produto tem um guia com uma query de uso completa. Para mais informações, consulte [Consulte dados de uso do Data Stream](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-data-stream-com-graphql/), [Consulte os dados de uso de Applications](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-edge-application-com-graphql/), [Consulte dados de uso de Functions](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-edge-functions-com-graphql/), [Consulte dados de uso do Image Processor](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-image-processor-com-graphql/) e [Consulte dados de uso do Tiered Cache](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-tiered-cache-com-graphql/).

## Regiões e países

Os campos `countryCode` e `region` de `workloadConsumptionMetrics` indicam o local onde a Azion processou o uso. A arquitetura de rede e o roteamento determinam esse local, então ele pode ser diferente do local a partir do qual o usuário acessou o serviço e da origem dos dados.

`workloadConsumptionMetrics` agrupa os países nestas regiões:

| Região | Países |
| --- | --- |
| All Other Regions | Angola, South Africa |
| Brazil | Brazil |
| Canada | Canada |
| Europe | Deutschland, Spain, France, Great Britain, Italy, Netherlands, United Kingdom |
| Latam | Argentina, Bolivia, Chile, Colombia, Ecuador, Mexico, Peru, Paraguay, Uruguay, Venezuela |
| No Region | No Region |
| North America | Canada, United States |
| United States | United States |
