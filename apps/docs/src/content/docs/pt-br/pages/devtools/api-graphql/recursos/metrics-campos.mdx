Os datasets do Real-Time Metrics da GraphQL API contêm dados de requisições que a Azion agrega em buckets de tempo, atendidos pelo endpoint de metrics, `https://api.azion.com/v4/metrics/graphql`. Cada seção desta página lista os campos de um dataset: o nome que uma query seleciona, o tipo que o schema declara, o que o campo contém e um valor de exemplo. Os mesmos campos são a base do [Real-Time Metrics](/pt-br/documentacao/plataforma/real-time-metrics/) no Azion Console, onde alguns dashboards também oferecem um campo `domains`, que lista todos os domínios configurados na conta.

Um campo que resulta de um cálculo, como uma soma, é um *campo calculado*, e cada dataset lista os seus campos calculados em uma tabela própria. Um campo descontinuado continua no schema, e a sua linha indica o campo que o substitui. Para filtrar, agrupar e ordenar por esses campos, consulte [Datasets e argumentos de query](/pt-br/documentacao/devtools/graphql/recursos/).

## workloadMetrics

`workloadMetrics` contém os dados de requisições de [Applications](/pt-br/documentacao/plataforma/applications/) e do Web Application Firewall (WAF) de um [firewall](/pt-br/documentacao/plataforma/firewall/), em buckets de minuto, hora e dia. `httpMetrics` foi descontinuado; use `workloadMetrics`. Os dois atendem os mesmos campos e retornam as mesmas linhas.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `bytesSent` | Int | Número de bytes enviados a um cliente. O valor é uma soma. Exemplo: `191` |
| `configurationId` | String | Identificador único de configuração da Azion definido no arquivo de configuração do virtual host. Exemplo: `1595368520` |
| `geolocCountryName` | String | Nome do país resolvido a partir do endereço IP do cliente. Exemplo: `Canada` |
| `geolocRegionName` | String | Nome da região ou do estado resolvido a partir do endereço IP do cliente. Exemplo: `Parana` |
| `host` | String | Informação de host enviada na linha da requisição: o nome do host da linha da requisição, o nome do host do header de requisição `Host` ou o nome do servidor que corresponde à requisição. Exemplo: `www.example.com` |
| `proxyStatus` | Int | Código de status HTTP de erro, ou da origem, quando nenhuma resposta é obtida do upstream. Exemplo: `500` |
| `remoteAddressClass` | String | Classe do endereço IP da origem que gerou a requisição. Exemplo: `192.0.2.0/24` |
| `requestLength` | Int | Tamanho da requisição em bytes, incluindo a linha da requisição, os headers e o corpo. O valor é uma soma. Exemplo: `167` |
| `requestMethod` | String | Método da requisição HTTP. Exemplo: `GET` ou `POST` |
| `requestTime` | Decimal | Tempo de processamento da requisição, em segundos, desde que os primeiros bytes foram lidos do cliente. O valor é uma soma. Exemplo: `0.234` |
| `requests` | Int | Quantidade total de requisições na agregação em uso. O valor é uma soma. Exemplo: `11` |
| `scheme` | String | Esquema da requisição. Exemplo: `HTTP` ou `HTTPS` |
| `sentHttpXOriginalImageSize` | Int | O header `X-Original-Image-Size` enviado na resposta da origem, usado pelo Image Processor para informar o tamanho original da imagem. O valor é uma soma. Exemplo: `987390` |
| `serverProtocol` | String | Versão do protocolo da requisição. Exemplo: `HTTP/1.1`, `HTTP/2.0` ou `HTTP/3.0` |
| `sourceLocPop` | String | Localização do servidor da Azion que recebeu a requisição. Exemplo: `lax-bso` |
| `sslProtocol` | String | Protocolo de uma conexão TLS estabelecida. Exemplo: `TLS v1.2` |
| `status` | Int | Código de status HTTP da requisição. Exemplo: `200` |
| `ts` | CustomDateTime | Timestamp de quando o evento foi criado. Exemplo: `2026-10-03T13:00:00Z` |
| `upstreamBytesReceived` | Int | Número de bytes recebidos da origem quando o conteúdo não está em cache. O valor é uma soma. Exemplo: `8304` |
| `upstreamCacheStatus` | String | Status do cache local: `MISS`, `BYPASS`, `EXPIRED`, `STALE`, `UPDATING`, `REVALIDATED`, `HIT` ou `-` |
| `upstreamResponseTime` | Decimal | Tempo que a Azion leva para receber a resposta da origem, em segundos, incluindo headers e corpo. O valor é uma soma. Exemplo: `0.876` |
| `upstreamStatus` | Int | Código de status HTTP da origem. Quando nenhum servidor pode ser selecionado, o valor é `502` (Bad Gateway). Exemplo: `200` |
| `wafAttackFamily` | String | Categoria do ataque detectado pelo WAF, com base nas suas características. Exemplo: `$SQL`, `$RFI`, `$XSS` ou `$OTHERS` |
| `wafBlock` | String | Indica se a requisição foi bloqueada pelo WAF: `0` quando não foi e `1` quando foi. No [modo _Logging_](/pt-br/documentacao/plataforma/firewall/waf/score-e-modos/), que este dataset chama de learning, nenhuma requisição é bloqueada pelo WAF, qualquer que seja o valor. |
| `wafLearning` | String | Indica se WAF roda no modo _Logging_, que o nome do campo chama de learning. Retorna `0` quando não roda e `1` quando roda. |

## workloadBreakdownMetrics

`workloadBreakdownMetrics` detalha os dados de requisições de Applications por atributos da requisição, como path, user agent e rede do cliente, em buckets de hora. `httpBreakdownMetrics` foi descontinuado; use `workloadBreakdownMetrics`. Os dois atendem os mesmos campos e retornam as mesmas linhas.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `geolocAsn` | String | Alocação do Autonomous System Number (ASN), consultada na tabela MaxMind. Exemplo: `AS52580 Azion Technologies Ltda.` |
| `geolocCountryName` | String | País do cliente remoto, detectado pela geolocalização do endereço IP. Exemplo: `United States` ou `Russian Federation` |
| `geolocRegionName` | String | — Exemplo: `Pernambuco` |
| `host` | String | Informação de host enviada na linha da requisição: o nome do host da linha da requisição, o nome do host do header de requisição `Host` ou o nome do servidor que corresponde à requisição. Exemplo: `www.example.com` |
| `httpReferer` | String | Endereço da página a partir da qual a requisição foi feita. Exemplo: `https://example.com` |
| `httpUserAgent` | String | Valor do header `User-Agent`: a aplicação, o sistema operacional, o fornecedor ou a versão do usuário final. Exemplo: `Mozilla/5.0 (Windows NT 10.0; Win64; x64)` |
| `remoteAddress` | String | Endereço IP da origem que gerou a requisição. Exemplo: `192.0.2.10` |
| `requestPath` | String | Path da requisição feita pelo usuário final, sem o host, o protocolo e os argumentos. Exemplo: `/v1/application` |
| `sentHttpContentType` | String | O header `Content-Type` enviado na resposta da origem. Exemplo: `text/html; charset=UTF-8` |
| `ts` | CustomDateTime | Timestamp de quando o evento foi criado. Exemplo: `2026-10-03T13:00:00Z` |
| `upstreamAddr` | String | Endereço IP e porta do upstream. Também pode conter vários servidores ou grupos de servidores. Exemplo: `192.0.2.1:80`. O valor `127.0.0.1:1666` indica que o upstream é Azion Runtime. |

### Campos calculados

Os campos calculados de `workloadBreakdownMetrics` são o resultado de um cálculo, como uma soma, sobre as requisições de cada bucket:

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `blockedRequests` | Int | Quantidade total de requisições bloqueadas na agregação em uso. O valor é uma soma. Exemplo: `17` |
| `requests` | Int | Quantidade total de requisições na agregação em uso. O valor é uma soma. Exemplo: `11` |
| `wafThreatRequests` | Int | Quantidade total de requisições detectadas e bloqueadas pelo WAF por causa de ameaças de segurança identificadas. Exemplo: `1523` |

`connectedUsersMetrics` contém os dados de sessões do [Live Ingest](/pt-br/documentacao/plataforma/connectors/live-ingest/ingestao-e-entrega/), em buckets de minuto.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `host` | String | Host de onde os dados foram coletados. |
| `ts` | CustomDateTime | Timestamp do ponto de dados. Exemplo: `2026-10-03T13:00:00Z` |

### Campos calculados

Os campos calculados de `connectedUsersMetrics` contam as sessões únicas de cada bucket:

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `uniqueSessions` | Int | Número de sessões únicas registradas para o host. |
| `uniqueSessionsTotal` | Int | Total de sessões únicas calculado em todos os hosts. |

## botManagerMetrics

`botManagerMetrics` contém os dados de requisições do [Bot Manager](/pt-br/documentacao/plataforma/firewall/bot-manager/score-de-bots/), em buckets de minuto. O dataset retorna dados apenas em uma conta com assinatura do Bot Manager.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `action` | String | Ação executada pelo Bot Manager em uma requisição identificada como bot: `allow`, `deny`, `redirect`, `custom_html`, `drop`, `random_delay` ou `hold_connection`. Exemplo: `deny` |
| `botCategory` | String | Categoria de bot identificada na requisição. Exemplo: `scraping`, `crawling` ou `brute-force` |
| `botMode` | String | Modo de proteção contra bots da requisição. Exemplo: `Web` |
| `challengeSolved` | String | Indica se o bot passou no desafio CAPTCHA: `1` para resolvido e `0` para não resolvido. |
| `classified` | String | Identificação do tráfego: `bad bot`, `good bot`, `legitimate` ou `under evaluation`. |
| `geolocCountryName` | String | País de onde veio o ataque de bot. Exemplo: `Brazil` |
| `geolocRegionName` | String | Estado ou região de onde veio o ataque de bot. Exemplo: `Pernambuco` |
| `host` | String | Informação de host enviada na linha da requisição: o nome do host da linha da requisição, o nome do host do header de requisição `Host` ou o nome do servidor que corresponde à requisição. Exemplo: `www.example.com` |
| `requestMethod` | String | Método HTTP da requisição. Exemplo: `GET` |
| `sourceLocPop` | String | Localização do servidor da Azion que recebeu a requisição. Exemplo: `lax-bso` |
| `ts` | CustomDateTime | Timestamp de quando o evento foi criado. Exemplo: `2026-10-03T13:00:00Z` |

Os sete valores de `action` são as ações que podem ser executadas pelo Bot Manager. Para saber o que cada uma faz, como a resposta `403` de `deny`, consulte [Argumentos](/pt-br/documentacao/plataforma/firewall/bot-manager/argumentos/#action).

### Campos calculados

O campo calculado de `botManagerMetrics` é uma soma sobre as requisições de cada bucket:

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `requests` | Int | Quantidade total de requisições analisadas pelo Bot Manager. O valor é uma soma. Exemplo: `11` |

## botManagerBreakdownMetrics

`botManagerBreakdownMetrics` detalha os dados de requisições do Bot Manager por endereço do cliente e URL, em buckets de minuto. O dataset retorna dados apenas em uma conta com assinatura do Bot Manager.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `host` | String | Informação de host enviada na linha da requisição: o nome do host da linha da requisição, o nome do host do header de requisição `Host` ou o nome do servidor que corresponde à requisição. Exemplo: `www.example.com` |
| `remoteAddr` | String | Endereço IP da origem que gerou a requisição. Exemplo: `192.0.2.10` |
| `requestUrl` | String | URL da requisição feita pelo usuário final, com o host e o path e sem argumentos. Exemplo: `www.example.com/v1` |
| `ts` | CustomDateTime | Timestamp de quando o evento foi criado. Exemplo: `2026-10-03T13:00:00Z` |

### Campos calculados

Os campos calculados de `botManagerBreakdownMetrics` contam as requisições de bots de cada bucket:

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `badBotRequests` | Int | Quantidade total de requisições classificadas como bots maliciosos. O valor é uma soma. Exemplo: `12` |
| `botRequests` | Int | Quantidade total de requisições classificadas como bots. O valor é uma soma. Exemplo: `11` |
| `uniqRequestUrl` | Int | Número de URLs distintas que bots requisitaram. Exemplo: `5` |

## l2CacheMetrics

`l2CacheMetrics` contém os dados de requisições do Tiered Cache, em buckets de minuto, hora e dia, e o schema dá a ele os mesmos campos de `tieredCacheMetrics`.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `bytesSent` | Int | Número de bytes enviados a um cliente. O valor é uma soma. Exemplo: `191` |
| `configurationId` | String | Identificador único de configuração da Azion definido no arquivo de configuração do virtual host. Exemplo: `1595368520` |
| `host` | String | Informação de host enviada na linha da requisição: o nome do host da linha da requisição, o nome do host do header de requisição `Host` ou o nome do servidor que corresponde à requisição. Exemplo: `www.example.com` |
| `proxyStatus` | Int | Código de status HTTP de erro, ou da origem, quando nenhuma resposta é obtida do upstream. Exemplo: `520` |
| `remoteAddressClass` | String | Classe do endereço IP da origem que gerou a requisição. Exemplo: `192.0.2.0/24` |
| `requestLength` | Int | Tamanho da requisição em bytes, incluindo a linha da requisição, os headers e o corpo. O valor é uma soma. Exemplo: `167` |
| `requestMethod` | String | Método da requisição HTTP. Exemplo: `GET` ou `POST` |
| `requestTime` | Decimal | Tempo de processamento da requisição, em segundos, desde que os primeiros bytes foram lidos do cliente. O valor é uma soma. Exemplo: `0.234` |
| `requests` | Int | Quantidade total de requisições na agregação em uso. O valor é uma soma. Exemplo: `11` |
| `scheme` | String | Esquema da requisição. Exemplo: `HTTP` ou `HTTPS` |
| `sourceLocPop` | String | Localização do servidor da Azion que recebeu a requisição. Exemplo: `lax-bso` |
| `status` | Int | Código de status HTTP da requisição. Exemplo: `200` |
| `ts` | CustomDateTime | Timestamp de quando o evento foi criado. Exemplo: `2026-10-03T13:00:00Z` |
| `upstreamBytesReceived` | Int | Número de bytes recebidos da origem quando o conteúdo não está em cache. O valor é uma soma. Exemplo: `8304` |
| `upstreamCacheStatus` | String | Status do cache local: `MISS`, `BYPASS`, `EXPIRED`, `STALE`, `UPDATING`, `REVALIDATED`, `HIT` ou `-` |
| `upstreamResponseTime` | Decimal | Tempo que a Azion leva para receber a resposta da origem, em segundos, incluindo headers e corpo. O valor é uma soma. Exemplo: `0.876` |
| `upstreamStatus` | Int | Código de status HTTP da origem. Quando nenhum servidor pode ser selecionado, o valor é `502` (Bad Gateway). Exemplo: `200` |

### Campos calculados

Os campos calculados de `l2CacheMetrics` são o resultado de um cálculo, como uma soma, sobre as requisições de cada bucket:

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `dataTransferredIn` | Float | Soma do tamanho da requisição, em bytes. Quando a requisição não é um cache hit, o tamanho da requisição é somado mais uma vez. Exemplo: `1202` |
| `dataTransferredOut` | Float | Soma dos bytes enviados. Quando a requisição não é um cache hit, os bytes enviados do upstream são somados. Exemplo: `6460` |
| `dataTransferredTotal` | Float | `dataTransferredIn` mais `dataTransferredOut`, em bytes. Exemplo: `766` |
| `offload` | Float | Porcentagem dos dados do cliente entregues pela Azion, o que economiza dados. Exemplo: `9.71` |

## idnsQueriesMetrics

`idnsQueriesMetrics` contém os dados de consultas do Edge DNS, em buckets de minuto, hora e dia. Ele atende os mesmos campos de `dnsQueriesMetrics` e retorna as mesmas linhas.

| Campo | Tipo | Descrição |
| --- | --- | --- |
| `qtype` | String | Tipo do registro que a consulta pede. Exemplo: `PTR`, `A`, `AAAA`, `HTTPS`, `NS` ou `SRV` |
| `requests` | Int | Quantidade total de requisições na agregação em uso. O valor é uma soma. Exemplo: `11` |
| `sourceLocPop` | String | Localização do servidor da Azion que recebeu a requisição. Exemplo: `lax-bso` |
| `ts` | CustomDateTime | Timestamp de quando o evento foi criado. Exemplo: `2026-10-03T12:00:00Z` |
| `zoneId` | String | Identificador único da zona do Edge DNS. Exemplo: `1340` |

O campo da zona é `zoneId`, com `d` minúsculo. Uma query que agrupa por `zoneID` retorna `400`, com um `detail` que termina em `Expected type "IdnsQueriesMetricsGroupByFields", found zoneID.`
