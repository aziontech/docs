**Edge Services** permite que serviços orquestrados sejam gerenciados em seus próprios edge nodes. Para isso, você deve ter um edge service criado e vinculá-lo a um edge node.

<DocButton href="/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/criar-edge-service-v3/" label="ir para o guia de como criar um edge service" kind="secondary" target="_blank" size="medium" />

Você pode criar uma relação entre um edge node e um edge service no Azion Console ou com a Azion API.

## Vincule o edge service ao edge node

<Tabs client:visible sharedStore="interface">
    <Fragment slot="tab.console">Console</Fragment>
    <Fragment slot="tab.api">API</Fragment>

<Fragment slot="panel.console">

### Console

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Selecione o edge node que você deseja vincular a um serviço.
3. Na aba **Main Settings**, procure a opção **Add-On Services** na seção **Orchestration Modules** e ative-a.
4. Vá para a aba **Services** e selecione **+ Service**.
5. Escolha o serviço que deseja vincular e adicione as variáveis se necessário.
6. Selecione **Save**.
</Fragment>

<Fragment slot="panel.api">

### API

1. Execute a seguinte requisição `GET` em seu terminal, substituindo `[TOKEN VALUE]` pelo seu [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) para recuperar o ID do edge node que você deseja vincular a um edge service:

```bash
curl --location 'https://api.azionapi.net/edge_nodes/' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]'
```

2. Execute a seguinte requisição `GET` em seu terminal, substituindo `[TOKEN VALUE]` pelo seu [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) e recupere o ID do edge service que você deseja vincular a um edge node:

```bash
curl --location 'https://api.azionapi.net/edge_services/' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]'
``` 

3. Execute a seguinte requisição `POST` em seu terminal:

```bash
curl --location 'https://api.azionapi.net/edge_nodes/:id/services' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]' \
--header 'Content-Type: application/json' \
--data '{
"service_id": 0,
"variables": [
{
"name": "string",
"value": "string"
}
]
}'
```

Substitua `[TOKEN VALUE]` pelo seu [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/), `:id` pelo ID do edge node e informe as seguintes propriedades no corpo da requisição:

| Propriedade | Descrição | Obrigatório | 
| - | - | - | 
| `service_id` | ID do edge service sendo vinculado ao edge node | Sim |
| `variables` | Variáveis a serem substituídas durante o processamento no edge node | Não  |

Agora, seu edge node e seu edge service têm uma relação entre eles e estão prontos para serem orquestrados. 

:::tip[dica]
Confira a [documentação da API da Azion](https://api.azion.com/v3) e a [especificação OpenAPI](https://github.com/aziontech/azionapi-openapi/) para saber mais sobre todos os recursos disponíveis via API.
:::
