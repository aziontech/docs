Se você já instalou o [Azion Orchestrator Agent](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/instalar-orchestrator-agent/) no seu dispositivo, o próximo passo é autorizar o edge node na plataforma. Você pode fazer isso no Azion Console. A API v4 não tem endpoints do Orchestrator.

<DocButton href="/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/instalar-orchestrator-agent/" label="instalar o orchestrator agent" kind="secondary" size="medium" />

## Autorize o edge node

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Encontre o edge node que você deseja autorizar, que terá o status `Waiting Authorization`.
3. Selecione o ícone de três pontos e depois selecione **Authorize**.
4. Confirme a autorização.

Depois da autorização, um edge node pode levar até 10 segundos para que serviços possam ser orquestrados nele.

## Autorize vários edge nodes de uma vez

Para autorizar vários edge nodes em uma única ação no Azion Console:

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Selecione os edge nodes que você quer autorizar. Para selecionar todos os edge nodes da lista, selecione a caixa de seleção no cabeçalho da lista.
3. Selecione **Actions** e depois selecione **Authorize**.
4. Selecione **Confirm**.

Uma mensagem de confirmação aparece.
