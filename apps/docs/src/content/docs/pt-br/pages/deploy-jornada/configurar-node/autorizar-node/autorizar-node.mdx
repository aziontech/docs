Se você já instalou o [Azion Orchestrator Agent](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/instalar-orchestrator-agent/) no seu dispositivo, o próximo passo é autorizar o edge node na plataforma. Você pode fazer isso no Azion Console ou com a Azion API.

## Autorize o edge node

<Tabs client:visible sharedStore="interface">
    <Fragment slot="tab.console">Console</Fragment>
    <Fragment slot="tab.api">API</Fragment>

<Fragment slot="panel.console">

### Console

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Encontre o edge node que você deseja autorizar, que terá o status `Waiting Authorization`.
3. Selecione o ícone de três pontos e depois selecione **Authorize**.
4. Confirme a autorização.
</Fragment>

<Fragment slot="panel.api">

### API

1. Execute a seguinte requisição `GET` no seu terminal, substituindo `[TOKEN VALUE]` pelo seu [token pessoal](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/):

```bash 
curl --location 'https://api.azionapi.net/edge_nodes/' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]'
```

2. Execute a seguinte requisição `PATCH` no seu terminal, substituindo `[TOKEN VALUE]` pelo seu [token pessoal](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) e informando o ID do edge node:

```bash 
curl --location --request PATCH 'https://api.azionapi.net/edge_nodes/authorize' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]' \
--header 'Content-Type: application/json' \
--header 'accept: application/json; version=3' \
--data '{
    "edge_node_ids": [
        0
    ]
}'
```

Agora, seu edge node está autorizado e pode trabalhar com [edge services](/pt-br/documentacao/plataforma/orchestrator/edge-services/). 

:::tip[dica]
Confira a [documentação da API Azion](https://api.azion.com/) e a [especificação OpenAPI](https://github.com/aziontech/azionapi-openapi/) para saber mais sobre todos os recursos disponíveis via API.
:::
</Fragment>

</Tabs>

Depois da autorização, um edge node pode levar até 10 segundos para que serviços possam ser orquestrados nele.

## Autorize vários edge nodes de uma vez

Para autorizar vários edge nodes em uma única ação no Azion Console:

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Selecione os edge nodes que você quer autorizar. Para selecionar todos os edge nodes da lista, selecione a caixa de seleção no cabeçalho da lista.
3. Selecione **Actions** e depois selecione **Authorize**.
4. Selecione **Confirm**.

Uma mensagem de confirmação aparece.
