Você pode criar um edge service no Azion Console ou com a Azion API.

## Crie o edge service

<Tabs client:visible sharedStore="interface">
    <Fragment slot="tab.console">Console</Fragment>
    <Fragment slot="tab.api">API</Fragment>

<Fragment slot="panel.console">

### Console

1. Acesse o [Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/) > **Edge Services**.
2. Clique no botão **+ Service**.
3. Nomeie seu serviço.
4. Defina as variáveis a usar, se necessário.
    - As variáveis devem seguir o padrão "Variável = Valor".
5. Defina o status como **Active**.
6. Clique no botão **Save**.
7. Selecione a aba **Resources** e [forneça recursos](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/provisionar-arquivos-v3/) para seu serviço.
</Fragment>

<Fragment slot="panel.api">

### API

1. Execute a seguinte requisição `POST` no seu terminal, substituindo `[TOKEN VALUE]` pelo seu [token pessoal](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) e informando o nome do serviço a ser criado:

```bash
curl --location 'https://api.azionapi.net/edge_services/' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]' \
--header 'Content-Type: application/json' \
--data '{
"name": "string"
}'
```

2. Guarde o `id` retornado no corpo da resposta. A API cria o serviço com `"active": false`.

3. Execute a seguinte requisição `PATCH` para definir o serviço como ativo, substituindo `[TOKEN VALUE]` pelo seu token pessoal e `:id` pelo ID do edge service:

```bash
curl --location --request PATCH 'https://api.azionapi.net/edge_services/:id' \
--header 'Accept: application/json; version=3' \
--header 'Authorization: Token [TOKEN VALUE]' \
--header 'Content-Type: application/json' \
--data '{
  "active": true
}'
```

Agora, o serviço está ativo e você pode vinculá-lo aos seus edge nodes.

:::note[nota]
Se um edge service não estiver definido como ativo, ele não estará disponível para vinculação a um edge node.
:::

:::tip[dica]
Confira a [documentação da API da Azion](https://api.azion.com/v3) e a [especificação OpenAPI](https://github.com/aziontech/azionapi-openapi/) para saber mais sobre todos os recursos disponíveis via API.
:::
