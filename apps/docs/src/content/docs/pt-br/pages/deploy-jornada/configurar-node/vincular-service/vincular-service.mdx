**Edge Services** permite que serviços orquestrados sejam gerenciados em seus próprios edge nodes. Para isso, você deve ter um edge service criado e vinculá-lo a um edge node.

<DocButton href="/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/criar-edge-service/" label="ir para o guia de como criar um edge service" kind="secondary" target="_blank" size="medium" />

Você pode criar uma relação entre um edge node e um edge service no Azion Console. A API v4 não tem endpoints do Orchestrator.

## Vincule o edge service ao edge node

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Selecione o edge node que você deseja vincular a um serviço.
3. Na aba **Main Settings**, procure a opção **Add-On Services** na seção **Orchestration Modules** e ative-a.
4. Vá para a aba **Services** e selecione **+ Service**.
5. Escolha o serviço que deseja vincular e adicione as variáveis se necessário.
6. Selecione **Save**.
