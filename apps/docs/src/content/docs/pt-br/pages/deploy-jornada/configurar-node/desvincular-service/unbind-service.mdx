Você pode desvincular um edge service de um edge node no Azion Console. A API v4 não tem endpoints do Orchestrator.

---

## Desvincule o edge service

1. Acesse [Azion Console](https://console.azion.com/) > **Edge Nodes**.
2. Selecione o edge node do qual você deseja desvincular um serviço.
3. Vá para a aba **Services**.
4. Encontre o serviço que você deseja desvincular e selecione o ícone de lixeira.
5. Confirme a desvinculação.
