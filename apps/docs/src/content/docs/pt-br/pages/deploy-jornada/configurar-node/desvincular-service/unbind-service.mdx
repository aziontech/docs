Você pode desvincular um edge service de um edge node no Azion Console. A API v4 não tem endpoints do Orchestrator.

---

## Desvincule o edge service

1. Acesse o [Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
2. No canto superior esquerdo da página, abra o **Products menu**, representado por três linhas horizontais, e então selecione **Edge Nodes**.
3. Selecione o edge node do qual você deseja desvincular um serviço.
4. Vá para a aba **Services**.
5. Encontre o serviço que você deseja desvincular e clique no ícone de lixeira.
6. Confirme a desvinculação.
