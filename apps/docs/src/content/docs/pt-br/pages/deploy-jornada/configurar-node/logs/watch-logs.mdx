**Orchestrator Agent** escreve dois logs em cada node que gerencia: o log dele próprio e um log dos serviços vinculados àquele node. Você lê os dois em um terminal no node. Juntos, eles dizem se o agente alcançou o servidor e se os triggers de um serviço rodaram.

---

## Pré-requisitos

- Orchestrator Agent instalado no node. Para instalá-lo, consulte [Instalar o Orchestrator Agent](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/instalar-orchestrator-agent/).
- Acesso de shell àquele node, com permissão para executar `sudo`.

---

## Ler o log do Orchestrator Agent

O agente escreve em `/var/log/azion/edge-orchestrator.log`. Toda entrada desse arquivo vem do próprio agente, não de um serviço que o agente executa.

Para abrir o log do agente no node:

```bash
sudo vim /var/log/azion/edge-orchestrator.log
```

:::note[nota]
Você pode escolher o editor de texto que quiser, desde que ele esteja instalado no node.
:::

O arquivo abre no editor. Ele guarda a versão do manifesto, a comunicação do agente com o servidor e os erros que o agente registrou.

---

## Ler o log dos serviços

Os serviços vinculados ao node escrevem em `/var/log/azion/edge-services.log`, um arquivo separado do log do próprio agente.

Para abrir o log dos serviços no node:

```bash
sudo vim /var/log/azion/edge-services.log
```

O arquivo abre no editor. Ele guarda os registros escritos pelos triggers de instalação, atualização e exclusão configurados dentro desses serviços.
