Você pode ler as requisições que um rule set do [Web Application Firewall (WAF)](/pt-br/documentacao/plataforma/firewall/waf/) correspondeu e transformar as legítimas em exceções na aba **Tuning** do Azion Console. A Azion CLI e a API não têm um comando de Tuning. Para escrever uma exceção à mão, consulte [Crie uma exceção do WAF](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/configurar-waf-allowed-rules/).

---

## Pré-requisitos

- Um rule set que uma regra de um Firewall aplica com um behavior _Set WAF_. Consulte [Crie e aplique um WAF rule set](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/criar-waf-rule-set/).
- Um Workload cujo deployment define esse Firewall. A aba **Tuning** exige um.
- Requisições que o rule set pontuou nos últimos 3 dias, o intervalo de tempo mais longo que o Tuning lê. O WAF pontuou requisições apenas quando a Application as enviou a um Connector.
- Acesso ao [Azion Console](https://console.azion.com/). Consulte [Acesse Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

---

## Filtre os registros do Tuning

Uma consulta lê um intervalo de tempo e pelo menos um Workload. Os outros filtros a restringem. Para ler os registros no Azion Console:

<DocSteps>
  <DocStep title="Abra a página WAF Rules">

  Acesse [Azion Console](https://console.azion.com/) > **WAF Rules**.

  </DocStep>
  <DocStep title="Selecione o rule set a ajustar" />
  <DocStep title="Selecione a aba Tuning" />
  <DocStep title="Escolha um intervalo de tempo">

  As opções vão de **Last 1 hour** a **Last 3 days**.

  </DocStep>
  <DocStep title="Selecione um ou mais Workloads">

  Esse filtro é obrigatório. Em uma conta que ainda usa domínios, o filtro mostra **Domain** em vez de **Workload**.

  </DocStep>
  <DocStep title="(Opcional) Selecione uma Network List">

  A consulta então retorna apenas os registros cujo endereço do cliente está na [Network List](/pt-br/documentacao/plataforma/firewall/network-shield/network-lists/).

  </DocStep>
  <DocStep title="(Opcional) Adicione um filtro de campo">

  Selecione **Filter**, escolha **Country** ou **IP Address** e então selecione **Apply**.

  </DocStep>
</DocSteps>

O Console mostra quantos registros encontrou e lista uma linha por regra interna que correspondeu, com as colunas **Rule ID**, **Hits**, **Paths**, **IPs**, **Countries**, **Top 10 IP Addresses** e **Top 10 Countries**.

:::note[nota]
O campo **IP Address** não pode ser combinado com uma Network List de IP ou CIDR, e o campo **Country** não pode ser combinado com uma Network List de países. O Console avisa quando uma consulta carrega os dois.
:::

Para cada filtro e cada coluna desta aba, consulte [WAF Exceptions](/pt-br/documentacao/plataforma/firewall/waf/custom-allowed-rules/#tuning).

## Crie exceções a partir dos registros

O Azion Console chama uma exceção de allowed rule. Uma seleção escreve várias delas, uma para cada possível ataque em cada caminho. Para permitir registros no Azion Console:

<DocSteps>
  <DocStep title="Selecione um rule ID na lista de resultados">

  O drawer **More Details** abre com as ocorrências desse rule ID.

  </DocStep>
  <DocStep title="Selecione os registros a permitir">

  Marque a caixa de seleção de cada registro.

  </DocStep>
  <DocStep title="Selecione Allow Rules" />
  <DocStep title="Informe o motivo para permitir essas regras">

  O motivo vira a descrição de cada allowed rule.

  </DocStep>
  <DocStep title="Selecione Allow Rules para confirmar" />
</DocSteps>

O Console mostra quantas allowed rules criou, e cada uma aparece na aba **Allowed Rules** do rule set.

Quando o Console escreve apenas parte de uma seleção, ele mostra a mensagem **Partial failure** com o número criado. Selecione os registros restantes e permita-os de novo.
