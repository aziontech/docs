Você pode apontar um domínio raiz para um hostname da Azion com um registro ANAME no [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/) pelo Azion Console, pela Azion CLI ou pela Azion API. Edge DNS então responde às consultas pelo apex com os endereços desse hostname. Para apontar um subdomínio como `www`, consulte [Aponte um subdomínio com CNAME](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/subdominio-cname/).

O apex, também chamado de domínio raiz ou naked domain, é o seu domínio sem nenhum subdomínio, como `example.com`. Um registro CNAME não pode ficar no apex, então o registro ANAME ocupa o lugar dele ali. Para entender o motivo, consulte [Como o Edge DNS funciona](/pt-br/documentacao/plataforma/edge-dns/como-funciona/#aname-no-apex).

## Pré-requisitos

- Uma zona para o seu domínio no Edge DNS. Para criar uma, consulte [Crie, edite ou exclua uma zona](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/edge-dns-definir-main-settings/).
- A permissão **Edit Edge DNS**, que requer **View Edge DNS**. Consulte [Permissões de equipes](/pt-br/documentacao/fundamentos/teams-permissions/).
- O hostname da Azion para o qual o registro aponta, como o domínio do workload `<your-workload>.map.azionedge.net`. Para encontrá-lo e fazer o workload aceitar o seu domínio raiz, consulte [Aponte um domínio para um workload](/pt-br/documentacao/guias/plataforma/migracao/apontar-dominio-para-a-azion/).

## Adicione o registro ANAME no apex

O nome de registro `@` representa o apex. O valor é um hostname sob `azioncdn.net`, `azionedge.net` ou `azionedge.com`, e o TTL é sempre `20`. Para editar ou excluir o registro depois, consulte [Adicione, edite ou exclua um registro](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/adicionar-registros/).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para adicionar o registro pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a página do Edge DNS">

  Acesse [Azion Console](https://console.azion.com/) > **Edge DNS**.

  </DocStep>
  <DocStep title="Abra a zona">

  Na página **Zones**, selecione a linha da zona que contém o seu domínio.

  </DocStep>
  <DocStep title="Selecione a aba Records" />
  <DocStep title="Selecione + Record">

  O drawer **Create Record** é aberto.

  </DocStep>
  <DocStep title="Informe @ como nome">

  Em **Name**, informe `@`. O Console adiciona o domínio para você, então o registro responde por `example.com`.

  </DocStep>
  <DocStep title="Selecione o tipo de registro ANAME">

  Em **Record Type**, selecione *ANAME - Maps a name to another name*. O Console define **TTL (seconds)** como `20`.

  </DocStep>
  <DocStep title="Mantenha o TTL em 20">

  Deixe **TTL (seconds)** em `20`. Edge DNS recusa qualquer outro TTL para um registro ANAME.

  </DocStep>
  <DocStep title="Informe o hostname">

  Em **Value**, informe o hostname da Azion, como `<your-workload>.map.azionedge.net`. Informe um hostname, nunca um endereço IP.

  </DocStep>
  <DocStep title="Mantenha a política Simple">

  Na seção **Policy**, mantenha **Policy Type** em *Simple*. O campo **Weight** fica indisponível para um registro ANAME.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Console mostra `Edge DNS Record has been created`, e o registro aparece na tabela **Records**.

</Fragment>

<Fragment slot="panel.cli">

Para adicionar o registro pela Azion CLI, substitua `<zone-id>` pelo ID da sua zona e o valor pelo seu hostname:

```bash
azion create dns-record --zone-id <zone-id> --name @ --type ANAME --rdata <your-workload>.map.azionedge.net --ttl 20
```

O comando mostra o ID do registro:

```text
Created DNS record with ID 100779
```

A zona contém o registro ANAME no apex. Em `--name`, `@` representa o domínio: nunca digite o próprio domínio.

</Fragment>

<Fragment slot="panel.api">

Para adicionar o registro pela Azion API, envie uma requisição `POST` ao endpoint de registros da zona. Substitua `<zone-id>` pelo `id` da sua zona e o valor em `rdata` pelo seu hostname:

```bash
curl -X POST https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records \
  -H "Authorization: Token [TOKEN VALUE]" \
  -H "Content-Type: application/json" \
  -d '{"name":"@","type":"ANAME","rdata":["<your-workload>.map.azionedge.net"],"ttl":20}'
```

Um `201` retorna o registro:

```json
{
  "state": "executed",
  "data": {
    "id": 100186,
    "description": "",
    "name": "@",
    "ttl": 20,
    "type": "ANAME",
    "rdata": ["<your-workload>.map.azionedge.net"],
    "policy": "simple",
    "weight": 255
  }
}
```

A zona contém o registro ANAME no apex. Em `name`, `@` representa o domínio: nunca envie o próprio domínio.

</Fragment>

</Tabs>

A API recusa um registro ANAME com qualquer TTL diferente de `20` com `19011`, e um hostname fora dos três domínios da Azion com `19016`. Para todas as regras do tipo, consulte [Tipos de registro](/pt-br/documentacao/plataforma/edge-dns/tipos-de-registro/#aname).

## Consulte o apex nos nameservers da Azion

Consulte o nameserver da Azion diretamente, sem o cache do seu resolver, para confirmar que ele responde pelo apex. Esta verificação funciona antes de o seu registrador delegar o domínio à Azion.

Para consultar o apex em `ns1.aziondns.net`, substitua `example.com` pelo seu domínio:

```bash
dig +short @ns1.aziondns.net example.com A
```

O nameserver retorna os endereços do hostname, um por linha:

```text
<address>
<address>
```

O próprio Edge DNS consulta o hostname e responde pelo apex com os endereços dele como registros A. Sem `+short`, a saída mostra `status: NOERROR`, a flag `aa`, um TTL de `20` em cada registro A e nenhum CNAME na resposta.

Se o comando não mostrar nada, aguarde alguns minutos e execute-o novamente. Depois que você adiciona ou altera um registro, a alteração pode levar alguns minutos para chegar a todos os nameservers. Para mais informações, consulte [Como o Edge DNS funciona](/pt-br/documentacao/plataforma/edge-dns/como-funciona/#cache-e-propagacao).

Os resolvers na internet só usam o registro depois que o seu registrador delega o domínio aos três nameservers do Edge DNS. Para a delegação, consulte [Migre nameservers para a Azion](/pt-br/documentacao/guias/plataforma/migracao/migrar-ns-para-a-azion/).
