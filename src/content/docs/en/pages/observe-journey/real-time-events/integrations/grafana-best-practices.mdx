You can control what a Grafana panel renders by setting the fields the Azion data source plugin adds to the panel's query editor. Every rule on this page applies to that editor, which holds the query itself and the fields that tell Grafana how to read the response.

A panel set to _Time series_ requires two of those fields: **Time path** and **Group by**.

---

## Prerequisites

- Grafana with the Azion data source plugin. To install and authorize it, refer to [Connect Grafana to Azion](/en/documentation/guides/platform/observability/integrate-grafana/).
- A dashboard panel that reads the Azion data source. To build one, refer to [Customize a Grafana log table](/en/documentation/guides/platform/observability/azion-plugin-grafana-customize-log-table/).

---

## Write the query

The query field holds the query the panel sends. It names the dataset the panel reads and the filters that narrow it, and [Data sources](/en/documentation/platform/real-time-events/data-sources/) lists every dataset the plugin can query. When the query uses a Grafana variable, replace the variable directly in the query's field.

---

## Reference a nested field by its flattened name

Nested objects are flattened with underscores. Write the flattened name wherever the editor asks for a field name, including **Time path**, **Group by**, and **Alias by**.

---

## Set the time path

**Time path** takes a timestamp. The timestamp is in `ISO8601` format or in a configurable custom format.

---

## Group the data into data points

**Group by** is what turns one result into multiple data points. Set it to the field the aggregation runs on.

---

## Rename a field in the legend

**Alias by** sets the name a field carries in the panel legend. Substitute `$field_<field.name>` with the values for the field. Substitute `$fieldName` with a name for the field.

---

## Annotate the graph

Grafana carries annotations as a dashboard feature, so no field in the query editor sets one. Use [annotations](https://grafana.com/docs/grafana/latest/dashboards/build-dashboards/annotate-visualizations/) to mark points on a graph.

---

## Set the dashboard time range

The dashboard carries its own [time range](https://grafana.com/docs/grafana/latest/dashboards/use-dashboards/#time-units-and-relative-ranges). Use it to explore and analyze your data.
