You can read the observability data of your applications on Azion from a Grafana dashboard, with the Azion data source plugin. The plugin queries [Real-Time Metrics](/en/documentation/platform/real-time-metrics/) and [Real-Time Events](/en/documentation/platform/real-time-events/) through the [GraphQL API](/en/documentation/devtools/graphql/overview/). Grafana renders what a query returns as charts and tables.

The plugin is not published through the Grafana plugin catalog. You install it from source on a Grafana instance that runs locally. An Azion personal token authorizes the queries the plugin sends.

---

## Prerequisites

- An Azion account. To create one, refer to [How to create an account on Azion](/en/documentation/fundamentals/creating-account/).
- A personal token. To create one, refer to [Personal Tokens](/en/documentation/fundamentals/personal-tokens/).
- One or more [applications](/en/documentation/platform/applications/) on your account, so that the datasets hold records to query.
- A [Grafana](https://grafana.com/) instance that runs locally and that you administer.

---

## Install the plugin on a local Grafana instance

The plugin works only with a local Grafana instance. It is unsigned, so that instance must accept unsigned plugins before it loads the data source.

Azion maintains the plugin as an open-source project, and the install procedure ships with the source. For the install steps, refer to the [Azion Grafana plugin repository](https://github.com/aziontech/grafana-plugin).

The plugin authenticates with your personal token. Supply the token when you configure the Azion data source in Grafana. Grafana can then query Real-Time Metrics and Real-Time Events from a dashboard panel.
