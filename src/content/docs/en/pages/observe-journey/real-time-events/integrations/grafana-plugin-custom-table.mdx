With the Azion data source plugin, you can build a Grafana dashboard panel that shows the Azion data you need. This page covers the panel itself: the data source, the query, the five fields that shape the result, and the visualization type.

Connecting Grafana to your account is a separate task. For more information, refer to [Install the Azion plugin for Grafana](/en/documentation/guides/platform/observability/integrate-grafana/).

---

## Prerequisites

- A Grafana instance running on your machine. To install one, refer to the [Azion Grafana plugin repository](https://github.com/aziontech/grafana-plugin).
- The Azion plugin installed on that instance and authorized. For more information, refer to [Install the Azion plugin for Grafana](/en/documentation/guides/platform/observability/integrate-grafana/).
- A query that returns the [Real-Time Events](/en/documentation/platform/real-time-events/) data you want the panel to show.

---

## Build the panel

A panel holds one query and one visualization type. The five fields below map the fields the query returns onto the visualization.

To add a panel that reads Azion data, in Grafana:

<DocSteps>
  <DocStep title="Open the dashboard list">

  Select **Dashboards**. The dashboard page opens.

  </DocStep>
  <DocStep title="Create a dashboard">

  Beside the search bar, _search_, select **New** > **New Dashboard**.

  </DocStep>
  <DocStep title="Select Add visualization" />
  <DocStep title="Select the data source">

  On the **Data source** dropdown, select _Azion_.

  </DocStep>
  <DocStep title="Enter the query">

  In the code box, enter the query the panel runs. For example queries, refer to [GraphQL API](/en/documentation/devtools/graphql/overview/).

  </DocStep>
  <DocStep title="Complete the panel fields">

  Five fields complete the setup. Which ones you fill depends on the visualization type and on what the panel shows:

  - **Data path**: enter the value `Events`.
  - **Time path**: enter a timestamp. The field is dot-delimited.
  - **Time format**: enter a time format in [moment.js format](https://momentjs.com/docs/#/parsing/string/).
  - **Group by**: use this field when you want the data grouped in aggregated form.
  - **Alias by**: use this field to change the value and the name a field carries in the legend.

  </DocStep>
  <DocStep title="Select the visualization type">

  On the **Visualization** list, select the type the panel uses. To read raw event records in large volume, or a top X query, Azion recommends the _Table_ type. You can combine it with other types of charts and graphs.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

Grafana saves the panel, and the dashboard shows the data the query returns.
