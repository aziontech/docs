You can write the data a stream produces into an [Object Storage](/en/documentation/store/object-storage/) bucket, by pointing a [Data Stream](/en/documentation/guides/platform/observability/use-data-stream/) connector at the bucket's S3 endpoint. Once the stream is active, Azion writes an object into the bucket for each batch of records it sends.

This guide covers the connector alone. For the stream itself, its data source, and its filters, refer to [Use Data Stream](/en/documentation/guides/platform/observability/use-data-stream/).

---

## Prerequisites

- An Object Storage bucket to write into. To create one, refer to [Create a bucket](/en/documentation/guides/application-development/data/create-and-modify-bucket/).
- An S3 credential whose capabilities include **List Files** and **Write Files**. Data Stream lists the bucket and writes objects into it, and a credential without both is rejected at save. To create one, refer to [Use S3-compatible tools with Object Storage](/en/documentation/guides/application-development/data/use-s3-compatible-tools-with-object-storage/).
- The credential's access key and secret key. The secret key is shown only when the credential is created.
- Permission to edit streams in your account. For more information, refer to [Teams Permissions](/en/documentation/fundamentals/teams-permissions/).

---

## Configure the connector

The connector needs the bucket's S3 address, the region, and the credential's key pair.

<DocSteps>
  <DocStep title="Open the stream">

  Access [Azion Console](https://console.azion.com/) > **Data Stream**, and open the stream you want to change or start a new one.

  </DocStep>
  <DocStep title="Select the connector type">

  On the **Connector** dropdown, select **Simple Storage Service (S3)**.

  </DocStep>
  <DocStep title="Enter the endpoint and the bucket">

  In **URL**, enter the Object Storage S3 host, `s3.us-east-005.azionstorage.net`. In **Bucket Name**, enter the name of your bucket. In **Region**, enter `us-east-005`.

  </DocStep>
  <DocStep title="Enter the credential">

  In **Access Key** and **Secret Key**, enter the key pair of the S3 credential. Both fields are masked after saving, and only a user with the `Edit Data Stream` permission can reveal them.

  </DocStep>
  <DocStep title="Set the object key prefix">

  In **Object Key Prefix**, enter the path the objects are written under, such as `user/logs`. The field is optional; leaving it empty writes to the root of the bucket.

  </DocStep>
  <DocStep title="Set the content type">

  In **Content Type**, select the format of the objects Azion writes. The field accepts `plain/text` or `application/gzip`.

  </DocStep>
  <DocStep title="Activate the connector">

  Turn the **Active** switch on.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The stream now writes to the bucket. Azion assembles each object's key from the prefix, the date and time the batch was sent in the format `YYYY/MM/DD/hh/mm/`, and a UUID, as in `user/logs/2026/09/17/22/45/37d66e78-c308-4006-9d4d-1c013ed89276`.

## Confirm the data is arriving

Two places show whether the connector is working.

<DocSteps>
  <DocStep title="List the objects in the bucket">

  Replace `[TOKEN VALUE]` with your [personal token](/en/documentation/guides/platform/account-and-billing/personal-tokens/) and the bucket name with your own:

  ```bash
  curl --request GET \
    --url 'https://api.azion.com/v4/workspace/storage/buckets/my-bucket/objects?prefix=user/logs/' \
    --header 'Accept: application/json' \
    --header 'Authorization: Token [TOKEN VALUE]'
  ```

  The response lists one entry per object written, each with its key, its size in bytes, and when it was last modified:

  ```json
  {
    "continuation_token": null,
    "results": [
      {
        "key": "user/logs/2026/09/17/22/45/37d66e78-c308-4006-9d4d-1c013ed89276",
        "last_modified": "2026-09-17T22:45:17.394000Z",
        "size": 4821,
        "is_folder": false
      }
    ]
  }
  ```

  </DocStep>
  <DocStep title="Read the delivery attempts">

  Access [Azion Console](https://console.azion.com/) > **Real-Time Events**, select **Data Source** > **Data Stream**, and filter as you need. Each row records one delivery attempt from Data Stream to the bucket, including the ones that failed.

  </DocStep>
</DocSteps>

An object under the prefix and a successful delivery in Real-Time Events together confirm the connector.
