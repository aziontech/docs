[Application Accelerator](/en/documentation/build/application-accelerator/) changes one bound on a cache setting of an [Applications](/en/documentation/platform/applications/) resource: the shortest time the cache holds an object. This page carries that bound, the bound at the other end of the range, and the condition that decides which one is in force. For the fields these values apply to, with their types and defaults, refer to [Settings](/en/documentation/build/application-accelerator/settings/).

---

## Cache TTL

`modules.cache.max_age` sets how long the cache holds an object, in seconds. Azion Console renders the field as **Max Age**, in the **Cache** section of a cache setting. The field is an integer from 0 to 31,536,000, and it takes no value outside that range. Application Accelerator and [Tiered Cache](/en/documentation/build/cache/tiered-cache/) decide how low inside the range a cache setting goes.

| Limit | Value | Applies when |
| --- | --- | --- |
| Minimum cache TTL | 60 seconds | Application Accelerator is off on the application. |
| Minimum cache TTL | 0 seconds | Application Accelerator is on and Tiered Cache is off. |
| Minimum cache TTL | 3 seconds | Application Accelerator is on and Tiered Cache is on. |
| Maximum cache TTL | 31,536,000 seconds, one year | Every cache setting, whichever modules are on. |

The 3-second floor belongs to Tiered Cache, not to Application Accelerator. Tiered Cache holds the cache layer to at least 3 seconds, which narrows the 0-second floor Application Accelerator unlocks.

Limits are raised on request, according to the plan on the account. To ask for an increase, contact the [technical support](/en/documentation/support/) team.

Application Accelerator on an application can generate usage-related costs. For more information, refer to [Pricing](/en/documentation/fundamentals/pricing/#application-accelerator).

## Limits from other products

A request that Application Accelerator varies is still bounded by the products that hold the object and run the code on it. Each value below sits on the page of the product that owns it.

[Cache](/en/documentation/build/cache/) carries the limits on the object itself: the size of a single object held in cache, and the size of a slice file when a large file is split into fragments. For those values, refer to [Cache](/en/documentation/build/cache/).

Where the application also runs a function, that function carries its own limits on the code and on each invocation. For more information, refer to [Functions](/en/documentation/build/functions/).
