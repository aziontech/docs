This guide instructs you through storing and reading your first row in [SQL Database](/en/documentation/store/sql-database/), using Azion Console. By the end you will have:

- Your first database, with the status `created`.
- A `users` table inside it.
- One row stored in that table.
- The same row returned by a `SELECT` statement.

Prefer the API? Refer to [SQL Database quickstart using the API](/en/documentation/store/sql-database/quickstart-api/).

The result rests on two objects. The **database** is the container, and its name cannot be changed after creation. Each **table** lives inside one database, and this guide creates the table with a `CREATE TABLE` statement in the **Editor** tab. A database is provisioned asynchronously. Its status reads `creating` first, and a statement runs against it only after the status reads `created`.

---

## Prerequisites

- Access to Azion Console. To sign in, refer to [How to access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).
- SQL Database enabled on the account. The product is in Preview, and access is requested through the technical support team. To request it, refer to [Technical Support](/en/documentation/support/).
- The **Edit SQL Database** permission on the account. It grants permission to create and edit databases and their data through the Azion API. For more information, refer to [Teams Permissions](/en/documentation/fundamentals/teams-permissions/).

## 1. Create a database

A database holds the tables you create. To create your first one:

<DocSteps>
  <DocStep title="Open the database list">

  Access [Azion Console](https://console.azion.com/) > **SQL Database**.

  </DocStep>
  <DocStep title="Open the create form">

  Start a new database from the list, with the **SQL Database** control.

  </DocStep>
  <DocStep title="Name the database">

  Under **General**, in **Name**, enter a name of 6 to 50 characters, using letters, numbers, and the hyphen. A name another database in the account holds is refused.

  </DocStep>
  <DocStep title="Select Save" />
</DocSteps>

The database appears in the list, which shows its **Name**, **Status**, **Last Editor**, and **Last Modified**. Its status reads `creating` until it reads `created`, which takes about 15 seconds.

---

## 2. Create a table

The **Editor** tab runs SQL against one database. To create the table this guide uses:

<DocSteps>
  <DocStep title="Open the database">

  In the **SQL Database** list, select the database you created.

  </DocStep>
  <DocStep title="Go to the Editor tab" />
  <DocStep title="Enter the CREATE TABLE statement">

  Create the `users` table with three columns:

  ```sql
  CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT, email TEXT);
  ```

  </DocStep>
  <DocStep title="Select Run query" />
</DocSteps>

The table appears under the **Tables** tab.

---

## 3. Insert a row

An `INSERT` statement stores a row in the table. To store the first one:

<DocSteps>
  <DocStep title="Enter the INSERT statement">

  In the **Editor** tab, enter the following statement:

  ```sql
  INSERT INTO users (name, email) VALUES ('Ada', 'ada@example.com');
  ```

  </DocStep>
  <DocStep title="Select Run query" />
</DocSteps>

The table holds one row.

---

## 4. Read the row back

A `SELECT` statement returns what the table holds. To read the row you inserted:

<DocSteps>
  <DocStep title="Enter the SELECT statement">

  In the **Editor** tab, enter the following statement:

  ```sql
  SELECT id, name, email FROM users;
  ```

  </DocStep>
  <DocStep title="Select Run query" />
</DocSteps>

The result carries one row under the columns `id`, `name`, and `email`: `1`, `Ada`, and `ada@example.com`.

Your first database holds a `users` table with one row, and the **Editor** reads it back. The same statements run through the Azion API and inside a function.
