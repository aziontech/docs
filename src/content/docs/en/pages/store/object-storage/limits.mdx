[Object Storage](/en/documentation/store/object-storage/) bounds the name of a bucket, the key of an object, how many records one list request returns, and how many buckets and access keys an account holds. This page states each bound and what the platform does past it. It also states the storage and the operations each service plan includes in a month. To request a higher limit for the account, contact the [technical support](/en/documentation/support/) team.

---

## Default limits

Object Storage applies each bound below by default. Where the Azion API rejects a request past a bound, it answers HTTP `400`, and the Past the limit column names the error code and the title the response carries. A row reads Not documented where no source states what happens past the value.

| Scope | Limit | Past the limit |
| --- | --- | --- |
| Bucket name length (`name`) | 6 to 63 characters | `10048` `Min Length` below 6 characters. Past 63 characters, not documented. |
| Bucket name characters | Letters, numbers, and the hyphen (`-`) | The request is rejected and the bucket is not created. |
| Bucket name prefix | A name never begins with `azion` | `17001` `Bucket Name Not Available`. |
| Bucket name uniqueness | One name across every Azion account | `17000` `Bucket Already Exists`. |
| Object key length (`object_key`) | 1 to 1,024 characters | Not documented. |
| Single upload through Azion Console | 300 MB | Azion Console refuses the file: "Files larger than 300 MB cannot be uploaded." The bound applies to the Console, not to the Azion API or the S3 protocol. |
| Buckets per account | 100 buckets | Not documented. |
| S3 credential access keys per account | 100,000 access keys | Not documented. |
| Buckets per list response (`page_size`) | 100 buckets | The list is paginated. Read the rest with `page`. |
| Objects per list response (`max_object_count`) | 1,000 keys | The response carries a `continuation_token`. Send it back to read the next page. |
| Bucket deletion | Blocked while the bucket holds objects, and for 24 hours after the last object is removed | `17006` `Cannot Delete Non Empty Bucket`. |
| Region | `us-east-005` | The region cannot be selected. |

## Included usage per plan

Azion offers three service plans: Hobby, Pro, and Enterprise. Each one includes an amount of storage and a number of operations every month.

The class of an operation decides which counter it spends, and the [Terms of Service](/en/documentation/agreements/tos/) define the three lists. Class A covers the control and listing calls, among them `CreateBucket`, `ListBuckets`, `ListObjectsV2`, `HeadBucket`, `CopyObject`, and `ListParts`. Class B covers the object reads `GetObject` and `HeadObject`. Class C covers the writes, among them `PutObject`, `DeleteObject`, `DeleteBucket`, and `UploadPart`, and it is included on every plan. Storage is metered per GB.

| Metric | Hobby | Pro | Enterprise |
| --- | --- | --- | --- |
| Storage | 10 GB / month included | 20 GB / month included | Custom |
| Class A operations | 10,000 / month included | 20,000 / month included | Custom |
| Class B operations | 100,000 / month included | 200,000 / month included | Custom |
| Class C operations | Included | Included | Included |

The plan decides what happens past an included amount. On Hobby, use beyond the included amount may require an upgrade, and Azion may restrict the account. On Pro and Enterprise, Azion bills the additional consumption at on-demand rates, and configurable spend limits bound the additional charge. For the rates, refer to [Pricing](/en/documentation/fundamentals/pricing/#object-storage).
