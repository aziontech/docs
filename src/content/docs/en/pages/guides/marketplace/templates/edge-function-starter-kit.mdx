The **Function Starter Kit** template contains the configurations for creating a function-based application without origin dependencies. This template simplifies the configuration process, so you can deploy a function that is ready to run.

The deployment of this template creates an application, a basic "Hello World” function, and a domain you manage through Azion Web Platform.

---

## Prerequisites

- This template uses [Application Accelerator](/en/documentation/build/application-accelerator/) and [Functions](/en/documentation/build/functions/), and it may generate usage-related costs. Check the [pricing page](https://www.azion.com/en/pricing/) for more information.

---

You obtain and configure the template through Azion Console. To deploy it, select the button below.

## Set up the template

In the configuration form, you must provide the information to configure your application. Fill in the presented fields. 

Fields identified with an asterisk are mandatory.

1. Define a name for your application.
    - The bucket for storage and the function will use the same name.
    - Use a unique, memorable name. If the name is already taken, the platform returns an error message.
2. Select **Deploy** to start the deployment.

During the deployment, a window shows the logs. When it completes, the page shows the application and the options to continue.

:::note
The link opens the application in the browser. Propagating and configuring the application across Azion's distributed network takes a few minutes, so the URL may not answer immediately.
:::

## Manage the template

Considering that this initial setup may not be optimal for your specific application, all settings can be customized any time you need by using Azion's platform.

### Update the function

This template includes a simple `Hello World` function that is ready to run. Follow these steps to update it according to your needs:

1. [Access Azion Console](https://console.azion.com).
2. On the upper-left corner, select **Products menu**, the icon with three horizontal lines, > **Functions**.
3. Find the function related to your template and select it. It carries the same name as your application.
    - The list is organized alphabetically. The **search bar** in the upper-left corner of the list filters by **Function Name**.
4. On the function page, use the tabs to configure your function.
    - On the **Main Settings** page, you can rename the function and change some basic settings.
    - On the **Code** tab, you can update the function's code.
    - On the **Arguments** tab, you can define the arguments used by the function.
5. Select **Save**.

:::tip
Read the documentation about [managing functions](/en/documentation/build/functions/) for more details.
:::

### Manage the application

To manage and edit your application's settings, follow these steps:

1. [Access Azion Console](https://console.azion.com).
2. On the upper-left corner, select **Products menu**, the icon with three horizontal lines, > **Applications**.
    - The **Applications** page opens. It lists every application on the account.
3. Find the application related to your template and select it.
    - The list is organized alphabetically. The **search bar** in the upper-left corner of the list filters by **Application Name**.

Selecting the application opens a page that carries every setting you can configure.

:::tip
Read the documentation about [managing applications](/en/documentation/platform/applications/first-steps/) for more details.
:::

### Add a custom domain

The application created during the deployment has an assigned Azion Workload domain to make it accessible through the browser. The domain has the following format: `xxxxxxxxxx.map.azionedge.net/`. However, you can add a custom domain for users to access your application through it.
