You can deploy the Image Optimization template from Azion Console to enhance image loading and caching by file extension. The template applies advanced cache key rules through Rules Engine for Applications, for the extensions `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.gif`, `.png`.

---

## Prerequisites

- [Application Accelerator](/en/documentation/build/application-accelerator/), which the template uses.
- [Functions](/en/documentation/build/functions/), which the template uses.

For what each one counts against, refer to [Pricing](/en/documentation/fundamentals/pricing/).

## Configure the template fields

The configuration form requests the information to configure your application. An asterisk marks a mandatory field.

- **Application Name** *: the name of your application on Azion.
    - Use a unique, memorable name. If the name is already in use, the platform returns an error message.
- **Origin Address** *: the address of the hosted origin the application fetches the original content from.
    - Example: `www.yourwebsite.com`
- **Custom Host Header**: adds host information to the request header the application sends to the origin.
    - Example: `${host}`. For more information, refer to [Origins](/en/documentation/platform/connectors/origins/#host-header).
- **Image file extensions to cache** *: the file extensions for the rules, separated by a comma. Add as many extensions as you need, following the example.
    - Example: `jpg,jpeg,bmp,ico,gif,png`
- **CDN Static Maximum TTL** *: the maximum TTL, in seconds, for cached content to be delivered.
    - Accepts values from `0` to `31536000`. Default: `31536000`.
- **Browser Image Maximum TTL** *: the maximum TTL, in seconds, for cached content in the browser.
    - Accepts values from `0` to `31536000`. Default: `0`.

After you complete the form, select **Deploy** to start the deployment.

A window shows the deployment logs while it runs. When it completes, the page shows information about the application and options to continue.

The deployment creates an application that runs on Azion Platform, where you can manage and adjust the settings.

:::note
The application URL takes time to propagate across Azion's data centers. Wait a few minutes if the page does not load right away.
:::

## Manage the application afterwards

You can customize any setting at any time from Azion Console.

To manage the application's settings:

<DocSteps>
  <DocStep title="Access Applications">

  Access [Azion Console](https://console.azion.com/) > **Applications**. The page lists every application you created.

  </DocStep>
  <DocStep title="Find and select the application">

  Find the application for the **Image Optimization** template and select it. The list is alphabetical, and the search bar filters by **Application Name** only.

  </DocStep>
</DocSteps>

The application opens to a page with every setting you can configure.

:::tip
For more information, refer to [Applications first steps](/en/documentation/platform/applications/first-steps/) and [Image Processor](/en/documentation/build/image-processor/).
:::
