The **Static Cache** template deploys an application that caches static files, such as JavaScript and CSS, by their file extension. Its rules are applied through [Rules Engine](/en/documentation/platform/applications/rules-engine/), and they respect the cache settings the origin sends or apply a default TTL instead. The rules cover the **GET**, **HEAD**, and **OPTIONS** methods.

You link the template to your own origin, and the deployment creates an application on [Azion Platform](/en/documentation/platform/applications/) where every setting stays editable.

---

## Requirements

- The template uses [Application Accelerator](/en/documentation/build/application-accelerator/) and [Functions](/en/documentation/build/functions/), which can generate usage-related costs. For the rates, refer to [Pricing](/en/documentation/fundamentals/pricing/).
- Access to Azion Console. Refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).

## Configure the template fields

The configuration form requests the information the application needs. An asterisk marks a mandatory field.

| Field | What to enter |
| --- | --- |
| **Application Name** * | The name of the application on Azion. It must be unique; a name already in use returns an error message. |
| **Origin Address** * | The address of the origin the application fetches content from. For example: `www.yourwebsite.com`. |
| **Custom Host Header** | The host information added to the request that retrieves content from the origin. For example: `${host}`. For more information, refer to [Host Header](/en/documentation/platform/connectors/origins/#host-header). |
| **Static files extensions to cache** * | The file extensions the static rules cover, separated by commas. Add as many as you need. For example: `aif,aiff,au,avi,bin,cab,carb,cct,cdf,class,doc`. |
| **CDN Static Maximum TTL** * | The maximum time in seconds that cached content is delivered. It accepts `0` to `31536000`, and the default is `1296000`. |
| **Browser Static Maximum TTL** * | The maximum time in seconds that content stays cached in the browser. It accepts `0` to `31536000`, and the default is `0`. |

Select **Deploy** in the lower-right corner to start the deployment. A window shows the logs while it runs, and the page then shows the application information and the options to continue.

:::note
The link to the application opens it in the browser, and the configuration takes time to propagate across Azion's distributed infrastructure. Wait a few minutes for the URL to answer.
:::

## Manage the template

Every setting the form asked for stays editable in Azion Console. To open the application:

1. Access [Azion Console](https://console.azion.com/) > **Products Menu** > **Applications**.
2. Find the application the template created. The list is alphabetical, and the search bar filters it by **Application Name** only.
3. Select the application to open its settings.

The application page carries the **Cache Settings** and **Rules Engine** tabs the template configured.

:::tip
To change how long the static files stay cached, refer to [Create a cache setting](/en/documentation/guides/application-performance/cache-and-purge/tune-cache-settings/). For the fields of an application, refer to [First steps](/en/documentation/platform/applications/first-steps/).
:::
