You can connect the Azion GitHub App from Azion Console, review, suspend, uninstall, or revoke it from your GitHub settings, or remove the connection from Azion Console. The app links your GitHub account to your Azion account. Azion can then import your repositories and deploy every push you make to them. To import a repository and deploy it, refer to [Import a project from GitHub](/en/documentation/guides/application-development/automation/import-an-existing-project-from-github/) instead. GitHub is a trademark of GitHub, Inc.

---

## Prerequisites

- An Azion account. To create one, refer to [Create an account](/en/documentation/fundamentals/creating-account/).
- A GitHub account, personal or organization. To install the app on an organization, you must be the organization owner or have admin permission on a repository.

---

## What the app can access

The Azion GitHub App asks for these permissions when you install it. Decide on the account and the repositories before you connect:

| Area | Access |
| --- | --- |
| Account | Installs on a personal account or an organization. You select the account in the GitHub window that opens during authorization. On an organization, only owners manage the settings of the installed app. |
| Identity and code | Verifies your GitHub identity. Reads the code, metadata, and resources your account can access. |
| Repositories | Reads all repositories of the account, or only the repositories you select. You set this during installation and can edit it on GitHub at any time. |
| Continuous deployment | Deploys every push to a connected repository to your Azion environment, so the project stays current. |

## Connect GitHub

Azion Console connects GitHub from **Account Settings**, which you open from the account menu under your avatar. To connect the Azion GitHub App in Azion Console:

<DocSteps>
  <DocStep title="Open Account Settings">

  Access [Azion Console](https://console.azion.com/) > **Account Settings**.

  </DocStep>
  <DocStep title="Select Connect with GitHub">

  In the **GitHub Integration** section, select **Connect with GitHub**. GitHub opens in a new window.

  </DocStep>
  <DocStep title="Select the GitHub account">

  In the GitHub window, select the personal account or the organization to connect.

  </DocStep>
  <DocStep title="Choose the repository access">

  Give the app access to all repositories, or select the repositories it can read.

  </DocStep>
  <DocStep title="Confirm the installation" />
</DocSteps>

Azion Console shows **GitHub integration connected successfully**. The **GitHub Integration** section lists the account under **Connected Account**, marked **Integration active**.

You can also connect GitHub at two other moments, with the same GitHub window:

- When you sign up for Azion with your GitHub account.
- When you deploy one of the [Azion Templates](/en/documentation/platform/marketplace/templates/) or import a project from GitHub. The **GitHub Connection** section of the form shows **Connect with GitHub** until an account is connected.

On those forms, the **Git Scope** field selects the connected GitHub account that Azion reads the project from. To connect another account, open the **Git Scope** list and select **Add GitHub Account**.

## Review the app on GitHub

After the installation, the Azion GitHub App appears among the installed applications in your GitHub settings. On GitHub, **Settings** is in the account menu under your avatar, and **Applications** is in its **Integrations** section. To open the app's configuration page:

<DocSteps>
  <DocStep title="Open the Applications page">

  Sign in to [GitHub](https://github.com/login) and go to **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Configure the app">

  In the **Installed GitHub Apps** tab, find the Azion GitHub App and select **Configure**.

  </DocStep>
</DocSteps>

The configuration page shows the app's description and its **Permissions**. There, you can edit the **Repository access** settings. The **Danger zone** section holds the options to suspend and uninstall the app.

The **Applications** page has three tabs:

- **Installed GitHub Apps**: the GitHub Apps installed on your account.
- **Authorized GitHub Apps**: the GitHub Apps that have access to your account.
- **Authorized OAuth Apps**: the OAuth Apps that have access to your account.

For more information, refer to [GitHub Apps](https://docs.github.com/en/apps).

## Suspend the app

A suspension stops the Azion GitHub App from reading your account resources and keeps the installation, so you can restore it. To suspend the app on GitHub:

<DocSteps>
  <DocStep title="Open the Applications page">

  Sign in to [GitHub](https://github.com/login) and go to **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Configure the app">

  In the **Installed GitHub Apps** tab, find the Azion GitHub App and select **Configure**.

  </DocStep>
  <DocStep title="Select Suspend">

  In the **Danger zone** section, select **Suspend**.

  </DocStep>
  <DocStep title="Confirm the suspension" />
</DocSteps>

The app no longer has access to your account resources. The **Danger zone** section shows **Unsuspend**, which restores the access.

---

## Uninstall the app

Uninstalling removes the Azion GitHub App from your GitHub account and revokes its access to every resource of the account. To uninstall the app on GitHub:

<DocSteps>
  <DocStep title="Open the Applications page">

  Sign in to [GitHub](https://github.com/login) and go to **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Configure the app">

  In the **Installed GitHub Apps** tab, find the Azion GitHub App and select **Configure**.

  </DocStep>
  <DocStep title="Select Uninstall">

  In the **Danger zone** section, select **Uninstall**.

  </DocStep>
  <DocStep title="Confirm the uninstallation" />
</DocSteps>

The app is removed from your GitHub account. To install it again, refer to [Connect GitHub](/en/documentation/guides/application-development/automation/azion-github-app/#connect-github).

---

## Revoke the app's authorization

A revocation stops the Azion GitHub App from calling the GitHub API for your account. You cannot undo a revocation. To revoke the authorization on GitHub:

<DocSteps>
  <DocStep title="Open the Applications page">

  Sign in to [GitHub](https://github.com/login) and go to **Settings** > **Applications**.

  </DocStep>
  <DocStep title="Select Revoke">

  In the **Authorized GitHub Apps** tab, find the Azion GitHub App and select **Revoke**.

  </DocStep>
  <DocStep title="Confirm the revocation" />
</DocSteps>

The Azion GitHub App can no longer access the GitHub API for your account.

---

## Disconnect from Azion

You remove a connected GitHub account in **Account Settings**. To remove the connection in Azion Console:

<DocSteps>
  <DocStep title="Open Account Settings">

  Access [Azion Console](https://console.azion.com/) > **Account Settings**.

  </DocStep>
  <DocStep title="Select Remove">

  In the **GitHub Integration** section, find the account under **Connected Account** and select **Remove**.

  </DocStep>
</DocSteps>

Azion Console shows **GitHub integration removed successfully**, and the account no longer appears under **Connected Account**.
