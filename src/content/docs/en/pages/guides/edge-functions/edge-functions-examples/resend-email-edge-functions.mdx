In this tutorial, you will build an HTTP endpoint on Azion Functions that sends a transactional email through Resend. You will create the project from a template, write the handler, store the API key, deploy the project, and send a live message.

The finished project is in the [edge-functions-examples repository](https://github.com/egermano/edge-functions-examples/tree/main/packages/resend).

---

## Prerequisites

- An Azion account. To create one, refer to [How to create an account on Azion](/en/documentation/fundamentals/creating-account/).
- A [Resend](https://resend.com/) account with an API key.
- Azion CLI installed. For the installation options, refer to [Azion CLI](/en/documentation/devtools/cli/).
- Node.js version 18 or higher.

## 2. Write the handler that calls the Resend API

The handler answers a `GET` request on the root path, posts the message to the Resend API, and returns the API response as JSON. The `entry` field of `azion.config.js` names the entry file of the project. Open that file and replace its contents with:

```typescript
import { Hono } from "hono";

const app = new Hono();

const RESEND_API_KEY = Azion.env.get("RESEND_API_KEY")!;
const EMAIL_TO = "<your-email-address>";

app.get("/", async (c) => {
  const res = await fetch("https://api.resend.com/emails", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${RESEND_API_KEY}`,
    },
    body: JSON.stringify({
      from: "onboarding@resend.dev",
      to: EMAIL_TO,
      subject: "hello world",
      html: "<strong>it works!</strong>",
    }),
  });

  const data = await res.json();

  return c.json(data);
});

export default app;
```

Set `EMAIL_TO` to the address that receives the message. The `html` field carries the message body as an HTML string, so a template literal substitutes the values that change per recipient.

The final line exports the app as an ES Modules handler, the pattern Azion recommends over the legacy Service Worker pattern. For both patterns and the move between them, refer to [Migrate handler patterns in Functions](/en/documentation/guides/application-development/functions-and-runtime/migrate-handler-patterns/).

## 3. Store the Resend API key as an environment variable

The handler reads `RESEND_API_KEY` at run time, so the key stays out of the project files and out of version control. To create the variable on your account:

```bash
azion create variables --key "RESEND_API_KEY" --value "[TOKEN VALUE]" --secret true
```

A variable whose key contains `password`, `pwd`, `secret`, `key`, `hash`, `encrypted`, `passcode`, `auth`, or `token` is sent as a secret by default. The `--secret true` flag repeats that default here. Give the Resend API key the smallest permission set that the send call needs.

To replace the value later, run `azion update variables` and deploy the project again. A change to a variable does not reach a function that is already running.

The account holds the variable, and the handler reads it by key after the deployment.

---

## 4. Deploy the project

To build the project and publish it:

```bash
azion deploy
```

The deployment uploads the function code, configures the application, sets the routing rules, applies the environment variables and secrets, and returns a domain in the format `https://xxxxxxx.map.azionedge.net`. Azion opens a browser at the Azion Console page that carries the deployment logs.

:::caution
The deployed endpoint is public, and every request to it sends a message. Before the handler takes the recipient or the body from the request, validate and sanitize both fields, require authentication on the route, and limit its request rate.
:::

The endpoint answers on the returned domain a few minutes after propagation.

---

## 5. Send the first email

To run the handler, request the root path of the domain the deployment returned:

```bash
curl https://<your-azion-domain>/
```

The response body is the JSON that the Resend API returns for the request. The message arrives in the inbox of the address set in `EMAIL_TO`, with the subject `hello world` and the body `it works!`.

:::note
If the response carries an error from Resend, confirm that `RESEND_API_KEY` exists on your account and that the project was deployed after the variable was created. For a function that does not run, stops early, or writes an error to its logs, refer to [Troubleshoot function execution and logs](/en/documentation/build/functions/troubleshooting/).
:::

The endpoint now sends a transactional email on every request to its root path.
