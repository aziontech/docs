In this tutorial, you will build and deploy a function from the terminal with [Azion CLI](/en/documentation/devtools/cli/). You will save a personal token and create a project. Then you will write the handler, run it on your machine, and deploy it.

The [Functions quickstart](/en/documentation/build/functions/quickstart/) reaches the same result through Azion Console. This page is the terminal path, and it ends with the same three objects: a function, an instance, and the application that serves it.

## Prerequisites

- An Azion account. To create one, refer to [How to create an account on Azion](/en/documentation/fundamentals/creating-account/).
- [Azion CLI](/en/documentation/devtools/cli/) installed on your machine.
- A [personal token](/en/documentation/fundamentals/personal-tokens/).
- Node.js and a package manager, which the CLI uses to build the project.

## 1. Save your personal token

The CLI authorizes every command with a personal token stored on your machine. To save it:

```bash
azion -t <your-token>
```

The token is stored locally, and the commands that follow authorize with it. You do not pass it again.

## 2. Create the project

`azion init` creates the project and its build configuration. To start it:

```bash
azion init
```

The command asks for a name, suggesting one you can accept:

```bash
(Hit enter to accept the suggested name in parenthesis) Your applications name:  (resilient_zeus)
```

Then it asks which preset to use. Select **Javascript**, the preset for a function written in plain JavaScript rather than a framework:

```bash
? Choose a preset:  [Use arrows to move, type to filter]
> AI Studio
  Angular
  Astro
  ...
  Javascript
```

The project directory now holds the build configuration and the entrypoint the build reads.

## 3. Write the handler

Open `main.js`, the entrypoint the build reads by default, and replace its contents with an ES Modules handler:

```js
export default {
  async fetch(request, env, ctx) {
    return new Response('Hello World', {
      headers: { 'content-type': 'text/plain' }
    });
  }
};
```

The `fetch` method receives the request, the environment variables, and the execution context, and returns the response the client receives. This is the pattern Azion recommends.

## 4. Run the function locally

Before deploying, run the project on your machine and send it a request. To start the local server:

```bash
azion dev
```

The command builds the project, then prints the address it serves on:

```bash
[Azion Bundler] [Server] › ✔  success   Function running on port http://localhost:3000
```

From another terminal, request that address:

```bash
curl http://localhost:3000/
```

The handler answers with its response body:

```bash
Hello World
```

Stop the server with `Ctrl+C` once the response is correct.

## 5. Deploy the project

To deploy the project to Azion:

```bash
azion deploy
```

The command builds the project and creates the application and the function on your account. It instantiates the function and prints the domain that serves it. The domain has the format `xxxxxxxxxx.map.azionedge.net`.

Requesting that domain returns the same response you read locally:

```bash
curl https://xxxxxxxxxx.map.azionedge.net/
```

```bash
Hello World
```

A new domain takes a few minutes to propagate. An immediate request can fail before the configuration is in place. Wait and retry before diagnosing.
