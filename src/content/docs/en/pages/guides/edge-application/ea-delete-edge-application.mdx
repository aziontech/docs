You can delete an [application](/en/documentation/platform/applications/) from Azion Console or the Azion API. To keep a copy of its settings before you delete it, refer to [Clone an application](/en/documentation/guides/application-development/getting-started/clone-applications/).

## Prerequisites

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

You need access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).

</Fragment>

<Fragment slot="panel.api">

- A personal token for the `Authorization` header, in the form `Token [TOKEN VALUE]`. To create a token, refer to [Manage a personal token](/en/documentation/guides/platform/account-and-billing/personal-tokens/).
- An HTTP client, such as `curl`.
- The ID of the application. It appears in the Azion Console address of the application page, after `/applications/edit/`.

</Fragment>

</Tabs>

## Delete the application

Azion deletes the application together with the settings and instances that belong to it, such as its rules and cache settings. You cannot undo a deletion.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

To delete the application in Azion Console:

<DocSteps>
  <DocStep title="Open the Applications page">

  Access [Azion Console](https://console.azion.com/) > **Applications**.

  </DocStep>
  <DocStep title="Find the application">

  To narrow the list, enter the name of the application in the search box.

  </DocStep>
  <DocStep title="Open the Actions menu of the application">

  In the row of the application, select the **Actions** menu.

  </DocStep>
  <DocStep title="Select Delete">

  Select **Delete**. The **Delete Application** dialog opens and warns that the deletion cannot be reversed.

  </DocStep>
  <DocStep title="Type the confirmation text">

  In the confirmation box, type the text that the dialog quotes, which is the name of the application. **Delete** stays unavailable until the text matches.

  </DocStep>
  <DocStep title="Confirm the deletion">

  Select **Delete**.

  </DocStep>
</DocSteps>

Azion Console shows `Resource successfully deleted`, and the application no longer appears in the **Applications** list.

</Fragment>

<Fragment slot="panel.api">

To delete the application with the API, send a `DELETE` request to the endpoint of the application. Put its ID in place of `<application-id>`:

```bash
curl --request DELETE \
  --url https://api.azion.com/v4/workspace/applications/<application-id> \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]'
```

The API answers `202` when it accepts the deletion. Once the deletion completes, the application no longer appears when you list the applications in your account.

</Fragment>

</Tabs>
