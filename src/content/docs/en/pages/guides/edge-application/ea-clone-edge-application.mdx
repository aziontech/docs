You can clone an [application](/en/documentation/platform/applications/) from Azion Console. The clone is a separate application, with its own ID, that starts with the same settings as the original. To build an application from nothing instead, refer to [Applications quickstart](/en/documentation/platform/applications/quickstart/).

---

## Prerequisites

You need access to Azion Console. To sign in, refer to [Access Azion Console](/en/documentation/guides/platform/account-and-billing/how-to-access-azion-console/).

---

## Clone the application

Azion Console copies the settings of the original into the clone, under a name you choose. Both applications then appear in the same list, so pick a name that tells them apart.

To clone the application in Azion Console:

<DocSteps>
  <DocStep title="Open the Applications page">

  Access [Azion Console](https://console.azion.com/) > **Applications**.

  </DocStep>
  <DocStep title="Find the application">

  To narrow the list, enter the name of the application in the search box.

  </DocStep>
  <DocStep title="Open the Actions menu of the application">

  In the row of the application, select the **Actions** menu.

  </DocStep>
  <DocStep title="Select Clone" />
  <DocStep title="Name the clone">

  In **Name**, enter a name that no other application uses. If another application already has that name, Azion Console shows an error. Enter a different name.

  </DocStep>
  <DocStep title="Confirm the clone">

  Select **Clone**.

  </DocStep>
</DocSteps>

Azion Console shows `Your Application has been cloned` and opens the page of the clone. The clone also appears in the **Applications** list under the name you entered.

A workload serves the clone only after you select the clone as its application. In Azion Console, that choice is the **Application** field in the **Deployment Settings** of the workload. For more information, refer to [Workloads](/en/documentation/platform/workloads/).
