A software development kit (SDK) for an API is a library that exposes the API as the functions and types of one programming language. Your program fills in typed objects and calls methods. The library builds each HTTP request, sends it, and hands back the response, so you do not compose requests by hand.

**Go SDK** is the Azion library for Go, published in the [azionapi-go-sdk repository](https://github.com/aziontech/azionapi-go-sdk/) on GitHub. Each service of the Azion API has its own package in the module, such as `idns` for [Edge DNS](/en/documentation/platform/edge-dns/). Your program creates a client for that package with your personal token. Use the Go SDK to create DNS zones, manage applications, functions, and domains, or purge cached content from a Go program.

The [Azion CLI](/en/documentation/devtools/cli/) and the [Azion Terraform Provider](/en/documentation/devtools/terraform/) also call the [Azion API](/en/documentation/devtools/api/) through the Go SDK. Your own code can call the same API directly over HTTPS instead.

## Install the SDK

The Go SDK installs into a Go module. Before you add it, your machine and project need the following:

- Go 1.17 or later.
- A Go project with a `main.go` file.
- A Go module, initialized with `go mod init <name>`.

From the root folder of the project, add the module with `go get`:

```bash
go get github.com/aziontech/azionapi-go-sdk
```

When `main.go` already imports a package of the SDK, `go mod tidy` adds the module to the `go.mod` file of the project instead:

```bash
go mod tidy
```

## Example program

The following program creates an Edge DNS zone through the `idns` package of the Go SDK. The example targets Azion API v3: it sets the API v3 host as its server and asks for version 3 in its `Accept` header. Copy the whole program into the `main.go` file of your project:

```go
package main

import (
    "bufio"
    "context"
    "fmt"
    "io"
    "net/http"
    "os"
    "strings"

    sdk "github.com/aziontech/azionapi-go-sdk/idns"
)

const (
    intelligentDnsURL = "https://api.azionapi.net/"
)

type Client struct {
    apiClient sdk.APIClient
}

func main() {
    var personalToken string

    fmt.Println("Hey, there! Welcome to iDNS example")

    fmt.Println("Please, provide your Personal Token: ")
    fmt.Scanf("%s", &personalToken)

    err := IDNSHandler(personalToken)
    if err != nil {
        fmt.Println(err)
    }

}

// IDNSHandler
//
//   - I/O operations - asks and reads domain name e zone
//   - Instantiates a new client
//   - Calls NewIdns
func IDNSHandler(personalToken string) error {
    var domainName, dnsZone string
    active := true

    reader := bufio.NewReader(os.Stdin)

    fmt.Println("Plase, provide the Domain Name: ")
    domainName, err := reader.ReadString('\n')
    if err != nil {
        return err
    }
    domainName = strings.Replace(domainName, "\n", "", -1)

    fmt.Println("Enter a dns zone: ")
    dnsZone, err = reader.ReadString('\n')
    if err != nil {
        return err
    }
    dnsZone = strings.Replace(dnsZone, "\n", "", -1)

    var f *http.Client

   client := NewClient(f, intelligentDnsURL, personalToken)
    err = client.NewIdns(&domainName, &dnsZone, &active)
    if err != nil {
        fmt.Println(err)
        return err
    }
    return nil
}

// NewIdns
//   - Instantiate a sdk.Zone object
//   - Instantiate the request and exec it
//   - Prints success or error
func (c *Client) NewIdns(domainName, domain *string, active *bool) error {
    ctx := context.Background()
    idns := new(sdk.Zone)
    idns.Name = domainName
    idns.Domain = domain
    idns.IsActive = active

    fmt.Println("Creating iDNS zone....")

    req := c.apiClient.ZonesApi.PostZone(ctx).Zone(*idns)
    _, httpResp, err := req.Execute()
    if err != nil {
        fmt.Println(httpResp)
        return err
    }
    bytes, err := io.ReadAll(httpResp.Body)
    if err != nil {
        return err
    }

    fmt.Println(string(bytes))
    return nil
}

// NewClient
//   - Instantiates a new skd-api client
//   - Set headers
func NewClient(f *http.Client, url string, token string) *Client {

    conf := sdk.NewConfiguration()

    conf.HTTPClient = f
    conf.AddDefaultHeader("Authorization", "token "+token)
    conf.AddDefaultHeader("Accept", "application/json;version=3")
    conf.Servers = sdk.ServerConfigurations{
        {URL: url},
    }

    return &Client{
        apiClient: *sdk.NewAPIClient(conf),
    }
}
```

The program has four parts:

- **Import**: the line `sdk "github.com/aziontech/azionapi-go-sdk/idns"` loads the Edge DNS package under the name `sdk`.
- **Client**: `NewClient` creates a configuration with `sdk.NewConfiguration()` and adds two default headers. `Authorization` carries your personal token with the `token` scheme, and `Accept` selects the API version. The configuration then points the client at one server URL.
- **Request**: `NewIdns` fills an `sdk.Zone` with `Name`, `Domain`, and `IsActive`, then sends it with `ZonesApi.PostZone(ctx).Zone(*idns)` and `Execute()`.
- **Response**: `Execute()` returns the HTTP response beside the error. On success, the program reads the response `Body` with `io.ReadAll` and prints it. On failure, it prints the response and the error.

If you have worked with `net/http`, the client and the response carry over. The configuration takes an `*http.Client`, and the program reads the body of the response as with any HTTP call.

From the root folder of the project, run the program:

```bash
go run main.go
```

The program asks for your personal token, then for the domain name and the DNS zone, one per line. It creates the zone as active and prints the body of the API response.

## API version and authentication

Two settings of the client decide which API the Go SDK reaches and how each request proves who sends it:

- **API version**: the example on this page targets Azion API v3, through the server URL and the `Accept` header that `NewClient` sets. Azion API v4 serves its resources at `https://api.azion.com/v4`, and some resources change between the versions: API v4 replaces the v3 Domains resource with workloads. For the resources and endpoints that change, refer to [API v4 Migration](/en/documentation/fundamentals/api-v4-migration/).
- **Authentication**: each request of the client carries a [personal token](/en/documentation/fundamentals/personal-tokens/) in the `Authorization` header. The example writes the scheme in lowercase, as `token`, and Azion API v4 accepts that form too. To create a token, refer to [Manage personal tokens](/en/documentation/guides/platform/account-and-billing/personal-tokens/).
