The [code editor](/en/documentation/build/functions/code-editor/) of a function calls the [ChatGPT](https://openai.com/blog/chatgpt) APIs. The integration explains, generates, and refactors JavaScript inside the editor, so you do not open a separate tab. It runs on the credentials of your own OpenAI account, which you declare in the source code of the function.

---

## Credentials

The ChatGPT integration authenticates with an OpenAI API key and an OpenAI organization ID. Generate both on the OpenAI platform:

- [OpenAI API keys](https://platform.openai.com/account/api-keys)
- [OpenAI organization settings](https://platform.openai.com/account/org-settings)

Declare the two values as a comment in the source code of the function:

<Code lang="javascript" code={`
/*
ChatGPTKey=[TOKEN VALUE]
ChatGPTOrg=<your-organization-id>
*/
`} />

---

## Code explanation

Code explanation returns a description of the code in the editor. Use it when you debug a function, when you review one before a change, or when you read code you did not write.

---

## Code generation

Code generation turns a comment into JavaScript. The **ChatGPT: Generate** command, in the context menu of the editor, reads the selected comment as the prompt and returns the generated code.

This prompt asks for an HTML table with three columns:

<Code lang="javascript" code={`
// generate an html table with name, phone number and address
`} />

The integration returns the markup:

```html
<body>
  <table>
    <thead>
      <tr>
        <th>Name</th>
        <th>Phone Number</th>
        <th>Address</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>John Smith</td>
        <td>(123) 456-7890</td>
        <td>123 Main St, Anytown, USA</td>
      </tr>
      <tr>
        <td>Jane Doe</td>
        <td>(987) 654-3210</td>
        <td>456 Oak St, Anytown, USA</td>
      </tr>
      <tr>
        <td>Bob Johnson</td>
        <td>(555) 555-1212</td>
        <td>789 Maple St, Anytown, USA</td>
      </tr>
    </tbody>
  </table>
</body>
```

---

## Code refactor

Code refactor rewrites a block of JavaScript. The **ChatGPT: Refactor** command, in the context menu of the editor, refactors the code you select.

:::tip
Test the code the integration returns before the function serves traffic. [Preview deployment](/en/documentation/build/functions/preview-deployment/) returns the response of the generated or rewritten code without a deployment.
:::
