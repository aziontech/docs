Copy any of these JavaScript snippets into a function as a starting point for your own code. The examples cover the patterns functions are most often used for: returning a response or a JSON payload, redirecting traffic, reading cookies, running an A/B test, and denying a request by country. They are grouped by where the function runs: Applications, for functions that handle the `fetch` event on an application, and Firewall, for functions that handle the `firewall` event on a firewall.

The handlers in this collection are written in the Service Worker pattern, which registers the handler with `addEventListener`. New code uses ES Modules: refer to [Best practices](/en/documentation/build/functions/best-practices/) for the current pattern, and to [Migrating handler patterns](/en/documentation/guides/application-development/functions-and-runtime/migrate-handler-patterns/) for the before-and-after of each handler.
