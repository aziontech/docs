## About this template

This template is a blog built with [Astro](/en/documentation/devtools/runtime/frameworks/astro/) and the [Cosmic](https://www.cosmicjs.com/) headless CMS. Authors create and organize posts in Cosmic, while Astro turns that content into fast, statically generated pages with a ready-made reading layout. Running on Azion, the blog is served via a distributed architecture for quick, globally consistent page loads.

## Key features

- Blog content modeled and managed in the Cosmic headless CMS.
- Astro Static Site Generation (SSG) for lightweight, SEO-friendly pages.
- Pre-built post and listing layouts you can restyle to match your brand.
- One-click deployment to Azion's globally distributed global network.
