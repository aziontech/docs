## About this template

This template is a blog site built with [Gatsby](/en/documentation/devtools/runtime/frameworks/gatsby/), a React-based static site generator focused on performance. It comes with sample posts, listing and detail layouts, and the structure you need to publish articles right away. Built as static pages and deployed on Azion, the blog is served via a distributed architecture for fast load times anywhere in the world.

## Key features

- Preconfigured blog layouts with example posts you can edit or replace.
- Static site generation that produces fast, SEO-friendly pages.
- GraphQL-based data layer for sourcing and querying content.
- Edge delivery on Azion for low-latency reads across regions.

For more information about deploying this template visit the [template guide](/en/documentation/guides/application-development/frameworks/gatsby-blog-starter-kit/).
