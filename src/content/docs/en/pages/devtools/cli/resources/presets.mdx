The Azion CLI `presets` command lists the presets you can build and deploy a project with. A preset gives a project the default build settings of one framework or language, and you pick one when you set up a project with [Azion CLI init](/en/documentation/devtools/cli/init/) or [Azion CLI link](/en/documentation/devtools/cli/link-command/). The options every command accepts, such as `--format`, `--out`, and `-y`, are on [Global options](/en/documentation/devtools/cli/globals/).

---

## List

`azion list presets` prints the name of every preset the CLI offers:

```bash
azion list presets [flags]
```

The command takes no flags of its own. A list flag such as `--details` is refused with `Error: unknown flag: --details`.

This command lists the presets:

```bash
azion list presets
```

The command prints a status line and a Node.js deprecation warning, then one row per preset:

```text
Fetching available presets
…
[Azion] › 📦  angular
[Azion] › 📦  astro
[Azion] › 📦  docusaurus
[Azion] › 📦  eleventy
[Azion] › 📦  emscripten
[Azion] › 📦  gatsby
[Azion] › 📦  hexo
[Azion] › 📦  html
[Azion] › 📦  hugo
[Azion] › 📦  javascript
[Azion] › 📦  jekyll
[Azion] › 📦  next
[Azion] › 📦  nitro
[Azion] › 📦  nuxt
[Azion] › 📦  opennextjs
[Azion] › 📦  preact
[Azion] › 📦  qwik
[Azion] › 📦  react
[Azion] › 📦  rustwasm
[Azion] › 📦  stencil
[Azion] › 📦  svelte
[Azion] › 📦  typescript
[Azion] › 📦  vitepress
[Azion] › 📦  vue
[Azion] › 📦  vuepress
```

The list prints as text only. With `--format json`, the command prints the status line and the warning, and no presets.

The command also creates a `.edge` folder in the current directory. When that directory holds a `.env` file, the command copies it to `.edge/.env`.

`azion link --preset` takes a name from this list: `azion link --preset html` sets up an HTML site that serves the `./www` folder. A name the list does not carry, such as `static`, fails with `Error: exit status 1`. `azion build --preset` changes the preset of a project during the build.

The preset picker of `azion init` is a separate list. It carries entries this command does not print, such as _AI Studio_ and _Hono_, and it has no _Html_ entry. To set up an HTML site, run `azion link --preset html`.
