[Bot Manager](/en/documentation/secure/bot-manager/) uses these terms in its own way, and each definition links the page that documents the term in full.

| Term | Definition |
| --- | --- |
| arguments | The JSON object a function instance carries, which sets the threshold, the action, and the logging Bot Manager applies on that firewall. You edit it in the **Arguments** section of the instance form, and [Arguments](/en/documentation/secure/bot-manager/arguments/#fields) documents every field. |
| `az_asm` | One of the two session cookies Bot Manager Lite sets on a request that arrives without a valid session. Its value is an HMAC signature of the value in `az_botm`, and a mismatch between the two is what rule `17` scores. [Bot Manager Lite](/en/documentation/secure/bot-manager/bot-manager-lite/#rules) lists the rules that read the pair. |
| `az_botm` | The unsigned half of the session cookie pair Bot Manager Lite sets, carrying the `x-azion-request-id` of the response that set it. Both cookies are scoped to the workload domain and expire after 24 hours. [Logs](/en/documentation/secure/bot-manager/logs/) documents what Bot Manager records about a request. |
| bot category | The bot type or attack Bot Manager identified in a request, recorded in the `bot_category` log field. Values include `Search Engine Bot`, `Bad Bot Signatures`, and `Credential Stuffing`. [Logs](/en/documentation/secure/bot-manager/logs/#classification) lists every one. |
| classification | The verdict Bot Manager records for a request in the `classified` log field: `legitimate`, `good bot`, `bad bot`, or `under evaluation`. [Logs](/en/documentation/secure/bot-manager/logs/#classification) gives the criteria for each, and [Real-Time Metrics](/en/documentation/platform/real-time-metrics/#bot-manager) charts the four together. |
| dynamic score | The part of a score the full edition derives from a fingerprint's behavioral history, measured against the host's overall traffic pattern. Bot Manager Lite runs static rules only. [How Bot Manager works](/en/documentation/secure/bot-manager/how-it-works/#scoring) describes the model. |
| fingerprint | The hash Bot Manager derives from a device's session attributes, such as its IP address and `User-Agent` header. It identifies the same device across requests and is reported in the `azion_fingerprint` log field, documented on [Logs](/en/documentation/secure/bot-manager/logs/#fields). |
| function instance | The object that binds an installed function to a [Firewall](/en/documentation/platform/firewall/), carrying the arguments that function runs with. Bot Manager runs as one, selected by a [Rules Engine for Firewall](/en/documentation/platform/firewall/rules-engine/) rule whose behavior is `Run Function`. Azion Console lists them under **Functions Instances**. |
| log tag | The identifier an instance stamps on the log records it writes, so you can tell one instance's records from another's in [Real-Time Events](/en/documentation/observe/real-time-events/). The `log_tag` argument sets it, documented on [Arguments](/en/documentation/secure/bot-manager/arguments/#fields). |
| Reputation Intelligence | The check that compares a request's IP address against [Network Lists](/en/documentation/secure/network-shield/network-lists/) Azion maintains, raising the score when the address appears on one. It is also one of the values the `bot_category` log field records, listed on [Logs](/en/documentation/secure/bot-manager/logs/#classification). |
| score | The number Bot Manager assigns a request, raised by each static rule it matches and, on the full edition, by the dynamic score. The instance's `action` runs when the score reaches the threshold. [How Bot Manager works](/en/documentation/secure/bot-manager/how-it-works/#scoring) describes the model. |
| session signature | The HMAC signature Bot Manager Lite stores in `az_asm` and rechecks on every later request from the same client. The `session_signature_key` argument supplies the key, documented on [Bot Manager Lite](/en/documentation/secure/bot-manager/bot-manager-lite/#arguments). |
| static rule | A check Bot Manager runs against the attributes of a single request, such as its headers and metadata, with no reference to earlier traffic. Each rule a request matches raises its score. [Bot Manager Lite](/en/documentation/secure/bot-manager/bot-manager-lite/#rules) publishes the rules that edition runs and the score each one adds. |
| threshold | The score at or above which a function instance runs its configured `action`. The `threshold` argument sets it, and a request under it continues to your application. [Arguments](/en/documentation/secure/bot-manager/arguments/#action) lists what each action does. |
| `under evaluation` | The classification Bot Manager records when it does not yet have enough fingerprint data to place a request. Consolidating a fingerprint's score takes up to 15 minutes, and a fingerprint not seen for 15 minutes or more returns to this state. [Logs](/en/documentation/secure/bot-manager/logs/#classification) covers the four classifications. |
