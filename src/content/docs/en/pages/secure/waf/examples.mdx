Copy any of these snippets and change the names and ids for your own account. Each one is the smallest complete form of a task the rest of the [Web Application Firewall (WAF)](/en/documentation/secure/waf/) documentation describes at length: a rule set, the Rules Engine rule that applies it, the exception that clears a false positive, and the query that returns what WAF decided about a request.

A rule set scores nothing on its own. Until a Rules Engine rule on a firewall carries a `Set WAF` behavior naming it, no request is scored, so the first two snippets belong together. Where a snippet has both an API and an Azion CLI form, the page carries both.
