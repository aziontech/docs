The vocabulary [Web Application Firewall](/en/documentation/secure/waf/) uses in its own way, with each entry pointing at the page that documents the term in full.

| Term | Definition |
| --- | --- |
| Allowed Rules | The Azion Console name for WAF exceptions, and the tab on a rule set where you create and manage them. The API and the CLI call the same object an exception. [WAF Exceptions](/en/documentation/secure/waf/custom-allowed-rules/) documents it under both names. |
| `Blocking` | The mode in which WAF blocks a request whose score reaches a threat family's threshold, before the request reaches your application. It is one of the two values the `Set WAF` behavior accepts, and it is set per rule rather than on the rule set. [How WAF works](/en/documentation/secure/waf/how-it-works/#modes) describes both modes. |
| condition | The part of a request an exception matches, expressed as a match zone and, for a specific zone, the name or value it applies to. The Azion Console field is **Condition**, and the API takes `conditions` as an array with at least one entry. [WAF Exceptions](/en/documentation/secure/waf/custom-allowed-rules/#match-zones) lists every option. |
| Custom Allowed Rules | A retired name for WAF exceptions. It appears in no Azion interface: the Azion Console tab reads Allowed Rules, and the API and the CLI call the object an exception. |
| exception | An entry that exempts part of a request from one internal rule, or from all of them, so a false positive stops being blocked. The Azion Console calls it an allowed rule, and the API and the CLI call it an exception. [WAF Exceptions](/en/documentation/secure/waf/custom-allowed-rules/#fields) documents the rule ID, conditions, and operator it carries. |
| false positive | A legitimate request that reaches a threat family's threshold and is treated as an attack. It is what [Tuning](/en/documentation/secure/waf/custom-allowed-rules/#tuning) is for finding and what an exception is for clearing. A false negative is the reverse, an attack whose score stays under the threshold, and raising a sensitivity level trades one for the other. |
| `Logging` | The mode in which WAF scores a request and records the match without blocking it. It is the other value the `Set WAF` behavior accepts, described alongside `Blocking` on [How WAF works](/en/documentation/secure/waf/how-it-works/#modes). [Real-Time Events](/en/documentation/observe/real-time-events/) reports the same state through the `wafLearning` field, labelled **WAF Learning**. |
| match zone | The part of a request a condition inspects, such as a query string value, a header name, or the raw body. There are 15 of them. The Azion Console selects one through the **Condition** field, not through a control named match zone. |
| `Operator` | The field that decides how an exception compares the value in its condition. It accepts `regex` or `contains`, defaults to `contains`, and is documented with the other fields on [WAF Exceptions](/en/documentation/secure/waf/custom-allowed-rules/#fields). There is no separate regex switch; the choice is a value of this field. |
| rule ID | The identifier of one internal WAF rule, which an exception names to scope itself to that rule. `0` means all rules and is the default. The API accepts 63 IDs, listed on [WAF Rule Sets](/en/documentation/secure/waf/rules-set/#internal-rules), and the Azion Console offers 62 of them, omitting `1314`. |
| rule set | The object that carries the eight threat families and the sensitivity level chosen for each, listed in the Azion Console under **WAF Rules**. A rule set detects nothing on its own: a Rules Engine rule with the `Set WAF` behavior applies it to traffic. [WAF Rule Sets](/en/documentation/secure/waf/rules-set/#fields) documents its fields. |
| score | The number WAF gives a request for a threat family, raised by each further piece of evidence of that threat. A request is blocked when its score reaches the family's threshold. [How WAF works](/en/documentation/secure/waf/how-it-works/#scoring-and-sensitivity) describes the model. |
| sensitivity level | The setting that fixes the threshold for one threat family, with five values from `highest` to `lowest` and a default of `medium`. A higher sensitivity means a lower threshold, so more requests are blocked. [WAF Rule Sets](/en/documentation/secure/waf/rules-set/#sensitivity-levels) carries the score each level blocks at. |
| `Set WAF` | The [Rules Engine for Firewall](/en/documentation/platform/firewall/rules-engine/) behavior that applies a rule set to the requests a rule matches, and carries the mode that rule set runs in. A rule carries at most one `Set WAF` behavior. Without it, a rule set never runs. |
| threat family | One of the eight classes of attack a rule set scores, each carrying its own sensitivity level. They cover attack types such as [SQL injection, cross-site scripting, and directory traversal](https://www.azion.com/en/learning/). [WAF Rule Sets](/en/documentation/secure/waf/rules-set/#threat-families) names all eight and what each one detects. |
| threshold | The score at which WAF blocks a request for one threat family. The sensitivity level chosen for that family fixes it, so a higher sensitivity sets a lower threshold. [How WAF works](/en/documentation/secure/waf/how-it-works/#scoring-and-sensitivity) describes how the two relate. |
| Tuning | The tab on a rule set that lists the requests each internal rule matched, over a window of up to the last 3 days. You filter it by workload or domain, path, country, IP address, and [Network Lists](/en/documentation/secure/network-shield/network-lists/), then turn selected records into allowed rules in bulk. [WAF Exceptions](/en/documentation/secure/waf/custom-allowed-rules/#tuning) documents the screen. |
| WAF module | The switch on a [Firewall](/en/documentation/platform/firewall/) configuration that turns WAF on for it. No rule set runs until the module is enabled on the firewall the request passes through. [How to configure Firewall main settings](/en/documentation/guides/application-security/firewall-and-waf/firewall-configure-main-settings/) shows where the switch is. |
