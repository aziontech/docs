**Orchestrator Agent** writes two logs on every node it manages: its own log, and one log for the services bound to that node. You read both from a terminal on the node. Together they say whether the agent reached the server and whether a service's triggers ran.

---

## Prerequisites

- Orchestrator Agent installed on the node. To install it, refer to [Install the Orchestrator Agent](/en/documentation/guides/application-development/automation/install-orchestrator-agent/).
- Shell access to that node, with permission to run `sudo`.

---

## Read the Orchestrator Agent log

The agent writes to `/var/log/azion/edge-orchestrator.log`. Every entry in that file comes from the agent itself, not from a service the agent runs.

To open the agent log on the node:

```bash
sudo vim /var/log/azion/edge-orchestrator.log
```

:::note
You can choose the text editor you want, as long as it is installed on the node.
:::

The file opens in the editor. It holds the manifest version, the agent's communication with the server, and the errors the agent recorded.

---

## Read the services log

The services bound to the node write to `/var/log/azion/edge-services.log`, a separate file from the agent's own log.

To open the services log on the node:

```bash
sudo vim /var/log/azion/edge-services.log
```

The file opens in the editor. It holds the records written by the install, update, and delete triggers configured inside those services.
