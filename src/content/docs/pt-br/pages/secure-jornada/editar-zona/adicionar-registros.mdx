Você pode adicionar, editar ou excluir um registro em uma zona do [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/) pelo Azion Console, pela Azion CLI ou pela Azion API. Cada registro informa aos nameservers da Azion quais valores retornar para um nome da zona. Para criar a própria zona, consulte [Crie, edite ou exclua uma zona](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/edge-dns-definir-main-settings/).

## Pré-requisitos

- Uma zona no Edge DNS para o seu domínio. Para criar uma, consulte [Crie, edite ou exclua uma zona](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/edge-dns-definir-main-settings/).
- A permissão **Edit Edge DNS**, que requer **View Edge DNS**. Consulte [Permissões de equipes](/pt-br/documentacao/fundamentos/teams-permissions/).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

</Fragment>

<Fragment slot="panel.cli">

- A [Azion CLI](/pt-br/documentacao/devtools/cli/) instalada e autorizada.
- O ID da zona. O comando `azion list dns-zone` o exibe na coluna `ID`, ao lado de `NAME` e `DOMAIN` da zona.

</Fragment>

<Fragment slot="panel.api">

- Um [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) e o `curl`.
- O `id` da zona. Uma requisição `GET` para `https://api.azion.com/v4/workspace/dns/zones` lista as zonas da conta em `results`, cada uma com o seu `id` e o seu `domain`.
- Para todos os endpoints e campos da API, consulte a [referência da Azion API](https://api.azion.com/).

</Fragment>

</Tabs>

## Adicione um registro

O exemplo adiciona um registro A que responde `192.0.2.1` para `www.example.com`. Substitua o nome, o tipo e o valor pelos seus. O formato do valor de cada tipo está em [Tipos de registro](/pt-br/documentacao/plataforma/edge-dns/tipos-de-registro/).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para adicionar o registro pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a página do Edge DNS">

  Acesse [Azion Console](https://console.azion.com/) > **Edge DNS**.

  </DocStep>
  <DocStep title="Abra a zona">

  Na página **Zones**, selecione a linha da zona.

  </DocStep>
  <DocStep title="Selecione a aba Records" />
  <DocStep title="Selecione + Record">

  O drawer **Create Record** se abre.

  </DocStep>
  <DocStep title="Informe o nome do registro">

  Em **Name**, informe `www`. O nome é relativo à zona, e o Console adiciona o domínio para você, então nunca o digite. Para responder pelo próprio domínio, informe `@`.

  </DocStep>
  <DocStep title="Selecione o tipo de registro">

  Em **Record Type**, selecione *A - IPv4 Address*.

  </DocStep>
  <DocStep title="Defina o TTL">

  Em **TTL (seconds)**, mantenha `3600` ou informe por quanto tempo os resolvers podem armazenar a resposta em cache. Para um registro ANAME, mantenha o TTL em `20`.

  </DocStep>
  <DocStep title="Informe o valor">

  Em **Value**, informe `192.0.2.1`. Para responder com vários valores, informe um valor por linha.

  </DocStep>
  <DocStep title="(Opcional) Escolha a política">

  Na seção **Policy**, mantenha **Policy Type** em *Simple*. Para dividir as respostas entre vários registros de um mesmo nome, selecione *Weighted* e siga [Distribua o tráfego com pesos](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/balanceamento-de-carga-dns/).

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Console mostra `Edge DNS Record has been created`, e o registro aparece na tabela **Records** da zona.

</Fragment>

<Fragment slot="panel.cli">

Para adicionar o registro pela Azion CLI, substitua `<zone-id>` pelo ID da sua zona. Informe o nome relativo à zona, sem o domínio:

```bash
azion create dns-record --zone-id <zone-id> --name www --type A --rdata 192.0.2.1 --ttl 3600
```

O comando exibe o ID do registro:

```text
Created DNS record with ID 100228
```

A zona contém o registro. Para dar vários valores a um registro, repita `--rdata` ou passe os valores em uma lista separada por vírgulas.

</Fragment>

<Fragment slot="panel.api">

Para adicionar o registro pela Azion API, envie uma requisição `POST` ao endpoint de registros da zona. Substitua `<zone-id>` pelo `id` da sua zona e informe o nome relativo à zona, sem o domínio:

```bash
curl -X POST https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records \
  -H "Authorization: Token [TOKEN VALUE]" \
  -H "Content-Type: application/json" \
  -d '{"name":"www","type":"A","rdata":["192.0.2.1"],"ttl":3600}'
```

Um `201` retorna o registro:

```json
{
  "state": "executed",
  "data": {
    "id": 100172,
    "description": "",
    "name": "www",
    "ttl": 3600,
    "type": "A",
    "rdata": ["192.0.2.1"],
    "policy": "simple",
    "weight": 255
  }
}
```

A zona contém o registro. Anote o `id` dele: você edita ou exclui o registro por esse ID.

</Fragment>

</Tabs>

A API recusa um registro que entra em conflito com a zona, como um segundo registro simples com o mesmo nome e o mesmo tipo, e o registro não é salvo. Para cada recusa e o seu código, consulte [Zonas e registros](/pt-br/documentacao/plataforma/edge-dns/zonas-e-registros/#erros).

Salve um registro antes que alguém consulte o nome dele. Um nome que ninguém consultou antes de você salvar o registro responde em segundos. Um nome consultado antes recebe a resposta `NXDOMAIN` por até uma hora, o mínimo do SOA. Para corrigir isso, consulte [Um registro novo retorna NXDOMAIN](/pt-br/documentacao/plataforma/edge-dns/solucao-de-problemas/#um-registro-novo-retorna-nxdomain).

## Edite um registro

Você altera um registro no próprio lugar, sem precisar excluí-lo e adicioná-lo de novo. O exemplo reduz o TTL de `www` para 300 segundos, o que encurta o tempo em que os resolvers mantêm o valor antigo antes de uma alteração planejada. Para essa prática, consulte [Reduza o TTL alguns dias antes de uma alteração planejada](/pt-br/documentacao/plataforma/edge-dns/boas-praticas/#reduza-o-ttl-alguns-dias-antes-de-uma-alteracao-planejada).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para editar o registro pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a página do Edge DNS">

  Acesse [Azion Console](https://console.azion.com/) > **Edge DNS**.

  </DocStep>
  <DocStep title="Abra a zona">

  Na página **Zones**, selecione a linha da zona.

  </DocStep>
  <DocStep title="Selecione a aba Records" />
  <DocStep title="Abra o registro">

  Na tabela **Records**, selecione a linha do registro. O drawer **Edit Record** se abre com os campos dele.

  </DocStep>
  <DocStep title="Altere o TTL">

  Em **TTL (seconds)**, informe `300`. Para alterar o que o registro responde, edite **Value**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Console mostra `Edge DNS Record has been updated`, e a coluna **TTL (seconds)** do registro mostra `300`.

</Fragment>

<Fragment slot="panel.cli">

Para editar o registro pela Azion CLI, passe apenas as flags que você altera. Substitua `<record-id>` pelo ID que a criação exibiu:

```bash
azion update dns-record --zone-id <zone-id> --record-id <record-id> --ttl 300
```

O comando confirma a atualização:

```text
DNS record 100214 was updated
```

Para alterar o que o registro responde, passe o valor para `--rdata`. Para conferir o resultado, liste os registros da zona:

```bash
azion list dns-record --zone-id <zone-id>
```

A saída exibe uma linha por registro, com o ID dele:

```text
ID      NAME  TYPE  TTL  RDATA
100172  www   A     300  192.0.2.1
…
```

A coluna `TTL` do registro mostra `300`.

</Fragment>

<Fragment slot="panel.api">

Para editar o registro pela Azion API, envie uma requisição `PATCH` apenas com os campos que você altera. Substitua `<record-id>` pelo `id` que a criação retornou:

```bash
curl -X PATCH https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records/<record-id> \
  -H "Authorization: Token [TOKEN VALUE]" \
  -H "Content-Type: application/json" \
  -d '{"ttl":300}'
```

Um `200` retorna o registro inteiro com o TTL alterado:

```json
{
  "state": "executed",
  "data": {
    "id": 100172,
    "description": "",
    "name": "www",
    "ttl": 300,
    "type": "A",
    "rdata": ["192.0.2.1"],
    "policy": "simple",
    "weight": 255
  }
}
```

Para alterar o que o registro responde, envie `rdata`. Uma requisição `PUT` substitui o registro e recebe `name`, `type` e `rdata`. Uma requisição `GET` para `https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records` lista os registros da zona com o `id` de cada um.

</Fragment>

</Tabs>

Uma alteração em um registro existente pode levar alguns minutos para chegar a todos os nameservers. Depois disso, cada resolver mantém o valor antigo até que o TTL dele expire. Se uma consulta ainda retornar o valor antigo, consulte [Um registro alterado ainda retorna o valor antigo](/pt-br/documentacao/plataforma/edge-dns/solucao-de-problemas/#um-registro-alterado-ainda-retorna-o-valor-antigo).

## Exclua um registro

Excluir um registro o remove da zona, e não é possível desfazer a exclusão. Para um registro com política *Weighted*, primeiro defina o peso dele como `0`, como explica [Defina o peso 0 antes de excluir um registro com política Weighted](/pt-br/documentacao/plataforma/edge-dns/boas-praticas/#defina-o-peso-0-antes-de-excluir-um-registro-com-politica-weighted).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para excluir o registro pelo Azion Console:

<DocSteps>
  <DocStep title="Abra a página do Edge DNS">

  Acesse [Azion Console](https://console.azion.com/) > **Edge DNS**.

  </DocStep>
  <DocStep title="Abra a zona">

  Na página **Zones**, selecione a linha da zona.

  </DocStep>
  <DocStep title="Selecione a aba Records" />
  <DocStep title="Selecione Delete na linha do registro">

  Na tabela **Records**, abra as ações da linha do registro e selecione **Delete**.

  </DocStep>
  <DocStep title="Digite o nome do registro">

  No diálogo **Delete record**, digite na caixa o **Name** do registro, como `www` ou `@`.

  </DocStep>
  <DocStep title="Selecione Delete" />
</DocSteps>

O Console mostra `Edge DNS Record successfully deleted`, e o registro sai da tabela **Records**.

</Fragment>

<Fragment slot="panel.cli">

Para excluir o registro pela Azion CLI, substitua `<zone-id>` e `<record-id>` pelos IDs da zona e do registro:

```bash
azion delete dns-record --zone-id <zone-id> --record-id <record-id>
```

O comando confirma a exclusão:

```text
DNS record 100228 was successfully deleted
```

O registro é excluído, e `azion list dns-record --zone-id <zone-id>` deixa de listá-lo.

</Fragment>

<Fragment slot="panel.api">

Para excluir o registro pela Azion API, envie uma requisição `DELETE` ao registro:

```bash
curl -X DELETE https://api.azion.com/v4/workspace/dns/zones/<zone-id>/records/<record-id> \
  -H "Authorization: Token [TOKEN VALUE]"
```

A API responde `200`:

```json
{"state":"executed"}
```

O registro é excluído. Uma requisição `GET` no ID dele passa a retornar `404` com `10004` `Not Found`.

</Fragment>

</Tabs>

Os resolvers que armazenaram em cache uma resposta do registro a mantêm até que o TTL do registro expire.
