[Image Processor](/pt-br/documentacao/build/image-processor/) aplica três limites padrão a uma imagem, e cada plano de serviço inclui uma quantidade de imagens processadas a cada mês. Esta página traz os dois tipos de limite: os valores que se aplicam a uma única imagem e a quantidade que se aplica a um mês.

---

## Limites padrão

Os valores abaixo são os limites padrão que Image Processor aplica a uma imagem. Para solicitar um limite maior para a conta, entre em contato com o time de [suporte técnico](/pt-br/documentacao/suporte/).

| Escopo | Limite |
| --- | --- |
| Tamanho máximo | 150 MB |
| Largura máxima | 3840 pixels |
| Altura máxima | 2160 pixels |

Cada parâmetro `ims` também aceita a sua própria faixa de valores. Essa faixa fica com o parâmetro ao qual pertence, e não nesta tabela. Para mais informações, consulte [Parâmetros de URL](/pt-br/documentacao/build/image-processor/parametros-de-url/).

---

## Uso incluído por plano

Todo plano de serviço inclui uma quantidade de imagens processadas a cada mês. O tamanho, a largura e a altura máximos limitam uma imagem. A quantidade abaixo limita um mês, e ela difere por plano.

| Métrica | Hobby | Pro | Enterprise |
| --- | --- | --- | --- |
| Imagens | 5.000 / mês | 10.000 / mês | Custom |

Uma imagem é uma imagem processada por Image Processor em uma requisição, seja a requisição otimizando, recortando, redimensionando, filtrando ou convertendo o formato. Imagens que [Cache](/pt-br/documentacao/build/cache/) serve sem processamento não são contadas. Uma imagem derivada já mantida em cache não soma nada ao total do mês nas requisições que o cache responde. Por exemplo, uma aplicação que serve uma fotografia em três larguras conta três imagens, e nenhuma nas requisições posteriores que o cache responde.

Para as tarifas que se aplicam à métrica Images, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#image-processor). Para ler quantas imagens a conta já processou até agora, consulte [Consulte dados de uso do Image Processor](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-de-uso-image-processor-com-graphql/).
