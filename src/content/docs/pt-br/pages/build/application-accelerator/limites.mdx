[Application Accelerator](/pt-br/documentacao/build/application-accelerator/) altera um limite do cache setting de um recurso de [Applications](/pt-br/documentacao/plataforma/applications/): o menor tempo que o cache mantém um objeto. Esta página traz esse limite, o limite na outra ponta da faixa e a condição que decide qual dos dois está em vigor. Para os campos a que esses valores se aplicam, com os seus tipos e defaults, consulte [Configurações](/pt-br/documentacao/build/application-accelerator/configuracoes/).

---

## Cache TTL

`modules.cache.max_age` define por quanto tempo o cache mantém um objeto, em segundos. Azion Console apresenta o campo como **Max Age**, na seção **Cache** de um cache setting. O campo é um inteiro de 0 a 31.536.000 e não aceita valor fora dessa faixa. Application Accelerator e [Tiered Cache](/pt-br/documentacao/build/cache/tiered-cache/) decidem quão baixo um cache setting chega dentro dessa faixa.

| Limite | Valor | Aplica-se quando |
| --- | --- | --- |
| Cache TTL mínimo | 60 segundos | Application Accelerator está desativado na aplicação. |
| Cache TTL mínimo | 0 segundos | Application Accelerator está ativado e Tiered Cache está desativado. |
| Cache TTL mínimo | 3 segundos | Application Accelerator está ativado e Tiered Cache está ativado. |
| Cache TTL máximo | 31.536.000 segundos, um ano | Todo cache setting, quaisquer que sejam os módulos ativados. |

O piso de 3 segundos pertence a Tiered Cache, não a Application Accelerator. Tiered Cache mantém a camada de cache em no mínimo 3 segundos, o que estreita o piso de 0 segundos que Application Accelerator libera.

Os limites são aumentados mediante solicitação, conforme o plano da conta. Para solicitar um aumento, entre em contato com o time de [suporte técnico](/pt-br/documentacao/suporte/).

Application Accelerator em uma aplicação pode gerar custos relacionados ao uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#application-accelerator).

## Limites de outros produtos

Uma requisição que Application Accelerator varia continua limitada pelos produtos que mantêm o objeto e executam o código sobre ele. Cada valor abaixo está na página do produto que o detém.

[Cache](/pt-br/documentacao/build/cache/) traz os limites do próprio objeto: o tamanho de um único objeto mantido em cache e o tamanho de um slice file quando um arquivo grande é dividido em fragmentos. Para esses valores, consulte [Cache](/pt-br/documentacao/build/cache/).

Quando a aplicação também executa uma função, essa função tem os seus próprios limites de código e de cada invocação. Para mais informações, consulte [Functions](/pt-br/documentacao/build/functions/).
