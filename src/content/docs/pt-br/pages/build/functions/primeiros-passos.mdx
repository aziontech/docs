Este guia conduz você por executar sua primeira função na Azion. Os passos levam cerca de 10 minutos.

- Criar uma função que retorna `Hello World!`.
- Instanciar a função em uma aplicação.
- Adicionar uma regra do Rules Engine que executa a instância na URI `/hello-world`.
- Requisitar essa URI e ler a resposta.

Três objetos fazem uma função ser executada, e cada um se conecta ao seguinte:

1. A **função** contém o código JavaScript.
2. A **instância de função** vincula a função a uma aplicação. Ela também carrega os Args, um objeto JSON passado para o contexto de execução.
3. A regra do **Rules Engine** seleciona a instância com o comportamento **Run Function**. A regra define a fase de execução e os critérios que a acionam.

Criar uma função não a executa. Uma instância sem uma regra do Rules Engine nunca é executada.

Este guia usa o Azion Console. O Azion CLI, a Azion API e o Azion Terraform provider gerenciam os mesmos três objetos. Para conhecer todas as interfaces, consulte [Functions](/pt-br/documentacao/build/functions/#escopo-e-limites).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- A permissão **Edit Functions** na conta. Ela concede permissão para criar, editar e remover funções, e também requer a permissão **View Functions**.
- A permissão **Edit Applications** na conta. As etapas 2 e 3 alteram uma aplicação, e essa permissão concede permissão para editar, criar e remover aplicações. Ela também requer a permissão **View Applications**. Consulte [Teams Permissions](/pt-br/documentacao/fundamentos/teams-permissions/).
- Uma aplicação. Para criar uma, consulte [Criar uma aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/criar-uma-aplicacao/).

## 1. Crie a função

Para criar a função que retorna a resposta:

<DocSteps>
  <DocStep title="Abra a página Functions">

  Acesse [Azion Console](https://console.azion.com/) > **Products Menu** > **Libraries** > **Functions**.

  </DocStep>
  <DocStep title="Selecione + Function" />
  <DocStep title="Nomeie a função">

  Digite um nome para a função. Por exemplo: `hello-world`.

  </DocStep>
  <DocStep title="Cole o código na aba Code">

  Na aba **Code**, cole o código a seguir:

  ```javascript
  export default {
    async fetch(request, env, ctx) {
      return new Response('Hello World!');
    },
  };
  ```

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A função é salva e fica disponível para ser instanciada em uma aplicação.

:::tip[dica]
Para ler a resposta da função antes que ela atenda tráfego, use o [Preview deployment](/pt-br/documentacao/build/functions/preview-deployment/). Ele roda o código no Azion Console sem um deployment.
:::

---

## 2. Instancie a função na sua aplicação

:::caution[Atenção]
Tempo de computação e invocações de funções geram custos relacionados ao uso. Para as taxas, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).
:::

Para vincular a função a uma aplicação:

<DocSteps>
  <DocStep title="Ainda em Azion Console, vá para Products Menu > Build > Applications" />
  <DocStep title="Selecione a aplicação que executa a função" />
  <DocStep title="Na aba Main Settings, ative o módulo Functions" />
  <DocStep title="Selecione Save" />
  <DocStep title="Vá para a aba Functions Instances" />
  <DocStep title="Selecione + Function Instance" />
  <DocStep title="Nomeie a instância">

  Digite um nome para a instância. Por exemplo: `hello-world instance`.

  </DocStep>
  <DocStep title="Selecione a função">

  Selecione a função `hello-world`.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A nova instância aparece na aba **Functions Instances**.

---

## 3. Adicione a regra que executa a função

Uma instância é executada apenas quando uma regra do Rules Engine a seleciona. Para executar a instância em requisições para `/hello-world`:

<DocSteps>
  <DocStep title="Na mesma aplicação, vá para a aba Rules Engine" />
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Digite um nome para a regra. Por exemplo: `Run hello-world`.

  </DocStep>
  <DocStep title="Selecione Request Phase" />
  <DocStep title="Selecione a variável na seção Criteria">

  Na seção **Criteria**, selecione a variável `${uri}`.

  </DocStep>
  <DocStep title="Selecione is equal como operador de comparação" />
  <DocStep title="Digite o argumento">

  Digite `/hello-world` como argumento.

  </DocStep>
  <DocStep title="Na seção Behaviors, selecione Run Function" />
  <DocStep title="Selecione a instância que você criou" />
  <DocStep title="Selecione Save" />
</DocSteps>

A regra executa a instância em toda requisição cuja URI é `/hello-world`. Novas regras podem levar alguns minutos para propagar. Aguarde antes de requisitar a URI.

:::note[nota]
Se **Run Function** não estiver na lista de **Behaviors**, a aplicação também precisa do módulo **Application Accelerator**. Consulte [Run Function não aparece na lista de comportamentos](/pt-br/documentacao/build/functions/solucao-de-problemas/#run-function-nao-aparece-na-lista-de-comportamentos) para a correção.
:::

---

## 4. Verifique a resposta

Sua aplicação responde em um domínio no formato `xxxxxxxxx.map.azionedge.net`. Para definir o domínio da sua aplicação, consulte [Como configurar um domínio](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).

Para confirmar que a função é executada, requisite a URI definida na regra:

```bash
curl https://<your-azion-domain>/hello-world
```

O corpo da resposta é a string que a função retorna:

```
Hello World!
```

A função agora é executada em toda requisição que corresponde aos critérios da regra.
