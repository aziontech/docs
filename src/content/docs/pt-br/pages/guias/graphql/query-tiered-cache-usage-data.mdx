O dataset `workloadConsumptionMetrics` retorna dados agregados de consumo dos produtos da Azion, incluindo o [Tiered Cache](/pt-br/documentacao/build/cache/tiered-cache/). Você o consulta pela API GraphQL, e os dados ficam disponíveis por até 24 meses.

Este guia executa a consulta no GraphiQL Playground. A mesma consulta funciona a partir de qualquer cliente GraphQL que envie as suas credenciais.

---

## Pré-requisitos

- Uma conta Azion, autenticada. O Playground retorna uma mensagem de erro para uma requisição sem sessão.
- Acesso ao [GraphiQL Playground](/pt-br/documentacao/devtools/graphql/playground-graphql/).

---

## Consulte as requisições e os dados transferidos

A consulta filtra o dataset por produto e por um intervalo de tempo, e soma o uso contabilizado por métrica. Para executá-la:

<DocSteps>
  <DocStep title="Abra o Playground">

  Acesse `https://api.azion.com/v4/consumption/graphql`.

  </DocStep>
  <DocStep title="Insira a consulta">

  O `productId` `1564082375` é o Tiered Cache. Ajuste `begin` e `end` para o período que você quer ler:

  ```graphql
  query {
    workloadConsumptionMetrics(
      filter: {
        tsRange: {
          begin: "2025-02-01T00:00:00",
          end: "2025-03-01T00:00:00",
        }
        productId: 1564082375
        metricNameIn: ["data_transferred_total", "requests"]
      }
      aggregate: {
        sum: accounted
      }
      limit: 10000
      groupBy: [clientId, workloadId, productId, metricName]
    ) {
      clientId
      workloadId
      productId
      metricName
      total: sum
    }
  }
  ```

  </DocStep>
  <DocStep title="Execute a consulta e leia a resposta">

  A resposta carrega um objeto por grupo, com o uso somado em `total`:


  </DocStep>
</DocSteps>

Você agora tem as requisições que o Tiered Cache processou e os bytes que ele transferiu no período, por workload.

## Campos da consulta

| Campo | O que ele carrega |
| --- | --- |
| `filter` | Os critérios que restringem os dados retornados |
| `tsRange` | Um subcampo de `filter`, com um timestamp `begin` e um `end` no formato `YYYY-MM-DDTHH:mm:ss` |
| `productId` | O produto a que as linhas pertencem. O Tiered Cache é `1564082375` |
| `metricNameIn` | As métricas a retornar. Esta consulta lê `data_transferred_total` e `requests` |
| `aggregate` | Com `sum: accounted`, o uso contabilizado de cada evento que casa com os filtros e os grupos |
| `limit` | O número máximo de resultados. O máximo do sistema é `10000` |
| `groupBy` | Os campos pelos quais os resultados são agrupados |

## Campos da resposta

| Campo | O que ele carrega |
| --- | --- |
| `clientId` | O identificador único do cliente na Azion. Por exemplo: `8437r` |
| `workloadId` | O identificador do workload a que o uso pertence. Por exemplo: `4829103746` |
| `productId` | O produto a que a linha pertence |
| `metricName` | A métrica que a linha informa |
| `total` | O valor somado da métrica. Para `data_transferred_total`, os bytes que o Tiered Cache transferiu. Para `requests`, as requisições que ele processou |

Para cada campo do dataset, consulte [Campos da API GraphQL de Consumption](/pt-br/documentacao/devtools/graphql/campos-gql-consumption/).
