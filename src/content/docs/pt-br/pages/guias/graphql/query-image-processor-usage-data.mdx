Consulte o número total de imagens processadas pelo Image Processor a partir do [GraphiQL Playground](/pt-br/documentacao/devtools/graphql/playground-graphql/), usando o conjunto de dados **workloadConsumptionMetrics**.

A Azion retém esses dados por até 24 meses, e você pode exportar os resultados para uma plataforma de terceiros para uma análise mais aprofundada.

---

## Pré-requisitos

- Uma conta Azion, com sessão iniciada. O endpoint de consumo retorna um erro para uma requisição não autenticada.

---

## Consulte o total de imagens processadas

Para obter a contagem de um intervalo de tempo específico:

<DocSteps>
  <DocStep title="Abra o GraphiQL Playground">

  Acesse `https://api.azion.com/v4/consumption/graphql`.

  </DocStep>
  <DocStep title="Envie a consulta">

  Envie uma consulta neste formato:

```graphql
query {
  workloadConsumptionMetrics(
    filter: {
      tsRange: { 
        begin: "2025-02-01T00:00:00",
        end: "2025-03-01T00:00:00",
      }
      productId: 1441110021
      metricName: "images_processed"
    }
    aggregate: {
      sum: accounted
    }
    limit: 10000
    groupBy: [clientId, workloadId, productId, metricName]
  ) {
    clientId
    workloadId
    productId
    metricName
    total: sum
  }
}
```

Onde:

| Campo | Descrição |
|----------|----------|
| `filter` | Define os critérios usados para filtrar os dados retornados pela consulta. |
| `tsRange` | Um subcampo de `filter`. Especifica um intervalo de tempo para filtrar os dados. Inclui os campos `begin` e `end` para definir os timestamps de início e fim. Formato: `"YYYY-MM-DDTHH:mm:ss"`; exemplo: `"2024-04-11T00:00:00"`. |
| `sum: accounted` | Como um subcampo de `aggregate`, calcula o uso total contabilizado para eventos que correspondem aos filtros e grupos da consulta. |
| `limit` | Especifica o número máximo de resultados a serem retornados. Máximo do sistema: `10000`. |
| `groupBy` | Especifica os campos pelos quais os resultados da consulta devem ser agrupados. Exemplo: `[clientId, metricName]`. |
| `productId` | Identificador único do produto em uso. Neste caso, `1441110021` para o Image Processor. |
| `metricName` | Nome da métrica calculada para análises. Neste caso, `images_processed`. |

:::note[nota]
Esta consulta soma as imagens que o Image Processor processou e agrupa o total por `clientId` e `workloadId`. Para mais informações, consulte [Campos da GraphQL API de Consumption](/pt-br/documentacao/devtools/graphql/campos-gql-consumption/).
:::

  </DocStep>

Onde:

| Campo | Descrição |
|----------|----------|
| `clientId` | Identificador único do cliente na Azion. Exemplo: `8437r`. |
| `workloadId` | Identificador do workload associado ao uso. Exemplo: `4829301746`. |
| `productId` | Identificador único do produto em uso. Neste caso, `1441110021` para o Image Processor. |
| `metricName` | Nome da métrica medida para análises. Exemplo: `images_processed`. |
| `total` | Número total de imagens processadas pelo Image Processor. Este campo é o resultado de uma soma. Exemplo: `268675`. |

A resposta retorna o número total de imagens processadas para cada cliente e workload no período consultado.
