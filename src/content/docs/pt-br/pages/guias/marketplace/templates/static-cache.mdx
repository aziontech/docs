O template **Static Cache** implanta uma aplicação que coloca arquivos estáticos em cache, como JavaScript e CSS, pela extensão do arquivo. As suas regras são aplicadas pelo [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/), e elas respeitam as configurações de cache que a origem envia ou aplicam um TTL padrão. As regras cobrem os métodos **GET**, **HEAD** e **OPTIONS**.

Você liga o template à sua própria origem, e a implantação cria uma aplicação na [Azion Platform](/pt-br/documentacao/plataforma/applications/), onde cada configuração continua editável.

---

## Pré-requisitos

- O template usa o [Application Accelerator](/pt-br/documentacao/build/application-accelerator/) e o [Functions](/pt-br/documentacao/build/functions/), que podem gerar custos de uso. Para as taxas, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).
- Acesso ao Azion Console. Consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Configure os campos do template

O formulário de configuração pede as informações de que a aplicação precisa. Um asterisco marca um campo obrigatório.

| Campo | O que inserir |
| --- | --- |
| **Application Name** * | O nome da aplicação na Azion. Ele precisa ser único; um nome já em uso retorna uma mensagem de erro. |
| **Origin Address** * | O endereço da origem de onde a aplicação busca conteúdo. Por exemplo: `www.yourwebsite.com`. |
| **Custom Host Header** | A informação de host acrescentada à requisição que busca conteúdo na origem. Por exemplo: `${host}`. Para mais informações, consulte [Host Header](/pt-br/documentacao/plataforma/connectors/origins/#host-header). |
| **Static files extensions to cache** * | As extensões de arquivo que as regras estáticas cobrem, separadas por vírgulas. Adicione quantas precisar. Por exemplo: `aif,aiff,au,avi,bin,cab,carb,cct,cdf,class,doc`. |
| **CDN Static Maximum TTL** * | O tempo máximo, em segundos, em que o conteúdo em cache é entregue. Aceita de `0` a `31536000`, e o padrão é `1296000`. |
| **Browser Static Maximum TTL** * | O tempo máximo, em segundos, em que o conteúdo permanece em cache no browser. Aceita de `0` a `31536000`, e o padrão é `0`. |

Selecione **Deploy** no canto inferior direito para iniciar a implantação. Uma janela mostra os logs enquanto ela roda, e a página então mostra as informações da aplicação e as opções para continuar.

:::note[nota]
O link para a aplicação a abre no browser, e a configuração leva tempo para propagar pela infraestrutura distribuída da Azion. Aguarde alguns minutos até a URL responder.
:::

## Gerencie o template

Cada configuração que o formulário pediu continua editável no Azion Console. Para abrir a aplicação:

1. Acesse [Azion Console](https://console.azion.com/) > **Products Menu** > **Applications**.
2. Encontre a aplicação que o template criou. A lista é alfabética, e a barra de busca a filtra apenas pelo **Application Name**.
3. Selecione a aplicação para abrir as suas configurações.

A página da aplicação carrega as abas **Cache Settings** e **Rules Engine** que o template configurou.

:::tip[dica]
Para alterar por quanto tempo os arquivos estáticos permanecem em cache, consulte [Crie um cache setting](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/ajustar-cache-settings/). Para os campos de uma aplicação, consulte [Primeiros passos](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
:::
