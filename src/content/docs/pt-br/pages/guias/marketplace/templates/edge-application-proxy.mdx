Você pode implantar o template Applications Proxy pelo Azion Console para ignorar o cache em uma rota de URL da sua origem. O template coloca uma [aplicação](/pt-br/documentacao/plataforma/applications/) na frente da origem. Ele cria uma regra no [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/) e a regra continua editável depois do deployment.

O critério da regra compara a variável `${uri}` com a rota que você informa, como `/url_route`, pelo operador `starts_with`. Uma requisição que corresponde a ele executa três behaviors:

- [Set Connector](/pt-br/documentacao/plataforma/applications/rules-engine/#set-connector) envia a requisição para `Default Origin`, a origem que o template cria a partir do endereço que você informa.
- [Bypass Cache](/pt-br/documentacao/plataforma/applications/rules-engine/#bypass-cache) impede que a Azion armazene em cache a resposta da origem, então os cache settings da aplicação não se aplicam à rota.
- [Forward Cookies](/pt-br/documentacao/plataforma/applications/rules-engine/#forward-cookies) envia o header `Set-Cookie` da origem para o usuário.

Bypass Cache age sobre o cache da Azion e não sobre a camada do Tiered Cache. Se um cache setting da aplicação ativa Tiered Cache, essa camada ainda armazena em cache os objetos da rota pelo TTL mínimo dela. Para mais informações, consulte [Tiered Cache](/pt-br/documentacao/plataforma/applications/cache/tiered-cache/).

## Pré-requisitos

- O endereço da sua origem, o servidor de onde a aplicação busca o conteúdo original.
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Implante o template

O template Applications Proxy é implantado a partir de um formulário no Azion Console, e o formulário marca cada campo obrigatório com um asterisco. A aplicação que ele cria usa [Application Accelerator](/pt-br/documentacao/plataforma/applications/como-funciona/#application-accelerator) e [Functions](/pt-br/documentacao/plataforma/functions/), o que pode gerar custos relacionados ao uso. Para os valores, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

Abra o formulário do template no Azion Console:

<DocButton label="Implantar" href="https://console.azion.com/create/azion/edge-application-proxy" icon="ai ai-azion" size="medium" />

Para implantar o template pelo formulário:

<DocSteps>
  <DocStep title="Nomeie a aplicação">

  Insira um nome único para a aplicação na Azion. Um nome que já está em uso retorna uma mensagem de erro.

  </DocStep>
  <DocStep title="Insira o endereço da origem">

  Insira o endereço da origem de onde a aplicação busca o conteúdo original, como `www.yourwebsite.com`.

  </DocStep>
  <DocStep title="(Opcional) Insira um host header personalizado">

  Se a sua origem precisa de informações de host no header da requisição para retornar conteúdo, insira essas informações, como `${host}`. Para mais informações sobre o host header, consulte [Origins](/pt-br/documentacao/plataforma/connectors/origins/).

  </DocStep>
  <DocStep title="Insira a rota que o bypass cobre">

  Insira a rota de URL à qual a regra de bypass se aplica, como `/url_route`.

  </DocStep>
  <DocStep title="Inicie o deployment">

  Envie o formulário. Uma janela mostra os logs do deployment enquanto ele é executado.

  </DocStep>
</DocSteps>

Quando o deployment termina, a página mostra as informações da aplicação e as opções para continuar. A configuração leva alguns minutos para se propagar pela infraestrutura distribuída da Azion. Até lá, o link da aplicação pode não mostrar a página, então aguarde alguns minutos e abra o link de novo.

## Abra a regra de bypass

A regra que o template Applications Proxy cria continua editável na aba **Rules Engine** da aplicação. Nessa aba, você pode alterar a rota ou os behaviors da regra.

Para abrir a regra:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A página lista todas as aplicações da conta em ordem alfabética.

  </DocStep>
  <DocStep title="Pesquise a aplicação">

  Insira o nome que você deu à aplicação. A busca filtra a lista apenas pelo nome da aplicação.

  </DocStep>
  <DocStep title="Selecione a aplicação" />
  <DocStep title="Selecione a aba Rules Engine" />
  <DocStep title="Selecione a regra que o template criou" />
</DocSteps>

A regra abre para edição, com o critério e os três behaviors que o template definiu. Para cada campo do critério e dos behaviors, consulte [Rules Engine para Applications](/pt-br/documentacao/plataforma/applications/rules-engine/#bypass-cache). Para as configurações da própria aplicação, consulte [Main Settings](/pt-br/documentacao/plataforma/applications/main-settings/). Para criar uma aplicação manualmente, com um connector e uma regra próprios, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
