O template **Static Cache + Videoteca Player** implanta uma aplicação que coloca conteúdo estático e dinâmico em cache por extensão de arquivo, e entrega o player da Videoteca, da Videofront, por um iframe. A implantação cria um repositório no GitHub com o projeto, uma aplicação com vários cache settings e uma rota preconfigurada que executa a função do Videoteca Player, e um domínio que a entrega.

Cada push nesse repositório é implantado automaticamente.

---

## Pré-requisitos

- Uma conta no [GitHub](https://github.com/signup), para conectar com a Azion e criar o repositório.
- A integração Videoteca Player instalada e configurada. Consulte [Videofront Player](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/integracoes/videofront-player/).
- Uma conta Videoteca, que carrega o username e o token de API que o formulário pede.
- O template usa o [Application Accelerator](/pt-br/documentacao/build/application-accelerator/), o [Functions](/pt-br/documentacao/build/functions/), o [Image Processor](/pt-br/documentacao/build/image-processor/) e o [Cache](/pt-br/documentacao/build/cache/), que podem gerar custos de uso. Para as taxas, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).
- Acesso ao Azion Console. Consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

## Configure os campos do template

O formulário de configuração pede as informações de que a aplicação precisa. Um asterisco marca um campo obrigatório.

Primeiro, nomeie a aplicação. O bucket de armazenamento e a função recebem o mesmo nome, então ele precisa ser único; um nome já em uso retorna uma mensagem de erro.

Depois, preencha os campos da integração Videoteca Player:

| Campo | O que inserir |
| --- | --- |
| **Origin Address** | O nome de domínio ou o endereço IP da origem. |
| **Custom Host Header** | O valor do header `host` enviado à origem. Em branco, ele recebe o endereço da origem. Para mais informações, consulte [Host Header](/pt-br/documentacao/plataforma/connectors/origins/#host-header). |
| **Videoteca Player Path** | O path que entrega o player. Por exemplo: `/player`. |
| **Videoteca Username** | O username da sua conta Videoteca. |
| **Videoteca API Token** | O token de API da sua conta Videoteca. |

O token de API está disponível em `https://<SEU-USUARIO>.videotecaead.com.br/Apidoc`, onde `<SEU-USUARIO>` é o seu username da Videoteca.

Selecione **Deploy** para iniciar a implantação. Uma janela mostra os logs enquanto ela roda, e a página então mostra as informações da aplicação e as opções para continuar.

:::note[nota]
A configuração leva tempo para propagar pela infraestrutura distribuída da Azion. Aguarde alguns minutos até a URL responder.
:::

## Gerencie o template

Cada configuração que o formulário pediu continua editável no Azion Console. Para abrir a aplicação:

1. Acesse [Azion Console](https://console.azion.com/) > **Products Menu** > **Applications**.
2. Encontre a aplicação que o template criou. A lista é alfabética, e a barra de busca a filtra apenas pelo **Application Name**.
3. Selecione a aplicação para abrir as suas configurações.

A página da aplicação carrega os cache settings e a rota que o template configurou.

:::tip[dica]
Para alterar por quanto tempo os arquivos estáticos permanecem em cache, consulte [Crie um cache setting](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/ajustar-cache-settings/). Para os campos de uma aplicação, consulte [Primeiros passos](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
:::
