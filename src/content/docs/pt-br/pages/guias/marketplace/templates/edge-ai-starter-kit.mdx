Você pode implantar o template **AI Inference Starter Kit** e gerenciar o que ele cria pelo Azion Console. O template cria uma aplicação com uma função e um domínio, e a função serve um endpoint compatível com OpenAI.

O guia [Primeiros passos com AI Inference](/pt-br/documentacao/build/ai-inference/primeiros-passos/) cobre a mesma implantação e acrescenta uma primeira requisição ao modelo.

## Pré-requisitos

O template usa [Application Accelerator](/pt-br/documentacao/build/application-accelerator/), [Functions](/pt-br/documentacao/build/functions/) e [AI Inference](/pt-br/documentacao/build/ai-inference/), que podem gerar custos de uso. Para conhecer os valores, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

---

## Implante o template

Para criar a aplicação, a função e o domínio a partir de um único template:

1. Acesse [Azion Console](https://console.azion.com/) e selecione **+ Create**.
2. Selecione o template **AI Inference Starter Kit**.
3. Insira um nome para a aplicação.
4. Selecione **Deploy**.

Uma janela mostra os logs da implantação enquanto ela é executada. Quando ela termina, a página mostra informações sobre a aplicação e as opções para continuar.

:::note[nota]
A página da implantação mostra um link para a aplicação. A aplicação leva alguns minutos para se propagar aos data centers da Azion, e o domínio não resolve até que ela se propague. Aguarde alguns minutos e selecione o link novamente.
:::

A aplicação responde em um Workload Domain na forma `xxxxxxxxxx.map.azionedge.net/` e serve um endpoint compatível com OpenAI nesse domínio. Para conhecer o caminho que uma requisição percorre do domínio até o modelo, consulte a [arquitetura do AI Inference](/pt-br/documentacao/guias/ai/inferencia/ai-inference-architecture/).

## Atualize a função

A função que o template instala contém a chamada ao modelo, e a página dela tem três abas:

- **Main Settings** renomeia a função e altera as configurações básicas dela.
- **Code** contém o código da função.
- **Arguments** define os argumentos que a função usa.

Para alterar a função:

1. Acesse [Azion Console](https://console.azion.com/) > **Products menu** > **Functions**.
2. Selecione a função que tem o mesmo nome da aplicação. A lista está em ordem alfabética, e a **barra de busca** a filtra apenas por **Function Name**.
3. Abra a aba que contém a configuração que você quer alterar.
4. Selecione **Save**.

A função tem as alterações que você salvou. Para conhecer todas as configurações que uma função tem, consulte [Functions](/pt-br/documentacao/build/functions/).

A aba **Code** abre em uma função pronta para ser executada. Ela recebe uma requisição POST, chama o modelo e retorna a resposta. A chamada abaixo define `stream` como `false`, então o modelo retorna a resposta inteira:

```ts
const modelResponse = await Azion.AI.run("Qwen/Qwen3-30B-A3B-Instruct-2507-FP8", {
  "stream": false,
  "messages": [
    {
      "role": "system",
      "content": "You are a helpful assistant."
    },
    {
      "role": "user",
      "content": "Name the European capitals."
    }
  ]
})
return modelResponse
```

O modelo responde com uma entrada em `choices`, e o texto gerado fica em `choices[0].message.content`:

```json
{
  "id": "chatcmpl-example",
  "object": "chat.completion",
  "created": 1746821581,
  "model": "Qwen/Qwen3-30B-A3B-Instruct-2507-FP8",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "reasoning_content": null,
        "content": "Sure! Here is a list of some European capitals...",
        "tool_calls": []
      },
      "logprobs": null,
      "finish_reason": "stop",
      "stop_reason": null
    }
  ],
  "usage": {
    "prompt_tokens": 9,
    "total_tokens": 527,
    "completion_tokens": 518,
    "prompt_tokens_details": null
  },
  "prompt_logprobs": null
}
```

Este exemplo chama o [modelo Qwen3](/pt-br/documentacao/build/ai-inference/qwen3-30ba3b/). Para chamar outro modelo, altere o primeiro argumento de `Azion.AI.run` para o id dele, listado em [Modelos de AI](/pt-br/documentacao/build/ai-inference/modelos/). O corpo também aceita `stream`, que transmite a resposta em vez de retorná-la inteira. Para conhecer todos os campos que o corpo aceita, consulte [Invocação de modelos](/pt-br/documentacao/build/ai-inference/invocacao-de-modelos/).

Antes de alterar a chamada, leia [Boas práticas do AI Inference](/pt-br/documentacao/build/ai-inference/boas-praticas/) para conhecer os padrões de requisição que Azion recomenda, e [Limites do AI Inference](/pt-br/documentacao/build/ai-inference/limites/) para conhecer as condições em que Azion encerra um modelo.

## Gerencie a aplicação

A página da aplicação contém todas as configurações que a implantação criou, e você pode alterar qualquer uma delas. Para abri-la:

1. Acesse [Azion Console](https://console.azion.com/) > **Products menu** > **Applications**.
2. Selecione a aplicação que tem o nome que você inseriu durante a implantação. A lista está em ordem alfabética, e a **barra de busca** a filtra apenas por **Application Name**.

A página da aplicação abre nas configurações que você pode ajustar. Para saber o que cada configuração faz, consulte [Applications primeiros passos](/pt-br/documentacao/plataforma/applications/primeiros-passos/).
