Você implanta o SQL Database Starter Kit pelo Azion Console, e a implantação constrói um projeto CRUD em JavaScript sobre [SQL Database](/pt-br/documentacao/store/sql-database/).

A implantação cria um repositório no GitHub que guarda o projeto, uma aplicação, um banco de dados e um domínio que alcança a aplicação por um navegador. O template roda sobre [Application Accelerator](/pt-br/documentacao/build/application-accelerator/), [Functions](/pt-br/documentacao/build/functions/) e [Cache](/pt-br/documentacao/build/cache/).

---

## Pré-requisitos

- SQL Database habilitado na sua conta. O produto está em Preview e não é habilitado por padrão, então solicite o acesso ao time de suporte técnico. Para solicitá-lo, consulte [Technical Support](/pt-br/documentacao/suporte/). A quantidade de bancos de dados que cada plano inclui está em [Limites do SQL Database](/pt-br/documentacao/store/sql-database/limites/).
- Uma conta no GitHub. A implantação cria o repositório do projeto nela, e cada push nesse repositório é implantado automaticamente.
- Uma conta que alcança Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Os produtos sobre os quais o template roda podem gerar custos de uso. Para mais informações, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#sql-database).

---

## Implante o template

Você obtém e configura o template pelo Azion Console. Para iniciar a implantação:

<DocSteps>
  <DocStep title="Abra o template no Azion Console">

  Acesse o template [SQL Database Starter Kit](https://console.azion.com/create/azion/edgesql-starter-kit) no [Azion Console](https://console.azion.com/).

  </DocStep>
</DocSteps>

O formulário de configuração abre, com os campos que a implantação lê. Os campos marcados com um asterisco são obrigatórios.

---

## Configure o template

O formulário pede a conexão com o GitHub que cria o repositório e o nome que os recursos implantados recebem. Para configurar o template:

<DocSteps>
  <DocStep title="Conecte a Azion com a sua conta do GitHub">

  Uma janela abre para confirmar a instalação do [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/), que conecta a sua conta do GitHub com a Azion. Defina ali as suas permissões e o acesso ao repositório.

  </DocStep>
  <DocStep title="Selecione o Git Scope" />
  <DocStep title="Nomeie a aplicação">

  Insira um nome para a aplicação. O bucket de armazenamento e a function recebem o mesmo nome, então use um nome único e fácil de lembrar. Um nome que já está em uso é recusado com uma mensagem de erro.

  </DocStep>
  <DocStep title="Inicie a implantação">

  Selecione **Deploy**.

  </DocStep>
</DocSteps>

Uma janela mostra os logs enquanto a implantação roda. Quando ela termina, a página mostra as informações sobre a aplicação e as opções para continuar.

:::note[nota]
O link na página final abre a aplicação em um navegador. A aplicação leva alguns minutos para se propagar pela infraestrutura distribuída da Azion, então o endereço pode ficar inativo até a propagação terminar.
:::

## Gerencie o template

As configurações que a implantação escreve são um ponto de partida, e todas elas são editadas pelo Azion Console depois. Para alcançar as configurações da aplicação:

<DocSteps>
  <DocStep title="Abra a lista de aplicações">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A página lista todas as aplicações que a sua conta criou.

  </DocStep>
  <DocStep title="Selecione a aplicação">

  Encontre a aplicação que o template criou e selecione-a. A lista está ordenada alfabeticamente, e a busca filtra apenas pelo campo **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre na página que carrega todas as configurações que você pode ajustar. Para mais informações, consulte [Applications primeiros passos](/pt-br/documentacao/plataforma/applications/primeiros-passos/) e [Crie e gerencie bancos de dados](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/dados/gerenciar-bancos-dados-edge-sql/).

### Adicione um domínio personalizado

A implantação atribui à aplicação um domínio Azion Workload, no formato `xxxxxxxxxx.map.azionedge.net/`, e esse endereço alcança a aplicação por um navegador. Um domínio personalizado alcança a mesma aplicação sob um nome próprio. Para mais informações, consulte [Como configurar um domínio](/pt-br/documentacao/guias/plataforma/migracao/configurar-dominio/).
