Você pode implantar o template Image Optimization a partir do Azion Console para aprimorar o carregamento e o cache de imagens por extensão de arquivo. O template aplica regras avançadas de cache key por meio do Rules Engine para Applications, para as extensões `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.gif`, `.png`.

---

## Pré-requisitos

- [Application Accelerator](/pt-br/documentacao/build/application-accelerator/), que o template usa.
- [Functions](/pt-br/documentacao/build/functions/), que o template usa.

Para saber contra o que cada um conta, consulte [Preços](/pt-br/documentacao/fundamentos/precos/).

## Configure os campos do template

O formulário de configuração solicita as informações para configurar sua aplicação. Um asterisco marca um campo obrigatório.

- **Application Name** *: o nome da sua aplicação na Azion.
    - Use um nome único e memorável. Se o nome já estiver em uso, a plataforma retorna uma mensagem de erro.
- **Origin Address** *: o endereço da origem hospedada de onde a aplicação busca o conteúdo original.
    - Exemplo: `www.yourwebsite.com`
- **Custom Host Header**: adiciona informações de host ao cabeçalho da requisição que a aplicação envia à origem.
    - Exemplo: `${host}`. Para mais informações, consulte [Origins](/pt-br/documentacao/plataforma/connectors/origins/#host-header).
- **Image file extensions to cache** *: as extensões de arquivo para as regras, separadas por vírgula. Adicione quantas extensões precisar, seguindo o exemplo.
    - Exemplo: `jpg,jpeg,bmp,ico,gif,png`
- **CDN Static Maximum TTL** *: o TTL máximo, em segundos, para o conteúdo em cache ser entregue.
    - Aceita valores de `0` a `31536000`. Padrão: `31536000`.
- **Browser Image Maximum TTL** *: o TTL máximo, em segundos, para o conteúdo em cache no navegador.
    - Aceita valores de `0` a `31536000`. Padrão: `0`.

Depois de preencher o formulário, selecione **Deploy** para iniciar a implantação.

Uma janela mostra os logs da implantação enquanto ela é executada. Quando ela é concluída, a página mostra informações sobre a aplicação e opções para continuar.

A implantação cria uma aplicação que é executada na Azion Platform, com a qual você pode gerenciar e ajustar as configurações.

:::note[nota]
A URL da aplicação leva um tempo para propagar pelos data centers da Azion. Aguarde alguns minutos se a página não carregar imediatamente.
:::

## Gerencie a aplicação depois

Você pode personalizar qualquer configuração a qualquer momento pelo Azion Console.

Para gerenciar as configurações da aplicação:

<DocSteps>
  <DocStep title="Acesse Applications">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**. A página lista todas as aplicações que você criou.

  </DocStep>
  <DocStep title="Encontre e selecione a aplicação">

  Encontre a aplicação do template **Image Optimization** e selecione-a. A lista é alfabética, e a barra de busca filtra apenas por **Application Name**.

  </DocStep>
</DocSteps>

A aplicação abre em uma página com todas as configurações que você pode ajustar.

:::tip[dica]
Para mais informações, consulte [Applications primeiros passos](/pt-br/documentacao/plataforma/applications/primeiros-passos/) e [Image Processor](/pt-br/documentacao/build/image-processor/).
:::
