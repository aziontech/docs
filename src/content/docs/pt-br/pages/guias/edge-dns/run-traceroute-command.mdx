Você pode rastrear a rota do seu computador até um nameserver do [Edge DNS](/pt-br/documentacao/plataforma/edge-dns/) com o `traceroute` no macOS e no Linux, ou com o `tracert` no Windows. O rastreamento lista cada salto de rede que os pacotes atravessam, para que o suporte da Azion veja onde o tráfego até o nameserver fica lento ou para. Para conferir quais registros uma zona responde, consulte [Consulte uma zona com o dig](/pt-br/documentacao/guias/seguranca-de-aplicacoes/dns/executar-o-comando-dig/).

---

## Pré-requisitos

- Um host para rastrear. Para o Edge DNS, rastreie um dos nameservers da Azion: `ns1.aziondns.net`, `ns2.aziondns.com` ou `ns3.aziondns.org`. Os comandos desta página usam `ns1.aziondns.net`.
- No Linux, o pacote `traceroute`. Consulte [Instale o traceroute no Linux](#instale-o-traceroute-no-linux).

---

## Instale o traceroute no Linux

O macOS já inclui o `traceroute` e o Windows usa o `tracert`, então este passo vale apenas para o Linux. O comando de instalação depende da distribuição.

No Red Hat ou no CentOS, instale o pacote com o `yum`:

```bash
sudo yum install traceroute -y
```

No Ubuntu ou no Debian, atualize a lista de pacotes e depois instale o pacote com o `apt-get`:

```bash
sudo apt-get update -y
sudo apt-get install traceroute
```

O comando `traceroute` fica então disponível no terminal.

---

## Rastreie a rota no Windows

O Windows executa o rastreamento na janela de comando, com o `tracert`.

Para rastrear a rota até o nameserver no Windows:

<DocSteps>
  <DocStep title="Abra a janela de comando">

  Pressione a tecla Windows e R.

  </DocStep>
  <DocStep title="Inicie o prompt de comando">

  Digite `cmd` e selecione **OK**.

  </DocStep>
  <DocStep title="Execute o tracert">

  No prompt de comando, digite `tracert ns1.aziondns.net` e pressione Enter.

  </DocStep>
</DocSteps>

O resultado do rastreamento aparece na janela de comando. Para interpretá-lo, consulte [Leia a saída](#leia-a-saida).

## Rastreie a rota no macOS ou no Linux

No macOS, abra o **Terminal**. No Linux, abra um terminal. Depois, execute o `traceroute` com o host:

```bash
traceroute ns1.aziondns.net
```

O comando imprime uma linha de cabeçalho e depois uma linha para cada salto. Para interpretar a saída, consulte [Leia a saída](#leia-a-saida).

---

## Leia a saída

Este exemplo executa o `traceroute` no macOS com `-m 6`, que encerra o rastreamento após seis saltos, e com `-q 1`, que envia uma sonda por salto. Cada endereço de um salto da sua rede aparece como `<hop address>`:

```bash
traceroute -m 6 -w 2 -q 1 ns1.aziondns.net
```

```text
traceroute to ns1.aziondns.net (179.191.160.2), 6 hops max, 40 byte packets
 1  <hop address> (<hop address>)  4.464 ms
 2  <hop address> (<hop address>)  6.936 ms
 3  <hop address> (<hop address>)  6.223 ms
 4  <hop address> (<hop address>)  20.735 ms
 5  *
 6  <hop address> (<hop address>)  35.464 ms
```

Leia a saída linha por linha:

- **O cabeçalho** informa o host, o endereço para o qual ele foi resolvido, o limite de saltos e o tamanho de cada pacote de sonda.
- **Cada linha de salto** mostra o número do salto, o nome e o endereço do salto e o tempo de ida e volta em milissegundos. Com `-q 1`, cada linha mostra um tempo.
- **Um `*`** substitui um salto que não responde. O rastreamento continua no salto seguinte, então um salto posterior ainda pode responder.

Com `-m 6`, o rastreamento para no salto 6, chegue ou não ao nameserver.

---

## Compartilhe o rastreamento com o suporte da Azion

Copie a saída completa, com o cabeçalho, para a sua solicitação ao suporte da Azion. O cabeçalho mostra ao suporte qual endereço o seu computador resolveu para o nameserver. Para abrir uma solicitação, consulte [Suporte](/pt-br/documentacao/suporte/).
