Você pode criar uma função, instanciá-la em um firewall e acioná-la com uma regra do Rules Engine. Todos os passos são executados em Azion Console. Para instanciar uma função em um firewall pela Azion API, consulte [Instancie uma função em um firewall](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/instanciar-functions/). Para executar uma função em uma aplicação, consulte [Execute uma função em uma aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/functions-e-runtime/funcoes-serverless/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- A permissão **Edit Functions** na conta. Ela concede permissão para criar, editar e remover funções, e também requer a permissão **View Functions**.
- A permissão **Edit Firewall** na conta. Ela concede permissão para visualizar, criar, editar e remover um firewall, e também requer a permissão **View Firewall**. Consulte [Teams Permissions](/pt-br/documentacao/fundamentos/teams-permissions/).

## Crie a função

Uma função é executada em um firewall quando ela exporta um handler `firewall`. Para criar a função:

<DocSteps>
  <DocStep title="Abra a página Functions">

  Acesse [Azion Console](https://console.azion.com/) > **Products Menu** > **Libraries** > **Functions**.

  </DocStep>
  <DocStep title="Selecione + Function" />
  <DocStep title="Nomeie a função">

  Digite um nome para a função. Por exemplo: `deny-request`.

  </DocStep>
  <DocStep title="Cole o código na aba Code">

  Na aba **Code**, cole o código a seguir:

  ```javascript
  export default {
    firewall: (request, env, ctx) => {
      ctx.deny();
    }
  };
  ```

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A função é salva e fica disponível para ser instanciada em um firewall.

O handler `firewall` define o desfecho da requisição. `ctx.deny()` encerra a requisição com uma resposta HTTP `403 Forbidden`. Quando o handler não chama `ctx.deny()`, a requisição segue para o handler `fetch`. Para os outros desfechos que uma função de firewall retorna, consulte [Functions no Firewall](/pt-br/documentacao/plataforma/firewall/functions/).

:::tip[dica]
O exemplo usa o padrão ES Modules. Para migrar uma função do padrão Service Worker para esse padrão, consulte [Migre padrões de handler em Functions](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/functions-e-runtime/migrar-padroes-de-handler/).
:::

## Crie o firewall

Um firewall executa uma função apenas com o módulo **Functions** ativado. Para criar o firewall:

<DocSteps>
  <DocStep title="Abra a página Firewall">

  Em Azion Console, vá para **Products Menu** > **Firewall**.

  </DocStep>
  <DocStep title="Selecione + Firewall" />
  <DocStep title="Nomeie o firewall">

  Digite um nome para o firewall. Por exemplo: `deny-request firewall`.

  </DocStep>
  <DocStep title="Selecione os domínios que o firewall protege">

  No campo **Domains**, selecione os domínios a associar ao firewall.

  </DocStep>
  <DocStep title="Ative o módulo Functions" />
  <DocStep title="Ative o switch Active" />
  <DocStep title="Selecione Save" />
</DocSteps>

O firewall é salvo, e as abas **Functions Instances** e **Rules Engine** ficam disponíveis na mesma página.

:::note[nota]
Para usar um firewall que já existe, abra-o e ative o módulo **Functions** na aba **Main Settings**.
:::

## Instancie a função no firewall

Uma instância de função vincula a função a um firewall. Para criar a instância:

<DocSteps>
  <DocStep title="Vá para a aba Functions Instances">

  No firewall que você criou, vá para a aba **Functions Instances**.

  </DocStep>
  <DocStep title="Selecione + Function Instance" />
  <DocStep title="Nomeie a instância">

  Digite um nome para a instância. Por exemplo: `deny-request instance`.

  </DocStep>
  <DocStep title="Selecione a função">

  Selecione a função `deny-request`. Apenas as funções com **Initiator Type** definido como _Firewall_ aparecem na lista.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A instância aparece na aba **Functions Instances**. Ela não é executada até que uma regra do Rules Engine a selecione.

---

## Adicione a regra que executa a função

Uma regra do Rules Engine define os critérios que acionam a instância. Para executar a instância em requisições cuja URI começa com `/admin`:

<DocSteps>
  <DocStep title="Vá para a aba Rules Engine">

  No mesmo firewall, vá para a aba **Rules Engine**.

  </DocStep>
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Digite um nome para a regra. Por exemplo: `Run deny-request`.

  </DocStep>
  <DocStep title="Selecione a variável na seção Criteria">

  Na seção **Criteria**, selecione a variável `Request URI`.

  </DocStep>
  <DocStep title="Selecione starts with como operador de comparação" />
  <DocStep title="Digite o argumento">

  Digite `/admin` como argumento.

  </DocStep>
  <DocStep title="Na seção Behaviors, selecione Run Function" />
  <DocStep title="Selecione a instância que você criou" />
  <DocStep title="Selecione Save" />
</DocSteps>

A regra executa a instância em toda requisição cuja URI começa com `/admin`, e a função responde a essas requisições com uma resposta HTTP `403 Forbidden`. As mudanças podem levar alguns minutos para propagar. Aguarde antes de enviar uma requisição que corresponde aos critérios.

:::caution[Atenção]
A função de exemplo nega toda requisição que a regra corresponde. Defina critérios que selecionam apenas as requisições que você quer bloquear.
:::
