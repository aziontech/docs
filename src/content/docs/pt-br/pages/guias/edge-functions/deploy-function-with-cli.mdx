Neste tutorial, você vai construir e fazer o deploy de uma function pelo terminal com o [Azion CLI](/pt-br/documentacao/devtools/cli/). Você vai salvar um personal token e criar um projeto. Depois vai escrever o handler, rodá-lo na sua máquina e fazer o deploy.

O [Functions quickstart](/pt-br/documentacao/build/functions/primeiros-passos/) chega ao mesmo resultado pelo Azion Console. Esta página é o caminho pelo terminal, e termina com os mesmos três objetos: uma function, uma instância e a aplicação que a serve.

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- [Azion CLI](/pt-br/documentacao/devtools/cli/) instalado na sua máquina.
- Um [personal token](/pt-br/documentacao/fundamentos/personal-tokens/).
- Node.js e um gerenciador de pacotes, que o CLI usa para fazer o build do projeto.

## 1. Salve seu personal token

O CLI autoriza cada comando com um personal token armazenado na sua máquina. Para salvá-lo:

```bash
azion -t <seu-token>
```

O token fica armazenado localmente, e os comandos seguintes se autorizam com ele. Você não o informa de novo.

## 2. Crie o projeto

O `azion init` cria o projeto e sua configuração de build. Para começar:

```bash
azion init
```

O comando pede um nome e sugere um que você pode aceitar:

```bash
(Hit enter to accept the suggested name in parenthesis) Your applications name:  (resilient_zeus)
```

Depois ele pergunta qual preset usar. Selecione **Javascript**, o preset para uma function escrita em JavaScript puro, sem framework:

```bash
? Choose a preset:  [Use arrows to move, type to filter]
> AI Studio
  Angular
  Astro
  ...
  Javascript
```

O diretório do projeto agora carrega a configuração de build e o entrypoint que o build lê.

## 3. Escreva o handler

Abra o `main.js`, o entrypoint que o build lê por padrão, e substitua seu conteúdo por um handler ES Modules:

```js
export default {
  async fetch(request, env, ctx) {
    return new Response('Hello World', {
      headers: { 'content-type': 'text/plain' }
    });
  }
};
```

O método `fetch` recebe a requisição, as variáveis de ambiente e o contexto de execução. Ele retorna a resposta que o cliente recebe. Este é o padrão recomendado pela Azion.

## 4. Rode a function localmente

Antes do deploy, rode o projeto na sua máquina e envie uma requisição. Para iniciar o servidor local:

```bash
azion dev
```

O comando faz o build do projeto e então exibe o endereço em que serve:

```bash
[Azion Bundler] [Server] › ✔  success   Function running on port http://localhost:3000
```

De outro terminal, faça uma requisição a esse endereço:

```bash
curl http://localhost:3000/
```

O handler responde com o corpo da resposta:

```bash
Hello World
```

Pare o servidor com `Ctrl+C` quando a resposta estiver correta.

## 5. Faça o deploy do projeto

Para fazer o deploy do projeto na Azion:

```bash
azion deploy
```

O comando faz o build do projeto e cria a aplicação e a function na sua conta. Ele instancia a function e exibe o domínio que a serve. O domínio tem o formato `xxxxxxxxxx.map.azionedge.net`.

Uma requisição a esse domínio retorna a mesma resposta que você leu localmente:

```bash
curl https://xxxxxxxxxx.map.azionedge.net/
```

```bash
Hello World
```

Um domínio novo leva alguns minutos para propagar. Uma requisição imediata pode falhar antes de a configuração estar no lugar. Espere e tente de novo antes de diagnosticar.
