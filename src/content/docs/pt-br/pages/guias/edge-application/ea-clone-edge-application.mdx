Você pode clonar uma [aplicação](/pt-br/documentacao/plataforma/applications/) pelo Azion Console. O clone é uma aplicação separada, com ID próprio, que começa com as mesmas configurações da original. Para criar uma aplicação do zero em vez disso, consulte [Primeiros passos com Applications](/pt-br/documentacao/plataforma/applications/primeiros-passos/).

---

## Pré-requisitos

Você precisa de acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

---

## Clone a aplicação

Azion Console copia as configurações da original para o clone, com um nome que você escolhe. As duas aplicações passam a aparecer na mesma lista, então escolha um nome que as diferencie.

Para clonar a aplicação no Azion Console:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**.

  </DocStep>
  <DocStep title="Encontre a aplicação">

  Para filtrar a lista, insira o nome da aplicação na caixa de busca.

  </DocStep>
  <DocStep title="Abra o menu Actions da aplicação">

  Na linha da aplicação, selecione o menu **Actions**.

  </DocStep>
  <DocStep title="Selecione Clone" />
  <DocStep title="Nomeie o clone">

  Em **Name**, insira um nome que nenhuma outra aplicação usa. Se outra aplicação já tiver esse nome, Azion Console mostra um erro. Insira um nome diferente.

  </DocStep>
  <DocStep title="Confirme o clone">

  Selecione **Clone**.

  </DocStep>
</DocSteps>

Azion Console mostra `Your Application has been cloned` e abre a página do clone. O clone também aparece na lista **Applications** com o nome que você inseriu.

Um workload só entrega o clone depois que você seleciona o clone como a aplicação dele. No Azion Console, essa escolha é o campo **Application** nas **Deployment Settings** do workload. Para mais informações, consulte [Workloads](/pt-br/documentacao/plataforma/workloads/).
