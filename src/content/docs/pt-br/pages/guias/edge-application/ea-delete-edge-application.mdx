Você pode excluir uma [aplicação](/pt-br/documentacao/plataforma/applications/) pelo Azion Console ou pela Azion API. Para guardar uma cópia das configurações dela antes de excluí-la, consulte [Clone uma aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/clonar-applications/).

## Pré-requisitos

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Você precisa de acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

</Fragment>

<Fragment slot="panel.api">

- Um personal token para o header `Authorization`, no formato `Token [TOKEN VALUE]`. Para criar um token, consulte [Como criar um personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).
- Um cliente HTTP, como o `curl`.
- O ID da aplicação. Ele aparece no endereço da página da aplicação no Azion Console, depois de `/applications/edit/`.

## Exclua a aplicação

A Azion exclui a aplicação junto com as configurações e as instâncias que pertencem a ela, como as regras e os cache settings dela. Não é possível desfazer uma exclusão.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para excluir a aplicação no Azion Console:

<DocSteps>
  <DocStep title="Abra a página Applications">

  Acesse [Azion Console](https://console.azion.com/) > **Applications**.

  </DocStep>
  <DocStep title="Encontre a aplicação">

  Para filtrar a lista, insira o nome da aplicação na caixa de busca.

  </DocStep>
  <DocStep title="Abra o menu Actions da aplicação">

  Na linha da aplicação, selecione o menu **Actions**.

  </DocStep>
  <DocStep title="Selecione Delete">

  Selecione **Delete**. A caixa de diálogo **Delete Application** abre e avisa que a exclusão não pode ser revertida.

  </DocStep>
  <DocStep title="Digite o texto de confirmação">

  Na caixa de confirmação, digite o texto que a caixa de diálogo cita, que é o nome da aplicação. **Delete** fica indisponível até que o texto corresponda.

  </DocStep>
  <DocStep title="Confirme a exclusão">

  Selecione **Delete**.

  </DocStep>
</DocSteps>

Azion Console mostra `Resource successfully deleted` e a aplicação não aparece mais na lista **Applications**.

</Fragment>

<Fragment slot="panel.api">

Para excluir a aplicação com a API, envie uma requisição `DELETE` para o endpoint da aplicação. Coloque o ID dela no lugar de `<application-id>`:

```bash
curl --request DELETE \
  --url https://api.azion.com/v4/workspace/applications/<application-id> \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]'
```

A API responde `202` quando aceita a exclusão. Depois que a exclusão termina, a aplicação não aparece mais quando você lista as aplicações da sua conta.

</Fragment>

</Tabs>
