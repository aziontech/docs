[Application Accelerator](/pt-br/documentacao/build/application-accelerator/) libera a [Advanced Cache Key](/pt-br/documentacao/build/cache/cache-settings/#advanced-cache-key), que varia um objeto em cache por argumento de query string ou por cookie. Você a configura em um cache setting em Azion Console e depois aplica esse cache setting com uma regra do [Rules Engine](/pt-br/documentacao/plataforma/applications/rules-engine/).

Para conteúdo que não varia entre requisições, consulte [Configure políticas de cache para uma aplicação](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/cache-settings/). Para o que uma variação altera na cache key, consulte [Como Application Accelerator funciona](/pt-br/documentacao/build/application-accelerator/como-funciona/).

---

## Pré-requisitos

- Uma aplicação. Para criar uma, consulte [Criar uma aplicação](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/primeiros-passos/criar-uma-aplicacao/).
- Acesso a Azion Console. Consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Application Accelerator pode gerar custos relacionados ao uso. Para as tarifas, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#application-accelerator).

---

## Ative Application Accelerator

O módulo vem desativado por padrão, e um cache setting varia o objeto em cache apenas enquanto o módulo está ativado. Para ativá-lo:

<DocSteps>
  <DocStep title="Abra a aplicação">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação**.

  </DocStep>
  <DocStep title="Ative o módulo">

  Na aba **Main Settings**, na seção **Modules**, ative **Application Accelerator**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

A aplicação passa a operar com Application Accelerator, e os cache settings dela podem variar o objeto em cache por query string ou por cookie.

## Varie o cache por um argumento de query string

Uma aplicação serve a URL `domain.com/page?city=city_name`. A URI `/page` chama uma API que lista o conteúdo da cidade indicada no argumento `city`. A API atualiza esse conteúdo a cada cinco minutos. Para armazenar um objeto por cidade e expirá-lo no mesmo intervalo:

<DocSteps>
  <DocStep title="Abra a aba Cache Settings">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação** e vá para a aba **Cache Settings**.

  </DocStep>
  <DocStep title="Selecione + Cache" />
  <DocStep title="Nomeie o cache setting">

  Em **Name**, insira um nome que identifique o cache setting. Por exemplo: `city-listing`.

  </DocStep>
  <DocStep title="Defina o cache do navegador">

  Em **Browser Cache**, selecione _Override cache settings_ e defina a idade máxima como `300`.

  </DocStep>
  <DocStep title="Defina Max Age">

  Em **Cache**, selecione _Override cache behavior_ e defina **Max Age** como `300`.

  </DocStep>
  <DocStep title="Coloque o argumento na allowlist">

  Em **Application Accelerator**, abra **Cache vary by Query String** e defina **Behavior** como _Allowlist_.

  </DocStep>
  <DocStep title="Insira o argumento">

  Adicione `city` à lista de argumentos de query string.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O cache setting aparece na aba **Cache Settings** e varia o objeto em cache pelo argumento `city`.

:::note[nota]
As cache keys diferenciam maiúsculas de minúsculas. A Azion armazena `?city=Lisbon` e `?city=lisbon` como dois objetos.
:::

Um cache setting entra em vigor apenas quando uma regra o aplica. Para aplicar este à URI `/page`:

<DocSteps>
  <DocStep title="Vá para a aba Rules Engine" />
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Insira um nome para a regra. Por exemplo: `city-listing rule`.

  </DocStep>
  <DocStep title="Selecione Request Phase" />
  <DocStep title="Selecione a variável na seção Criteria">

  Na seção **Criteria**, selecione a variável `${uri}`.

  </DocStep>
  <DocStep title="Selecione starts with como operador de comparação" />
  <DocStep title="Insira o argumento">

  Insira `/page` como argumento.

  </DocStep>
  <DocStep title="Na seção Behaviors, selecione Set Cache Policy" />
  <DocStep title="Selecione o cache setting que você criou" />
  <DocStep title="Selecione Save" />
</DocSteps>

As requisições cuja URI começa com `/page` carregam o cache setting. O navegador e a Azion mantêm o objeto de cada cidade por 300 segundos. Uma nova regra leva alguns minutos para propagar.

## Varie o cache por um cookie

Uma aplicação autentica usuários com um cookie, e a página `/profile` que ela serve depois de um login precisa ser diferente por sessão. O cookie `session_cookie` carrega o valor que identifica a sessão. Para armazenar um objeto por sessão:

<DocSteps>
  <DocStep title="Abra a aba Cache Settings">

  Acesse [Azion Console](https://console.azion.com/) > **Applications** > **sua aplicação** e vá para a aba **Cache Settings**.

  </DocStep>
  <DocStep title="Selecione + Cache" />
  <DocStep title="Nomeie o cache setting">

  Em **Name**, insira um nome que identifique o cache setting. Por exemplo: `profile-by-session`.

  </DocStep>
  <DocStep title="Defina o behavior de cache">

  Nas seções **Browser Cache** e **Cache**, defina o behavior e a idade de que a página de perfil precisa.

  </DocStep>
  <DocStep title="Coloque o cookie na allowlist">

  Em **Application Accelerator**, abra **Cache vary by Cookies** e defina **Behavior** como _Allowlist_.

  </DocStep>
  <DocStep title="Insira o nome do cookie">

  Adicione `session_cookie` à lista de nomes de cookies.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O cache setting aparece na aba **Cache Settings** e varia o objeto em cache pelo valor de `session_cookie`. Os nomes de cookies diferenciam maiúsculas de minúsculas, como todo valor que compõe uma cache key.

Para aplicar este cache setting à URI `/profile`:

<DocSteps>
  <DocStep title="Vá para a aba Rules Engine" />
  <DocStep title="Selecione + Rule" />
  <DocStep title="Nomeie a regra">

  Insira um nome para a regra. Por exemplo: `profile rule`.

  </DocStep>
  <DocStep title="Selecione Request Phase" />
  <DocStep title="Selecione a variável na seção Criteria">

  Na seção **Criteria**, selecione a variável `${uri}`.

  </DocStep>
  <DocStep title="Selecione starts with como operador de comparação" />
  <DocStep title="Insira o argumento">

  Insira `/profile` como argumento.

  </DocStep>
  <DocStep title="Na seção Behaviors, selecione Set Cache Policy" />
  <DocStep title="Selecione o cache setting que você criou" />
  <DocStep title="Selecione Save" />
</DocSteps>

As requisições cuja URI começa com `/profile` carregam o cache setting. Cada sessão recebe o objeto armazenado em cache para o próprio valor de `session_cookie`. Uma nova regra leva alguns minutos para propagar.
