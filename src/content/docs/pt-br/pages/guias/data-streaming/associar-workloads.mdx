Você pode associar [workloads](/pt-br/documentacao/plataforma/workloads/) a um stream do [Data Stream](/pt-br/documentacao/plataforma/data-stream/) pelo Azion Console. Para associar domínios a um stream, consulte [Como associar domínios no Data Stream](/pt-br/documentacao/guias/plataforma/observabilidade/data-stream-associar-dominios/).

Um stream coleta os eventos dos workloads associados a ele e os envia ao endpoint que você configura no stream. Um stream pode coletar os eventos de um único workload ou de vários. Você os escolhe na seção **Workloads** do stream.

---

## Pré-requisitos

- Um ou mais workloads na sua conta. Para criar um workload, consulte [Primeiros passos com Workloads](/pt-br/documentacao/plataforma/workloads/primeiros-passos/).
- Acesso ao Azion Console. Para mais informações, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

---

## Crie um stream para seus workloads

Você escolhe os workloads no mesmo formulário em que nomeia o stream e define a fonte e o template dele. A escolha é todos os workloads da sua conta ou uma lista que você monta.

Para criar o stream no Azion Console:

<DocSteps>
  <DocStep title="Abra a página Data Stream">

  Acesse [Azion Console](https://console.azion.com/) > **Observe** > **Data Stream**.

  </DocStep>
  <DocStep title="Selecione + Stream" />
  <DocStep title="Insira um nome para o stream" />
  <DocStep title="Selecione a fonte">

  Em **Source**, selecione a fonte de dados dos eventos. Para mais informações, consulte [Data sources](/pt-br/documentacao/plataforma/data-stream/#data-sources).

  </DocStep>
  <DocStep title="Selecione o template">

  Em **Template**, selecione o template dos eventos. Para mais informações, consulte [Templates](/pt-br/documentacao/plataforma/data-stream/#templates).

  </DocStep>
  <DocStep title="Escolha a opção de workloads">

  Em **Workloads** > **Option**, selecione um destes valores:

  - _All Current and Future Workloads_: a Azion seleciona todos os workloads da sua conta, incluindo os workloads que você criar depois.
  - _Filter Workloads_: o stream coleta apenas os workloads que você move para **Chosen Workloads**.

  </DocStep>
  <DocStep title="Mova os workloads para Chosen Workloads">

  Se você selecionou _Filter Workloads_, use os controles da lista **Available Workloads**. Caso contrário, pule esta etapa.

  - Para encontrar um workload, insira caracteres ou palavras, ou role a lista.
  - Para mover um workload para **Chosen Workloads**, selecione-o e depois selecione `>`.
  - Para mover vários de uma vez, selecione-os com `ctrl` no Windows e no Linux ou `command` no Mac e depois selecione `>`.
  - Para selecionar todos os workloads que a lista mostra, selecione `>>`.
  - Para remover workloads de **Chosen Workloads**, selecione-os e depois selecione `<`. Para remover todos, selecione `<<`.

  Os workloads que você move aparecem em **Chosen Workloads**.

  </DocStep>
  <DocStep title="Preencha os campos obrigatórios restantes">

  Para mais informações, consulte [Como configurar as main settings do Data Stream](/pt-br/documentacao/guias/plataforma/observabilidade/como-usar-data-stream/).

  </DocStep>
  <DocStep title="Ative o switch Active">

  Confirme que o switch **Active** está ativado.

  </DocStep>
  <DocStep title="Salve o stream">

  Selecione **Save**.

  </DocStep>
</DocSteps>

O stream coleta os eventos dos workloads que você escolheu e os envia ao endpoint dele.
