Você pode editar, parar ou excluir um stream do [Data Stream](/pt-br/documentacao/plataforma/data-stream/) no Azion Console ou com a Azion API. Para criar um stream, consulte [Primeiros passos do Data Stream](/pt-br/documentacao/plataforma/data-stream/primeiros-passos/).

Um stream parado mantém as configurações e não envia nada até você iniciá-lo de novo. Um stream excluído deixa de existir, junto com as configurações. Para ver todos os campos que você pode alterar, consulte [Configurações do stream](/pt-br/documentacao/plataforma/data-stream/configuracoes-do-stream/).

## Pré-requisitos

- Um stream na sua conta Azion. Para criar um, consulte [Primeiros passos do Data Stream](/pt-br/documentacao/plataforma/data-stream/primeiros-passos/).
- A permissão **Edit Data Stream**. Só com **View Data Stream**, você vê os streams, mas não pode editá-los, pará-los nem excluí-los. Para mais informações, consulte [Configurações do stream](/pt-br/documentacao/plataforma/data-stream/configuracoes-do-stream/#permissoes).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

- Acesso ao Azion Console. Para entrar, consulte [Acessar Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma conta com menos de 3.000 workloads. A partir de 3.000 workloads, o Console bloqueia os formulários de stream, e você gerencia os streams só pela API.

</Fragment>

<Fragment slot="panel.api">

- Um personal token. Para criar um, consulte [Criar um personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).
- `curl`.
- O ID do stream. A resposta de listagem de `GET /v4/workspace/stream/streams` traz o ID no campo `id` de cada stream. No Azion Console, ele é o número no final da URL da página de edição do stream, `/data-stream/edit/<stream-id>`.

</Fragment>

</Tabs>

## Edite um stream

Uma edição mantém o ID do stream e altera só as configurações que você salva. Salvar verifica o formato dos campos, não o endpoint, então uma credencial errada aparece depois como envios com falha.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para editar um stream no Azion Console:

<DocSteps>
  <DocStep title="Abra o Data Stream">

  Acesse [Azion Console](https://console.azion.com/) > **Data Stream**.

  </DocStep>
  <DocStep title="Abra o stream">

  Na lista, selecione a linha do stream. A página de edição abre com o nome do stream como título.

  Um stream sem sampling abre com *Filter Workloads* selecionado em **Option**, porque o formulário lê a opção a partir dos transforms do stream.

  </DocStep>
  <DocStep title="Altere as configurações">

  Na seção **General**, **Input**, **Transform**, **Render Template**, **Output** ou **Status**, altere os campos necessários. A seção **Output** chama o campo do endpoint de **Connector**.

  Em uma edição, o Console não exige a **Secret Key** do S3. Para AWS Kinesis Data Firehose, informe a **Secret Key** de novo a cada vez que salvar.

  </DocStep>
  <DocStep title="Selecione Save" />
  <DocStep title="Confirme o aviso de sampling">

  Se **Sampling** estiver ligado, a caixa de diálogo **Attention** abre com `After activating and saving these settings, all other Data Streams will be disabled.` Selecione **Confirm**.

  </DocStep>
</DocSteps>

O Console mostra `Your data stream has been updated`.

</Fragment>

<Fragment slot="panel.api">

Para editar um stream com a API, envie uma requisição `PATCH` só com as chaves que você altera. Este exemplo renomeia o stream. Substitua `<stream-id>` pelo ID do seu stream:

```bash
curl -X PATCH 'https://api.azion.com/v4/workspace/stream/streams/<stream-id>' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Token [TOKEN VALUE]' \
  -d '{"name": "activity-to-bucket"}'
```

A API responde `200` com o stream armazenado:

```json
{
  "state": "executed",
  "data": {
    "id": 19553,
    "name": "activity-to-bucket",
    "last_editor": "user@example.com",
    "created": "2026-10-02T19:15:47.308874Z",
    "last_modified": "2026-10-02T19:15:59.607883Z",
    "product_version": "1.0",
    "active": true,
    "inputs": [{ "type": "raw_logs", "attributes": { "data_source": "activity_history" } }],
    "transform": [
      { "type": "sampling", "attributes": { "rate": 100 } },
      { "type": "render_template", "attributes": { "template": 251 } }
    ],
    "outputs": […]
  }
}
```

O `name` é o que você enviou, e `last_modified` avança. A fonte de dados, os transforms e o endpoint continuam como estavam. Para substituir o stream inteiro, envie uma requisição `PUT` com as chaves que uma criação exige: `name`, `inputs`, `transform` e `outputs`. Para o corpo de cada chave, consulte [Configurações do stream](/pt-br/documentacao/plataforma/data-stream/configuracoes-do-stream/#objeto-do-stream).

</Fragment>

</Tabs>

As edições levam alguns minutos para se propagar. Salvar um stream ativo que usa sampling desativa todos os outros streams da conta. Depois de alterar o endpoint, verifique os próximos envios no [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/#data-stream): cada envio é registrado com o status code que o endpoint retornou.

## Pare um stream

Um stream parado mantém as configurações, então você pode iniciá-lo de novo sem configurá-lo.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para parar um stream no Azion Console:

<DocSteps>
  <DocStep title="Abra o Data Stream">

  Acesse [Azion Console](https://console.azion.com/) > **Data Stream**.

  A coluna **Status** mostra cada stream como *Active* ou *Inactive*.

  </DocStep>
  <DocStep title="Abra o stream">

  Na lista, selecione a linha do stream.

  </DocStep>
  <DocStep title="Desligue Active">

  Na seção **Status**, desligue **Active**.

  </DocStep>
  <DocStep title="Selecione Save" />
  <DocStep title="Confirme o aviso de sampling">

  Se a caixa de diálogo **Attention** abrir, selecione **Confirm**.

  </DocStep>
</DocSteps>

O Console mostra `Your data stream has been updated`, e a lista mostra o stream como *Inactive*. Para iniciar o stream de novo, ligue **Active** e selecione **Save**.

</Fragment>

<Fragment slot="panel.api">

Para parar um stream com a API, envie uma requisição `PATCH` que define `active` como `false`:

```bash
curl -X PATCH 'https://api.azion.com/v4/workspace/stream/streams/<stream-id>' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Token [TOKEN VALUE]' \
  -d '{"active": false}'
```

A API responde `200` com o stream armazenado:

```json
{
  "state": "executed",
  "data": {
    "id": 19553,
    "name": "activity-to-bucket",
    …
    "last_modified": "2026-10-02T19:48:37.538700Z",
    "product_version": "1.0",
    "active": false,
    …
  }
}
```

O stream mostra `"active": false`, e as outras configurações não mudam. Para iniciar o stream de novo, envie a mesma requisição com `{"active": true}`.

</Fragment>

</Tabs>

Uma mudança no estado ativo entra em vigor depois de um a dois minutos. Durante esse intervalo, o stream pode continuar enviando. Depois dele, o [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/#data-stream) não registra mais nenhum envio do stream parado para o endpoint.

:::caution[Atenção]
Iniciar um stream que usa sampling desativa todos os outros streams da conta, e a API não retorna nenhum aviso. Uma taxa de `100` conta como sampling. Para executar vários streams ao mesmo tempo, dê a cada um deles um filtro de workloads. Para os passos, consulte [Associe workloads a um stream](/pt-br/documentacao/guias/plataforma/observabilidade/data-stream-associar-workloads/).
:::

## Exclua um stream

Excluir um stream remove o stream e as configurações dele. Um stream excluído não pode ser restaurado: o Console avisa `Once confirmed, this action can't be reversed.` Para pausar um stream e manter as configurações, pare o stream em vez disso.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para excluir um stream no Azion Console:

<DocSteps>
  <DocStep title="Abra o Data Stream">

  Acesse [Azion Console](https://console.azion.com/) > **Data Stream**.

  </DocStep>
  <DocStep title="Selecione Delete">

  Na linha do stream, selecione **Delete**, o ícone de lixeira. A caixa de diálogo **Delete stream** abre.

  </DocStep>
  <DocStep title="Digite o nome do stream">

  Na caixa, digite o nome do stream exatamente como a caixa de diálogo o mostra.

  </DocStep>
  <DocStep title="Selecione Delete" />
</DocSteps>

O Console mostra `Data Stream successfully deleted`.

</Fragment>

<Fragment slot="panel.api">

Para excluir um stream com a API, envie uma requisição `DELETE`:

```bash
curl -X DELETE 'https://api.azion.com/v4/workspace/stream/streams/<stream-id>' \
  -H 'Authorization: Token [TOKEN VALUE]'
```

A API responde `200`:

```json
{"state":"executed"}
```

O valor `"state": "executed"` confirma que a API excluiu o stream.

</Fragment>

</Tabs>
