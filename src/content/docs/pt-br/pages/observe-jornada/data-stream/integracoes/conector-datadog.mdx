Você pode enviar os logs de um stream para o [Datadog](https://www.datadoghq.com/) pelo Azion Console ou com a Azion API.

[Data Stream](/pt-br/documentacao/plataforma/data-stream/) envia cada lote de linhas de log para a URL de intake de logs da sua conta do Datadog e se autentica com uma API key do Datadog. No formulário do stream, o endpoint é definido no campo **Connector**, e o Datadog é a opção *Datadog* desse campo. Para ver todos os campos e os limites deles, consulte [Endpoints](/pt-br/documentacao/plataforma/data-stream/endpoints/#datadog).

Neste guia, o stream coleta as requisições que um workload recebe, por meio da fonte de dados *Applications*.

## Pré-requisitos

- Uma conta Azion com a permissão **Edit Data Stream**. Para ver as permissões, consulte [Configurações do stream](/pt-br/documentacao/plataforma/data-stream/configuracoes-do-stream/#permissoes).
- Um [workload](/pt-br/documentacao/plataforma/workloads/) na conta que recebe requisições.
- Uma conta do Datadog.
- A URL de intake de logs da sua conta do Datadog, com o esquema, como `https://http-intake.logs.datadoghq.com/v1/input`.
- Uma API key do Datadog, criada no dashboard do Datadog.

- Acesso ao Azion Console. Para entrar, consulte [Acessar Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).

</Fragment>

- O ID do workload.
- `curl`.

## Crie o stream

Um filtro de workloads limita o stream ao workload que você escolher. Ao contrário de um stream com sampling, um stream com filtro de workloads mantém seus outros streams ativos.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para criar o stream no Azion Console:

<DocSteps>
  <DocStep title="Abra o Data Stream">

  Acesse [Azion Console](https://console.azion.com/) > **Data Stream**.

  </DocStep>
  <DocStep title="Selecione + Stream" />
  <DocStep title="Dê um nome ao stream">

  Na seção **General**, informe um **Name**. Por exemplo: `logs-to-datadog`.

  </DocStep>
  <DocStep title="Selecione a fonte de dados">

  Na seção **Input**, selecione *Applications* em **Data Source**.

  </DocStep>
  <DocStep title="Desative o Sampling">

  Na seção **Transform**, desative **Sampling** enquanto **Option** ainda estiver em *All Current and Future Workloads*, o valor inicial. Um stream não pode ter sampling e filtro de workloads ao mesmo tempo.

  </DocStep>
  <DocStep title="Escolha o workload">

  Na seção **Transform**, defina **Option** como *Filter Workloads*. Em **Available Workload**, selecione seu workload e mova-o para **Chosen Workload** com a seta.

  </DocStep>
  <DocStep title="Selecione o template">

  Na seção **Render Template**, selecione *Applications Event Collector* em **Template**.

  </DocStep>
  <DocStep title="Selecione o endpoint Datadog">

  Na seção **Output**, selecione *Datadog* em **Connector**.

  </DocStep>
  <DocStep title="Informe a URL de intake">

  Em **URL**, informe a URL de intake de logs da sua conta do Datadog. Por exemplo: `https://http-intake.logs.datadoghq.com/v1/input`.

  </DocStep>
  <DocStep title="Informe a API key">

  Em **API Key**, informe sua API key do Datadog.

  </DocStep>
  <DocStep title="Mantenha o stream ativo">

  Na seção **Status**, mantenha **Active** ativado.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O Console mostra `Your data stream has been created`. O stream aparece na lista do **Data Stream** com `Datadog` na coluna **Connector** e o status **Active**.

</Fragment>

<Fragment slot="panel.api">

Envie uma requisição `POST` para `https://api.azion.com/v4/workspace/stream/streams`. No corpo, substitua `<workload-id>` pelo ID do seu workload e informe sua URL de intake e sua API key na entrada de `outputs`. Substitua `[TOKEN VALUE]` pelo seu personal token:

```bash
curl -X POST 'https://api.azion.com/v4/workspace/stream/streams' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Token [TOKEN VALUE]' \
  -d '{
    "name": "logs-to-datadog",
    "active": true,
    "inputs": [
      { "type": "raw_logs", "attributes": { "data_source": "workloads" } }
    ],
    "transform": [
      { "type": "filter_workloads", "attributes": { "workloads": [<workload-id>] } },
      { "type": "render_template", "attributes": { "template": 2 } }
    ],
    "outputs": [
      {
        "type": "datadog",
        "attributes": {
          "url": "https://http-intake.logs.datadoghq.com/v1/input",
          "api_key": "[API KEY]"
        }
      }
    ]
  }'
```

No corpo, `workloads` é o nome na API da fonte de dados *Applications*, e o template `2` é *Applications Event Collector*. Uma resposta `201` retorna o stream como a Azion o armazenou:

```json
{
  "state": "executed",
  "data": {
    "id": 19562,
    "name": "logs-to-datadog",
    "last_editor": "user@example.com",
    "created": "2026-10-02T19:55:37.913926Z",
    "last_modified": "2026-10-02T19:55:37.913908Z",
    "product_version": "1.0",
    …
    "outputs": [
      {
        "type": "datadog",
        "attributes": {
          "url": "https://http-intake.logs.datadoghq.com/v1/input",
          "api_key": "[API KEY]"
        }
      }
    ]
  }
}
```

O `id` identifica o stream em todas as requisições seguintes, como `/v4/workspace/stream/streams/19562`. Para ver todas as chaves do corpo, consulte [Configurações do stream](/pt-br/documentacao/plataforma/data-stream/configuracoes-do-stream/#objeto-do-stream).

</Fragment>

</Tabs>

Nem o Console nem a API contatam o Datadog quando você salva. Uma URL digitada errada ou uma API key inválida só aparece como um envio com falha. O stream começa a enviar de um a dois minutos depois de você ativá-lo.

## Confirme a entrega

Cada tentativa do stream de enviar um lote, com sucesso ou não, aparece no [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/#data-stream) com o status code que o Datadog retornou. Envie algumas requisições ao workload e espere cerca de um minuto. O stream envia um lote a cada 60 segundos, ou antes, quando o lote chega a 2.000 linhas de log.

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para encontrar os envios no Azion Console:

<DocSteps>
  <DocStep title="Abra o Real-Time Events">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione a fonte de dados Data Stream" />
  <DocStep title="Leia os envios mais recentes">

  Cada linha é um envio. Encontre as linhas com `DATADOG` em **Endpoint Type** e leia o **Status Code** delas.

  </DocStep>
</DocSteps>

Um **Status Code** `200` significa que o Datadog aceitou o lote. **Streamed Lines** mostra o número de linhas de log do lote.

</Fragment>

<Fragment slot="panel.api">

Para ler os envios com a API, consulte o dataset `dataStreamedEvents` da API GraphQL do Real-Time Events. Substitua as datas por um intervalo que cubra a ativação do stream:

```bash
curl -X POST 'https://api.azion.com/v4/events/graphql' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Token [TOKEN VALUE]' \
  -d '{"query":"query { dataStreamedEvents(limit: 20, filter: {tsRange: {begin: \"2026-10-02T19:45:00\", end: \"2026-10-02T20:30:00\"}}, orderBy: [ts_DESC]) { ts endpointType statusCode streamedLines dataStreamed } }"}'
```

A API responde `200` com um registro para cada envio, do mais recente para o mais antigo. Este registro vem de um stream que envia para o S3:

```json
{
  "data": {
    "dataStreamedEvents": [
      {
        "ts": "2026-10-02T19:47:04Z",
        "endpointType": "S3",
        "statusCode": 200,
        "streamedLines": 2,
        "dataStreamed": 2797
      }
    ]
  }
}
```

Um envio para o Datadog traz `DATADOG` em `endpointType`. Um `statusCode` `200` significa que o Datadog aceitou o lote, e `streamedLines` e `dataStreamed` dão o tamanho dele em linhas de log e em bytes. Uma lista `dataStreamedEvents` vazia significa que o stream não enviou nada no intervalo. Para ver todos os campos, consulte [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/#datastreamedevents-data-stream).

</Fragment>

</Tabs>

Qualquer status diferente de `200` é a resposta do Datadog, exceto `503`, que significa que Data Stream encontrou o endpoint indisponível. Para ver as causas, consulte [Solucionar problemas de Data Stream](/pt-br/documentacao/plataforma/data-stream/solucao-de-problemas/).
