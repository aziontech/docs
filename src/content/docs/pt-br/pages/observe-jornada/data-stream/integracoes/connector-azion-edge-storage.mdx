Você pode gravar os dados que um stream produz em um bucket do [Object Storage](/pt-br/documentacao/store/object-storage/), apontando um connector do [Data Stream](/pt-br/documentacao/guias/plataforma/observabilidade/como-usar-data-stream/) para o endpoint S3 do bucket. Com o stream ativo, a Azion grava um objeto no bucket a cada lote de registros que envia.

Este guia cobre apenas o connector. Para o stream em si, sua fonte de dados e seus filtros, consulte [Como usar o Data Stream](/pt-br/documentacao/guias/plataforma/observabilidade/como-usar-data-stream/).

---

## Pré-requisitos

- Um bucket do Object Storage para receber os dados. Para criar um, consulte [Criar um bucket](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/dados/criar-e-modificar-um-bucket/).
- Uma credencial S3 cujas capabilities incluam **List Files** e **Write Files**. O Data Stream lista o bucket e grava objetos nele, e uma credencial sem as duas é recusada ao salvar. Para criar uma, consulte [Use ferramentas compatíveis com S3 com o Object Storage](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/dados/protocolo-s3-para-object-storage/).
- O access key e o secret key da credencial. O secret key é exibido apenas no momento em que a credencial é criada.
- Permissão para editar streams na sua conta. Para mais informações, consulte [Teams Permissions](/pt-br/documentacao/fundamentos/teams-permissions/).

---

## Configure o connector

O connector precisa do endereço S3 do bucket, da região e do par de chaves da credencial.

<DocSteps>
  <DocStep title="Abra o stream">

  Acesse [Azion Console](https://console.azion.com/) > **Data Stream**, e abra o stream que você quer alterar ou crie um novo.

  </DocStep>
  <DocStep title="Selecione o tipo de connector">

  No menu **Connector**, selecione **Simple Storage Service (S3)**.

  </DocStep>
  <DocStep title="Informe o endpoint e o bucket">

  Em **URL**, informe o host S3 do Object Storage, `s3.us-east-005.azionstorage.net`. Em **Bucket Name**, informe o nome do seu bucket. Em **Region**, informe `us-east-005`.

  </DocStep>
  <DocStep title="Informe a credencial">

  Em **Access Key** e **Secret Key**, informe o par de chaves da credencial S3. Os dois campos ficam mascarados depois de salvos, e apenas um usuário com a permissão `Edit Data Stream` pode revelá-los.

  </DocStep>
  <DocStep title="Defina o prefixo da chave do objeto">

  Em **Object Key Prefix**, informe o caminho sob o qual os objetos são gravados, como `user/logs`. O campo é opcional; deixá-lo vazio grava na raiz do bucket.

  </DocStep>
  <DocStep title="Defina o content type">

  Em **Content Type**, selecione o formato dos objetos que a Azion grava. O campo aceita `plain/text` ou `application/gzip`.

  </DocStep>
  <DocStep title="Ative o connector">

  Ligue o switch **Active**.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O stream passa a gravar no bucket. A Azion monta a chave de cada objeto a partir do prefixo, da data e da hora em que o lote foi enviado no formato `YYYY/MM/DD/hh/mm/` e de um UUID, como em `user/logs/2026/09/17/22/45/37d66e78-c308-4006-9d4d-1c013ed89276`.

## Confirme que os dados estão chegando

Dois lugares mostram se o connector está funcionando.

<DocSteps>
  <DocStep title="Liste os objetos do bucket">

  Substitua `[TOKEN VALUE]` pelo seu [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) e o nome do bucket pelo seu:

  ```bash
  curl --request GET \
    --url 'https://api.azion.com/v4/workspace/storage/buckets/my-bucket/objects?prefix=user/logs/' \
    --header 'Accept: application/json' \
    --header 'Authorization: Token [TOKEN VALUE]'
  ```

  A resposta lista uma entrada por objeto gravado, cada uma com sua chave, seu tamanho em bytes e quando foi modificada pela última vez:

  ```json
  {
    "continuation_token": null,
    "results": [
      {
        "key": "user/logs/2026/09/17/22/45/37d66e78-c308-4006-9d4d-1c013ed89276",
        "last_modified": "2026-09-17T22:45:17.394000Z",
        "size": 4821,
        "is_folder": false
      }
    ]
  }
  ```

  </DocStep>
  <DocStep title="Leia as tentativas de entrega">

  Acesse [Azion Console](https://console.azion.com/) > **Real-Time Events**, selecione **Data Source** > **Data Stream** e filtre conforme precisar. Cada linha registra uma tentativa de entrega do Data Stream para o bucket, inclusive as que falharam.

  </DocStep>
</DocSteps>

Um objeto sob o prefixo e uma entrega bem-sucedida no Real-Time Events confirmam juntos o connector.
