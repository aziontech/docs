Você pode ler um registro de evento do [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) pelo Azion Console. O que o registro responde depende das variáveis que você lê. Cada fonte de dados carrega seu próprio conjunto de variáveis pré-organizadas. Elas informam sobre o acesso, o comportamento e a performance das suas aplicações e dos produtos relacionados.

Para cada variável que uma fonte de dados carrega, com a descrição dela e um exemplo, consulte [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/).

Duas buscas levam a esse registro. Execute uma [busca geral](#executar-uma-busca-geral) para retornar todos os registros que uma fonte de dados escreveu no período. Execute uma [busca filtrada](#executar-uma-busca-filtrada) para retornar apenas os registros que correspondem aos valores que você nomeia.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Um produto que já escreveu registros na fonte de dados que você quer buscar.

---

## Executar uma busca geral

Uma busca geral retorna todos os registros que uma fonte de dados escreveu no período, com todas as variáveis que ela carrega. Execute uma quando você quer o máximo de informação possível, ou quando ainda não sabe o que investigar.

Para executar uma busca geral no Azion Console:

<DocSteps>
  <DocStep title="Abra Real-Time Events">

  Acesse [Azion Console](https://console.azion.com) > **Products menu** > **Observe** > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione a fonte de dados">

  Em **Data Sources**, selecione o produto cujos registros você quer ler.

  </DocStep>
  <DocStep title="Defina o período">

  Em **Time Filter**, selecione o período que a busca cobre.

  </DocStep>
  <DocStep title="Deixe Filter by em branco" />
  <DocStep title="Selecione Refresh" />
</DocSteps>

A tabela de resultados carrega todos os registros que essa fonte de dados escreveu no período.

Considere uma aplicação que não exibe o que você configurou em uma [function](/pt-br/documentacao/plataforma/functions/). Selecione a fonte de dados **Functions** e leia todas as variáveis dos registros que ela retorna. Elas mostram se a function correta foi executada, e qual mensagem ela retornou.

## Executar uma busca filtrada

Uma busca filtrada retorna apenas os registros que correspondem às variáveis e aos valores que você nomeia. Execute uma quando você já sabe o que vai analisar.

Para executar uma busca filtrada no Azion Console:

<DocSteps>
  <DocStep title="Abra Real-Time Events">

  Acesse [Azion Console](https://console.azion.com) > **Products menu** > **Observe** > **Real-Time Events**.

  </DocStep>
  <DocStep title="Selecione a fonte de dados">

  Em **Data Sources**, selecione o produto cujos registros você quer ler.

  </DocStep>
  <DocStep title="Defina o período">

  Em **Time Filter**, selecione o período que a busca cobre.

  </DocStep>
  <DocStep title="Informe o filtro">

  Em **Filter by**, informe uma condição por variável que você quer corresponder.

  </DocStep>
  <DocStep title="Selecione Refresh" />
</DocSteps>

A tabela de resultados carrega apenas os registros que correspondem ao filtro.

Considere a suspeita de que usuários maliciosos estão tentando alcançar sua aplicação. Selecione a fonte de dados **HTTP Requests** e filtre pelas variáveis que identificam o cliente. `Host`, `HTTP Referer`, `Remote Address` e `Request Uri` reduzem o resultado, cada uma, a uma propriedade diferente da requisição.

Para a sintaxe completa do **Filter by**, com um exemplo por variável, consulte [Filtrar eventos](/pt-br/documentacao/guias/plataforma/observabilidade/adicionar-filtros-events/).

## Buscar por request ID

Um request ID alcança o registro de uma requisição e de nenhuma outra. O campo `requestId` guarda um identificador único para cada requisição, como `5f222ae5938482c32a822dbf15e19f0f`.

Um valor que você retira de um cabeçalho de resposta HTTP, como `X-Request-Id`, pode carregar um sufixo numérico depois de um hífen. Por exemplo: `5f222ae5938482c32a822dbf15e19f0f-1234`. A camada de rede adiciona esse sufixo, e o registro de evento não o guarda.

Busque no Real-Time Events, ou na [API GraphQL](/pt-br/documentacao/devtools/graphql/visao-geral/), apenas com o identificador base. Uma busca que inclui o sufixo pode não retornar resultado nenhum, ou retornar um erro `400`.

Onde o cabeçalho retorna `5f222ae5938482c32a822dbf15e19f0f-1234`, filtre por `5f222ae5938482c32a822dbf15e19f0f`.

---

## Abrir um registro

Uma linha da tabela de resultados mostra algumas variáveis do registro por trás dela. Abrir o registro mostra as demais.

Para abrir um registro no Azion Console, selecione a linha dele na tabela de resultados.

A visualização **More details** abre. Ela carrega todas as variáveis daquela fonte de dados para o registro que você selecionou.

Para o significado de cada uma dessas variáveis, consulte [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/).
