Você pode ler os dados de observabilidade das suas aplicações na Azion a partir de um dashboard do Grafana, com o data source plugin da Azion. O plugin consulta [Real-Time Metrics](/pt-br/documentacao/plataforma/real-time-metrics/) e [Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) pela [API GraphQL](/pt-br/documentacao/devtools/graphql/visao-geral/). Grafana renderiza o que uma consulta retorna como gráficos e tabelas.

O plugin não é publicado pelo catálogo de plugins do Grafana. Você o instala a partir do código-fonte em uma instância do Grafana que roda localmente. Um personal token da Azion autoriza as consultas que o plugin envia.

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Como criar uma conta na Azion](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- Um personal token. Para criar um, consulte [Personal Tokens](/pt-br/documentacao/fundamentos/personal-tokens/).
- Uma ou mais [aplicações](/pt-br/documentacao/plataforma/applications/) na sua conta, para que os datasets carreguem registros para consultar.
- Uma instância do [Grafana](https://grafana.com/) que roda localmente e que você administra.

---

## Instalar o plugin em uma instância local do Grafana

O plugin funciona apenas com uma instância local do Grafana. Ele não é assinado, portanto essa instância precisa aceitar plugins não assinados antes de carregar o data source.

Azion mantém o plugin como um projeto open source, e o procedimento de instalação acompanha o código-fonte. Para os passos de instalação, consulte o [repositório do plugin do Grafana da Azion](https://github.com/aziontech/grafana-plugin).

O plugin se autentica com seu personal token. Informe o token quando você configurar o data source da Azion no Grafana. Grafana pode então consultar Real-Time Metrics e Real-Time Events a partir de um painel de dashboard.
