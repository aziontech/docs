Você controla o que um painel do Grafana renderiza definindo os campos que o data source plugin da Azion adiciona ao editor de consultas do painel. Toda regra desta página se aplica a esse editor, que guarda a consulta em si e os campos que dizem ao Grafana como ler a resposta.

Um painel configurado como _Time series_ exige dois desses campos: **Time path** e **Group by**.

---

## Pré-requisitos

- Grafana com o data source plugin da Azion. Para instalar e autorizar o plugin, consulte [Instale o plugin da Azion para Grafana](/pt-br/documentacao/guias/plataforma/observabilidade/integrar-grafana/).
- Um painel de dashboard que lê o data source da Azion. Para criar um, consulte [Personalizar uma tabela de logs no Grafana](/pt-br/documentacao/guias/plataforma/observabilidade/azion-plugin-grafana-personalizar-tabela-logs/).

---

## Escreva a consulta

O campo de consulta guarda a consulta que o painel envia. Ele nomeia o dataset que o painel lê e os filtros que o reduzem, e [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/) lista todos os datasets que o plugin pode consultar. Quando a consulta usa uma variável do Grafana, substitua a variável diretamente no campo da consulta.

---

## Referencie um campo aninhado pelo nome achatado

Objetos aninhados são achatados com underscores. Escreva o nome achatado sempre que o editor pedir um nome de campo, incluindo **Time path**, **Group by** e **Alias by**.

---

## Defina o time path

**Time path** recebe um timestamp. O timestamp está no formato `ISO8601` ou em um formato personalizável.

---

## Agrupe os dados em pontos de dados

**Group by** é o que transforma um resultado em múltiplos pontos de dados. Defina-o com o campo sobre o qual a agregação é executada.

---

## Renomeie um campo na legenda

**Alias by** define o nome que um campo carrega na legenda do painel. Substitua `$field_<field.name>` pelos valores do campo. Substitua `$fieldName` por um nome para o campo.

---

## Anote o gráfico

Grafana carrega anotações como uma funcionalidade de dashboard, portanto nenhum campo do editor de consultas define uma. Use [anotações](https://grafana.com/docs/grafana/latest/dashboards/build-dashboards/annotate-visualizations/) para marcar pontos em um gráfico.

---

## Defina o intervalo de tempo do dashboard

O dashboard carrega seu próprio [intervalo de tempo](https://grafana.com/docs/grafana/latest/dashboards/use-dashboards/#time-units-and-relative-ranges). Use-o para explorar e analisar seus dados.
