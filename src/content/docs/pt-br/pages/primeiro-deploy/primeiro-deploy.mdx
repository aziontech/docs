## Antes de começar

Tudo o que você precisa é de uma conta Azion. Você pode criar uma gratuitamente, e ela não pede cartão de crédito. O que for específico de um caminho está listado no próprio caminho.

## Faça o deploy de um template pelo Console

Templates são projetos prontos (e-commerce, blogs, APIs, SSR full-stack) que entram no ar em poucos cliques. Você não precisa de nenhuma ferramenta local.

<DocCallout kind="note">Alguns templates são integrados a serviços de terceiros, então você pode precisar criar contas, gerar tokens ou ativar produtos Azion antes do deploy. Templates integrados ao GitHub pedem para conectar sua conta: clique em Connect with GitHub quando solicitado e confirme a conexão no pop-up. O guia de cada template lista seus pré-requisitos específicos.</DocCallout>

<DocSteps>
  <DocStep title="Acesse o Azion Console." />
  <DocStep title="Clique em + Create na página inicial." />
  <DocStep title="No modal, selecione Templates." />
  <DocStep title="Navegue e escolha aquele com que você quer começar." />
  <DocStep title="Preencha a página de configuração." />
  <DocStep title="Clique em Deploy, no canto inferior direito." />
</DocSteps>

Acompanhe o deploy pela janela de logs. Quando terminar, a página mostra o nome da sua aplicação, os logs do deploy e o domínio Azion dela. Alguns templates também criam uma função e aplicam configurações predefinidas para otimizar o desempenho da aplicação. O guia do template lista o que está incluído.

### Teste

Copie o domínio Azion da página de confirmação:

```bash
curl -I https://<your-azion-domain>
# HTTP/2 200
```

Abra a mesma URL no navegador para ver sua aplicação rodando.

<DocCallout kind="note">URLs novas podem levar alguns minutos para se propagar até as edge locations da Azion. Se você receber um erro logo após o deploy, aguarde um momento e tente de novo.</DocCallout>

## Importe um projeto do GitHub

<DocCallout kind="info">Você precisa de uma conta no GitHub e de um repositório que use um dos frameworks suportados.</DocCallout>

<DocSteps>
  <DocStep title="No Azion Console, clique em + Create." />
  <DocStep title="Selecione Import from Git." />
  <DocStep title="Conecte a conta Git que possui o repositório." />
  <DocStep title="Escolha o repositório a importar." />
  <DocStep title="Dê um nome à aplicação e confira os comandos de build e deploy.">

  A Azion lê os comandos do repositório, então ambos chegam preenchidos para um projeto que ela reconhece — altere-os apenas se o seu build for diferente. O nome vira parte da URL publicada.

  </DocStep>
  <DocStep title="Deixe Protect with Azion Firewall desligado, ou ligue para publicar um firewall junto com a aplicação." />
  <DocStep title="Clique em Create and deploy e acompanhe os logs até o domínio Azion aparecer." />
</DocSteps>

## Faça o deploy com a Azion CLI

<DocCallout kind="info">Você precisa da Azion CLI (instalada abaixo) e de um projeto local que use um dos frameworks suportados, com as dependências instaladas.</DocCallout>

<DocCallout kind="tip">Começando do zero? Execute `azion init` para criar um novo projeto a partir de um template de framework e faça o deploy do mesmo jeito. Veja a [visão geral da CLI](/pt-br/documentacao/devtools/cli/) e a [referência do comando link](/pt-br/documentacao/devtools/cli/link-comando/) para detalhes.</DocCallout>

<DocPrompt client:visible kind="line" title="Assistente de IA">Instale a Azion CLI, vincule este projeto à minha conta Azion usando o preset que corresponde ao framework dele, faça o deploy e imprima o domínio Azion assim que ele responder 200.</DocPrompt>

<DocSteps>
  <DocStep title="Instale a Azion CLI">

  ```bash
  curl -fsSL https://cli.azion.app/install.sh | bash
  ```

  </DocStep>
  <DocStep title="Vincule e faça o deploy">

  Autentique-se:

  ```bash
  azion login
  ```

  Na pasta raiz do projeto, vincule-o à Azion:

  ```bash
  azion link
  ```

  A CLI conduz você a partir daí: confirme o vínculo, aceite ou altere o nome sugerido para a aplicação e escolha um preset compatível com seu framework. Quando ela perguntar `Do you want to deploy your project?`, responda sim. (Se responder não, execute `azion deploy` quando estiver pronto.)

  Ao final do deploy, a CLI imprime o domínio Azion da sua aplicação.

  </DocStep>
  <DocStep title="Teste">

  ```bash
  curl -I https://<your-azion-domain>
  # HTTP/2 200
  ```

  Se você receber um erro de imediato, aguarde alguns minutos: URLs novas levam um momento para se propagar até as edge locations da Azion.

  </DocStep>
</DocSteps>

## O que você construiu

Você publicou uma aplicação na rede global da Azion e confirmou que ela responde no próprio domínio. O fluxo é o mesmo que você vai usar em projetos de produção.
