**Integration Services** é a forma mais rápida e segura para migrar seus conteúdos, aplicações web e APIs para a Azion, não importando a complexidade e o volume de recursos que você utiliza. O time irá prover as documentações necessárias para seu sucesso utilizando a plataforma da Azion.

| Suporte  | Horas        | Horas adicionais disponíveis |
| ----------------- | ------------ | ---------------------------- |
| Business          | 5 horas/ano  | Sim                          |
| Enterprise        | 20 horas/ano | Sim                          |
| Mission Critical  | 60 horas/ano | Sim                          |

Para obter informações mais detalhadas, consulte as opções de [Serviços de Suporte](https://www.azion.com/pt-br/servicos-profissionais/).

Um especialista da Azion estará disponível para apoiar o cliente em todo o processo através de:

1. Ativação dos serviços Azion contratados pelo cliente conforme descritos na *Ordem de Serviço*.
2. Levantamento de requisitos técnicos e de negócios junto ao cliente.
3. Treinamento de uso do Azion Console.
4. Configuração dos serviços da Azion para o cliente.
5. Revisão e otimização de configurações dos serviços Azion de acordo com as demandas do cliente durante o lançamento.

O especialista da Azion irá seguir um processo de integração composto pelas seguintes etapas:


| Estágio | Responsabilidades do Cliente | Responsabilidades da Azion |
| ------- | ---------------------------- | -------------------------- |
| Alocação de recursos para o projeto, levantamento de requisitos, treinamento, ferramentas e revisão de documentações. | • Designar os recursos necessários para colaborar com o time de Integration Services.<br />• Revisar documentações técnicas e guias de implementação.<br />• Apoiar internamente no levantamento de requisitos técnicos e de negócio guiado pela Azion, respondendo as perguntas realizadas e fornecendo informações. | • Designar um especialista de Integrations.<br />• Agendar o início do projeto com o Customer Success Manager responsável para a coleta de requisitos.<br />• Realizar uma análise detalhada de necessidades apresentadas pelo cliente, entendendo requisitos técnicos e de negócios a partir das descrições apresentadas pelo cliente ou pela análise do conteúdo ou aplicação. |
| Planejamento do projeto | • Confirmar agenda do projeto, plano de implementação e plano de testes.<br />• Criar plano e teste funcional e condições para teste de aceitação. | • Identificar e projetar as soluções adequadas para cada requisito técnico ou de negócio do cliente.<br />• Planejar cronograma de implementação e testes.<br />• Validar plano de teste funcional e condições para teste de aceitação do cliente. |
| Implementação | • Preparar a infraestrutura de origem para entregar o conteúdo através da plataforma da Azion. | • Realizar a configuração no Azion Console para o cliente.<br />• Disponibilizar as configurações necessárias para os testes por parte do cliente.<br />• Validar as configurações de origem executadas pelo cliente para integração com a Azion. |
| Testes | • Testar o conteúdo e aplicação no ambiente disponibilizado pela Azion para garantir o funcionamento.<br />• Obter aceite dos stakeholders para o funcionamento da plataforma, conforme esperado. | • Testar o conteúdo e aplicação para os requisitos levantados durante a fase inicial do projeto.<br />• Testar o desempenho de entrega e a conquista dos objetivos propostos. |
| Onboarding | • Executar a implementação do conteúdo ou aplicação para a plataforma da Azion.<br />• Testar o ambiente de produção, acompanhar gráficos e logs de acesso.<br />• Solicitar rollback em caso de problemas. | • Observar o comportamento do ambiente de produção para identificar eventuais anomalias.<br />• Assistir o cliente no que for necessário durante a virada de produção.<br />• Acompanhar o processo e os testes do cliente. |
| Conclusão | • Validar o sucesso dos objetivos do projeto.<br />• Comunicar os procedimentos de suporte para o time responsável pela manutenção do conteúdo e da aplicação. | • Agendar reunião de review.<br />• Conduzir, junto ao cliente, revisão e validação do sucesso do projeto.<br />• Analisar as necessidades que não foram levantadas durante o planejamento e fazer ajustes.<br />• Revisar procedimentos de suporte para incidentes e problemas em produção.<br />• Encerrar projeto. |

:::note[nota]
Todo o processo de integração é conduzido remotamente, por *telefone* ou *videoconferência*.
:::
