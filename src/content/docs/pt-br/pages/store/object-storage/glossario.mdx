O vocabulário da documentação do [Object Storage](/pt-br/documentacao/store/object-storage/), uma linha por termo, cada uma com link para a página que o define.

| Termo | Definição |
| --- | --- |
| access key | A metade pública de uma [credencial S3](/pt-br/documentacao/store/object-storage/compatibilidade-s3/), enviada com toda requisição assinada para o protocolo S3. Identifica a credencial e pode ser lida novamente depois da criação, ao contrário do secret key. |
| `azion:storage` | O módulo do [Azion Runtime](/pt-br/documentacao/devtools/runtime/api-reference/storage/) que uma function importa para ler e gravar objetos sem sair da requisição. Expõe `put`, `get`, `delete` e `list` em um bucket que a function nomeia. |
| bucket | O contêiner em que o Object Storage guarda objetos. Buckets não são aninhados, um nome é único entre todas as contas Azion e o nome não pode ser alterado depois da criação. [Buckets e objetos](/pt-br/documentacao/store/object-storage/buckets-e-objetos/) documenta cada campo e as regras que um nome segue. |
| capability | Uma permissão em uma [credencial S3](/pt-br/documentacao/store/object-storage/compatibilidade-s3/), que nomeia um grupo de operações S3 que ela pode executar. As seis são `listFiles`, `readFiles`, `writeFiles`, `deleteFiles`, `listAllBucketNames` e `listBuckets`, e uma capability fora desse conjunto é rejeitada. |
| chave do objeto | A string que identifica um objeto dentro de um bucket, entre 1 e 1.024 caracteres. Uma chave pode conter a barra, que as interfaces leem como um [prefixo](/pt-br/documentacao/store/object-storage/buckets-e-objetos/), e uma chave não pode ser renomeada. |
| classe de operação | O grupo de cobrança em que uma requisição se enquadra. A Classe A abrange operações de controle e de listagem, a Classe B abrange leituras de objeto e a Classe C abrange gravações e o gerenciamento de upload, e está incluída em todos os planos. [Limites do Object Storage](/pt-br/documentacao/store/object-storage/limites/) lista as operações de cada classe e a quantidade que cada plano inclui. |
| Connector | O recurso da plataforma que aponta uma aplicação para um bucket, de modo que as requisições a um domínio são respondidas a partir dos objetos nele. Um connector do tipo Object Storage nomeia o bucket e, opcionalmente, um prefixo dentro dele. Para mais informações, consulte [Connectors](/pt-br/documentacao/plataforma/connectors/). |
| credencial S3 | O par de access key e secret key que autentica uma requisição ao endpoint do protocolo S3, limitado pelas suas capabilities e, opcionalmente, por uma lista de buckets. Uma credencial funciona independentemente do personal token que a criou, então continua funcionando depois que esse token expira. [Compatibilidade com S3](/pt-br/documentacao/store/object-storage/compatibilidade-s3/) documenta os campos. |
| Object Storage | O produto da Azion que armazena dados não estruturados como objetos em buckets, alcançáveis pelo Azion Console, pela API da Azion, pela Azion CLI, pelo Azion Runtime, pela biblioteca `azion` e pelo protocolo S3. É um produto Store, ao lado do [KV Store](/pt-br/documentacao/store/kv-store/) e do [SQL Database](/pt-br/documentacao/store/sql-database/). |
| objeto | Um arquivo armazenado em um bucket, junto com a chave sob a qual é guardado e o content type com que é servido. Um objeto é substituído por inteiro: um upload para uma chave em uso sobrescreve o conteúdo, e a versão anterior não pode ser recuperada. |
| período de carência | As 24 horas em que um objeto excluído é retido antes de ser removido em definitivo. O objeto deixa de ser listado e deixa de ser servido imediatamente, e o bucket não pode ser excluído até o período terminar. [Buckets e objetos](/pt-br/documentacao/store/object-storage/buckets-e-objetos/) documenta as operações de exclusão a que ele se aplica. |
| prefixo | Um segmento inicial compartilhado por um grupo de chaves de objeto, que as interfaces apresentam como um agrupamento. Um prefixo não é uma pasta e não é criado com antecedência: um upload para `src/assets/logo.svg` cria o objeto e os seus prefixos em uma única requisição. Um [Connector](/pt-br/documentacao/plataforma/connectors/) pode servir um prefixo como a raiz do caminho de uma aplicação. |
| secret key | A metade privada de uma [credencial S3](/pt-br/documentacao/store/object-storage/compatibilidade-s3/), usada para assinar uma requisição ao protocolo S3. É retornada apenas pela requisição que cria a credencial e não pode ser lida nem alterada depois. Um secret key perdido é substituído pela criação de outra credencial. |
| `Storage-Content-Type` | Um cabeçalho que a API da Azion aceita em um upload e sobre o qual não age. O content type armazenado com um objeto vem de `Content-Type`, e a Azion detecta o tipo quando a requisição não envia `Content-Type`. [Buckets e objetos](/pt-br/documentacao/store/object-storage/buckets-e-objetos/) documenta o comportamento. |
| workloads access | O campo do bucket que decide o que a plataforma da Azion pode fazer com os objetos nele, definido como `read_only`, `read_write` ou `restricted`. Não restringe a API da Azion nem o protocolo S3, que são governados pelo token ou pela credencial que a requisição carrega. [Buckets e objetos](/pt-br/documentacao/store/object-storage/buckets-e-objetos/) documenta cada valor. |
