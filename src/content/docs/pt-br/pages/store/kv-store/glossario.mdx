Os termos que a documentação do [KV Store](/pt-br/documentacao/store/kv-store/) usa de forma própria, cada um definido uma vez e com link para a página que o apresenta por completo.

| Termo | Definição |
| --- | --- |
| `Azion.KV` | O global do runtime que alcança o KV Store de dentro de uma [function](/pt-br/documentacao/build/functions/). Seu construtor é privado, então o único caminho até um cliente é `Azion.KV.open`, que é aguardado com `await`, e não há linha de import para escrever. [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) documenta todos os métodos que ele carrega. |
| `Azion.KV.open` | O método estático que abre um namespace pelo nome e retorna o cliente correspondente. É assíncrono e é o único ponto de entrada para os dados. [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) traz sua assinatura. |
| `cacheTtl` | A opção que um `get` ou `getWithMetadata` de chave única aceita para definir por quantos segundos o resultado permanece em cache onde a function que o leu foi executada. [Boas práticas](/pt-br/documentacao/store/kv-store/boas-praticas/) indicam quando aumentá-la ajuda e quando ela sai caro. |
| cold read | Uma leitura cujo resultado ainda não está em cache onde a function é executada, então KV Store busca o valor antes de responder. Uma hot read é a que o cache responde. A leitura de uma chave que não existe fica em cache da mesma forma, então `cacheTtl` também a governa. |
| default namespace | Não existe: todo cliente nomeia o namespace que abre, e [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) mostra a única forma que abre um. |
| eventual consistency | O modelo de consistência que KV Store aplica. Uma gravação é legível onde foi feita antes de ser legível em todos os outros lugares, e gravações concorrentes em uma mesma chave resolvem para a última gravação. [Como KV Store funciona](/pt-br/documentacao/store/kv-store/como-funciona/) descreve o que uma leitura pode retornar nesse intervalo. |
| `expiration` | A opção de `put` que expira uma chave em um timestamp Unix dado em segundos. `expirationTtl` expressa a mesma expiração como uma contagem de segundos. [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) documenta as duas. |
| `expirationTtl` | A opção de `put` que expira uma chave depois de um número de segundos, contados em vez de dados como um ponto no tempo. `expiration` é a mesma expiração dada como um timestamp. [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) documenta as duas. |
| keys read | O medidor de cobrança que conta toda chave lida do KV Store. É um de três, com keys written e storage, e [Limites do KV Store](/pt-br/documentacao/store/kv-store/limites/) traz a quantidade incluída. |
| keys written | O medidor de cobrança que conta toda chave que uma gravação afeta, incluindo um `put` e um `delete`. [Limites do KV Store](/pt-br/documentacao/store/kv-store/limites/) traz a quantidade incluída. |
| metadata | Um valor serializável armazenado ao lado do valor de uma chave e definido pela opção de `put` de mesmo nome. `getWithMetadata` o retorna junto do valor, e ele é `null` quando a chave não carrega nenhum. [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) documenta as duas chamadas. |
| multi-key get | Um `get` ou `getWithMetadata` que recebe um array de chaves em vez de uma. Retorna um objeto simples, aceita apenas os tipos de retorno `text` e `json`, e chaves duplicadas no array são removidas. [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) documenta o formato e o que uma chave ausente retorna. |
| namespace | Um espaço de chaves isolado, endereçado pelo nome com que foi criado, que também é seu identificador. Um namespace é permanente: não pode ser renomeado, desativado, esvaziado nem excluído em nenhuma interface. [Namespaces](/pt-br/documentacao/store/kv-store/namespaces/) documenta seus campos e a API que o cria. |
| Preview | O estágio de lançamento em que KV Store é disponibilizado. O acesso ao Preview é concedido mediante solicitação e sujeito a aprovação, então uma conta não o possui até que o [suporte técnico](/pt-br/documentacao/suporte/) o habilite. |
| `returnType` | O segundo argumento de `get` e `getWithMetadata`, que decide a forma em que o valor volta. Seu padrão é `text`, e [Cliente KV](/pt-br/documentacao/store/kv-store/cliente-kv/) lista todos os valores que ele aceita. |
| storage | O medidor de cobrança dos dados que seus namespaces guardam. É um de três, com keys read e keys written, e [Limites do KV Store](/pt-br/documentacao/store/kv-store/limites/) traz a quantidade incluída. |
