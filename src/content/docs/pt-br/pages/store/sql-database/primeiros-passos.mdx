Este guia orienta você a armazenar e ler a sua primeira linha no [SQL Database](/pt-br/documentacao/store/sql-database/), pelo Azion Console. No fim, você vai ter:

- O seu primeiro banco de dados, com o status `created`.
- Uma tabela `users` dentro dele.
- Uma linha armazenada nessa tabela.
- A mesma linha retornada por uma instrução `SELECT`.

Prefere a API? Consulte [Primeiros passos com SQL Database usando a API](/pt-br/documentacao/store/sql-database/primeiros-passos-api/).

O resultado se apoia em dois objetos. O **banco de dados** é o container, e o seu nome não pode ser alterado depois da criação. Cada **tabela** fica dentro de um banco de dados, e este guia cria a tabela com uma instrução `CREATE TABLE` na aba **Editor**. Um banco de dados é provisionado de forma assíncrona. O seu status marca `creating` primeiro, e uma instrução só é executada contra ele depois que o status marca `created`.

---

## Pré-requisitos

- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- SQL Database habilitado na conta. O produto está em Preview, e o acesso é solicitado ao time de suporte técnico. Para solicitá-lo, consulte [Technical Support](/pt-br/documentacao/suporte/).
- A permissão **Edit SQL Database** na conta. Ela concede permissão para criar e editar bancos de dados e os seus dados pela API da Azion. Para mais informações, consulte [Teams Permissions](/pt-br/documentacao/fundamentos/teams-permissions/).

## 1. Crie um banco de dados

Um banco de dados guarda as tabelas que você cria. Para criar o seu primeiro:

<DocSteps>
  <DocStep title="Abra a lista de bancos de dados">

  Acesse [Azion Console](https://console.azion.com/) > **SQL Database**.

  </DocStep>
  <DocStep title="Abra o formulário de criação">

  Inicie um novo banco de dados a partir da lista, com o controle **SQL Database**.

  </DocStep>
  <DocStep title="Nomeie o banco de dados">

  Em **General**, no campo **Name**, insira um nome de 6 a 50 caracteres, usando letras, números e o hífen. Um nome que outro banco de dados da conta já tem é recusado.

  </DocStep>
  <DocStep title="Selecione Save" />
</DocSteps>

O banco de dados aparece na lista, que mostra o seu **Name**, **Status**, **Last Editor** e **Last Modified**. O seu status marca `creating` até marcar `created`, o que leva cerca de 15 segundos.

---

## 2. Crie uma tabela

A aba **Editor** executa SQL contra um banco de dados. Para criar a tabela que este guia usa:

<DocSteps>
  <DocStep title="Abra o banco de dados">

  Na lista **SQL Database**, selecione o banco de dados que você criou.

  </DocStep>
  <DocStep title="Vá para a aba Editor" />
  <DocStep title="Insira a instrução CREATE TABLE">

  Crie a tabela `users` com três colunas:

  ```sql
  CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT, email TEXT);
  ```

  </DocStep>
  <DocStep title="Selecione Run query" />
</DocSteps>

A tabela aparece na aba **Tables**.

---

## 3. Insira uma linha

Uma instrução `INSERT` armazena uma linha na tabela. Para armazenar a primeira:

<DocSteps>
  <DocStep title="Insira a instrução INSERT">

  Na aba **Editor**, insira a seguinte instrução:

  ```sql
  INSERT INTO users (name, email) VALUES ('Ada', 'ada@example.com');
  ```

  </DocStep>
  <DocStep title="Selecione Run query" />
</DocSteps>

A tabela guarda uma linha.

---

## 4. Leia a linha de volta

Uma instrução `SELECT` retorna o que a tabela guarda. Para ler a linha que você inseriu:

<DocSteps>
  <DocStep title="Insira a instrução SELECT">

  Na aba **Editor**, insira a seguinte instrução:

  ```sql
  SELECT id, name, email FROM users;
  ```

  </DocStep>
  <DocStep title="Selecione Run query" />
</DocSteps>

O resultado traz uma linha sob as colunas `id`, `name` e `email`: `1`, `Ada` e `ada@example.com`.

O seu primeiro banco de dados guarda uma tabela `users` com uma linha, e o **Editor** a lê de volta. As mesmas instruções são executadas pela API da Azion e dentro de uma function.
