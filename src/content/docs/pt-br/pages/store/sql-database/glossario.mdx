Uma linha por termo da documentação do [SQL Database](/pt-br/documentacao/store/sql-database/), cada uma com link, na definição, para a página que documenta o termo.

| Termo | Definição |
| --- | --- |
| `azion/sql` | O export da [biblioteca `azion`](/pt-br/documentacao/devtools/azion-lib/sql/) que cria bancos de dados e executa consultas a partir de Node ou TypeScript. Carrega `createDatabase`, `getDatabase`, `getDatabases`, `deleteDatabase`, `useQuery`, `useExecute` e `getTables`. Seus campos são camelCase, e uma consulta por ele descarta `rows_read`, `rows_written` e `query_duration_ms`. |
| `azion:sql` | O módulo do [Azion Runtime](/pt-br/documentacao/devtools/runtime/api-reference/sql-database/) que uma function importa para executar SQL durante a requisição que ela atende. O import é `import { Database } from "azion:sql"`. |
| `AZION_TOKEN` | A variável de ambiente que guarda o [personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/) com que o [EdgeSQL Shell](/pt-br/documentacao/store/sql-database/edgesql-shell/) e a biblioteca `azion` se autenticam. Os dois leem o valor do ambiente, e não de um argumento. |
| banco de dados | O objeto que SQL Database cria, e a unidade contra a qual uma consulta é executada. Um nome tem de 6 a 50 caracteres, aceita letras, números e o hífen, e é único dentro da conta. Um banco de dados não pode ser renomeado depois da criação, e [Bancos de dados e consultas](/pt-br/documentacao/store/sql-database/bancos-de-dados-e-consultas/) documenta cada campo que ele carrega. |
| coluna de vetor | Uma coluna que guarda um vetor, como um [embedding](https://www.azion.com/en/learning/ai/what-are-embeddings-and-vectors/), declarada com um tipo que informa a quantidade de dimensões. Os tipos são `FLOAT1BIT`, `FLOAT8`, `FLOATB16`, `FLOAT16`, `FLOAT32` e `FLOAT64`, cada um com um alias de blob como `F32_BLOB(3)`. [Vector search](/pt-br/documentacao/store/sql-database/vector-search/) documenta os tipos e as funções que os leem. |
| EdgeSQL Shell | A ferramenta de linha de comando em Python que cria bancos de dados, executa SQL e importa dados a partir de um terminal. Seu prompt é `EdgeSQL>`, e ela é instalada a partir do código-fonte, e não de um índice de pacotes. [EdgeSQL Shell](/pt-br/documentacao/store/sql-database/edgesql-shell/) documenta cada comando, opção e variável de ambiente. |
| índice de vetor | O índice de vizinhos mais próximos aproximados que uma coluna recebe quando `CREATE INDEX` a envolve em `libsql_vector_idx`. É suportado em uma tabela com um `ROWID` ou uma `PRIMARY KEY` de coluna única, e adiciona uma shadow table chamada `<index>_shadow`. [Vector search](/pt-br/documentacao/store/sql-database/vector-search/) documenta o índice e o algoritmo DiskANN por trás dele. |
| instância principal | A instância de um banco de dados que recebe as escritas. A Azion a replica para as réplicas de leitura que respondem às leituras, como [Como o SQL Database funciona](/pt-br/documentacao/store/sql-database/como-funciona/) descreve. |
| instrução | Uma string SQL no array `statements` de uma requisição de consulta. Cada instrução retorna sua própria entrada em `data`, na ordem em que foi enviada. Uma instrução que falha carrega `error` no lugar de `results`, dentro de uma resposta HTTP `200`, como [Bancos de dados e consultas](/pt-br/documentacao/store/sql-database/bancos-de-dados-e-consultas/) documenta. |
| linhas escritas | A quantidade de linhas que uma instrução escreveu, retornada como `rows_written` ao lado do resultado dessa instrução. É o segundo valor medido, e [Limites do SQL Database](/pt-br/documentacao/store/sql-database/limites/) traz a quantidade diária que cada plano inclui. |
| linhas lidas | A quantidade de linhas que uma instrução leu, retornada como `rows_read` ao lado do resultado dessa instrução. A Azion a mede, e [Limites do SQL Database](/pt-br/documentacao/store/sql-database/limites/) traz a quantidade que cada plano inclui. |
| Preview | O estágio de lançamento que SQL Database carrega em todos os planos. Um produto em Preview não vem habilitado em uma conta por padrão, e o acesso é solicitado ao [time de suporte técnico](/pt-br/documentacao/suporte/). |
| réplica de leitura | Uma cópia de um banco de dados que responde às instruções que apenas leem. O destino das escritas é a instância principal, e [Como o SQL Database funciona](/pt-br/documentacao/store/sql-database/como-funciona/) descreve como uma consulta chega aos dados. |
| SQL Database | O produto da Azion que armazena [dados relacionais](https://www.azion.com/en/learning/storage-database/what-is-relational-database/) e executa SQL sobre eles, no [dialeto SQLite](https://www.sqlite.org/lang.html). É um produto Store, ao lado do [Object Storage](/pt-br/documentacao/store/object-storage/) e do [KV Store](/pt-br/documentacao/store/kv-store/). Você o alcança pelo Azion Console, pela API da Azion, pela biblioteca `azion`, pelo Azion Runtime e pelo EdgeSQL Shell. |
| status | O estado de provisionamento de um banco de dados: `creating`, `created` ou `deleting`. Não é a chave `state` do envelope da resposta, que traz `pending` na resposta a uma criação ou a uma exclusão. [Bancos de dados e consultas](/pt-br/documentacao/store/sql-database/bancos-de-dados-e-consultas/) documenta os dois. |
| `vector_top_k` | A função que retorna as `k` linhas mais próximas de um vetor, como valores `id` lidos de um índice de vetor nomeado. Uma consulta faz join desse resultado em `rowid` para ler as linhas em si. [Vector search](/pt-br/documentacao/store/sql-database/vector-search/) mostra a instrução completa. |
