[SQL Database](/pt-br/documentacao/store/sql-database/) limita o nome de um banco de dados, as colunas que uma tabela guarda, as dimensões que um vetor carrega e os bancos de dados que uma requisição de listagem retorna. Esta página indica cada limite, o que a plataforma faz além dele e o armazenamento e as linhas que cada plano de serviço inclui em um mês. SQL Database é um produto em Preview: não é habilitado por padrão, e o acesso é solicitado por meio de um ticket de suporte. Para solicitar acesso, ou um limite maior para a conta, entre em contato com o time de [suporte técnico](/pt-br/documentacao/suporte/).

---

## Limites padrão

SQL Database aplica cada limite abaixo em todos os planos. Quando a API da Azion rejeita uma requisição além de um limite, a resposta carrega um array `errors`, e a coluna Além do limite indica o código de erro e o título que esse array carrega.

| Escopo | Limite | Além do limite |
| --- | --- | --- |
| Tamanho do nome do banco de dados (`name`) | 6 a 50 caracteres | `14000` `Invalid Database Name Format`, mais `10048` `Min Length` abaixo de 6 caracteres. |
| Caracteres do nome do banco de dados | Letras, números e o hífen (`-`) | `14000` `Invalid Database Name Format`. |
| Unicidade do nome do banco de dados | Um nome por conta | `14001` `Name Already In Use.` |
| Colunas por tabela | 2.000 colunas | A instrução falha com `too many columns on <table>` dentro de um HTTP `200`. |
| Dimensões de vetor | 65.536 dimensões | A instrução falha com `vector: max size exceeded 65536` dentro de um HTTP `200`. |
| Bancos de dados por resposta de listagem (`page_size`) | 1 a 100, padrão 10 | `10097` `Invalid Page Size`. |
| Renomear um banco de dados | Não suportado | `10007` `Method Not Allowed`. |

Os limites de colunas e de dimensões de vetor são aplicados quando a instrução é executada, e não quando a requisição é validada. `CREATE TABLE t (v F32_BLOB(65537));` tem sucesso, porque o dialeto não valida o parâmetro que um tipo de coluna carrega. O teto de 65.536 dimensões é aplicado por `vector()` quando um valor é construído a partir de sua forma de texto, e não pelo esquema.

Os dois erros de nível de instrução chegam dentro de um HTTP `200`, na chave `error` da entrada daquela instrução em `data`, e não em um array `errors`. Um cliente que lê apenas o status HTTP trata uma instrução rejeitada como sucesso. Leia a chave `error` de cada entrada que a resposta retorna.

## Limites por plano

Os tetos abaixo são o que um plano de serviço permite. Eles são distintos das quantidades medidas que o mesmo plano inclui, indicadas na próxima seção.

| Teto | Hobby | Pro | Enterprise |
| --- | --- | --- | --- |
| Bancos de dados | 10 | 50 | 200 |
| Tamanho máximo do banco de dados | 200 MB | 500 MB | 2 GB |
| Armazenamento máximo por conta | 5 GB | 50 GB | 300 GB |

---

## Uso incluído por plano

A Azion oferece três planos de serviço: Hobby, Pro e Enterprise. Cada um inclui uma quantidade de armazenamento e um número de linhas lidas por mês, e um número de linhas escritas por dia. SQL Database é um produto em Preview nos três.

Uma consulta retorna `rows_read` e `rows_written` ao lado do resultado de cada instrução, então o custo de uma instrução é medido a partir da resposta que a carrega. Para a resposta em que os dois campos aparecem, consulte [Bancos de dados e consultas](/pt-br/documentacao/store/sql-database/bancos-de-dados-e-consultas/).

| Métrica | Hobby | Pro | Enterprise |
| --- | --- | --- | --- |
| Armazenamento | 1 GB / mês incluídos | 1 GB / mês incluídos | Personalizado |
| Linhas lidas | 150M / mês incluídos | 150M / mês incluídos | Personalizado |
| Linhas escritas | 20.000 / dia incluídos | 20.000 / dia incluídos | Personalizado |

O plano decide o que acontece além de uma quantidade incluída. No Hobby, o uso além da quantidade incluída pode exigir um upgrade, e a Azion pode restringir a conta. No Pro e no Enterprise, a Azion cobra o consumo adicional a taxas sob demanda, e limites de gasto configuráveis restringem a cobrança adicional. Para as taxas, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#sql-database). Para a comparação do que os três planos oferecem, consulte [Preços da Azion](https://www.azion.com/pt-br/precos/).
