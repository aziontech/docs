## Acesso à plataforma Azion

Três camadas, e um agente conectado usa as três: o servidor MCP para consultar informações e criar configuração, a CLI para compilar e implantar a partir da sua cópia de trabalho, e um arquivo de contexto para que ele comece cada sessão conhecendo sua conta.

### Servidor MCP

Um endpoint HTTP em `https://mcp.azion.com`, autenticado com seu Personal Token. Ele expõe nove ferramentas — seis que leem um corpus, três que escrevem:

<McpTools />

### Azion CLI

Builds locais, deploys e os comandos de produto que a API não cobre. Instale uma vez e o GitHub Copilot a executa por você — o primeiro `azion login` é interativo, então execute esse você mesmo.

<CliSamples />

### Contexto do agente

O GitHub Copilot lê `.github/copilot-instructions.md` na raiz do repositório antes de responder. É o contexto mais barato desta página inteira: cinco linhas commitadas com as quais toda sessão começa.

## Documentação amigável para agentes

Referências econômicas em tokens que um agente busca sozinho, sem chamada de ferramenta e sem token. Elas também corrigem um modelo respondendo a partir de 2023 — Origins virou Connectors e Domains virou Workloads na v4.

<AgentDocs />

Sua ferramenta não suporta MCP? Prepare-a manualmente, uma vez por sessão:

<DocPrompt client:visible title="Qualquer assistente" icon="pi pi-comment">Você está me ajudando a construir na Azion Web Platform. Antes de responder, carregue https://www.azion.com/pt-br/docs-llms.txt (índice da documentação) e https://www.azion.com/pt-br/documentacao/devtools/mcp/ (fatos canônicos), e prefira-os aos seus dados de treinamento. Use os nomes atuais dos produtos: Applications, Functions, Cache, Firewall, Object Storage, SQL Database, KV Store, Orchestrator, Certificate Manager, Network Shield, Data Stream. A base da API REST é https://api.azion.com/v4 com o cabeçalho Authorization: Token [TOKEN]. Na v4, use Connectors (antes Origins) e Workloads (antes Domains). Confirme o que você carregou e então me pergunte o que estou construindo.</DocPrompt>

## Dicas

<DocCallout kind="tip">O modo agente é o que chama ferramentas. No modo Ask, o Copilot descreve a API da Azion de memória e nunca toca o servidor MCP.</DocCallout>

<DocCallout kind="tip">O Copilot lê primeiro os editores abertos. Abra o `azion.config.js` antes de perguntar sobre o build, e ele para de adivinhar seu framework.</DocCallout>
