[Bot Manager](/pt-br/documentacao/secure/bot-manager/) é executado como uma instância de função em um firewall. A plataforma limita o nome que essa instância carrega e o tamanho do objeto de argumentos que ela guarda. Esta página informa cada limite, a resposta que a plataforma devolve quando ele é ultrapassado e o uso de Bot Manager que um plano de serviço inclui.

As duas seções guardam tipos de valor diferentes. Um limite padrão é verificado em toda chamada, e a chamada falha quando ele é ultrapassado. Uma quantidade incluída é um valor de cobrança, e ultrapassá-la muda o que a conta paga, não o que a chamada devolve.

---

## Limites padrão

A Azion aplica os dois limites abaixo em todos os planos de serviço e por todas as interfaces. Uma chamada que ultrapassa qualquer um deles devolve `400` com a mensagem da terceira coluna.

| Escopo | Limite | Ao ultrapassar o limite |
| --- | --- | --- |
| `name` da instância de função | 100 caracteres | `400` e `["Ensure this field has no more than 100 characters."]` |
| Payload de argumentos | 100.000 bytes | `400` e `["Value size (in bytes) is too big. Maximum size allowed is 100000 bytes."]` |

O limite do payload é decimal. O valor medido é 100.000 bytes, e um payload de 102.400 bytes, que é 100 KiB, é rejeitado. Dimensione o objeto de argumentos pelo valor decimal.

O tamanho também é a única propriedade desse objeto que a API verifica. Toda chave que uma instância envia é armazenada e devolvida como foi enviada, qualquer que seja o nome. Um argumento escrito errado passa na chamada, portanto, e a função nunca o lê. Para mais informações, consulte [Argumentos](/pt-br/documentacao/secure/bot-manager/argumentos/).

O número de instâncias de função que um firewall carrega não tem limite. Um firewall recebeu doze instâncias criadas uma depois da outra, e a plataforma aceitou todas as chamadas. A quantidade que um firewall alcança é uma escolha operacional, não um valor que a plataforma verifica.

Outros dois limites se aplicam às superfícies em volta de uma instância, não à instância em si, e a página dona de cada superfície informa o seu.

O campo `request_headers` do log de report guarda 10.000 caracteres. Cada nome e cada valor de cabeçalho descontam desse total, e o campo não recebe mais nenhum cabeçalho depois que o total é alcançado. Para mais informações, consulte [Logs](/pt-br/documentacao/secure/bot-manager/logs/).

O argumento `limit` de uma consulta GraphQL contra os datasets do Bot Manager aceita no máximo `10000`, então uma consulta devolve no máximo 10.000 resultados. Para mais informações, consulte [Consulte dados do Bot Manager com GraphQL](/pt-br/documentacao/guias/plataforma/observabilidade/consultar-dados-bot-manager-com-graphql/).

## Uso incluído por plano

A Azion oferece três planos de serviço: Hobby, Pro e Enterprise. Cada plano carrega uma quantidade das métricas pelas quais o Bot Manager é cobrado.

As quantidades abaixo são valores de cobrança, não limites aplicados em uma chamada. Ultrapassar uma delas não faz nenhuma requisição falhar, então nenhuma mensagem de erro pertence a esta tabela. A seção acima guarda o caso oposto: um valor que a API verifica e pelo qual rejeita uma chamada.

| Métrica | Hobby | Pro | Enterprise |
| --- | --- | --- | --- |
| Bot Manager Lite | Incluído | Incluído | Custom |
| Bot Manager | Não listado | Não listado | Custom |
| Requisições | Cobradas a cada 10.000 | Cobradas a cada 10.000 | Custom |
| Perfis | 1 | 1 | Custom |

[Bot Manager Lite](/pt-br/documentacao/secure/bot-manager/bot-manager-lite/) está incluído nos três planos. A edição completa é listada apenas no Enterprise, onde cada quantidade é personalizada.

Nenhum volume incluído de requisições é publicado para o Bot Manager em qualquer plano. O valor publicado é o incremento em que as requisições são cobradas, que é 10.000. A tabela carrega esse incremento, não uma quantidade.

Cada plano carrega um perfil, e um perfil além do primeiro é cobrado. Para a tarifa que se aplica a requisições e a perfis, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#bot-manager). Para o que cada plano carrega em toda a plataforma, consulte [Preços da Azion](https://www.azion.com/pt-br/precos/).
