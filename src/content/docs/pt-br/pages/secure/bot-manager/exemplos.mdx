Copie qualquer um destes snippets e altere os nomes e os ids para os da sua própria conta. Cada um é a menor forma completa de um único objeto que o resto da documentação de [Bot Manager](/pt-br/documentacao/secure/bot-manager/) descreve em detalhe: os argumentos com que uma instância roda, a regra do Rules Engine que entrega uma requisição a ela e a query que retorna o que ela pontuou. São configurações para copiar, e não um passo a passo, então leia na ordem que preferir. [Primeiros passos com Bot Manager](/pt-br/documentacao/secure/bot-manager/primeiros-passos/) percorre os mesmos objetos uma vez, em ordem, para quem nunca os construiu.

Uma instância não pontua nada por conta própria, e uma regra precisa nomeá-la antes. O behavior `run_function` que faz essa referência recebe o id da **instância**, nunca o id da função instalada, então a instância existe antes de a regra poder ser escrita. Três destes quatro snippets trazem painéis de Azion Console, Azion CLI e API. A leitura do report log traz apenas a API, porque nenhuma rota de Azion CLI ou de Azion Console para isso foi verificada.
