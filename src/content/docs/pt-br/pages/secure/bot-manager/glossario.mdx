[Bot Manager](/pt-br/documentacao/secure/bot-manager/) usa estes termos de um jeito próprio, e cada definição liga a página que documenta o termo por completo.

| Termo | Definição |
| --- | --- |
| argumentos | O objeto JSON que uma instância de função carrega, que define o threshold, a ação e o registro em log que o Bot Manager aplica naquele firewall. Você o edita na seção **Arguments** do formulário da instância, e [Argumentos](/pt-br/documentacao/secure/bot-manager/argumentos/#campos) documenta cada campo. |
| assinatura de sessão | A assinatura HMAC que o Bot Manager Lite guarda em `az_asm` e reverifica em cada requisição posterior do mesmo cliente. O argumento `session_signature_key` fornece a chave, documentado em [Bot Manager Lite](/pt-br/documentacao/secure/bot-manager/bot-manager-lite/#argumentos). |
| `az_asm` | Um dos dois cookies de sessão que o Bot Manager Lite define em uma requisição que chega sem sessão válida. Seu valor é uma assinatura HMAC do valor em `az_botm`, e a divergência entre os dois é o que a regra `17` pontua. [Bot Manager Lite](/pt-br/documentacao/secure/bot-manager/bot-manager-lite/#regras) lista as regras que leem o par. |
| `az_botm` | A metade não assinada do par de cookies de sessão que o Bot Manager Lite define, carregando o `x-azion-request-id` da resposta que o definiu. Os dois cookies têm escopo no domínio do workload e expiram depois de 24 horas. [Logs](/pt-br/documentacao/secure/bot-manager/logs/) documenta o que o Bot Manager registra sobre uma requisição. |
| categoria de bot | O tipo de bot ou o ataque que o Bot Manager identificou em uma requisição, registrado no campo de log `bot_category`. Os valores incluem `Search Engine Bot`, `Bad Bot Signatures` e `Credential Stuffing`. [Logs](/pt-br/documentacao/secure/bot-manager/logs/#classificacao) lista todos. |
| classificação | O veredito que o Bot Manager registra para uma requisição no campo de log `classified`: `legitimate`, `good bot`, `bad bot` ou `under evaluation`. [Logs](/pt-br/documentacao/secure/bot-manager/logs/#classificacao) dá o critério de cada um, e [Real-Time Metrics](/pt-br/documentacao/plataforma/real-time-metrics/#bot-manager) reúne os quatro nos mesmos gráficos. |
| fingerprint | O hash que o Bot Manager deriva dos atributos de sessão de um dispositivo, como o endereço IP e o cabeçalho `User-Agent`. Identifica o mesmo dispositivo entre requisições e é reportado no campo de log `azion_fingerprint`, documentado em [Logs](/pt-br/documentacao/secure/bot-manager/logs/#campos). |
| instância de função | O objeto que vincula uma função instalada a um [Firewall](/pt-br/documentacao/plataforma/firewall/), carregando os argumentos com que essa função é executada. O Bot Manager é executado como uma instância, selecionada por uma regra do [Rules Engine for Firewall](/pt-br/documentacao/plataforma/firewall/rules-engine/) cujo comportamento é **Run Function**. Azion Console lista as instâncias em **Functions Instances**. |
| log tag | O identificador que uma instância carimba nas linhas de log que escreve, para você separar as linhas de uma instância das de outra em [Real-Time Events](/pt-br/documentacao/observe/real-time-events/). O argumento `log_tag` o define, documentado em [Argumentos](/pt-br/documentacao/secure/bot-manager/argumentos/#campos). |
| pontuação | O número que o Bot Manager atribui a uma requisição, elevado por cada regra estática que ela corresponde e, na edição completa, pela pontuação dinâmica. A `action` da instância é executada quando a pontuação alcança o threshold. [Como Bot Manager funciona](/pt-br/documentacao/secure/bot-manager/como-funciona/#pontuacao) descreve o modelo. |
| pontuação dinâmica | A parte da pontuação que a edição completa deriva do histórico de comportamento de um fingerprint, medida contra o padrão geral de tráfego do host. O Bot Manager Lite executa apenas regras estáticas. [Como Bot Manager funciona](/pt-br/documentacao/secure/bot-manager/como-funciona/#pontuacao) descreve o modelo. |
| regra estática | Uma verificação que o Bot Manager faz sobre os atributos de uma única requisição, como seus cabeçalhos e metadados, sem referência ao tráfego anterior. Cada regra que a requisição corresponde eleva a pontuação dela. [Bot Manager Lite](/pt-br/documentacao/secure/bot-manager/bot-manager-lite/#regras) publica as regras que essa edição executa e a pontuação que cada uma soma. |
| Reputation Intelligence | A verificação que compara o endereço IP de uma requisição com as [Network Lists](/pt-br/documentacao/secure/network-shield/network-lists/) que a Azion mantém, elevando a pontuação quando o endereço aparece em uma delas. É também um dos valores que o campo de log `bot_category` registra, listados em [Logs](/pt-br/documentacao/secure/bot-manager/logs/#classificacao). |
| threshold | A pontuação a partir da qual uma instância de função executa a `action` configurada. O argumento `threshold` a define, e uma requisição abaixo dela segue para sua aplicação. [Argumentos](/pt-br/documentacao/secure/bot-manager/argumentos/#action) lista o que cada ação faz. |
| `under evaluation` | A classificação que o Bot Manager registra quando ainda não tem dados de fingerprint suficientes para situar uma requisição. Consolidar a pontuação de um fingerprint leva até 15 minutos, e um fingerprint não visto há 15 minutos ou mais volta para esse estado. [Logs](/pt-br/documentacao/secure/bot-manager/logs/#classificacao) cobre as quatro classificações. |
