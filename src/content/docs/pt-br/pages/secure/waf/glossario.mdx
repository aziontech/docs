O vocabulário que o [Web Application Firewall](/pt-br/documentacao/secure/waf/) usa à sua maneira, com cada entrada apontando para a página que documenta o termo por completo.

| Termo | Definição |
| --- | --- |
| Allowed Rules | O nome que o Azion Console dá às exceções de WAF, e a aba de um rule set onde você as cria e gerencia. A API e a CLI chamam o mesmo objeto de exceção. [WAF Exceptions](/pt-br/documentacao/secure/waf/custom-allowed-rules/) documenta o objeto sob os dois nomes. |
| `Blocking` | O modo em que o WAF bloqueia uma requisição cujo score atinge o limiar de uma família de ameaças, antes que a requisição chegue à sua aplicação. É um dos dois valores que o comportamento `Set WAF` aceita, e é definido por regra, não no rule set. [Como WAF funciona](/pt-br/documentacao/secure/waf/como-funciona/) descreve os dois modos. |
| condição | A parte de uma requisição que uma exceção corresponde, expressa como uma match zone e, para uma zona específica, o nome ou valor a que se aplica. O campo no Azion Console é **Condition**, e a API recebe `conditions` como um array com pelo menos uma entrada. [WAF Exceptions](/pt-br/documentacao/secure/waf/custom-allowed-rules/) lista todas as opções. |
| Custom Allowed Rules | Um nome descontinuado para as exceções de WAF. Não aparece em nenhuma interface da Azion: a aba do Azion Console diz Allowed Rules, e a API e a CLI chamam o objeto de exceção. |
| exceção | Uma entrada que isenta parte de uma requisição de uma regra interna, ou de todas elas, para que um falso positivo deixe de ser bloqueado. O Azion Console a chama de allowed rule, e a API e a CLI a chamam de exceção. [WAF Exceptions](/pt-br/documentacao/secure/waf/custom-allowed-rules/) documenta o ID da regra, as condições e o operador que ela carrega. |
| falso positivo | Uma requisição legítima que alcança o limiar de uma família de ameaças e é tratada como um ataque. É o que o [Tuning](/pt-br/documentacao/secure/waf/custom-allowed-rules/#tuning) serve para encontrar e o que uma exceção serve para eliminar. Um falso negativo é o inverso, um ataque cujo score fica abaixo do limiar, e aumentar um nível de sensibilidade troca um pelo outro. |
| família de ameaças | Uma das oito classes de ataque que um rule set pontua, cada uma com seu próprio nível de sensibilidade. Cobrem tipos de ataque como [SQL injection, cross-site scripting e directory traversal](https://www.azion.com/en/learning/). [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/) nomeia todas as oito e o que cada uma detecta. |
| ID da regra | O identificador de uma regra interna do WAF, que uma exceção indica para limitar seu escopo a essa regra. `0` significa todas as regras e é o padrão. A API aceita 63 IDs, listados em [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/), e o Azion Console oferece 62 deles, omitindo `1314`. |
| limiar | O score a partir do qual o WAF bloqueia uma requisição para uma família de ameaças. O nível de sensibilidade escolhido para essa família o fixa, portanto uma sensibilidade maior define um limiar menor. [Como WAF funciona](/pt-br/documentacao/secure/waf/como-funciona/) descreve como os dois se relacionam. |
| `Logging` | O modo em que o WAF atribui um score a uma requisição e registra a correspondência sem bloqueá-la. É o outro valor que o comportamento `Set WAF` aceita, descrito ao lado de `Blocking` em [Como WAF funciona](/pt-br/documentacao/secure/waf/como-funciona/). [Real-Time Events](/pt-br/documentacao/observe/real-time-events/) reporta o mesmo estado pelo campo `wafLearning`, rotulado **WAF Learning**. |
| match zone | A parte de uma requisição que uma condição inspeciona, como o valor de uma query string, o nome de um header ou o corpo bruto. Existem 15 delas. O Azion Console seleciona uma pelo campo **Condition**, não por um controle chamado match zone. |
| módulo WAF | O switch em uma configuração de [Firewall](/pt-br/documentacao/plataforma/firewall/) que ativa o WAF nela. Nenhum rule set é executado até que o módulo esteja habilitado no firewall por onde a requisição passa. [How to configure Firewall main settings](/pt-br/documentacao/guias/seguranca-de-aplicacoes/firewall-e-waf/firewall-definir-main-settings/) mostra onde o switch fica. |
| nível de sensibilidade | A configuração que fixa o limiar de uma família de ameaças, com cinco valores de `highest` a `lowest` e padrão `medium`. Uma sensibilidade maior significa um limiar menor, portanto mais requisições são bloqueadas. [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/) traz o score em que cada nível bloqueia. |
| `Operator` | O campo que decide como uma exceção compara o valor na sua condição. Aceita `regex` ou `contains`, tem `contains` como padrão e é documentado junto dos outros campos em [WAF Exceptions](/pt-br/documentacao/secure/waf/custom-allowed-rules/). Não existe um switch regex separado; a escolha é um valor desse campo. |
| rule set | O objeto que carrega as oito famílias de ameaças e o nível de sensibilidade escolhido para cada uma, listado no Azion Console em **WAF Rules**. Um rule set não detecta nada sozinho: uma regra do Rules Engine com o comportamento `Set WAF` o aplica ao tráfego. [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/) documenta seus campos. |
| score | O número que o WAF atribui a uma requisição para uma família de ameaças, aumentado a cada novo indício dessa ameaça. Uma requisição é bloqueada quando seu score atinge o limiar da família. [Como WAF funciona](/pt-br/documentacao/secure/waf/como-funciona/) descreve o modelo. |
| `Set WAF` | O comportamento do [Rules Engine for Firewall](/pt-br/documentacao/plataforma/firewall/rules-engine/) que aplica um rule set às requisições que uma regra corresponde, e que carrega o modo em que esse rule set é executado. Uma regra carrega no máximo um comportamento `Set WAF`. Sem ele, um rule set nunca é executado. |
| Tuning | A aba de um rule set que lista as requisições que cada regra interna correspondeu, em uma janela de até os últimos 3 dias. Você a filtra por workload ou domínio, path, país, endereço IP e [Network Lists](/pt-br/documentacao/secure/network-shield/network-lists/), e depois transforma os registros selecionados em allowed rules em massa. [WAF Exceptions](/pt-br/documentacao/secure/waf/custom-allowed-rules/) documenta a tela. |
