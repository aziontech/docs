O [Web Application Firewall](/pt-br/documentacao/secure/waf/) limita o nome que um rule set recebe, as condições que uma exceção carrega, o tamanho do corpo da requisição que ele inspeciona e o que uma requisição de listagem retorna. Esta página indica cada limite, a resposta que a plataforma retorna acima dele e as requisições, os rule sets e as exceções que um plano de serviço inclui. Os dois conjuntos são coisas diferentes: os limites da primeira seção são aplicados em toda chamada, e as quantidades da segunda são valores de cobrança.

---

## Limites padrão

O WAF aplica cada limite abaixo em todos os planos de serviço. A API responde a uma chamada rejeitada com um `code` numérico, um `title`, um `detail` e um ponteiro `source` que indica o campo que falhou. A coluna Acima do limite indica o status, o código e o título, além do texto que chega com eles.

| Escopo | Limite | Acima do limite |
| --- | --- | --- |
| `name` do rule set | Até 250 caracteres | `400` `10046 Max Length`, `Ensure this field has no more than 250 characters.` |
| `name` da exceção | Até 255 caracteres | `400` `10046 Max Length`, `Ensure this field has no more than 255 characters.` |
| `name` e `value` da condição de uma exceção | 1 a 255 caracteres | Um valor vazio retorna `400` `10018 Blank Field`, `This field may not be blank.` Um valor mais longo é rejeitado. |
| Condições por exceção | No mínimo 1; mais de uma é aceita | Um array vazio retorna `400` `10049 Min Length List Field`, `Ensure this field has at least 1 elements.` |
| Registros por resposta de listagem (`page_size`) | 100 no máximo, padrão 10 | `400` `10097 Invalid Page Size`, `Page size must be between 0 and 100.` |
| Requisições de API por minuto | 200, no escopo `global-default` | A resposta carrega `x-ratelimit-limit`, `x-ratelimit-remaining`, `x-ratelimit-reset` e `x-ratelimit-scope`, que informam o saldo restante na janela e o momento em que ela é reiniciada. |
| Entradas de `thresholds` em um rule set | 1 a 8, uma por família de ameaça | Um `threat` repetido retorna `500` `10067 Internal Server Error`, `A server error occurred.` |
| `rulesets` | `[1]` | `400` `10039 Invalid Choice`, `"<value>" is not a valid choice.` |
| `engine_version` | `2021-Q3` | `400` `10039 Invalid Choice` |
| `engine_settings.type` | `score` | `400` `10039 Invalid Choice` |
| `operator` em uma exceção | `contains` ou `regex`, padrão `contains` | `400` `10039 Invalid Choice` |
| `mode` em um comportamento `Set WAF` | `logging` ou `blocking`, e obrigatório | Um valor fora da lista retorna `400` `10039 Invalid Choice`. Um `mode` ausente retorna `400` `10059 Required Field`, `This field is required.` |
| Corpo da requisição que o WAF inspeciona | 131.072 bytes, que são 128 KiB | `400` e a página de erro padrão da Azion, e não um `413`. |
| Janela de consulta do WAF Tuning | 3 dias | A lista de intervalos de tempo do Console vai no máximo até `Last 3 days`, e nenhuma interface oferece um intervalo maior. |

O limite do corpo foi medido com `Content-Type: application/x-www-form-urlencoded` e um corpo sem nenhum padrão de ataque: 131.072 bytes retornaram `200` e 131.073 bytes retornaram `400`. No mesmo teste, o mesmo corpo enviado como `application/json` ou `text/plain` foi bloqueado nos dois tamanhos, porque outras regras corresponderam à requisição antes de a verificação de tamanho ser aplicada. Portanto, um teste desse limite usa `application/x-www-form-urlencoded` ou `multipart/form-data`.

O `500` que um `threat` repetido retorna é uma falha de validação, e não um defeito no serviço. Envie cada uma das oito famílias de ameaça no máximo uma vez em `thresholds`.

Mais um limite se aplica ao firewall em que um rule set é executado, e não ao WAF: um log de Debug Rules carrega 1,5 kB. Esse recurso pertence ao [Firewall](/pt-br/documentacao/plataforma/firewall/).

Para os campos a que esses limites se aplicam, consulte [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/) e [WAF Exceptions](/pt-br/documentacao/secure/waf/custom-allowed-rules/).

## Uso incluído por plano

A Azion oferece três planos de serviço: Hobby, Pro e Enterprise. O WAF é cobrado por três métricas: Requests, Rule Sets e Exceptions. Cada plano inclui uma quantidade de cada métrica antes que uma cobrança se aplique.

As quantidades abaixo são quantidades de cobrança, e não limites que a plataforma aplica a uma chamada. Uma requisição de criação acima da quantidade incluída de rule sets ou de exceções é aceita, portanto a contagem que uma conta alcança é um custo a acompanhar, e não uma rejeição a tratar.

| Métrica | Hobby | Pro | Enterprise |
| --- | --- | --- | --- |
| Requests | 100.000 por mês | 200.000 por mês | Custom |
| Rule Sets | 1 | 2 | Custom |
| Exceptions por rule set | 10 | 20 | Custom |

O Enterprise carrega uma quantidade personalizada nas três métricas. Para aumentar uma quantidade incluída em qualquer plano, entre em contato com o time de [Suporte Técnico](/pt-br/documentacao/suporte/).

Para a taxa que se aplica acima de uma quantidade incluída, consulte [Preços](/pt-br/documentacao/fundamentos/precos/#web-application-firewall). Para a comparação do que os três planos carregam, consulte [Preços da Azion](https://www.azion.com/pt-br/precos/).
