Um rule set guarda as oito famílias de ameaças e o nível de sensibilidade escolhido para cada uma. O corpo abaixo cria um rule set com toda família em `medium`, que é o nível em que uma família abre e o nível a partir do qual começar antes que o tráfego tenha dito o contrário. Recorra a ele quando você precisar de um rule set para nomear em um behavior `Set WAF` e ainda não tiver razão para aumentar uma família.

```bash
curl --request POST \
  --url https://api.azion.com/v4/workspace/wafs \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]' \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "storefront-waf",
  "active": true,
  "product_version": "1.0",
  "engine_settings": {
    "engine_version": "2021-Q3",
    "type": "score",
    "attributes": {
      "rulesets": [1],
      "thresholds": [
        { "threat": "cross_site_scripting", "sensitivity": "medium" },
        { "threat": "directory_traversal", "sensitivity": "medium" },
        { "threat": "evading_tricks", "sensitivity": "medium" },
        { "threat": "file_upload", "sensitivity": "medium" },
        { "threat": "identified_attack", "sensitivity": "medium" },
        { "threat": "remote_file_inclusion", "sensitivity": "medium" },
        { "threat": "sql_injection", "sensitivity": "medium" },
        { "threat": "unwanted_access", "sensitivity": "medium" }
      ]
    }
  }
}'
```

A API responde `202` e ecoa o objeto sob `data`, onde `"state": "pending"` significa que a mudança ainda está se propagando. Anote `data.id`: esse é o valor que um behavior `Set WAF` nomeia.

## Como funciona

Um create simples já está completo. O rule set volta ativo, rodando no ruleset `1` com engine version `2021-Q3` e engine type `score`, e carregando as oito famílias de ameaças em `medium`. A lista de oito famílias é o que o formulário do Azion Console preenche para você; a API aceita menos, e um array `thresholds` com uma única entrada cria um rule set que pontua apenas aquela família.

O nível de sensibilidade fixa o score em que uma família bloqueia. Uma família em `medium` precisa de mais evidência para alcançar o seu limiar do que a mesma família em `high`, então ela produz menos falsos positivos e pega menos. Aumente uma família por vez, a partir do que o tráfego registrou, em vez de aumentar o rule set inteiro de uma vez. Para o limiar que cada nível define, consulte [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/#niveis-de-sensibilidade).
