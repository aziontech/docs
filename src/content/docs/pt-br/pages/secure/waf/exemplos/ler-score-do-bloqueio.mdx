Nada em uma resposta bloqueada identifica o WAF. A requisição recebe `400` e a página de erro padrão da Azion, encabeçada por **Bad Request**, sem header de WAF e sem mensagem que nomeie uma regra ou um score. O header `x-azion-request-id` é o identificador que encontra o registro. Recorra a este par sempre que você precisar saber qual regra interna disparou antes de escrever uma exceção para ela.

```bash
curl -i "https://<your-workload-domain>/?q=1%27%20OR%20%271%27%3D%271"
```

```text
HTTP/2 400
content-type: text/html
x-azion-request-id: 1123d5bf29651faaaaf6e09dbafcc4e3
```

O [Real-Time Events](/pt-br/documentacao/observe/real-time-events/) responde a uma query GraphQL em `https://api.azion.com/v4/events/graphql`, sobre o dataset `workloadEvents`. Envie-a com um personal token, filtrada pelo request id e por uma janela ao redor dele:

```graphql
query {
  workloadEvents(
    limit: 1
    filter: { tsGte: "<start>", tsLt: "<end>", requestIdEq: "<request-id>" }
  ) {
    ts
    requestUri
    status
    upstreamStatus
    wafBlock
    wafMatch
    wafScore
    wafAttackFamily
    wafAttackAction
  }
}
```

```json
{
  "ts": "2026-09-20T16:03:51Z",
  "requestUri": "/?q=1%27%20OR%20%271%27%3D%271",
  "status": 400,
  "upstreamStatus": 0,
  "wafBlock": "1",
  "wafMatch": "0:1009:ARGS:q,1:1013:ARGS:q",
  "wafScore": "0:$SQL:18,1:$XSS:32",
  "wafAttackFamily": "$SQL,$XSS",
  "wafAttackAction": "$BLOCK"
}
```

## Como funciona

`wafMatch` carrega uma entrada por regra interna que correspondeu, no formato `<index>:<ruleId>:<zone>:<varName>`. Esta requisição correspondeu à regra `1009` e à regra `1013` no argumento `q`, que são o sinal de igual e o apóstrofo, não a regra que roda um parser de SQL injection sobre o mesmo valor. `wafScore` reporta um score por família de ameaças que disparou, no formato `<index>:$<family>:<score>`, então uma requisição tem vários scores em vez de um. `upstreamStatus` lê `0` porque a requisição nunca alcançou uma origem: um `400` junto de um `0` é a aparência de um bloqueio do WAF visto de fora.

Uma requisição sobre a qual o WAF não agiu carrega `-` em cada um desses campos, e um `400` sem uma linha dessas não é um bloqueio do WAF. Consulte o path v4: o antigo `https://api.azion.com/events/graphql` responde `204` com um corpo vazio, e os campos ali são camelCase em vez das grafias em snake_case que um payload do [Data Stream](/pt-br/documentacao/observe/data-stream/) usa.
