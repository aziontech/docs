A sensibilidade é definida por família de ameaças, então uma família pode bloquear com menos evidência do que o resto. O corpo abaixo aumenta `sql_injection` para `high` e deixa as outras sete famílias em `medium`. Recorra a ele quando os eventos mostrarem uma família pegando ataques reais e as outras produzindo apenas falsos positivos.

```bash
curl --request PATCH \
  --url https://api.azion.com/v4/workspace/wafs/<waf-id> \
  --header 'Accept: application/json' \
  --header 'Authorization: Token [TOKEN VALUE]' \
  --header 'Content-Type: application/json' \
  --data '{
  "engine_settings": {
    "engine_version": "2021-Q3",
    "type": "score",
    "attributes": {
      "rulesets": [1],
      "thresholds": [
        { "threat": "cross_site_scripting", "sensitivity": "medium" },
        { "threat": "directory_traversal", "sensitivity": "medium" },
        { "threat": "evading_tricks", "sensitivity": "medium" },
        { "threat": "file_upload", "sensitivity": "medium" },
        { "threat": "identified_attack", "sensitivity": "medium" },
        { "threat": "remote_file_inclusion", "sensitivity": "medium" },
        { "threat": "sql_injection", "sensitivity": "high" },
        { "threat": "unwanted_access", "sensitivity": "medium" }
      ]
    }
  }
}'
```

A API responde `202`, e o rule set é lido de volta carregando exatamente as oito entradas que você enviou.

## Como funciona

Um `PATCH` substitui o array `thresholds` inteiro em vez de mesclá-lo entrada por entrada. Envie todas as oito famílias, incluindo as sete que você não está alterando: um corpo que carrega apenas `sql_injection` deixa o rule set pontuando somente aquela família, e as outras sete deixam de estar configuradas.

Envie cada família uma vez. Um `threat` repetido é respondido com `500` e o erro `10067 Internal Server Error` em vez de uma mensagem de validação, que é a falha mais difícil de interpretar a partir da resposta neste endpoint. O array guarda no máximo oito entradas, uma por família, e `sensitivity` aceita `highest`, `high`, `medium`, `low` ou `lowest`. Aumentar uma família baixa o score que as suas requisições têm que alcançar, então ela pega mais e produz mais falsos positivos no mesmo tráfego. Para o limiar que cada nível define, consulte [WAF Rule Sets](/pt-br/documentacao/secure/waf/rule-sets/#niveis-de-sensibilidade).
