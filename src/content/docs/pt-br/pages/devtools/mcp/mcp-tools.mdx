O [MCP server da Azion](/pt-br/documentacao/devtools/mcp/) expõe ferramentas e recursos a um agente de código que se conecta com um [personal token](/pt-br/documentacao/fundamentos/personal-tokens/) da Azion, e não expõe prompts. Toda ferramenta retorna texto, e nenhuma ferramenta cria, altera ou exclui nada na sua conta.

---

## Ferramentas

Uma conta no perfil de API v4 vê as oito ferramentas da tabela abaixo. Cada ferramenta de busca retorna um item `text` cujo valor é um array JSON de documentos, e todo documento traz `title`, `content`, `source`, `similarity`, `search_type` e `relevance_score`.

| Ferramenta | Retorna | Entradas |
| --- | --- | --- |
| `search_azion_docs_and_site` | Documentos da documentação e do site da Azion, para uma pergunta como configurar a proteção contra DDoS | `query` (string, obrigatório); `docsAmount` (number, opcional, padrão `5`) |
| `search_azion_code_samples` | Bibliotecas e exemplos de código, para um pedido como exemplos de deploy de Next.js | `query` (string, obrigatório); `docsAmount` (number, opcional, padrão `5`) |
| `search_azion_cli_commands` | Documentos sobre os comandos da [Azion CLI](/pt-br/documentacao/devtools/cli/) e o uso deles, para uma pergunta como quais comandos gerenciam functions | `query` (string, obrigatório); `docsAmount` (number, opcional, padrão `5`) |
| `search_azion_api_v4_commands` | Documentos da referência v4 da [Azion API](/pt-br/documentacao/devtools/api/), como o fragmento OpenAPI de uma operação | `query` (string, obrigatório); `docsAmount` (number, opcional, padrão `5`) |
| `search_azion_terraform` | Documentos da documentação do [Azion Terraform Provider](/pt-br/documentacao/devtools/terraform/), para uma pergunta como criar um recurso do Terraform | `query` (string, obrigatório); `docsAmount` (number, opcional, padrão `5`) |
| `create_rules_engine` | Uma proposta de regra para o Rules Engine de uma [aplicação](/pt-br/documentacao/plataforma/applications/rules-engine/) ou de um [firewall](/pt-br/documentacao/plataforma/firewall/rules-engine/), como texto JSON com `criteria`, `behaviors`, `phase` e `explanation` dentro de `data`; nenhuma regra é criada | `useCase` (string, obrigatório): `edge_application`, `edge_firewall` ou `""`; `query` (string, opcional) |
| `create_graphql_query` | Uma query para a [GraphQL API](/pt-br/documentacao/devtools/graphql/) que responde ao objetivo em `query`; quando nenhuma query válida resulta, o texto diz isso e aponta para a documentação da GraphQL API | `query` (string, obrigatório); `dataSource` (string, obrigatório): `real-time-metrics`, `real-time-events`, `accounting` ou `consumption` |
| `deploy_azion_static_site` | Texto de guia para fazer o deploy de um site estático e testar o cache dele; `help` lista os sete recursos, `deploy` retorna as quatro etapas de deployment e `test-cache` retorna as três etapas de teste de cache | `action` (string, opcional): `deploy`, `test-cache` ou `help` |

Três entradas precisam de mais do que a tabela comporta:

- `docsAmount` define quantos documentos uma ferramenta de busca retorna. Envie esse valor apenas quando quiser um número diferente de cinco.
- `useCase` filtra os documentos que `create_rules_engine` lê: `edge_application` para regras de aplicação e `edge_firewall` para regras de firewall. O schema exige apenas `useCase`, mas a ferramenta monta a regra a partir de `query`, então envie o objetivo ali também. Por exemplo, o objetivo `redirect requests for /old to /new with a 301` pode retornar uma regra cujo critério compara `${uri}` com `/old` e cujo comportamento é `Redirect_to_301`.
- `action` é uma string livre, não um enum. A ferramenta documenta `deploy`, `test-cache` e `help` como os valores dela.

`create_graphql_query` executa as queries que gera na GraphQL API de analytics da sua conta, com o seu token, para validá-las. Essas queries apenas leem dados.

## Recursos de site estático

Um cliente que suporta recursos MCP lista sete guias em `azion://static-site/deploy/` e `azion://static-site/test-cache/` e lê cada um com `resources/read`. Todo recurso é `text/markdown`, o nome dele é o caminho da URI unido por hífens, como em `static-site-deploy-step-0-preparation`, e o servidor não oferece templates de recurso.

| URI | Conteúdo |
| --- | --- |
| `azion://static-site/deploy/step-0-preparation` | Instruções para analisar a estrutura do projeto, detectar o framework e o gerenciador de pacotes e reunir os requisitos do deployment |
| `azion://static-site/deploy/step-1-configuration` | Instruções para instalar a Azion CLI, autenticar, vincular o projeto e testar a configuração de build |
| `azion://static-site/deploy/step-2-execute` | Instruções para fazer o deploy do projeto e verificar o status do deployment |
| `azion://static-site/deploy/step-3-basic-test` | Instruções para executar testes básicos do deployment e do comportamento de cache dele |
| `azion://static-site/test-cache/step-0-preparation` | Instruções para analisar a configuração de cache do site após o deploy e preparar cenários de teste |
| `azion://static-site/test-cache/step-1-execution` | Instruções para executar testes de cache para cada tipo de asset estático e verificar a proporção entre hits e misses |
| `azion://static-site/test-cache/step-2-validation` | Instruções para validar os resultados dos testes, calcular a taxa de cache hits e escrever um relatório de teste |

Um cliente sem suporte a recursos chega aos mesmos guias por meio de `deploy_azion_static_site`, com `action` definida como `deploy` ou `test-cache`.

## Prompts

O MCP server da Azion não expõe prompts. A resposta de `initialize` dele não declara a capacidade `prompts`, e uma requisição `prompts/list` retorna o erro JSON-RPC `-32601` com a mensagem `Method not found`.

---

## Conjunto de ferramentas por perfil de API

As ferramentas que uma conta vê dependem do perfil de API dela. Uma conta no perfil de API v3 vê uma nona ferramenta, `search_azion_api_v3_commands`, que busca na documentação da Azion API v3.

Uma conta no perfil v4 não vê essa ferramenta, e uma requisição `tools/call` para ela retorna o erro JSON-RPC `-32602` com esta mensagem:

```text
MCP error -32602: Tool search_azion_api_v3_commands not found
```

## Chamada de uma ferramenta de busca

A requisição abaixo chama `search_azion_docs_and_site` com uma query e dois documentos. Ela é um `POST` para `https://mcp.azion.com` com os headers `Authorization: Bearer [TOKEN VALUE]`, `Content-Type: application/json` e `Accept: application/json, text/event-stream`, e com este corpo:

```json
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "id": 1,
  "params": {
    "name": "search_azion_docs_and_site",
    "arguments": {
      "query": "how to configure cache",
      "docsAmount": 2
    }
  }
}
```

O servidor responde com o status `200` e um evento server-sent. Os dados desse evento, decodificados, são o resultado abaixo, com o valor de `text` cortado em `…`; o valor completo traz os dois documentos que `docsAmount` pede:

```json
{
  "result": {
    "content": [
      {
        "type": "text",
        "text": "[\n  {\n    \"title\": \"application-acceleration\",\n    \"content\": \"Title: application-acceleration\\nDescription: Application Accelerator speeds up web applications and APIs through protocol optimizations and manages dynamic content requirements.\\nMetatag Keywords: Application Accelerator, Serveless, Edg…"
      }
    ]
  },
  "jsonrpc": "2.0",
  "id": 1
}
```
