Este guia orienta você na sua primeira pergunta ao MCP server da Azion pelo Claude Code.

- Crie um personal token no Azion Console.
- Registre o servidor no Claude Code com um comando.
- Verifique as ferramentas e os recursos que o servidor expõe com o MCP Inspector.
- Faça ao Claude Code uma pergunta que o servidor responde a partir da documentação da Azion.

Três peças se conectam, nesta ordem:

1. O **personal token** identifica a sua conta Azion.
2. A **entrada do servidor** `azion-mcp` no Claude Code aponta para `https://mcp.azion.com` e envia o token no header `Authorization` de cada requisição.
3. O **MCP server da Azion** verifica o token e entrega ao Claude Code as ferramentas e os recursos dele.

Para mais informações sobre o servidor, consulte [MCP server](/pt-br/documentacao/devtools/mcp/).

---

## Pré-requisitos

- Uma conta Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).
- O Claude Code, instalado na sua máquina.
- Node.js e npm. O MCP Inspector é executado com `npx`.

---

## 1. Crie um personal token

O servidor aceita um personal token da Azion como credencial. Para criar o token no Azion Console:

<DocSteps>
  <DocStep title="Abra a página de personal tokens">

  Acesse [Azion Console](https://console.azion.com/) > **Account** > **Personal Token**. **Account** é o menu do avatar.

  </DocStep>
  <DocStep title="Selecione + Personal Token" />
  <DocStep title="Dê um nome ao token">

  Na seção **General**, insira um **Name**. Por exemplo: `mcp-server`.

  </DocStep>
  <DocStep title="Defina a expiração">

  Na seção **Token**, selecione um valor em **Expires within**. O padrão é _1 day_.

  </DocStep>
  <DocStep title="Selecione Save" />
  <DocStep title="Copie o token">

  Na caixa de diálogo **Personal Token has been created**, selecione **Copy**. A caixa de diálogo mostra o token apenas uma vez, então guarde-o antes de continuar.

  </DocStep>
  <DocStep title="Selecione Confirm" />
</DocSteps>

O token aparece na lista **Personal Tokens**, e o valor dele está na sua área de transferência. Para mais informações, consulte [Como criar um personal token](/pt-br/documentacao/guias/plataforma/conta-e-billing/personal-tokens/).

Mantenha o token seguro:

- Nunca faça commit de um token. Adicione ao `.gitignore` todo arquivo de configuração que contenha um.
- Guarde o token em uma variável de ambiente quando o seu cliente oferecer suporte a isso.
- Faça a rotação dos seus tokens regularmente.

---

## 2. Conecte o Claude Code

O comando `claude mcp add` registra o servidor. A flag `-t http` seleciona o transporte HTTP, e `-H` define o header que carrega o seu token. Execute o comando e substitua `[TOKEN VALUE]` pelo seu token:

```bash
claude mcp add "azion-mcp" "https://mcp.azion.com" -t http -H "Authorization: Bearer [TOKEN VALUE]"
```

O Claude Code guarda o servidor na sua configuração de usuário, que não é um arquivo do seu projeto. O servidor também aceita o token com o esquema `Token`, `Authorization: Token [TOKEN VALUE]`, e responde aos dois esquemas da mesma forma.

O Claude Code tem o MCP server da Azion registrado como `azion-mcp`. Para mais informações sobre o Claude Code com a Azion, consulte [Claude Code + Azion](/pt-br/documentacao/agent-setup/claude-code/).

---

## 3. Verifique a conexão

O MCP Inspector se conecta a um MCP server e lista o que o servidor expõe. Inicie o Inspector:

```bash
npx @modelcontextprotocol/inspector
```

Para instalar o Inspector em vez de executá-lo com `npx`, execute `npm install -g @modelcontextprotocol/inspector`.

Para conectar o Inspector ao MCP server da Azion:

<DocSteps>
  <DocStep title="Selecione o transporte">

  Defina **Transport type** como _streamable-http_.

  </DocStep>
  <DocStep title="Insira o endereço do servidor">

  Em **URL**, insira `https://mcp.azion.com`.

  </DocStep>
  <DocStep title="Insira o header">

  Em **Authentication**, insira `Authorization: Bearer [TOKEN VALUE]`, com o seu token no lugar de `[TOKEN VALUE]`.

  </DocStep>
  <DocStep title="Selecione Connect" />
  <DocStep title="Abra a aba Tools" />
  <DocStep title="Abra a aba Resources" />
</DocSteps>

Para uma conta no perfil v4 da API, a aba **Tools** lista oito ferramentas, e a aba **Resources** lista sete recursos. Uma conta no perfil v3 da API vê uma ferramenta a mais. Para a lista completa, consulte [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/#conjunto-de-ferramentas-por-perfil-de-api).

Uma requisição sem um token válido falha com `401`. Para diagnosticar uma conexão que falhou, consulte [Solucionar problemas do MCP server](/pt-br/documentacao/devtools/mcp/solucao-de-problemas/).

## 4. Faça sua primeira pergunta

A ferramenta `search_azion_docs_and_site` pesquisa na documentação e no site da Azion. Em uma sessão do Claude Code, faça uma pergunta que precise dela:

```text
Search the Azion documentation: how to configure cache
```

A ferramenta retorna as páginas da documentação que melhor correspondem à pergunta, cada uma com o título, o conteúdo e a URL de origem. O Claude Code monta a resposta a partir dessas páginas.

As outras ferramentas do servidor retornam exemplos de código, comandos da Azion CLI, operações da Azion API, propostas de regras do Rules Engine, queries GraphQL e guias para fazer o deploy de um site estático. Nenhuma ferramenta cria, altera ou exclui nada na sua conta. Experimente um destes prompts em seguida:

- `I have a static website with HTML, CSS, and JavaScript files. Help me deploy it to Azion.`
- `Generate a query to analyze cache hit rates for my images.`
- `Create Rules Engine rules to add security headers including HSTS, X-Frame-Options, and CSP for my application.`
- `My deployment is failing with error 503. How can I debug this?`

O Claude Code responde a perguntas sobre a Azion a partir do MCP server da Azion.

## Conecte outro cliente

Cada cliente da tabela abaixo tem a própria página de configuração. Todos se conectam a `https://mcp.azion.com` com o seu personal token:

| Cliente | Onde o servidor é configurado | Página de configuração |
| --- | --- | --- |
| Cursor | `.cursor/mcp.json` | [Cursor + Azion](/pt-br/documentacao/agent-setup/cursor/) |
| GitHub Copilot | `.vscode/mcp.json` | [GitHub Copilot + Azion](/pt-br/documentacao/agent-setup/github-copilot/) |
| Windsurf | `.codeium/windsurf/mcp_config.json` | [Windsurf + Azion](/pt-br/documentacao/agent-setup/windsurf/) |
| Codex | `~/.codex/config.toml` | [Codex + Azion](/pt-br/documentacao/agent-setup/codex/) |
| Gemini CLI | `~/.gemini/settings.json` | [Gemini CLI + Azion](/pt-br/documentacao/agent-setup/gemini-cli/) |
| OpenCode | `opencode.json` | [OpenCode + Azion](/pt-br/documentacao/agent-setup/opencode/) |

O Cursor usa o esquema `Token` em vez de `Bearer` no header `Authorization`.

Claude Desktop, Warp e Kiro não têm página de configuração. As configurações deles vêm a seguir.

### Claude Desktop

O Claude Desktop inicia a conexão pelo `mcp-remote`, uma ponte entre um cliente local e um MCP server remoto. O comando `npx` baixa o `mcp-remote` no primeiro uso, e a ponte precisa do Node.js 18 ou posterior. A conexão leva cerca de 10 segundos.

Nas configurações do Claude Desktop, abra a configuração MCP e adicione o servidor. Substitua `[TOKEN VALUE]` pelo seu token:

```json
{
  "mcpServers": {
    "azion": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote@latest",
        "https://mcp.azion.com",
        "--header",
        "Authorization: Bearer [TOKEN VALUE]"
      ]
    }
  }
}
```

### Warp

O Warp também se conecta pelo `mcp-remote`, com o mesmo requisito de Node.js. Nas configurações MCP do Warp, adicione o servidor. Esta configuração não tem uma chave `mcpServers` em volta do servidor. Substitua `[TOKEN VALUE]` pelo seu token:

```json
{
  "azion": {
    "command": "npx",
    "args": [
      "-y",
      "mcp-remote@latest",
      "https://mcp.azion.com",
      "--header",
      "Authorization: Bearer [TOKEN VALUE]"
    ]
  }
}
```

### Kiro

O Kiro lê o token de um campo `token` em vez de um header. Crie o arquivo `.kiro/settings/mcp.json` com o servidor. Substitua `[TOKEN VALUE]` pelo seu token:

```json
{
  "servers": {
    "azion": {
      "url": "https://mcp.azion.com",
      "token": "[TOKEN VALUE]"
    }
  }
}
```
