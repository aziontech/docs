Este glossário define os termos que o [MCP server da Azion](/pt-br/documentacao/devtools/mcp/) usa nas respostas dele, na configuração de um agente de código e em toda a sua documentação.

| Termo | Definição |
| --- | --- |
| ferramenta | Uma função que o MCP server oferece e que um agente de código chama pelo nome, com argumentos JSON, como `search_azion_docs_and_site` com uma `query`. Toda ferramenta retorna texto, e nenhuma altera a conta. [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/) lista cada ferramenta com os argumentos dela. |
| MCP server | O servidor [Model Context Protocol](https://modelcontextprotocol.io) hospedado que a Azion executa em `https://mcp.azion.com/`, onde um agente de código busca na documentação da Azion, em exemplos de código, em comandos da CLI, em operações da API e em recursos do Terraform. Ele responde apenas no host sem caminho, e `/mcp` retorna 404. [MCP server](/pt-br/documentacao/devtools/mcp/) descreve o que ele oferece, e [Configuração de agentes](/pt-br/documentacao/agent-setup/) conecta cada agente de código a ele. |
| `mcp-remote` | O pacote que conecta ao MCP server, por HTTP, um cliente que inicia os servidores dele como processos locais. O `npx` baixa e executa o pacote com a URL do servidor e o header `Authorization`, como em `npx -y mcp-remote@latest https://mcp.azion.com --header "Authorization: Bearer [TOKEN VALUE]"`. [Primeiros passos com o MCP server](/pt-br/documentacao/devtools/mcp/configuracao/) mostra os clientes que o usam. |
| perfil de API | A versão da Azion API, `v3` ou `v4`, à qual uma conta corresponde quando o MCP server autentica o token dela. O perfil decide quais ferramentas o servidor lista: 8 no perfil `v4` e 9 no perfil `v3`, que adiciona `search_azion_api_v3_commands`. [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/) lista todas as ferramentas. |
| personal token | A credencial da Azion que autentica cada requisição ao MCP server: `azion` seguido de 35 letras e dígitos, 40 caracteres no total. Um cliente o envia como `Authorization: Bearer [TOKEN VALUE]` ou `Authorization: Token [TOKEN VALUE]`, que o servidor trata da mesma forma, e uma requisição sem ele recebe 401 `No authentication provided`. [Tokens pessoais](/pt-br/documentacao/fundamentos/personal-tokens/) descreve como um token é criado e quando ele expira. |
| `Pragma: azion-debug-cache` | O header de requisição que faz uma resposta da Azion trazer os headers de debug de cache dela, como `x-cache`, `x-cache-key` e `x-cache-expires-in`. [Teste o comportamento do cache com o MCP server](/pt-br/documentacao/guias/performance-e-confiabilidade/cache-e-purge/testar-cache-com-mcp/) o usa para ler o estado do cache de um site após o deploy, e [Primeiros passos com Cache](/pt-br/documentacao/plataforma/applications/cache/primeiros-passos/) explica `x-cache` e `x-cache-key`. |
| prompt | Um template de mensagem que um servidor Model Context Protocol pode oferecer aos clientes dele. O MCP server da Azion não oferece nenhum, então uma requisição pelos prompts dele retorna `-32601 Method not found`. [Execute um MCP server na Azion](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/executar-mcp-server/) mostra como adicionar prompts a um servidor seu. |
| recurso | Um documento que um cliente lê do MCP server pela URI dele, como lê um arquivo, sem chamar uma ferramenta. O MCP server da Azion disponibiliza sete recursos em Markdown, em `azion://static-site/deploy/` e `azion://static-site/test-cache/`. [Ferramentas e recursos](/pt-br/documentacao/devtools/mcp/ferramentas/) lista cada URI. |
| streamable HTTP | O transporte do Model Context Protocol que o MCP server usa: um cliente envia cada mensagem como um POST HTTP para `https://mcp.azion.com/`, e o servidor responde com uma resposta `text/event-stream`. O servidor não mantém sessão entre requisições e exige TLS 1.3. As configurações de clientes nomeiam esse transporte como `http` ou `streamable-http`, e [Como o MCP server funciona](/pt-br/documentacao/devtools/mcp/como-funciona/) descreve o fluxo de requisição. |
