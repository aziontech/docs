Copie qualquer um destes trechos de JavaScript para uma função como ponto de partida para o seu próprio código. Os exemplos cobrem os padrões para os quais as funções são mais usadas: retornar uma resposta ou um conteúdo JSON, redirecionar tráfego, ler cookies, executar um teste A/B e negar uma requisição por país. Eles são agrupados por onde a função é executada: Applications, para funções que tratam o evento `fetch` em uma aplicação, e Firewall, para funções que tratam o evento `firewall` em um firewall.

Os handlers desta coleção são escritos no padrão Service Worker, que registra o handler com `addEventListener`. Código novo usa ES Modules: consulte [Boas práticas](/pt-br/documentacao/build/functions/boas-praticas/) para o padrão atual e [Migre padrões de handler em Functions](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/functions-e-runtime/migrar-padroes-de-handler/) para o antes e depois de cada handler.
