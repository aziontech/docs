Este glossário define os termos que o [Azion Runtime](/pt-br/documentacao/devtools/runtime/) usa de forma própria. Para os termos que ele compartilha com Functions, como handler, Cell e tempo de relógio, consulte o [glossário de Functions](/pt-br/documentacao/plataforma/functions/glossario/).

| Termo | Definição |
| --- | --- |
| BYOB | Abreviação de Bring Your Own Buffer (traga o seu próprio buffer): uma forma de ler um stream de bytes para um buffer que o seu código fornece, o que evita copiar os dados. [ReadableStreamBYOBReader](/pt-br/documentacao/devtools/runtime/api-reference/readable-byob-reader/) lê um `ReadableStream` dessa forma. |
| `EdgeRuntime` | A string global que o Azion Runtime define, para que o código teste `typeof EdgeRuntime === 'string'` e detecte que executa nele. Em uma function após o deploy, o valor é `azion`, e no `azion dev` é `edge-runtime`. [Web APIs](/pt-br/documentacao/devtools/runtime/api-reference/javascript/#propriedade-edgeruntime) mostra as três formas de ler esse valor. |
| `FetchEvent` | O evento que o Azion Runtime passa a um listener registrado com `addEventListener` para o tipo `fetch`. Ele carrega a requisição recebida em `event.request` e recebe a resposta por meio de `event.respondWith()`, como [FetchEvent](/pt-br/documentacao/devtools/runtime/api-reference/fetch-event/) descreve. Ele pertence ao padrão Service Worker, que o glossário de Functions define. |
| metadados | O objeto de valores sobre cada requisição que uma function em uma aplicação ou em um firewall lê de `request.metadata`, como a localização GeoIP do cliente, o endereço dele, detalhes de TLS, fingerprints e identificadores. No `azion dev`, o objeto é `undefined`. [API de metadados](/pt-br/documentacao/devtools/runtime/api-reference/metadata/) lista todas as chaves. |
| Parcialmente suportado | O rótulo de status que a tabela de [APIs do Node.js](/pt-br/documentacao/devtools/runtime/node/) dá a um módulo do Node.js, ou que a página de um módulo dá a um método, do qual apenas alguns métodos ou recursos estão disponíveis. A página de cada módulo lista o status dos seus métodos. |
| polyfill | Código que leva um recurso a um ambiente que não o tem, como uma API do Node.js que o Azion Runtime não implementa. O Azion Bundler adiciona polyfills no momento do build, e a propriedade `polyfills` do [objeto build](/pt-br/documentacao/devtools/cli/azion-config-js/#build) no `azion.config.js` controla isso. [APIs do Node.js](/pt-br/documentacao/devtools/runtime/node/) lista os módulos que os polyfills resolvem. |
| preset | Um conjunto de configurações padrão de build para um framework ou uma linguagem que o Azion Bundler aplica quando faz o build de um projeto para o Azion Runtime, como `javascript`, `typescript`, `emscripten` para C++, `rustwasm` para Rust ou `vue`. [Azion CLI presets](/pt-br/documentacao/devtools/cli/recursos/presets/) lista todos os presets. |
| Somente para build | O rótulo de status que a tabela de [APIs do Node.js](/pt-br/documentacao/devtools/runtime/node/) dá a um módulo do Node.js, ou que a página de um módulo dá a um método, incluído para que o build seja concluído, embora as chamadas dele não funcionem em tempo de execução. Quando um módulo se comporta de forma diferente do seu rótulo, a página dele informa como o módulo se comporta. |
| strict mode | O modo do JavaScript que o Azion Runtime aplica por padrão e exige. Ele transforma alguns erros silenciosos do JavaScript em erros lançados e proíbe algumas sintaxes que versões posteriores do ECMAScript podem definir, como [Como o Azion Runtime funciona](/pt-br/documentacao/devtools/runtime/como-funciona/) descreve. |
| structured clone | O algoritmo que duplica objetos complexos do JavaScript e que `structuredClone()` executa. Ele recusa funções, símbolos, `WeakMap` e promises com `DataCloneError`, e [structuredClone](/pt-br/documentacao/devtools/runtime/api-reference/structured-clone/) lista o que mais ele altera na cópia. |
| Suportado | O rótulo de status que a tabela de [APIs do Node.js](/pt-br/documentacao/devtools/runtime/node/) dá a um módulo do Node.js, ou que a página de um módulo dá a um método, que funciona em tempo de execução. Quando um módulo se comporta de forma diferente do seu rótulo, a página dele informa como o módulo se comporta. |
| WinterTC | O Comitê Técnico da Ecma International, TC55, que padroniza uma API mínima comum para runtimes JavaScript server-side com interoperabilidade web. A Azion participa dele, e [Web APIs](/pt-br/documentacao/devtools/runtime/api-reference/javascript/#conformidade-com-wintertc) descreve o que isso significa para o código no Azion Runtime. |
