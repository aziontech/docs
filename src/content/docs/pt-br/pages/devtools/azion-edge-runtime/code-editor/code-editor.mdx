O editor de código é onde você escreve o JavaScript de uma [função](/pt-br/documentacao/build/functions/) em Azion Console. Ele é construído sobre o [Monaco Editor](https://microsoft.github.io/monaco-editor/docs.html), o editor usado pelo [VS Code](https://code.visualstudio.com/). Cada função carrega o código dela na aba **Code**, que abre com um código inicial que você substitui. **Save** armazena o código e torna a função disponível para ser instanciada em uma aplicação. Editar uma função requer a permissão **Edit Functions** na conta. Para o caminho que alcança o editor a partir do Azion Console, consulte [Primeiros passos](/pt-br/documentacao/build/functions/primeiros-passos/).

---

## Recursos do editor

O editor de código carrega estes recursos do Monaco Editor:

- Syntax highlighting
- IntelliSense
- Debugging

O editor suporta os [globals e tipos](/pt-br/documentacao/devtools/runtime/api-reference/azion-runtime-globals/) e as [Web APIs](/pt-br/documentacao/devtools/runtime/api-reference/javascript/) que [Azion Runtime](/pt-br/documentacao/devtools/runtime/) implementa. O menu de contexto do editor também carrega o comando **Format Document**.

---

## Preview do código

O editor de código mostra a resposta da função enquanto você a escreve, sem um deployment. O preview chama uma função `PreviewProvider` no código-fonte, que monta uma requisição simulada. Para conhecer a função auxiliar e os formatos que o preview renderiza, consulte [Preview deployment](/pt-br/documentacao/build/functions/preview-deployment/).

---

## Integração com ChatGPT

O editor de código chama as APIs do ChatGPT, então a assistência de código é executada dentro do editor e não em uma guia separada. A integração cobre:

- Explicação de código
- Geração de código
- Refatoração de código
- Debugging

A integração usa as credenciais da sua própria conta OpenAI, declaradas no código-fonte da função. Para conhecer as credenciais e os comandos do editor, consulte [Integração com ChatGPT](/pt-br/documentacao/build/functions/ai-integration/).
