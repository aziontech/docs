O módulo `node:http` reúne os utilitários do Node.js para servidores e clientes HTTP. No Azion Runtime, o build aceita `import http from "node:http"`, e as constantes do módulo podem ser lidas em uma function com deploy feito e com `azion dev`. `http.STATUS_CODES[404]` retorna `Not Found`, e `http.METHODS` lista 35 métodos.

As funções de cliente e servidor não estão implementadas. `http.request`, `http.get` e `http.createServer` existem como funções, mas uma chamada a qualquer uma delas lança um `Error`. `http.request()` lança `[unenv] http.request is not implemented yet!`, e `http.createServer()` lança `[unenv] http.createServer is not implemented yet!`. O módulo `node:https` se comporta da mesma forma: `https.get()` lança `[unenv] https.get is not implemented yet!`. Para enviar uma requisição HTTP a partir de uma function, use a [Fetch API](/pt-br/documentacao/devtools/runtime/api-reference/fetch/).

`_connectionListener`, `setMaxIdleHTTPParsers`, `validateHeaderName` e `validateHeaderValue` não têm suporte.
