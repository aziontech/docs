## Sobre este template

Este template é construído com [Astro](/pt-br/documentacao/devtools/runtime/frameworks/astro/) e integra o Nano Stores, uma biblioteca minúscula de gerenciamento de estado que mantém os dados sincronizados entre componentes escritos em qualquer framework. É uma ótima opção para recursos interativos como carrinhos de compras, em que o mesmo estado precisa ser compartilhado entre ilhas distintas. Implantado na Azion, ele é servido por meio de uma arquitetura distribuída para uma entrega rápida e distribuída globalmente.

## Principais recursos

- Estado compartilhado e agnóstico de framework com o Nano Stores
- Footprint mínimo em runtime, mantendo os bundles do cliente reduzidos
- Stores reativas que permanecem sincronizadas entre ilhas independentes do Astro
- Entrega otimizada para o edge pela Azion, com baixa latência em todo o mundo
