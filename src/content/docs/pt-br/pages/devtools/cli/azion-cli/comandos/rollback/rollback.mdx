O comando `rollback` da Azion CLI faz um site estático servir de novo os arquivos de um deploy anterior. Esses arquivos ficam no bucket do [Object Storage](/pt-br/documentacao/plataforma/object-storage/) do projeto, e o comando atua por meio do [connector](/pt-br/documentacao/plataforma/connectors/) de storage que os entrega. As opções que todo comando aceita, como `--format`, `--out` e `-y`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion rollback` atua sobre o connector de storage cujo ID você passa:

```bash
azion rollback [flags]
```

| Flag | Curta | Tipo | Padrão | Descrição |
| --- | --- | --- | --- | --- |
| `--config-dir` | — | string | `"azion"` | Caminho relativo para a pasta que guarda os seus arquivos `azion.json` e `args.json`. |
| `--connector-id` | — | int | — | ID do connector de storage que entrega os arquivos estáticos do site. `azion deploy` grava esse ID na entrada `connectors` de `azion/azion.json`. |
