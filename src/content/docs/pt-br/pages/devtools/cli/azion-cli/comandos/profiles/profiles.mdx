O comando `profiles` da Azion CLI mostra os perfis configurados na sua máquina e troca o perfil ativo. Um perfil guarda o personal token de uma conta, então vários perfis permitem trabalhar com várias contas ou ambientes a partir da mesma máquina. Para criar ou excluir um perfil, use os comandos de [Azion CLI profile](/pt-br/documentacao/devtools/cli/recursos/profile/). As opções que todo comando aceita, como `--debug` e `--timeout`, estão em [Opções globais](/pt-br/documentacao/devtools/cli/globals/).

---

## Uso

`azion profiles` abre um seletor com todos os perfis que você configurou:

```bash
azion profiles [flags]
```

O comando não tem flags próprias. `-h` ou `--help` imprime a ajuda do comando.

O seletor é interativo: mova o cursor com as setas do teclado e pressione Enter para escolher um perfil. O comando precisa de um terminal para ler a sua escolha. Sem um, como em um script, ele imprime a lista e termina com `Error: EOF`. Nenhum comando lista os perfis sem um seletor.

O seletor sempre abre com o cursor em `default`, qualquer que seja o perfil ativo. Para ver o perfil ativo, execute [`azion whoami`](/pt-br/documentacao/devtools/cli/whoami/), que o imprime como `Active Profile`.

---

## Exemplos

Este comando abre o seletor em uma máquina com dois perfis, `default` e `my-profile`:

```bash
azion profiles
```

O comando lista os perfis, com o cursor em `default`:

```text
? Choose a profile:  [Use arrows to move, type to filter]
> default
  my-profile
```

Depois que você move o cursor para `my-profile` e pressiona Enter, o comando substitui a lista pela sua escolha e não imprime mais nada:

```text
? Choose a profile: my-profile
```

`my-profile` passa então a ser o perfil ativo, e o `~/.azion/profiles.json` o indica:

```text
Name = 'my-profile'
```
