As páginas desta seção usam os termos abaixo no sentido que [Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/) dá a eles.

| Termo | Definição |
| --- | --- |
| Default Tag | Uma das duas formas da tag JavaScript do Edge Pulse que Azion Console fornece. Ela espera a conclusão do evento de carregamento da página e então baixa e executa o RUM Client, para que esse evento não seja interrompido. Para saber onde ela entra na página, consulte [Tag JavaScript do Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/tag-javascript/). |
| identificador de visitante | O valor que distingue as medições de um visitante das de outro. Edge Pulse o gera com o algoritmo UUID4, a forma aleatória do identificador único universal, e o mantém no local storage do browser. Para saber como a configuração `navigator.doNotTrack` altera o tempo de vida desse valor, consulte [Tag JavaScript do Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/tag-javascript/). |
| Pre-loading Tag | Uma das duas formas da tag JavaScript do Edge Pulse que Azion Console fornece, para uma página cujas configurações de Content Security Policy impedem o uso de JavaScript inline. Ela é executada antes que o evento de load seja disparado. Para escolher entre as duas tags, consulte [Tag JavaScript do Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/tag-javascript/). |
| pulseEvents | O dataset que guarda as medições do Edge Pulse na API GraphQL do Real-Time Events, e o que deve ser consultado. O `edgePulseEvents`, mais antigo, está descontinuado, e o schema avisa. Para os campos dele, consulte [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/). |
| RUM Client | O componente que a tag JavaScript do Edge Pulse baixa e executa no browser do visitante, e que realiza as medições. A **Default Tag** espera a conclusão do evento de carregamento da página antes de baixá-lo. Para saber qual tag o baixa e quando, consulte [Tag JavaScript do Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/tag-javascript/). |
| tag JavaScript do Edge Pulse | O script que você adiciona a uma página para que Edge Pulse a meça. Azion Console o fornece em duas formas, a **Default Tag** e a **Pre-loading Tag**, e uma tag cobre uma página. Para saber o que ela coleta e quais configurações do browser ela respeita, consulte [Tag JavaScript do Edge Pulse](/pt-br/documentacao/plataforma/edge-pulse/tag-javascript/). |
| teste | Uma medição que o browser de um visitante realiza contra endereços da infraestrutura distribuída da Azion. Edge Pulse repete o teste em um intervalo fixo para cada visitante, e os resultados vão para os servidores de processamento da Azion. Para saber quantos endereços um teste cobre e qual é o intervalo entre os testes, consulte [Como o Edge Pulse funciona](/pt-br/documentacao/plataforma/edge-pulse/como-funciona/). |
