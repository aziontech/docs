[Real-Time Events](/pt-br/documentacao/plataforma/real-time-events/) usa os termos deste glossário com um significado próprio.

| Termo | Definição |
| --- | --- |
| Activity History | Uma das oito fontes de dados do Real-Time Events. Guarda um registro por ação executada em uma conta Azion, conforme [Activity History](/pt-br/documentacao/fundamentos/activity-history/) a registra, e mantém esse registro por 2 anos. Para as variáveis que o registro carrega, consulte [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/#activity-history). |
| Data Scan | Uma das duas métricas pelas quais Real-Time Events é cobrado, cobrada por GB. Mede o volume de dados que uma consulta lê, portanto uma busca sobre um período amplo escaneia mais que uma busca estreita. Para o volume incluído por mês, consulte [Limites](/pt-br/documentacao/plataforma/real-time-events/limites/). |
| dataset | O nome que a API GraphQL do Real-Time Events dá a uma fonte de dados, e a palavra que a visualização mais recente do Azion Console usa para ela. Um dataset nomeia seus campos em camelCase, portanto a variável `Remote Address` na classic view do Azion Console é o campo `remoteAddress` em uma consulta, e um payload do [Data Stream](/pt-br/documentacao/plataforma/data-stream/) escreve o mesmo campo em snake_case. [Campos da API GraphQL do Real-Time Events](/pt-br/documentacao/devtools/graphql/campos-gql-real-time-events/) lista cada dataset e seus campos. |
| filtro de tempo | O limite do período que uma busca cobre, aplicado sobre a fonte de dados: a fonte de dados decide quais registros são lidos e o filtro de tempo decide até onde a busca alcança no passado. Um intervalo personalizado alcança tão longe quanto a retenção permite. [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/#filtro-de-tempo) descreve como os dois se combinam. |
| fonte de dados | O produto ou serviço da Azion que gerou os eventos que você consulta. Em uma consulta, ela é o índice de onde os registros são lidos, portanto toda busca seleciona uma. [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/) documenta as oito que Real-Time Events expõe e as variáveis que cada uma carrega. |
| GraphiQL Playground | O cliente de navegador que a API GraphQL do Real-Time Events serve em `https://api.azion.com/v4/events/graphql`, onde você compõe e executa uma consulta contra um dataset. Para obter um token e enviar uma primeira consulta, consulte [Primeiros passos da API GraphQL](/pt-br/documentacao/devtools/graphql/primeiros-passos/). |
| registro de evento | Uma entrada que uma fonte de dados guarda: o conjunto de variáveis que um produto escreveu para um único evento, como uma requisição, uma consulta DNS ou uma ação na conta. [Como Real-Time Events funciona](/pt-br/documentacao/plataforma/real-time-events/como-funciona/) acompanha um registro do produto que o escreve até a consulta que o lê. Para abrir um registro e ler suas variáveis, consulte [Ler um registro de evento](/pt-br/documentacao/guias/plataforma/observabilidade/entender-logs/). |
| retenção | Por quanto tempo Real-Time Events mantém um registro de evento consultável. Os registros são mantidos por 7 dias, equivalentes a 168 horas, e os registros de Activity History por 2 anos. [Limites](/pt-br/documentacao/plataforma/real-time-events/limites/) carrega os dois valores e os limites que uma consulta carrega. |
| Storage | Uma das duas métricas pelas quais Real-Time Events é cobrado, cobrada por GB. Mede o volume de registros de eventos mantidos. Para o volume incluído por mês, consulte [Limites](/pt-br/documentacao/plataforma/real-time-events/limites/). |
| variável | O nome que a classic view do Azion Console dá a um campo de um registro de evento. Cada fonte de dados carrega seu próprio conjunto, portanto as variáveis de um registro de HTTP Requests diferem das de um registro de Edge DNS. [Fontes de dados](/pt-br/documentacao/plataforma/real-time-events/fontes-de-dados/) lista as variáveis das oito, e [Filtrar eventos](/pt-br/documentacao/guias/plataforma/observabilidade/adicionar-filtros-events/) mostra como uma busca se reduz a uma delas. |
