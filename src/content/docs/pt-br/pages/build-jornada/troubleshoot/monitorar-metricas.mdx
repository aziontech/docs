Depois de criar applications, você também conta com os produtos de [Observe](/pt-br/documentacao/) para monitorar os comportamentos e o desempenho delas.

- [Real-Time Metrics](/pt-br/documentacao/plataforma/real-time-metrics/): acesso a gráficos com dados agregados para explorar comportamentos durante períodos mais longos de armazenamento de dados.
- [API GraphQL](/pt-br/documentacao/devtools/graphql/visao-geral/): acesso a dados agregados e brutos via API com consultas personalizadas, apenas com os dados solicitados.
- [Real-Time Events](/pt-br/documentacao/observe/real-time-events/): acesso a logs com dados brutos para realizar análises mais detalhadas.
