Você pode fazer o deploy de um site Jekyll na Azion a partir de um template no Azion Console ou com a [Azion CLI](/pt-br/documentacao/devtools/cli/). Os dois caminhos entregam um site Jekyll que roda na Azion e responde em um domínio da Azion.

A Azion serve um site Jekyll como uma aplicação estática. A configuração do projeto envia a pasta `./_site` para um bucket de armazenamento, e uma [aplicação](/pt-br/documentacao/plataforma/applications/) serve os arquivos desse bucket. Para os outros frameworks de que a Azion faz o build, consulte [Compatibilidade com web frameworks](/pt-br/documentacao/devtools/runtime/frameworks/compatibilidade-frameworks/).

## Pré-requisitos

- Uma conta na Azion. Para criar uma, consulte [Criar uma conta](/pt-br/documentacao/fundamentos/criar-uma-conta/).

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

- Acesso ao Azion Console. Para entrar, consulte [Como acessar o Azion Console](/pt-br/documentacao/guias/plataforma/conta-e-billing/como-acessar-o-azion-console/).
- Uma conta no GitHub. O deploy do template pede que você a conecte.

</Fragment>

<Fragment slot="panel.cli">

- A Azion CLI instalada e com login feito. Para configurá-la, consulte [Primeiros passos com a Azion CLI](/pt-br/documentacao/devtools/cli/primeiros-passos/).
- Node.js 18 ou posterior e o npm.
- Ruby e Bundler.
- Um terminal e um editor de código.

</Fragment>

## Templates Jekyll

Cada template é um projeto Jekyll do qual a Azion faz o deploy para você. O caminho pelo Console começa por um destes templates:

| Template | Uso |
| --- | --- |
| [Jekyll Boilerplate](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/jekyll-boilerplate/) | Projeto inicial |
| [Jekyll Cart](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/jekyll-ecommerce-collection/) | Carrinho de compras |
| [Supply](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/frameworks/jekyll-ecommerce-collection/) | E-commerce |

Jekyll Cart e Supply compartilham um guia. Para mais informações sobre templates, consulte [Marketplace da Azion](/pt-br/documentacao/plataforma/marketplace/). No caminho pela CLI, o seletor de templates do `azion init` lista os mesmos três templates.

## Faça o deploy do site

Cada caminho faz o build do projeto Jekyll e cria os recursos que o servem na Azion. Use o painel do seu caminho:

<Tabs client:visible sharedStore="interface">

<Fragment slot="panel.console">

Para fazer o deploy de um template Jekyll pelo Azion Console:

<DocSteps>
  <DocStep title="Abra os templates">

  Acesse [Azion Console](https://console.azion.com/) > **Create** > **Templates**.

  </DocStep>
  <DocStep title="Pesquise por Jekyll">

  Em **Search by name, framework, or keyword**, digite `Jekyll`.

  </DocStep>
  <DocStep title="Selecione um template Jekyll" />
  <DocStep title="Conecte sua conta do GitHub">

  Quando o formulário mostrar **GitHub Connection**, selecione **Connect with GitHub**. Depois, instale o [Azion GitHub App](/pt-br/documentacao/guias/desenvolvimento-de-aplicacoes/automacao/azion-github-app/).

  </DocStep>
  <DocStep title="Selecione um Git Scope">

  Em **Git Scope**, selecione o escopo do template.

  </DocStep>
  <DocStep title="Preencha as configurações que o template solicita" />
  <DocStep title="Selecione Deploy" />
</DocSteps>

A página do deploy abre e mostra o **Deploy Log** durante o build. Depois de um deploy bem-sucedido, a página mostra **Successfully created!**, a URL do domínio e um botão **Manage** que abre a aplicação.

</Fragment>

<Fragment slot="panel.cli">

Para criar o projeto, execute `azion init` e dê um nome a ele. No seletor de presets, selecione _Jekyll_. No seletor de templates, selecione um template:

```bash
azion init --name my-site --auto -y
```

Com `-y`, o comando instala as dependências. Com `--auto`, ele não pergunta sobre um servidor de desenvolvimento local nem sobre um deploy. Para as perguntas que ele faz sem essas opções, consulte [Azion CLI init](/pt-br/documentacao/devtools/cli/init/). Com o template _Jekyll Boilerplate_, a saída é:

O projeto fica em uma pasta `my-site`. O arquivo `azion.config.cjs` dele define o preset `jekyll`. Ele também envia `./_site` para um bucket de armazenamento que os workloads podem ler, mas não alterar. Para todas as configurações do arquivo, consulte [azion.config.js](/pt-br/documentacao/devtools/cli/azion-config-js/).

Para fazer o build do site, vá para a pasta do projeto e execute `azion build`:

```bash
cd my-site
azion build
```

O comando executa o Azion Bundler com o preset `jekyll`, que executa `bundle install && bundle exec jekyll build`. Por isso, a versão do Bundler que o `Gemfile.lock` indica precisa estar instalada. Para as flags do comando, consulte [Azion CLI build](/pt-br/documentacao/devtools/cli/build/).

Para fazer o deploy do site, execute `azion deploy` na pasta do projeto:

```bash
azion deploy
```

O comando envia o projeto e abre no navegador a página do deploy no Console. Ele também imprime a URL dessa página, para quando o navegador não abrir. No final, ele imprime a URL do domínio do site. Para a saída completa e todas as flags, consulte [Azion CLI deploy](/pt-br/documentacao/devtools/cli/deploy/).

Para testar o site na sua máquina antes do deploy, consulte [Azion CLI dev](/pt-br/documentacao/devtools/cli/dev-comando/). Para um projeto Jekyll que já existe, execute `azion link` na pasta dele e selecione o preset Jekyll. Para mais informações, consulte [Azion CLI link](/pt-br/documentacao/devtools/cli/link-comando/).

## Verifique o site

O deploy fornece a URL do domínio da Azion do site, no formato `https://xxxxxxxxxx.map.azionedge.net`. A página do deploy no Console mostra a URL, e o `azion deploy` a imprime no final. Abra a URL em um navegador para ver o site Jekyll.

O primeiro deploy pode levar vários minutos para responder em todas as localidades; os deploys seguintes levam cerca de dois minutos. Uma localidade que ainda não tem o site responde com uma página `404` que diz `There's nothing here yet`. Se você receber essa resposta, aguarde e solicite a URL novamente.
