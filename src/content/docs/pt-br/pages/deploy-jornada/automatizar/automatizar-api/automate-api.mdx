## O que você pode automatizar

Com a API da Azion, você pode criar, configurar e gerenciar seus recursos de forma programática, em vez de operar o console manualmente. Cenários comuns de automação incluem provisionar Applications e Functions, atualizar regras e configurações de cache, gerenciar domínios e certificados digitais e integrar essas operações aos seus pipelines de CI/CD para implantações repetíveis e versionadas.
